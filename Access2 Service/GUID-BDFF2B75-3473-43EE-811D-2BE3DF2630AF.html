Pack Monitoring Theory of Operation

Purpose

Pack Monitoring uses the pressure monitor in the main pipettor to sense whether sufficient reagent is dispensed for testing. Reagent pack monitoring can detect unexpected levels of reagent in the pack, and as a result avoid errors because of improper pack loading.

Overview

Table 78: Overview of Pack Monitoring
Part Function
Data storage Dispense measurements are stored in the console database. The instrument sends dispense data at the conclusion of every reagent dispense. The console stores the measurement in the database and determines whether the dispense is good.
Filter Value The Filter Value is the average measurement of acceptable pressure readings for a particular pack well within a particular assay.

Each particular assay well has it own filter.

Example: Folate well 1 and TSH well 1 have different filters.

Hardware Obstruction detection PCB, obstruction detection cables, I/O PCB, and CPU PCB.

The Stepper Motor Controller PCB is involved indirectly via control of the precision pump motion timing.

Pipettor Reset This feature is for enabling the pipettor after the pipettor is disabled because of five sequential insufficient reagent measurements. A disabled pipettor sets the instrument to Not Ready. The pipettor stays disabled through initialization and PC and instrument reboots.

To enable the pipettor, select Diagnostics > Device Diagnostics > Reset Pipettor.

Reagent Inventory Screen When a reagent pack has three bad dispenses, the supply screen updates to show the reagent pack as red. No new tests are scheduled to this reagent pack. After this reagent pack is unloaded from the reagent inventory, it is deleted from inventory.

Result Flag Test results with low dispense pressures detected are flagged with QSD. The results with the QSD flag are suppressed.
Service Reset

This password-protected feature is for service engineer to reset all filter values for new pressure monitor hardware or drastic fluidics changes. The filter values are reset to avoid flagged results and wasted QC material if the values drastically shift because of service.

To access this feature:
  1. Select Diagnostics > Device Diagnostics > Analog Devices > Pressure Monitor.
  2. Select Service Reset.
  3. Enter the Password Access2Support.
  4. Select OK > OK.
Note: The Service Reset button only resets Pack Process Monitoring. The Service Reset button does not impact Obstruction Detection features.

Process and Logic

The detection and analysis process performed by software:

  1. The area of the dispense is measured.
    1. The pressure sensor measures the Baseline when there is no fluid movement in the system, before each reagent dispense measurement.
    2. The pressure sensor measures the Qualified Area and the Residual Area.
    3. The Adjusted Pressure Measurement is calculated by removing the Baseline.
  2. The reagent dispense is checked for monitoring eligibility. Values that meet these requirements are monitored.
    • Aspiration volume >25 µL
    • Dispense Volume
      • 25 to 400 µL for software versions 3.4.2 (Access 2) or 6.1 (Access2i) and below
      • 40 to 400 µL for software versions 3.4.3 (Access 2) or 6.2.3 (Access2i) and above
    • For dispense with a wash buffer chase dispense: The ratio of the aspiration to dispense volume minus air gaps >0.50
      Note: The equation for the ratio = aspiration volume / (dispense volume - 15).
  3. The area and failure pattern in analyzed. More than one of the following scenarios can occur per test replicate.

FAQ

Topic Frequently Asked Questions
Obstruction Detection
  1. How are obstruction detection and pack monitoring different?
    • Obstruction detection monitors samples for higher than expected pressures. A reference curve is generated. Obstruction detection is optional.
    • Pack monitoring monitors reagent dispense for lower than expected pressures. Pack monitoring averages pack dispense over time rather than using a reference curve. Pack monitoring is not optional with 3.4 and higher software.
  2. Will pack monitoring work when sample obstruction detection is disabled or not calibrated?
    • Yes, as long as the pressure monitor hardware is functional. Regardless of the obstruction detection settings, pack monitoring will turn on with 3.4 software.
  3. Can obstruction detection be disabled with 3.4 software?
    • Yes. Obstruction Detection remains unchanged with 3.4 software. The customer can enable or disable Obstruction Detection.
Pack Monitoring
  1. Can pack monitoring be disabled?
    • No.
  2. Is calibration required?
    • No pack monitoring calibration is required. The calibration occurs during the first 5 replicates from an assay, the first time the instrument runs that assay after 3.4 software is installed.
  3. What size of reagent dispenses are monitored?
    • Aspiration volume >25 µL
    • Dispense Volume
      • 25 to 400 µL for software versions 3.4.2 (Access 2) or 6.1 (Access2i) and below
      • 40 to 400 µL for software versions 3.4.3 (Access 2) or 6.2.3 (Access2i) and above
    • The ratio of the aspiration to dispense volume minus air gaps >0.50 T
    Note: Software monitors the dispense of multiple wells per reagent pack so each assay has one or more wells monitored.
  4. Why is obstruction detection an improvement over the IND flag?
    • Some assays do not have an IND flag. These typically include assays which have a valid result of 0.0.
  5. Will pack monitoring detect wrong pack loaded scenarios?
    • Current pack monitoring is not designed for this feature. The majority of CF linked to CAPA 14932 are for missing packs, where no pack was present at all. Wrong pack loaded scenarios will only be detected if the pack physically located in the reagent carousel slot has an unused reagent well in the well position where the expected assay monitors for pack detection.
  6. Will pack monitoring detect every shared pack?
    • If a test result has one low pressure reagent well dispense the result will be flagged QSD and the results supressed.
    • Additional tests may begin processing before that reagent pack is disabled. Three low pressure dispenses on one reagent pack will set the reagent pack to disabled.
  7. How does the pipettor disable feature work?
    • The pipettor is disabled when five sequential dispenses occur with Qualified Area <90% (regardless of well or reagent pack). This prevents the instrument from disabling all of the reagent packs and stops the instrument in the case of a leaking pipettor.
