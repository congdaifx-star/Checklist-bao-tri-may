PCB - BCR Cable Interface

Purpose

This Procedure provides information regarding the BCR Cable Interface PCB.

Note:
  • This PCB is referred to as the BCR Cable Interface due to the function of the PCB but is also referred to as the RSI Cable Interface. The BCR and RSI are interchangeably used.
  • The BCR Cable Interface PCB can only be found on the Access 2 - Enhanced System at the time of system release. In the future, it may also be used for obsolescence purposes for the standard Access 2 systems.
  • The BCR Cable Interface PCB is a digital signal converter between the Bar Code Readers Ribbon Cable and the Bar Code Reader cables that go back to the Sample/Reagent Interface PCB.
  • There are two on each system - one each for the Sample BCR and the Reagent BCR (The Internal Reagent BCR is a new feature for Access 2 - Enhanced systems).
  • There is a Ribbon (Flex) Cable that goes from the Bar Code Reader to J1 of the BCR Cable Interface PCB.
  • The Sample BCR Cable goes from J2 on the BCR Cable Interface PCB to J11 on the Sample/Reagent Interface PCB.
  • The Reagent BCR Cable goes form J2 on the BCR Cable Interface PCB to J10 on the Sample/Reagent Interface PCB.
