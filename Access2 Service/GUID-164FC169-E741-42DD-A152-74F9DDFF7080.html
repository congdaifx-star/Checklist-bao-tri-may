Replacing Interface PCB (Access 2)

This procedure describes how to replace the sample/reagent module interface PCB.

This document provides instructions for removing the original style sample/reagent module interface PCB and replacing it with the new style sample/reagent module interface PCB.
Caution: This procedure is associated with the (audible) Noise Reduction Modification and is for use with Access 2 ONLY.
  1. Remove the on-board reagent packs.
    1. Select Main Menu > Supplies. Select a reagent pack and then select Unload Reagent Pack.
    2. When prompted, open the reagent carousel door and unload the reagent pack from the system. Select Done.
    3. Repeat, until all the reagent packs have been unloaded from the system.
    4. If the packs will not be reloaded onto this system, then discard the packs and delete the packs from the Reagent Inventory.
  2. Verify the correct operation of the cooling system before performing this procedure.
    1. Select Main Menu > Diagnostics Screen > Device diagnostics > Analog devices > Analog data.
    2. Verify that the reagent temperature is within the acceptable range of +1 °C to +5 °C on the Temperature/Voltage Status screen.
      Note: Under normal startup conditions, the reagent carousel temperature is within the acceptable temperature range within one hour.
    3. Verify that the duty cycle is below 0.80%.
      Note: If the reagent carousel temperature is out-of-limits, then the duty cycle is higher as the Peltiers works harder to correct the temperature. Under normal startup conditions, the reagent carousel duty cycle is within the acceptable range within one hour.
      • If the temperature or duty cycle are out-of-range, then refer to the Replacing Peltier (Access 2) and Replacing Reagent Carousel Thermistor procedures.
  3. Remove the old style PCB.
    1. Power off the instrument.
    2. Disconnect the waste bag from the waste chute and remove the instrument upper and lower front covers.
    3. Label or mark the connectors before you remove them from the old PCB, for reference in the installation of the new PCB.
    4. Remove the four screws to release the PCB from the bracket. Use the metallic washer (normally on the upper right screw only) with the original screws and white standoff when the new PCB is installed.
      Caution: When removing the four screws to remove the PCB, do not lose the four white plastic standoffs from behind the PCB.
  4. Install the new style PCB.
    1. Install the interface PCB onto the existing bracket. Install the four screws to attach the PCB to the bracket. Use the metallic washer (normally on the upper right screw only) with the original screws and white standoff when the new PCB is installed.
      Note: When installing the new PCB, remember to install the white plastic standoffs.
    2. Reconnect all connectors.


      For reference, J8 and J23 are not used.
    3. Reinstall the instrument upper and lower front covers.
    4. Reinstall waste bag.
    5. Power on the instrument.
  5. Verify system operation after installation of the sample and reagent carousels module.
    1. Initialize and verify that the system reaches the Ready mode.
    2. Select Main Menu > Diagnostics Screen > Device diagnostics > Analog devices > Analog data.
    3. Verify that the reagent temperature is within the acceptable range of +1 °C to +5 °C on the Temperature/Voltage Status screen.
      Note: Under normal startup conditions, the reagent carousel temperature is within the acceptable temperature range within one hour.
    4. Verify that the duty cycle is below 0.80%.
      Note: If the reagent carousel temperature is out-of-limits, then the duty cycle is working harder to correct the temperature. Under normal startup conditions, the reagent carousel duty cycle is within the acceptable range within one hour.
    5. Reload any reagent packs onto the reagent carousel.
    6. Perform a System Check.
  6. Verify system operation.
    1. Perform the required system verification.
      Note: Refer to the Verification of Preventive Maintenance document.
    2. Contact your local support organization with any questions or concerns.
