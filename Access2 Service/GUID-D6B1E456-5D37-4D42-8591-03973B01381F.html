Software Version 3.6.0

Software version 3.6.0 release notes

Intended Use

For Internal Use Only - Sensitive data intended for use within BCI and normally shared with employees. There may be an occasional need to distribute this data outside the company with Management approval.

Software version 3.6.0 feature details

  • Reagent pack barcode lot scale up – Software is able to read new reagent barcode schema that expands the range of pack serial and ID numbers that can be used. This will allow for larger reagent builds to be made and reduce the number of reagent pack lot numbers that a customer may see. The feature is available in the software but will not be implemented until a future date. The existing barcode schema will continue to be compatible with software version 3.6.0.

  • Reagent pack lot correction factor – Feature to adjust the calibration dose concentrations for a reagent pack lot number to reduce lot to lot variability when switching to a new pack lot number. Each reagent pack lot number will have a specific correction factor. The correction factor is contained in the reagent pack barcode schema. Software version 3.6.0 will have the capability to read the correction factor in the pack barcode but the feature will not be implemented in pack barcodes until a later date.

  • Level sense maximum depth height for 0.5 and 2.0 ml cups – The maximum depth parameter for 0.5 and 2.0 ml cups is being modified to prevent a scenario where a level sense error may not occur if the operator does not put at least the minimum required dead volume of fluid in the cup.

  • Automatic instrument reboot prior to software load – The instrument (AU) will be automatically rebooted before system software version 3.6.0 is installed if it hasn’t been rebooted within the past 24 hours. This will prevent software load failures due to files not being updated during the load because they were in use or not properly shut down.

  • Waste bag monitoring during system initialization – Feature will prevent the instrument from initializing if a waste bag is not detected. This will prevent RVs with hazardous waste from being ejected onto the instrument baseplate.

  • Reagent pack and calibration expiration added to supplies screen – The customer will be alerted when the reagent packs and/or calibration curves will expire within the next 72 hours. Hours to expiration will count down to 0 and will update in the supplies screen after exiting and re-entering the screen within the 72 hour window of expiration.

  • Event log message for APF or software loads – A message will be posted to the event log when system software or the APF is loaded to indicate it was successful.

  • Substrate dispense pump resolution change – The uL/step for the substrate pump changes from 0.327 to 0.320. Original value was based on an incorrect pulley diameter. Same pump resolution change has already been made for DxI.

  • Add cancel button to reagent pack loading – The “cancel” button was inadvertently removed from the reagent pack loading screen on current software versions. This forced the operator to wait up to 2 minutes for processing to finish before they could access another screen. The cancel button will be added back.

  • APF drive recognition – Feature to allow the APF to be loaded when the CD drive is not recognized by the PC as the D: drive. The APF can be loaded from whatever drive the PC is able to see.

  • Reagent lot number associated with test ID – Feature will not allow a reagent pack to be loaded on the instrument if the same lot number is detected with a different test ID. The instrument currently assigns a duplicate pack lot number the test that it was originally loaded as. This will prevent inadvertent reuse of lot numbers between filling sites.

  • Authenticate reagent and substrate bar codes - This feature will not allow a reagent pack or substrate lot number to be loaded on the instrument unless it is recognized as an authentic BEC lot number. Counterfeit packs will be prevented from loading on the instrument.

  • Updated event log messages and system help files – Event log messages for the new features in this software version were created and the system help files were updated.

Implementation

  • Access 2 software version 3.6.0 will be released as Mod 12132 for all instruments in all geographies.
  • Software version 3.6.0 is considered customer installable but will also be installed by FSEs as a result of the Mod.
  • Software version 3.6.0 can be installed on Windows XPe or Windows 8e operating systems only. It is not compatible with Windows NT.
  • Access 2 software version 3.6.0 or above will be required to implement the lot scale up and correction factor features. Those features will be released via an updated APF when available.
