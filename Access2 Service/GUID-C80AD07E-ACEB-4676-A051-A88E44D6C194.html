Mixer Belt Tensioner and Speed Detector Theory of Operation

Mixer Belt Tensioner and Speed Detector Components

Component Function
Mixer belt tensioner Maintains constant tension on the mixer belt as it rotates on a spring-loaded pulley.
Mixer speed sensor Detects the interruption of a light beam and sends pulses to the I/O PCB for speed calculation.
Power driver PCB Maintains the voltage to the mixer motor in order to maintain a specific speed. The mixer speed is adjustable by rotating R61 on the Power Driver PCB.

Speed Detection System Process

Step Action
1 The output of the sensor is sent to the fluidics PCB and then to the backplane.
2 The sensor output enters the I/O PCB where it is converted to a specific speed.
3 The speed is sent to the CPU PCB, and processed for display.
4 The RPM (continually updated) is displayed in the digital devices screen.
5 The mixer speed is adjustable by rotating R61 on the Power Driver PCB located in the card cage.

Mixer Belt Tensioner Details

Item Explanation
Serial Number of Cut-In The mixer belt tensioner is installed in all instruments starting with serial number 400600.
Purpose of Automatic Belt Tension
  • Automatic tensioning eliminates manual mixer belt tension adjustment.
  • Correct tension increases mixer belt and bearing life.
Software Requirements The mixer belt tensioner operates with any version of software.
Mixer Belt Tension Specification Automatically tensions the belt to 1.7 lb (deflection of 0.025 in).
Additional Requirement The tensioner arm and pulley should not bounce or be noisy when the mixer motor is running.

Mixer Belt Speed Sensor Details

Item Explanation
Justification for Mixer Speed Detection
  • Flags any result processed with mixer speed out-of-range.
  • Detects broken mixer belt.
  • Detects defective bearing.
Software Requirements Software V3.13 and higher incorporates mixer speed detection.
Configuration Screen Settings
  • Set to 0 or 1 for no mixer speed detection.
  • Set to 2 to activate mixer speed detection (software defaults the system to 2).
Hardware Requirements
  • B Fluidics: Connect the speed sensor to the fluidics PCB.
  • Access 2: Instruments were manufactured with speed detection.
How to Test Error Detection
  1. Place pressure on the mixer belt while the mixer is operating.
  2. View the speed on the Digital Devices screen.
Note: Speeds less than 1500 rpm create an event log entry, Mixer speed out of Range Error.
Mixer Belt Specification Refer to the Instrument Specifications and Information document for current mixer speed specifications.
