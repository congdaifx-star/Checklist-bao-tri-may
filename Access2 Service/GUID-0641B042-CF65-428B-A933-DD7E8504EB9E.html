Troubleshooting Lexmark Printer

Purpose

This document provides general troubleshooting information for the Lexmark E350 Laserjet printer.

Troubleshooting

Issue Cause Resolution
Printer jams
  • Paper might not be stiff enough to feed correctly.
  • Too much paper or tray guides are too tight.
  • Wrinkled, creased, or damp paper.
  • Use minimum 16 lb to 24 lb (60 to 90 g/m²) paper.
  • Do not overload paper tray.
Printer beeps when page is printed Printer has no internal beeper. Beep is most likely coming from UPS that can be momentarily overloaded when heating element in printer cycles on to print a page. Connect printer to a power source other than UPS.
Paper feeds out the back of printer If rear paper guide is extended, paper exits through rear of printer. Push rear paper guide fully into printer.
Printer is online but does not print Many possible causes.
Note: Refer to the Peripherals: Troubleshoot Printing System procedure for more details.
  • Print Menu page using printer keypad.
  • Request a test page from Windows NT printer window.
  • Disconnect and reseat printer parallel cable connection at PC and printer.
  • Pull out and reseat paper tray.
  • Cycle printer power.
Replace Drum, Replace PC Cnt, or Replace PC Kit error message Printer page count has reached expected life of image drum. Reset drum count if print quality is still acceptable, otherwise replace the drum.
Faded areas on printed page Toner is almost empty or drum is worn out.

Paper smoothness, moisture, grain, and fiber content affects print quality.

Replace the toner, possibly replace the drum.
PC - Dump of Physical Memory when UI launches (BSOD) Printer software has been loaded using CD. DxI instrument should use the appropriate Laserjet printer driver to operate the Lexmark printer. Reboot PC. When Windows logo appears, hold down the [Ctrl] key until boot is complete. Delete suspect printer. Add a printer using correct printer driver.
Note: When rebooting the Privacy & Security compliant Windows 8 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

Crystal Reports printing errors Many possible causes. Refer to the Peripherals: Troubleshoot Printing System procedure for more details.

Printer Control Panel

The printer control panel is comprised of an indicator light, six buttons, and a LCD display.

Item Name Function
1 LCD display Two rows of characters displaying printer status, menu items, and error messages.
2 Indicator Light Indicates: Off, On, Busy (flashing).
3 Stop ( x ) Press Stop to stop the mechanical operation of the printer. Press Go to resume.
4 Menu (< / check mark / >) Press < or > to scroll through the menu groups. Press the Check Mark to select the item on the display.
5 Back Press Back to scroll backward to the previous menu item.
6 Go Press Go to go to the ready state.

Load manual feeder with <Custom Type>
  • Load the specified paper in the manual feed tray or multipurpose feeder.
  • To ignore the manual feed request and print on paper already installed in one of the input sources, press GO.

Maintenance Replace the maintenance items and, if necessary, reset the printer maintenance counter.
Menus Disabled The printer menus are disabled. You cannot change the printer settings from the control panel.
Network A network interface is the active communication link.
Network Card Busy
  • An internal print server (also called an internal network adapter or INA) is being reset.
  • Wait for the message to clear.
Not Ready The printer is not ready to receive or process data. Someone pressed Stop X to take the printer off-line. Press GO to make the printer ready to receive jobs.
Parallel A parallel interface is the active communication link.
Performing Self Test The printer is running the series of start-up tests it performs after it is turned on. Wait for the message to clear.
Power Saver
  • Send a job to print.
  • Press GO to warm the printer to normal operating temperature and display the Ready message.
Printing Directory List The printer is processing or printing a directory of all files stored in USB memory. Wait for the message to clear.
Printing Font List The printer is processing or printing a list of all available fonts for the specified printer language. Wait for the message to clear.
Printing Menu Settings The printer is processing or printing the menu settings page. Wait for the message to clear.
Printing Device Statistics The printer is printing statistical information about the printer. Wait for the message to clear.
Printing Quality Test Pages The printer is formatting and printing the Print Quality Test, which consists of four pages. Page 1 contains a mixture of graphics and text, pages 2 and 3 contain only graphics, and page 4 is a blank page. If duplex is turned on, then the pages are duplexed. Wait for the message to clear.

Warning: Do not turn the printer off while this message is displayed.
Program Flash

DO NOT POWER OFF

Warning: Do not turn the printer off while this message is displayed.

DO NOT POWER OFF

Warning: Do not turn the printer off while this message is displayed.

Resetting the Printer Wait for the message to clear.
Res Reduced The printer is reducing the resolution of a page in the current job from 600 dots per inch (dpi) to 300 dpi to prevent a 38 Memory Full error. Res Reduced remains on the display while the job prints.
Restoring Factory Defaults Wait for the message to clear.
Note: When factory default settings are restored:
  • All downloaded resources (fonts, macros, symbol sets) in the printer memory are deleted.
  • All menu settings return to the factory default setting except:
    • the Display Language setting in the Setup Menu.
    • all settings in the Parallel Menu, Network Menu, and USB Menu.
Std Bin Full The standard bin is full.
Toner Low
  • Replace the toner cartridge.
  • Press GO to clear the message and continue printing.
Tray <x> Missing Insert the tray into the printer.
USB The printer is processing data through the specified USB port.
Waiting
  • The printer has received a page of data to print, but is waiting for an end-of-job command, a form-feed command, or additional data.
  • Press GO to print the contents of the buffer.
  • Cancel the current job.
31 Missing or defective cart. Insert or replace the toner cartridge.
32 unsupported print cartridge Install a toner cartridge that is the correct type and capacity for this printer.
34 Short paper
  • Load the appropriate media in the selected source.
  • To clear the message and print the job using a different paper source, press GO.
35 Res save off deficient memory
  • To disable Resource Save and continue printing, press GO.
  • To enable Resource Save after you get this message:
    • Make sure the link buffers are set to Auto, then exit the menus to activate the link buffer changes.
    • When Ready is displayed, enable Resource Save.
  • Install additional memory.
37 Insufficient collation area
  • To print the portion of the job already stored and begin collating the rest of the job, press GO.
  • Cancel the current job.
37 Insufficient Defrag memory
  • To stop the defragment operation and continue printing, press GO.
  • Delete fonts, macros, and other data in printer memory.
  • Install additional printer memory.
38 Memory Full
  • To clear the message and continue printing, press GO. The job may not print correctly.
  • Cancel the current job.
  • Install additional printer memory.
39 Complex Page The page may not print correctly because the print information on the page is too complex.
  • Press GO to clear the message and continue printing the job. The job may not print correctly.
  • Press > to open the Job Menu and cancel the current job.
To avoid this error in the future:
  • Reduce the complexity of the page by reducing the amount of text or graphics on the page and deleting unnecessary downloaded fonts or macros.
  • Set Page Protect to On in the Setup Menu.
  • Install additional printer memory.
42 Cartridge Region Mismatch The geographic region of the printer does not match the geographic region of the installed toner cartridge. Remove the toner cartridge and install a new cartridge that matches the region of the printer.
50 PPDS font error
  • To clear the message and continue printing, press GO. The job may not print correctly.
  • Cancel the current job.
51 Defective flash
  • To clear the message and continue printing, press GO.
  • You must install different USB memory before you can download any resources to USB.
52 Flash full
  • To clear the message and continue printing, press GO.
  • Downloaded fonts and macros not previously stored in flash memory are deleted.
  • Delete fonts, macros, and other data stored on the flash memory.
  • Install a larger capacity flash memory card.
53 Unformatted flash
  • To clear the message and continue printing, press GO.
  • You must format the USB memory before you can store any resources on it. If the error message remains, the USB memory may be defective and require replacing.

54 Std network software error
  • To clear the message and continue printing, press GO. The job may not print correctly.
  • Program new firmware for the network interface.
  • Reset the printer.
55 Unsupported flash in slot <x>
  1. Turn the printer off.
  2. Unplug the power cord from the wall outlet.
  3. Remove the unsupported option.
  4. Plug in the power cord.
  5. Turn the printer on.
56 Std parallel port disabled
  • To clear the message, press GO.
  • The printer discards any data received through the parallel port.
  • Make sure the Parallel Buffer menu item is not set to Disabled .
56 Standard USB port disabled
  • To clear the message, press GO.
  • The printer discards any data received through the USB port.
  • Make sure the USB Buffer menu item is not set to Disabled.
56 Standard USB port disabled
  • To clear the message, press GO.
  • The printer discards any data received through the USB port.
  • Make sure the USB Buffer menu item is not set to Disabled.
58 Too many flash options
  1. Turn off and unplug the printer.
  2. Remove the excess flash memory.
  3. Plug in the printer, and turn it on.
58 Too many trays attached
  1. Turn off and unplug the printer.
  2. Remove the excess trays.
  3. Plug in the printer, and turn it on.
80 Scheduled maintenance
  • To clear the message, and continue printing, press GO.
  • Replace the maintenance items and if necessary, reset the printer maintenance counter.

81 Engine Code CFC Failure The microcode to be programmed in the engine flash code module has failed a CRC check. Press GO to clear the message. The microcode data will be discarded and must be re-transmitted from the host.
84 Photoconduct life warning
  • To clear the message, and continue printing, press GO.
  • Replace the photoconductor (drum) unit.
84 Replace Photoconductor
  • To clear the message, and continue printing, press GO.
  • Replace the photoconductor (drum) unit.
84 PC unit abnormal Replace the photoconductor (drum) unit.
88 Toner low
  • Replace toner cartridge
  • To clear the message, and continue printing, press GO.

  1. Clear paper path.

  1. Turn printer off.
  2. Unplug power cord from the wall.
  3. Check all cable connections.
  4. Plug in power cord.
  5. Turn printer back on.
