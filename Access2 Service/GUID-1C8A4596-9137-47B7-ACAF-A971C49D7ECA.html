Examples of Acceptable Data to be Collected

The following table contains examples of acceptable data that can be collected to show objective evidence that the service activity has been completed and the instrument is verified to return to service. These are only examples of data and other forms may also be acceptable.

Verification Data to be Collected Examples of Acceptable Data
System check printout

-OR-

QC printout
Precision printout
HS system check printout
Carryover printout
Dilution assay correction factor printout
Temperature printout
Assay calibration printout
Correlation printout
Incubator belt calibration report printout
Ultrasonic level sense printout
