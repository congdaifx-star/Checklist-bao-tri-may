Deinstall: Removing Supplies

This procedure describes how to remove supplies from an Access system before removal from service or deinstallation.

This procedure describes how to remove supplies from an Access system in preparation for instrument removal from service or deinstallation.
If the Access will be Then perform these steps
Powered down for more than one hour.
  • Remove and Clear Sample Trays
  • Remove Reagent Packs
Moved or will sit idle for more than one week.
  • Remove and Clear Sample Trays
  • Remove Reagent Packs
  • Remove Liquid Waste
  • Remove RVs from the Waste Chute
Transported in a vehicle.
Note: If transporting, then disinfect the instrument. Refer to the Deinstall: Disinfecting for Shipping procedure.
  • Remove and Clear Sample Trays
  • Remove Reagent Packs
  • Remove Liquid Waste
  • Remove Unibase Fluids Tray
  • Remove RVs from the Waste Chute
  • Remove RVs from the Rake
  • Remove non-RoHS compliant Luminometer for disposal
  1. Remove and clear sample trays.
    1. From the Main Menu, select Test Request/Progress > Next Onboard Tray.
    2. If on-board tray information is presented, then select Unload Tray #, remove the tray, and select Done. When asked whether to clear the tray, select Yes > Enter. Repeat until all trays are unloaded.
    3. In the Test Request/Progress screen, use the arrow keys to move the cursor into the Tray Info field. Press [Shift] + [F12]. If a pop-up window displays with unloaded trays, then select a tray with the arrow keys and press [Enter].
    4. Clear the presented tray by selectingMore Options > Clear Tray, and pressing [Enter].
    5. Repeat until all unloaded trays are cleared.
  2. Remove reagent packs.
    1. From the Main Menu, select Supplies.
    2. Place the cursor over any displayed reagent pack and select Unload Reagent Pack.
    3. When prompted, open the reagent carousel door and unload the reagent pack from the system, and then select Done.
    4. Repeat until all reagent packs are unloaded from the system.
    5. From the Main Menu, select Supplies > Reagent Inventory > Select Criteria, toggle the Sort List to All Packs, and then press [Enter].
    6. Use the arrow keys to move to each unloaded pack, and then select Delete Reagent.
    7. If the packs will not be reloaded on this system, then discard the packs and delete them from reagent inventory.
  3. Remove liquid waste.
    1. Remove the liquid waste container from the fluids tray.
    2. Prime DI water into the buffer system, and then prime the buffer system dry.
    3. Empty the substrate bottle.
    4. Prime DI water into the substrate system, and then prime the substrate system dry.
    5. Disconnect the substrate, waste, and buffer supply lines from the instrument bulkhead fittings.
    6. Disconnect the fluids sensor cable from the instrument bulkhead fitting.
  4. Remove RVs from the waste chute.
    1. Open the front panel.
    2. Remove the waste bag, and discard the bag in a biohazardous waste container.
    3. Remove the lower instrument cover.
    4. Remove all RVs from the waste chute, and discard the RVs into a biohazard waste container.
    5. Reinstall the lower instrument cover, and close the front panel.
  5. Remove RVs from the rake.
    1. Open the front panel.
    2. Remove the waste bag, and discard the bag in a biohazardous waste container.
    3. Remove the lower instrument cover.
    4. From the Main Menu, select Diagnostics > Mechanics > Select Primary Device > Rake, and then press [Enter].
    5. Select Home Device.
    6. Remove the transparent incubator cover by opening the RV loader door, gently pulling the snap tabs on the sides of the cover, and then lifting the cover.
    7. Remove all RVs from the rake and discard the RVs in the trash.
    8. Reinstall the transparent incubator cover.
    9. Select Move to Position to advance the rake
    10. Reinstall the lower instrument cover, and close the front panel.
  6. Remove non-RoHS compliant Luminometer for disposal.
    Note: This section applies to instruments that were tagged for MOD 12912 and MOD 12913 only. See MOD procedures in the documentation distribution platform for more details and the impacted instruments list.
    1. Remove the Analytical module. Refer to Removing Analytical Module procedure.
    2. Remove the non-RoHS Luminometer. Refer to Replacing Luminometer procedure.
    3. Follow the Decontamination of Returned Parts GLB-QS-PCD-0086 document and return the part to this address: 312 Lake Hazeltine Dr. Chaska, MN 55318.
    4. Reinstall the Analytical module. Refer to Installing Analytical Module procedure.
