Software Version 3.5.0

Software version 3.5.0 release notes

Intended Use

For Internal Use Only - Sensitive data intended for use within BCI and normally shared with employees. There may be an occasional need to distribute this data outside the company with Management approval.

Software version 3.5.0 feature details

  • Designed for Access 2 Enhanced (Bridge) systems with new hardware features including
    • Internal Reagent Barcode Reader.
    • Status Light.
    • Multiple Pack Loading Feature.
    • PROService Connectivity.

  • New features
    • Added the ability to scrub HIPPA data from customer databases to DBTest.
    • Improved Software Process For Waste Bag Change.
  • Also compatible with Access 2 non-enhanced systems either on Windows 8e or XPe. The software will recognize if the internal reagent barcode is present to determine whether the system has enhanced features to support.
