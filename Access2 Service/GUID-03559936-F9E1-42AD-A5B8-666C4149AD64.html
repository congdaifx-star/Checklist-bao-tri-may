Troubleshooting Access 2 Enhanced - Internal Reagent Barcode Reader/Scanner

Use the following table for troubleshooting the internal reagent barcode reader/scanner.

Table 87: Internal Reagent Barcode Reader/Scanner Event Errors
Event Possible Causes Troubleshooting Instructions

Reagent pack bar code discrepancy identified

  • Pack was moved by an operator.
  • Pack was loaded out of sequence.
  • Pack was loaded without using the Load Packs function.
  1. From the Supplies screen, select a reagent pack button with ???? in the Reagent Pack Name and Lot Number.
  2. Unload the pack.
  3. Reload the pack using the external bar code reader.

Reagent pack bar code length is incorrect,

or

Reagent pack bar code is invalid

and

Reagent pack bar code is unreadable or the slot is empty

  • Incorrect bar code.
  • Damaged bar code label.
  • Problem with bar code reader.
  • Pack was improperly removed from the instrument.
  • Bar code is no longer readable.
  1. From the Supplies screen, select a reagent pack button with ???? in the Reagent Pack Name and Lot Number.
  2. Unload the pack.
  3. Reload the pack using the external bar code reader.
    • If the system correctly reads the bar code, the pack is now loaded and can be used by the system to run tests. To determine if the internal reagent bar code reader is broken, skip to step 4 to troubleshoot the internal reagent bar code reader.

    • If the external bar code reader also failed to read the bar code, the label may be unreadable. Enter the code manually using the keyboard, and then skip to the last step in this procedure.

  4. If the pack was successfully read with the external bar code reader in step 3, the pack is now correctly loaded on the instrument. To troubleshoot the internal reagent bar code reader, try loading a pack with a known good bar code label, using the internal bar code reader. If the system fails to read the bar code, contact Technical Support to troubleshoot the internal bar code reader.
  5. Review the Supplies screen for additional instances of reagent pack buttons with ???? in the Reagent Pack Name and Lot Number fields. Repeat this procedure for each instance.

Reagent pack is already loaded

  • Duplicate bar code.
  • Pack was improperly moved from one instrument to another in a workgroup.
  1. From the Supplies screen, select a reagent pack button with ???? in the Reagent Pack Name and Lot Number.
  2. Unload the pack.
  3. Repeat step 1 and step 2 for all instances of reagent pack buttons with ???? in the Reagent Pack Name and Lot Number fields.
  4. Visually inspect the bar code on each unloaded pack.
    • For packs with duplicate bar codes, contact Technical Support. Do not use packs that have the same bar code as another pack.
    • For unloaded packs with bar codes that are not duplicates, continue with the remaining steps of this procedure.
  5. Load the pack again using the external bar code reader.
    • If the system correctly reads the bar code, the pack is now loaded and can be used by the system to run tests. To determine if the internal reagent bar code reader is broken, skip to step 6 to troubleshoot the internal reagent bar code reader.
    • If the external bar code reader also failed to read the bar code, the label may be unreadable. Enter the code manually using the keyboard.

  6. If the pack was successfully read with the external bar code reader in step 5, the pack is now correctly loaded on the instrument. To troubleshoot the internal reagent bar code reader, try loading a pack with a known good bar code label, using the internal bar code reader. If the system fails to read the bar code, contact Technical Support to troubleshoot the internal bar code reader.

Reagent pack is empty

and

Reagent pack has been deleted

  • Pack is empty.
  • Reagent pack monitoring detected an issue
  • Pack has been marked as deleted in the database, but was found on the instrument.
Unload the pack and discard it. If you can locate the pack on the Reagent Inventory screen, unload it from that screen. If not, perform the following steps.
  1. From the Mechanics screen, select Disable Motors F8.
  2. Slide the carousel door to the left and open the reagent carousel door.
  3. Manually rotate the reagent carousel clockwise until the pack is in the loading position.
  4. Remove the pack and discard it.
  5. Select Enable Motors F8.
  6. Select Reagent Carousel in the Device list. Select Home Device F1.
  7. Close the reagent carousel door and the carousel door.
  8. Remap the reagent packs (from the Reagent Inventory or Supplies screen, select Remap F3).

Reagent pack was not found or the bar code is not readable

  • Pack was improperly removed from the instrument.
  • Bar code is no longer readable.
  • Database error.
Locate the pack in the carousel or in an external location. If the pack is found in the carousel, reload it manually. To locate the pack in the carousel, perform the following steps:
  1. From the Mechanics screen, select Disable Motors F8.
  2. Slide the carousel door to the left and open the reagent carousel door.
  3. Manually rotate the reagent carousel clockwise until the pack is in the loading position.
  4. Remove the pack.
  5. Select Enable Motors F8.
  6. Select Reagent Carousel in the Device list. Select Home Device F1.
  7. Reload the pack manually by entering the pack bar code.

Reagent pack found in slot XXX was not expected

and

Reagent pack found in unexpected slot

or

Expected slot contains another pack

  • Packs were moved by an operator.
  • A pack was loaded out of sequence, without using the Load Packs function.
  • Packs were moved by an operator.
The system will automatically recover from this error by remapping empty slots and packs that were automatically loaded. However, any packs that were manually entered will not be remapped. In this case, perform the following steps.
  1. Review the reagent pack buttons on the Supplies screen, and take one of the following actions:
    • If no buttons are found with ???? in the Reagent Pack Name and Lot Number fields, skip the remaining steps of this procedure. No additional action is needed.
    • If buttons with ???? in the Reagent Pack Name and Lot Number fields are found, select one of the buttons and continue with the remaining steps of this procedure.
  2. Unload the pack.
  3. Load the pack again using the external bar code reader.
    • If the system correctly reads the bar code, the pack is now loaded and can be used by the system to run tests. To determine if the internal reagent bar code reader is broken, skip to step 4 to troubleshoot the internal reagent bar code reader.
    • If the external bar code reader also failed to read the bar code, the label may be unreadable. Enter the code manually using the keyboard, and then skip to the last step in this procedure.
  4. If the pack was successfully read with the external bar code reader in step 3, the pack is now correctly loaded on the instrument. To troubleshoot the internal reagent bar code reader, try loading a pack with a known good bar code label, using the internal bar code reader. If the system fails to read the bar code, contact Technical Support to troubleshoot the internal bar code reader.
  5. Review the Supplies screen for additional instances of reagent pack buttons with ???? in the Reagent Pack Name and Lot Number fields. Repeat this procedure or each instance.

Remap completed with errors

An error occurred during the remap operation. One or more additional events will be displayed.

Troubleshoot according to recent related events.

Reagent pack has expired

Expired reagent pack was loaded.

Unload the expired pack and discard it.

Verification
  • Ensure reagent packs can be loaded on the analyzer.
