Aligning CTA Pick and Place to Sample Carousel

This procedure describes how to align the CTA Pick and Place to the Access Sample Wheel.

Pre-requisites:
These alignments must have been performed at the DxC console prior to completing the CTA P&P alignment to the Access Sample Wheel. Follow the on-screen instructions to complete the alignments. Refer to the DxC service manual (CTA Alignments chapter) for details.
  • Pick & Place Crane (Horizontal)
  • Pick & Place Crane (Vertical)
  1. Set the CTA offline using the CTA Status button on the Access console. The CTA icon will turn red when it is offline.
  2. Select Diagnostics > Device Diagnostics > Mechanics and choose Sample Carousel as the device.
  3. Choose CTA AV Loader as the position, place an automation rack on the wheel, and select Move to Position to move the carousel to the alignment position.
    Note: The carousel will move to tube position 3 if the current offset is set to zero. Use the double arrow keys move the carousel to position 1 on the rack. Position 1 is approximately 5000 steps.
  4. From the DxC console, perform the following steps to move the CTA Pick & Place to the Access sample wheel position.
    • Click on the Utilities icon and select Diagnostics and choose CTA Diagnostics for the sub functional area.
    • Select Electro-Mechanical > Devices > AV Transport and select Move to Access2 Wheel.
    • Select Cancel to exit the AV Transport screen.
    • Select AV Pick & Place and select Disable to prepare the P&P for alignment.
    • Place an AV into the Pick and Place
  5. Move the Pick and Place down into position 1 of the automation rack on the Access sample wheel. Use the single arrow keys on the Access screen to move the sample wheel so that the AV in the P&P is centered in the rack position.
  6. Select Save Offsets, then raise the P&P and remove the AV.
  7. Exit the Diagnostics screen and select Yes to the Do you want to save alignments message.
  8. Set the CTA online using the CTA Status button.
  9. Exit the diagnostics menu on the DxC console to home the CTA and return it to the standby state.
