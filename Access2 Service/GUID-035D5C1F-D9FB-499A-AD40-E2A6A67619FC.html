Installing I/O PCB

This procedure describes how to install a new I/O PCB or a used I/O PCB.

Install the I/O PCB.
  • To install a new I/O PCB:
    1. Install the PCB.
    2. Power on the instrument.
    3. From the Diagnostics screen, home the RV shuttle, home the incubator belt, and then home the wash carousel.
    4. Initialize the system to Ready.
    5. Change the waste bag and load substrate.
      Note:
      • The replacement I/O PCB does not have any substrate or waste bag count data or has incorrect data. The supply status must be reset by loading supplies before the system can aspirate samples.
      • The system alignment files are automatically transferred from the nvsetup.csv file on the hard drive into the I/O PCB nvram when the instrument finishes initialization.
  • To install a used I/O PCB:
    1. Power on the instrument with the front cover open to ensure that initialization fails.
      Caution: Do not allow the system to initialize with a used I/O PCB installed. Initialization transfers the alignments from the I/O PCB into the new instruments hard drive. The alignments and serial number are from the previous system. When a used I/O PCB is installed in a new system, the I/O PCB NVRAM memory can be erased using the vmod -u command in the BIN directory on the AU or overwritten using the disk_to_nvram.sh or nvinit.sh -d commands.
    2. Select Start > Run, on the Run text line, type telnet 192.168.2.x (the address of the AU, x normally = 4). Select OK.
    3. At the user name prompt in the telnet window, type super user, and then press [Enter].
    4. At the (super) [/hØ/>] prompt, type cd /hØ/nexstep/scriptutil, and then press [Enter].
    5. At the (super) [/hØ/nexstep/scriptutil/>] prompt, type nvinit.sh -d, and then press [Enter] to send the nvsetup file information to the I/O PCB.
      Note: If there are errors, check your typing, otherwise contact support, and do not proceed.
    6. Close the instrument front cover and reboot the instrument.
    7. Close the telnet window. Start the user interface, if it is not running.
    8. Initialize the instrument.
      Note:
      • If an RV Cleanout or NVRAM INIT error occurs, then in the Diagnostics screen, home the RV shuttle, home the incubator belt, and home the wash carousel. Initialize the system to Ready.
      • A statinit error can indicate that the nvsetup file structure is corrupt. The structure can be corrected by replacing the nvsetup file using a backup copy. Refer to the Restoring Instrument NVRAM (Access 2) procedure.
    9. Change the waste bag and load substrate.
      Note: The replacement I/O PCB has missing or incorrect substrate and waste bag count data. The supply status must be reset by loading substrate and changing the waste bag before the system can aspirate samples.
    10. In the User Interface select Diagnostics >> Device Diagnostics >> Analog Devices >> Pressure Monitor >> Determine Curve for the obstruction detection application.

    11. Schedule a sample test that will use a reagent pack and start the test by pressing RUN from the Ready state. This will save a pressure sensor baseline for the reagent pack monitor application
