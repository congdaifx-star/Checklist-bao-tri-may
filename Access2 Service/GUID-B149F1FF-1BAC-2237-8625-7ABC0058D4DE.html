Tshoot: Pack Monitoring

Purpose

This document provides instructions for troubleshooting failures of the reagent pack process monitoring.

For a detailed explanation of reagent pack process monitoring, refer to the Pack Monitoring Theory of Operation document.

Event Messages

Events are listed in the order of expected frequency, with the most common events listed first.

Reagent pack monitoring detected insufficient reagent Reagent pack monitoring detected that an insufficient dispense volume was drawn from the reagent pack. The test is canceled.
  • Insufficient reagent pack volume. Misplaced reagent pack. Missing or disconnected pressure sensor.
  • Pressure monitor failure.
  • Raised RVs.
Reagent pack monitoring device failure Reagent pack monitoring failed to measure the dispensed amount. The test is canceled.
Unable to initialize system due to disabled main pipettor Pipettor is disabled because of reagent pack monitoring Resolve the cause of the other event logs that precede this message. Then enable the pipettor. To enable the pipettor, select Diagnostics > Device > Diagnostics > Reset Pipettor.

Note:
  • This event indicates that the filter value is updated.
  • Test results are not flagged due to this event.
  • Reagent packs are not disabled (not set to zero) due to this event.
  • For more information, refer to the Pack Monitoring Theory of Operation document.
  • Utility Assay disabled.
  • Precision pump or valve failure.
  • Insufficient reagent pack volume.
  • Misplaced reagent pack.
  • Air in the pipettor tubing.
  • Pressure monitor drift or failure.
  • Raised RVs.
Reagent pack monitoring reset after repeated measurements outside limits The reagent pack monitoring algorithm encountered too many consecutive dispense measurements outside of expected limits. Reagent pack monitoring restarts. No tests are canceled. Subtle, non-critical changes between reagent packs, the fluidics systems, or the pressure sensor.

  • Pack shared among instruments not in a work group.

  • Missing reagent packs.
  • Leak in the fluidic system.

Failure Modes

These failure modes are possible with reagent pack process monitoring:
  • Air in the fluidics lines.
  • Utility Assay disabled.
  • A reagent pack issue.
  • Poor pipettor to reagent pack alignment.
  • Faulty pressure sensor.
  • Pipettor or precision pump/valve issue.
  • Raised RVs.
    Note: If there are raised RVs, then consider performing the Rake and RV Shuttle alignments and replacing the RV load door assembly with the new assembly that has the extension cover.

View Event Log Details

To review event log message details, perform these steps.
  1. Select the Reagent Dispense event from the event log, and then select Details.
  2. Review the details of the event log for each pack monitoring event posted. Note the Assay Name, Pack Well, Pack Bar Code, and Carousel Slot.

Troubleshooting Reagent Pack

If troubleshooting an issue with the reagent pack, then perform these steps.
  1. Verify that the correct reagent pack is positioned correctly in the reagent carousel.
  2. Verify that the reagent pack is not empty and has not been used on any other Access or DxI instruments in the lab.
    Note:
    • If the reagent pack well in the event log message details is well 0, then the pack is likely to be a shared pack.
    • If the number of tests used from this reagent pack is near 50, then this could indicate a pack volume issue, poor alignment, or elastomer debris in the pack.
  3. Verify that the elastomer is not loose on the pack and that there is no debris from a bad puncture of the elastomer.
  4. Verify that the reagent pack has not been treated in any way that could cause reagent to be lost from a well. Ensure that the reagent pack has not been:
    • Mixed after opening.
    • Inverted.
    • Vortexed.

Troubleshooting the Pipettor Fluidics System

If troubleshooting an issue with the pipettor fluidics lines, then perform these steps.
  1. Confirm that the Utility Assay is enabled. If the pack monitoring errors occur at the beginning of runs after periods of inactivity, then the Utility Assay being disabled is a probable root cause.
  2. Inspect the precision pump, valve, valve manifold, and fluidics tubing for indications of leaks. Replace or secure any loose or damaged parts.
  3. If significant hardware is replaced, then consider resetting the stored pack monitoring values before running quality control. If abnormal pressure values were saved, the values are reset to prevent reagent packs from being marked unusable.
    To access this feature:
    1. Select Diagnostics > Device Diagnostics > Analog Devices > Pressure Monitor.
    2. Select Service Reset.
    3. Enter the Password Access2Support.
    4. Select OK > OK.

Troubleshooting Pressure Sensor Electrical System

If troubleshooting an issue with the pressure sensor electrical system, then perform these steps.
  1. Select Diagnostics > Copy to Disk.

    Analyze the data in this file for patterns that could indicate pressure sensor failure or other issues. For information, refer to the Diagnostic Copy to Disk section of the Pack Monitoring Theory of Operation document.

  2. Consider reseating or replacing cables and parts on these boards: Obstruction detection PCB, I/O PCB, and CPU PCB.
  3. For further investigation or troubleshooting, please contact Technical Support.
