Software Version 1.2

These release notes apply to upgrades from Version 1.1 software to Version 1.2 software. There were a number of significant changes made to the software in the 1.1 release, which are described in the Version 1.1 release notes but are not further described here in the Version 1.2 release notes.

Confidential

Software release notes are to be considered Beckman Coulter, Inc. company confidential and treated as such.

Additions

  • Ability to configure the Access 2 system for Codabar without check digit labels
  • Help screens translated in the following languages: French, Italian, German, Spanish and Japanese.
  • The Access 2 software now supports the following assays: TgAb, TT3, HbsAg, HAVAb, HBsAgBlk, and HBsAgCtl.
  • The Access2 software no longer supports the following assays: CA19-9, CA125II, and CA15-3.

Corrections

Issue: The database has been updated to the latest version provided by the vendor. This update corrects a problem, which can result in a corrupt database due to “database checksum” errors following deletion of items from the database. Note that “database checksum” corruption may still occur due to other scenarios (e.g. inappropriate shutdown).

Issue: A message is displayed during software installation incorrectly instructing the operator to reboot the instrument which had resulted in failed installations. This message was changed to reflect appropriate action.

Issue: "Waiting for LIS" message after loading a tray and immediately pressing run with Host Query enabled. Changes were made to allow the operator to load a rack and immediately press run without errors.

Issue: Locked reagent packs due to the following two conditions: 1) Incorrect handling of the volume remaining in a reagent pack following the detection of a “No RV In Pipetting Position 1 or 2” error. 2) Potential incorrect handling of the volume remaining in a reagent pack for two-step assays if a fatal hardware error (e.g.: Stop key) occurs during the first incubation period. Changes were made to prevent locked packs resulting from the described scenarios.

Issue: Changing the default test ID numbers resulted in failures of the following features: Manual Rerun, Batch Mode, and Change Reagent Lot # for a Calibration. The issues with each feature were corrected.

Issue: Quality Control units are not changed when the units are changed in the Test Setup screen. Changes were made to ensure that the following are also changed: reference ranges, critical ranges, LIS ranges and QC parameters. The updates are not applied to historical data.

Issue: A problem was corrected that could result in incorrect range values including: LIS, Critical, Reference, and QC ranges. If the user changed the default units for a specific fluid type in the Test Setup screen, the ranges for all fluid types were converted using the same conversion factor. This does not affect the actual result.

Issue: The Priming screen in diagnostics was updated to display a message indicating the successful completion of a prime.

Issue: QC points for qualitative assays were not being plotted appropriately. The QC review screens were corrected to use two digits of precision for qualitative assays.

Issue: A problem was corrected in the APF for hGH, which affected conversion from mass units to international units.

Issue: The Page Up and Page Down keys now work in the Off Board column of the Sample Manager screen. This was simply an issue of not being able to use Page Up or Page Down to view additional off board racks.

Issue: A problem was corrected with the database software that resulted in a Dr.Watson error from the Test Results screen if the user attempted to select a new filter following cancellation of a previous screen refresh.

Issue: A problem in the instrument software was corrected which resulted in a failure to establish communications between the PC and the instrument, following an instrument reboot. Note that the symptom of this problem is the inability of the PC to send operations to the instrument (e.g. Load a Rack). This typically results in a “Connection to the instrument is unavailable.” message box in response to attempts to initiate an instrument operation.
