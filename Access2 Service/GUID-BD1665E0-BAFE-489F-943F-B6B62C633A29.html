Database - Unlocking Sample Rack (Access 2)

This procedure describes how to change the sample rack status in the database to unlock the rack.

Use this procedure to remove a sample rack that is unable to be unloaded or cleared from the user interface. Use this procedure to remove an invisible rack which takes up one of the spaces on the sample carousel so that a sixth rack cannot be loaded. An invisible rack in position 1 can cause unexplained bar code reader failures to read the rack errors by causing the carousel to advance to position 2 when loading (and the operator has prematurely placed the rack in position 1).

Note: The LXi Access software reserves sample carousel position 1 (home position), so that a rack cannot be loaded there. This feature prevents disturbing loaded samples and preserves sample integrity while loading reagents.
  1. Unload and clear all sample racks through the user interface.
    1. In the Sample Manager screen, unload and clear all available racks.
    2. From the Main Menu, press [Alt] + [F4], and enter the password Access2Support to exit the user interface. Exit the user interface on the server PC and any client PCs.
      Note: Confirm that the system is in the Ready state before proceeding. In-process tests lock the sample racks.
  2. Create the local copy of the database.
    Note: Poet Object Server (Access2 Software 3.4.2 and below ) and Fast Objects Server (Access2 Software 3.4.3 and above) are the same objects server running the database. Fast Objects Server replaces Poet Object Server on the latest Access2 system software.

    For Windows XP console PC with Access2 Software 3.4.2 and below:

    1. From the Main Menu in the user interface, select [Alt] + [F4].
    2. Enter the password Access2Support observing upper and lower case. The PC will exit to the Windows desktop.
    3. Select the poet server icon near the clock at the bottom right corner of the display.
    4. Select the X at the upper right corner of the poet server window and OK to the shutdown server pop-up.
    5. Select Start > Programs > Windows Explorer to open Windows Explorer.
    6. Navigate to the C:\NexStep\PC folder.
    7. Right-click on the DRW folder and select Copy.
      If errors occur during the copy, then:
      • Use the Task Manager to end any applications which may prevent copying the database.
      • A software error may have locked the database. Select the Poet Object Server icon at the bottom right corner of the display near the system clock. Shut down the server and close any error messages. Restart the server by selecting Start> Run, typing ptserv32.exe on the text line, and selecting OK.
    8. Right-click on the PC folder and select Paste to make a Copy of the DRW folder.
    9. Close Windows Explorer when finished making the copy.

    For Windows 8 console PC with Access2 Software 3.4.3 and above:
    Note: Access2 Software 3.4.3 or above is compatible with Windows XP console PC. If the software was installed on the Windows XP console PC, then follow the Windows XP section to make a copy of the database.
    1. From the Main Menu, press [Alt] + [F4] and then enter Access2Support to exit the user interface.
    2. Shut down the Fast Objects Server.
      • Press Ctrl + Alt + Delete and select Task Manager or right click on the task bar and select Task Manager.
      • In the Task Manager box, click on Processes, select FastObjects Server and click on End Task in the bottom corner of the box.
    3. Press Windows key and select File Explorer icon or type file explorer and open the program.
    4. Navigate to the C:\NexStep\PC folder.
    5. Right-click on the DRW folder and select Copy.
      If errors occur during the copy, then:
      • Use the Task Manager to end any applications which may prevent copying the database.
      • A software error may have locked the database. Shut down the Fast Objects Server and close any error messages. Restart the server by pressing Windows key and select the Fast Objects Server icon or type run, open the Run program, typing ptserv32.exe on the text line, and selecting OK.
    6. Right-click on the PC folder and select Paste to make a Copy of the DRW folder.
    7. Close File Explorer when finished making the copy.
  3. Open the Poet or Fast database application.

    For Windows XP console PC with Access2 Software 3.4.2 and below:

    Note: If the Poet Developer or Administrator does not start because the Poet Object Server is not running, then start the Poet Object Server. From the Windows desktop, select Start > Run, type ptserv32.exe on the text line, and press [Enter].
    1. From the Windows Desktop on the console PC, select Start > Programs > Access2 > Poet Developer or Poet Administrator.
    2. In Poet browser, select File > Open Database.
    3. In the Host field, enter LOCALHOST. In the Database field, enter NexStepBase. Select OK.
      Note: NexStepBase is case-sensitive.
    4. Select Objects > Browse Extent.

    For Windows 8 console PC with Access2 Software 3.4.3 and above:

    Note: If the Fast Developer or Administrator does not start because the Fast Objects Server is not running, then start the Fast Objects Server. From the Windows desktop, press Windows key and select the Fast Objects Server icon or type run, open the Run program, typing ptserv32.exe on the text line, and selecting OK.
    Note: Access2 Software 3.4.3 or above is compatible with Windows XP console PC. If the software was installed on the Windows XP console PC, then follow the Windows XP section to launch Fast database application. Poet database application is replaced by Fast database application.
    1. Press Windows key, select Fast Developer or Fast Administrator icon or type developer or administrator and open the program.
    2. In Fast browser, select File > Open Database.
    3. In the Host field, enter LOCALHOST. In the Database field, enter NexStepBase. Select OK.

      Note: NexStepBase is case-sensitive.
    4. Select Objects > Browse Objects.
  4. Select the Access instrument in the database.
    1. In the extent browser window, navigate to and click on BPtAccessAU.
      Note: The right side of the Poet Browser or Fast Browser window displays the instrument objects in gray text. Each line of gray text represents a different instrument.
    2. Double-click on the top line of gray text to open the instrument database. Confirm that the correct instrument is selected by checking the serial number on the right side of the double window that has opened. If the serial number does not match the problem instrument, then close the window and double-click on the next line until the correct instrument database is opened.
  5. Select the locked sample rack in the database.


    1. Select the depend lset <ondemand<BPtAUSubSystem line on the left side of the double window to expand the instrument sub systems lines of text.
    2. Select the BPtAccessSampleCarousel line on the left side of the double window to expand the sample carousel lines of text.
    3. Highlight the depend lset <ondemand<BPtRackSlot> line of text.
      Note: The onboard sample racks are displayed as gray text on the right side of the double window. Each line of text represents a different rack.
    4. Select the black text in the right-hand window to open the status window for that sample rack.
  6. Edit the sample rack state in the database to unlock the rack.


    1. In the sample rack information window, highlight the BPtRack 'm_odPtRack line of text. The rack information is on the right side of the sample rack window.
    2. On the right side of the sample rack information window, highlight the enum m_ePhysicalState : line of text, right-click on the text, and select Edit from the menu that displays.
      Note: If there is no rack state information, return to the step: Select the depend lset <ondemand<BPtAUSubSystem line on the left side of the double window to expand the instrument sub systems lines of text. Highlight the black text in the right-hand window, right-click on the text, and select Remove from the menu that displays to delete the rack from the sample carousel. If the rack was deleted from BPtRack before, then there is no editable information for the rack in the sample carousel subsystem and the rack can be deleted (removed).
    3. Change the physical state to 1 (onboard), and select OK.
    4. In the sample rack information window, highlight the enum m_eLogicalState line of text, then right-click on the text and select Edit from the menu that displays.
    5. Change the logical state to 4 (done), and select OK.
    6. After the rack is edited, highlight the PtObjID line of text (the top line of left side of the double window). Right-click the highlighted line, and select Store from the menu that displays.
    7. Exit the Poet or Fast Developer.
  7. Perform the Database Consistency Check.
    Note: Refer to the Software: Database - Performing Database Consistency Check (DxI and Access2) procedure.
  8. Verify that the rack is unlocked.
    1. Relaunch the user interface.
      • For Windows XP system, select Start > Programs > Access2 > Access2 or NexStep.
      • For Windows 8 system, double click on the NexStep Application shortcut on the desktop.
    2. Verify that the rack can be unloaded and cleared.
