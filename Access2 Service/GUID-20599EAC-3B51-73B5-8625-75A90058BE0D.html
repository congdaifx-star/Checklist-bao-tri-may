Software Version 2.8

Access 2 Software Release Notes Version 2.8

Intended Use

For Internal Use Only - Sensitive data intended for use within BCI and normally shared with employees. There may be an occasional need to distribute this data outside the company with Management approval.

Scope

These release notes apply to upgrades from version 2.5 to version 2.8 software. Please note that versions 2.6 and 2.7 were not released for distribution. If necessary, customers should be advised to install v2.5 and convert to Wash Buffer II before installing software v2.8. There may be a small number of systems on the following Wash Buffer I software versions: 1.4.6, 2.1, 2.2, 2.3.

New Features or Enhancements

  • If the sample carousel position is compromised (by extraneous forcible movement or inhibition of movement), then the current and next reps will be cancelled.
  • Obstruction detection will no longer be performed on dilution vessels.
  • Help system updates.
  • Additional foreign language text translations.
  • Enhanced DbTest tool functionality for support of ADAM data collection (Chaska systems only).

Corrections

  • APF installations that do not complete due to hang-up or forcible termination will no longer appear complete. The APF revision number displayed in the Tests screen will be updated only after a successful APF update.
  • The utility assay will be prevented from running if there is a vacuum under limits error, in order to avoid wash buffer spills.

Contact your local support organization with any questions or concerns.
