Database - Managing Database Size

This procedure describes how to configure Auto Delete.

This procedure provides instructions for configuring the Auto Delete feature on the Access 2, and for deleting old calibrators and QCs. The normal size for an Access 2 database is about 20 MB. When the Auto Delete feature is not configured and old calibrators are not deleted manually, the database size can approach 150 MB. Excessively large databases can slow the user interface response time and interfere with APF updates.

Perform this procedure when the user interface becomes slow or the APF update process does not complete with an Update Successful message.

  1. Configure Auto Delete.
    1. In the user interface, select Configure > PC Admin > Auto Delete Setup, and enter the password Access2Support.
    2. Select the three boxes for Patient, QCs, and Reagents. Enter the number of days for the system to retain results data.
      Note: Because data will be deleted permanently, check with the customer before configuring Auto Delete. Common settings for the number of days are 7 to 30 days for patients and 60 to 90 days for QCs.
    3. Select OK to exit the Auto Delete Setup window. Select OK to the Configuration Change popup.
      Note: Auto Delete runs in the background and begins to mark the old data deleted. The deletion process can take several hours to complete.
  2. Delete expired calibrators.
    1. In the user interface, select Calibration > Calibrator Setup.
    2. Highlight an expired calibrator lot, select Delete Calibrator, and enter the password Access2Support if prompted.
    3. Select OK to the Confirm Deletion popup.
    4. Continue deleting calibrators until all expired calibrators have been deleted.
      Note: An error with a calibrator sample is the most likely source for AFP update failures. If a problem updating the APF still exists after deleting the expired calibrators, then some calibrators that are not expired might have to be deleted.
  3. Delete expired QCs.
    1. In the user interface, select Quality Control > QC Setup.
    2. Highlight an expired QC, select Delete QC, and enter the password Access2Support if prompted.
      Note: Check with the customer before deleting QCs. The customer might want to keep the QC or obtain a printout before deletion.
    3. Select OKat the Confirm Deletion popup.
    4. Continue deleting QCs until all expired QCs have been deleted.
  4. Reorganize the Access 2 database.
    Note: Refer to the Software: Database - Reorganizing Database (DxI and Access 2) procedure.
  5. Perform the Database Consistency Check.
    Refer to the Software: Database - Performing Database Consistency Check (DxI and Access2) procedure.
