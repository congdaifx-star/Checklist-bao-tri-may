Replacing Sample and Reagent Carousels Module

This procedure describes how to remove and install the sample and reagent carousels module.

This document provides instructions for removing and installing the sample and reagent carousels module. This document is intended to be used with other documents that provide detailed information on alignments and specific areas of the module.
  1. Power off the instrument.
  2. Remove the sample and reagent carousels module.
    1. Disconnect the waste bag from the waste chute, and then remove the instrument upper and lower front covers.
    2. Disconnect the connectors from the sample/reagent module interface PCB:
      • J1 - Ribbon cable
      • J12 - Vacuum valve
      • J16 - Temperature cable
      • J18 - System Power Harness
      • J20 - Fan power
    3. Remove the two screws holding the module support rails to the instrument base. Lift the module up slightly to release it from its alignment pins, and then slide the module out of the instrument.
      Caution: Newer sample/reagent module interface PCBs (PN A43491) have a large heat sink that can catch on the center bracket. Slowly remove the module and remove the center bracket if necessary.
  3. Install the sample and reagent carousels module.
    Caution: Newer sample/reagent module interface PCBs (PN A43491) have a large heat sink that can catch on the center bracket. Slowly slide the module and remove the center bracket, if necessary.
    1. Slide the module into the instrument.
    2. Position the module guide rails onto the alignment pins.
      Note: The module is placed correctly when it locks into the alignment pins and the hold-down screws can be installed.
    3. Install the two hold-down screws.
    4. Connect the connectors to the sample/reagent module interface PCB.
  4. Check the sample pipettor to sample/reagent storage module alignments.
  5. Verify system operation.
    1. Perform the required system verification.
      Note: Refer to the Verification of Preventive Maintenance document.
    2. Contact your local support organization with any questions or concerns.
