Ultrasonics Level Sense Theory of Operation

Purpose

This procedure provides information regarding ultrasonics level sensing and the terminology used for various parameters of sample cups and pipettor z (vertical) motion.

Background

When processing samples, the instrument performs level sense on every sample repetition to:
  • Locate the liquid level in the sample container where sample aspiration will begin.
  • Determine if the sample volume is sufficient for processing.
Note:
  • The calculation of Quantity Detected in a sample container is based on the number of steps that the probe goes down to detect liquid. That value is compared to a corresponding value encoded in system software, which in turn depends on the sample container type and the assay requested.
  • The system generates a QNS (Quantity Not Sufficient) error if the calculation indicates that there is not enough sample available for processing.

Level Sense Parameters

Parameter Definition
Pipettor Z axis top of travel The pipettor z-axis home position.
Level sense start The point (above the container's top) at which level sense begins.
Pipettor sample Z alignment offset A value used in determining level sense start. This value corrects for instrument to instrument variability in pipettor height.
Maximum Steps Maximum steps allowed to seek sample level. This is done to ensure sufficient quantity of sample. It is dependent upon the type of assay (sample amount required and type of container used. (µL/step). Refer to the volume resolution table for more information.
Maximum Depth Relative value encoded in software, the maximum number of steps the pipettor can travel downwards from its Level Sense Start.
Dead volume The amount of unusable fluid in the container.
Note: The dead volume fluid is within reach of the probe, but is not used because the ul/step varies too much due to the container's shape.

Event Log Messages

This section lists ultrasonic related Event log messages.
  • Ultrasonic Probe Lock Failed Before Lower (transducer PLL never locked and therefore did not begin stepping downward to the sample)
  • Ultrasonic Surface Detect Failed Before Lower (surface detected before reaching the expected maximum fluid height for the vessel/tray)
  • PIP Level Sense Lower Sensor Not Found (surface detected below maximum number of downward steps for vessel dead volume)
  • Ultrasonic Surface Detect Failed On Lower ("QNS" surface not detected and maximum number of downward steps reached for vessel dead volume)
