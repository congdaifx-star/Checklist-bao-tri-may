Replacing Fluidics Interface PCB

This procedure describes how to remove and install the fluidics interface PCB.

Perform this procedure when the fluidics interface PCB must be replaced or repaired. Refer to the fluidics PCB layout drawing during this procedure.
Note: Refer to the Fluidics PCB Layout drawing.
  1. Remove the precision pump.
    Caution: All service personnel that handle material sensitive to electrostatic discharge (ESD) used to analyze, repair, or test instruments and test equipment must use ESD precautions and be aware of all ESD policies. Refer to the North American Commercial Operations (NACO), Kit Testing, Handling, and Storage of Electrostatic Discharge (ESD) Service Devices for the Corporate procedure and policy regarding ESD.
    1. Power off the instrument. Open the top and front covers.
    2. Disconnect these connectors from the fluidics interface PCB:
      • J3 - Precision Pump Home Sensor
      • J26 - Precision Pump Motor Power
    3. Mark the cable connector location for reinstallation.
    4. Using a 3/32-in Allen wrench, loosen the two captive screws on the right side of the fluidics manifold that secure the precision pump.
      Caution: Place towels underneath the pipettor tip to absorb leaking wash buffer.
    5. Lift the pump up and away from the manifold.
    6. Set the pump aside for installation later.
  2. Remove the wash pump.
    1. Disconnect these connectors from the fluidics interface PCB:
      • J8 - Pump Home Sensor
      • J23 - Wash Pump Motor Power
    2. Mark the cable connector location for reinstallation.
    3. Using a 3/32-in Allen wrench, loosen the two captive screws on the right side of the fluidics manifold that secure the precision pump.
      Caution: Place towels underneath the pipettor tip to absorb leaking wash buffer.
    4. Lift the pump up and away from the manifold.
    5. Set the pump aside for installation later.
  3. Remove the fluidics interface PCB.
    1. Using a 3/32-in Allen wrench, remove the screw and star washer that secures the grounding strap cable attached to the top of U5 (heat sink) on the upper left of the fluidics interface PCB. Set the screw and washer aside.
    2. To disconnect J27, J28, and J14, depress the locking tab while pulling the cable free. The locking tab is located on the center of the connector on the right and left side. Press and hold the tab while pulling forward on the connector.
      Note: Remove J27 and J28 first to access the J14 connector.
    3. Disconnect the remaining cables from the fluidics interface PCB.
    4. Mark the cable connector locations for reinstallation.
    5. Disconnect the tubing from the vacuum sensor by pulling the tubing downward.
    6. Using a 7/64-in Allen wrench, remove the Allen screw that secures the fluidics interface PCB.
    7. Locate and remove the six plastic standoffs (with locking tab) that hold the fluidics interface PCB in place.
      Caution: Do not pull the circuit board too far forward until all six standoffs are disengaged and the 7/64-in Allen screw is removed.
      Note: The tabs of the plastic standoffs can be easily disengaged for removal using the Access RV Alignment tool.
    8. If you are replacing the vacuum sensor, use a flat screw driver to break free the red GLYPT insulating varnish on R43 adjustment pot for ease of adjustment later.
      Note: Refer to Replacing Vacuum Sensor procedure.
  4. Install the fluidics interface PCB.
    1. Align the fluidics interface PCB with the standoffs. Push the PCB firmly in place until it is held secure by the locking tabs on the standoffs.
    2. Using a 7/64-in Allen wrench, install and secure the fluidics interface PCB.
    3. Install the cables to the previously marked connectors on the fluidics interface PCB. Refer to the Fluidics PCB Layout diagram and table for connector locations and devices.
      Caution: Wrong connections can damage the PCB and immediate circuits.
      Note: Do not connect the vacuum tubing until after the vacuum sensor voltage has been confirmed.
    4. Secure the grounding strap to the top of U5 (heat sink) on the upper left of the fluidics interface PCB using the Allen screw and washer that was removed earlier.
    5. If the vacuum sensor was replaced, then refer to Adjusting Vacuum Sensor procedure.
  5. Install the precision pump.
    1. Confirm the presence of the o-ring for sealing the precision pump to the manifold. Align the precision pump with the manifold block, and slide the pump into place.
    2. Using a 3/32-in Allen wrench, tighten the Allen screws to secure the precision pump.
    3. Connect these connectors to the fluidics interface PCB:
      • J3 - Precision Pump Home Sensor
      • J26 - Precision Pump Motor Power
  6. Install the wash pump.
    1. Confirm the presence of the o-ring for sealing the wash pump to the manifold. Align the wash pump with the manifold block, and slide the pump into place.
    2. Using an 3/32-in Allen wrench, tighten the Allen screws to secure the wash pump.
    3. Connect these connectors to the fluidics interface PCB:
      • J8 - Pump Home Sensor
      • J23 - Wash Pump Motor Power
  7. Verify vacuum pump operation.
    Note: The air filter bottle can become clogged with dried buffer residue causing slow vacuum increase or limiting maximum vacuum. Replace the air filter if it blocks the air discharge from the vacuum pump.
    1. Power on the instrument and allow the instrument to initialize.
    2. From the Main Menu, select Diagnostics > Device Diagnostics > Digital Devices.
    3. Select the Pump On and Probe Wash Valve options. Confirm that the vacuum reaches a minimum of 450 mm Hg.
    4. Clear the Pump On option and confirm that the vacuum does not drop by more than 50 mm Hg within 30 seconds with the valve on. If the vacuum drops more than 50 mm Hg in 30 seconds, then inspect the vacuum system for leaks (fittings, vacuum bottle cap, tubing).
    5. With the vacuum valve still closed, power off the vacuum pump and confirm the vacuum does not drop by more than 50 mm Hg within 30 seconds.
    6. Clear the Probe Wash Valve option and confirm that the vacuum immediately falls to almost zero.
    7. Optional - the automated Vacuum Test can also be run. Select F2 Vacuum Test to run the test.
  8. If vacuum is not in specification, then flush the vacuum pump.
    Refer to the Flushing Vacuum Pump procedure.
  9. Verify the instrument meets specifications.
    1. From the Main Menu, select Diagnostics > Device Diagnostics > Analog Devices > Analog Data.
    2. Use the temperatures table in the Specification Summary Sheet to check for any open circuit via the Fluidics Interface PCB.
    3. Complete four main pipettor priming cycles and four wash pump prime cycles, to confirm that all the air is removed from the precision pump, wash pump, and manifold.
  10. Verify system operation.
    1. Perform the required system verification.
      Note: Refer to the Verification of Preventive Maintenance document.
    2. Contact your local support organization with any questions or concerns.
