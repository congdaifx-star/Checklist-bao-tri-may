Perform CW Index Sensor Check During Troubleshooting

This procedure describes how to perform a CW index sensor check when troubleshooting incubator belt calibration.

Perform this procedure when instructed to do to so as part of the troubleshooting process for incubator belt calibration.
Note: Refer to the Tshoot: Incubator Belt Calibration procedure.
Perform CW index sensor check.
Note: If the failing nominal differences were in the CW direction, the index sensor is not adjustable.
  1. Use the information from the Incubator Calibration Report, determine the next step.
    • If CW nominal difference for clip #35 is ±3 or less, then swap the home clip location.
    • If CW nominal difference for clip #35 is ±4 or greater, then replace the index sensor.
