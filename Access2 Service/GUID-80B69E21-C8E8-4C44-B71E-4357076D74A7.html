Adjusting Luminometer Drift Correction Factor

This procedure describes how to adjust the luminometer Drift Correction Factor.

The luminometer output can drift slightly over time as the luminometer ages. Adjusting the Drift Correction Factor is essentially adjusting the luminometer sensitivity so that its output, when reading the light from the LED, matches the stored LED target value.

Note:
  • A DCF error is generated when the DCF is greater than 1.7 or less than 0.6.
  • The DCF is applied to current RLU counts to compensate for drift in the photomultiplier tube.
  1. Prepare for luminometer assembly adjustment.
    1. Print an Alignment Report.
    2. Obtain a printout of the most recent System Check.
  2. Adjust the Drift Correction Factor.
    1. Select Diagnostics > Device Diagnostics > Luminometer > Read
    2. Confirm that the dark counts are less than 100, with the LED off and all covers installed and closed.
    3. Select Enable LED.
    4. Place the cursor in the High Voltage Control window. Use the up and down arrow keys to adjust the high voltage control voltage so that the Current RLU matches the LED Target Value within 2%.
      Note: The HV control voltage can be typed into the High Voltage Control window. After entering the number (voltage), select [Enter].
    5. Select Cancel.
    6. Select Save High Voltage Control. At the prompt select OK to save the new H.V. control value.
      Note:
      • Do not select Save LED Reading.
      • If a new LED target is saved, then assay recalibration is required.
    7. Select Enable LED to power off the LED.
    8. Press the [Esc] key to exit the luminometer diagnostics.
  3. Verify the instrument and luminometer meet specification.
    1. Verify the dark counts with covers closed are <100 RLUs
    2. Perform a System Check procedure to verify luminometer operation, the DCF, and the Substrate Mean RLU.
      Note: If the Substrate Mean RLU is not within specification (5000 to 9000), evaluate the system for substrate contamination. Refer to the Confirming Substrate System Contamination procedure. If the substrate is not contaminated, adjust the substrate RLUs. Refer to the Adjusting Substrate RLUs procedure.
    3. Print a new Alignment Report.
    4. If a new LED value has been saved, recalibrate all customer assays.
    5. Run QC on all customer assays with results within customer limits.
