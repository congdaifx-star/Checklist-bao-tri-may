Installing Windows 10 Updates

This topic includes information about how to install critical security patches or updates for Windows 10.
Important: Perform this procedure only at the customer's request. Critical security patches can be installed or updated every six months.

Requirements

You must have the following items to perform this procedure.

  • A Documentum enterprise document management system (EDMS) account. If you do not have an account, submit a GPTS inquiry at https://danaher.sharepoint.com/sites/bec_service/gpts/SitePages/GPTS-Technical-Requests-Submission-Form.aspx
  • USB flash drive

Installing Updates

  1. Back up the system database. See Creating Immediate Backup Tape for more information.
    Important: If you are unable to back up the system database, contact customer technical support for assistance. Do not install updates for Windows 10 without first backing up the system database.

  2. On the service laptop, insert a USB drive. Scan the USB drive for malware. See USB Drive Malware Scan and Removal for more information.
  3. Sign in to use the Documentum enterprise document management system (EDMS).
  4. In the Documentum EDMS go to Cabinets > Product Development > Design History and Project Files > High Sensitivity Testing > Immunoassay > Platform > Access 2 > 2.5.5 System Evaluations.
  5. Select the ZIP file that contains the update you wish to install. The following table lists the available ZIP files and their contents.
    Important: Always install the updates contained in the most recent ZIP file.
    ZIP File Windows Update Package Files KB Number
    2025 Windows 10 Q4 Patches RSU-Access2-UniCelDxI800-UniCelDxI600-2025July.msu KB5062070
    RSU-Access2-UniCelDxI800-UniCelDxI600-2025Aug.msu KB5066187
    2024 Win10 Q4 Patches RSU-Access2-UniCelDxI800-UniCelDxI600-2024Aug.msu KB5041913
    RSU-Access2-UniCelDxI800-UniCelDxI600-2024Sep.msu KB5043050
    2024_Win 10 Q1 Patches RSU-Access2-2024Feb_1.msu KB5035849
    RSU-Access2-2024Mar_1.msu KB5034619
    2023_Windows 10 Q3 Patches RSU-Access2-2023Aug_1.msu KB5029247
    RSU-Access2-2023Aug_2.msu KB5028960
    Win10 Patch RSU-Access2-2023Jan_1.msu KB5022286

  6. Go to File > Export to export the file from EDMS to a destination folder.
  7. In the destination folder, right-click the ZIP file and select Extract All. A new folder with the same name as the ZIP file will appear.
  8. Open subfolders until you find the Windows update package (.msu) files.
  9. Select the Windows update package (.msu) files. Copy the files to the USB drive.
  10. Remove the USB drive from the service laptop.
  11. Insert the USB drive into the console PC for the instrument.
  12. Copy the Windows update package (.msu) files from the USB drive to the Desktop on the console PC.
  13. For each Windows update package (.msu) file:
    1. Open the Windows update package (.msu) file.
      Note: If you have more than one Windows update package (.msu) file, install the oldest file first.

      A dialog will be displayed with the question Do you want to install the following Windows software update?. Select Yes.
      Note: If a dialog is displayed with the message You need to accept the license terms before installing updates, select I Accept.
      Note: If the update has already been installed on the console PC, a dialog will be displayed with the notification that the update has already been installed on the computer.

      The update will be installed on the console PC. When installation is complete, a dialog will be displayed with the notification Installation Complete. You must restart your computer for the updates to take effect.

    2. Select Restart Now.
  14. Go to Settings > View update history.
  15. Confirm the KB number associated with each Windows update package (.msu) file is listed in the Quality Updates list in the update history.
