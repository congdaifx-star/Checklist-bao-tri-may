Software Versions 3.0 3.1 3.2

Access 2 Software Release Notes Version 3.0 / 3.1 / 3.2

Intended Use

For Internal Use Only - Sensitive data intended for use within BCI and normally shared with employees. There may be an occasional need to distribute this data outside the company with Management approval.

Scope

Software versions 3.0 - 3.2 require Windows XP.
  • Software version 3.0 was an update to support the Windows XP release.
  • Software version 3.1 was never released.
  • Software version 3.2 has an update to support the new IOWA CPU board. Refer to CPU Identification in the CPU CMOS Settings document.

Software 3.0 Improvements

These improvements are included in software version 3.0.
  • Backup function can now use the USB port in addition to the tape drive.
  • Copy-To-Disk functions can now use the USB port in addition to the floppy drive.
  • MS WINDOWS XPe operating system is replacing the WIN NT OS on the console only. The instrument operating system remains OS9000.
  • The new WIN XPe operating system now configures all languages after installation. Separate install steps for Japanese and Chinese languages are no longer needed and have been removed.
  • Additional foreign language text translations.
  • Derived results will now accept an assay name more than once in a single formula.

Software 3.2 Improvements

These improvements are included in software version 3.2.
  • Software has an update to support the new IOWA instrument CPU board.
