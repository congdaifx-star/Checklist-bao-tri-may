Instrument Hard Drive Contents

Summary

This document provides a listing of the Access 2 Instrument hard drive file structure. This information can be used as a quick reference to help identify the location or presence of files or directories on the instrument hard drive.

Drive Map of the /h0/ Partition

This is the first partition of the instrument hard drive. Files with attributes beginning with d are directories. To change directories, type cd <the directory name>. To list the contents of a directory, type dir -e.
