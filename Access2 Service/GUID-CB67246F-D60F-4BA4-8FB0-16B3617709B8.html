Troubleshooting Assay - HSFoamA2/HSNoFmA2

Materials required to perform the HSFoamA2 and HSNoFmA2 tests:
  • High Sensitivity System Check Solution.
  • One DOS formatted, 1.44 MB, High Density, Double Sided Floppy Disc or a flash drive (virus scanned).
  • Wash Efficiency Macro (attached, delete old copies)
Note:
  • This procedure requires the HS System Check Solution, PN A24510.
  • This procedure cannot be run with the FS System Check, PN A21537 or 81910.
  • Do not leave HS System Check at customer sites.
These tests were developed to:
  • Provide analysis of system performance beyond what is available using the system check procedure.
  • Test instrument performance at high sample RLU levels.
  • Test for smooth reaction vessel handling by using an extended incubation period (HSNoFmA2).
  • Test wash efficiency by using samples with foam on top (HSFoamA2).
  • Create alignment between the Access HS System Check and the DxI HS System Check.
Test Name Purpose Test Steps
HSNoFmA2
  • Incubates sample for 52 pitches before washing and reading

Tests RV movement through the incubator track (incubation) to detect splashing

  1. Pipette 165 µL of HS System Check into the RV.
  2. Load the RV onto the incubator belt.
  3. Moves (incubate) the RV for 52 pitches (31.2 minutes).
  4. Continues to process additional vessels, loading each belt clip with a test RV, until the incubator belt is completely full.
  5. After every clip has an RV, the instrument begins to move each RV to the wash carousel for washing.
  6. Moves the RV to the luminometer for reading.
HSFoamA2
  • Sonicates sample to create foam. Immediately washes and reads

Tests the waste system (aspiration).

Foam stresses washing and minimizes possible splashing

  1. 165 µL of HS System Check is pipetted into the RV.
  2. Sonicates the RV at high power to create a 'head' of foam over fluid.
  3. Load the RV onto the incubator belt.
  4. Incubate for 1 pitches (36 seconds).
  5. Move the RV to the wash carousel for washing.
  6. Move the RV to the luminometer for reading.
Note: Only 2 belt clips actually handle the RV's, when the incubation time is only 1 pitch. Use HSNoFmA2 for checking belt clips for splashing.

  1. Run the HSNoFmA2 (test 950) and HSFoamA2 (test 951) tests on the Access 2 instrument.
    Note:
    • The total time for running 50 replicates of each test is 1 hour and 45 minutes.
    1. Navigate to the Sample Manager screen, and unload all racks from the system.
    2. Enter the rack number into the Rack ID field and press [Enter].
      Note: Use a rack between 1 and 99.
    3. Select Test Request > More Options > Request Service Assay.
      Note: A service sample ID will be requested.
    4. For samples 1 to 5, enter a Service Sample ID, such as: 101, 102, 103, 104, or 105. Select OK.
    5. For each sample, 1 to 5, request 10 repetitions of test 950 (HSNoFmA2).
      Note:
      • Use the [+] key to add repetitions.
      • To display the service assay test menu, select Show Test Menu.
    6. For samples 6 to 10, enter a Service Sample ID, such as: 201, 202, 203, 204, or 205. Select OK.
    7. For each sample 6 to 10, request 10 repetitions of test 951 (HSFoamA2).
    8. Place ten 2-mL sample cups into the tray and fill each cup with 2.1 mL (minimum volume is now 185*10 + 150 = 2000uL) of High Sensitivity System Check solution.
    9. Select Load Rack.
    10. Place the rack on the sample carousel, and select Done.
    11. Confirm all supplies are adequate (RVs, waste bag, substrate, and the waste bottle).
    12. Select Run to begin the test.
  2. Save the Diagnostic Data.
    1. From the Main Menu, select Test Results > Filter > Onboard samples,sort by test name (not ascending) and completion time (ascending). Select Copy to Disk > All Filtered Results > OK.
    2. Save the data.
      Media Saving Procedure
      Floppy
      1. Insert a floppy disk into the A: drive.
      2. Select Copy To Disk > Current Selection > A: > OK
      3. Remove the floppy disk.
      USB

      (XP consoles only)

      Caution: If using an external USB thumb drive to collect data, be aware that external USB memory shared between the DxI console PC and other systems may introduce a virus
      1. Run virus scan on any suspect USB device that will be installed in the Console PC. See USB Drive Malware Scan and Removal for more information.
      2. Insert a flash drive into the USB port of the Console PC.
      3. Select Copy To Disk  > Current Selection. Select the desired drive from the drop down menu, and select OK.
      4. When saving is complete, remove the USB drive.
  3. Run the Performance Macro to determine pass/fail status.
    Note: Refer to Using Performance Macro procedure for detailed instructions for use. The Performance Macro automatically performs calculations on the archived results, graphs the results, and displays the results on screen. The Performance Macro also compares the test results to the default limits listed in the pass fail section of this procedure
    1. Detach and saver Performance Macro to your PC Desktop. Performance Macro.xls
    2. Open the Performance Macro file and select Enable Macros.
    3. Select the test from the macro test menu and then select Select Data file (*.csv)
    4. Enter the instrument serial number and substrate RLU, if prompted.
    5. Locate the test result data file and open it.
  4. Troubleshoot any failures. If the test fails, then refer to individual test that failed for verification and troubleshooting information.
    HSFoamA2 Failure: Check for
    Aspirate Probes
    • Restriction (dirty/clogged/bent probes).
    • Tubing snagged and pulling up on probe when aspirating.
    • Tubing kinked, pinched, or holed.
    • Improper wash arm height adjustment. Refer to the procedure Wash Arm / Probe Plate Adjustment.
    • Loose or damaged probe.
    Supplies Check that HS System Check was used. Regular System Check solution (PN A21537 or 81910) can cause failures in HSFoamA2.
    Peristaltic Pump and Waste Fluids System
    • Tubing kinked, pinched, or holed.
    • Peri pump cartridge not locked into place.
    • Blocked waste fluids system.
    • Clogged or restricted waste air filter.
    Dispense Probes
    • Probe spray pattern.
    • Dirty probe
    Wash Pump / Valve
    • Wash pump seal worn.
    • Damaged pump belt.
    • Stator / rotor / valve cap.
    HSNoFmA2 Failure: Check for
    Incubator track Debris or bump on the incubator track.
    Vessel holder Defective holder. Run Vessel Holder Exerciser.
    Incubator belt
    • Tension correct.
    • Proper guide block adjustment.
    • Torn dovetail or faulty belt.
    • Belt pulley bearings rough movement. Replace as a precaution.
    Wash Carousel bearings Rough movement. Replace as a precaution.
    Mixer
    • Bearings - rough movement. Replace as a precaution.
    • Mixer speed, mixer belt, pinch rollers, tensioner wheel.
    Mixer actuator arm Actuator bracket adjustment (0.050").
    Pipettor Alignment to RV at the dispense position.
    RV Shuttle Home and mechanical alignments.
