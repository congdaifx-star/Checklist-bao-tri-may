Advisor - Install Disconnected Version

This document describes how to install the disconnected version of Advisor.

This procedure can be performed only when Internet access is available.

Advisor is an online knowledge base tool. A separate software program, Advisor KM Offline, allows users to replicate the knowledge base to a computer. This Disconnected Version allows access to a local copy of the knowledge base when the Internet is not available.

Updates to the local copy of Disconnected Version occur through Synchronization. Technical Support recommends synchronizing once per week. For instructions, refer to the Advisor - General Info document.

Note: The Offline version of Advisor will only launch when there is physically no internet connection present. If the on-line version is down and the offline version is to be used, but network connection must be present for other programs, follow these steps:
  1. Disconnect from the internet (turn wireless radio off or disconnect network cable).
  2. Launch the KM Offline program and log in.
  3. Reconnect to the internet and re-launch any other network related programs which may have closed.
  1. Install the Disconnected Version of Advisor.
    1. Log in into Advisor while connected to the Internet.
      Note: Website: http://beckmancoulter.ptcmanaged.com/beckman-advisor
    2. Select Download KM Offline in the upper right corner.
    3. Click the Download button to save the package to your computer.
      Note: Make sure to select Save File when downloading the "KMoffline-5.4-1.zip" file.
    4. Unzip the installation package in a local directory.
      Note: It is suggested to create a folder on the user's desktop labeled "Advisor Offline". The package can be unzipped to here.
    5. Open the folder where the package was unzipped and launch the "install-and-start.bat" file.
    6. Follow the prompts in the DOS window and read the PTC Customer Agreement.
      Note: If you decline the PTC customer agreement the program will not be installed.
    7. After answering the last prompt the program will launch a browser window. Offline is now installed. Use the following commands in the "bin" folder of the package to control the program:
      • To start the service launch the "start_PTC_SKM.bat" file
      • To stop the service launch the "stop_PTC_SKM.bat" file
      • To uninstall the service launch the "uninstall.bat" file
  2. Register and synchronize Advisor.
    1. While connected to the internet, launch Advisor Offline via the "start_PTC_SKM.bat" file in the bin folder of the unzipped package.
      Note: This will launch a "tomcat" DOS window and a browser window. Do not close either while using the program.
    2. Click on the "Go online then to KM Advisor" link on the Servigistics browser page.
    3. Login with your Advisor username and password.
    4. Create your Advisor Offline password and confirm.
    5. The synchronization page will load and start synchronizing all projects that are assigned to the user group.
      Note: Synchronization can take up to an hour depending on the number of projects and the speed of the internet connection.
    6. Once synchronization is complete you can click the Home button to proceed to the disconnected version homepage.
  3. Log out of Advisor and any programs from the install process.
    1. Close the Advisor browser window.
    2. Launch the "stop_PTC_SKM.bat" file in the bin folder of the unzipped package.
    3. Close all other folders/windows that may still be open form the installation/sync process.
