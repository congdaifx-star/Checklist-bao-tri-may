Software Version 3.4.2

Access 2 Software Release Notes Version 3.4.2

Intended Use

For Internal Use Only - Sensitive data intended for use within BCI and normally shared with employees. There may be an occasional need to distribute this data outside the company with Management approval.

PCA Corrective Action

Version 3.4.2 software implements reagent pack monitoring, a corrective action for PCA 14932. The pressure monitor used for obstruction detection will now monitor pressure of reagent dispense. Test results with abnormal reagent dispense pressure will be flagged QSD and those results will be suppressed.

Mod 11296 implements software version 3.4.2.

These features are released with 3.4.2 software:
  • Implement pack monitoring
  • Prevent:
    • User Interface exit after sample tube rearrangement
    • Unknown Processes message on new small form factor PC
  • Improve:
    • QC tile creation and Levey Jennings charts
    • Dispense Probe 3 volume check
    • Software install messages
    • Text and help updates

Software version 3.4.2 will support both XP and NT consoles.

DxC 600i requires a separate software release, version 6.2.2 will be the equivalent version of this release.

Version 3.4.2 Details

Component Details
Pack Monitoring Overview The pressure monitor in the Main Pipettor will sense whether sufficient reagent is dispensed for testing. Reagent pack monitoring can detect unexpected levels of reagent in the pack, thereby avoiding errors due to improper pack loading.
New instrument pressure monitoring features:
  • If sufficient reagent is not dispensed from a reagent pack, then test replicates will be flagged with QSD and events will be reported in the event log.
  • If the system detects a pattern of reagent pack monitoring failures, then the main pipettor may be set to disabled or the pack may be rejected.
Diagnostic Copy to Disk file logs additional data New columns are included in Diagnostic Copy to Disk file:
  • reps remaining in the pack.
  • number of dispense failures.
The new section "BO_Packs_Dispense_Record" is located at the end of Diagnostic Copy to Disk file and contains:
  • Pack barcode.
  • POET ID of test replicate (allows tracking to Sample ID).
  • assay number.
  • well number of reagent pack.
  • volume of reagent dispense.
  • pressure data.
For more detailed information, refer to Theory of Operation - Pack Monitoring.
Improved capability to handle and log dispense messages
  • The console PC will store the Test ID for in progress tests and match it to the correct dispense message sent from the instrument.
  • If unexpected pack dispense messages are received from the instrument, the console will process the dispense message to prevent a critical events jam. Instrument function and pack monitoring will continue.
  • The console will log dispense message communication and details in NexStep\PC\DRW\EventSinkLog.txt.
  • If a mismatch occurs, then EventSinkLog.txt will be updated with "Console test ID is different than ID sent by the instrument" with specific details.
Quality Control Screens Prevent missing QC tiles Whenever a control rep is generated, the system will now ensure that a tile is created.
Prevent rounding errors on Levey Jennings Charts The Levey Jennings charts displayed on the QC Chart and Data screen will use more precise data (to more decimal points) to calculate the y-axis standard deviation coordinates. This prevents rounding errors which previously caused y-axis coordinates to display incorrectly.
User Interface Exit User selects >> Get Selected Rack >> Cancel >> Run. Resolves a database conflict that occurs when users rearrange sample tubes on an onboard rack, then select Cancel and Run within approximately 5 seconds. This issue previously caused a User Interface exit and Database error on version 3.3.1 software. The conflict will no longer occur.
Unknown Processes Message at User Interface Launch RTHDCPL and IGFXSRVC Resolves Unknown Processes (RTHDCPL and IGFXSRVC) message on the small form factor PC with a gray front panel. These applications are now recognized by the User Interface and no longer considered unknown.
Volume Checks Dispense Probe 3 The Dispense Probe 3 volume check will now include an operation to remove belt backlash, similar to the Dispense Probe 1 and 2 volume check.
Installation Messages Pop-up Messages

The software installation messages are changed to reduce customer confusion.

(From) Pop-up message for previous versions:
  1. The Access 2 software in the current instrument matches the setup version.  Do you want to overwrite anyway?  (Options: Yes or No)
  2. The OS9000 Software in the instrument matches the setup version.  Do you want to overwrite anyway?  (Options: Yes or No)
(To) Pop-up messages for version 3.4.2 and higher:
  1. The software version on the CD is already installed. Do you want to reinstall the software?  (Options: Yes or No)
  2. Select Yes to continue with the Operating System update.  (Options: Yes or No)

New and Updated Events

Reagent Pack Monitoring events:
  • Reagent pack monitoring reset after repeated measurements outside limits
  • Reagent pack monitoring device failure
  • Unable to initialize system due to disabled main pipettor
  • Reagent pack monitoring detected insufficient reagent
  • Pressure during reagent dispensing was not as expected
  • Reagent dispense monitoring reset due to drift from original measurements
  • Reagent pack volume set to zero after repeated monitoring failures
  • Main pipettor disabled after repeated dispensing failures
APF install events:
  • APF update attempt with a disk from another system failed
  • APF update attempt with a disk from a previous revision failed
Updated Events - added the word Main before Pipettor:
  • Main Pipettor X-Axis Motion Error
  • Main Pipettor Motion Error - Front Panel Open
  • Main Pipettor Motion Error
Updated Event details: Vacuum Under Limit Error|Vacuum Under Limit

LIS Vendor Document Update

The LIS Vendor document is updated to state that patient ID is a required field. Refer to version 387264J or higher.
