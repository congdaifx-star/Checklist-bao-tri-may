Re-image Windows 8 Console PC

This procedure describes how to re-image the Windows 8 "Mini" Console PC.

Perform this procedure when the Windows 8 console PC does not boot to the Windows desktop or when desktop appears to be corrupted.

  1. Make an immediate backup if the user interface is available. If the user interface is not available, make sure that a backup is available on the USB drive.
    Note: The re-image process erases all information on the PC hard drive. A backup of the database is required to restore the database.
  2. Insert image disk 1 of 2 into the external optical drive and restart the PC to begin the re-image process.
  3. Press Yes to the deploy ghost in the System Recovery window when it appears.
    Note:
    • "Deploy S2015ID.gho Image" displays for the original Windows 8 mini PC.
    • "Deploy S22693A.gho Image" displays for the Privacy & Security compliant Windows 8 mini PC.
    • It may take several minutes for the system recovery window to appear.
    • The image starts to load using the Symantec Ghost application
    • There is a visible "time remaining" countdown in the Ghost application screen.
  4. Insert disk 2 of 2 when prompted and press OK to continue.
  5. Remove the CD from the drive and press OK to reboot the PC when the "Process Completed" window is displayed.
    Note: When rebooting the Privacy & Security compliant Windows 8 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

  6. Plug a live network cable into the middle network port of the PC and remove all other network cables when prompted in the "Waiting for Hardware Detection" message window. Click the mouse in hardware detection window and then press any key to continue.
    Note:
    • You must click the mouse in the "Waiting for Hardware Detection" window and then press any key to auto configure the network ports. If the window is not highlighted before pressing a key, the PC network port IP addresses will not be configured and the hardware detection window will re-launch every time the PC is restarted.
    • The image program auto configures the network ports to the default IP addresses in this step. Failure to complete this step will require manually setting the IP addresses before software can be loaded.
    • The middle network port is port number 2 and should be the one that is plugged into the network hub. The network hub must be powered on for this step so the PC ports can be configured properly.
    • All other network cables must be removed from the PC during this step so the program can properly identify the network ports.
  7. Re-connect all network cables that were removed during the previous step.
  8. Activate Windows 8e on the PC.
    1. Press the Windows key and double click on the Command Prompt icon to open.
    2. Type slui.exe and press Enter.
    3. Select the Activate by Phone icon.
      • If the Activate by Phone icon is not available, select the Activate icon.
      • The activation will fail because there is no internet connection. Select Close to the failed activation window.
      • The Activate by Phone icon should now be available. If the Activate by Phone icon is still not available, reboot the PC and try again.
      • Select the Activate by Phone icon.
    4. Change the location to United States and select Next.
    5. Call the phone number listed and follow the instructions to activate Windows.
      Note: There is an option to manually enter the activation numbers or to use a smart phone to enter and receive the activation numbers. Either option works to activate Windows.
    6. Close all activation windows.
  9. Load system software and then restore the database. Refer to the Restoring PC Using Immediate Backup (Access2) or Restoring PC Using Previous Backup (Access 2) procedures for details.
