Perform Electrical Check During Troubleshooting

This procedure describes how to perform an electrical check when troubleshooting incubator belt calibration.

Perform this procedure when instructed to do to so as part of the troubleshooting process for incubator belt calibration.
Note: Refer to the Tshoot: Incubator Belt Calibration procedure.
Perform electrical check.
  1. From the Main Menu, select Diagnostics > Device Diagnostics > Mechanics > Incubator Belt.
  2. Select Home to home the incubator belt.
  3. Note the state of the home and index sensors on the screen. If the sensor states are not on or green, repair the sensors as necessary.
  4. Select Shuttle Transfer position, and then Move X to Position.
  5. Note the saved alignment value. Best practices advises that the alignment be within ±3 steps.
    If this value is greater than ±5 steps, an INCB Calib Range overrun error event is posted (even after a passing incubator belt calibration). Align the incubator belt.
    Note: Refer to the Aligning Incubator Belt procedure.
  6. Select Home to home the incubator belt.
