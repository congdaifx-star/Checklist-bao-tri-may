Software Version 2.1

Access 2 Software Release Notes Version 2.1

Intended Use

For Internal Use Only - Sensitive data intended for use within BCI and normally shared with employees. There may be an occasional need to distribute this data outside the company with Management approval.

Scope

These release notes apply to upgrades from software version 1.4.6 to software version 2.1. There were a number of significant changes made to the software in the 1.1 – 1.4.6 releases, which are described in the previous release notes but are not further described here in the Version 2.1 release notes. Version 1.4.6 contained an APF change for the Progesterone assay and there were no release notes for that version.

New Features

  • Added support for the Japanese language to the software.
  • Added obstruction detection capability to sample aspiration operation.
  • Added the assays BR15-3Ag #193, GI19-9Ag #159, BNPTriag #164, Taby #204, and Frins #205.
  • Added sonication to the mixing of assay Dil-hCG #152 to improve assay robustness.
  • Added an option to Auto-Delete Setup to allow the user to automatically delete off-board reagent packs 30 days after expiration. (Also viewed as a performance improvement on systems with large reagent inventories.)

Enhancements to existing features

Test Results screens (i.e., fields, filters):

  • Updated the Test Results Print dialog to remember the users last print type and range throughout the UI session.
  • Updated the Test Results screen to populate the Verify field based on the LIS auto verification for the result.
  • Updated the Test Results screen to set the LIS status field to “Not Sent” for LIS tests if the test result fails auto verification or the LIS is set to “Off”.
  • Updated the Sample Details dialog and Patient Report to display the patient birth year with four digits. Previous versions displayed only two digits for the birth year.
  • Added “# of Hours” as an option to the Test Results Filter Date and Time Range dialog.
  • Added the instrument serial number to Diagnostic Copy to Disk, Sample Report, and Patient Report.
  • Updated the Sample Report to sort the test results by assay name.
  • Updated the software to display, report, and transmit an interpretation for QC confirmatory results.

Quality Control screens (i.e., configuration, displays):

  • Updated the QC Add/Edit Control screens to allow the user to define a maximum of 50 assays per control. Previous versions of software allowed a maximum of 20 assays.
  • Updated the software to display, report, and transmit an interpretation for QC confirmatory results.
  • Updated the QC Chart Data screen to combine the Change Reagent Lot and Edit Date Range functions into a single filter dialog. Corrected the reagent lot selection list to always contain all reagent lots in the database. Previous versions required the user to first change the reagent lot selection to “All”, when switching the reagent lot to be viewed.

Miscellaneous (LIS, event log, supplies, work-flow, multi-dimensional screen changes):

  • Increased the maximum total allowed characters for the patient name fields from 30 to 40 characters when receiving patient demographics from the LIS.
  • Changed the Patient ID field from required to optional when receiving it from the LIS.
  • Updated the “Patient Id could not be updated” event log message to indicate the Sample Id and Patient Id sent from the LIS Host.
  • Updated the “Curve Fit Failed” Event Log message to indicate the assay that failed.
  • Updated the Reagent Supplies screen to only display the test left field in yellow if there are <10 onboard for the entire reagent lot. Previous versions of software displayed the field in yellow, if there was <10 test left in an individual reagent pack.
  • Updated the software to allow confirmatory assays to run on an aliquot of the sample that is different than the corresponding screen assay. Updated the software to allow reflexing of confirmatory assays to a different tube of the sample. Previous versions of software forced confirmatory assays to always run on the same sample tube as the screen assay.
  • Updated the status bar to display the instrument ID number. (New requirement for DxI.)
  • Updated the system to consistently display and print the configured number of decimal places for an assay. Fields affected are as follows:
    • Displaying ranges for a test in following reports and dialogs:
      • Patient Report
      • Sample Report
      • Continuous Sample Report
      • Ranges report (Reference, LIS and Critical ranges)
      • Test Results Screen -> Sample Details Dialog
      • Test Screen->Ranges Dialog- Low/High dose range.
    • Calculated Mean/SD and SDI
      • QC Chart and Data screen
      • QC Compare Charts screen
      • QC Chart/QC Data Report
      • QC Copy to Disk
    • SDI
      • QC Chart and Data screen
      • QC Chart/QC Data Report
      • QC Copy to Disk
    • Stated Mean/SD
      • QC Chart/QC Data Report
      • QC Copy to Disk
    • Calculated and Stated Concentration
      • Calibration Data screen
      • Calibration Data Report

Note: A Pipettor field was added to the following screens and reports to allow a consistent implementation between DxI and Access 2: QC Review Report, QC Data Report, QC Chart Report, Test Setup Report, QC Setup screen, QC Chart and Data screen, QC Chart and Data Filter dialog, Test Results screen, and Test Setup screen. For the Access 2 this field will always display N/A.

Improved System Performance

  • Changed the default Event Log filter to the “Last 7 days”.
  • Improved the performance of the Event Log screen by converting the Events database to use a new indexing feature of the POET database.
  • Improved the performance of printing Event Log reports.
  • Improved the performance of communications with the LIS Host when sending “Idle” test results to the LIS, querying for test requests, and sending test results (automatically or manually from the Test Results screen).

Problems Corrected in this Release

There were many issue corrected in this software release, some issues presented a higher field or customer impact than others. The list below is divided into two sections with the first including issues that held a slightly higher impact and the second including issues that held lower field or customer impact.

Higher impact issues:

  • Corrected a problem that caused reagent packs to be permanently “locked” following a fatal device error for packs used in two-step assays. Future recovery includes rebooting the AU and console.
  • Updated the software to prevent the user from deleting a calibrator lot if calibration curves are in-progress or requested for the calibrator lot. This prevents a problem condition where the user receives the popup message "Warning: The default reagent lot already has a curve in process or requested. Select another lot.” when attempting to re-calibrate the reagent lot which was in-progress or requested at the time of the calibration lot deletion.

    • Updated Restore Utility to correctly allow setting of the IP address by service personnel.
    • Updated the instrument software to always home the sample carousel prior to scanning a rack. This eliminates a problem that could occur if the user moved the carousel by a full position, when loading a rack. In that case, if a sample tube in position 5 or 6 had a barcoded sample id that was combination of a numeric value followed by alphanumeric characters (e.g. 1300A), the sample id would be read as a valid rack id. Subsequently , the user would be unable to unload this rack from the system.
