Aligning and Adjusting Internal Reagent BCR (Access 2 Enhanced Only)

This procedure describes how to check and adjust the Internal Reagent Bar Code Reader alignment.

This procedure should be done anytime there is an Internal Reagent Bar Code Reader failure or after a Peltier Replacement.

  1. Open the instrument front cover and insert the interlock switch bypass key into the front cover interlock switch.
  2. Align the Reagent Carousel to the Internal Reagent Bar Code Reader.
    1. From the Main Menu select Diagnostics [F7] > Device Diagnostics [F4] > Mechanics [F1].
    2. In theMechanics [F1] screen select the Reagent Carousel from the device drop down menu.
    3. Home [F1] the Reagent Carousel.
    4. Open the Reagent Pack Loader Door and ensure there is a Reagent Pack in the current position (position #1) on the Reagent Carousel.
      Note: If the current position is empty, then load a reagent pack into the empty position.
    5. Select the Bar Code Reader position.
    6. Select Move X to Position [F2] to move the reagent pack to the Bar Code Reader position.
      • If the pack is detected, the Bar Code Reader field will look like this (characters present):
      • If the pack is not detected, the Bar Code Reader filed will look like this (empty):
      Note: It may take several seconds for the Bar Code Reader field to populate with characters.
    7. Determine the window of detection for the Reagent Bar Code Reader.
      • Using the left and right arrow keys on the screen or keyboard, move the Reagent Carousel as far to the left and as far to the right until the Reagent Bar Code Reader last detects the pack (still shows characters in the Bar Code Reader field).
      • Record those two alignment offset numbers (this is the window of detection).
    8. Center the alignment.
      • Using the left/right arrow keys, set the alignment offset value to the midpoint of the window of detection.
    9. Save the alignment by selecting Save Offsets [F7].
      Note: Due to Reagent Pack Barcode label variability it may be necessary to perform the alignment to multiple packs to calculate the best alignment offset number.
  3. Confirm the Reagent Carousel to Internal Reagent Bar Code Reader Alignment.
    1. Home [F1] the Reagent Carousel.
    2. Select Move X to Position [F2].
    3. Verify Bar Code Reader detects the reagent pack by noting characters in the Bar Code Reader field.
    4. Home [F1] the Reagent Carousel.
    5. If a reagent pack was loaded for this alignment procedure, then remove the reagent pack.
    6. Press [Esc] key to exit the Alignment screen.
    7. Select Yes [F1] when prompted to save the alignments.
    8. Remove the interlock switch bypass key and close the instrument front cover.
      Note: If the alignment offset requires more than + or - 15 steps, then the offset can be reduced by the following (in stated order):
      • Adjusting the Reagent Cover.
      • Adjusting the Reagent Cover BCR Bracket.
      • Adjusting the Reagent Carousel Home Sensor. If adjustment of the sensor position is not sufficient, then realign the carousel to the drive pulley. Refer to the Alignment section of Replacing Peltier (Access 2) procedure.
    9. If any adjustments are made then repeat steps 1 through 3.
  4. Verify system operation.
    1. Perform the required system verification.
      Note: Refer to the Instrument Verification Protocol for Access Service Repair document.
    2. Contact your local support organization with any questions or concerns.
  5. Ensure the Cover Interlock Bypass Key is removed from the Front Cover Interlock Switch. Do not leave the key at customer site.
