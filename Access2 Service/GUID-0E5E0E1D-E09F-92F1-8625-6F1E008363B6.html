Software version 2.2

Access 2 Software Release Notes Version 2.2

Intended Use

For Internal Use Only - Sensitive data intended for use within BCI and normally shared with employees. There may be an occasional need to distribute this data outside the company with Management approval.

Scope

These release notes apply to upgrades from Version 2.1 software to Version 2.2 software. There were a number of significant changes made to the software in the 2.1 release, which are described in the Version 2.1 release notes but are not further described here in these release notes. Version 2.1 software had many bug fixes and enhancements and those release notes should be reviewed as well, especially if that version had not been installed.

New Features or enhancements to existing features

  • Added an option to have the patient name printed on the continuous sample report if it is available.
  • Added a new LIS option to ignore duplicate test orders (registry setting - a mod will follow).
  • Simplified installation, it now takes care of exiting and terminating the correct processes and prevents installing while the instrument is in operation.
  • The software will now allow a reflex to TBhCG2 from a low Dil-hCG2 value.
  • Removed APF files from software installation disk. (They are available on a separate disk)
  • Removed PDF manuals from system software disk and the links into them in the online help (except Japanese).
  • Updated help files for French, Italian, German, Spanish, and Japanese versions.

Problems Corrected in this Release

  • Fixed an assertion error (UI vaporization) when pressing “RUN” resulting from a POET database bug.
  • Fixed the missing QC tile issue.
  • Removed “Assay not found” message.
  • Fixed the Obstruction Detection Comm error preventing the initialization when the instrument is started with the cover open.
  • Fixed the issue that resulted in the Folate icon remaining red after calibration.
  • System software now prevents loading APFs from another platform.
  • Fixed an assertion error in test request when a sample that is selected on screen is removed from the tray.
  • Fixed an assertion error in calibration review when changing the filter no longer displays the currently selected calibration.
  • Improved the UI control over other processes at startup.
  • Fixed issues associated with loading APFs for R&D and Systems Integration.
  • Fixed display of Y axis in QC review.
  • Fixed an assertion error related to a reagent carousel load/unload issue.

Contact

Contact your local support organization with any questions or concerns.
