Changing File Paths on Console PC (DxI and Access 2)

This procedure describes how to change the load path of various files so that the files can be copied from or to the console PC USB flash drive or hard drive.

Change the file paths on the console PC to:
  • Update the APF from a USB flash drive if there is a problem with the APF CD.
  • Load software if there is a problem with the software CD.
Note: For Windows XP systems running software 5.2 and below or Windows 8 systems running software 5.3.1 and above, it is not necessary to change the file path for the for the following copy-to-disk functions:
  • Save the diagnostic archive files to the PC hard drive so that they can be downloaded remotely for analysis.
  • Save test results files to the PC hard drive so that they can be downloaded remotely for analysis.

The functions have a drop-down menu to select a location of the prefer drive for the copied data. If the drop-down does not show the preferred drive, then exit the user interface and relaunch it.

Note:

For Windows XP console PC:

  • If the customer is using the USB drive as a backup device, then the USB drive used for copy-to-disk functions cannot have the name BACKUPDRIVE. To change the name of the USB drive in Windows Explorer, right click on the USB drive name and select Rename.

For Windows 8 Mini PC:
  • If the customer is using the USB drive as a backup device, then the USB drive used for copy-to-disk functions cannot have the name BACKUPDRIVE. To change the name of the USB drive in File Explorer, right click on the USB drive name and select Rename.
  1. Modify the APFLoadPath to update the APF from a USB flash drive.

    For Windows XP console PC:

    1. Press the Windows key, and then select Run > regedit. In the registry editor, double-click to select HKEY_LOCAL_MACHINE > SOFTWARE > Beckman > NexStep.
    2. Use a laptop PC to copy the APF files from the CD onto a USB flash drive.
    3. In the NexStep folder in the registry editor, right click on APFLoadPath, select Modify, and change the value from D: to E or F:.
      This instructs the software to copy the files CD-ROM drive (D:).
    4. Insert the USB flash drive containg the APF files into the console PC. In the user interface, select Configure > Tests > Update APF to update using the files on the USB flash drive.
    5. In the registry editor, right click on APFLoadPath, select Modify, and change the value from E or F: to D: to return to the original file path.
    6. Exit the registry editor.

    For Windows 8 Mini PC:

    1. Press the Windows key, type regedit and open the program. In the registry editor, double-click to select HKEY_LOCAL_MACHINE > SOFTWARE > Beckman > NexStep.
    2. Use a laptop PC to copy the APF files from the CD onto a USB flash drive.
    3. In the NexStep folder in the registry editor, right click on APFLoadPath, select Modify, and change the value from D: to E or F:.
      This instructs the software to copy the files CD-ROM drive (D:).
    4. Insert the USB flash drive with the APF files into the console PC. In the user interface, select Configure > Tests > Update APF to update using the files on the USB flash drive.
    5. In the registry editor, right click on APFLoadPath, select Modify, and change the value from E or F: to D: to return to the original file path.
    6. Exit the registry editor.
    For Windows 10 PC:
    1. Press the Windows key, type regedit and open the program. In the registry editor, double-click to select HKEY_LOCAL_MACHINE > SOFTWARE > WOW6432Node > Beckman > NexStep.
    2. Use a laptop PC to copy the APF files from the CD onto a USB flash drive.
    3. In the NexStep folder in the registry editor, right click on APFLoadPath, select Modify, and change the value from D: to E or F:. This instructs the software to copy the files CD-ROM drive (D:).
    4. Insert the USB flash drive with the APF files into the console PC. In the user interface, select Configure > Tests > Update APF to update using the files on the USB flash drive.
    5. In the registry editor, right-click on APFLoadPath, select Modify, and change the value from E or F: to D: to return to the original file path.
    6. Exit the registry editor.
  2. Modify the software load path to update the software from the C: drive.

    For Windows XP console PC:

    1. Exit the user interface. Insert the software CD into the CD-ROM drive, and then cancel the software installation if it launches.
    2. Right-click on the PC desktop, and select New > Folder to create a folder on the console PC desktop
    3. In Windows Explorer browse to the D: drive, press [Ctrl] + [A] to select all the files on the CD. To copy all the selected files to the clipboard, press [Ctrl] + [C].
    4. Right click on the new folder and select Paste.
      Note: If there is an error copying the files, then the software CD is unusable.
    5. In Windows Explorer, browse to the new folder and double click on the setup.exe file to start the software installation.

    For Windows 8/10 PC:

    1. Exit the user interface. Insert the software CD into the CD-ROM drive, and then cancel the software installation if it launches.
    2. Right-click on the PC desktop, and select New > Folder to create a folder on the console PC desktop
    3. In File Explorer browse to the D: drive, press [Ctrl] + [A] to select all the files on the CD. To copy all the selected files to the clipboard, press [Ctrl] + [C].
    4. Right click on the new folder and select Paste.
      Note: If there is an error copying the files, then the software CD is unusable.
    5. In File Explorer, browse to the new folder and double click on the setup.exe or installer.exe file to start the software installation.
  3. Verify that the file path has been returned to its original setting before completing service.
