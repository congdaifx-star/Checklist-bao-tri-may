Determining which Diagnostic Test to Perform

Purpose

This procedure contains an overview of the various diagnostic tests available for troubleshooting system performance.

Identifying symptoms

Important notes related to identifying symptoms of instrument failures:

  • Always verify a complaint or issue by analyzing data.
  • The description provided by the customer may not always accurately describe the issue, therefore obtain as much supporting information as possible.
  • Determine if the issue is general imprecision, an occasional outlier, or a one-time shift.
  • Determine if the issue relates to patient samples, controls or both?
  • Ensure that a current system check is being reviewed. Old system checks contain old data.
  • The system check procedure is the most comprehensive diagnostic tool available to characterize a system issue involving sample pipetting, RV mixing and washing, substrate delivery, and RLU measurement.
  • System check does not assess high-power ultrasonics, pipetting from a reagent pack, pipetting very small volumes, or making dilutions.

Verifying performance

Verify the performance of each suspected module using the appropriate diagnostic test from the menu of diagnostic tests. When the source of the issue has been determined, correct the issue, and then verify system performance using the correct tests. Perform a complete system check to verify system performance.
