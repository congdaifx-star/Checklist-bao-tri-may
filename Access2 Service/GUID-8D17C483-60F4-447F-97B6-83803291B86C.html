Modifying AU NVRAM

This procedure describes how to edit the Access 2 instrument NVRAM file, repair the instrument serial number information, or modify the run time.

This procedure describes how to edit the Access 2 instrument NVRAM file, repair the instrument serial number information, or modify the run time. The nvsetup.csv file in the instrument hard drive contains the serial number, alignment offset, run time, and luminometer setup values. This procedure is for Access 2 systems only.

Perform this procedure ONLY when you have determined that the instrument NVRAM must be edited because of any of these circumstances:
  • A swapped in I/O PCB has overwritten the nvsetup.csv file on the hard drive.
  • The nvsetup file requires modification beyond what can be adjusted in the user interface.
  • Software installation on a new AU hard drive has uploaded a blank nvsetup file into the I/O PCB.
  • Replacing with a new AU hard drive or imaging the AU hard drive has reset the run time to zero.
This procedure uses:
  1. Notepad or Wordpad to edit a backup copy of the nvsetup.csv file located on the PC.

  2. Ftp to move the nvsetup.csv file to the AU hard drive.

  3. Telnet to send the nvsetup.csv file to the I/O PCB.

Table 138: AU Programs and Commands
Program Result Examples
nvinit.sh Saves NVRAM from hard drive into I/O PCB. Replacing used I/O PCB. Transfers NVRAM from hard drive.
ram2disk.sh Saves I/O PCB NVRAM to hard drive. Replacing AU hard drive. Transfers NVRAM from I/O PCB.
setserial.sh Allows modification of instrument serial number and saves nvsetup file from hard drive into I/O PCB. Instrument has wrong serial number (an uncommon situation).

  1. Modifying AU NVRAM on Windows 8/10 system.
    1. Identify the AU IP address.
      Note: The AU IP address can be changed by editing the startup file and sending it to the AU h0/sys directory.
      1. In File Explorer, navigate to the c:\nexstep\pc\drw\os9000 directory.
      2. Open the startup file using Notepad or Wordpad.
      3. Scroll down to the line that starts with ifconfig enet0 192.168.2.x and identify the AU IP address. (192.168.2.x where x=the address of the AU).
      4. Exit Notepad or Wordpad.
    2. Edit the nvsetup.csv file as required (run seconds, serial number, system ID, LED counts).
      1. (Option 1) If the file has no alignments (all zeros), then check the nvsetup.csv copy stored in the backup folder.
        1. Confirm that the alignment values are present in the nvsetup.csv file.
        2. Exit the nvsetup.csv file.
        3. Right-click on the nvsetup.csv file, and select Copy (xxxxxx).
        4. Navigate to c:\nexstep\pc\drw\os9000.
        5. Right-click on the os9000 folder and select Paste to paste the nvsetup.csv file into the os9000 folder.
        6. At any Confirm File Replacement messages, select Yes.
        Note:
        • Each time software is loaded, the copy of the nvsetup file in the PC is saved so the alignments and run seconds might not be current.
        • Instruments on Windows XP with flash drive backup have multiple backup folders on the PC. If the alignment file in Backup contains all zeros, then check the nvsetup.csv files in Backup1, Backup2, Backup3, Backup4, or Backup5.
      2. (Option 2) Modify the Access 2 run time.
        1. In File Explorer, navigate to c:\nexstep\pc\drw\os9000.
        2. Open the nvsetup.csv file using Notepad or Wordpad.
        3. Scroll down until you locate line Run Time (seconds). Change the Run Time, calculated in seconds, to the desired time. For example, to change Run Time to 7 hours, calculate the time in seconds: 3600 sec/hour × 7 hours = 25,200 seconds.
        4. Save the file and exit.
    3. Send the nvsetup.csv file from the PC to the AU hard drive.
      1. At the Windows desktop, press Windows key, and open the Command Prompt icon or type command prompt and open the program.
      2. In the CMD window, at the C:>prompt type ftp and then press [Enter].
      3. At the ftp> prompt, type open 192.168.2.x and then press [Enter] (x= the address of the AU).
        Note:
        • The most common AU IP address is 192.168.2.4. Client instruments or instruments with new AU hard drives can have different IP addresses.
        • If the IP address is unknown, then:
          1. Press Windows key, select Restore Utility icon or type restore utility and open the program.
          2. In the Restore Utility, select Modify PC Specific Registry.
          3. Record the AU IP address that is shown.
      4. At the ftp> prompt, type super and then press [Enter]. For password, type user then press [Enter].
        Note: The password user is invisible when typed.
      5. At the ftp> prompt, type ascii and then press [Enter].
      6. At the ftp> prompt, type prompt and then press [Enter].
      7. At the ftp> prompt, type cd /nexstep/drw and then press [Enter].
        Note: There is a space between cd and /nexstep.
      8. At the ftp> prompt, type mput c:\nexstep\pc\drw\os9000\nvsetup.csv and then press [Enter].
        Note: If the prompt responds with mput c:\nexstep\pc\drw\os9000\nvsetup.csv?, then type y and press [Enter]. This extra question indicates that a previous step was not completed; however, typing y resolves the issue.
      9. Close the CMD window.
    4. Send the nvsetup.csv data from the AU hard drive to the I/O PCB.
      1. At the Windows desktop, press Windows key, type run and open the program.
      2. In the Run dialog box, type telnet 192.168.2.x (x= the address of the AU), and then press Enter.
      3. In the telnet window, at the user name prompt, type super and then press [Enter]. For password, type user then press [Enter].
        Note: The password user is invisible when typed.
      4. At the (super) [/hØ/>] prompt, type cd /hØ/nexstep/scriptutil and press [Enter].
      5. At the (super) [/hØ/nexstep/scriptutil/>] prompt, type nvinit.sh -d and press [Enter] to send the nvsetup file information to the I/O PCB.
        Note: If the instrument serial number must be changed, then type setserial.sh, [space], enter the new serial number, and then press [Enter].
      6. Type break and press [Enter] to reboot the AU.
      7. Close the telnet window and any other open windows on the desktop.
      8. Restart the user interface.
    5. Confirm that the nvsetup.csv file has been modified correctly.
      1. (Option 1) Modifying alignments: Confirm that the AU alignments have been restored correctly.
        1. Use a previous alignment report to confirm that the LED target is correct in the Luminometer Diagnostics screen and the device alignments are correct.
        2. If the LED value and alignments do not match the alignment report, then adjust and save the values from the user interface.
      2. (Option 2) Modifying Run Time: If the Run Hours in the Event Log details are still showing the old time, initialize the system to create an event message and refresh the message from the instrument to post the modified (new) time to the PC.
    6. Verify System operation.
      1. Perform the required system verification.
        Note: Refer to the Instrument Verification Protocol for Access Service Repair document.
      2. Contact your local support organization with any questions or concerns.
