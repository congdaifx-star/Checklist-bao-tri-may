Replacing Vacuum Sensor

This procedure describes how to replace the vacuum sensor on the fluidics interface PCB.

Required Materials:
  • New vacuum sensor
  • Philips-head screwdriver
  • 5/16-in socket adapter
This procedure applies to Access Fluidics Interface PCB PN 7639F and higher, because earlier versions do not have a removable sensor.
Replace the sensor when:
  • Vacuum sensor reading is not 10 mm Hg or less with the vacuum pump turned off and the vacuum valve open.
  • Vacuum sensor voltage reading is not 1.485 V DC or more with the vacuum pump turned on and the vacuum valve closed (vacuum at a minimum is 450 mm Hg).
  • Vacuum sensor is the only failed component.
  1. Remove the fluidics interface PCB.
    Note: Refer to the Replacing Fluidics Interface PCB procedure.
  2. Remove the vacuum sensor.
    Caution: Use ESD precautions when working with electrical components.
    1. Locate the vacuum sensor on the fluidics interface PCB. The sensor is secured with two Philips screws, six washers, and two nuts.
    2. Place a 5/16-in socket adapter on the nut to hold the nut securely. Using a Philips-head screwdriver, loosen and then remove the screw and nut.
      Caution: When removing the screw and nut, do not to lose the washers and spacers.
    3. Remove the sensor from the PCB, by bending the sensor upward and pulling away from the PCB socket firmly.
      Caution: When removing the sensor, do not to break off any pins in the socket. If a pin breaks off inside the socket, replace the PCB, the PCB is damaged.
  3. Install the vacuum sensor.
    1. Locate the notch on the new vacuum sensor pin. Refer to the Fluidics Interface PCB diagram.
    2. Align the four pins of the sensor with the socket on the PCB.
      Caution: Install the notch to the left when facing the component side of the PCB. Installing the sensor incorrectly damages the sensor.
    3. Push the pins of the sensor into the socket. Then bend the sensor down toward the PCB until the sensor is flush against the PCB plane.
      Caution: Do not attach the vacuum tubing until the vacuum sensor voltage is confirmed.
    4. Assemble and secure the sensor to the PCB. Refer to the figure for correct order of the washer and spacers.


  4. Install the fluidics interface PCB.
    Note: Refer to the Replacing Fluidics Interface PCB procedure.
