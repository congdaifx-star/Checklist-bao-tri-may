Software Version 4.0.0

Software version 4.0.0 release notes

Intended Use

For Internal Use Only - Sensitive data intended for use within BCI and normally shared with employees. There may be an occasional need to distribute this data outside the company with Management approval.

Software version 4.0.0 feature details
  • hsTnI carryover resolution for field action (FA-000604) - Installation of software version 4.0.0 along with APF 2023B as part of Mod 12828 is the mitigation for field action FA-000604 for hsTnI. The customer no longer needs to perform the actions in FA-000604 after completing Mod 12828. The software implements an "O" command wash of the pipettor for all hsTnI samples. Refer to the updated hsTnI assay IFU on the Beckman Coulter website for the new carryover specifications.
  • APF Installation Control - Ensures that only .3 APF versions (example 2.9.183.3) can be loaded on new instruments with software version 4.0.0 or above. This ensures proper implementation of "O" command probe washing.
  • BAssert Error When Utility Assay Completes - Software version 4.0.0 updates the memory handling of events to prevent a BAssert error from occurring when the utility assay completes.
  • Installer Database Licensing - The database license is updated when converting from PoetObjects to FastObjects during the software load. This feature improves the installation process when upgrading from older software versions.
  • Installer Upgrade - The software installer tool will automatically update data files which were not properly versioning in the previous software versions. This feature improves the installation process.

Implementation

  • Software version 4.0.0 along with APF version 2.9.183.3 will be implemented as mandatory Mod 12828 for fielded instruments.
  • The software requires regulatory clearance in all geographies and is not available in all countries upon the initial release date of Mod 12828.
  • Refer to Oracle Mod 12828 to determine if software version 4.0.0 is released for a specific instrument or geography.
  • Software version 4.0.0 will only ship with new instruments for geographies that have regulatory clearance.
  • Software version 3.7.0 will continue to ship with new instruments for geographies that have not received regulatory clearance.
  • Software version 4.0.0 can be installed on Windows XPe, 8e, or 10 operating systems.
