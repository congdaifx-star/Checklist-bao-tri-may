Troubleshoot Access 2 PC

Summary

This document provides a central location for some known PC hardware and software issues and troubleshooting guidelines for problem resolution. This document is updated as new issues or resolutions are identified.

General PC Errors

Error Possible Cause Recovery
The PC presents various errors after accessing the hard drive.
  • PC hardware issue.
  • Over temperature because of blocked ventilation holes.
  • Replace the hard drive ribbon cable. The CD ROM ribbon cable can be borrowed for confirmation.
  • Reseat the PC peripheral cards (modem, video, serial)
  • Confirm that the vent holes are not blocked.
The mouse and keyboard are locked up.
  • Mouse connected to a USB port.
  • Insufficient power provided by the DTx PC when using mouse or keyboard extension cables.
  • Connect the mouse only to the PS2 mouse port. Windows NT does not support USB operation.
  • Try removing cable extenders or install a powered keyboard and mouse extender (A22794).
The touch screen monitor is not detected.
  • Wrong port selected or port is locked up.
  • Try connecting the serial cable to alternate ports on the PC, and then attempt to find the touch screen using the Touchware program. The find feature requests a port selection.
  • Reinstall the Touchware program (C:\installs \touch\setup.exe).
  • Port Com 2 has a noise lockup problem on DTx PCs. Use cable 986389 to resolve lockup issue.
The USB touch screen monitor is not detected
  • USB not connected at monitor or PC.
  • Defective USB cable
  • USB port not functioning
  • Verify USB connection at monitor and PC
  • The printer uses the same USB cable, try swapping the cables to see if touch screen function returns.
  • Try using an alternative USB port.
The bar code reader beeps but does not scan text.
  • Bar code reader connected to the PC mouse port.
  • Connect the bar code reader to the keyboard connector on the PC, and then connect the keyboard to the bar code reader.
Windows could not start because the following file is missing or corrupt: \WINNT\SYSTEM32\CONFIG\SYSTEM HARDWARE Profile / Last Known Good Menu.
  • System configuration file and backup have both been corrupted on the hard drive by powering down the PC without shutting down Windows (where the system file is written incorrectly) or by Windows NT itself.
  • Replace the hard drive. If needed, the database files can be recovered from the old hard drive (with assistance from technical support).
Physical Memory Dump.

The name of the process or program that crashed is displayed in the last line of the upper section of the window (for example, mga64.dll (video), pcAnywhere, AUobj.exe).

BSOD - "Blue Screen of Death.

  • pcAnywhere connection.
  • Okidata printer driver. The Okidata printer comes with an installation software CD in the box. Do not use the CD. Installing the Okidata software can cause the system to crash. All the files for installing the printers are resident in the PC.
  • No identifiable cause.
  • Reboot the PC.
  • If the error continues, reboot the PC. Press and hold [Ctrl] key after the large NT logo displays to prevent the UI software from launching. From the Windows desktop, delete the Okidata printer driver and install a LaserJet III printer driver.
Terminator record missing in LIS message. The event is posted each time the UI console initializes or the Host is queried.
  • SW V2.1 The LIS transmission index is corrupt. The transid.dat file in the DRW folder is looking for an incorrect or lost LIS message. The LIS message files are saved in the C:\ directory. Each message is normally deleted when its data is saved to the database.
  • SW V1.4. The terminator record is the "L|1|F" in the LIS message indicating that no more records are going to be sent in the message.
  • Example message:
  • H|\^&|||ACCESS|||||LIS||P|1|20011217115504
  • Q|1|^SampleID||ALL||||||||O
  • L|1|F
  • SW V2.1 Delete the contents of the transid.dat file. Save the empty file. Delete all the left over .lii message files in the C:\ directory. Expect to delete thousands of (date_time_index, 20041102_150906_879.lii) message files (1 KB each).
  • SW V1.4 or V1.5 is used in the LXi. The error message can indicate an interruption in the LIS transmission before receipt of the terminator record. The transid.dat file was created in V2.1 to fix this issue.
