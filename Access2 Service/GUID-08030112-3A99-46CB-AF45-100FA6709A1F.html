Changing AU IP Address Assignment

This procedure describes how to assign an instrument a specific PC.

This procedure provides instructions for assigning an instrument to a specific PC.

The Access 2 user interface on the server PC does not launch when its assigned instrument is not communicating. The user interface launch fails with a socket connect failed error message. If the server user interface does not start, then the client user interface, which depends on the Server, also does not start. Sometimes the server instrument is down for repairs and the customer must run on the client instrument. Temporarily assigning the client instrument to the server PC allows the customer to operate the client instrument from the server PC console.

Perform this procedure to:

  • Use a client instrument while the server instrument is waiting for repair.
  • Change the instrument IP address that the console PC connects to following promoting a client PC to a server PC.
  • Swap instruments between the client PC and the server PC

For the following action... Refer to...
Changing AU IP address assignment on Windows 8 system Step 1
Changing AU IP address assignment on Windows XP system Step 2
  1. Changing AU IP address assignment on Windows 8 system.
    1. Modify the AU IP address assignment in the PC registry.
      Note: The registry entry tells the PC what address to connect to for communicating with an instrument.
      1. On the server PC, press Windows key and select Restore Utility application icon.
      2. In the Restore Utility window, select Modify PC Specific Registry.
      3. Change the last digit of the Instrument IP address to match the address of the functional (client) instrument.
        Note:
        • Normally, the server instrument address is 2.4 and the client instrument address is 2.6. If needed, ping to identify the correct address.
        • Refer to the Ping the PC section of the Troubleshooting Network Errors Access 2 procedure.
      4. Select OK to complete the Modify PC Specific Registry process. Select Exit.
      5. Launch the user interface.
        • Double click on the NexStep Application shortcut on the desktop.
      6. If this change is temporary, then return to the Modify PC Specific Registry function, change the address back to the original number, and then exit the Restore Utility.
        Note: The user interface operates normally, controlling its assigned instrument. The IP address assignment change does not take effect until the UI is relaunched or the PC is rebooted.
        Note: When rebooting the Privacy & Security compliant Windows 8 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

  2. Changing AU IP address assignment on Windows XP system.
    1. Modify the AU IP address assignment in the PC registry.
      Note: The registry entry tells the PC what address to connect to for communicating with an instrument.
      1. On the server PC, select Start > Programs > Access2 > Restore Utility.
      2. In the Restore Utility window, select Modify PC Specific Registry.
      3. Change the last digit of the Instrument IP address to match the address of the functional (client) instrument.
        Note:
        • Normally, the server instrument address is 2.4 and the client instrument address is 2.6. If needed, ping to identify the correct address.
        • Refer to the Ping the PC section of the Troubleshooting Network Errors Access 2 procedure.
      4. Select OK to complete the Modify PC Specific Registry process. Select Exit.
      5. Launch the user interface.
        • Select Start > Programs > Access2 > Access2 or NexStep.
      6. If this change is temporary, then return to the Modify PC Specific Registry function, change the address back to the original number, and then exit the Restore Utility.
        Note: The user interface operates normally, controlling its assigned instrument. The IP address assignment change does not take effect until the UI is relaunched or the PC is rebooted.
