Disabling ProMon and Intel(R) NMS Applications

This procedure describes how to disable the NMS and ProMon applications on the DTxPC.

This procedure provides instructions for disabling the NMS and ProMon applications on the DTx PC.

The NMS and ProMon applications were installed when the Dual NIC (Network Interface Card) was added to the console PC. These applications might not have been disabled on some new Blue Dot (A30133) or Orange Dot (A38446) DTx PCs. The NIC upgrade procedure MOD 6693 (located in the DxI service manual) provides instructions for disabling these two applications after installing the NIC software into older DTx PCs.

Perform this procedure when:
  • The NMS (Network Management System) application slows the installation of system software into Access2 or DxI systems. The installation progress bar stalls at 99% for several minutes, then the installation dialogue windows disappear for another several minutes. Eventually the installation windows reappear and the installation process continues normally.
  • A related application, ProMon, creates an Unknown Processes Running popup window before the UI launches after each reboot of the PC.
  1. Disable the ProMon application on the PC.
    1. Right-click on the Intel(R) Proset II icon located at the bottom right corner of the display.


      Note: If the icon is not present, then ProMon has been disabled.
    2. Select Exit and Do Not Launch at Startup from the menu that displays.
  2. Disable the NMS application on the PC.
    1. From the Windows NT desktop, select Start > Settings > Control Panel > Services,


    2. Using the vertical scroll bar, move up or down the Service list to find the Intel(R) NMS service.


    3. Select the Intel(R) NMS Service entry, and then select Startup.
    4. In the Service window, change the Startup Type to Disabled and select OK.


      Note: Keep the Log On As selection set to System Account and the Allow Service to Interact with Desktop option selected.
    5. Select Close to exit the Services window, and then Restart the PC.
      Note: If you do not want to reboot the PC now, select Stop with Intel(R) NMS highlighted before closing the Services window.
