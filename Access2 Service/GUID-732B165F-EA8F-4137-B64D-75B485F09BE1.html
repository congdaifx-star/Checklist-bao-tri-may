Installing Touch Screen Monitor Driver

Use this procedure to install the driver necessary to operate the touch feature on the DTX USB touch screen monitor and add the driver to the Privacy & Security white list if needed.
Note: The driver for all serial cable monitors are compatible with all previous touch screen monitors used on the Access 2 and DxI systems.

Pre-requisite:
  • Install the USB touch screen monitor to instrument cart or arm with all cables are connected to the Console PC.

New USB Touch Screen Monitor Driver - eGalaxTouch Software

Note: Download the following zip file if the touch screen software/driver CD is missing or not available.

eGalaxTouch Touch Software/Driver - Zip File

Installing USB Touch Screen Monitor Driver on Windows 8 Privacy & Security console PC

  1. Disable white listing if necessary. Windows 8e systems with Privacy & Security will require this step.
    1. Open a command prompt window.
    2. Enter "sadmin disable" and enter the password "Access2Admin" when prompted.
    3. Reboot the console PC.
  2. After the PC reboots, confirm white listing is disabled.
    1. Open command prompt window.
    2. Enter "sadmin status".
    3. Confirm the McAfee Solidifier status is "Disabled".

  3. Insert the touch screen driver CD into the CD rom drive and open or view the driver CD contents.
    1. If driver CD automatically shows on the upper right corner, click on the driver CD and select Open folder to view files using File Explorer to view the CD files.

    2. If driver CD is not automatically open, navigate to Computer and double click on D: drive( (D:) DTx# 19864 ) to open the CD files.
    3. Copy the Touch Driver folder from the CD into the C:\directory on the PC.
  4. Install the eGalaxTouch Touch Driver.
    1. Open the Touch Driver folder.

    2. Double click on the Setup.exe file to launch the installation.

    3. Click Next on the eGalaxTouch box to continue the installing process.

    4. Select I accept the terms of the license agreement and click Next.

    5. Uncheck Install PS/2 interface driver and click Next.

    6. Uncheck Install RS232 interface driver and click Next.

    7. Select None and click Next.

    8. Click OK to install the USB touch device.
      Note: If eGalaxTouch application does not appear, then verify the USB is connected to the monitor and Console PC.

    9. Uncheck Support Multi-Monitor System and click Next.

    10. Click Next on Choose Destination Location box.

    11. Click Next on Select Program Folder box.

    12. Check Create a eGalaxTouch Utility shortcut on desktop and click Next.

    13. Check Create a eGalaxTouch Utility shortcut to the Start Menu and click Next.

    14. When installing USB driver is complete and click Yes on Would you do 4 point calibration now? question.

    15. Touch and release the targets to perform a 4 point calibration on all four screen corners. Refer to Peripherals: Calibrating Touch Screen Monitor (DxI and Access2) procedure.
      Note: If touching the screen generates beeping sound, refer to Peripherals: Calibrating Touch Screen Monitor (DxI and Access2) procedure to disable the sound.

    16. Close the Window Explorer or File Explorer box.
  5. Add the eGalaxTouch Touch Driver to the white list.
    1. Open command prompt window.
    2. Enter the following command "sadmin updaters add eGalaxTouch.exe" and enter the password "Access2Admin" when prompted.
  6. Solidify the white list:
    1. In the command prompt window, enter "sadmin so" and enter the password "Access2Admin" when prompted.
    2. The solidify process may take up to 15 - 20 minutes.
  7. Enable white listing after solidification is complete.
    1. In the command prompt window, enter "sadmin enable" and enter the password "Access2Admin" when prompted.
    2. Reboot the computer.
  8. Verify white listing is enabled after the reboot completes.
    1. Open a command prompt window.
    2. Enter "sadmin status" and verify the McAfee Solidifier status is "Enabled".

    3. Close the command prompt window.
  9. Verify touch screen functions as expected.
    Note: There may be a transparent + icon on the display after running the eGalax program or calibration. It can be removed by exiting the eGalax program found in the hidden applications icon list at the bottom right corner of the display by the clock.

Installing USB Touch Screen Monitor Driver on Windows XP and Windows 8 Non-Privacy & Security console PCs

  1. Insert the touch screen driver CD into the CD rom drive and open or view the driver CD contents.

    For Windows XP Console PC
    1. If driver CD is automatically open, select Open folder to view files using Windows Explorer to view the CD files.

    2. If driver CD is not automatically open, navigate to My Computer and double click on D: drive( DTx# 19864 (D:) ) to open the CD files.

      For Windows 8 Console PC

    3. If driver CD automatically shows on the upper right corner, click on the driver CD and select Open folder to view files using File Explorer to view the CD files.

    4. If driver CD is not automatically open, navigate to Computer and double click on D: drive( (D:) DTx# 19864 ) to open the CD files.
    5. Copy the Touch Driver folder from the CD into the C:\directory on the PC.
  2. Install the eGalaxTouch Touch Driver.
    1. Open the Touch Driver folder.

    2. Double click on the Setup.exe file to launch the installation.

    3. Click Next on the eGalaxTouch box to continue the installing process.

    4. Select I accept the terms of the license agreement and click Next.

    5. Uncheck Install PS/2 interface driver and click Next.

    6. Uncheck Install RS232 interface driver and click Next.

    7. Select None and click Next.

    8. Click OK to install the USB touch device.
      Note: If eGalaxTouch application does not appear, then verify the USB is connected to the monitor and Console PC.

    9. Uncheck Support Multi-Monitor System and click Next.

    10. Click Next on Choose Destination Location box.

    11. Click Next on Select Program Folder box.

    12. Check Create a eGalaxTouch Utility shortcut on desktop and click Next.

    13. Check Create a eGalaxTouch Utility shortcut to the Start Menu and click Next.

    14. When installing USB driver is complete and click Yes on Would you do 4 point calibration now? question.

    15. Touch and release the targets to perform a 4 point calibration on all four screen corners. Refer to Peripherals: Calibrating Touch Screen Monitor (DxI and Access2) procedure.
      Note: If touching the screen generates beeping sound, refer to Peripherals: Calibrating Touch Screen Monitor (DxI and Access2) procedure to disable the sound.

    16. Close the Window Explorer or File Explorer box.
  3. Verify the touch screen functions as expected.
    Note: There may be a transparent + icon on the display after running the eGalax program or calibration. It can be removed by exiting the eGalax program found in the hidden applications icon list at the bottom right corner of the display by the clock.
