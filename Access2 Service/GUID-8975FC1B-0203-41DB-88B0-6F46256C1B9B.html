Installing Analytical Module

This procedure describes how to install the analytical module.

Use this procedure with other documents that provide detailed information on alignments and specific areas of the module. To remove the analytical module, refer to the Removing Analytical Module procedure.

  1. Install the analytical module.
    1. Slide the module into the instrument.
      Note:
      • The module is placed correctly when it locks into the alignment pin and the hold-down screw can be installed.
      • Take care that all cables are free and not pinched while installing the module.
    2. Position the module guide rails onto the alignment pins.
    3. Install the module hold-down screws.
    4. Install the wash arm and the substrate probe.
      Note: Manually move the wash arm fully down and back up to confirm that the aspirate and dispense tubing is not snagging.
    5. Manually move the main pipettor to the RV pipetting location and confirm that the probe centers (in the front to back direction) on the RV in shuttle position 1.
      Note: If the probe is not centered on the RV, then make sure that the analytical module is seated fully into the instrument base. If the probe is not centered on the RV and the module is seated fully, then realign the pipettor gantry tower.
  2. Reconnect the analytical module cables.
    1. Reconnect the analytical module interface PCB connectors.
      Note: The PMT, INC, WW, and RV connectors line up, with PMT being the rearmost connector (PMT is not used).
    2. Connect the ground cable, the ribbon cable (J1), and the power cable (J11) to the analytical interface PCB.
    3. Connect the luminometer, the LED, and the ground cables.
      Note: Match the cable coloring when making the connections.
    4. Reconnect the mixer index sensor to the fluidics interface PCB at J33.
    5. Inspect all cable connections.
  3. Verify analytical module operation.
    1. Install the waste bag and confirm that the ejected RVs are caught.
    2. Power on the instrument.
      Note: Load RVs if necessary.
    3. Initialize the instrument.
    4. Verify the pipettor and wash arm alignments.
    5. Perform an LED read to confirm that the luminometer is functioning.
    6. Verify that the system temperatures are returning to within specification limits.
    7. Prime the instrument and inspect for leaks on these components:
      • Main pipettor
      • Dispense probes
      • Aspirate probes
    8. If no leaks are observed, then install all of the covers.
  4. Verify system operation.
    1. Perform the required system verification.
      Note: Refer to the Verification of Preventive Maintenance document.
    2. Contact your local support organization with any questions or concerns.
