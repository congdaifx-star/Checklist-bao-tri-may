Adjusting Bar Code Reader HD3130

This procedure describes the configuration settings and how to modify the bar code reader to the Beckman Coulter default settings.

Occasionally a handheld bar code reader is shipped with incorrect programming. Use the instructions in this document to modify the bar code reader to the Beckman Coulter default settings.

Note:
  • The PC keyboard [Caps Lock] key inverts the upper and lower case of the scanned characters. With the [Caps Lock] on , the scanned upper case letters are sent to the PC as lower case letters, and the lower case as upper case. This inversion can cause problems when reading bar code labels on tubes that contain case-sensitive information.
  • the characters scanned by the bar code reader can be viewed by opening the Notepad program (Windows > Start > Programs > Accessories > Notepad) and scanning a bar code.
  • If optional bar code reader programming is desired, look up the Produce Reference Guide (PRG), HD3130 which can be found online at Datalogic.com. For internal EDMS users search for HD3130.
Caution: Changing some aspects of the programming can affect the ability of the bar code reader to read other bar codes. Confirm that all accessory products scan correctly ( i.e. substrate, reagents, calibrator cards) after changing the programming for any bar code reader feature.
  1. Scan the bar code in the table to restore the scanner to the Beckman Coulter default configurations.
    Settings Description Bar code
    Beckman Coulter Default Sets the bar code reader to the Beckman Coulter settings for use with the PC console and keyboard.
    Note:
    • If the "Restore Beckman Coulter Configurations" bar code does not restore the scanner to expected operational state, then reprogram scanner through bar code series listed in Appendix of the MSS which can be obtained from Tech Support (Search under "B80418").
    • Scanning the sequence of 11 bar codes listed in the Appendix will set a new default firmware configuration file within the scanner device and over-write the existing resident firmware configuration file.
  2. Verify bar code reader function
    1. Confirm that the bar code reader configuration has been modified correctly by scanning the bar code that previously did not scan correctly.
    2. Verify that all accessory products scan correctly ( i.e substrate, reagents, calibrator cards).
