Perform CCW Index Sensor Check During Troubleshooting

This procedure describes how to perform a CCW index sensor check when troubleshooting incubator belt calibration.

Perform this procedure when instructed to do to so as part of the troubleshooting process for incubator belt calibration.
Note: Refer to the Tshoot: Incubator Belt Calibration procedure.
Perform a CCW index sensor check.
  1. If the failing nominal differences were in the CCW direction, determine if the index sensor is adjustable.
    1. Determine which version of interface PCB and index sensor are installed on the analytical module.
    2. Compare your findings to this chart.
      Analytical Interface PN Compatible Incubator Belt Index Sensor PN Sensor Type
      6618E 973028 Not adjustable
      A60765 973028 or A60636 Adjustable
      Note: No other sensor can be substituted.
  2. If the failing nominal differences were in the CCW direction and the index sensor is NOT adjustable, use the information on the Incubator Belt Calibration Report to determine the next troubleshooting step.
    • If CCW nominal difference for clip #37 is ±3 or less, then swap the home clip location.
    • If CCW nominal difference for clip #37 is ±4 or greater, then replace the index sensor.
  3. If the failing nominal differences were in the CCW direction and the index sensor IS adjustable, adjust the LED intensity of the index sensor using potentiometer RS3 on Interface PN A60765.


    If calibration Then
    Stopped and TP17 is >1.2 volts Adjust RS3 to decrease the TP17 voltage by approximately 0.5 volts and repeat the calibration. Repeat this adjustment if necessary. The voltage may also be returned to the original value and increased by 0.5 volt increments if decreasing the voltage doesn't resolve the calibration.
    Stopped and TP17 is <1.2 volts Adjust RS3 to increase the TP17 voltage by approximately 0.5 volts and repeat the calibration. Repeat this adjustment if necessary. The voltage may also be returned to the original value and decreased by 0.5 volt increments if increasing the voltage doesn't resolve the calibration.
    Passed but nominal differences are ≥4 Adjust RS3 to increase or decrease TP17 voltage by 0.1 to 0.2 volt increments and repeat calibration. If the voltage adjustments do not correct the Nom. Diff., swap the home clip location.
    Note: Increasing the voltage will create a more negative CCW Nom. Diff. while decreasing the voltage will create a more positive one.
    Still fails Replace the incubator index sensor.
