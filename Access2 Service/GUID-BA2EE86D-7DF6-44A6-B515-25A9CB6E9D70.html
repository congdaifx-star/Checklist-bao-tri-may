Swap Home Clip (Auto-Cal Aid)

This procedure describes how to change the home clip position on the incubator belt during incubator belt calibration troubleshooting.

Perform this procedure when instructed to do to so as part of the troubleshooting process for incubator belt calibration.
Note: Refer to the Tshoot: Incubator Belt Calibration procedure.

Change the home clip position to put a different nominal difference into the CW or CCW starting (lead) positions. Changing the nominal difference at the lead position changes the nominal differences at other positions, which could change a failing calibration to a passing calibration.

The Incubator Belt Calibration Tool is an automated spreadsheet that is used to select a new home clip position for the incubator belt.

Belt Clip Locations:

Clip # Location
0 wash chute intersection with the incubator track
35 home clip (with magnet)
36 clip in the index sensor
0 to 59 (all clips) clip numbers increase in clockwise direction


  1. Copy the incubator belt calibration file from the Access PC to your laptop PC using an external USB device.
    Caution: If using an external USB thumb drive to collect data, the external USB memory shared between the Access PC and other systems can introduce a virus. Run a virus scan on the external USB first.
    1. Run a virus scan on any suspect USB device before installing the device in the Console PC. See USB Drive Malware Scan and Removal for more information.
    2. On the Access PC, press the [Windows] key to open Windows Explorer.
    3. Navigate to C:\Nexstep\PC\DRW\Reports.
    4. Select the Incubator belt.csv file, and then right-click and select Copy.
    5. Select the USB drive, and then right-click and select Paste.
    6. Transfer the USB drive to your laptop PC.
  2. Open the calibration aid and select the Calibration tab.
    Note: If a Security Warning is displayed with the message that content or macros are disabled, select Enable Content.

    CalAid.xls

  3. Select Find.csv File, browse to the location of the saved calibration file, and then select the incubator belt.csv file to open it.
    Note: The macro only opens the file when the file is titled incubator belt.csv. If there is an error opening the file, rename the file, and try opening it again.
  4. Review the calibration data transferred to the spreadsheet to determine what conditions would create a passing calibration.
    Note:
    • The report data is separated into CW (yellow columns) and CCW (blue columns) runs.
    • The clips are listed in the order that they enter the index sensor for both the CW and CCW directions.
    • The clip to clip steps (Step Counts) are calculated in both directions. Under normal situations, the step counts are within 200 steps ±2 steps. These values are used to predict the new home position.
    1. Locate the largest CW and CCW nominal differences for each run. To create a passing calibration, determine if these nominal differences must be more positive, negative, or stay the same.
    2. Note the Nom Diff and the Step Count for the lead positions (CW clip #35 and CCW clip #37).
  5. Select the New Run Profile tab.
  6. Review the New Run Profile spreadsheet to determine a new home clip location.
    1. Compare the Step Count for the lead positions (CW clip #35 and CCW clip #37) determined on the Calibration tab to the Step Key.

      If a change is required, consider a new Step Count that has a Nom Diff that is one step greater than the current Nom Diff.

    2. On the Potential Home Clips and Lead Pairs table, find a clip position that will move both the CW and CCW nominal differences in the correct direction.
    3. Select Run a Cal Profile.
    4. Enter the clip number from the Potential Home Clips and Lead Pairs table, and then select OK.
      The spreadsheet simulates changing the home clip position and calculates the Nom Diff from the new home clip position.
      • If the simulated calibration does not result in passing nominal differences, then repeat this step using a different clip number and simulate another calibration.
      • If the simulated calibration results in passing nominal differences, then proceed to the next step.
  7. Physically change the position of the home clip to the new clip position that resulted in the passing simulated calibration.
