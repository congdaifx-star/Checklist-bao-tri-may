Restoring Factory Settings to Individual PC or AU using MFG Cleanup

This procedure describes how to restore factory settings on an individual PC or AU using MFG Cleanup or a manual cleanup procedure.

This procedure describes how to restore individual Access 2 components to the factory settings using the PC or the service boot disk.
Perform these procedures when:
  • PC and AU pair has been separated.
  • client system has been removed from a workgroup and MFG Cleanup was not run before removal.
  • PCs and AUs of unknown origin were not cleaned up before septation.
Note: The cleanup erases all reagent information, all user configuration settings, all calibrations, and all user configured tests such as Dil-Factor.

After Cleanup Notes:

Newer PCs with multiple network ports may have problems when loading software after being cleaned up with MFG Cleanup. The software installation looks for a registry entry called PrimaryConsoleIPAddress to help identify the network port that will be communicating with the analytical unit. MFG cleanup deletes this registry entry. The software installation may then choose a random network port for the server address. Ensure that after loading software the expected port settings exist (Server PC 192.168.2.3) on the primary network port, and that secondary port addresses do not conflict with the primary port. Corrections to the port addresses and the workgroup entries in the registry may be needed. Generally the corrective steps are to 1) Correct the network port addresses, 2) correct the workgroup IP address entries in the registry, and 3) reboot the PC to launch the user interface.
The following procedures are included in this document:
  • Clean up only the PC.
  • Clean up only the AU (through the PC).
  • Manually Clean up only the PC.
  • Manually Clean up only the AU.
  1. Clean up only the PC.
    Warning: Do not use the MFG Cleanup application unless the intention is to scrap the system. Using the NS Utility severely interferes with getting a system back to a Ready state.

    Perform these steps to run MFG Cleanup and delete the database on the PC console, remove registry entries, reset the PC console IP address, reset the AU IP address, erase the instrument alignment file (nvsetup.csv) and the I/O PCB alignments.

    1. Disconnect the network cable from the rear of the PC.
      Note: If the PC is connected to the original AU, then the instrument is cleaned up also.
    2. In the Main Menu, press [Alt] + [F4], and then enter Access2Support to exit the user interface.
    3. Select the Poet Object Server icon next to the clock at the bottom right corner of the display.
    4. Shut down the Poet Object Server application when it opens.
    5. Select Start > Programs > Access2 > NS Utility.
    6. In the NexStep Utilitieswindow, select the MFG Cleanup button.
    7. Select Yes to the Warning dialog box.
    8. Select OK to the error message indicating that communication to the instrument is not available.
      Note: The cleanup takes less than two minutes. Status messages are displayed at the bottom of the NexStep Utilities window.
    9. When the cleanup is complete (no additional messages display), select Exit.
    10. Power off the PC.
      Note: The changes take effect on the next power-up.
  2. Clean up only the AU.
    1. In the Windows desktop, select Start > RunStart.
    2. In the text box type cmd, and then press [Enter].
    3. In the dialog box at the C:\> prompt, type ping 192.168.2.x and press [Enter].
      Note:
      • x= 2, 4, 6, .. the IP address of the AU to connect to.
      • Depending on the previous installation, the address could also end in an odd number.
      • The PC also replies when its address is pinged. Replies from AUs end in 255. Replies from PCs end in 128.
      • Communication is required to proceed with the AU cleanup using the PC.
    4. Verify communication between the PC and the AU.
      • A Reply verifies communication to the AU.
        Note: If the AU is in a networked workgroup, identify the correct AU.
      • If the AU does not reply, then verify the network connections between the PC and AU, reboot the AU, and retry.
    5. In the Windows desktop, select Start > RunStart.
    6. In the text box, type telnet 192.168.2.x, and then press [Enter].
      Note: The (x) is the last number in the IP address of the AU being connected to.
    7. At the connection login prompt, type super user and press [Enter].
      Note: Verify the prompt is now (super)[/hØ/]>.
    8. Type cd /nexstep/scriptutil and press [Enter] to change to the scriptutil directory on the AU hard drive.
      Note: Verify the prompt is now (super)[/hØ/scriptutil/]>.
    9. Type cleanup.sh and press [Enter].
      Note: During this process, file information is displayed and completion is indicated by a return to the (super)[/hØ/scriptutil/]> prompt.
    10. Power down the AU.
      Note: The changes take effect on the next power-up.
  3. Manually clean up only the PC.
    Manually clean up only the PC after a failed initial software installation where MFG Cleanup was not loaded into the PC and additional attempts to load the software have failed.
    1. In the Windows desktop, select Start > Settings > Control Panel.
    2. Select Network > Protocols > Internet Protocol [TCP/IP] > Properties > IP Address.
    3. Change the IP Address of the primary adapter to 192.168.2.1
    4. Select OK to save the changes and close all open windows.
      Note: For Windows NT, the changes take effect after the PC is rebooted.
    5. In the Windows desktop, select Start > Run.
    6. In the text box, type regedit and then press [Enter].
      In the Registry Editor, select HKEY_LOCAL _MACHINE  > SOFTWARE > Beckman  > NexStep.
    7. With the NexStep folder selected, select Edit > Delete to delete the Nexstep folder.
      Note: The NexStep folder contains information that can interfere with subsequent installations.
    8. In the Windows desktop, select Start > Programs > Windows Explorer.
    9. Navigate to the folder C:\Nexstep.
    10. Select the Nexstep folder, and then select Delete to delete the folder.
      Note:
      • The folder is moved to the recycle bin and can be recovered. Renaming the folder is sometimes a better option than deleting it.
      • If the folder cannot be deleted or renamed, then exit the user interface, exit the poet object server (ptserv32.exe) and any other interfering application.
    11. Power down the PC.
      Note: The changes take effect on the next power-up.
  4. Manually clean up only the AU.
    Manually clean up only the AU if there is no PC available for connection or if the IP address of the AU is not known or cannot be identified.
    1. Connect a monitor and keyboard to the instrument.
    2. Insert the Access 2 Service Boot Disk (973142) into the AU floppy drive and power on the AU.
      Note:
      • A message .Reading bootfile... followed by about two lines or periods (.) is displayed. This message is followed by system revision information and then a (0S9_wØ)[/hØ/]> prompt.
      • A keyboard must be present for the Utility disk to boot the AU correctly.
    3. Type cd /nexstep/scriptutil and press [Enter] to change to the scriptutil directory on the AU hard drive.
      Note: Verify the prompt is now (super)[/hØ/scriptutil/]>.
    4. Type cleanup.sh and press [Enter].
      Note: During this process, file information is displayed and completion is indicated by a return to the (super)[/hØ/scriptutil/]> prompt.
    5. Power down the AU.
      Note: The changes take effect on the next power-up. The AU will then reply at IP address 192.168.2.2.
    6. Remove the Service Boot Disk, the monitor, and the keyboard.
