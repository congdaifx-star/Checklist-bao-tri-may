Calibrating Incubator Belt

This procedure describes how to calibrate the incubator belt to allow software to identify the exact location of each vessel holder on the belt.

Locating the vessel holders exactly, helps reduce splashing and vessel jams, and improves detection of motion errors.

Calibrate the incubator belt when:
  • A vessel holder is replaced or moved to a new position on the incubator belt.
  • The incubator belt is removed and reinstalled or replaced with a new belt.
  • Any change is made to the incubator belt mechanical assembly (bearings, pulleys, drive belt, belt guides).
  • Any change is made in the electrical components associated with the incubator belt assembly (Interface PCB, home or index sensors, motor, supply power harness, or I/O ribbon cables).
  • An incubator belt motion failure occurs.
  • An incubator belt alignment changes.
Before calibrating the incubator belt:
  • Make sure the incubator belt is properly tensioned.
  • Make sure the incubator belt index sensor is not cracked, warped, or damaged.
  • If the incubator belt index sensor or the Analytical Module Interface PCB were replaced, then adjust the incubator belt index sensor before calibrating the belt.
Calibration Definitions:
  • CW—The number of motor steps at which the index sensor detects the flag on each vessel holder when moving in the clockwise direction.
  • CCW—The number of motor steps at which the index sensor detects the flag on each vessel holder when moving in the counter-clockwise direction.
  • Nom Diff—The difference between the actual and the theoretical flag location.
  • Vessel holder number— The vessel holder number increases in the clockwise direction (0 to 59).
    • Number 0 = Vessel holder at the shuttle transfer position, when the belt is in the home position.
    • Number 1 = First vessel holder clockwise from the shuttle position, when the belt is in the home position.
    • Number 11 = Vessel holder at the front right pulley, when the belt is in the home position.
    • Number 35 = Home vessel holder.
    • Number 36 = Vessel holder at the index sensor position, when the belt is in the home position.
  1. Run the incubator belt calibration.
    1. Diagnostics > Device Diagnostics > Calibrate Incubator Belt > Start
    2. Select the Print Report at End of Calibration option.
  2. Check the Event Log for the incubator belt calibration status and review the calibration report if available.

  3. Review the incubator belt calibration report to determine if the calibration meets best practice requirements.
    Note: The software calibration status is acceptable when the largest nominal difference is 4 steps or less. However, best practices incubator belt calibration requirements are ±3 steps.
    1. Note any CW nominal differences (yellow columns) that are greater than ±3.
    2. Note any CCW nominal differences (blue columns) that are greater than ±3.
    3. Compare the nominal difference findings against the following guidelines.


      Nominal Differences Calibration Status Recommendation
      All within ±2 Meets best practices Calibration is complete.
      1. File calibration report.
      2. Proceed to Verify system operation step.
      None greater than ±3 Passes Acceptable calibration.

      Run the calibration two more times to ensure that the Nom Diff does not shift to 4 or greater.

      ±4 or greater Not acceptable Troubleshoot. Refer to the Tshoot: Incubator Belt Calibration procedure.
  4. Verify system operation.
    1. Perform the required system verification.
      Note: Refer to the Verification of Preventive Maintenance document.
    2. Contact your local support organization with any questions or concerns.
