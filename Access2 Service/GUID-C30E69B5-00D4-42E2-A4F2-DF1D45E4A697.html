Troubleshooting Console PC Lockup

Purpose

This document provides information to help troubleshoot console PC lockup issues.

Failure Modes

Error Details Take this troubleshooting action
Handheld Bar Code Reader
  • The system locks up when the handheld bar code reader is used.
  • Identifying the Bar Code Reader
  • Scan Rate Reduction
  • If this failure occurred before and the scan rate was reduced, file a CF.
System Lockup When Idle
  • The system locks up when not in use.
  • Troubleshoot Console PC Lockup
  • Identifying the Bar Code Reader
  • Scan Rate Reduction
  • If this failure occurred before and the scan rate was reduced, file a CF.
Troubleshooting action Steps
Identify the bar code reader Determine if the handheld bar code reader came from the vendor pre-programmed with scan rate reduction.
  1. Locate the revision number on the vendor sticker on the handheld bar code reader.
    Note: This sticker is located on the bottom of the bar code reader.
  2. If the revision number is less than nine, then continue to Scan Rate Reduction.
Troubleshoot console PC Lockup
  1. Verify that there are no loose cables on the back of the PC.
  2. FOR DxI INSTRUMENTS ONLY: Delete files from the hard drive.
    Note: Refer to the Software: Deleting Files When Hard Drive Is Full procedure.
  3. Reorganize the database.
    Note: Refer to the Software: Reorganizing Database procedure.
  4. Perform a Database Consistency Check.
    Note: Refer to the Software: Performing Database Consistency Check procedure.
Scan Rate Reduction Reduce the scan rate of the handheld bar code reader.
Caution: The scan rate reduction is validated for use only on the handheld bar code reader used on the console PC to scan in calibrator cards. Do not use scan rate reduction on the handheld bar code reader used to scan in the substrate lot numbers.
Note:
  • If this procedure has been performed on the instrument before, file a type 2 CF. Record the serial number of the handheld bar code reader, and return the bar code reader for investigation.
  • If this procedure has not been performed on the instrument before, continue with the procedure.
  1. Scan the bar code label using the handheld bar code reader connected to the console PC.
    Note: You need to perform this procedure only once on the system. The following document can be printed and used to reduce the scan rate. Scan Rate Reduction Access.pdf
  2. Verify that the handheld bar code reader beeped (long beep or double beep - two distinctive tones).
    Note: If this procedure was performed before, then the beep is a short beep.
Correctly logging this change Verify that the scan rate reduction is logged in Oracle correctly.
  1. Enter the phrase BC Scan Rate to log in Oracle that the handheld bar code reader scan rate reduction was performed.
  2. Log the size of the database in Oracle.
  3. Ask the customer these questions and log the answers in Oracle:
    1. What was the customer doing before the PC console lockup?
    2. What is the frequency of the console PC lockup?
    3. How has it been resolved in the past?
    4. What screen was the user interface in when it locked up (example Main Menu, Sample Manager)?
    5. Was the keyboard or bar code reader being used when the console PC locked up?
    6. When did the customer start to see the console PC lockup (since installation)?
  4. If this procedure was performed on the instrument before, file a type 2 CF. Record the serial number of the handheld bar code reader and return the bar code reader for investigation.
