Troubleshooting Okidata Printer

Purpose

This document provides general troubleshooting information for the Okidata B4300, B4350, and B4600 LaserJet printers.

Troubleshooting

Issue Cause Resolution
Printer beeps when page is printed Printer has no internal beeper. Beep is most likely coming from UPS that can be momentarily overloaded when the heating element in the printer cycles on to print a page. Connect printer to a power source other than UPS.
Paper feeds out the back of printer If rear paper guide is extended, paper will exit through the rear of printer. Push rear paper guide fully into printer.
Printer is online but does not print On power-up, printer attempts to contact PC and waits, but PC does not respond.
  • Press online button twice to reset printer.
  • Turn off bidirectional support in printer internal menu.
Printer is online but does not print Many possible causes.
Note: Refer to the Peripherals: Troubleshoot Printing System procedure for more details.
  • Print Menu Map page using printer keypad.
  • Request a test page from Windows NT printer window.
  • Disconnect and reseat printer parallel cable connection to PC.
  • Pull out and reseat paper tray.
  • Cycle the printer power, and then press printer online / offline button twice.
Replace Drum error message Printer page count has reached the expected life of image drum. Reset drum count, if print quality is still acceptable, otherwise replace drum.
Faded areas on printed page Toner is almost empty or drum is worn out Replace toner, possibly replace drum.
PC - Dump of Physical Memory when UI launches (BSOD) Okidata software has been loaded. DxI instruments should use the generic HP LaserJet III printer driver to operate the Okidata printer. Reboot PC. When Windows logo appears, hold down the [Ctrl] key until boot is complete. Delete Okidata printer. Install HP LaserJet printer driver.
Crystal Reports printing errors Many possible causes. Refer to the Peripherals: Troubleshoot Printing System procedure for more details.
Error 120 on LCD display Printer power supply fan issue. Replace printer.

Printing Menu Map

Step Action
1 Press the Menu button until the Info menu option appears in the display.
2 Press the Select button to select the Info menu.
3 Press the Item button until the Print Menu Map option appears.
4 Press the Select button to print the menu map page.
