Performing Ultrasonics Level Sense Test - Wet/Dry

Perform the following prior to performing the level sense test:

  • Pipettor Z and X alignments.
  • Ensure that the appropriate sample container/tray combination is used.
  • Ensure the main pipettor probe is tightened properly.
  • Ensure no pipettor or tubing leaks.
  • QNS failures can also be caused by selection of a tray number that is inappropriate for the sample container used.
  • A broken cover interlock switch or interlock cable may cause intermittent PLL errors. The switch disables ultrasonics.
This procedure describes the Ultrasonic Level Sense (Dry / Wet) Test which is available in the Access User Interface. This procedure is used to verify proper operation of the level sense function and to assist in the troubleshooting of:
  • QNS errors
  • PLL errors
  • False level sense
Note: The Dry / Wet Test may not detect all failures. Some failures only occur at specific fluid levels. Passing this test does not always guarantee that there is not an ultrasonics' issue. The Ultrasonic Transducer, Service Loop, Main Pipettor Probe, or Ultrasonics PCB might need replacement even if the Dry / Wet test passes multiple times.
  1. Place a 2ml sample cup in positions 1 and 2 of a tray with ID 1-99 or 400-499.
    Note: The level sense test can be run with any valid sample container/tray combination.
  2. Fill the cup in position 2 with 500ul of wash buffer. (1/4 full). The sample cup in position 1 should remain empty.
  3. From the Main menu navigate to the Diagnostics - Device Diagnostics - Ultrasonics screen
  4. Verify that sonicator power is "Low", then select "Level Sense Test"
  5. Select the desired test: Dry, Wet, or Dry and Wet.
  6. Enter the number of test repetitions desired (1 to 999).
  7. Select "Print report at end of test" if a hard copy is desired.
    Note: The results are cleared when exiting the level sense test screen.
  8. Select "Load a Rack". Place the sample rack on the sample carousel and select "Done".
  9. Unload the rack when the test has completed
