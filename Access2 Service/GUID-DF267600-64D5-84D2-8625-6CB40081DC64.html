Test IDs And Datalink Codes

Test IDs And Datalink Codes

Use this table to identify the test ID number and Datalink code for each customer assay.

  • To configure Datalink codes refer to the "Configure a Parameter" procedure in the Datalink service manual.
  • This is a link to the Access/Access2/DxI/LXi Chemistry Codes in the Datalink service manual.
  • Example: Enable the new aTnI test in the Access2, load reagents, and calibrate. In the Datalink interface, select Configuration >> Parameter Definition . For "param. co de" and "abbreviation" use aTnI, units use ng/ml, and sample use serum twice [F2] to save. For Environment >> Instrument Codes select the instrument from the list (For LXi the Datalink needs the test code to be configured for 2 instrument entries LXi and LX20H). In instrument setup, for the "aTnI" parameter under instrument code enter A84 [F2] to save . Set Environment >> Priorities to 1 for the new test and then from the main DL2000 screen select Configuration >> Save to save the changes. Configure the new A84 code on the customers LIS.
