Data Security

Purpose

This document provides information on Access 2 database security.

System Description

The Access 2 is an automated random and continuous access immunoassay system that operates as a stand-alone instrument or as a network of up to three clients and a server.

The system includes an analytical unit (AU) that processes immunoassay tests on patient samples, and a console PC that contains the user-interface software and a database with information pertaining to supplies, calibration curves, QC data, test menu, test results, and patient demographics.

The AU and PC of an Access 2 system are connected to each other via TCP/IP over an ethernet connection. Beckman Coulter, Inc. supplies the hardware for this local area network. Beckman Coulter does not support or allow the installation of Access 2 onto a corporate or public network environment.

General Security Features

Security controls include physical isolation, user ID and password requirements for Remote Desktop access, and user interface controls requiring a local operator to grant the Beckman Coulter employees explicit consent to access the system remotely.

Privacy & Security Features

Access 2 systems with Privacy & Security features include the general security features listed above as well as a new encrypted hard disk drive that is mated to the motherboard via an encryption key, application white listing & code signing which prevents the installation of unlisted & unsigned programs, and the Windows Firewall has been configured & enabled to prevent malicious code execution.

Data Types Stored by System

Data stored on the Access 2 PC include supply information, test requests, test results, and patient demographics. Details regarding test result and demographic information that can be stored are explained in the Operators Guide. In summary, the following can be stored: Patent ID, First Name, Last Name, Sex, Birth Date, Doctor Name, Sample ID, Sample Type, Dilution, Test Name, Reference Range, Result, Sample Comment, and Flags. The only demographic / PHI data that is transmitted from the Access during LIS communication are the sample ID and patient ID numbers.

Data Storage Time Interval

The data storage time can be configured, depending on operator preference. If the auto-delete feature is not used, the data is deleted in a first-in first-out method after 50,000 patients or 40,000 QC.

Media Types

Media types include hard disk drive, CD-ROM drive, floppy disk drive, and USB Flash drive.

Interface Capabilities

Beckman Coulter, Inc. allows a LIS connection via serial port that can be enabled or disabled via the Access 2 user interface. Access 2 systems with serial numbers 570000 and higher may be enrolled in PROService.

Network Types

Connection between the instrument AU and PC is via ethernet LAN. Beckman Coulter does not support or allow the installation of Access 2 in a corporate or public network environment.

Modem Type

The modem is an IBM V.90 PCI Data Fax Modem.

Remote Access Network Capability

RAS is not installed on the PC. The only remote access is via pcAnywhere. Access 2 systems with serial numbers 570000 and higher may be enrolled in PROService.

Questions or Concerns

Contact your local support office with any questions or concerns.
