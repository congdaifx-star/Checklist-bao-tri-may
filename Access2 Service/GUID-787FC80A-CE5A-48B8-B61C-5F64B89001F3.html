Restoring Factory Settings to Access 2 System Using MFG Cleanup

This procedure describes how to use the NS Utility to restore factory settings on an Access 2 system.

Using the MFG Cleanup (Manufacturing Cleanup) when troubleshooting installed systems only creates more problems and deletes most recovery options.
Note: Refer to the Restoring Factory Settings (MFG Cleanup) to Individual PC or AU procedure or Database - Clearing Jammed Critical Events (Access 2) procedure.

This procedure provides instructions to restore an Access 2 system to factory settings using MFG Cleanup.

MFG Cleanup:
  • deletes the database from the PC.
  • resets the PC and the AU IP addresses to the factory default settings
  • erases all reagent information
  • erases all user configuration settings
  • erases all calibrations
  • erases all user configured tests such as Dil-Factor
  • deletes all backups that might be used to recover the database.
Newer PCs with multiple network ports may have problems when loading software after being cleaned up with MFG Cleanup. The software installation looks for a registry entry called PrimaryConsoleIPAddress to help identify the network port that will be communicating with the analytical unit. MFG cleanup deletes this registry entry. The software installation may then choose a random network port for the server address. Ensure that after loading software the expected port settings exist (Server PC 192.168.2.3) on the primary network port, and that secondary port addresses do not conflict with the primary port. Corrections to the port addresses and the workgroup entries in the registry may be needed. Generally the corrective steps are to 1) Correct the network port addresses, 2) correct the workgroup IP address entries in the registry, and 3) reboot the PC to launch the user interface.
Perform this procedure when:
  • A workgroup client will be separated into a single system and a backup of the servers database is not available for promoting the client to a server.
  • A server that is already installed/programmed will be incorporated into another workgroup as a client.
  • This procedure can also be performed on a PC separated from its AU. It will display an error message indicating that it cannot connect to an expected IP address (no AU connected). Dismiss that message by selecting OK when the message is presented.
    Note: Refer to the Restoring Factory Settings to Individual PC or AU procedure.
  1. Exit the user interface and the poet object server.
    1. In the Main Menu, press [Alt] + [F4], and then enter Access2Support to exit the user interface.
    2. Select the Poet Object Server icon next to the clock at the bottom right corner of the display.
    3. Shut down the Poet Object Server application when it opens.
  2. Run MFG Cleanup.
    Note: The PC must be able to communicate with the instrument for a successful cleanup.
    1. Select Start > Programs > Access2 > NS Utility.
    2. In the NexStep Utilitieswindow, select the MFG Cleanup button.
    3. Select Yes to the Warning dialog box.
    4. Select OK to the error message indicating that communication to the instrument is not available.
      Note: The cleanup takes less than two minutes. Status messages are displayed at the bottom of the NexStep Utilities window.
    5. When the cleanup is complete (no additional messages display), select Exit.
      Note:
      • The changes take effect when the systems are rebooted.
      • If not restoring from immediate backup, then discard all punctured reagents. The reagent pack contents data has been erased.
  3. Select Start > Shut down > Shut down, and then power off the PC when prompted.
  4. Power off the analytical unit.
