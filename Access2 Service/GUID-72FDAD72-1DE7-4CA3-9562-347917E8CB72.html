Using Task Manager

This procedure describes how to check the Task Manager for processes currently running on the server PC. Typically, this would not be used as a stand alone document but as a reference document for other support procedures.

Use this procedure to end specific processes if a "sharing violation" message is displayed when attempting to make a local copy of the database or if a "?POET?" message is displayed when attempting to perform a database maintenance procedure (reindex or reorganize).

Use Task Manager to view and end specific processes.

For Windows 8:

  1. Press [Alt] + [F4], and then enter the password Access2Support to exit the user interface.
  2. Press Ctrl + Alt + Delete keys together and select Task Manager or press Windows key, type Task Manager and open the program.
  3. From the Task Manager window, select the Processes tab.
  4. Determine if any of these processes are running in the Task Manager.
    • NexGenUI MFC Application or NexStepUI MFC Application
    • AUCommunicator DLL
    • DbMaintenance DLL
    • InstrumentModel Module
    • LISService MFC Application
    • PostOffice DLL
    • Reduce MFC Application
    • Screen TransitionTool MFC Application
  5. For each process that is running, select the process, and then select End Task.
  6. Close the Task Manager window.

For Windows XP:

  1. Press [Alt] + [F4], and then enter the password Access2Support to exit the user interface.
  2. Select Start > Run, type taskmgr in the Run dialog box, and then select OK.
  3. From the Task Manager window, select the Processes tab.
  4. Determine if any of these processes are running in the Task Manager.
    • DbMaintenanceUD
    • AUCOMM~.EXE
    • INSTRU~.EXE
    • LISServiceUD.exe
    • NexGenUIUD.exe or NexStepUIUD.exe
    • ReduceUD.exe
    • NSWGSVUD.exe
    • POSTOF~.EXE
  5. For each process that is running, select the process, and then select End Process > Yes.
  6. Close the Task Manager window.
