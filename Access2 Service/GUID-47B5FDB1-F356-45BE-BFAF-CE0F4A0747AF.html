Demoting Server (PC/AU) Workgroup

This procedure describes how to demote a server workgroup (PC/AU) for installation in another workgroup as a client.

Perform this procedure when a server workgroup must be demoted for connection to another workgroup as a client. This procedure might be done when a server is moved into an area with an existing server workgroup and the customer wants a single connection to the Datalink/LIS.
  1. Clean up the server workgroup that is being demoted.
    1. Unload all reagents from the instrument that will be demoted.
    2. Discard any reagents that are punctured.
      Caution: Punctured reagents must be discarded because the system will not remember the status of the reagents.
    3. Perform an MFG Cleanup on the workgroup (server PC and instrument) that is being demoted.
      Note: Refer to the Restoring Factory Settings (MFG Cleanup) to Individual PC or AU procedure.
    4. Confirm that the cleaned-up PC replies to a ping at 192.168.2.1 and its instrument replies to a ping at 192.168.2.2 following the MFG cleanup.
    5. Connect the cleaned-up PC and its instrument to the workgroup where the PC will be installed as a client.
    6. Confirm communication by pinging the server PC at 192.168.2.3, the cleaned-up PC at 192.168.2.1, and the cleaned-up instrument at 192.168.2.2.
    7. Load software onto the cleaned-up PC and instrument.
      Note:
      • Use the same process as is used for new installations.
      • The PC and instrument will be installed as a client in the workgroup of the existing server.
    8. Configure the client PC and instrument.
      • Setup printer
      • Setup LIS
      • Enable tests
      • Configure QC
      • Configure calibrators
      • Load supplies
  2. Verify installation of the client into the workgroup.
    1. Calibrate assays and run QC (passing) on the client instrument.
    2. Confirm LIS upload and download for patient samples.
    3. Confirm printer function.
