Troubleshooting Assay - DilTest

This procedure provides instructions for performng the DilTest procedure, specifically testing the hardware that affects high dilution assays. These include:

  • Dil-hCG2
  • AFP
  • Cortisol
  • Myoglobin
  • Many of the Infectious Disease assays
  • Many of the Blood Virus assays.
Note: These assays perform serial dilutions of sample using a second RV.

Perform this procedure when high dilution assays are problematic or to test the system's serial dilution functionality (precision pump, etc.). The DilTest procedure uses the DilTest (932) and LumiAP (907) service assays to verify the dilution function on the instrument.

  1. Perform these steps to prepare a 1:201 dilution of System Check solution which will provide RLU results that are within the system's dynamic range.
    1. Dispense 4.0 mL of Access Wash Buffer into a container.
    2. Pipette 20 ul of System Check into the container with the Wash Buffer.
    3. Mix the contents well.
  2. Perform these steps to run the DilTest procedure on an Access 2.
    1. Place 2 sample cups into a sample rack and fill each with > 2ml of the 1:201 System Check solution.
      Note:
      • Avoid dispensing bubbles or foam in the sample container.
      • Two sample containers are used to prevent a first rep high result issue.
    2. Navigate to the Sample Manager screen.
    3. Enter the rack ID number into the Rack ID field and press [Enter].
    4. For the first sample select Test Request >> More Options >> Request Service Assay.
    5. Enter a sample ID and press OK. (Example: "diltest")
    6. Enter 932 in the Test field of the Test Menu and press "+" 10 times to request 10 reps of test 932 (DilTest) for the first sample.
      Note: If the test menu is not displayed, then select Show Test Menu.
    7. For the second sample select Test Request >> More Options >> Request Service Assay.
    8. Enter a sample ID and press OK. (Example: "LumiAP")
    9. Request 10 reps of test 907 (LumiAP) for the second sample.
    10. Verify that no other tests are in progress, then load the rack and press Run.
      Note: The run takes approximately 30 minutes to complete.
  3. Use this table to calculate the results of the DilTest procedure.
    1. Calculate the mean and CVs for each test, then use the mean result of each test to calculate the Ratio of the results.
      Formula: (Ratio = Mean of LumiAP / Mean of DilTest).
      Use this attachment to assist with calculations -> DilTest.xls .

    2. Review results. Results should be within these ranges:
      • LumiAP mean RLU values from 10M to 20M
      • LumiAP CVs < 2.0
      • DilTest CVs < 4.0
      • DilTest Ratio = 205 to 300
      Note: Typical DilTest means are from 38K to 66K RLU.

Use the Troubleshooting DilTest results procedure for more info
