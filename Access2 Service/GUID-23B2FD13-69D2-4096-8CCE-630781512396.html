Tshoot: System Check

This document shows the details of the System Check process and provides troubleshooting information. The System Check procedure is a diagnostic test comprised of three independently executable tests. The tests evaluate sample pipetting, RV washing, substrate delivery, and RLU measurement.

System Check process

The four System Check sections, Washed, Clean, Substrate and Unwashed, aid in localizing instrument performance issues.

System Check process:

  • The Main Pipettor aspirates fluid from the sample cup and delivers it to the reaction vessel.
  • A wash sequence is performed on the RVs having sample aspirated from the first two cups.
  • Substrate is delivered to each reaction vessel.
  • Any System Check fluid or contamination in the RV reacts with the substrate to produce photons.
  • The photon excitement level is measured by the Luminometer.
  • The luminometer output is presented in terms of relative light units (RLUs).

Areas tested by System Check include:

  • Sample aspiration
  • Sample delivery
  • RV handling
  • RV washing
  • Substrate delivery
  • Luminometer function

Areas not tested by System Check include:

  • Pipetting from reagent packs
  • Ultrasonic particle mixing
  • Magnetic particle pipetting
  • Small volume pipetting
  • Sample Dilutions
  • Sample Incubation

When to perform System Check

Use this table to determine when to perform the System Checks.

Weekly Maintenance: Customers should perform a full System Check each week as part of routine maintenance. Refer to the Operator's Guide for routine maintenance procedures.
Troubleshooting:
  • A full System Check is broadly diagnostic of system and assay performance issues.
  • Individual System Checks are more narrowly diagnostic of issues with individual analyzer functions.
Note: Refer to the Selecting a Diagnostic Test for a list of diagnostic tests and their functions.
Verification: A full System Check is a good diagnostic test to help verify proper system performance following maintenance or repair procedures.

System Check

Use these steps to perform the System Check

  1. Perform a full System Check procedure.
    Note: Refer to the Tests: System Check for details on sample loading and requesting the tests.
  2. Troubleshoot the full System Check, running individual System Check as necessary.
  3. After servicing any assay-critical system components, verify proper performance by performing a full System Check procedure.
  4. Ensure that all System Check specifications pass.

Troubleshooting steps

Use these steps to troubleshoot the System Check results.

  1. Determine which System Check portions have failed specification (see "Specifications" section below).
  2. Determine the common functions of each failed portion (see "Processing Steps and Functions" section below).
  3. All System Checks include the Substrate functions (substrate, substrate delivery, and luminometer), so the Substrate portion should be checked first to verify functionality of these items. In general, System Check troubleshooting focus should be applied in order of decreasing commonality as follows:
    1. Substrate (checks substrate, substrate delivery, and luminometer)
    2. Substrate Ratio and Clean (checks aspiration and Substrate functions)
    3. Unwashed (checks pipetting and Substrate functions)
    4. Washed (checks washing, pipetting, and Substrate functions)
