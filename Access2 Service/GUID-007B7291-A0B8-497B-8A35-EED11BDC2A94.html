Creating and Printing a Manstock Parts List

Enter the prerequisites here (optional).
This document describes how to locate and print the "Manstock" parts list in the Access Service Manual.
Note: The "Manstock" parts list is a suggested group of parts and specialty tools needed for servicing the Access.
  1. Open the Access Service Manual G98 database.
  2. Locate the parts list and select "Active Parts" view.
  3. Search for the word "Manstock".
    Note: MSQ = Manstock Quantity (the recommended quantity to carry to perform Access service).
  4. Caution: If the Print Selected Documents function is used, the complete service manual will be printed.
    Print the results of this search by selecting, 'File', 'Print', then select 'Print View' in the File Print Box. Click 'OK'.
  5. Once the print out is complete, write "Access" and the current date on the first page. Lotus Notes does not place a print date on documents.
