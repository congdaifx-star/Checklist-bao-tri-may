CPU CMOS Settings

Summary

This document provides CPU PCB identification information and detailed CMOS settings for configuring CMOS on the PC PCB.

For instructions on how to enter the hard drive parameters using the CMOS Setup Application, refer to the Configuring CMOS on AU CPU PCB procedure.

CPU Identification

CPU Description
IOWA
  • Occupies only about half of the card cage width and the hard drive ribbon cable connector is blue.
  • Auto-detects the AU Hard Drive settings. Manual CMOS setup is not required normally.


DX4-S
  • Occupies only about half of the card cage width.


DX4-100 B
  • Config B. Advanced CHIPSET Setup screen contains a Memory Remapping field


DX4-100 A
  • Config A: Advanced CHIPSET Setup screen does not contain a Memory Remapping field or a HITMJ Sampling Timing field.


486 DLC
  • CMOS main menu includes a Power Management Setup option.


386 SX
  • Upper left corner has 386 CPU BD printed on the front of the board.

IOWA-8522 CPU PCB CMOS Settings

Note:
  • The IOWA CPU does not normally require any setup. The default settings are listed here for convenience.
  • A red dot has been placed on each graphic to indicate the settings the require change after "Load Defaults" has been selected. Do not select "Load Defaults" unless these entries are corrected afterwards.
Menu Fields, setting formats, or parameters
Main CMOS Setup The console PC will automatically update the Date and Time setting.
Advanced The Hard drive parameters are Auto Detected. No changes should be necessary.
PCI / PNP No changes should be necessary. IRQ 10, 11, and 15 should be set to [Reserved].
Boot No changes should be necessary. Enable SATA ROM should be set to [Disabled].
Security No changes should be necessary.
Chipset No changes should be necessary. Audio and LAN should be set to [Disabled].
Exit
