Replacing Analytical Module Interface PCB

This procedure describes how to replace the analytical module interface PCB.

Replace the analytical module interface PCB when:
  • Replacing the incubator belt index sensor. The new incubator belt index sensor PN A60636 requires the new analytical interface PCB PN A60765 or higher.
  • The RV sensor potentiometers are not adjustable.
  • The PCB is not functioning properly due to damage or corrosion.
Table 43: Part Compatibility
Note: Using incompatible parts can cause incubator belt calibrations to fail.
Incubator Belt Sensor PN Analytical Interface Board PN Compatible?
973028 6618E Yes
973028 A60765 Yes
A60636 6618E No
A60636 A60765 Yes
  1. Replace the analytical module interface PCB.
    1. Power down the instrument and remove the front cover.
    2. Remove all connectors from the analytical module interface PCB, making sure that all connectors are labeled appropriately.
    3. Remove the five screws holding the interface PCB to the analytical module.
    4. Install the new interface PCB using the same screws that were removed when the original board was removed.
    5. Reconnect all the connectors to the replacement interface PCB, including the ground connector.
      Note: Refer to the PCB - Analytical Module Interface document.
    6. Power on the instrument.
  2. Adjust the RV sensors to 1.15 ±0.15 V DC.
    Note: Refer to the Adjusting RV Sensors procedure.
  3. Adjust the incubator belt index sensor.
    Note: Refer to the Adjusting Incubator Belt Index Sensor procedure.
  4. Reinstall all instrument covers.
  5. Verify performance after installing the PCB.
    1. Initialize the system.
    2. Load the RVs so that the RVs fit snugly in the shuttle.
    3. Calibrate the incubator belt.
      Note: Refer to the Calibrating Incubator Belt procedure.
