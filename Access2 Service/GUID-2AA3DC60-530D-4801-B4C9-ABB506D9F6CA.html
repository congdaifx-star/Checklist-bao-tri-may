Obstruction Detection Operating Principles

Theory of Operation

An in-line pressure sensor is placed between the main pipettor and the precision pump. When a sample is aspirated, the force the fluid puts on the sensor is converted to a voltage. This voltage changes during aspiration proportional to the volume being aspirated. A two-point reference curve is set using 5 µL and 125 µL aspirations. All other volumes are referenced from this curve.

When there is an obstruction, the pressure during aspiration is higher than the reference curve and the sample is flagged CLT and logged. If two consecutive aspirations on the same sample are flagged, then the remaining tests are canceled. After five consecutive CLT flags, the system creates a fatal flag, does not start any new tests, and enters the Not Ready mode when the in-progress tests are finished.

If a determine curve routine is run and the curve fails, the sensor is disabled. The sensor remains disabled until a determine curve routine passes.
