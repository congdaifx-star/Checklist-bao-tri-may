PCB - Quad Stepper Motor Controller (QSMC)

Purpose

This document provides pinout information for the backplane connections to the Quad Stepper Motor Controller PCB. Information about the PCB is also included.

Quad Stepper Motor Controller ( QSMC ) PCB

Note: There are no test points or adjustments on this PCB. Troubleshooting is generally limited to reseating the PCB or making sure all socketed chips are firmly mounted.

Communication Errors

A "communication ERR" message is an indication of a problem with the QSMC PCB.

Examples of event log entries for "Communication Errors":
  • "PIP Z Move To Loc Communication ERR"
  • "PIP Z Home Communication ERR"
  • "PIP Z Move To Loc Communication ERR"
  • "Prec PMP to Loc Communication ERR"
  • "Wash Arm Move to Loc Communication ERR"
