Access 2 Software Version 3.4.3 and Access 2i Version 6.2.3 Release Notes

SW version 3.4.3 and 6.2.3 Release Notes.

Intended Use

For Internal Use Only - Sensitive data intended for use within BCI and normally shared with employees. There may be an occasional need to distribute this data outside the company with Management approval.

Software version 3.4.3 and 6.2.3 Feature Details

  • Software versions 3.4.3 (Access 2) and 6.2.3 (Access 2i) are equivalent versions with the only difference being the instrument platform they are available on.
  • Both software versions are capable of running on Windows XPe or Windows 8e operating systems. They are not capable of running on Windows NT.
  • The reagent pack monitoring feature has been updated. The minimum dispense volume monitored has been changed from 25ul to 40ul. It is designed to reduce the number of "false" errors observed.
  • FastObjects replaces the Poet database. All commands in FastObjects are the same as Poet.
  • Resource monitoring availability. New cosole PC diagnostic feature captures all files needed to investigate PC and software performance issues. Select Diagnostics >> Save Data >> Export Logs to capture the files. Files are compressed and saved to the SnapShot folder on the console C: drive.
  • Screen transition logging. Console PC feature that captures files needed to investigate user interface performance issues. Files are automatically captured and transferred to the same folder as the resource monitoring files if all defaults are selected when exporting logs in the resource monitor screen.
  • Improved software installer. Access 2 WIX (Windows Installer XML Toolset) installer. Compatible with Windows XPe or 8e.
  • User interface icons are updated to comply with new BEC branding standards.
  • Display of system software version in user interface screens has been updated for Chinese regulatory compliance.
  • Software startup script has been changed to eliminate the need to disable dual core processing on the console PC. Script sets all software process to run on the same processor core.

Implementation

  • Software versions 3.4.3 (A2) and 6.2.3 (A2i) are currently implemented as field service Mods 11771 and 11788 respectively.
  • The Mods are only released for US government account instruments.
  • The US government instruments must be converted to Windows 8e operating system. All medical instruments at these accounts must be converted from non-supported Microsoft operating systems by February 28, 2017. Windows XPe and NT are no longer supported.
  • No general release of Windows 8e and 3.4.3 or 6.2.3 is planned for existing fielded instruments.
  • When regulatory clearance is received from all geographies, Windows 8e and software version 3.4.3 will be implemented on all new instruments from manufacturing.
  • Access 2i software version 6.2.3 regulatory clearance in China is not being sought. As a result, Windows 8e and software version 6.2.3 will ship with all new A2i instruments in manufacturing starting approximately August 1, 2016. A stop ship on these instruments will be implemented for China and no further A2i instruments will be installed in China.
  • The Windows 8e PC is only capable of USB or Network printing and the Lexmark MS310 driver is the only one on the PC image.
