Advisor - General Info

This document provides procedures and general information for using Advisor.

About Advisor

Advisor is a searchable knowledge base program for Beckman Coulter employees. It contains cases with symptom-based troubleshooting. Cases contain:

  • Organized information.
  • Troubleshooting.
  • Knowledge gained through experience.
  • Links to information in many Lotus Notes Databases:
    • Access Service Manual.
    • Unicel DxI Service Manual.
    • Access Applications Manual.
    • Advisor Repository

Advisor also has feedback capability. User feedback is accepted and cases can be prioritized, updated, and created.

Disconnected and Online Modes

Disconnected mode details:

  • Allows access to the knowledge base without an internet connection by replicating data to the user's computer.
  • For installation instructions, refer to the Advisor - Installing Disconnected Version procedure.
  • Updates to the local copy of the program occurs through synchronization. Technical Support recommends synchronizing once per week
  • Feedback in disconnected mode is sent during synchronization.

Online mode details:

  • Allows access to the knowledge base with an internet connection.
  • Website: http://beckmancoulter.ptcmanaged.com/beckman-advisor.
Help using Advisor Email Advisor.Support@beckman.com
Installation of Advisor Advisor is a web based program and requires no installation unless using the disconnected version. Refer to the Advisor - Installing Disconnected Version document for details.
Obtaining a username To access Advisor:
  1. Complete the Advisor User Training (approximately 30 minutes) available in Knowledge Connection: http://beckmancoulter.intellinex.com/beckmancoulter/lang-default/SYS_login.asp). Search for PROService Advisor User.
  2. Follow the final training slide instructions. Email Advisor.Support@beckman.com with your:
    • Windows network login name.
    • Supervisor name.
    • Business role (example: call center agent or service engineer) and country.
    • E-mail address
Passwords The Disconnected mode password is:
  • Is chosen during the installation of the Disconnected Version.
  • Needs to be reset every 6 months
The Online password:
  • Is selected by the user.
  • May be "kaidara" during the first login.
  • Can be reset by selecting the "Lost your password?" link on the login page (e-mail address must be registered with the account to reset password).
Users Advisor is released for Beckman Coulter employees.

Login - Connected Mode

Perform these steps to login to the online version of Advisor.

  1. Use Internet Explorer to connect to http://beckmancoulter.ptcmanaged.com/beckman-advisor.
  2. Login with your Advisor username and password.
    • Username is the same as the Windows Network username.
    • Password is assigned by an Advisor Administrator.
  3. Select Enter.
  4. Select Access DxI.

Login - Disconnected Mode

Perform these steps to login to the online version of Advisor.

  1. Launch the "start_PTC_SKM.bat" file from the installation package.
    Note: If the disconnected mode has not been installed, then refer to the Advisor - Installing Disconnected Version document.
  2. Login with your Advisor username and disconnected password (set up during install/first sync).
  3. Select Enter.
  4. Select Access DxI.

Log off

Perform these steps to close Advisor.
  1. Close the Advisor browser window.
  2. If using the Disconnected Version, then:
    1. Close the Advisor Offline browser window.
    2. Launch the "stop_PTC_SKM.bat" file from the installation package.

Synchronize

Perform these steps to synchronize the Disconnected Version.

  1. Connect to the Internet.
  2. Launch the "start_PTC_SKM.bat" file from the installation package.
    Note: If the disconnected mode has not been installed, then refer to the Advisor - Installing Disconnected Version document.
  3. In the browser window that launched, click the link for "Go to Advisor online".
  4. Enter your online username and password.
  5. Select the "Synchronize" link in the upper right corner.
  6. Select Synchronize button (provided project updates are available).
  7. Select Home to return to the Advisor homepage.

Free Text Search

Perform these steps to login to the online version of Advisor.
  1. Type the search terms in the Left Side box, "describe your problem."
    Note: Use a module name (example: Sample Pump). Use the event log message if possible.
  2. Select Search.
  3. Continue answering questions on the left side of the screen or select a case from the right side of the screen.

Guided Search

Perform these steps to login to the Disconnected Version of Advisor.

  1. Select the Guided Search Tab at the top of the page.
  2. Answer the questions on the left side of the page. Select Next after each question.
  3. Continue answering questions until a case is identified on the right side of the page.
