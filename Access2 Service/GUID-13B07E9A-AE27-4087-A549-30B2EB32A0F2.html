FYI: System Beeps

This document lists the most common causes of beeps coming from the system.

Beep Causes

The most common causes of beeps coming from the system are:

  • The CPU PCB in the instrument has a problem.
    Note: The CPU emits one long beep at the end of a successful power-on self-test. This beep is normal. If a CPU error occurs, then the CPU PCB can beep a code pattern that indicates the cause of the problem.
  • The UPS is overloaded. Connect only the PC and the monitor to the UPS.
    Note:
    • The heating element in the LaserJet printer draws a lot of current when it cycles on to print a page and can cause a momentary overload of the UPS so that each time the printer prints a page the UPS emits a beep.
    • Connecting the instrument to the UPS overloads the UPS. The UPS beeps when overloaded or when disconnected from the main power .

CPU Beep Codes

Table 68: Beep codes associated with CPU PCB errors
Number and Type of Beeps Description of Problem Recommended Action
1 long POST passed Normal, no error.
1 long, 2 short Video failure Replace the CPU PCB.
1 long, 3 short Video failure Replace the CPU PCB.
1 short DRAM refresh failure Try re-seating the memory chips. If the error still occurs, replace the CPU PCB.
2 short Parity circuit failure Replace the CPU PCB.
3 short Base 64K RAM failure Replace the CPU PCB.
4 short System timer failure Replace the CPU PCB.
5 short Processor failure Replace the CPU PCB.
6 short Keyboard controller / Gate A20 failure Check parts of the system relating to the keyboard, e.g. try another keyboard.
7 short Virtual mode exception error Replace the CPU PCB.
8 short Display memory read/write failure Indicates a memory error on the video adapter. Replace the CPU PCB.
9 short ROM BIOS checksum failure Indicates faulty BIOS chip. Try to enter CMOS setup, then save when exiting.
10 short CMOS shutdown register read/write error Replace the CPU PCB.
