Adjusting Bar Code Reader GD4130

This procedure describes how to adjust the Datalogic Gryphon GD4130 Bar Code Reader to the Beckman Coulter default settings.

Use the instructions in this document to modify the A67742 Datalogic Gryphon GD4130 handheld bar code reader to the Beckman Coulter default settings, or to modify the default programming to meet customer requirements.

Note:
  • Make sure that the bar code reader is connected to the keyboard, not to the mouse.
  • The PC keyboard [caps lock] key inverts the upper and lower case of the scanned characters. With the [caps lock] on, the scanned upper case letters are sent to the PC as lower case letters, and lower case as upper case. This inversion can cause problems when reading bar code labels on tubes that contain case-sensitive information.
  • The characters scanned by the bar code reader can be viewed by opening the Notepad program and scanning a bar code (Windows  > Start > Programs  > Accessories > Notepad).
  • For additional information, refer to the multi-language GD4130 manuals located at the Datalogic website: http://www.adc.datalogic.com/search.aspx?search_key=gd4100&random=54620.9215536443
Caution: Changing some aspects of the programming can affect the ability of the bar code reader to read other bar codes. Confirm that all accessory products scan correctly (substrate, reagents, calibrator cards) after changing the programming for any bar code reader feature.
  1. Scan the bar code in the table to adjust the bar coder reader to the setting.
    Setting Description Bar code
    Beckman Coulter Default for PC Sets the Datalogic Gryphon GD4130 bar code reader to the Beckman Coulter default settings for use with the PC console and keyboard.
    Caution: The "Set IF to US Keyboard" code changes the output format of the reader to Keyboard. Do not use on the DxI instrument substrate bottle handheld bar code reader. That scanner is configured for serial output.
    		A67742 Datalogic BCR.pdf
    Default for Standalone Scanner Scan this bar code to configure the hand held bar code reader for connection to a PS2 keyboard port when no keyboard is connectedto the scanner "Y" cable.
    Note: There will be 2 short beeps, a pause and then 4 short beeps. The bar code scanner will then operate when connected by itself to a PS2 keyboard port. A keyboard connected to the bar code scanner "Y" cable will no longer operate properly. Many keys will be disabled.
    Carriage Return Adds a down arrow or a tab after the successful scan Carriage Return.

    Example:

    With a [carriage return], the cursor jumps into the Patient ID / Lot Number field after a scan.

    With a [carriage return] + [down arrow], the cursor jumps directly to the next sample ID position.

    		CR - Down Arrow.pdf
  2. Verify bar code reader function.
    1. Confirm that the bar code reader configuration has been modified correctly by scanning the bar code that did not scan correctly before.
    2. Verify that all accessory products scan correctly (substrate, reagents, calibrator cards).
