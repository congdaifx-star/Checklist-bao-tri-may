Obstruction Detection Troubleshooting

Summary

Instruments with serial numbers 502020 and above are manufactured with a pressure monitor that can detect an obstruction in the pipettor probe during sample aspiration. The obstruction detection feature is enabled or disabled through the user interface in software version 2.1 and higher. Obstruction detection is available as a sales upgrade for older Access 2 instruments.

Obstruction detection is enabled and disabled and calibrated from the Pressure Monitor screen, by selecting Device Diagnostics > Analog Devices > Pressure Monitor.

Troubleshooting obstruction detection issues

Step Action
1 Calibrate the obstruction detection sensor following:
  • Sensor replacement
  • Pump service
  • Pipettor replacement
  • Tubing replacement
2 If calibration fails, then reseat the cables, inspect tubing connections, prime the pipettor, and attempt to calibrate.
3 If calibration fails, then confirm the voltages on the interface PCB test points.
Note:
  • The test point voltages are labeled on the PCB. Refer to the Drawings - Obstruction Detection Interface PCB document.
  • TP-4 pressure on the interface PCB is approximately 5.18 V DC in standby.
  • The Obstruction Detection PCB, the pressure sensor, and the cables are available to order.

Diagnose obstruction detection events

Code Description Notes
CLT An obstruction was detected. Check the sample for clots. Confirm that the sample container is correct for the rack ID. Re-spin the sample.
22xx14 Abnormal low pressure. Obstruction detected during sample aspiration. Possible clot, gel, or solid.
22xx15 Abnormal high pressure. Obstruction detected during sample dispense. The pipettor might be clogged. A tube might be leaking.
22xx16 Too many consecutive obstructions. The obstruction detection is disabled until the Determine Curve passes.
  1. Prime.
  2. Run special clean.
  3. Run Determine Curve.
  4. Check TP voltages.
