Archive Data File Description (Access 2)

Purpose

This document provides definitions and user instructions for Access Archive Data files. This document contains:
  • Description of the data in the Archive Selected Results file.
  • Description of the data in the Expanded Archive Data file.
  • Description of the data in the Archive Service Data file.
  • List of the result flags that can be included in the archive files.
  • Instructions for using Microsoft Excel to view Archdata files.
The information contained in an Archive file can sometimes be useful when troubleshooting instrument and assay issues.

Types of Archive Data Files

Three types of archive files can be obtained from an Access instrument:
  • Archive Selected Results - Basic test results information.
  • Expanded Archive Data - Detailed test results information.
  • Archive Service Data - Complete instrument information and detailed test results.

This type of archive is performed by selecting specific results to be transferred onto a floppy disc.
Note: The results in this file are sorted according to the criteria selected in the View Test Results screen on the instrument.

Service Archive Data

This archive option copies all of the instrument data files (drw/*.dat, NVSeutp.CSV, event log) to the floppy disc that allows software engineers to examine raw data files.

Note: Service Archive is performed or required rarely. Performing a Service Archive Data requires multiple floppy discs. The number of floppy discs required is unknown by the software at the start of the Archive. After each disc is full, the software asks for another floppy disc.

Results Flags

Test Result Flags are binary fields that indicate something abnormal occurred during a test. More than one flag can be set for any given test. The final test flag value corresponds to the sum of all of the flags set for that test. Test results are suppressed when fatal flags occur.

Example: No Curve (0000008000) + Curve Expired (0000000004) = Flag value (000008004).

Viewing An Arch Data File

Microsoft Excel is used to view Arch Data files. Perform these steps to open and view an archdata file.

  1. Ensure that the floppy disk used to archive the data is formatted for the computer on which you are reviewing the data (i.e., if you are reviewing the data in Excel on a PC, the disk must be formatted for DOS).
  2. To view the data, open Excel and insert the floppy disk.
  3. Select File/Open and choose Drive A.
  4. Select the desired archive file.
  5. When the pop up box labeled Data Type opens, select Delimited > Next.
  6. When the pop up box labeled Delimiter opens, select Tab to remove the X. Select Comma to select comma-separated, then select Next.
  7. Ensure that General is selected, and then select Finish.
Note: When the Expanded Archive Data option is used, some of the columns are in scientific notation. These columns contain dates, lot numbers, or data and must be reformatted to be readable. To view the data, highlight or select the column. Select Format/Number. Choose 0 to 2 decimal places or a date format depending on the data contained in the column.
Note: Many of the entries are too long for the space provided and display as ### until the columns are widened to accommodate the entry.
