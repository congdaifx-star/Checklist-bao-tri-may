Tshoot: Sample/Reagent Carousel

Use this table for troubleshooting the hardware items in the Sample/Reagent Carousel module.

Part

Failure

Bar Code Reader

  • Serial cable not connected to CPU PCB.
  • Defective CPU PCB.
  • Bar Code reader improperly aligned.
  • Label type not supported on specific version of software.
  • Improper sample carousel alignment.
  • Defective bar code reader (rare).
  • Bar Code reader mounting bracket is bent or deformed.
  • Won't initialize - CPU defective or CMOS Setups incorrect

Cup/Tube Reader

  • Adjustments incorrect.
  • Sensor dirty.
  • Defective Cup/tube reader PCB.

Reagent Carousel Errors/ Failures

Reagent Pack

  • Loose elastomer seal on reagent pack.
  • Pack not fully seated in carousel.
  • Elastomer not properly slit for probe entry.
  • Reagent carousel and pipettor not properly aligned.

Motion Errors

  • Ice forming due to failing temperature thermistor.
  • Flag on the drive pulley hitting the home sensor, height not centered when transtorque nut tightened.
  • Bad shaft bearing.
  • Ribbon cable, Reagent Carousel to Fluidics interface PCB or, Fluidics interface PCB to Backplane defective.
  • Aspirate alignment > 12 steps (from 0).
  • Transtorque nut loose or belt slipping on drive pulley.

Sample Carousel Errors/ Failures

  • Alignment values > 7 steps from 0.
  • Drive wheel slips on sample carousel (flat spot).
  • Sample rack not fully positioned on sample carousel before starting test.
  • Sample carousel (Rack or barrier between racks) snagging on tubing, wiring, or tube detector PCB connector.
  • Large screw securing sample carousel drive motor assembly is loose.
  • Metal weight in a rack bottom is falling out.
  • Ribbon cable, Reagent Carousel to Fluidics interface PCB or, from Fluidics interface PCB to Backplane defective.
  • 16mm tray interference with the Cup /tube detector PCB.
  • Motion error message (Cap=0, Exp=82, maxErr = 61). An alignment has positioned the index sensor at the edge of a flag slot and it toggles on/off while the carousel is stationary. Move the index sensor position away from the home sensor. 2 small screws are accessed through index slots in the carousel.
