Troubleshooting RV Waste Sensor

Summary

This document provides instructions for troubleshooting the RV waste bag sensor and bypassing it if necessary while waiting for replacement parts.

Failure Symptoms

Use this table to confirm waste bag failure symptoms.

Note:
  • The sensor includes an LED and an optical transistor. The LED shines on the waste bag flange and the transistor senses the reflected light.
  • The sensor status is shown in the digital devices window of the user interface.
Symptom Check
The message RV ejected with no waste bag present is generated each time an RV is ejected into the waste chute while the waste bag sensor does not detect a waste bag present.
  • Waste bag not present.
  • Waste bag flange not engaged in the waste chute.
  • Sensor obstructed.
  • Sensor or sensor wires corroded or broken.
  • Sensor not connected.

Troubleshooting

Action Item Steps
1 Inspect the sensor
  1. Remove the instrument front top cover that contains the waste bag and inspect the waste sensor for debris.
    Note: Dried buffer can obstruct the face of the sensor.
  2. If the sensor has debris covering its face, then clean with a dry brush.
  3. Inspect the sensor and sensor wires for corrosion.
  4. If the sensor has broken or corroded wires, then remove and replace the sensor.
2 Measure the sensor function.
  1. Remove the instrument front top cover that contains the waste bag and identify the waste sensor connector J22 on the Analytic Module Interface PCB.
  2. Remove the cover from the top of the waste bag sensor connector so that the pins can be probed.
  3. Measure the voltages on connector J22 to confirm the status of the sensor. Measure TP3 ground to:
    • TP13: 0V = Waste bag present

      4.8 V = Not present

    • J22 Pin1: 4.2 V = Waste bag present,

      0 V = Not present

    • J22 Pin2: 5 V = Power supply OK
    • J22 Pin3: 3.6 V = Sensor LED OK
    • J22 Pin4: 5 V = Power supply OK
    Note:
    • Keep the sensor connector connected to the interface PCB connector when making the measurements.
    • Voltages are approximate, ±10% is acceptable.
  4. If the sensor is defective, replace or bypass the sensor until a replacement can be installed.
    Note: To bypass the sensor, disconnect the sensor connector from J22 and jumper J22 Pin1 to Pin2.
3 Replace the waste bag sensor.
  1. Remove the two Allen screws holding the sensor to the bottom of the waste chute.
    Note: The sensor can be removed without removing the analytical module.
  2. Disconnect the sensor from the adjacent connector.
  3. Connect the new sensor to the connector and then mount the sensor to the waste chute.

  4. Fasten the sensor and bracket to the rear sensor mounting hole.
4 Verify the sensor function.
  1. Reassemble the instrument and power on the system.
  2. After initialization, proceed to the Digital Devices screen in Diagnostics, and observe the sensor status readings with and without the RV waste bag in place.
