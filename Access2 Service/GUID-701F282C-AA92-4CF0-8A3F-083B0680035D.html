Keyboard Connector Pinouts

Purpose

This document provides information regarding the keyboard connector on the Access instrument.

Keyboard Circuit

The keyboard connects to the keyboard connector on the right side of the instrument. The keyboard connector is part of the backplane PCB. The keyboard signals go from the keyboard connector J14 to J15 on the backplane PCB and then through the keyboard / reset harness into the CPU PCB.
  • If the keyboard is not functioning correctly, then connect the keyboard directly to the instrument without use of the bar code reader cable.
  • If the keyboard still is not functioning correctly, then try another keyboard if available.
  • If the keyboard is still not functioning correctly, then check the resistance values to those shown in the table.
  • If any value is incorrect, then check the internal cable harness from the backplane to the CPU PCB.
Note: The latest version of the bar code reader is available only with a PS2 style connector.
