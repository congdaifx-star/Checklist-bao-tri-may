Tshoot: Substrate - Manual Read

Prior to performing this test ensure that:
  • The wash carousel is clean.
  • The Luminometer leaf spring must be clean and properly arched.
  • Substrate volume checks have been performed with acceptable results.
This procedure can be used to bypass instrument substrate dispense functions by manually dispensing substrate into RVs. Reading the substrate RLU values will then verify the Luminometer's ability to read using known volumes of substrate.

Perform this test when:

  • The system check contains a DCF which changes erratically, and the substrate portion of the system check contains CVs which are erratic.
  • Additional confirmation of possible substrate contamination is desired.
  1. Manually pipette substrate
    1. Perform system initialization.
    2. Remove 10 RVs from the RV Shuttle.
    3. Manually pipette 200 ul of substrate into the removed RVs.
    4. Place the manually pipetted RVs back into the RV Shuttle.
  2. Substrate read
    1. Disconnect the substrate valve power lead from the Fluidics PCB so that no substrate will be dispensed by the instrument.
    2. Request the "substrate only" portion of the system check. Refer to Tests: System Check for sample loading and test details.
      Note: Do not request any washed or unwashed tests.
    3. Load a sample tray as instructed by the system check procedure. Empty cup in position 1 [Access], or 9 [Access 2].
    4. Start the test.
  3. Analyzing results
    1. Print the test results.
    2. Determine if the results have good CVs and that they are in the acceptable range of 5000 to 9000 RLUs.
    3. If the results have good CVs and are within specification, then the Luminometer can be considered to be functioning properly, however the instrument's ability to dispense substrate properly is questionable and should be tested using Substrate Volume check.
    4. If the results have poor CVs then the Luminometer may be drifting erratically from one LED read to the next ( a read is taken once per wash wheel revolution and the reading is used to calculate the DCF for that revolution).
    5. If the Luminometer appears to be drifting, then verify all Luminometer connections and verify that the Luminometer mounting screws are tight. If the Luminometer connections and mounting screws are secure, then the Luminometer may need replacement.
