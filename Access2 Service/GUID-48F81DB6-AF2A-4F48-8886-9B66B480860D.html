Evaluate Ultrasonic Level Sense Test Results

This document is used to evaluate the level sense results.

Criteria

Use this table for examples of passing results for the Wet and Dry tests. The examples are based on a 2.0 ml sample cup with 20 repetitions.

Table 82: Passing results Dry & Wet
Field Name Result Comments
Dry Failure Count 0 This should always be 0, and it indicates that no false level sense events occurred.
Note: A "Failed on Lower" error will be entered into the event log for each Dry replicate.
Dry Z Step Range 272-272 This should be the same number twice. (Access 2 is 264 steps)
Note: The number of steps is set in the software and depends on the sample container and tray used.
Dry % CV 0.00 This should always be 0.
Wet Failure Count 0 This should always be 0 (No failure to detect liquid).
Wet Z Step Range 152 - 158 The difference between the maximum and minimum should be less than or equal to 9 steps.
Note:
  • The wet Z step count is determined by the sample fluid level detected.
  • The wet Z step will increase during the run by approximately 1 step for every 5 repetitions.
  • The step count logged is actually several steps lower than the surface detection point.
Wet % CV 0.89 CV% greater than 5 indicates a problem.

Use this table for an example of failing a Dry test. The example is based on a 2.0 ml sample cup with 20 repetitions.

Table 83: Dry test failure example
Field Name Result Comments
Dry Failure Count 20 Fluid was detected 20 times in an empty container.
Dry Z Step Range 120 - 209 False fluid detection occurred between 120 and 209 steps.
Dry % CV 14 This value normally varies for failures.

Use these tables for examples of failing Wet tests. The examples are based on a 2.0 ml sample cup with 20 repetitions.

Table 84: Wet test failure example 1
Field Name Result Comments
Wet Failure Count 1 Failed to detect liquid once.
Wet Z Step Range 0 - 171 The 0 indicates at least one PLL failure where probe frequency lock did not occur. If the result is 0 - 0, all tests had the PLL failure.
Wet % CV 55 CV% greater than 5 indicates a problem.

Table 85: Wet test failure example 2
Field Name Result Comments
Wet Failure Count 5 Failed to detect liquid five times.
Wet Z Step Range 121 - 272 If no fluid is detected before the maximum step count is reached (272 for a 2 ml cup), then a QNS error is entered into the event log.
Wet % CV 55 CV% greater than 5 indicates a problem.

Troubleshoot Dry Test

Use this table for a list of possible causes for the failed Dry level sense test shown in the table above.

Possible Cause Action
Main Pipettor Probe may be touching the sample cup. Check alignments.
Loose Main Pipettor Probe. Tighten probe to specification with proper tools.
Loose or damaged Service Loop connections. Repair or replace service loop as necessary.
Intermittent Service Loop open circuit. Inspect the service loop for cracks in insulation or wires.
Transducer failure. Replace the Transducer.
Ultrasonics PCB failure. Check ultrasonics voltage.Adjustment: Ultrasonics Transducer
Failure of PLL to consistently lock. Check ultrasonics voltage.Adjustment: Ultrasonics Transducer
Drip on end of probe. Check for fluid leaks.

Troubleshoot Wet Test

Use this table for a list of possible causes for the failed Wet level sense tests shown in the tables above.

Note:
  • A Wet Z step range of 272-272 (for 2 ml cups) indicates that liquid level was never detected even though PLL locked each time.
  • A wide Z step range (%CV > 5) may indicate a mechanical problem or a false liquid level sense, even if the Wet failure count was 0.
Possible Cause Action
Pipettor home Z alignment and sample Z alignment Check alignments.
Pipettor home alignments not centered in sample cup/tube. (Touches the side of the cup, or a drip on the tube wall, or the necked down portion of a tube.) Check alignments.
Ultrasonic PCB, VCO control adjustment Check ultrasonics voltage .Adjustment: Ultrasonics Transducer
Ultrasonic Transducer Replace transducer.
Open circuit or loose connectors on the service loop cable Inspect the service loop for cracks in insulation or wires.
Misaligned, bent, or defective pipettor probe Check probe and replace if necessary.
