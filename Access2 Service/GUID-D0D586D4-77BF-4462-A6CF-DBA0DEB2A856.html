Access 2 Glossary

A

Access 2— The Access instrument with a new style gantry with a 3-inch pipettor probe. The user interface is separate from the instrument and uses an NT-based PC.

Access2Admin default user password— The user password that is case-sensitive and can be changed by the customer. If this password is changed to Access2Support, it cannot be changed again.

Access2Support— The service password that is case-sensitive and cannot be changed.

Analytical unit— The Access instrument, not including the PC. The analyzer.

Analog line— A standard telephone line. This line is usually a fax or modem line with a four-wire connector.

Assertion error— An unexpected condition occurred in the program execution. The program cannot continue.

AU— Analytical unit.

Auto launch— A program that starts without operator intervention. The software CD starts loading software when the CD is placed in the CD Drive. The user interface starts up automatically when the PC is rebooted.

B

Back tab— The tab located on the right side of most software screens that when used navigates the operator up one level in the program screen structure. Refer to the quick reference guide for software screen hierarchy.

Backup—The process of saving a copy of all volatile databases, that can be used when a system failure occurs.

Backup tape— The Access 2 uses a tape drive to store backup copies of the volatile databases. The backup copies are stored on special cartridge tapes.

Base Access— The original Access instrument without the computer interface.

Black box phone line management system— A phone line management system using a single dedicated analog phone line to handle multiple modem connections.

Boot or boot up— To restart the PC or AU by cycling the power, pressing the reset switch, or using software commands.

Bus contention— Multiple devices trying to access the internal data busses in the PC or AU at the same time.

C

Clear instrument critical messages— The database management function that clears the instrument critical messages file on the AU.

Client— An instrument within a workgroup that is not the server. This PC and AU combination contains software, but no databases. The database is located on the server PC.

Command prompt— The OS9000 'carrot' or 'prompt' that indicates that the operator can input a command (usually a blinking cursor and a backslash).

Connect dialog— A box that opens at the start of a Telnet session when the operator inputs the IP address on the AU that they want to connect to.

Consistency check— Database consistency check.

Console— The PC portion of the Access 2 that includes the PC tower, monitor, keyboard, mouse, and printer.

Console initialization— The successful start of the user interface application on the console PC.

Console IP address— The Internet Protocol address of the PC.

Correct inconsistent records and unload packs/racks logically— A Restore Utility Database Maintenance command that corrects inconsistent data and allows the operator to unload reagent packs and sample racks after a restore.

CMD— Command-line prompt. A Microsoft Windows command that accesses a DOS prompt dialog box.

Critical event failure— An unrecoverable event error indicating a hardware issue or supply shortage on the AU.

Critical messages— A database that tracks critical data on the AU, such as supplies and event log data. The database resides on the AU hard drive.

Crossover cable— The ethernet cable that is used to connect two devices without using a hub between them.

D

Database consistency check— The database test that determines whether objects that must be linked are linked. A sports analogy is a coach checking that all of the fielders have gloves. If they do not, there is an inconsistency. The fielder cannot perform their tasks without a glove. For more information, refer to Database Consistency Check in the service manual.

Database maintenance— One of two types of maintenance performed on the Access 2: Reindex and reorganize.

Date/ Time settings - server only— In a workgroup situation, the date and time can be set only at the server.

Default printer—The printer that the software uses when no other printer is selected.

Derived results— A number calculated from the results of previously or concurrently run tests (constituents) from a single patient. The system reports a derived result as if another test had run. A mathematical formula stored on the system predefines the calculation that is performed. Some formulas are predefined at the factory. The operator can create new formulas on the Derived Results screen.

Desktop— The screen that has icons in a row on the left side and the Access 2 shutdown and restart procedures written in the aqua area.

Drop-down list— Indicated by a gray box with a black arrow in it. When the box is selected, a window opens displaying the list and giving the operator more options to select from.

E

Eject tape— The button on the PC Admin screen that prepares the backup tape for removal from the computer. Selecting this button does not eject the tape physically, but rather rewinds the tape and prepares it for removal by the operator.

Ethernet— A type of networking technology for local area networks.

Ethernet connection— The connection between a device and the local network.

Ethernet drivers— A software routine written to allow the AU or PC to talk over the local network or ethernet.

Events database— A database in POET that records program events.

Exception error— An unexpected condition has occurred in the program execution. The program cannot continue. Knowing the difference between assertions and exceptions is helpful to programmers in identifying the exact location of the problem.

F

Factory settings— For the AU, the hard drive is formatted and imaged for Access 2 but contains no OS9000 software and the IP address is 192.168.2.2. For the PC, the PC has a modified Windows NT operating system, no Access 2 software, and an IP address of 192.168.2.1.

Future server— The PC that will become the new server in the workgroup, when configuring or reconfiguring a network.

G

Global navigation controls— The Back and Menu buttons located on the right side of most screens that the operator uses to navigate one screen backwards or select a new menu option at any time.

Guide chain— The protective plastic housing that controls the bending and location of the service loop.

H

Hub— A central device that connects several computers together or several networks together, like the hub of a wheel.

I

I/O address— Input/Output address. A unique address given to a peripheral device for input and output. On a PC or AU, the I/O address is a three-digit hexadecimal number.

Idle timer expired— An error message that is displayed on the PC indicating that the PC has lost communications with the AU.

Immediate backup— An option on the PC Admin screen that performs a backup of the databases.

Inconsistent database— A database that has lost track of some data or has some data that it does not know where it belongs.

Individual cleanup AU/PC— A procedure in the service manual that instructs the operator how to return the PC or the AU to factory settings. The action wipes out all databases and prepares the system for software reload. Do not use this when updating software.

Install, Instrument— The process of taking the AU and PC from their shipping containers, making all the necessary cable connections, and setting them up for operation.

Install, Software— The process of loading Access 2 Software onto the system. Installing software is very technique-sensitive and must be performed in a certain way. Refer to the service manual for instructions.

Instrument IP— The unique network address given to the AU. This number is assigned automatically when software is loaded. The last digit of this number is an even number (192.168.2.X where x is an even number).

Instrument Mode field— The colored field in the upper left corner that indicates the instrument mode. The four modes are: 1) Blue, instrument in ready mode; 2) Green, instrument running; 3) Yellow, instrument paused; and 4) Red, instrument not ready.

Internal modem— The modem inside the PC in all Access 2 Systems. The internal modem occupies one of the expansion slots in the PC cabinet and Beckman Coulter uses the modem for PC Anywhere remote troubleshooting. The modems are V90 K56 modems.

IP internet protocol— The IP part of TCP/IP. The protocol that is used to route a data packet from its source to its destination over the network.

IP address— The unique internet protocol address assigned to a particular PC or device on the network. For Access 2 systems, the address is 192.168.2.x (where x is the unique number for that AU or PC).

J

K

L

Launch— To start or initialize the Access 2 software.

Local copy of database— This process is used when doing database maintenance and is accomplished in Windows Explorer by copying and pasting of the database file.

login is prompted when using a Telnet session and tells the software who you are and what type of edit privileges you have. The login password is ' super user'.

lpt1— Logical Parallel Terminal 1. The parallel port connection on the back of the PC where the printer is connected.

M

Main Menu— The Access 2 screen that first comes up first when the software is launched. Because of the Global Navigation controls through the software, the Main Menu does not need to be accessed to route the operator to other areas of the software.

Master boot 2 disk one of the four service disks for the Access 2 they have a similar function to the Base Access Utility Disk. For further information, refer to the service manual.

Master install disk one of the four service disks for the Access 2 they have a similar function to the Base Access Utility Disk. For further information, refer to the service manual.

Master network card boot disk one of the four service disks for the Access 2 they have a similar function to the Base Access Utility Disk. For further information, refer to the service manual.

Menu tab— One of the global navigation controls found on the right side of most of the screens. Can be used to access the menu items, making returning to the Main Menu not necessary.

MFG cleanup software command— The command in Windows NT that removes the operating software from the PC and AU and restores the IP addresses to the factory settings after a reboot of both the AU and PC.

MFG exception event log error— refer to Troubleshooting Software in the service manual.

Modem switch box phone line management system— A phone line management system using a single dedicated analog phone line to handle multiple modem connections.

Modify PC specific registry— The command that displays current console IP address, workgroup server IP address, and instrument IP address (the AU connected to the PC that you are sitting at).

Multiple I/O cable— Multi-port communications takes a single connection from the PC and separates it into four numbered communication connections.

N

NAO— North American Operations. Refers to all of North America: The United States, Puerto Rico, and all of Canada.

Network— The connection of the Access 2s together. When two or more Access 2 instruments are connected through a HUB device, one instrument is the server and the others are the clients.

Network printer server— The PC that is connected to its own printer, when the other PCs on the network are not connected to their own printers but share the one printer through the network. When Access 2 systems are networked, all the instrument can share one printer device. Any one or all of the PCs in the network can be connected to a printer.

NIC— Network Interface Card. The device that allows the AU and PC to communicate using the TCP/IP communications protocol.

NT Windows New Technology—A 32-bit operating system from Microsoft for high-end workstations, servers, and networks.

NT backup— A Microsoft Windows program that saves a copy of all the selected files to the device. We use a tape drive device to store the backup copy of the databases.

NT Backup Utility— The program that performs the NT Backup.

NT Event Viewer— Displays the event log kept by the Windows NT Operating System. We look here to determine what PC hardware issues are occurring, including unexpected shutdown of the PC and failures of the tape drive.

O

OS9000— A Microware assembly language operating system used to operate the AU instrument.

OUS— Outside the United States. Roughly means outside of the NAO.

P

Patch cable— A Category 5 cable (four twisted pairs of wires) with an RJ45 connector on either end. All of the wires on a patch cable have the same location on either end of the cable.

PC—Personal Computer. The computer part of the Access 2.

PC Admin— The screen in the Access 2 software where backups, backup tape eject, database maintenance scheduling, and rebooting can be accessed. The screen contains a button for Restore, but this button has no function.

Ping packet internet groper— A program used to test whether a particular network destination is online, by sending an internet control message protocol (ICMP) echo request and waiting for a response.

POET— Poet Database. A database structure program that the Access 2 uses to manage the user interface or what we refer to as the Access 2 software.

Possible unpunctured reagent packs— The statement that refers to the fact that you could use any reagent packs that have not been punctured following a restore routine. Following a Restore routine, all reagent packs that have been punctured by the Access instrument must be removed. We do not level sense the reagent packs ever.

Previous backup— Any backup that took place before now or an immediate backup.

Printer sharing— Multiple instruments in a workgroup using one printer and combining all printouts.

Promote client— Changing which instrument is the server in a workgroup. The original server becomes a client and one of the client instruments becomes the server.

Protocol— A set of rules or a standard, designed so that computers can exchange information with a minimum of errors.

PS/2 to AT keyboard adaptor— An adaptor that converts the smaller 6-pin mini-DIN connector to the Advanced Technology plug.

Q

R

Radio button— The circles with a black dot in the center, where at least two buttons on a screen are used to select or deselect options. Selecting one deselects the others. Only one of the buttons can be selected at any time.

Registry— A central hierarchical database used by Windows NT to store configuration information. The registry has information Windows accesses continually during operations, such as what types of applications are installed and what type of document each can create. It is possible to edit the registry; however, a computer can be disabled if there are any errors after editing the registry.

Reindex— To reassign each item in the database a unique, sequential index number.

Remote diagnostics— To use PC Anywhere to call into the Access 2 PC over an analog phone line to perform system diagnostics and sometimes repairs remotely without the need for an engineer site visit.

Reorganize— To relocate data in the database to make accessing the data quicker and more reliable. When this process is done, the software reindexes all the data.

Restore— To retrieve files from a backup tape and restore them back onto the PC hard drive. We use Windows NT Restore Utility.

Restore information— The dialog box that comes up during a Restore routine. For more information, refer to the service manual.

Restore status— The status dialog box that is displayed while doing a Restore routine. For more information, refer to the service manual.

Restore Utility— A Microsoft Windows NT utility program that we use in the Access 2 product. For more information, refer to the service manual.

RJ45 connector— The industry standard connector used on Category 5 cables including crossover cables and patch cables.

S

Same server restore— To restore databases onto the same PC within a workgroup.

Sample Manager— The Access 2 screen that allows the operator to load and clear racks and to change rack IDs. This screen also allows access to the Work Pending, Test Request, and Maintenance Request screens.

Scroll bar— The bar on the right or bottom of the computer screen that allows the operator to navigate to a new location.

Seagate crystal reports— The print utility used by the Access 2 software to generate and print reports on the printer.

Server— The PC in a workgroup of Access 2 instruments that contains the databases and communicates with the LIS. A stand-alone Access 2 is also considered a server.

Server local hard drive— The hard drive located in the network server PC.

Shutdown— The process that must be followed when turning off the Access 2 PC. The shutdown function is accessed from the PC Admin screen.

Single board computer— The functions of a computer minus the drives are located on one board.

Single system— A single Access 2 not networked with any other Access 2.

Snapshot— The data in an instantaneous moment that is captured when a backup is performed (snapshot of the databases).

Socket connect failed— The messages that are displayed any time the AU is rebooted at the same time or before the PC has booted to Windows NT. This includes rebooting the AU when the PC is powered off. This occurs because the OS9000 network drivers are not installed, if a network is not visible when the AU boots.

System initialization— The instrument has initialized successfully. All devices are homed and all in-progress samples are removed. A completed initialization is recorded in the Event Log as System Initialization. Initialization occurs automatically on power-on or can be requested by the operator.

T

TCP/IP— Transmission Control Protocol (TCP) on top of Internet Protocol (IP). The protocols developed by DARPA to enable communications between different types of computers and computer networks. The Internet Protocol is a connectionless protocol that provides packet routing. TCP is connection-oriented and provides reliable communication and multiplexing.

Telnet— A terminal emulation protocol that lets an operator log in remotely to other computers over an ethernet connection. It has a command-line interface.

Test Request— The screen in the Access 2 software that allows the operator to: Get racks, delete samples, access the test results screen, request QC, request calibrations, clear samples, program tests, and request service assays.

Touch Screen— A PC monitor that has a pointing device mounted to the surface of the screen. The pointing device allows the operator to move the cursor and push software buttons by touching the screen.

U

Uplink— The port on the hub closest to the Uplink switch. The switch and port should be avoided in the Access 2 application. The uplink is used in other applications to link multiple hubs together.

UPS— Uninterruptible Power Supply. Protects the Access 2 software and its PC from interruptions caused by short power outages. If a power outage occurs, devices that are plugged into the UPS remain operational while the batteries in the UPS last. The UPS is sized to keep the computer running for about 15 minutes.

Unexpected shutdown— The error on the Microsoft Windows NT Event Viewer whenever the PC is turned off or reset unexpectedly, without using the correct shutdown commands. These unexpected shutdowns have been known to cause database problems and should be avoided.

Unpunctured packs— Reagent packs that the main pipettor probe has not punctured. Following a restore procedure, all unpunctured packs can remain on the system. The punctured packs may or may not remain, depending on the time the backup occurred.

User interface— The Access 2 software that resides on the PC.

Utility assay— The end of run probe clean procedure. The customer can disable this procedure.

V

VESA— Video Electronics Standards Association. A consortium of video adaptor and monitor manufacturers whose goal is to standardize video protocols. VESA has developed a family of video standards that offer greater resolution and more colors than VGA. These standards are known collectively as Super VGA (SVGA).

W

Windows Explorer— The Microsoft Windows application that allows the operator to access programs and their structures.

Windows key— The key that shows the Microsoft Windows emblem. Two keys with this symbol are on the keyboard; one on either side of the space bar and alt key.

Windows NT logo bitmap— The graphic on the PC display while windows is starting.

Workgroup —The multiple Access instruments that are networked together and share a common database.

Workgroup server— The PC in the workgroup where the database resides. All LIS communications go through the workgroup server PC. Data backup and date and time functions also reside on this PC.

Workgroup server IP— The network address of the server PC 192.168.2.x (where x equals the server number).

Work pending— The Access 2 screen that shows all samples that are programmed and not on-board the instrument. This feature is significant on systems using dynamic downloading via an LIS.

X

X-cable— The longer section of the service loop that accommodates the side to side or x-axis movement of the pipettor.

Y

Y-cable— The shorter of the two sections of the service loop that accommodates the up and down or y-axis movement of the pipettor.

Z

Numbers

3-inch pipettor— The pipette tip used on the Access 2 to enable smaller dead volume requirements on primary and pour off tubes.

550c Driver Hewlett Packard print driver software. The print driver used by the Access 2 software to print screens and reports.

840c Driver Hewlett Packard print driver software. The print driver used by Windows NT and the Access 2 Help Menu for printing projects.
