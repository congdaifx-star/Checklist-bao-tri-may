Adjusting Substrate RLUs

This procedure describes how to adjust the luminometer so Substrate RLUs in the System Check test are centered in the specification (5000 to 9000 RLU).

Do not adjust the system to compensate for high or low substrate RLUs without confirming that the substrate system is OK.

Substrate RLUs are affected by:
  • Contamination. Refer to the Decontaminating Substrate System procedure.
  • Residual fluids in the substrate fluidics immediately following decontamination.
  • Dispensed volume (substrate valve, loose fittings, worn pump belt or seals, damaged probe).
  • Luminometer sensitivity adjustment (LED target value).
  • Substrate storage and handling (contaminated, hot, cold, equilibrated, radioactive).
  • Lot to lot variability in the substrate (refer to QC release values).
  • Temperature.
  • Stray light (dark counts).
Note:
  • Ensure the temperature of the Incubator and the wash carousel are within specification.
  • Assay recalibration is required after performing this procedure.
  1. Prepare for luminometer assembly adjustment.
    1. Print an Alignment Report.
    2. Obtain a printout of the most recent System Check.
  2. Adjust the substrate RLUs.
    1. Select Diagnostics > Device Diagnostics > Luminometer  > Load / Read Vessel.
    2. Load an RV containing 200 µL of substrate as directed. Allow the output to stabilize for 6 minutes.
      Note:
      • Hand pipetting the substrate sample helps rule out contamination and dispense volume issues.
      • Use equilibrated substrate, which must sit unopened at room temperature (15 °C to 30 °C) for 18 hours before use.
      • The normal incubation time between substrate dispense and read is 6 minutes.
    3. Place the cursor in the High Voltage Control window, and then use the up and down arrow keys to adjust the control voltage so that the RLU displayed in the Current RLU window is approximately 1750.
      Note:
      • All instrument covers must be in place and closed so stray light does not affect the reading.
      • A current RLU of 1750 normally produces a system check substrate mean result of 7000 RLU.
      • Result RLU = (4 x (current RLU - dark counts) x the DCF).
      • The HV Control Voltage can be typed into the High Voltage Control window. Use the Arrow key or the [Enter] key to complete the number entry.
    4. Select Cancel and then remove the RV as directed.
    5. Select Save High Voltage Control. At the Save new H. V. Control value warning, Select Yes.
    6. Select Read.
    7. Select Enable LED, then allow the LED output to stabilize so that the Current %CV is less than 0.2%.
    8. Select Cancel.
      Note: Leave the LED enabled so that the Current Mean (approximately 1,000,000 RLUs) is still present.
    9. Select Save LED Reading. At the Save new LED Reading warning, select Yes.
      Note: All customer assays must be recalibrated after saving a new LED Target.
    10. Select Enable LED to power off the LED.
    11. Press the [Esc] key to exit the luminometer diagnostics.
  3. Verify the instrument and luminometer meet specification.
    1. Verify the dark counts with covers closed are <100 RLUs
    2. Perform a System Check procedure to verify luminometer operation, the DCF, and the Substrate Mean RLU.
      Note: If the Substrate Mean RLU is not within specification (5000 to 9000), evaluate the system for substrate contamination. Refer to the Confirming Substrate System Contamination procedure. If the substrate is not contaminated, adjust the substrate RLUs. Refer to the Adjusting Substrate RLUs procedure.
    3. Print a new Alignment Report.
    4. If a new LED value has been saved, recalibrate all customer assays.
    5. Run QC on all customer assays with results within customer limits.
