Adjusting Handheld Bar Code Reader ST2380

This procedure describes how to modify the handheld bar code reader ST2380 to the correct settings.

Occasionally a handheld bar code reader is shipped with incorrect programming. Use the instructions in this document to modify the handheld bar code reader to the correct settings.

For more information, refer to the multi-language manuals for the ST2380 located at the Hand Held Products website hhp.com. Search for ST2380.

Caution: Changing some aspects of the programming can affect the ability of the bar code reader to read other bar codes. Confirm that all accessory products scan correctly (substrate, reagents, calibrator cards) after changing the programming for any bar code reader feature.
  1. Scan the bar codes as instructed in the table to adjust the scanner to the setting.
    Setting and Description Instructions Bar code
    Carriage Return — Enables the automatic carriage return after each successful scan.
    1. Scan the ENTER bar code to begin programming.
    2. Scan the II bar code.
    3. Scan the A bar code.
    4. Scan the 0 (YES) bar code.
    5. Scan the D bar code (the ASCII character code for Enter).
    6. Scan the EXIT bar code to complete programming.


    Beep —Enables the beep tone after each successful scan.
    1. Scan the ENTER bar code to begin programming.
    2. Scan the VIII bar code.
    3. Scan the B bar code.
    4. Scan the 0 (YES) bar code.
    5. Scan the EXIT bar code to complete programming.


    Code 39 Check Digit —Enables or disables the code 39 check digit.
    Note: If the check digit is not enabled and there is a check digit present, then the check digit is sent as an extra letter at the end of the bar code. The check digit must be enabled if it is present, so that the "disable send check digit" function can suppress transmission of the check digit.
    1. Scan the ENTER bar code to begin programming.
    2. Scan the II bar code.
    3. Scan the D bar code.
    4. Scan the 0 (YES) bar code.
    5. Scan the EXIT bar code to complete programming.


  2. Verify bar code reader function.
    1. Confirm that the bar code reader configuration has been modified correctly by scanning the bar code label that did not scan correctly before.
    2. Verify that all accessory products scan correctly (substrate, reagents, calibrator cards).
