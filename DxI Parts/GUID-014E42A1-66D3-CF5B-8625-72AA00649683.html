A41904

A41904

Motor does not come with the pulley. Order pulley (part 126771). Use loctite 222 on set screws of the pulley. Motor has high-flex cable for more reliable wire connections. Replaces 102032.

Properly Attaching the Pulley to the Motor Shaft - How To:

  1. Apply Loctite 222 to the motor pulley set screws and start them into the pulley.
  2. Align the set screws with the two flats at the end of the motor shaft.
  3. Tighten one set screw until it lightly contacts a flat.
  4. Push the pulley toward the motor until the set screw stops at the end of the flat.
  5. Tighten both set screws securely.
