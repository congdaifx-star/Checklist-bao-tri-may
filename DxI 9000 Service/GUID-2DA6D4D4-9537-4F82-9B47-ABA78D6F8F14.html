Performing Sample Presentation Unit (SPU) Camera Diagnostics

This topic includes information about performing sample presentation unit (SPU) camera diagnostics, to determine the camera's ability to detect sample containers as expected.

Note: This diagnostic allows the user to select a sample container type, and then load a rack with containers in each of the seven positions to check if the camera is accurately detecting them. Only use approved container types. See the DxI 9000 Access Immunoassay Analyzer Instructions for Use (IFU) for the list of approved sample container types. Some containers must be Beckman Coulter parts (e.g. 1 mL insert cup, PN 81915).
  1. In the Console App select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  2. Go to MENU > Tools > Diagnostics > Intrusive Diagnostics to open the Intrusive Diagnostics page.
  3. Select Start Session.
  4. Select Sample Handler Camera to open the Sample Handler Camera page.
  5. Select Add Rack, and then select the container type to be tested. Multiple racks may be configured in the same diagnostic.
  6. Prepare the rack(s) with the designated sample containers, ensure there is a container in each of the seven positions of a rack.
    Note: If available, the sample containers may be filled with sample to help identify if this is part of a detection issue.
  7. Select Start Sample Handler Camera Diagnostics.
  8. Open the SPU on-load cover and place the racks in the same order that they were requested on the screen (with the top most rack from the screen in the left most position on the SPU, closest to the presentation tray).
  9. Close the SPU on-load cover, the diagnostic routine should begin.
  10. When the diagnostic has completed, review the results displayed on the right side of the screen.
    • A result of Pass indicates that the camera is properly calibrated and requires no further action.
    • If a result displays as Fail, troubleshoot based on the failure modes identified. See Troubleshooting Sample Container Detection for more information.
