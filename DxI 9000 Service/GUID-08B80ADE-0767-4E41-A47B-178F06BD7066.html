Operating Principles for Process Monitoring Flags and Log Files

This topic includes information about the operating principles, or theory of operation, for the process monitoring system flags and log files.

Process Monitoring Flags

The DxI 9000 instrument uses process monitoring, a combination of software, cameras, and pressure sensors, to identify when pressure, volume, and other readings are out of the operational range. In the event process monitoring identifies a problem, the system will display one of the following flags.

Flag Description
APO Aliquot Pipettor Obstruction (High Pressure) Flag
EWF A1 Wash Fluidics Error (Low Pressure) Flag
EWO A1 Wash Obstruction (High Pressure) Flag
PVDR Precision Pipettor Wrong Volume DV to RV Flag
PVSD Precision Pipettor Wrong Volume SV to RV Flag
PVSR Precision Pipettor Wrong Volume SV to DV Flag
PVSV Precision Pipettor Wrong Vlume Aspirated SV Flag
RPF Reagent Pipettor Fluidics Error (Low Pressure) Flag
RPO Reagent Pipettor Obstruction (High Pressure) Flag
RWF Reagent Wash Tower Fluidics Error (Low Pressure) Flag
RWO Reagent Wash Tower Obstruction (High Pressure) Flag
WDF Wash Wheel Fluidics Error (Low Pressure) Flag
WDO Wash Wheel Obstruction (High Pressure) Flag
WWA Wash Wheel Residual Volume Flag
WWS Wash Wheel Substrate Volume Flag

Log File Names and Locations

During process monitoring, the system generates log files that contain relative data. Depending on the result of an operation (pass or fail), the instrument will save log files in the following two locations.

Result Location
Pass D:\ProgramData\Beckman Coulter\Logs\Falcon Process Monitoring\Pass\
Fail D:\ProgramData\Beckman Coulter\Logs\Falcon Process Monitoring\Fail\

The instrument saves the log files inside ZIP files. The naming convention for the ZIP files is <YEAR><MONTH><DAY>.zip (e.g. 20241126.zip for 26 November 2024).

The instrument saves the individual log files as comma-separated-values (CSV) files. The naming convention for the CSV files is <SampleID>_<Automation ID>_<OperationName>_<YEAR>-<MONTH>-<DAY>-_<HOURS>-<MINUTES>-<SECONDS>-<milliseconds>.csv (e.g. TipCheck_AliquotSamplePipettor.Camera_PostTakeTip_2024-11-26_15-09-10-012.csv) where the <Automation ID> variable is the name of the menu selection in the Machine Control App.
