Troubleshooting Luminometer Calibration Failures

This topic includes information about how to troubleshoot luminometer calibration failures.
Note: For general luminometer troubleshooting steps, see Troubleshooting the Luminometer for more information.
  1. To confirm calibration failure, attempt to calibrate the luminometer. See Calibrating the Luminometer for more information.
    Important: This is a necessary step to ensure the data containing the failure is in the luminometer firmware.
  2. In the Machine Control App go to MENU > Machine Control > Luminometer > Luminometer.Assembly > Luminometer.Device.
  3. On the Action tab select GetCalibrationPoints.
  4. In dataType select PMTHighVoltageRLU.
  5. Select Execute. If the value for points is greater than (>) 10,000,000, MOD 13262 is necessary. After you complete MOD 13262, attempt to calibrate the luminometer.
    Note: If MOD 13262 has already been completed and the luminometer fails to calibrate:
    1. In the Machine Control App go to MENU > Machine Control > Luminometer > Luminometer.Assembly > Luminometer.Device.
    2. On the Action tab select GetCalibrationPoints.
    3. In dataType select every data type, one at a time, and select Execute.
      Important: This is a necessary step to ensure the data is written to the Machine Control log files.
  6. Gather information for escalation. See Gathering Information for Escalating Issues with the Luminometer for more information.
