Checking Dark Count Values

This topic includes information about how to check luminometer dark count values.
Note: Completing the stress test with the instrument covers open might increase dark count errors.

To check dark count values:

  1. In the Console App go to MENU > Tools > Diagnostics > Nonintrusive Diagnostics > Temperature to open the Temperature page.
  2. In the Luminometer row, view the value in the Out of Range column to verify whether the luminometer subsystem temperature is out of the acceptable range.
  3. In the Machine Control App go to MENU > Machine Control > Luminometer and select the Action tab.
  4. On the Action tab select LumiSetLightVoltage.
  5. In the value box type 0 (zero) and select Execute.
  6. Select LumiDiagnosticRead.
  7. In the samples box type 1 and select Execute.
  8. Select the Configuration tab.
  9. On the Configuration tab view the value in the LastDiagnosticRead box. Confirm the value does not exceed 300 RLU.
