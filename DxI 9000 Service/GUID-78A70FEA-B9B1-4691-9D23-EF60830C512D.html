Testing Luminometer Linearity Using Intrusive Diagnostics

This topic includes information about how to test luminometer linearity using intrusive diagnostics.
Note: For more information about how to perform the Luminometer Linearity Automated System Diagnostics (ASD) test, see Performing the Luminometer Linearity ASD Test.
Tip: See Luminometer Diagnostics Overview for more information about luminometer linearity.
Table of Contents

Testing Luminometer Linearity Using Intrusive Diagnostics

When to Perform

You can use intrusive diagnostics to test luminometer linearity as needed during troubleshooting. The luminometer linearity test will require approximately 20 minutes of service time.
Note: If you must test luminometer linearity as required for verification of instrument performance following service activity, see Performing the Luminometer Linearity ASD Test for more information.
Note: You can test luminometer linearity using either intrusive diagnostics or the ASD Tests page, but there are important differences:
  • If the instrument is in a RED (Stopped) status, you can test luminometer linearity using intrusive diagnostics, but you must then access log files to view historical data for tests completed using Intrusive Diagnostics.
  • If the instrument is in a GREEN (Ready) status, you must test luminometer linearity using the ASD Tests Menu to maintain easy access to viewing historical testing data using the Console App.

Testing Luminometer Linearity Using Intrusive Diagnostics

  1. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  2. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  3. Select Luminometer Linearity.
  4. Select Start Lumi Linearity.

  5. Go to Intrusive Diagnostics.

  6. SelectEnd Session.
  7. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
