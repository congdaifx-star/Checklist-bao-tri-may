Configuring for Remisol on Local Ethernet without a Firewall Device

This topic includes information about how to configure a DxI 9000 instrument connected to a DxA to be managed by Remisol on a private subnet.

When to Perform

Perform this procedure when the middleware/LIS managing the instrument is located locally, and a private subnet, separate from the lab network, is used, or when the instrument is connected to these entities using a peer-to-peer method. This also applies to a Command Central server or to a network printer.

Configuring the DxI 9000

Perform the following procedures to configure the DxI 9000:

  • Enabling Automation on the DxI 9000
    Note: This is mandatory for DxI 9000 to DxA communication. If not already connected, perform this first.
  • Configuring the LIS Protocol on the DxI 9000
  • Configuring the IP Address for the Local/LIS Remisol Interface
  • Configuring the Destination Address for the Remisol Dynamic Interface
  • Configuring the IP Address for the Network

If the configuration requires a connection to DxS IntelliServe, and if the customer's IT department requires the MAC address for the eth4 port on the DxI 9000 for whitelisting, see Determining the MAC Address for the eth4 Port for more information.

Connecting the Ethernet Cables to the DxI 9000

If the configuration includes a connection to DxS IntelliServe, connect the Ethernet cable from the lab network to the eth4 port at the rear of the instrument.

Connect the Ethernet cable from the private subnet to the eth1 port at the rear of the instrument.
