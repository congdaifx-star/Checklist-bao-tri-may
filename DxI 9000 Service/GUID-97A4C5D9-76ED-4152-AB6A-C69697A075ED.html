Resetting Drift Targets

This topic includes information about how to reset drift targets for the luminometer.
Note: See Luminometer Diagnostics Overview for more information about drift targets.
Warning:

It is critical to invalidate/expire all active assay calibrations after resetting RLU targets, as the RLU values will change and require re-calibration of all assays.

Wait for the status bar to indicate when the luminometer targets are reset.

  1. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  2. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.

  3. Select Luminometer Linearity to open the Luminometer Linearity page.

  4. Select Reset Drift Targets.

    The notification and question You are about to reset the luminometer targets.This will require a recalibration of all assays. Do you want to continue? will be displayed.

    Warning:

    This action will wipe out assay calibrations.

    Warning:

    This action cannot be undone once it is initiated.

  5. Select Yes.

  6. If no further diagnostics are required, select END SESSION.

  7. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
