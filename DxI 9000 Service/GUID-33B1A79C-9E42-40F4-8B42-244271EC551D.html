Auto-aligning the Tray Gripper

This topic includes information about how to auto-align the tray gripper.

Safety Reminder

Servicing the DxI 9000 instrument involves potential risks for pinch and puncture, electrical shock, and exposure to hazardous materials. You must mitigate these risks by taking appropriate countermeasures. See Safety for more information.

Prerequisites

Before you begin this alignment procedure:
  • If you must make changes to the instrument's hardware, you must complete those changes before you prepare the instrument for adjustments and alignments.
  • You must verify that alignments have previously been completed on the instrument. To verify, in the Machine Control App go to Menu > Prototype Alignment to open the Prototype Alignment page and to verify the Finalize Instrument Alignments button is GRAY in color. If the button is BLUE in color, do not complete this procedure. Instead, you must first complete manual alignments.
  • You must first initialize the instrument to a GREEN (Ready) status to ensure all subsystems have been successfully initialized and homed. You must then enter the instrument into a BLUE (Maintenance) status.

The Tray Gripper Must Be in the Home Position

Before you adjust and align DispoTip Stocker components, the tray gripper must be in the home position. See Homing the Tip Tray Gripper for more information.
Note: The Y and Z axes for the tray gripper are measured in horizontal steps and vertical steps.
  • A horizontal step is a unit of distance understood by the Machine Control App and the instrument hardware and software. The gripper moves up and down along the horizontal (Y) axis approximately 1 cm (0.39 in.) for every 167 horizontal steps.
  • A vertical step is a unit of distance understood by the Machine Control App and the instrument hardware and software. The gripper moves up and down along the vertical Z-axis approximately 1 cm (0.39 in.) for every 148 vertical steps.
The number of trays and tips will influence movement and distance.

Note: The tray gripper must not collide with other components of the DispoTip Stocker or the cabinet. A collision will damage or misalign the tray gripper.

Do Not Continue with Alignments if the Z-axis Offset Is Outside the Limit

During an alignment procedure, if the system notifies you that the Z-axis offset is outside the limit, you must not continue with alignments until you have used the Machine Control App to reset Z-axis values.

Perform the following procedure to reset the Z-axis values for the DispoTip Stocker module.

  1. In the Machine Control App go to Menu > Machine Control > Tray Gripper > TrayGripper.TrayGripperAssembly and select the Action tab.
  2. On the Action page select PreliminaryZTipSupplyReset and select Execute.
  3. Select PreliminaryZTipStockerReset and select Execute.
  4. Select the Configuration tab.
  5. On the Configuration page, confirm that the values are zero (0) for both the PreliminaryZTipSupplyDelta and PreliminaryZTipStockerDelta variables.

Prepare the Instrument for Adjustments and Alignments

You must prepare the instrument for adjustments and alignments.

  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Disable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  3. Open all hoods and covers.
  4. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
    Note: If the instrument enters into a RED (Stopped) status:
    1. Verify the interlock switch is in the correct position.
    2. Be sure you are signed in to use the BeckmanAdmin account.
    3. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
    4. Complete all troubleshooting, adjustments, manual alignments, and maintenance necessary to be able to initialize the instrument to a GREEN (Ready) status.
  5. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.

Auto-aligning the Tray Gripper

Perform this procedure to auto-align the tray gripper.

Important: If layer offset changes have been saved on the Tray Gripper Diagnostics page in the Console App, you must first reset the layer offsets before you auto-align the tray gripper. See Resetting the Tray Gripper Layer Offset for more information.
Note: You must complete the tray gripper auto-alignment procedure twice to ensure proper alignment.

Known Issue (Software 1.20): If the instrument has software version 1.20 installed, before you perform this procedure, you must first remove the tip trays from all locations except the active tray carrier. Otherwise, the auto-alignment feature might confuse the lower tip tray slots with carriage alignment positions.

  1. Close the drawer.
  2. If you have not already started a service diagnostics session, in the Console App go to Menu > Tools > Diagnostics > Service Diagnostics.
  3. Select Start Session to enter the instrument into a BLUE (Maintenance) status.
  4. In the Machine Control App go to Menu > Prototype Alignment > Tip Supply Tray Gripper > Tray Gripper Auto Alignment (MP Instrument Only) to view the tray gripper alignment keys and values.
  5. Select Auto Align. Do this twice to be sure the alignments are saved.
    Note: Observe as the instrument auto-aligns the tray gripper. Verify the gripper arms do not interfere with cables and reroute the cables if necessary.

  6. Initialize the instrument to a GREEN (Ready) status.
  7. Reload the tip supply to maximum capacity via the loader.
  8. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  9. Initialize the instrument to a GREEN (Ready) status. During initialization, observe the stocker. If the stocker fails on alignment positions, repeat the alignment process.
  10. If the tray gripper does not grip trays, update layer offset positions. See Updating the Tray Gripper Layer Offset for more information.

Ending an Adjustments and Alignments Session

  1. In the Console App go to Menu > Tools > Diagnostics > Service Diagnostics.
  2. Select End Session.
  3. Close all hoods and covers.
  4. Enable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  5. Sign out from the BeckmanAdmin account.
  6. Sign in to use the LabUser account.
  7. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.

Verification

Complete the verification of service repair. See Verification of Service Repairs for more information.
