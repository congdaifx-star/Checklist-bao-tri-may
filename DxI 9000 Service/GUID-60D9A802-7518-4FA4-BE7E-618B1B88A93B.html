Aligning the Reagent Loader Tray

This topic includes information about how to adjust and align the reagent loader tray in the reagent storage module (RSM).

Step 1: Complete the Prerequisites for Performing an Alignment Procedure

You must complete the following prerequisites before you begin an alignment procedure:
  • If you must make changes to the instrument's hardware, you must complete those changes before you prepare the instrument for adjustments and alignments.
  • You must verify that alignments have previously been completed on the instrument. To verify, in the Machine Control App go to Menu > Prototype Alignment to open the Prototype Alignment page and to verify the Finalize Instrument Alignments button is GRAY in color. If the button is BLUE in color, do not complete this procedure. Instead, you must first complete manual alignments.
  • You must first initialize the instrument to a GREEN (Ready) status to ensure all subsystems have been successfully initialized and homed. You must then enter the instrument into a BLUE (Maintenance) status.

Step 2: Unload In-Use Reagent Packs

You must unload in-use reagent packs and place them in an external refrigerator prior to opening reagent storage to prevent compromising reagent pack stability.

  1. Start a Service Session prior to opening covers and starting alignments, this should allow the compressor to continue operating as needed when the gripper is toggled open/close.
    1. Navigate to MENU > Tools > Diagnostics > Service Diagnostics.
    2. Pause the system.
    3. Select Start Session. The instrument should enter a BLUE (Maintenance) status.
  2. Open the sample presentation unit (SPU) and remove the reagent storage front cover to gain access to the interior. You may need to bypass the reagent storage cover switch with tape or something similar to allow the movement of devices with covers removed.

Step 3: Prepare the Instrument for Adjustments and Alignments

You must prepare the instrument for adjustments and alignments.

  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Disable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  3. Open all hoods and covers.
  4. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
    Note: If the instrument enters into a RED (Stopped) status:
    1. Verify the interlock switch is in the correct position.
    2. Be sure you are signed in to use the BeckmanAdmin account.
    3. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
    4. Complete all troubleshooting, adjustments, manual alignments, and maintenance necessary to be able to initialize the instrument to a GREEN (Ready) status.
  5. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.

Step 4: Start an Intrusive Diagnostics Session

You must start an intrusive diagnostics session to enter the instrument into a BLUE (Maintenance) status.

In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.

Step 5: Set the Alignment Position for Tray Number 1

Perform this procedure to set the alignment position for tray number 1 in the reagent loader.

  1. In the Machine Control App go to MENU > Prototype Alignment > Reagent Storage > Reagent Loader Tray.

  2. Select Home All.
  3. Type -2450 in the Alignment Value box for the ReagentLoader.TrayBarcodePos1 alignment key.
  4. Select Save All.

Step 6: Capture an Image of the Barcode Alignment for Tray Number 1

Perform this procedure to capture an image of the barcode alignment for tray number 1.

  1. In the Machine Control App go to MENU > Machine Control > ReagentLoader > ReagentLoader.Assembly.

  2. On the Action tab select PositionTrayForScan.
  3. Type 1 in the trayNumber box.
  4. Select Execute.
  5. Go to ReagentLoader > ReagentLoader.Assembly > ReagentLoader.BarcodeReader.

  6. On the Action tab select Read.
  7. Select Execute. The value box should display 1.
    • If the value box displays NR instead of 1, adjust the alignment position for the reagent loader tray. See Adjusting the Position of the Reagent Loader Tray for more information.
  8. Select CaptureImage.
  9. Select Execute. The data box will display the image captured.
  10. The barcode should appear near the lower edge of the image.
    • If the position of the barcode in the image varies from the example, adjust the alignment position for the reagent loader tray. See Adjusting the Position of the Reagent Loader Tray for more information.

Step 7: Home the Reagent Loader Tray

Perform this procedure to home the reagent loader tray.

  1. In the Machine Control App go to MENU > Machine Control > ReagentLoader > ReagentLoader.Assembly.

  2. On the Action tab select HomeTray.
  3. Select Execute. The tray should move to the home position.

Step 8: Load a Reagent Pack into Position 1

Open the load door and place a reagent pack into Position 1 (the left-most position).

Step 9: Capture an Image of the Barcode Alignment for the Reagent Pack

Perform this procedure to capture an image of the barcode alignment for the reagent pack.

  1. In the Machine Control App go to MENU > Machine Control > ReagentLoader > ReagentLoader.Assembly.

  2. On the Action tab select PositionTrayForScan.
  3. Type 1 in the trayNumber box.
  4. Select Execute.
  5. Go to ReagentLoader > ReagentLoader.Assembly > ReagentLoader.BarcodeReader.

  6. On the Action tab select Read.
  7. Select Execute. The value box should display the barcode value for the reagent pack.
    • If the value box displays NR instead of the barcode value for the reagent pack, adjust the alignment position for the reagent loader tray. See Adjusting the Position of the Reagent Loader Tray for more information.
  8. Select CaptureImage.
  9. Select Execute. The data box will display the image captured.
  10. The barcode should appear near the lower edge of the image.
    • If the position of the barcode in the image varies from the example, adjust the alignment position for the reagent loader tray. See Adjusting the Position of the Reagent Loader Tray for more information.

Step 10: End the Intrusive Diagnostics Session

You must end the intrusive diagnostics session.

  1. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics.
  2. Select End Session.
  3. Close all hoods and covers.
  4. Enable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  5. Sign out from the BeckmanAdmin account.
  6. Sign in to use the LabUser account.
  7. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.

Step 11: Complete the Verification of Service Repair

You must complete the verification of service repair. See Verification of Service Repairs for more information.

Adjusting the Position of the Reagent Loader Tray

While you are aligning the reagent loader tray, you may be asked to adjust the position of the tray. Perform these steps to adjust the position of the tray.

  1. In the Machine Control App go to ReagentLoader > ReagentLoader.Assembly > LoadTrayAxis.

  2. On the Action tab select MoveRelative.
  3. Enter the number of steps to move tray number 1 relative to its current position, and select Execute.
    Note: Adjust the position 50 steps at a time. Type 50 to or -50 to move the position 50 steps relative to the current position.
  4. Capture another image to check the position of the barcode.
    1. In the Machine Control App go to MENU > Machine Control > ReagentLoader > ReagentLoader.Assembly.

    2. On the Action tab select PositionTrayForScan.
    3. Type 1 in the trayNumber box.
    4. Select Execute.
    5. Go to ReagentLoader > ReagentLoader.Assembly > ReagentLoader.BarcodeReader.

    6. On the Action tab select Read.
    7. Select Execute. The value box should display 1.
      • If the value box displays NR instead of 1, adjust the alignment position for the reagent loader tray. See Adjusting the Position of the Reagent Loader Tray for more information.
    8. Select CaptureImage.
    9. Select Execute. The data box will display the image captured.
  5. If the barcode is in an acceptable position, go to MENU > Prototype Alignment > Reagent Storage > Reagent Loader Tray.

  6. Select Refresh to display the value for the Last Known Position.
  7. Type the value for the last known position into the Alignment Value box.
  8. Select Save All.
