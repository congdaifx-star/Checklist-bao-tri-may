Detecting and Removing Malware from the Instrument

This topic includes information about how to detect and remove malware from the instrument.

Important: You must only attempt to detect and remove malware while the instrument is idle. Do not perform this procedure while running samples.
Important: If malware is suspected on an instrument, it should be re-imaged, because this is the only way to be certain any malware present has been removed. If there is data on the instrument that should be preserved, save this data before re-imaging, and restore the data when complete.
Note: If a customer would like information about whether there was any malware on the device, use the following procedures to detect and remove it for them, but inform them we can only guarantee malware removal if we go through the re-imaging procedure.
Important: After you perform this procedure, delete any malware detection and removal tools that you copied to the instrument’s hard drive.
  1. Use the malware detection and removal tool to prepare a USB drive for transferring the tool to the BEC product. See Detecting and Removing Malware from USB Drives for more information.
  2. Download Microsoft Safety Scanner (64-bit) to the USB drive. See Downloading the Malware Detection and Removal Tool for more information.
  3. On the instrument, sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  4. Insert the USB drive into an open USB port on the instrument.
  5. In File Explorer, select This PC to display the drive letter assigned to your USB drive.
    Note: On the DxI 9000, the drive letter for your USB drive will likely be E:.
  6. Copy the malware detection and removal tool (MSERT.exe) to the Desktop.

  7. From the Desktop, open the malware detection and removal tool (MSERT.exe) to start the Microsoft Safety Scanner wizard.
    Note: If the notification Windows cannot access the specified device, path, or file. You may not have the appropriate permissions to access the item. is displayed, be sure you are opening the malware detection and removal tool (MSERT.exe) from the Desktop and not from the USB drive.

  8. Select Accept all terms of the preceding license agreement.
  9. Select Next, and select Next again to proceed to the Scan type page.
  10. On the Scan type page, select Customized scan. Select Choose Folder and select the C: drive. Select Select Folder.

    Important: Because the DxI 9000 also uses the D: drive, you will need to repeat this procedure to scan the D: drive.
  11. Select Next to start the scan.
    Note: Wait for the scan to complete. A progress bar and timer will be displayed. The tool will indicate whether malware was found.
    • If no malware was found, capture a screen shot as evidence. Select Finish.
    • If malware was found, the tool will indicate that viruses, spyware, and other potentially unwanted software was detected and removed. Select View detailed results of the scan to view the report.

  12. Capture a screenshot that shows the details about the malware found.

    Note: If you see the following malware, it can be ignored. It is a false positive and its removal has no effect on the system.

    Note: If you see any other malware, the PC must be reimaged. See Reimaging the PC for more information. After you reimage the PC, you must perform this troubleshooting procedure again.
  13. Open File Explorer.
  14. Go to C:\Windows\debug and locate the MSERT log file.
  15. Email the MSERT log file, along with the screenshots of the reported malware found, to ProductSecurity@beckman.com
  16. Delete the malware detection and removal tool (MSERT.exe) from the Desktop.
