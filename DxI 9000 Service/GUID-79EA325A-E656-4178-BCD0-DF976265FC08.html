Enrolling the DxI 9000 on DxS IntelliServe

This topic includes information about how to enroll the DxI 9000 instrument on DxS IntelliServe.

Prerequisites

Before you perform this procedure:
  • The DxI 9000 must be physically connected and configured to connect with DxS IntelliServe. See Automation (LAS) for more information.
  • The customer must have made the provisions for their network firewall as stated in the Remote Connections Form.
  • The Remote Connections Form must be complete, and you must confirm that the form has been forwarded to Global Remote Solutions Support ( RemoteSolutionsSupport@beckman.com).
  • You must have a USB drive that includes the instrument-specific certificate (<instance>.pfx) file. Be sure the USB drive is malware-free. See Detecting and Removing Malware from USB Drives for more information.
    To request the certificate:
    1. Send an email message to RemoteSolutionsSupport@beckman.com. Include the customer name and address, the DxI 9000 Instance ID, and the Instance ID of the firewall device it will be connected to. Allow for up to two business days to receive a reply.
    2. After you receive a reply to your email message, use the link in the reply to download the certificate.
    3. Confirm the certiicate file name matches the instrument Instance ID.
  • The DxI 9000 instrument must be using system software version 1.20 or later.
Enrolling the DxI 9000 on DxS IntelliServe
Step 1: Install the Certificate onto the Instrument
Step 2: Configure Security Settings on the Instrument
Step 3: Import the Certificate for the LabUser Account
Step 4: Restart RMSConnectorAgent.Console
Step 5: Enroll the Instrument with DxS IntelliServe

Step 1: Install the Certificate onto the Instrument

  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Insert the USB drive that includes the <instance>.pfx certificate file into an open USB port behind the console PC monitor.
  3. Press the Windows key and type file explorer to open File Explorer.
  4. Go to C:\Program Files (x86)\DxI 9000\RMSCertificateTool
  5. Right-click RMSCertificateTool.exe and select Run as Administrator to open the RMS Certificate Configuration wizard.
  6. Select IntelliServe.
  7. Select Next.

  8. Select I already have a certificate.

  9. Select Choose Certificate File, then go to the USB drive, select the <instance>.pfx certificate file, and select Open. The file path to the certificate file will be displayed in the Enter full certificate path below: box.
  10. Type BC$3v1ce, which is the password for the certificate, into the Enter password below: box.
  11. Select Next. If the credentials are correct, the notification Configuration Successful will be displayed.
  12. Select Close.

Step 2: Configure Security Settings on the Instrument

  1. Press the Windows key and type local group policy editor.

  2. Select Edit group policy to open Local Group Policy Editor.

  3. Go to Computer Configuration > Windows Settings > Security Settings > Local Policies > Security Options.

  4. Double-click System Cryptography: Force strong key protection for user keys stored on the computer to open a dialog.

  5. On the Local Security Setting tab select User input is not required when new keys are stored and used.
  6. Select Apply.
  7. Select OK.

Step 3: Import the Certificate for the LabUser Account

  1. Restart the console PC. See Restarting the Console PC for more information.
    Note: You automatically will be signed in to use the LabUser account.

  2. Press Windows key + E to open File Explorer.
  3. Go to the USB drive and double-click the <instance>.pfx certificate file to open the Certificate Import Wizard.

  4. Select Current User.
  5. Select Next. The path to the <instance>.pfx certificate file will be displayed in the File name: box.

    If the path to the file is not displayed, select Browse to select the file.

  6. Select Next.

  7. Type BC$3v1ce, which is the password for the certificate, into the Password: box.
  8. Select Next.

  9. Select Place all certificates in the following store.
  10. Select Browse to open the Select Certificate Store dialog.

  11. Select Personal.
  12. Select OK to close the dialog.
  13. Select Next.

  14. Select Finish. The notification The import was successful will be displayed.

  15. Select OK.

Step 4: Restart RMSConnectorAgent.Console

  1. Press the Windows key and type task manager to open Task Manager.
  2. On the Details tab, right-click RMSConnectorAgent.Console and select End Task. The RMSConnectorAgent.Console process should stop and then automatically start again.
    If the RMSConnectorAgent.Console process does not start automatically:
    1. Go to C:\Program Files (x86)\DXI9000.
    2. Double-click RMSConnectorAgent.Console.exe.

Step 5: Enroll the Instrument with DxS IntelliServe

  1. In the Console App go to MENU > Advanced > DxS IntelliServe to open the Connector: DxS IntelliServe page.

    Note: If DxS IntelliServe is disabled, select Enable to open the full page.

    The following data should be displayed in the Configuration: DxS IntelliServe pane:
    Connection Details Instrument Enrollment
    Connection Status Connected Instance ID <instance ID>
    RAID: <certificate number> Enrollment Status Not Enrolled
    Certificate Loaded
    • If Connection Status is Not Connected, or if Instance ID is blank, see Troubleshooting DxS IntelliServe Enrollment Issues for more information.
    • If Certificate is Not Loaded repeat Step 1: Install the Certificate onto the Instrument.

  2. Go to the Connector: DxS IntelliServe page.
  3. Select the appropriate Host location.
    • EU-Prod for all European Union countries.
    • US-Prod for all other countries.
    Note: After you switch host environments, it may take up to 30 seconds to connect to the host.

  4. If the customer uses their own proxy servers and has provided information about them on the Remote Connections Form, select Enable for the Enable Proxy setting to display Client Proxy Details.
  5. Type the relevant information in the Client Proxy Details boxes.
  6. Select Save Proxy.
  7. Select Enroll.
    After approximately 30 seconds, the following data should be displayed in the Configuration: DxS IntelliServe pane:
    Connection Details Instrument Enrollment
    Connection Status Connected Instance ID <instance ID>
    RAID: <certificate number> Enrollment Status Enrolled
    Certificate Loaded

    If Enrollment Status is Not Enrolled, or if Connection Status is Not Connected, see Troubleshooting DxS IntelliServe Enrollment Issues for more information.

  8. Restart the console PC. See Restarting the Console PCfor more information.
  9. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  10. In the Console App go to MENU > Advanced > DxS IntelliServe to open the Connector: DxS IntelliServe page.
    The following data should be displayed in the Configuration: DxS IntelliServe pane:
    Connection Details Instrument Enrollment
    Connection Status Connected Instance ID <instance ID>
    RAID: <certificate number> Enrollment Status Enrolled
    Certificate Loaded

    If Enrollment Status is Not Enrolled, or if Connection Status is Not Connected, see Troubleshooting DxS IntelliServe Enrollment Issues for more information.
