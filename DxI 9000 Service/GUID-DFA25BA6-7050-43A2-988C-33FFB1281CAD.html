Enabling and Disabling Access to the Machine Control App

This topic includes information about how to enable access to the Machine Control App.

Table of Contents

Using File Explorer to Disable Access

Using the Service App to Enable Access

Perform this procedure to use the Service App to enable access to the Machine Control App.
Note: Using the Service App is the preferred method for enabling access to the Machine Control App. However, if the Service App is not available, see Using File Explorer to Enable Access for more information about using File Explorer to enable access.
  1. In the Service App go to Menu > Application Configuration.
  2. Select Machine Control Access.
  3. The Machine Control App will now be visible, and the Messages box in the Service App will include the notification that the action was successful.

Using the Service App to Disable Access

Perform this procedure to use the Service App to disable access to the Machine Control App.
Note: Using the Service App is the preferred method for disabling access to the Machine Control App. However, if the Service App is not available, see Using the Service App to Disable Access for more information about using File Explorer to disable access.
  1. In the Service App go to Menu > Application Configuration.
  2. Clear Machine Control Access.
  3. The Machine Control App will now be hidden, and the Messages box in the Service App will include the notification that the action was successful.

Using File Explorer to Enable Access

Perform this procedure to use File Explorer to enable access to the Machine Control App.
Note: The preferred method for enabling access to the Machine Control App is to use the Service App. See Using the Service App to Enable Access for more information.
  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Open File Explorer.
  3. Go to D:\Program Data\Beckman Coulter\Falcon
  4. Create a new file with the name mcaccess.cmd
    Note: The file does not need to contain any data.
  5. The Machine Control App will now be visible.

Using File Explorer to Disable Access

Perform this procedure to use File Explorer to disable access to the Machine Control App.
Note: The preferred method for disabling access to the Machine Control App is to use the Service App. See Using the Service App to Disable Access for more information.
  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Open File Explorer.
  3. Go to D:\Program Data\Beckman Coulter\Falcon
  4. Delete mcaccess.cmd
  5. The Machine Control App will now be hidden.
