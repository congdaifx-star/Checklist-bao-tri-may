Testing Sample Pipettor Level Sense

This topic includes information about how to test sample pipettor level sense.

Table of Contents
When to Perform
Wet Test and Dry Test
Testing Level Sense
Troubleshooting Level Sense Failures

When to Perform

Perform the level sense diagnostic test to troubleshoot/confirm failures for the aliquot or precision sample pipettors, such as level sense failures or insufficient volume (QNS) errors. Note that the affected pipettor will be defined in the event message.

Wet Test and Dry Test

You can test sample pipettor level sense using a wet test or dry test.

Test Description
Wet Test The sample pipettor will attempt to level sense wash buffer in a reaction vessel to confirm that it can successfully detect fluid.
Dry Test The sample pipettor will attempt to level sense an empty reaction vessel to confirm that it can successfully detect absence of fluid.

Testing Level Sense

Ensure the system is not actively processing samples prior to beginning this test.
  1. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  2. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  3. Select Level Sense to open the Level Sense page.
  4. Select Aliquot Pipettor or Precise Sample Pipettor.
  5. Type the number of Wet Test Repetitions and Dry Test Repetitions.
    Note: The default and recommended minimum is 10. If you do not wish to perform one of the tests, type 0.
  6. Select Start Level Sense. The results and Pass/Fail status will be displayed in the Test Results area.

Troubleshooting Level Sense Failures

See the table below for direction on how to troubleshoot potential failures of the level sense test. Note that the failure modes and troubleshooting will be the same for either the aliquot or precision sample pipettor.
Failure Mode Troubleshooting/Possible Root Cause
Wet Test
  • Repeat the test with covers open and observe the vessel used for level sensing, confirm that wash buffer is dispense from reagent pipettor 1 into the vessel. If there are dispense failures from the pipettor this will cause "false failures" of the level sense test.
  • Inspect the pressure sensor printed circuit board (PCB) (the PCB on top of the pump housing) into the pipettor manifold to confirm that it is fully seated and there are no signs of damage/debris.
  • Inspect all cable/PCB connections and ensure they are fully seated and not damaged (sensor to intermediate connector, and intermediate to interface PCB).
  • Inspect the mandrel/acrylic pump housing for signs of obstruction. Consider purging the line/mandrel with compressed air by disconnecting the tubing between the mandrel and pump housing, blow the air out the tip of the pump to clear any obstructions.
  • Consider replacing/swapping pressure sensor (PCB), on top of the acrylic pump housing.
  • Consider replacing/swapping pipettor interface PCB.
Dry Test
  • Failures are rare but typically due to a faulty pressure sensor or PCB. Check all connections and consider replacing/swapping sensor or pipettor interface PCB to diagnose failure.
