Reagent Storage or Tip Stocker (RSI/TSI) Printed Circuit Board (PCB) Layout

This topic includes information about the locations and features of the DxI 9000 reagent storage or tip stocker (RSI/TSI) printed circuit board (PCB).

Cable Connections

Location

Function

Notes

J1JTAGUsed to program firmware. Requires special tool to plug into it. Intended for development use
J2Reagent Storage DoorSensor for the front Reagent Storage door
J3USB cable portConnects board to USB Hub network
J4EncodersZ and Y Tray Gripper encoders. X and Z Pack Gripper encoders

J5BCR Window Heater

Heating window for Reagent Storage barcode reader that remains on

J6dMCC SignalsLow level signals from valve control, etc. to home sensors, etc. The module’s dMCC
J724V OutputsCover locks and Z motor brakes
J8LED OutputsControls lock LEDs (sequentially blink)
J9Pack Gripper & Board IDTip Detect Sensor. Detects if row in tip tray has a tip or empty. Input for 2x pack gripper sensors. Has ID jumper installed for RSM location
J10Cover Switches2 module cover sensors connect here. Loader cover sensor
J11Reagent Storage Loader Motor InputLoader motor signals from dMCC
J12Power input24V (Purple) and Ground (Black)
J13dMCC PowerPower Tip Stocker module’s dMCC ID 13
J14Reagent Storage Loader Motor OutputLoader motor signals to motor. Motor is disabled by circuitry on this board when loader cover is open
J15Gripper X/Z HomeTray Waste Bin and

Home sensor for Reagent Storage gripper

J16N/AN/A
J17Interlock OverrideAllows module covers to be opened and power maintained when the override switch is enabled

LEDs

Location

Function

Notes

D5 USB signal Transmit (TX) Blinks when data is being transmitted to host computer from RSI-TSI via USB
D6 USB signal Receive (RX) Blinks when data is being transmitted from host computer to RSI-TSI via USB
D8 24V Cover Interlock 1 Not used
D9 24V Cover Interlock 2

LED on = Gripper Drawer lock is disengaged

See TP8

D12 Pack Gripper – Closed Sensor LED on = tip detected by tip detect sensor
D13 Pack Gripper – Opened Sensor LED on = tip detected by tip detect sensor
D14 Gripper X/Z Home LED on = Tray Waste bin present

LED on = gripper home

D15, D16 All Module Covers Closed

  • LED on = both tip stocker covers are closed

    Note:

    Note: Always on if interlock override is enabled

  • LED on = reagent storage loader door closed

    Note:

    Note: Always on if interlock override is enabled

D17 Cover Sensor 2 LED on = Rear cover closed
D19 Cover Sensor 1 LED on = Front Top cover closed

LED on = Reagent Loader Tray Cover closed

D22 Tip Stocker Brake 1

LED on = Tray Loader Brake disabled

See TP15

D23 Tip Stocker Brake 2

LED on = Tray Gripper Z Brake disabled

See TP16

Test Points

Location

Function

Notes

TP1 Brown Out 0V when power to board has been removed long enough to invalidate encoder value 5V when encoder value is valid
TP2 Reagent Storage Door

Sensor for the front Reagent Storage door

5V when front door closed

0V when front door removed

TP3 5V USB power Should provide +5V signal to DMM 5V provided by USB cable via J3
TP4 USB Ground Use as a ground when measuring TP3
TP5, TP17, TP21 GND Use as ground when measuring most test points
TP6 5V dMCC Should provide +5V signal to dMCC 5V provided by dMCC via J6
TP7 24V Cover Interlock 1 Not used
TP8 24V Cover Interlock 2

About 4V when Gripper Drawer Lock Solenoid (lock for pulling out tip stocker) is disengaged

0V when lock is engaged

TP9 dMCC Ground Use when measuring TP6
TP10 Gripper X/Z Home

  • 0V when tray waste bin is present

  • 5V when tray waste bin is not present

  • 0V when gripper home

  • 5V when gripper not home

TP11 Pack Gripper – Opened Sensor
TP12 Pack Gripper – Closed Sensor 0V = tip detected by tip detect sensor
TP13 24V Logic power

Should provide +24V signal to DMM

Used to power microcontroller and other logic components

TP14 All Module Covers Closed
  • 5V when both tip stocker covers are closed Otherwise 0V

  • 5V when reagent storage loader door closed

    Otherwise 0V

TP15 Tip Stocker Brake 1 0V = Tray Loader Brake enabled 24V = Tray Loader Brake disabled
TP16 Tip Stocker Brake 2 0V = Tray Loader Brake enabled

24V = Tray Loader Brake disabled

TP18 +5V Charge 5V when board is powered. Used to charge onboard capacitor. Regulated from 24V input on TP13
TP19 +5V Cap 4.5 – 5V when fully charged. Slowly goes down in voltage when instrument is powered off. When reaches < 2.20V, the encoder value stored is invalidated. Regulated from +5V Charge on TP18
TP20 +5V Encoder 5V when board is powered and for 30 seconds after power is lost. Regulated from +5V Cap on TP19
