LEDs

Location

Function

Notes

D1 Channel 1 Status

  • LED off = channel has not reached target temperature

  • LED flickering or low intensity = channel approaching target temperature

  • LED on = channel has reached target temperature

D2 Channel 3 Status

  • LED off = channel has not reached target temperature

  • LED flickering or low intensity = channel approaching target temperature

  • LED on = channel has reached target temperature

D3 Channel 4 Status

  • LED off = channel has not reached target temperature

  • LED flickering or low intensity = channel approaching target temperature

  • LED on = channel has reached target temperature

D4 Channel 2 Status

  • LED off = channel has not reached target temperature

  • LED flickering or low intensity = channel approaching target temperature

  • LED on = channel has reached target temperature

D6 Fault

  • LED off = no fault

  • LED on =

    • sensor disconnected for 5 sample intervals. Check sensor and sensor wiring.

    • temperature greater than max – Channel is disabled to protect heater. Could indicate a defective board.

    • failure of auto cal - All channels are disabled. Could indicate a defective board or RF interference.

    • ADC startup fails – All channels are disabled. Could indicate a defective board.

  • Note: Use Machine Control to view channel status for fault reason.

D7 USB signal Receive (RX) Blinks when data is being transmitted from host computer to this device via USB
D9 3.3V

  • LED on = 3.3V power supply active

  • LED off = 3.3V power supply inactive

3.3V is regulated from +6V (TP1)

D12 USB signal Transmit (TX) Blinks when data is being transmitted to host computer from this device via USB

Test Points

Location

Function

Notes

TP1 6V power

Should provide +6V to DMM, regulated down from 24V

TP2 3V power Should provide +3V to DMM, regulated down from 5V, used as reference voltage for microcontroller and ADC
TP3 3.3V power

Should provide +3.3V to DMM, regulated down from 6V, used to power microcontroller and other logic devices

TP4 5V power

Should provide +5V to DMM, regulated down from 6V, used to power temperature measurement circuit

TP5, TP6 Ground Use as a ground when connecting to other test points
