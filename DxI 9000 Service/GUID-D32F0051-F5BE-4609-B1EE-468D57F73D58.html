Troubleshooting the PVSV Precision Pipettor Wrong Volume Aspirated SV Flag

If the system displays the PVSV flag, the precision sample pipettor camera detected that an incorrect volume of fluid was aspirated from the sample vessel (SV) during dilution.

Table of Contents
Troubleshooting the PVSV Flag
Analyzing the Related Test Files

Troubleshooting the PVSV Flag

  1. Be sure the precision sample pipettor is not interfering with the reflector.
  2. Be sure the reflector and the mandrel are not scratched, bent, or slanted.
  3. Be sure the precision sample pipettor cameras have been calibrated. See Calibrating Cameras for more information.
  4. Be sure the precision sample pipettor has been aligned. See Aligning the Precision Sample Pipettor for more information.
  5. Be sure the tubing is not kinked or damaged.

Analyzing the Related Test Files

  1. Export the results of the test for further analysis. See Exporting Results to Disk for more information.
  2. Open the export file and check the values in the file.
    • If Volume Va in “AfterAspirationFromSVVolume[ul](Va)” is negative one hundred (-100), there is no meniscus in the DV or the monitoring system failed to find a meniscus.
    • If Volume Va is not negative one hundred (-100), the measured volume is incorrect because the monitoring system falsely located a meniscus or the pipettor has failed.
  3. Use the following information to calculate the accuracy of the measurement and to determine the failure(s):

    Aspiration volume: “AfetrAspirationFromSVVolume[uL](Va)” -- > Vactual
    Target volume: :PSPTargetVa[uL]” -- > VTarget
    Specification [uL][%]
    2≤ Volume <10 ± 30
    10≤Volume <20 ± 15
    20≤Volume ≤100 ± 12
