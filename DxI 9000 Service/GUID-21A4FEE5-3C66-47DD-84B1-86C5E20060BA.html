Calibrating the Pressure Sensors for the Wash Wheel

This topic includes information about how to calibrate the pressure sensors for the wash wheel.

Table of Contents

Prepare the Instrument for Pressure Sensor Calibrations

Perform the following procedure before you calibrate a pressure sensor.

  1. Perform necessary alignments.
  2. Be sure there is enough substrate in the instrument to prime the instrument and to perform the calibrations.
  3. Be sure there is adequate wash buffer in the instrument to perform the calibrations.
  4. Be sure there are enough tips to perform the calibrations.
  5. Be sure there are enough reaction vessels (RVs) to perform the calibrations.
  6. Initialize the instrument. See Initializing the Instrument for more information.
  7. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  8. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  9. Prime the instrument. Prime all components for five cycles. See Priming the Instrument for more information.
    Note: Initialization and priming may take several minutes, especially if the instrument has been inactive for an hour or more.

Calibrate the Pressure Sensor

  1. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics > Pressure Monitor Calibration to open the Pressure Monitor Calibration page.
  2. In the PRESSURE MONITOR column select the checkboxes for Wash Wheel QS Probe, Wash Wheel D1 Probe, Wash Wheel D2 Probe, and Wash Wheel A1 Wash.
    Note: If you are calibrating a pressure sensor for a previously failed calibration, only select the checkboxes for the pressure monitors that failed calibration.
  3. Select Start Pressure Monitor Calibration. Wait approximately 20 minutes for the system to complete calibration.
    1. If the calibration fails, and if the system displays EWF, EWO, WDF, or WDO flags, see the following topics for more information about how to troubleshoot the issue.
      1. Troubleshooting the EWF A1 Wash Fluidics Error (Low Pressure) Flag
      2. Troubleshooting the EWO A1 Wash Obstruction (High Pressure) Flag
      3. Troubleshooting the WDF Wash Wheel Fluidics Error (Low Pressure) Flag
      4. Troubleshooting the WDO Wash Wheel Obstruction (High Pressure) Flag
    2. If the calibration succeeds:
      1. The notification Operation completed: Pressure Monitor Calibration will be displayed in the STATUS area.
      2. Pass will be displayed in the RESULT column.
      3. Today will be displayed in the LAST CALIBRATION column.
  4. Go to Intrusive Diagnostics.
  5. Select End Session.
