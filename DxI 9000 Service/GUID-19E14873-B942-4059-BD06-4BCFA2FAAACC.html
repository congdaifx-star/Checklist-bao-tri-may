Priming an Empty Substrate System

This topic includes information about how to prime an empty substrate system.

Perform this procedure when substrate system lines must be primed from a "dry" state. This might include but is not limited to the following situations:

  • System installation (manufacturing primed dry for shipment)
  • System start-up after an extended downtime (FSE primed dry before dormant)
  • Component replacement (replacing substrate subsystem parts; pump, valve, tubing, probe)
  • Substrate system ran with empty bottle in place
  • Troubleshooting scenarios where air in the substrate lines has been observed
  1. Be sure the system is in a GREEN (Ready) status.
  2. In the Machine Control App go to MENU > MACHINE CONTROL to open the Machine Control page.
  3. Go to Priming Controller.
  4. On the Configuration tab select the down arrowhead (⌄) adjacent to Data to reveal options.
  5. Select the down arrowhead (⌄) adjacent to WashVesselConfig to reveal options.
  6. Select the down arrowhead (⌄) adjacent to 0 to reveal options.
  7. Select the down arrowhead (⌄) adjacent to PrimingOperationConfig to reveal options. See illustration below:
  8. Select the down arrowhead (⌄) adjacent to Stage 1 to reveal options.
  9. Change the value in the DelayBetweenDispense box from 8000 to 0.
  10. Change the value in the VolumePerDispense box from 200 to 675.
  11. Repeat for Stage2, Stage3, and Stage4.
  12. Select Apply.
    Note: There is no confirmation of this action.
    See illustration below:

  13. In Console App select SYSTEM RUNNING and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  14. Go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  15. Select Priming.
  16. Select Substrate Probe.
  17. In the CYCLES REQUESTED box type 1.
  18. Select Start Priming.
    The substrate syringe should complete 4 large full travel dispenses (675µL) followed by 24 smaller (200µL) ones.
    Note: System may display an error before completing all 28 stages of substrate prime. Allow the system to complete priming regardless of status.
  19. When the system has finished priming, either close and restart Machine Control, or reboot the system.
  20. Initialize the instrument. See Initializing the Instrument for more information.
  21. In the Console App select SYSTEM RUNNING and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  22. Go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  23. Select Volume Checks.


  24. In the Probe area select Wash Wheel Substrate.
  25. In the Measurement Method area select Camera.
    Important: Only select Camera. DO NOT select Gravimetric or Gravimetric plus Camera.
  26. In the Measurement Parameters area type 5 in Measurements.
  27. In the Measurement Parameters area type 200 in Volume.
  28. Select Start Operation.
    Substrate Priming is complete when the instrument demonstrates it can fill 5 vessels with at least 190 µL.
    Note: If results are not ≥ 190 µL, inspect tubing connections for leaks and repeat the process.
  29. Initialize the system and return it to a GREEN (Ready) state.
