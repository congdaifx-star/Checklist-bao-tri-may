Configuring for Remisol on a Lab Network with a Firewall Device

This topic includes information about how to configure a DxI 9000 instrument connected to a DxA to be managed by Remisol on a lab network with a firewall device.

When to Perform

Perform this procedure when the middleware/LIS managing the instrument is located on the lab network (e.g. a Virtual Remisol Server) and a firewall device is installed as a perimeter defense. This also applies to a Command Central server or to a network printer.

Configuring the DxI 9000

Perform the following procedures to configure the DxI 9000:

  • Enabling Automation on the DxI 9000
    Note: This is mandatory for DxI 9000 to DxA communication. If not already connected, perform this first.
  • Configuring the LIS Protocol on the DxI 9000
  • Configuring the IP Address for the Network
  • Configuring Port Forwarding for the Dynamic Interface

If a Command Central server is part of the configuration, you must also perform the Configuring Port Forwarding for the Command Central Server procedure.

OpenVPN Requirements

To establish inbound communication, this configuration requires you to install OpenVPN on the Remisol PC that manages the instrument on the lab network.
Important: You must install Command Central on the same PC as Remisol, to enable establishing connections via the VPN tunnel.
Note: OpenVPN encrypts PHI traffic to the LIS and provides for inbound connectivity over the firewall device as required by the Dynamic Interface from Remisol to the instrument and/or the connection from Command Central to the instrument.

See the Remote Solutions Service Manual for more information about how to install the OpenVPN client.

Connecting the Ethernet Cables to the DxI 9000

Connect the Ethernet cable from the INSTRUMENTS port on the firewall device to the eth4 port at the rear of the instrument.
