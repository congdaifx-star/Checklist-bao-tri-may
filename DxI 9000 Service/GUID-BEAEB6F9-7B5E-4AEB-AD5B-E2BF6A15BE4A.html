Nonintrusive Backup

In the Console App, there is a nonintrusive backup process that creates a minimal backup of key system files. The backup generally includes settings and alignments, but not customer data. It is not intended to backup customer data like curves, QC, or patient results.

Created

Intrusive Restore

In the Console App, there is an intrusive restore process that restores the system hardware settings (alignments and similar). The process is "intrusive" because it should only be performed during system downtime. The process does not restore patient data like curves, QC, etc.

Restores instrument settings and alignments from Nonintrusive backup

Service App Database Backup Script

The Database Backup script in the Service App backs up all major system databases, including those containing customer data.

System Configuration Roll Back

In the Console App, you can use the Roll Back function on the System Configuration page to load previous configurations for user settings, rules, etc.

Created during Activate

Finalize Instrument Alignment

In the Machine Control App on the Prototype Alignment page, the Finalize Instrument Alignments function is a key step in the instrument's manufacturing and commissioning process. The function indicates that the default settings embedded in the software have been configured for the individual instrument (i.e. the default alignment value has been updated at least once). Generally, an instrument is only 'finalized' once, during manufacturing. The function does not create or modify any backups.

Service App Delete Test Menu Script

The Delete Test Menu script in the Service App completely deletes all APF data. It removes tests, rules, panels, and QC settings from DxI 9000 software, and it removes sample and QC database data by user request. It also removes RAPID updates from the RSU database.

Modified

Installer

The installer backs up databases and configuration files during installation. Each Installation creates a new backup folder in D:\ProgramData\DxI9000Back
