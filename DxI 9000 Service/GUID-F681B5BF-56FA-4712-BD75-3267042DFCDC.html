Configuring the Geographical Region

This topic includes information about how to configure the geographical region on the instrument.
Note: Perform these steps during installation or whenever a system is changing geographies (typically during system installation). This setting determines which tests will be available to the system.
  1. Sign in to the Console App using the Service Login. See Signing In to the Console App Using the Service Login for more information.
    Note: This is required to access the Geographical Configuration menu.
  2. In the Console App go to MENU > System Configuration to open the System Configuration page.
  3. Go to Internal Use > Geographical Configuration to open the Geographical Configuration page.
  4. Select the Region and Country for the system location.

  5. Go to System Configuration.
  6. Select Activate.
  7. Enter comments (i.e. Configured region and country to xx) and select OK.
  8. The notification The Configuration was Updated Successfully will be displayed. Select OK.
  9. Sign out of the Service Login.
