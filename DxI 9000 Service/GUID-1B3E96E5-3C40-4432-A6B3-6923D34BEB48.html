Troubleshooting Racks in the Sample Presentation Unit (SPU)

This topic lists possible causes for events related to racks not moving the system to be analyzed.

Motor Issues

In the table below, review the possible causes for each event by type.
Event Description Possible Causes
Unrecoverable Slippage in Onload Onload Motor has slipped, and even after recovery it is out of the acceptable range.

Friction between racks and Onload rails

Additional load on Onload Pusher (Something is interfering with the pusher)

Loss in run current for Onload Motor - Motor or cable failure

Mechanical (linear rail, bearing, belt)

Movement Failure in Onload - Seek End of Rail Onload Motor fails to perform seek move at End of Rail Sensor with Rack Present.

End of Rail Sensor or cable is damaged or unplugged.

End of Rail Sensor optical path is blocked.

End of Rail Sensor does not detect rack (rack is damaged or molding issue).

Homing Failure in Onload Onload Motor fails to move home.

Home Sensor or cable is damaged or unplugged.

Home Sensor optical path is blocked.

Unrecoverable Slippage in Presentation Presentation Motor has slippage, and even after recovery it is out of the acceptable range.

Obstruction in Presentation Lane (RVs, Tips, etc.)

Something is interfering with Presentation Carrier.

Loss in run current for Presentation Motor due to motor or cable failure.

Mechanical (linear rail, bearing, belt)

Home Failure in Presentation Presentation Motor fails to move home.

Home Sensor or cable is damaged or unplugged.

Home Sensor optical path is blocked.

Camera Issues

In the table below, review the possible causes for each event by type.
Event Description Possible Causes
SPU Camera Communication Failure SPU Camera fails to trigger.

Cable is unplugged or damaged (power or network).

Camera is not configured on network properly.

SPU Camera Barcode Read Failure SPU Camera fails to read a barcode.

Barcode is out of specification (quality, placement, etc.).

Camera lens cover is dirty or damaged.

Background tape is damaged.

Specimen barcode is not visible (rotated in rack).

Camera is not calibrated or adjusted appropriately (see HLD for more info).

Misalignment with BCR Alignment point.

SPU Camera Container Identification (Vision) Failure SPU Camera fails to identify container type repeatedly.

Container is not approved.

Camera lens cover is dirty or damaged.

Background tape is damaged.

Container is not loaded into rack appropriately.

Camera is not calibrated or adjusted appropriately (see HLD for more info).

Container is covered up by label in key regions of interest (see HLD for more info).

Misalignment with BCR Alignment point.

Sensor Issues

In the table below, review the possible causes for each event by type.
Event Description Possible Causes
SPU Container Detect Failure (Rack Detect Sensor) SPU Detect Sensor fails to detect container present in rack. Sensor or cable is damaged/unplugged.
Swing Lock Detection Sensor Failure Swing lock sensor fails to detect with SPU is swung in. Sensor or cable is damaged/unplugged.

Sample Handler Movement Issues

In the table below, review the possible causes for each event by type.
Event Description Possible Causes
SPU Cannot be swung out User cannot swing out SPU.

Swing Lock Failure (mechanical)

Swing Linkage gets obstructed by foreign object.

SPU support at cantilever end gets stuck.

SPU Cannot be Swung In User cannot push in SPU.

Swing Linkage gets obstructed by foreign object.

Swing mount plate gets bent from excessive load.

SPU support at cantilever end is misaligned with mating ramp.

SPU Cannot be Locked SPU Swing Lock Mechanism is damaged and user cannot lock SPU.

Spring inside swing lock housing is broken.

Too much friction in the linkage

Lock Linkage gets blocked by some foreign object.

If not assembled correctly, pivoting shoulder screw could be loose.

Door cannot close User cannot close the door to start the SPU.

Door lock stuck in locked position (pin doesn’t retract and blocks user from closing door).

Hinge Failure

Door can close but SPU does not start User can close the door but the SPU does not start right away.

Misalignment with door sensor (sensor itself)

Hinge-induced misalignment with door sensor

Door sensor or cable is damaged.

Offload Area Issues

In the table below, review the possible causes for each event by type.
Event Description Possible Causes
Offload door cannot close User cannot close the offload door. Hinge Failure
Offload area full Rack Pusher will not Push.

Check to see whether the sensor at the back end of the offload is blocked.

Check the alignment of the sensor.

Rack Sticking Issues

In the table below, review the possible causes for each event by type.
Event Description Possible Causes
Rack stuck presented in instrument Instrument has encountered a system issue while the rack is at the aliquot position. Upon reinitialization, the rack is stuck at the aliquot position and will not release.

In the Machine Control App go toSPUPresentation > SPUPresentation.Assembly. On the Action tab select ReleaseRack and select Execute to release the rack from the system.

Rack Broken Rack has chipped or cracked and does not follow the rails properly. Mishandled/dropped racks can crack or break. Check for cracks and breaks.
