Configuring Standalone for Middleware/LIS on a Lab Network without a Firewall Device

This topic includes information about how to configure a standalone DxI 9000 instrument for middleware (e.g. Remisol) or a laboratory information system (LIS) connection on a lab network without a firewall device.

When to Perform

Perform this procedure when the middleware/LIS managing the instrument is located on the lab network (e.g. a Virtual Remisol Server). This also applies to Command Central server or to a network printer.

Configuring the DxI 9000

Perform the following procedures to configure the DxI 9000:

  • Configuring the LIS Protocol on the DxI 9000
  • Configuring the IP Address for the Network
  • Determining the MAC Address for the eth4 Port

If a Command Central server is part of the configuration, you must also perform the Configuring Port Forwarding for the Command Central Server procedure.

Connecting the Ethernet Cables to the DxI 9000

Connect the Ethernet cable from the lab network to the eth4 port at the rear of the instrument.
