Configuring the DxI 9000 to Connect to DxA

This topic includes information about how to configure the DxI 9000 instrument to connect to DxA.

Prerequisites

Before you configure the DxI 9000 instrument to connect to DxA, be sure the DxI 9000 instrument meets the following requirements.
  • Service Modification 12881 must be complete. (You must have the newest configuration for the EdgeMax router.)
  • You must first prepare the DxI 9000 for the automation connection, you must position and connect the system, and you must enable automation. See Physically Connecting the DxI 9000 to a Lab Automation System (LAS) for more information.
  • The newest operating system image with the newest DxI 9000 system software version must be installed, and all required Windows security updates must be installed as mandated by the Global Product Security hardware firewall guidance.
  • If a firewall device will be used, the firewall must be configured as described in the "Firewall Device" chapter of the Remote Solutions Service Manual.

Configuring the DxI 9000 for Remisol

Perform one of the following procedures to configure the DxI 9000 instrument for Remisol, depending on whether the DxI 9000 is being installed on a lab network or using local Ethernet, and whether the network includes a firewall device.

  • Configuring for a Lab Network
    • Configuring for Remisol on a Lab Network without a Firewall Device
    • Configuring for Remisol on a Lab Network with a Firewall Device
  • Configuring for Local Ethernet
    • Configuring for Remisol on Local Ethernet without a Firewall Device
    • Configuring for Remisol on Local Ethernet with a Firewall Device
Note: DxI 9000 Host Manual C87417 is available for download from beckmancoulter.com. Registration is required.
