Spin Mixer Printed Circuit Board (PCB) Layout

This topic includes information about the locations and features of the DxI 9000 Spin Mixer printed circuit board (PCB).

Function

Notes

J1

Power input

24V (Purple) and Ground (Black)

J4JTAGUsed to program firmware. Requires special tool to plug into it. Intended for development use.

LEDs

Location

Function

Notes

D2 USB signal Transmit (TX) Blinks when data is being transmitted to host computer from this device via USB
D3 USB signal Receive (RX) Blinks when data is being transmitted from host computer to this device via USB
D4 Fault

  • LED off = no fault

  • LED on = PWM fault (over current, over temperature or short circuit)

D7 5V Power

  • LED on = 5V power supply active

  • LED off = 5V power supply inactive

5V is from USB (TP3)

D8 Motor Status 1 Each LED blinks is succession showing motor direction
D9 Motor Status 2
D10 Motor Status 3
D11 Motor Status 4

Test Points

Location

Function

Notes

TP1 24V power Should provide +24V to DMM, used to drive motor
TP2 3.3V power Should provide +3.3V to DMM, regulated down from 5V, used to power microcontroller and other logic devices
TP3 5V power Should provide +5V to DMM, from USB 5V power, used to power encoder
TP4 3V power

Should provide +3V to DMM,

regulated down from 3.3V, used as reference voltage for microcontroller

TP5 Ground Use as a ground when connecting to other test points
