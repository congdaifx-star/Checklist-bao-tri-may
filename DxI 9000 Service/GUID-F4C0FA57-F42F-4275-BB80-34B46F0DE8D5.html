Configuring a Standalone DxI 9000 to Connect to External Devices

This topic includes information about how to configure a standalone DxI 9000 instrument to connect to external devices.

Prerequisites

Before you perform procedures to configure a standalone DxI 9000 instrument to connect to external devices, you must be sure the following requirements have been met.
  • Service Modification 12881 must be complete. (You must have the newest configuration for the EdgeMax router.)
  • If the DxI 9000 instrument is connected to the customer network using the TCP/IP protocol, the newest operating system image with the newest DxI 9000 system software version must be installed, and all required Windows security updates must be installed as mandated by the Global Product Security hardware firewall guidance.

Configuring a Standalone DxI 9000 for Middleware/LIS

Perform one of the following procedures to configure a standalone DxI 9000 instrument to connect to external devices, depending on whether the DxI 9000 is being installed using an RS-232 Serial connector, on a lab network, or using local Ethernet, and whether the network includes a firewall device.

  • Configuring for an RS-232 Serial connection
    • Configuring Standalone for Middleware/LIS via an RS-232 Serial Connector
  • Configuring for a Lab Network
    • Configuring Standalone for Middleware/LIS on a Lab Network without a Firewall Device
    • Configuring Standalone for Middleware/LIS on a Lab Network with a Firewall Device
  • Configuring for Local Ethernet
    • Configuring Standalone for Middleware/LIS on Local Ethernet
Note: DxI 9000 Host Manual C87417 is available for download from beckmancoulter.com. Registration is required.
