Installing the Check Valve

This topic includes information about how to install the check valve for the pneumatics system.

Important: The instrument must be powered down and disconnected from the power source before you perform this procedure. See Turning Off the Instrument for more information.

Safety Reminder

Servicing the DxI 9000 instrument involves potential risks for pinch and puncture, electrical shock, and exposure to hazardous materials. You must mitigate these risks by taking appropriate countermeasures. See Safety for more information.

Recommended Tools

The following tools are recommended for replacement of the components listed in this topic:
  • 2.5mm hex driver for M3 screws
  • 3mm hex driver for M4 screws

Installing the Check Valve

Installation: Follow these steps to install the Check Valve.

  1. Locate the tubing marked Compressor and Check Valve.
  2. Connect the end marked Check Valve to the inlet of the CHECK VALVE, COMPRESSOR.
  3. Locate the tubing marked Check Valve and Shuttle Valve.
  4. Connect the end marked Check Valve to the outlet of the Check Valve.
    Note: Ensure the Check Valve/Shuttle Valve tube is connected to the side of the Valve with the arrow pointing toward it.
  5. Secure QTY 2 C28593, TUBING CLAMPS, over the barbs of the Check Valve.

Making Adjustments

Make necessary adjustments (12psi, 20psi, and 32psi/H.A.) for affected components and subsystems.

Running the Bulk Feeder Exerciser

  1. Turn on the instrument. See Turning On the Instrument for more information.
  2. Initialize the instrument. See Initializing the Instrument for more information.
  3. In the Console App run the Vessel Exerciser, Bulk Feeder, for 100 reps.
    1. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
    2. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
    3. Select Exerciser to open the Exerciser page.
    4. Select RV Feeder.
    5. Type 100 in the Repetition box.
    6. Select Request.
  4. Confirm that you observe no errors for low system pressure.

Verification

Complete the verification of service repair. See Verification of Service Repairs for more information.
