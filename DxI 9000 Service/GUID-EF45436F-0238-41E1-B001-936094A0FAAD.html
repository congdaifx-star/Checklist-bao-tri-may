Enabling or Disabling a Reagent Pipettor

This topic includes information about how to enable or disable a reagent pipettor.

Note: See On-board Dilution (OBD) Assays and Reagent Pipettor Pairings for more information about which reagent pipettors are used for on-board dilution (OBD) assays.

Disabling a Reagent Pipettor

Note: Before you disable a reagent pipettor, be sure the system is not due for a scheduled automatic substrate priming, because a single disabled reagent pipettor will block test execution. After you disable a reagent pipettor, you must re-enable the pipettor to allow the system to complete the scheduled priming before resuming operations.
Note: Disabling reagent pipettors should only be used as a temporary countermeasure to keep a system running before a service repair to an inoperable pipettor. Disabling pipettors will impact throughput and dilution capabilities and will interfere with running of ASD. Do not use this feature as a method to run assays on a specific pipettor.
  1. In the Console App go to MENU > System Configuration to open the System Configuration page.
  2. Go to Analyzer Configuration > Analyzer Configuration to open the Analyzer Configuration page.
  3. Select Disabled for the desired pipettor to be disabled.
  4. Go to System Configuration.
  5. Select Activate.
  6. Enter comments and select OK.
  7. The notification The Configuration was Updated Successfully will be displayed. Select OK.
  8. Perform a Force Reinitialization of the system. See Initializing the Instrument for more information.
    Note: If you do not perform the Force Reinitialization, the pipettor will remain enabled.

Enabling a Reagent Pipettor

  1. In the Console App go to MENU > System Configuration to open the System Configuration page.
  2. Go to Analyzer Configuration > Analyzer Configuration to open the Analyzer Configuration page.
  3. Select Enabled for the pipettor that needs to be enabled.
  4. Go to System Configuration.
  5. Select Activate.
  6. Enter comments and select OK.
  7. The notification The Configuration was Updated Successfully will be displayed. Select OK.
  8. Perform a Force Reinitialization of the system. See Initializing the Instrument for more information.
    Note: If you do not perform the Force Reinitialization, the pipettor will remain disabled.
