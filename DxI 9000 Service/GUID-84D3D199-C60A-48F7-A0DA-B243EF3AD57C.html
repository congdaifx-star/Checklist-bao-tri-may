Calibrating the Ultrasonics Transducers

This topic includes information about how to calibrate the reagent pipettor ultrasonics transducers.
Note: If the calibration fails or if there is a voltage failure, troubleshoot the failure. See Troubleshooting the Ultrasonics Transducer for more information.

Safety Reminder

Servicing the DxI 9000 instrument involves potential risks for pinch and puncture, electrical shock, and exposure to hazardous materials. You must mitigate these risks by taking appropriate countermeasures. See Safety for more information.

Draining the Reagent Pipettors of Fluid

Perform this procedure to drain the reagent pipettors of fluid.

  1. Remove the reagent storage module (RSM) nest cover.
  2. Remove reagent packs from reagent pipettor nest positions.
  3. In the Machine Control App go to MENU > Prototype Alignment to open the Prototype Alignment page.
  4. Position the reagent pipettors for draining.
    1. Go to Reagent Pipettor 1 > Reagent Pipettor 1 to Reagent Storage for vertical adjustment.
    2. Select Move To Position.
    3. Go to Reagent Pipettor 2 > Reagent Pipettor 2 to Reagent Storage for vertical adjustment.
    4. Select Move To Position.
    5. Go to Reagent Pipettor 3 > Reagent Pipettor 3 to Reagent Storage for vertical adjustment.
    6. Select Move To Position.
    7. Go to Reagent Pipettor 4 > Reagent Pipettor 4 to Reagent Storage for vertical adjustment.
    8. Select Move To Position.
  5. Disable the reagent pipettors.
    1. Go to Reagent Pipettor 1 > Reagent Pipettor 1 to Reagent Storage for vertical adjustment.
    2. Select Disable All to clear all Enable Motor checkboxes.
    3. Go to Reagent Pipettor 2 > Reagent Pipettor 2 to Reagent Storage for vertical adjustment.
    4. Select Disable All.
    5. Go to Reagent Pipettor 3 > Reagent Pipettor 3 to Reagent Storage for vertical adjustment.
    6. Select Disable All.
    7. Go to Reagent Pipettor 4 > Reagent Pipettor 4 to Reagent Storage for vertical adjustment.
    8. Select Disable All.
  6. Place a kimwipe or similar absorbant material on top of the reagent nest positions.
  7. Enable the reagent pipettors.
    1. Go to Reagent Pipettor 1 > Reagent Pipettor 1 to Reagent Storage for vertical adjustment.
    2. Select Enable All to select all Enable Motor checkboxes.
    3. Go to Reagent Pipettor 2 > Reagent Pipettor 2 to Reagent Storage for vertical adjustment.
    4. Select Enable All.
    5. Go to Reagent Pipettor 3 > Reagent Pipettor 3 to Reagent Storage for vertical adjustment.
    6. Select Enable All.
    7. Go to Reagent Pipettor 4 > Reagent Pipettor 4 to Reagent Storage for vertical adjustment.
    8. Select Enable All.
  8. Drain the reagent pipettors of fluid.
    1. Remove the fluidics tubing by disconnecting the plastic fitting on the side of the transducer.
      Note: Some residual fluid may leak from the end of the fluid tubing so wrap it with a kimwipe or paper towel to ensure nothing drips into the instrument.
    2. Allow the transducer and probe tip to drain for five minutes before proceeding with the calibration steps.
    3. Clear and clean any debris from the tube fittings and from the transducer tube hole.
    4. If there is a kink or damage, replace the tube fitting.
    5. If you are calibrating the ultrasonics transducer, leave the fluidics tubing disconnected. Otherwise, be sure the tubing is completely dry and free of fluids and reconnect the tubing to the transducer.

Homing the Reagent Pipettors

Perform this procedure to home the reagent pipettors.

  1. In the Machine Control App go to MENU > Prototype Alignment to open the Prototype Alignment page.
  2. Go to Reagent Pipettor 1 > Reagent Pipettor 1 to Reaction Build Carriage 1.
  3. Select Home All.
  4. Go to Reagent Pipettor 2 > Reagent Pipettor 2 to Reaction Build Carriage 2.
  5. Select Home All.
  6. Go to Reagent Pipettor 3 > Reagent Pipettor 3 to Reaction Build Carriage 3.
  7. Select Home All.
  8. Go to Reagent Pipettor 4 > Reagent Pipettor 4 to Reaction Build Carriage 4.
  9. Select Home All.
  10. Return the reagent packs to their reagent pipettor nest positions.
  11. Place the reagent storage module (RSM) nest cover back into position.

Calibrating the Ultrasonics Transducers

Perform this procedure to calibrate the reagent pipettor ultrasonics transducers.
Note: Before you calibrate the transducers, you must drain the reagent pipettors of fluid. You must then home the reagent pipettors. See the following subtopics for more information:
  • Draining the Reagent Pipettors of Fluid
  • Homing the Reagent Pipettors
  1. In the Machine Control App go to MENU > Machine Control > ReagentPipettor_1 > ReagentPipettor_1.Assembly > ReagentPipettor_1.Ultrasonics.
    1. On the Action tab select Calibrate.
    2. Select Execute.
      • If the message box displays the notification ReagentPipettor_1.Ultrasonics - DeviceStatus(Ok), the reagent pipettor ultrasonics transducer calibrated successfully.
      • If the message box displays an error message, troubleshoot the ultrasonics transducer. See Troubleshooting the Ultrasonics Transducer for more information.
    3. Select GetCalibrated.
    4. Select Execute.
      • If calibrated is selected, the reagent pipettor ultrasonics transducer calibrated successfully.
      • If calibrated is cleared, the reagent pipettor ultrasonics transducer did not calibrate successfully. Calibrate the ultrasonics transducer again. If repeated attempts to calibrate the transducer fail, troubleshoot the ultrasonics transducer. See Troubleshooting the Ultrasonics Transducer for more information.
    5. Select PutPowerLevel.
    6. In the level box type 4.
    7. Select Execute.
    8. For the following steps, be sure that no more than 10 seconds elapse from the time you select Execute for the Lock command to the time you select Execute for the GetProbeVoltage command.
      1. Select Lock.
      2. Select Execute.
      3. Select GetProbeVoltage.
      4. Select Execute.
        • If the volts box displays a number in the range of 192 to 202, the voltage is within specification.
        • If the volts box displays a number outside the range of 192 to 202, the voltage is not within specification. Calibrate the ultrasonics transducer again. If repeated attempts to calibrate the transducer fail, troubleshoot the ultrasonics transducer. See Troubleshooting the Ultrasonics Transducer for more information.
    9. Select DisablePower.
    10. Select Execute.
    11. Reconnect fluidics tubing.
  2. Repeat the previous step for the remaining three ultrasonics transducers:
    • ReagentPipettor_2.Ultrasonics
    • ReagentPipettor_3.Ultrasonics
    • ReagentPipettor_4.Ultrasonics
  3. Return the reagent packs to their reagent pipettor nest positions.
  4. Place the reagent storage module (RSM) nest cover back into position.
