dMCC Printed Circuit Board (PCB) Layout

This topic includes information about the locations and features of the DxI 9000 dMCC printed circuit board (PCB).

Cable Connections

Location Function Notes
J1 Motor 0 drive signal

4 wires for motor + a jumper wire.

Jumper wire defines if motor runs at 24V or 58V

J2 Motor 1 drive signal

4 wires for motor + a jumper wire.

Jumper wire defines if motor runs at 24V or 58V

J3 Motor 2 drive signal

4 wires for motor + a jumper wire.

Jumper wire defines if motor runs at 24V or 58V

J4 Motor 3 drive signal

4 wires for motor + a jumper wire.

Jumper wire defines if motor runs at 24V or 58V

J5 4 independently controlled 24V Outputs Example uses: solenoid valves, vacuum pumps
J6 Power input 24V (Purple), 58V (Pink), and Ground (Black)
J7 USB cable port Connects board back to USB Hub network
J8 Input / Output Expansion Supports 3x inputs and 12x 5V outputs
J9 Channel 3 Input Signals Supports 3x inputs and encoder for motor 3
J10 Channel 2 Input Signals Supports 3x inputs and encoder for motor 2
J11 Channel 1 Input Signals Supports 3x inputs and encoder for motor 1
J12 Channel 0 Input Signals and board address jumper(s)

Supports 3x inputs and encoder for motor 0

Jumper wire(s) define board address

J13 DAQC Trigger Triggers data collection for some sensors on the Data Acquisition Card (DAQC)
J14 JTAG Used to program firmware. Requires special tool to plug into it. Intended for development use.

LEDs

Location

Function

Notes

D1, D2, D3 Channel 0 Inputs

Typical operation:

  • LED off = device at home position

  • LED on = device not at home position

Will blink when sensor flag is moved in and out of the sensor

D4, D5, D6 Channel 1 Inputs

Typical operation:

  • LED off = device at home position

  • LED on = device not at home position

Will blink when sensor flag is moved in and out of the sensor

D7, D8, D9 Channel 2 Inputs

Typical operation:

  • LED off = device at home position

  • LED on = device not at home position

Will blink when sensor flag is moved in and out of the sensor

D10, D11, D12 Channel 3 Inputs

Typical operation:

  • LED off = device at home position

  • LED on = device not at home position

Will blink when sensor flag is moved in and out of the sensor

D13, D14, D15 Input / Output Expansion Inputs

Typical operation:

  • LED off = device at home position

  • LED on = device not at home position

Will blink when sensor flag is moved in and out of the sensor

D16 USB signal Receive (RX) Blinks when data is being transmitted from host computer to dMCC via USB
D17 USB signal Transmit (TX) Blinks when data is being transmitted to host computer from dMCC via USB
D18, D20, D27, D30 Motor Status 0, 1, 2, 3

  • LED on = there is an issue with the motor driver chip. Typically due to a motor cable being shorted to the chassis (ground) or incorrect voltage coming to dMCC

LED off = normal operation

D19 General Status

  • LED on = dMCC powered on but has not been communicated with yet

LED off = normal operation

D21 5V Power Supply signal

  • LED on = 5V power supply active

  • LED off = 5V power supply inactive

5V is regulated on the dMCC from 24V_Logic (TP1)

D23 24V Power Supply signal

  • LED on = 24V power supply active

  • LED off = 24V power supply inactive

24V enters the dMCC via J6

D40 58V Power Supply signal

  • LED on = 58V power supply active

  • LED off = 58V power supply inactive

24V enters the dMCC via J6

D24, D25, D28, D29 24V Output 0, 1, 2, 3

  • LED on = 24V output enabled

LED off = 24V output disabled

Test Points

Location

Function

Notes

TP1 24V Logic power

Should provide +24V signal to DMM

Used to power microcontroller and other logic components

TP2 24V power

Should provide +24V signal to DMM

Used to drive motors

TP3 5V power

Should provide +5V signal to DMM

Regulated down from 24V logic

TP4 58V power

Should provide +58V signal to DMM

Used to drive motors

TP5, TP6 Ground Use as a ground when connecting to other test points
