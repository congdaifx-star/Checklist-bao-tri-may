Replacing the Presentation Tray Home Sensor

This topic includes information about how to replace the home sensor in the sample presentation unit (SPU) tray components.

Safety Reminder

Servicing the DxI 9000 instrument involves potential risks for pinch and puncture, electrical shock, and exposure to hazardous materials. You must mitigate these risks by taking appropriate countermeasures. See Safety for more information.

Recommended Tools

The following tools are recommended for replacement of the components listed in this topic:
  • 2.5mm hex driver (for M3 screws)
  • 3mm hex driver (for M4 screws)
  • 4mm hex driver (for M5 screws)

Removing the Presentation Tray Home Sensor

Perform this procedure to remove the presentation tray home sensor.

  1. Open the rear instrument door(s) to gain access to the rear of the presentation tray subsystem.
  2. Disconnect the home sensor cable from the extension cable.
  3. Remove the two screws (2.5mm driver) securing the home sensor to the frame and remove the home sensor.

Installing the Presentation Tray Home Sensor

Perform this procedure to Install the presentation tray home sensor.

  1. Install the home sensor onto the frame and secure with two screws (2.5mm driver).
  2. Connect the home sensor cable to the extension cable.

Alignments

Perform alignments. See Aligning the Sample Presentation Unit (SPU) for more information.

Verification

Complete the verification of service repair. See Verification of Service Repairs for more information.
