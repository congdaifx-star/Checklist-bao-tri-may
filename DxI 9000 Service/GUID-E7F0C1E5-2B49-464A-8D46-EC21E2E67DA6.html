Troubleshooting the PVDR Precision Pipettor Wrong Volume DV to RV Flag

If the system displays the PVDR flag, the precision sample pipettor camera detected that an incorrect volume of fluid was delivered from the dilution vessel (DV) to the reaction vessel (RV) during dilution.

Table of Contents
Troubleshooting the PVDR Flag:
Analyzing the Related Test Files

Troubleshooting the PVDR Flag:

  1. Be sure the precision sample pipettor is not interfering with the reflector.
  2. Be sure the reflector and the mandrel are not scratched, bent, or slanted.
  3. Be sure the precision sample pipettor cameras have been calibrated. See Calibrating Cameras for more information.
  4. Be sure the precision sample pipettor has been aligned. See Aligning the Precision Sample Pipettor for more information.
  5. Be sure the tubing is not kinked or damaged.

Analyzing the Related Test Files

  1. Export the results of the test for further analysis. See Exporting Results to Disk for more information.
  2. Open the export file and check the values in the file.
    • If Volume Vb in “AfterAspirationFromDVVolume[uL](Vb)” is an extremely negative value (nearly -600) and if Volume Vc in “AfterDispensingToRVVolume[uL](Vc)” is an extremely negative value (nearly -800), there is no meniscus in the RV.
    • If neither Volume Vb nor Volume Vc are extremely negative, the measured volume is incorrect or the monitoring system falsely located a meniscus.
  3. Use the following information to calculate the accuracy of the measurement and to determine the failure(s):

    Delivery volume: “PSPActualVbVc[uL]” -- > Vactual
    Target volume: “PSPTargetVbVc[uL]” -- > Vtarget
    Accuracy= (Vactual-Vtarget/Vtarget*100
    Specification [uL][%]
    2≤ Volume <10 ± 30
    10≤Volume <20 ± 15
    20≤Volume ≤100 ± 12

  4. Check the volumes in the cells ”AfterAspirationFromDVVolume[ul](Vb)” and “AfterDispensingToRVVolume[uL](Vc)” to see whether the error occurred after aspiration from the DV or after dispense to the RV. Typical values (not specifications) are:

    Vb Vtarget +/- 10% + 5uL
    Vc 4 to 8 uL
