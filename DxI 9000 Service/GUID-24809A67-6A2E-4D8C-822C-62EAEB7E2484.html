Calibrating the Pressure Sensor for the Aliquot Sample Pipettor

This topic includes information about how to calibrate the pressure sensor for the aliquot sample pipettor.

Table of Contents

Prepare the Instrument for Pressure Sensor Calibrations

Perform the following procedure before you calibrate a pressure sensor.

  1. Perform necessary alignments.
  2. Be sure there is enough substrate in the instrument to prime the instrument and to perform the calibrations.
  3. Be sure there is adequate wash buffer in the instrument to perform the calibrations.
  4. Be sure there are enough tips to perform the calibrations.
  5. Be sure there are enough reaction vessels (RVs) to perform the calibrations.
  6. Initialize the instrument. See Initializing the Instrument for more information.
    Note: Priming specific to initialization may require several minutes to complete, especially if the instrument has been inactive for an hour or more.
  7. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  8. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  9. Prime the instrument.
    Note: When you prime the instrument, only select to prime Reagent Pipettor 1 for 5 cycles. (The calibration only uses reagent pipettor 1.) Wait approximately nine minutes for priming to complete. See Priming the Instrument for more information.

Calibrate the Pressure Sensor

  1. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics > Pressure Monitor Calibration to open the Pressure Monitor Calibration page.
  2. In the PRESSURE MONITOR column select the Aliquot Sample Pipettor checkbox.
    Note: If you are calibrating a pressure sensor for a previously failed calibration, only select the checkboxes for the pressure monitors that failed calibration.
  3. Select Start Pressure Monitor Calibration.
    Note: Wait approximately 25 minutes for the calibration to achieve the Pass result. A Fail result may occur at any time within the duration. If the system displays the APO flag, see Troubleshooting the APO Aliquot Pipettor Obstruction (High Pressure) Flag for more information about how to troubleshoot the issue.
  4. If the calibration succeeds:
    1. The notification Operation completed: Pressure Calibration will be displayed in the STATUS area.
    2. Pass will be displayed in the RESULT column.
    3. Today will be displayed in the LAST CALIBRATION column.
  5. Go to Intrusive Diagnostics.
  6. Select End Session.
