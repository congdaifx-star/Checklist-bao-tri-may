Performing the System Carryover ASD Test

This topic includes information about performing the System Carryover Automated System Diagnostics (ASD) test, which tests the carryover of the reagent pipettors.

Note: It is recommended to run Substrate Blank ASD first, followed by Wash Efficiency ASD. The order of running Low Volume Pipetting, System Carryover, or Precision Sample Pipetting ASD is interchangeable.

System Carryover ASD Test Overview

This ASD runs 5 replicates of 929, ASD Sys Carryover Cold, followed by 1 replicate of 930, ASD Sys Carryover Hot, followed by 5 replicates of 929, ASD Sys Carryover Cold, specifically in that order on the reagent pipettor specified.

For each ASD Sys Carryover Cold:
  • An RV is retrieved from the RV supply carriage and moved to the specified RBC.
  • The reagent pipettor dispenses 100 uL of wash buffer into the RV.
  • The RV is moved to the wash wheel, but no washing occurs. The RV moves around the wash wheel under normal scheduling, waiting 8 seconds at each position.
  • At the end of the wash wheel, the vessel receives 200 uL of substrate.
  • The RV is moved to the incubate wheel for the 48 second substrate incubation time.
  • The RV is moved to the Luminometer and a reading is recorded. (This is the official end of the timer on the Console screen).
  • The RV is removed from the Luminometer and discarded (Lumi -> incubate wheel -> solid waste).
For the ASD Sys Carryover Hot:
  • An RV is retrieved from the RV supply carriage and moved to the specified RBC.
  • The reagent pipettor retrieves 40uL of ASD system check from the ASD pack and dispenses this into the RV, followed by 60uL of wash buffer.
  • The RV is moved to the incubate wheel for a 32 second incubation time.
  • The RV is moved to the Luminometer and a reading is recorded. (This is the official end of the timer on the Console screen).
    Note: This vessel received no substrate, this reading will be only the dark count, which should be less than 300 RLUs.
  • The RV is removed from the Luminometer and discarded (Lumi -> incubate wheel -> solid waste).

Once all replicates are complete, a SpecialProbeClean runs on each of the pipettors, removing any residual system check. These take ~4.5 minutes to complete.

Note: The specified order creates three groups of results based on where in the process the cold replicate was run.
  • The cold replicates before the hot replicate are used for the Baseline.
  • The cold replicate immediately after the hot replicate is used for Carryover.
  • The cold replicate after the Carryover replicate is used for Recovery.

This diagnostic takes ~15 minutes to complete for each pipettor, 11 minutes for the diagnostic itself and an additional 4 minutes for the probe cleans, as they will not start until the other replicates are completed due to the specified ordering or the replicates.

Parameters Acceptance RLU

Baseline

Median RLU ≤ 5000 RLUs

Carryover

4.1 ≤ Log10 of RLUs ≤ 6.3

Recovery

RLUs ≤ 18000

Requirements

  • System software version 1.14 or greater
  • Automated System Diagnostic (ASD) Reagent Pack C23913 is loaded onto the system
  • Associated RAPID files for running this test:
    • ASD Sys Carryover Cold (929)
    • ASD Sys Carryover Hot (930)
  • Be sure all reagent pipettors are enabled.

Performing the Test

  1. Be sure the instrument is in a GREEN (Ready) status.
  2. In the Console App go to MENU > Tools > ASD Tests to open the ASD Tests page.
  3. Select System Carryover: Reagent Pipettor # where # corresponds to the pipettor to be tested.
    Note: You may select multiple pipettors/tests.
  4. Select Order Diagnostics.
    Note: The system will prioritize patient, calibration, and QC samples over ASD tests, so the requested test may remain queued if other samples are being processed.
  5. The notification Completed will be displayed in the Status column when the test is complete.
  6. The notification Pass will be displayed in the Pass / Fail column when the test passes.

Reviewing the Results

  1. On the ASD Tests page select System Carryover: Reagent Pipettor # where # corresponds to the pipettor results to be reviewed.
  2. Select Details.
  3. To view details for a specific test, in the Summary area in the Details column select View.
  4. If you need to troubleshoot the test results, capture a screenshot of the page and then proceed with troubleshooting. See Troubleshooting Automated System Diagnostics (ASD) Test Results for more information.
