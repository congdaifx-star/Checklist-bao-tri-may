Determining the MAC Address for the eth4 Port

This topic includes information about how to determine the MAC address for the eth4 port on the DxI 9000 instrument if the customer needs the MAC address for whitelisting.

  1. Access the EdgeMax router dashboard. See Accessing the EdgeMax Router Dashboard for more information.
  2. Select CLI to open the command line interface.

  3. You will be prompted to login. Type the following username and password:

    DxI9000 login: BeckmanAdmin

    Password: CoulterAdmin20!

  4. Type show interfaces ethernet eth4 and press Enter. The MAC address will be displayed.
