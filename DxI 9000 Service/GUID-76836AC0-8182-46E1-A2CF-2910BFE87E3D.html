Performing the Wash Efficiency ASD Test

This topic includes information about performing the Wash Efficiency Automated System Diagnostics (ASD) test, which tests the washing performance (mixing, aspiration, and dispense) of the system.

Note: It is recommended to run Substrate Blank ASD first, followed by Wash Efficiency ASD. The order of running Low Volume Pipetting, System Carryover, or Precision Sample Pipetting ASD is interchangeable.

Wash Efficiency ASD Test Overview

This ASD runs 10 replicates of RAPID 927, ASD-3Wash-Eff on all 4 pipettors.

In each replicate:
  • An RV is retrieved from the RV supply carriage and moved to an RBC.
  • The reagent pipettor retrieves 100uL of ASD system check with a bottom draw from the ASD pack, with a 10uL overdraw and places the 100uL of ASD system check in the RV.
  • The reagent pipettor is washed as normal after a pack interaction, discarding the 10uL of overdraw.
  • The RV is mixed with the ultrasonics on the reagent pipettor.
  • The RV is moved to the incubate wheel and incubated for 32 seconds.
  • The RV is moved to the wash wheel.
  • The RV is washed by dispensing wash buffer to 500 uL, then aspirating and washing as normal.
  • At the end of the wash wheel, the now "empty" vessel receives 200 uL of substrate.
  • The RV is moved to the incubate wheel for the 48 second substrate incubation time.
  • The RV is moved to the Luminometer and a reading is recorded. (This is the official end of the timer on the Console screen).
  • The RV is removed from the Luminometer and discarded (Lumi -> incubate wheel -> solid waste).
  • Once all replicates are complete, a SpecialProbeClean runs on each of the pipettors, removing any residual system check, which takes ~4.5 minutes to complete, but begins during the process of the wash efficiency diagnostic.

This diagnostic takes ~7 minutes to complete.

Acceptance RLU

Minimum RLU: 11000 RLU

Maximum RLU: 284000 RLU

Minimum Mean RLU: 13000 RLU

Maximum Mean RLU: 123000 RLU

Requirements

  • System software version 1.11 or greater
  • Automated System Diagnostic (ASD) Reagent Pack C23913 is loaded onto the system
  • Associated RAPID files for running this test:
    • ASD-3Wash-Eff (927)
  • Be sure all reagent pipettors are enabled.

Performing the Test

  1. Be sure the instrument is in a GREEN (Ready) status.
  2. In the Console App go to MENU > Tools > ASD Tests to open the ASD Tests page.
  3. Select Wash Efficiency.
    Note: You may select multiple ASD tests.
  4. Select Order Diagnostics.
    Note: The system will prioritize performing patient, calibration, and QC samples over ASD tests, so the requested test may remain queued if other samples are being processed.
  5. The notification Completed will be displayed in the Status column when the test is complete.
  6. The notification Pass will be displayed in the Pass / Fail column when the test passes.

Reviewing the Results

  1. On the ASD Tests page select Wash Efficiency.
  2. Select Details to open the ASD History page.
  3. To view details for a specific test, in the Summary area in the Details column select View.
  4. If you need to troubleshoot the test results, capture a screenshot of the page and then proceed with troubleshooting. See Troubleshooting Automated System Diagnostics (ASD) Test Results for more information.
