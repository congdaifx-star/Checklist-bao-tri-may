Manually Homing the RSM Gripper Assembly

This topic includes information about how to troubleshoot issues with the Reagent Storage Module (RSM) by manually homing the RSM Gripper Assembly.

Safety Reminder

Servicing the DxI 9000 instrument involves potential risks for pinch and puncture, electrical shock, and exposure to hazardous materials. You must mitigate these risks by taking appropriate countermeasures. See Safety for more information.

To manually home the RSM Gripper Assembly:

  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Disable the Interlock System that controls the Instrument cover locks. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  3. In the Console App go to Menu > Tools > Diagnostics to open the Diagnostics page.
  4. Select Initialize.
  5. Go to Diagnostics.
  6. Select Service Diagnostics.
  7. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  8. Select Start Session to enter the instrument into a BLUE (Maintenance) status.
  9. Open the Sample Presentation Unit (SPU) cover.
  10. Push the carriage back into the Instrument so that it does not interfere with the swing arm.
  11. To open the swing arm, grab the SPU handle located underneath the middle portion of the SPU, pull the SPU toward you (approximately six inches), and then pivot the right side out and to the left.
  12. Remove the RSM cover and door.
  13. Verify there is no reagent pack in the gripper.
  14. Clear any offset or jammed reagent packs from the RSM main storage area.
  15. Clear any offset reagent packs from the Reagent Loader in the RSM.
  16. Remove reagent packs from the RSM.
  17. Close the cover.
  18. In the Machine Control App go to Menu > Machine Control > ReagentLoader > ReagentLoader.Assembly.
  19. On the Action tab select HomeTray.
  20. Select Execute.
  21. Inspect the RSM waste door to ensure no reagent packs are stuck in the waste trap. If there is a reagent pack in the gripper, or if the gripper is closed without a pack in the gripper, physically remove the pack (if present) and then remove the pack from its associated RSM passenger listing in Machine Control.
  22. Go to ReagentStorage > ReagentStorage.Assembly.
  23. On the Action tab select OpenGripper.
  24. Select Execute.
    • If the OpenGripper command fails, there may not be enough air pressure in the pneumatic line. Therefore, you must reset the pneumatic compressor.
    1. Go to Chassis > Chassis.Pneumatics.
    2. On the Action tab select the Set Compressor check box.
    3. Select Execute to turn on the compressor with no modulation.
    4. Go to Chassis > Chassis.Pneumatics.
    5. On the Action tab clear the Set Compressor check box.
    6. Select Execute to turn off the compressor.
    Note: If the problem persists, you may need to complete the gripper timing calibration procedure in a later step. Therefore, you must now temporarily unload all reagent packs from the RSM and tray loader and place them in an external refrigerator to prevent compromising the stability of the packs.
  25. Physically remove all packs from RSM and tray loader.
  26. Remove all packs from passenger listings in ReagentLoader and ReagentStorage.
    1. Go to ReagentStorage.
    2. On the Passengers tab select the pack to remove.
    3. Select Remove Passenger.
    4. Go to ReagentLoader.
    5. On the Passengers tab select the pack to remove.
    6. Select Remove Passenger.
    Note: You must remove passengers from the list individually. There is no method to remove more than one passenger at a time from the list.
  27. Grab hold of the RSM gripper and carefully guide it to the far lower left home position.
  28. If there is no tension on either the X or Z axis, there may be a lack of supply voltage. Therefore, you must
    1. Manually home the RSM gripper assembly with the gripper arms in the open position.
    2. Home the RSM loader.
  29. Go to ReagentLoader > ReagentLoader.Assembly.
  30. On the Action tab select HomeTray.
  31. Select Execute.
  32. Close the RSM Door.
  33. Close the SPU swing arm.
  34. Turn off the instrument and turn on the instrument to reset any lost voltage to the motor control board. See Turning Off the Instrument and Turning On the Instrument for more information.
  35. Start a Diagnostic Session
    1. In the Console App go to Menu > Tools > Diagnostics to open the Diagnostics page.
    2. Select Initialize.
    3. Select Force Initialization, Perform Full Consolidation, Perform Cleanout, and Remap Reagent Refrigerator.
    4. Select Initialize.
  36. Set the motor position from the encoders for both the X and Z motors.
    1. In the Machine Control App go to Menu > Machine Control > ReagentStorage > ReagentStorage.Assembly > PositionerXAxis.
    2. On the Action tab select SetMotorPositionFromEncoder.
    3. Select Execute.
    4. Go to ReagentStorage > ReagentStorage.Assembly > PositionerYAxis.
    5. On the Action tab select SetMotorPositionFromEncoder.
    6. Select Execute.
  37. While the gripper is in the home position and with the gripper arms open, execute the following commands to home the gripper assembly.
    1. Go to ReagentStorage > ReagentStorage.Assembly.
    2. On the Action tab select OpenGripper.
    3. Select Execute.
    4. Go to ReagentStorage > ReagentStorage.Assembly.
    5. On the Action tab select HomeGripper.
    6. Select Execute.
    7. Go to ReagentStorage > ReagentStorage.Assembly.
    8. On the Action tab select ReagentStorageWateDoor.Ejector.
    9. Select state.
    10. Select Execute.
    11. Go to ReagentStorage > ReagentStorage.Assembly.
    12. On the Action tab select ReagentStorageWateDoor.Ejector.
    13. Clear state.
    14. Select Execute.
      Important: Be sure the waste door is in the closed position.
  38. Perform alignments as needed.
  39. Replace the RSM door.
  40. Replace the RSM cover.
  41. Close SPU swing arm.
  42. Remap the RSM.
    1. In the Console App go to Menu > Tools > Diagnostics to open the Diagnostics page.
    2. Select Initialize.
    3. Select Force Initialization, Perform Full Consolidation, Perform Cleanout, and Remap Reagent Refrigerator.
    4. Select Initialize.
  43. Be sure the instrument is in a GREEN (Ready) status.
  44. If necessary, calibrate the gripper timing. See Calibrating Gripper Timingfor more information.
  45. Reload the reagent packs using the reagent loader.
  46. Verify the RSM storage and RSM loader passenger listings are correct.
  47. Sign out of the BeckmanAdmin user account.
  48. Sign in to use the LabUser account. If the notification You cannot have more than one instance of this application running at the same time is displayed, select OK and take one of the following actions:
    • If the message appeared after you signed in to use the BeckmanAdmin account
      1. Right-click the Windows taskbar and select Task Manager to open Task Manager.
      2. On the Details tab, right-click ICEexecutive.exe and select End Task.
      3. Select and open each app from the Desktop or select the Windows icon, select Programs, and select Beckman Coulter Machine Control and Console App
      .
    • If the message appeared after you signed in to use the LabUser account, restart the instrument and sign in to use the LabUser account again.
  49. Enable the interlock system that controls the instrument cover locks. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  50. Close the interlock switch cover.
