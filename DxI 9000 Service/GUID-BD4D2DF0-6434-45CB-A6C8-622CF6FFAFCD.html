Backing Up Alignment and Configuration Data

About this Process

This process creates a minimal backup of key system files. The backup generally includes settings and alignments, but not customer data. It is not intended to backup customer data like curves, QC, or patient results.

Note: For more information about how this and other processes interact with backups and settings files, see Process Interactions with Data Files and Databases.

Backing Up Alignment and Configuration Data

Perform this procedure to back up alignment and configuration data.

  1. In the Console App go to MENU > Tools > Diagnostics > Nonintrusive Diagnostics > Backup to open the Backup page.
  2. Select Backup. The system will save a .backup file in the D:\Backups\ folder.
