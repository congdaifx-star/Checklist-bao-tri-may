Troubleshooting the Printer Not Printing

This topic includes information about how to troubleshoot the printer when it is not printing as expected.

Troubleshooting the Printer Not Printing

Perform this procedure to troubleshooting an issue with the printer not printing.

  1. Determine whether the printer is properly configured for direct or network printing. See Installing the Lexmark Printer for Printing on a Local Private Network and Configuring Printing for Customer Network Printers for more information.
  2. View and resolve any messages displayed on the Lexmark printer's control panel (e.g. paper jam, toner issue, etc.)
  3. Restart the print spooler.
    • If you are signed in to use the LabUser account, you can restart the PC to restart the print spooler. See Restarting the Console PC for more information.
    • If you are signed in to use the BeckmanAdmin account, you can use the Services window to restart the print spooler without having to restart the PC.
      1. Press the Windows key and type Services to open the Services window.
      2. Select Services to view the list of services.
      3. On the Standards tab right-click Print Spooler and select Restart.
      4. Close the Services window.
  4. Attempt to print to be sure printer functionality has been restored.
