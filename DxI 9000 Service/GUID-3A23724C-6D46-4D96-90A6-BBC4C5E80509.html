Luminometer Diagnostics Overview

This topic includes information about luminometer diagnostics, including drift detection and linearity testing.

Table of Contents
Drift Detection
Linearity Testing

Drift Detection

Drift detection checks and corrects for gradual changes in the instrument's performance over time. Drift detection checks for differences between actual relative light unit (RLU) values versus target values.
  • If the difference between the actual and target values is greater than two percent (2%), the instrument will automatically perform LED points and linear response calibrations. The instrument will check again for differences between actual and relative RLU values, and if the difference is still greater than two percent (2%), the system will automatically perform a photomultiplier (PMT) high voltage calibration followed by LED points and linear response calibrations.
  • If the difference between the actual and target values is within two percent (2%), the instrument will automatically perform a PMT high voltage sweep to confirm the PMT high voltage calibration variable PMTDACCal is set to minimally impact RLU readings for the current run.
See Luminometer Calibrations Overview for more information.
The instrument automatically performs drift detection each day, or you can choose to perform drift detection or reset drift targets manually. See Performing Drift Detection and Resetting Drift Targets for more information.
Note: If you reset drift targets, you must recalibrate assays.

When you perform drift detection, the system saves data in the LuminometerDriftMeasurements.csv and LuminometerPMTHVCheck.csv files in the D:\ProgramData\Beckman Coulter\Falcon folder.

Linearity Testing

To be sure the luminometer is providing accurate, consistent readings across a range of light intensities, you can manually test the luminometer's linearity.

When you test linearity, the system will record RLU values along the operating range of the LED, with an equal number of points taken from the photon count and analog voltage regions. The system compares a linear regression plot against the original RLU values to determine whether there is a linear transition between the photon and analog readings. The difference between the linear regression plot and the recorded RLU values must be within two percent (2%). See Relative Light Unit (RLU) Calculations for more information.

If you service or replace the luminometer, you must test luminometer linearity. See Performing the Luminometer Linearity ASD Test for more information.

When you perform linearity testing, the system saves data in the LuminometerLinearity[date].csv and file in the D:\ProgramData\Beckman Coulter\Falcon folder.
