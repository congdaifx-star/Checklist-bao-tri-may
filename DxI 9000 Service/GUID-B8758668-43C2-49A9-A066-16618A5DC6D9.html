Configuring Printing for Customer Network Printers

This topic includes information about how to set up the instrument for printing on a network.
Important: To perform this procedure, the DxI 9000 instrument must be connected to the customer network.
Note: Not all Lexmark printers are compatible with all versions of the instrument software.
Software Version Compatibility
1.16 All Lexmark printer models
1.17 Lexmark printer model MS331 only
1.17.2 and newer Lexmark printer model MS331*
*Other Lexmark printers may work but have not been tested for compatibility

Installing the Printer for use with Windows

Perform this procedure to install the printer for use with Windows.

  1. If this is a new printer, follow the instructions included with the printer to prepare the printer for use.
  2. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  3. Plug in the printer power cord.
  4. Press the power button to turn on the printer.
  5. Follow the instructions in the Lexmark user manual to connect the printer to the network.
    Important: You will have to coordinate with local IT to verify the printer is connected to the network.
  6. Press the Windows key and type services.msc to open the Services application.
  7. Right-click Print Spooler and select Properties.
  8. Be sure the Startup Type is Automatic and the service status is Running. If necessary, select Start and select OK to start the service.
  9. Close the Services application.
  10. Press the Windows key and type settings to open the Settings application.
  11. Select Devices.
  12. Select Printers & Scanners.
  13. Select Add a printer or scanner. When the notification The printer that I want isn’t listed is displayed, select it to open the Add Printer dialog.
  14. Select Add a printer using an IP address or hostname.
  15. Select Next.
  16. Type the IP address that the local IT gave you for the network printer.
  17. Select Next. Wait for the printer to be recognized.
  18. Select the Lexmark option for the printer driver.
  19. Select OK.
  20. Be sure Do not share this printer is selected.
  21. Select Next.
  22. Select Print a Test Page to verify the printer is printing correctly.

    If the test page does not print, check the printer's user manual for troubleshooting steps. Repeat the steps above to reconnect the printer.

Configuring the Printer for the Instrument

Perform this procedure to configure the printer for the instrument.

  1. In the Console App go to MENU > System Configuration to open the System Configuration page.
  2. Go to Report Configuration > Printer to open the Detailed Report Settings page.

  3. For the page size select Letter.

  4. To add a printer destination:

    1. Select New to add a row to the Report Destinations area.

    2. For the TYPE select PRINTER.

      Select the Destination, which is the name of the printer connected to the instrument.

    3. Go to System Configuration.

      Select Activate.

  5. Select Print Screen.
    1. In the dialog, select the printer added above.
    2. Select Print. Be sure a page has printed.
  6. Update the Printing.prefs security settings in LabUser. This will allow all windows users to use the printer functions in Console.

Configuring Security Settings for Printing

Perform this procedure to configure security settings for LabUser to allow all Windows users to use the printer functions in the Console App.

  1. In File Explorer go to C:\ProgramData\Beckman Coulter\ICE\prefs\.
  2. Right-click the Printing.prefs file and select Properties.
  3. Select the Security tab.
  4. Select Edit.
  5. Select Users from the Group or user names box and select "Full Control" Allow so that all boxes are selected.
  6. Select Apply.
  7. Select OK to close the Permissions window.
  8. Select OK to close the Properties window.
