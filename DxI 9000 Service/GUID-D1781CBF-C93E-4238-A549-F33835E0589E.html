Aligning the Sample Presentation Unit (SPU)

This topic includes information about how to align the sample presentation unit (SPU).

Prerequisites

Before you begin an alignment procedure:
  • If you must make changes to the instrument's hardware, you must complete those changes before you prepare the instrument for adjustments and alignments.
  • You must verify that alignments have previously been completed on the instrument. To verify, in the Machine Control App go to Menu > Prototype Alignment to open the Prototype Alignment page and to verify the Finalize Instrument Alignments button is GRAY in color. If the button is BLUE in color, do not complete this procedure. Instead, you must first complete manual alignments.
  • You must first initialize the instrument to a GREEN (Ready) status to ensure all subsystems have been successfully initialized and homed. You must then enter the instrument into a BLUE (Maintenance) status.
Important: After you auto-align the SPU you must calibrate the SPU camera. See Calibrating the Sample Presentation Unit (SPU) Camera for more information.

Prepare the Instrument for Adjustments and Alignments

You must prepare the instrument for adjustments and alignments.

  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Disable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  3. Open all hoods and covers.
  4. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
    Note: If the instrument enters into a RED (Stopped) status:
    1. Verify the interlock switch is in the correct position.
    2. Be sure you are signed in to use the BeckmanAdmin account.
    3. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
    4. Complete all troubleshooting, adjustments, manual alignments, and maintenance necessary to be able to initialize the instrument to a GREEN (Ready) status.
  5. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.

Auto-Aligning the Sample Presentation Unit (SPU)

Perform this auto-alignment procedure to align the following components:
  • SPU Presentation to hard stop position
  • SPU Onload Pusher to hard stop position
  • SPU Presentation to SPU On-Load
Note: To establish successful alignment values, you must perform the alignments in the order given. After you complete the auto-alignments, the values will be saved automatically.
  1. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  2. In Machine Control App go to Menu > Prototype Alignment to open the Prototype Alignment page.
  3. Go to SPU Presentation > SPU Presentation to hard stop position.
  4. Select Auto Align.
  5. Go to SPU > SPU Onload Pusher to hard stop position.
  6. Select Auto Align.
  7. Go to SPU Presentation > SPU Presentation to SPU.
  8. Open the SPU onload cover.
  9. Place six empty racks in the on-load area of the SPU.
    Important: DO NOT close the SPU onload door, as this may trigger the SPU to attempt to process the racks.
  10. Select Auto Align.

Aligning the SPU Presentation Shuttle to Sample Pipettors

The rack presentation tray aligns to both sample pipettors, steps to perform alignment can be found in the referenced procedures:
  • Aligning the Aliquot Sample Pipettor
  • Aligning the Precision Sample Pipettor

Ending an Adjustments and Alignments Session

  1. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics.
  2. Select End Session.
  3. Close all hoods and covers.
  4. Enable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  5. Sign out from the BeckmanAdmin account.
  6. Sign in to use the LabUser account.
  7. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.

Verifications

Complete the verification of service repair. See Verification of Service Repairs for more information.
