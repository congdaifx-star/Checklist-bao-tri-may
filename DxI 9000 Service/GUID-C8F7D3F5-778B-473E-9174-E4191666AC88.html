Resetting the Super User Guest Account for the Console App

This topic includes information about how to reset the super user guest account for the Console App.

Note: You can use the super user guest account to reset the password for any other account.

Resetting the Super User Guest Account

Perform the following procedure to reset the super user guest account.

  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Connect to the databases. See Connecting to the Databases for more information.
  3. In the Object Explorer window, expand Databases.
  4. Right-click ICE_DB and select New Query to open the query window.
  5. In the query window type the following T-SQL code snippet:

    UPDATE AuthPolicies

    SET GuestAuth = '<2;ICE.DataKernel.CommonData;.;AdminAuth>'

  6. Select Execute. The Messages window will display the notification (1 row affected).
  7. Close the query window. Do not save the query.
  8. Close Object Explorer.
  9. Sign out of the BeckmanAdmin account and sign in to use the LabUser account.
  10. Open the Console App. Because you reset the super user guest account, by default you will be signed in to use the super user guest account.
  11. Select the user accounts icon to open the User Account Management page, where you can reset the passwords for user accounts.
  12. Assign the Super User role to a new or existing account.
    Note: The super user guest account will continue to have super user privileges until a new account is assigned the Super User role.
