Priming the Instrument

This topic includes information about how to prime the fluidics system.
Note: When you prime the instrument, the instrument must be in a GREEN (Ready) status but not actively processing samples.
Note: If you are priming the substrate system from "dry" (with air present in the line), refer to Priming an Empty Substrate System.

  1. In the Console App select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  2. Go to MENU > Tools > Diagnostics > Intrusive Diagnostics to open the Intrusive Diagnostics page.
  3. Select Start Session.
  4. Select Priming to open the Priming page.
  5. Select the devices to prime and enter the number of cycles desired for each device.
    Note: The "VERIFY" function is not yet enabled in current software but will be available in future builds.
  6. Select Start Priming. When priming is complete, the Priming has completed window will be displayed.
  7. Select OK.
  8. Go to Intrusive Diagnostics.
  9. Select End Session.
  10. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
