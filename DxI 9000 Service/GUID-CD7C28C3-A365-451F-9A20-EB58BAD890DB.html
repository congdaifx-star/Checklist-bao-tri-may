Calibrating the Luminometer

This topic includes information about how to calibrate the luminometer.
Note: See Luminometer Calibrations Overview for more information about luminometer calibrations.
Note: The system must be in a BLUE (Maintenance) status when you perform this procedure.
  1. In the Machine Control App go to MENU > Machine Control > Luminometer
  2. On the Action tab select Initialize.
  3. In the INITPHASES drop-down menu select All.
  4. Select Clear.
  5. Select Execute.
    The status will change to Luminometer-MachineControlStatus(Ok).
    Note: This may take several minutes.
  6. In the Action pane, select LumiCalibrate.
  7. In the calibrationType drop-down menu select DriftRecalibrate.
  8. Select Clear.
  9. Select Execute.
    The status will change to Luminometer-MachineControlStatus(Ok).
    Note: Wait 10 minutes or more for the calibration process to complete. During this period, there will be no notifications about progress.
