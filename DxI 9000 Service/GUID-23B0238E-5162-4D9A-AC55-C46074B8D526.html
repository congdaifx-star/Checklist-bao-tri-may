Signing In to Use the BeckmanAdmin Account

This topic includes information about how to sign in to use the BeckmanAdmin account on the PC.

  1. Use the Ctrl + Alt + Delete keyboard shortcut and select Sign out to sign out of the user account.
  2. Select Sign in and type the username and password for the BeckmanAdmin account.

    • Password: BeckmanFalcon18!
