Connecting to the Databases

This topic includes information about how to connect to the databases.

Connecting to the Databases

Perform this procedure to connect to the databases.

  1. In the Windows taskbar type ssms to open Microsoft SQL Server Management Studio. The Connect to Server dialog will be displayed.
  2. In Server type select Database Engine.
  3. In Server name select (local).
  4. In Authentication select Windows Authentication.
  5. Select Connect to open the Object Explorer window.
