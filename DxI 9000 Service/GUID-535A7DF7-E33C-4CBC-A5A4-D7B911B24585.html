Performing Drift Detection

This topic includes information about how to perform luminometer drift detection.
Note: See Luminometer Diagnostics Overview for more information about luminometer drift detection.
  1. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  2. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  3. Select Luminometer Linearity to open the Luminometer Linearity page.
  4. Select Perform Drift Detection.
    When the status bar says Operation Completed: Luminometer Linearity, the test is finished.
    Note: If no red system events are generated, the Drift Detection has completed successfully.
  5. If no further diagnostics are required, select END SESSION.
  6. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
