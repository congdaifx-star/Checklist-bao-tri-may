Clearing Passenger Obstructions from the Tray Loader Location to Any Carriage

Use this procedure to clear passenger obstructions from the tray loader location to any carriage:
Note: Only complete this procedure after you have auto-aligned the DispoTip Stocker and verified the DispoTip Stocker angular arm position. See the following topics for more information..
  • Auto-aligning the Tray Gripper
  • Adjusting and Aligning the DispoTip Stocker Angular Arm
  1. In the Console App select the SYSTEM event indicator in the navigation bar. The analyzer will display the System Events page and list the errors that have occurred. If an error indicates there may be a passenger obstruction in the tray loader location to any carriage, continue with this procedure.
  2. Align the tip supply loader.
    • If the tray gripper arms are out of alignment at the tray loader, adjust the bottom underside tray loader screws to resolve any X- or Y-axis issues.
    • If the alignment is off on the Z-axis, you may need to adjust the tray loader Z-axis home position flag so that the arm pins correctly seat into the tray loader alignment holes.
  3. Complete the auto-alignment procedure for the tray gripper. See Auto-aligning the Tray Gripper for more information.
  4. Once again, complete the auto-alignment procedure for the tray gripper.
  5. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
    Note: A successful remapping of the tray gripper assembly during initialization will clear from the Master Control passenger list any passengers that are not physically present in the tray stocker and tip supply locations.
  6. Complete the verification of the service repair. See Verification of Service Repairs for more information.
