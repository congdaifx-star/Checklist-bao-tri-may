Exporting Results to Disk

This topic includes information about how to export test and Automated System Diagnostics (ASD) results for offline analysis and review.

  1. In the Console App go to MENU > Advanced > Results to Disk to open the Results to Disk page.
  2. Select the Start Date Time (Local) and End Date Time (Local) for the results to capture.
  3. Type the filename in the File Name box to specify one. The default filename will be a date/time stamp.
  4. Select the type of results you wish to export:
    • Save Results: This report will export all test results within the specified date range. Exports are saved to D:\ProgramData\Beckman Coulter\FALCON\Results.
    • Save DR Data: This report will export a condensed version of the results within the specified date range for use with EP Evaluator tool.

    • Save ASD Results: This report will export Automated System Diagnostic (ASD) results within the specified date range. The export file will be saved to the export folder specified on the ASD Results to Disk Configuration page.

      To configure the export folder for ASD results:
      1. In the Console App go to MENU > System Configuration to open the System Configuration page.
      2. Go to Analyzer Configuration > ASD Results To Disk to open the ASD Results to Disk Configuration page.
      3. Select Browse and select the folder to export ASD results to.
      4. Go to System Configuration to open the System Configuration page.
      5. Select Activate.
  5. After the export file has been generated, the notification Status: Done will be displayed.
