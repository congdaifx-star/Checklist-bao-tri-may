Configuring Standalone for Middleware/LIS via an RS-232 Serial Connector

This topic includes information about how to configure a standalone DxI 9000 instrument for a middleware or laboratory information system (LIS) connection using an RS-232 Serial connector.

When to Perform

Perform this procedure when the middleware or LIS only supports connection using an RS-232 Serial connector.

Configuring the DxI 9000

Perform the following procedures to configure a standalone DxI 9000 instrument for a middleware or laboratory information system (LIS) connection using an RS-232 Serial connector.
  • Identifying the RS-232 Serial Port Number
  • Configuring the Serial Port

Connecting the Serial Cable

At the rear of the instrument, connect the DB9 connector for the Serial cable to the port that you identified when you performed the Identifying the RS-232 Serial Port Number procedure.
