Troubleshooting Luminometer Dark Count Failures

This topic includes information about how to troubleshoot luminometer dark count failures.
Note: Be sure you first complete general luminometer troubleshooting steps. See Troubleshooting the Luminometer for more information.
Table of Contents

Determining the Need to Replace the Luminometer

Confirming Dark Counts

Perform this procedure to confirm dark counts.

  1. In the Machine Control App go to MENU > Machine Control > Luminometer > Luminometer.Assembly.
  2. On the Action tab select CloseDoor.
  3. Select Execute.
  4. Select Read.
  5. In nReads type 3.
  6. Select Execute.
    • If any value inUncorrectedValues is greater than (>) 100, clean the luminometer. See Cleaning the Luminometer for more information.
      Important: Be sure to use only non-cotton, lint-free, non-abrasive swabs.
    • If any value in UncorrectedValues is less than (<) or equal to (=) 100, dark counts are performing as expected.

Determining the Need to Replace the Luminometer

Perform this procedure to determine whether you need to replace the luminometer.

  1. Be sure the luminometer is at temperature, and that it is idle and not reading and not being calibrated, for at least 15 minutes.
  2. In the Machine Control App go to MENU > Machine Control > Luminometer > Luminometer.Assembly.
  3. On the Action tab select CloseDoor.
  4. Select Execute.
  5. Select Read.
  6. In nReads type 10.
  7. In readContext select Dark.
  8. Be sure includeVoltage is clear and not selected.
  9. Select Execute.
  10. Ten values will be returned for each data type. If the first value in UncorrectedValues is greater than (>) 100 and then subsequent values slowly decrease, replace the luminometer.
    Important: Capture screenshots of all ten values for each data type. (You must scroll to view all ten values.) Gather the Machine Control log files.
