Initializing the Instrument

This topic includes information about how to initialize the DxI 9000 instrument.
Important: During initialization, do not make any changes to the instrument's configuration or settings.
Important: Before you initialize the instrument, be sure all instrument covers are closed.
Note: You may load supplies during initialization.
  1. In the Console App go to MENU > Tools > Diagnostics.
  2. Select Initialize to view initialization options.
  3. Select any or none of the following initialization options, as the situation requires.
    Important: If this is a first-time installation, select all options.
    Option Description
    Force Initialization Forces the instrument to start initialization from the beginning, regardless of status, except for the GREEN (Ready) status.
    Perform Full Consolidation Full consolidation will force the instrument to check every possible position a reaction vessel (RV) or sample vessel (SV) might be in. No samples will be lost.
    Perform Cleanout Clean out will clean all the RVs and SVs on the passenger list of the instrument, except for those still in the hopper. All samples will be lost. Typically performed in conjunction with Full Consolidation.
    Remap Reagent Refrigerator Takes inventory of the reagents in the reagent storage module (RSM) and their nest locations. Also homes the gripper.
  4. Select Initialize.
    Note: Initialization will take a minimum of seven minutes, however, it may take considerably more time for a first installation or if the instrument has been off for over one hour.
