Activating the Windows Operating System License

This topic includes information about how to activate the Windows operating system license.

  1. Press the Windows key and type cmd to open the Command Prompt window.
  2. Type slui.exe and press Enter. The system activation settings window will be displayed.
  3. Select Activate by Phone.

    If Activate by Phone is not available, select Activate. The activation will fail because there is no Internet connection. Close the failed activation window. Activate by Phone should now be available to select. If not, restart the console PC and start over. See Restarting the Console PC for more information.
