Gathering Information for Escalating Issues with the Luminometer

If you are unable to resolve issues for the luminometer using the troubleshooting steps in this service manual, gather the following information for escalation.
Note: For general luminometer troubleshooting steps, see Troubleshooting the Luminometer for more information.
  • Machine Control log files
  • The following files from D:\ProgramData\Beckman Coulter\Falcon
    • LuminometerDriftMeasurements.csv
    • LuminometerPMTHVCheck.csv
    • The newest two linearity files
  • Export results to disk. See Exporting Results to Disk for more information.
    Important: Export as many results as possible. When you export results, be sure you select Save Results (do NOT select Save DR Data) on the Results to Disk page.
