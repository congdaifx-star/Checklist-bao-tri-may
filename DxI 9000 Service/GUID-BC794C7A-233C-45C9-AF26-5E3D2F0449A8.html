Performing the Low Volume Reagent Pipetting ASD Test

This topic includes information about performing the Low Volume Reagent Pipetting Automated System Diagnostics (ASD) test, which tests the precision and accuracy of reagent pipettors.

Important:

There is a Software Bug in 1.16.2 that overrides Pass/Fail each time the software evaluates acceptance criteria. For example, if the last processed data (20uL) is Pass, it will apprear to Pass even if it is Fail (10uL).

Note: It is recommended to run Substrate Blank ASD first, followed by Wash Efficiency ASD. The order of running Low Volume Pipetting, System Carryover, or Precision Sample Pipetting ASD is interchangeable.

Low Volume Reagent Pipetting ASD Test Overview

This ASD runs 3 replicates of RAPID 951, ASD LV RP 10 and 9 replicates of RAPID 952, ASD LV RV 20 on each pipettor, for a total of 48 replicates across all pipettors.

For each ASD LV RP 10 replicate:
  • An RV is retrieved from the RV supply carriage and moved to an RBC.
  • The reagent pipettor retrieves 10uL of ASD system check with a top aspiration from the ASD pack with a 5uL overdraw and places the 10uL of ASD system check in the RV.
  • The reagent pipettor runs a full probe wash after interacting with the pack, discarding the 5uL of overdraw.
  • The reagent pipettor adds 250 uL of wash buffer to the RV and mixes the resulting solution with the reagent pipettor ultrasonics.
  • The RV is moved to the incubate wheel and incubated for 32 seconds.
  • The previous RV is moved back to an RBC as an SV.
  • A DV is moved from the RV supply to the next RBC (dilution builds use two RBCs).
  • The reagent pipettor adds 245 uL of wash buffer to the DV.
  • A new RV is moved from the RV supply to the next RBC with the DV. (dilution builds use two RBCs).
  • 45 uL of wash buffer are added to the RV.
  • A dilution is performed from the SV to the RV pulling 5 uL from the SV and mixing with the DV before drawing 10 uL.
  • The 5ul of sample are added to the RV.
  • The RV is moved to the wash wheel, but no washing occurs. The RV moves around the wash wheel under normal scheduling, waiting 8 seconds at each position.
  • At the end of the wash wheel, the vessel receives 200 uL of substrate.
  • The RV is moved to the incubate wheel for the 48 second substrate incubation time.
  • The RV is moved to the Luminometer and a reading is recorded. (This is the official end of the timer on the Console screen).
  • The RV is removed from the Luminometer and discarded (Lumi -> incubate wheel -> solid waste).
For each ASD LV RP 20 replicate:
  • An RV is retrieved from the RV supply carriage and moved to an RBC.
  • The reagent pipettor retrieves 20uL of ASD system check with a bottom aspiration from the ASD pack with a 10uL overdraw and places the 20uL of ASD system check in the RV.
  • The reagent pipettor runs a full probe wash after interacting with the pack, discarding the 10uL of overdraw.
  • The reagent pipettor adds 240 uL of wash buffer to the RV and mixes the resulting solution with the reagent pipettor ultrasonics.
  • The RV is moved to the incubate wheel and incubated for 32 seconds.
  • The previous RV is moved back to an RBC as an SV.
  • A DV is moved from the RV supply to the next RBC (dilution builds use two RBCs).
  • The reagent pipettor adds 250uL of wash buffer to the DV.
  • The reagent pipettor adds an additional 245 uL of wash buffer to the DV.
  • A new RV is moved from the RV supply to the next RBC with the DV. (dilution builds use two RBCs).
  • 45 uL of wash buffer are added to the RV.
  • A dilution is performed from the SV to the RV pulling 5 uL from the SV and mixing with the DV before drawing 10 uL from the DV.
  • The 5ul of sample are added to the RV.
  • The RV is moved to the wash wheel, but no washing occurs. The RV moves around the wash wheel under normal scheduling, waiting 8 seconds at each position.
  • At the end of the wash wheel, the vessel receives 200 uL of substrate.
  • The RV is moved to the incubate wheel for the 48 second substrate incubation time.
  • The RV is moved to the Luminometer and a reading is recorded. (This is the official end of the timer on the Console screen).
  • The RV is removed from the Luminometer and discarded (Lumi -> incubate wheel -> solid waste).
  • Once all replicates are complete, a SpecialProbeClean runs on each of the pipettors, removing any residual system check. These take ~4.5 minutes to complete.

This diagnostic takes ~55 minutes to complete.

Acceptance RLU Acceptance %CV

For LV RP 10, for each pipettor individually:

5200000 ≤ Median RLU ≤ 10200000

%CV ≤ 20

For LV RP 20, for each pipettor individually:

5200000 ≤ Median RLU ≤ 10200000

%CV ≤ 6.5
Note: Software versions below 1.20 have specifications for SV, RV, and DV median volumes. These specifications are removed on version 1.20 and above. Failures for median volumes on this ASD can be ignored as long as all other specifications are met.

Requirements

  • System software version 1.14 or greater
  • Automated System Diagnostic (ASD) Reagent Pack C23913 is loaded onto the system
  • Associated RAPID files for running this test:
    • ASD LV RP 10 (951)
    • ASD LV RP 20 (952)
  • Be sure all reagent pipettors are enabled.

Performing the Test

  1. Be sure the system is in a GREEN (Ready) status.
  2. In the Console App go to MENU > Tools > ASD Tests to open the ASD Tests page.
  3. Select Low Volume Reagent Pipetting.
    Note: You may select multiple ASD tests.
  4. Select Order Diagnostics.
    Note: The system will prioritize patient, calibration, and QC samples over ASD tests, so the requested test may remain queued if other samples are being processed.
  5. The notification Completed will be displayed in the Status column when the test is complete.
  6. The notification Pass will be displayed in the Pass / Fail column when the test passes.

Reviewing the Results

  1. On the ASD Tests page select Low Volume Reagent Pipetting.
  2. Select Details.
  3. To view details for a specific test, in the Summary area in the Details column select View.
  4. If you need to troubleshoot the test results, capture a screenshot of the page and then proceed with troubleshooting. See Troubleshooting Automated System Diagnostics (ASD) Test Results for more information.
