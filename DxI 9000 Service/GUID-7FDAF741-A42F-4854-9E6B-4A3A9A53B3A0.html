Troubleshooting the DispoTip Stocker and Tray Gripper Assembly

This topic includes information about troubleshooting tips and techniques for the DispoTip Stocker and tray gripper assembly. Includes information for troubleshooting DispoTip Stocker based on the event message or symptom presented by the system.

Note: Before troubleshooting, ensure the following MODs have been completed.
  • Cat-1 MOD 13059 - TSI RSI PCB Board - Replace
  • Cat -1 MOD 13033 - DXI 9000 USB 2.0 Cables - Replace

Troubleshooting

The table below includes symptoms (event messages, failed diagnostics, etc.), potential causes, and recovery steps for various DispoTip Stocker-related issues which may be encountered.

Symptom

Potential Cause

Recovery Steps

TrayGripper.TrayGripperAssemblySensorUnexpectedState

Tray gripper actual state does not match expected state.

  • Failed sensor

  • Bent gripper arm

  • Poor alignment/offset

  • Loose X or Y tray gripper belt

  1. Home the tip tray gripper. See Homing the Tip Tray Gripper for more information.
  2. Adjust and align the DispoTip Stocker angular arm and auto-align the tip tray gripper. See the following topics for more information.
    • Adjusting and Aligning the DispoTip Stocker Angular Arm
    • Auto-aligning the Tray Gripper
  3. Move the tray gripper to the middle stocker position (the 2nd stocker position). Ensure tray gripper closes into alignment positions. See the procedure for adjusting DispoTip Stocker locations in Adjusting DispoTip Stocker Locations for more information.

  4. If it fails, evaluate the sensor state. See Tray Gripper Sensor States for more information.

    1. If the gripper arms miss tray locations, use offset procedures to adjust.

    2. If the gripper is not able to auto-align for all positions, adjust the Z home sensor for the tray gripper.

  5. Verify alignments and tray gripper performance by preparing the loader and running the Tray Exerciser: Tray Exchange routine. See Performing Tip and Tray Exerciser Routines for more information.

TipSupply.YAxisSlip

Tip supply cannot move to correct location.

  • Tray gripper in the way of tip supply

  • Loose Y tip supply belt

  • Faulty home sensor

  • Poor alignment

  1. Observe tip supply locations. Ensure no obstructions.

  2. In the Machine Control App go to Tip Supply > TipSupplyAssembly > select Home > Execute.

  3. If home fails, initialize instrument.

  4. If tip supply moves to home position but fails, check home Y sensor.

  5. If homing fails by not moving/or doesn't move smooth then follow these steps:

    1. Disable tip supply motor current. Go to Tip Supply> TipSupply.TipSupplyAssembly > TipSupply.YAxis > Tip Supply.YAxisMotor > uncheck Enable Box >Execute.

    2. Manually move belt to ensure tip supply moves.

    3. If it doesn't move, check belt tension and motor. Enable motors by checking Enable box in TipSupply.YAxis Motor> Execute.

  6. Verify alignments and tray gripper performance by preparing the loader and running the Tray Exerciser: Tray Exchange routine. See Performing Tip and Tray Exerciser Routines for more information.
