Installing the Service App

This topic includes information about how to install the service application (the Service App).

  1. Copy ServiceAppInstaller_[ver].msi from the DxI 9000 subfolder in Box onto a USB drive.
  2. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  3. Insert the USB drive into a USB port on the instrument.
  4. Open ServiceAppInstaller_[ver].msi and follow the instructions to install the Service App.
  5. Go to C:\Program Files (x86)\Beckman Coulter\ServiceApp. Right-click Service.Application.ServiceApp.exe and select Properties.
  6. On the Compatibility tab select Change settings for all users.
  7. Select the Run this program as an administrator checkbox.
  8. Select OK.
