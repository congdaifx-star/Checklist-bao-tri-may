Troubleshooting Substrate Dispense Issues

This topic includes information about how to troubleshoot substrate dispense issues.

Safety Reminder

Servicing the DxI 9000 instrument involves potential risks for pinch and puncture, electrical shock, and exposure to hazardous materials. You must mitigate these risks by taking appropriate countermeasures. See Safety for more information.

When to Perform

Perform the troubleshooting steps when the DxI 9000 is unable to do the utility prime. Use when troubleshooting substrate calibration failures, or WWS flags are present. Refer to the steps below if Priming an Empty Substrate System was not performed during an installation.

Note:

The DxI 9000 substrate system is significantly different from the DxI 800 substrate system. The DxI 9000 is designed to refresh dispense lines automatically. It is less susceptible to bubbles, and it will automatically perform a utility prime on a periodic basis.

Considerations

Things To Consider With The DxI 9000 Substrate Loader System:

  • The substrate used on the DxI 9000 is reactive.

    • The substrate has a four-day onboard stability.

    • It can be removed from the cooler and placed directly on the instrument. There is no need to acclimate it to room temperature.

    • Contamination is an issue. Do not run DI water, warm water, wash buffer or any fluid other than substrate through the substrate system. Before you add fresh substrate to the system, you must perform the substrate priming dry procedure. See Decontamination and Priming Dry for more information.

    • There are no serviceable parts in the substrate heater assembly. If the heater assembly is defective, replace it and send the defective assembly back to Chaska for failure analysis.

  • The DxI 9000 was designed for minimal user interaction. It can automatically run routines like priming and daily clean.

  • Bubbles, crosstalk, or light intrusion do not affect the performance of the DxI 9000 substrate loader dispense system.

    • Use ASD tests as a guide for system performance. If ASD tests pass, then the system is operating well. Follow troubleshooting in the service manual if ASD tests fail.

Troubleshooting Susbrate Dispense Issues

  1. Perform Priming an Empty Substrate System

    Note:

    You may have to perform this more than once.

  2. Perform Performing the Substrate Blank ASD Test

    1. If the RLU values are in range without flags, don’t proceed to step b.

    2. If the RLU values are in range with WWS flags Calibrate the Wash wheel Camera. Refer to Wash Wheel (WW) Dispense Volume Camera Calibration and Wash Wheel Residual Volume Camera Calibration in Calibrating the Wash Wheel Dispense Volume Camera Setting and Calibrating the Wash Wheel Residual Volume Camera Setting.

    3. If RLUs are low perform the following steps:

      1. Priming an Empty Substrate System

      2. Open Cognex Insight and watch the substrate dispense. Right click to show spreadsheet view for the WW camera and verify the substrate is dispensing.

      3. Perform Volume Checks on the substrate dispense. Refer to the Volume Checks step in Priming an Empty Substrate System. The Volume Checks will return a failed result. This is a known issue. If the volume falls within range, then the substrate is dispensing properly. If you see NaN error or low numbers check the substrate connections, tubing and substrate volume in bottle.

      4. Tightening the Pump / Syringe Case

  3. Perform a manual syringe movement.

    1. Place paper towels or absorbent materials under the substrate probe.
    2. In the Machine Control App go to MENU > Machine Control > WashWheel > WashWheel.Assembly > WashWheel.Pumps > WashWheel.Pumps.SubstratePump.
    3. Repeat the following steps three times.
      1. Open the substrate aspirate valve.
        1. Go to WashWheel.Pumps.SubstratePump.AspirateValue,
        2. On the Action tab select PutLevel and select level.
        3. Select Execute.
      2. Home the substrate pump axis.
        1. Go to WashWheel.Pumps.SubstratePump.Axis.
        2. On the Action tab select Home.
        3. Select Execute.
      3. Move the syringe relative to the substrate pump axis.
        1. Go to WashWheel.Pumps.SubstratePump.Axis.
        2. On the Action tab select MoveRelative and type -1000 in the steps box.
        3. Select Execute.
      4. Close the substrate aspirate valve.
        1. Go to WashWheel.Pumps.SubstratePump.AspirateValue,
        2. On the Action tab select PutLevel and clear level.
        3. Select Execute.
      5. Open the substrate dispense valve.
        1. Go to WashWheel.Pumps.SubstratePump.DispenseValue,
        2. On the Action tab select PutLevel and select level.
        3. Select Execute.
      6. Home the substrate pump axis.
        1. Go to WashWheel.Pumps.SubstratePump.Axis.
        2. On the Action tab select Home.
        3. Select Execute.
      7. Close the substrate dispense valve.
        1. Go to WashWheel.Pumps.SubstratePump.DispenseValue,
        2. On the Action tab select PutLevel and clear level.
        3. Select Execute.
    4. Critical Step: Remove the substrate bottle from the system and replace with a fresh bottle.
    5. Remove the absorbent material from under the substrate probe.

  4. If the above steps do not resolve the issue.

    1. Check the tubing connections for leaks or damage.

    2. Check the electrical connections for damage or loss of function.

    3. Replace the substrate heater assembly. The assembly includes the substrate probe which is not replaceable by itself.

    4. Replace the substrate aspirate valve.
