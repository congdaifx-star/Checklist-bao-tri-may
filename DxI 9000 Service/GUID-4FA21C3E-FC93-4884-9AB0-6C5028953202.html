EdgeMax Router Ports

This topic includes information about the ports on the EdgeMax router.

The Edgemax EdgeRouter X is an internal network router within the DxI 9000 system that enables external connectivity to the system PC. The router has five ports.

Description Interface Default IP Address Purpose
Instrument eth0/PoE IN 172.16.6.1 Connection to the DxI 9000 Console.
Local LIS/Remisol eth1 192.168.150.191
Note: (Addresses may need adjustment based on the local subnet used as well as the number of instruments in the laboratory)
Used to connect to a local LIS or Middleware using a Peer-to-Peer connection. This port can also be used for a local Command Central server or a network printer.
Service eth2 172.16.7.1 Used to connect a Service Laptop. This interface has a DHCP server that will automatically assign an IP when the Service Laptop is connected.
Power Express eth3 134.217.96.191
Note: (Addresses may need adjustment based on the number of instruments in the laboratory)
Used for a Power Express dynamic interface connection to Cennexus.
Internet eth4/PoE OUT No default IP address (IP Address provided by the IT administrators needs to be assigned). WAN interface used to connect to a customer network to communicate to Middleware, LIS, Command Central server. This interface is also used for communicating to DxS Intelliserve.
Ports eth1 - eth4 are connected to the ports at the back of the instrument near the power cable for ease of connection:
Note: The order of the ports will be reversed for instruments with the serial numbers 300115 and below.
