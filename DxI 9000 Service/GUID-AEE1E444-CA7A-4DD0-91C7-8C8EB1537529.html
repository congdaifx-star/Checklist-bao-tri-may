Configuring the IP Address for the Network

This topic includes information about how to configure the IP address for the network and DxS IntelliServe.

  1. Access the EdgeMax router dashboard. See Accessing the EdgeMax Router Dashboard for more information.
  2. On the dashboard, for the Internet (eth4) interface, select Actions and then select Config to open the Interface Configuration for eth4 window.
    Note: Because the Description for an interface can be modified, the Description may vary, but the (eth#) will remain the same.

  3. For the Address select Manually define IP address.
  4. Type the IP address.
    • If the network configuration does NOT include a firewall device, and if the instrument is directly connected to the customer network, type the IP address provided by the IT administrator.
      Note: You must include the Classless Inter-Domain Routing (CIDR) number for the subnet mask after the IP address. For example, if the IP address is 192.16.13.11 and the desired subnet mask is 255.255.255.0, type 192.16.13.11/24. Refer to the following table for guidance about determining the correct CIDR number based on the subnet provided by IT.
      Subnet Mask CIDR Subnet Mask CIDR Subnet Mask CIDR
      255.128.0.0 /9 255.255.128.0 /17 255.255.255.128 /25
      255.192.0.0 /10 255.255.192.0 /18 255.255.255.192 /26
      255.224.0.0 /11 255.255.224.0 /19 255.255.255.224 /27
      255.240.0.0 /12 255.255.240.0 /20 255.255.255.240 /28
      255.248.0.0 /13 255.255.248.0 /21 255.255.255.248 /29
      255.252.0.0 /14 255.255.252.0 /22 255.255.255.252 /30
      255.254.0.0 /15 255.255.254.0 /23
      255.255.0.0 /16 255.255.255.0 /24

    • If the network configuration includes a firewall device, type an IP address in the range 192.168.150.35 to 192.168.150.39, followed by /24. For example, for DxI1 type 192.168.150.35/24.
      Important: These instructions assume the default IP address 192.168.150.254 is used for INSTRUMENTS port on the firewall device. If the IP address has been changed from the default, you must use an IP address on the DxI that matches the correct subnet.
  5. Select Save.
  6. Select System.
  7. In the Gateway section, in the System gateway address box, type the IP address for the default gateway
    • If the network configuration does NOT include a firewall device, type the IP address for the default gateway as provided by the IT administrator.
    • If the network configuration includes a firewall device, type 192.168.150.254, which is the IP address for the INSTRUMENTS port on the firewall device.
  8. In the Name Server section, in the System name server box, type the IP address for the DNS
    • If the network configuration does NOT include a firewall device, type the IP address for the DNS as provided by the IT administrator.
    • If the network configuration includes a firewall device, type 192.168.150.254, which is the IP address for the INSTRUMENTS port on the firewall device.
  9. Select Save.
