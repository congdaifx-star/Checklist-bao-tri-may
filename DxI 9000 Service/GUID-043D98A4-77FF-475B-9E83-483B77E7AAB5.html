LEDs

Location

Function

Notes

D1 Analog-to-Digital Converter (ADC) Fault

  • LED off = no faults

  • LED on = multiple consecutive ADC faults have occurred, i.e. fault means ADC did not start or complete a conversion in the time expected

D4 USB Status

  • LED off = USB not connected or programmed correctly

  • LED on = USB connected and programmed correctly

D5 DAQC Communication Mode Status

  • LED off = instrument software has configured DAQC correctly

  • LED on = instrument software has not opened yet, has not configured DAQC correctly, USB has not been programmed correctly or main firmware has not been programmed correctly
