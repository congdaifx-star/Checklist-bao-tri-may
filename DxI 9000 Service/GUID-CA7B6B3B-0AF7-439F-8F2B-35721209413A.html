Troubleshooting Electronics and Printed Circuit Boards (PCBs)

This topic includes information about how to troubleshoot electronics and printed circuit boards (PCBs) in the instrument.

Symptoms and Possible Causes

The following errors indicate the need to troubleshoot issues with electronics and PCBs.
  • Failed to open communication port for device
  • Unable to locate port for device
  • Device communication failure

These errors might be due to the following possible causes.

  • USB cable
  • PCB power cable
  • PCB
  • PCB jumper
  • Hub
  • Incorrect firmware installed on a PCB
  • DAQC PCB

Troubleshooting Electronics and PCBs

Perform this procedure to troubleshoot electronics and PCBs in the instrument.

Note: Before you troubleshoot, be sure MOD 13033 – DxI 9000 USB 2.0 Cables – Replace has been completed on instrument, if applicable.
  1. If the error occurred after the installation of a new PCB, check the firmware version for the board and update the firmware as needed. See the following topics for more information.
    • Viewing Firmware Version Information
    • Installing Firmware
  2. If the error occurred during a software upgrade, and if the instrument is connected to a lab automation system (LAS), the USB port assignment may have changed, which resulted in a conflict between LAS communication and PCB communication. Check the AutomationAgent.Falcon.settings “Portnumber”. See the following topics for more information.
    • Configuring the DxI 9000 to Connect to DxA
    • Configuring the DxI 9000 to Connect to Power Express
  3. Identify the impacted board and associated USB hubs from the error message. See the following topics for more information.
    • Electronics Locations and Reference Diagrams
    • Communication Diagram
  4. Inspect the LED lights on the hub.
    • If a single LED light on the hub is off, this indicates an issue that is downstream from the hub (a cable, a downstream hub, or a circuit board).
      1. Turn off the instrument. See Turning Off the Instrument for more information.
      2. Reconnect the USB cable at the circuit board and the hub.
      3. Reconnect the power cable and jumper connection on the PCB. See the layout for the impacted circuit board in the Drawings / Diagrams section for more information.
      4. Turn on the instrument. See Turning On the Instrument for more information.
    • If all of the LED lights on the hub are off, this indicates an issue with the hub or upstream from the hub (a cable, an upstream hub, or the PC).
      1. If there is an upstream hub, observe the status of the lights on the hub to determine which hub has an issue. See Communication Diagram for more information.
      2. Turn off the instrument. See Turning Off the Instrument for more information.
      3. On hub with the issue
        1. Reconnect both sides of the power cable. See Power Distribution Diagram for more information.
          Important: The parts numbers indicated in this diagram may not be current. See the parts manual for current parts numbers.
        2. Reconnect both sides of the USB cable on hub port 0 (the USB B connector). See Communication Diagram for more information.
          Note: To determine whether the USB cable might be the issue, temporarily swap the USB cable with the USB cable from another circuit board.
      4. Turn on the instrument. See Turning On the Instrument for more information.
  5. If the error persists, and if the error did not begin with the installation of a new board, consider replacing the impacted PCB, USB cable, and/or jumper. See Replacing Circuit Boards for more information.

Verification

Complete the verification of service repair. See Verification of Service Repairs for more information.
