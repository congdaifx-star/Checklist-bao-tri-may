Stress Testing the System

This topic includes information about how to stress test the system using a large batch of samples.

Note: To perform this procedure, you must have AP5 and ASD-3Wash-Eff enabled on the Tests page. See Enabling Tests for more information.
Important: Completing the stress test with the instrument covers open might increase dark count errors.

When to Perform

This procedure is required as part of system installation, but may be performed as desired to stress test the system by fully loading it with samples.
Note: The purpose of the test is only to stress the instrument workload and to check for intermittent failures and flags. The test results may be used for investigation or troubleshooting, but they have no passing specifications.

Supplies Required

The following items are required to perform the procedure:
  • Three sample container racks.
  • Qty. 21 sample tubes and/or cups specific to the laboratory. For example, if the customer uses 13x100 tubes, 12x75 tubes, and 2 mL cups, use three separate racks for the 13x100 tubes, 12x75 tubes, and 2mL cups.
    Important: You must use customer-specific tubes to help identify potential issues with container types failing to be detected in position 5.
    Note: Tube racks can have any combination of tubes but not cups. Cup racks cannot have tubes.
    Tip: See the DxI 9000 Access Immunoassay Analyzer Instructions for Use (IFU) for information about barcode label placement.
  • 2 ASD reagent packs (1 loaded and 1 unloaded).
  • Fresh 1:501 system check dilution
    Note: To make the dilution, add 20uL of system check solution to 10mL of wash buffer and mix gently.

Step 1: Load an ASD Reagent Pack

Load an Automated System Diagnostics (ASD) pack on the instrument. See the DxI 9000 Access Immunoassay Analyzer Instructions for Use (IFU) for more information.

Step 2: Open the Enhanced Test Order Page

In the Console App go to MENU > Advanced > Enhanced Test Order to open the Enhanced Test Order page.

Step 3: Enter an Enhanced Test Order for Position 1

  1. Enter the information listed in the table below.
    For example, for entry 1:
    1. In the Assays area, select AP5.
    2. Clear all Pipettors except 1.
    3. In the Replicates box type 1.
    4. Select Add.

    Perform these steps for each entry listed in the table below.

    Entry Assay Pipettors Selected Replicates
    1 AP5 1 1
    2 AP5 2 1
    3 AP5 3 1
    4 AP5 4 1
    5 ASD-3Wash-Eff 1 5
    6 ASD-3Wash-Eff 2 5
    7 ASD-3Wash-Eff 3 5
    8 ASD-3Wash-Eff 4 5

  2. In the Test Order Info area
    1. In the Sample ID box type a unique sample ID. For example, type ST-Tube1-[date/time] for the first test order.
    2. Select Add.
    3. Select New.

Step 9: Enter Rack IDs

Note: In the Pending Test Orders area, you can select the down arrowhead (⌄) or up arrowhead (⌃) adjacent to a Rack ID to show or hide detailed information about sample containers in a rack.
  1. In the Pending Test Orders area, in the options adjacent to Rack ID, select Unknown.
  2. Enter the digits of the Rack ID for each rack.
  3. Select Commit.

Step 10: Prepare the Racks

  1. Use a cup rack and place a 2ml Beckman Coulter cup into Position 1, Position 4, and Position 7.
  2. Place 240ul of system check dilution into the 2ml cups at Position 1, Position 4, and Position 7.
  3. Place 2ml Beckman Coulter cups into Position 2 , Position 3 , Position 5, and Position 6.
  4. Place at least 1ml of system check dilution into each of the cups at Position 2, Position 3, Position 5, and Position 6.
  5. Prepare two additional racks using a combination of sample containers used by the customer, and fill te sample containers with system check dilution.
    Note: Be mindful of dead volume for the tube type and/or cup. Fill according to the amount needed for tube type and add-on dead volume to prevent QNS.

Step 11: Load the Racks and Run the Tests

  1. Load the racks onto the SPU onload area and close the covers. The system should accept the racks and begin running tests.
  2. After the system begins performing tests, wait 15 minutes and then load the remaining single ASD pack.
  3. Troubleshoot any system failures or flags accordingly.
    Important: If there are failures to detect tubes/cups in position 5, see Troubleshooting Sample Presentation Unit (SPU) Camera Calibrations for more information.
