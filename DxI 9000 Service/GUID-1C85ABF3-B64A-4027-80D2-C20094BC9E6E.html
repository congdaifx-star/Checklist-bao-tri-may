Troubleshooting Luminometer Initialization Failures

This topic includes information about how to troubleshoot luminometer initialization failures.
Note: For general luminometer troubleshooting steps, see Troubleshooting the Luminometer for more information.

Turning on the Photomultiplier Tube (PMT)

Perform this procedure to turn on the photomultiplier tube (PMT).
Note: If the luminometer isn't calibrated, to pass initialization, the photomultiplier tube (PMT) must be manually turned on.
  1. In the Machine Control App go to MENU > Machine Control > Luminometer > Luminometer.Assembly > Luminometer.Device.
  2. On the Action tab select GetVoltage.
  3. Select Execute. If the value for volts is less than (<) 0.1:
    1. Select PutVoltage.
    2. In volts type 0.8.
    3. Select Execute.
  4. Initialize the luminometer.
  5. If you are unable to resolve the issue using these troubleshooting steps, gather information for escalation. See Gathering Information for Escalating Issues with the Luminometer for more information.

Determining Whether Luminometer Calibration Data Has Been Erased

Perform this procedure to determine whether luminometer caliibration data has been erased.

  1. In the Machine Control App go to MENU > Machine Control > Luminometer > Luminometer.Assembly > Luminometer.Device.
  2. On the Action tab select GetCalibrationData.
  3. Select Execute. If the value for LEDStandardCal is 0, all calibration data has been erased. Gather information for escalation. See Gathering Information for Escalating Issues with the Luminometer for more information.
