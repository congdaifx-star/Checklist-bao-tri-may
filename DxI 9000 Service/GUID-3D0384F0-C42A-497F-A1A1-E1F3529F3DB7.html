Auto-Aligning the Substrate Loader

This topic includes information about how to auto-align the substrate loader.

Prerequisites

Before you begin an alignment procedure:
  • If you must make changes to the instrument's hardware, you must complete those changes before you prepare the instrument for adjustments and alignments.
  • You must verify that alignments have previously been completed on the instrument. To verify, in the Machine Control App go to Menu > Prototype Alignment to open the Prototype Alignment page and to verify the Finalize Instrument Alignments button is GRAY in color. If the button is BLUE in color, do not complete this procedure. Instead, you must first complete manual alignments.
  • You must first initialize the instrument to a GREEN (Ready) status to ensure all subsystems have been successfully initialized and homed. You must then enter the instrument into a BLUE (Maintenance) status.

Auto-Alignment Process Overview

The auto-alignment feature for the substrate loader uses reduced motor current stall methods to determine alignments for the Z height and rotational platform. The operation completes auto-alignment in the following manner:

  1. The substrate loader is initialized.

  2. The probe and door arms are lowered using a standard low current motion profile until the arms reach lockout position (just above the bottles). A ten-minute time out period begins so the gaskets have time to relax their shape.

  3. The motion profile changes to a low current profile for the Z stall motion. The probe arm is lowered until slippage is detected. There’s a 25ms delay between step moves due to hardware vibration harmonic. The drive current is disabled for 200ms. This allows the arm to move up which releases pressure from the gasket. The encoder reading is captured, and drive current is re-enabled. The new encoder reading has an offset applied to it. This is the new Z position for the probe. The same process is repeated for the door arm. The loader reinitializes before moving on.

  4. The Z positions for the probe and door are checked against a minimum expected value to ensure a high degree of confidence.

  5. The probe and door move down to the calculated positions that are fifteen steps above the alignment positions. This ensures the gaskets are not touching the tops of substrate bottles before the platform alignment starts.

  6. The platform motor profile is changed to a new low current profile. The platform rotates clockwise until slippage is detected. The last known position that’s within range before slippage is detected is saved. There’s a 25ms delay between step moves due to hardware vibration harmonic. This is the same process as the probe and door arm.

  7. The platform is moved counterclockwise a few steps until the motor position is updated with the current position. The platform moves back to its original position.

  8. Platform motor slippage is repeated in the counterclockwise position. The last know position that’s within range before slippage is detected is saved. There’s a 25ms delay between step moves due to hardware vibration harmonic. This is the same process as the probe and door arm.

  9. The clockwise and counterclockwise slippage locations are averaged. This average is used for the platform alignment position.

  10. The substrate loader is reinitialized, and the alignments are saved.

Prepare the Instrument for Adjustments and Alignments

You must prepare the instrument for adjustments and alignments.

  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Disable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  3. Open all hoods and covers.
  4. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
    Note: If the instrument enters into a RED (Stopped) status:
    1. Verify the interlock switch is in the correct position.
    2. Be sure you are signed in to use the BeckmanAdmin account.
    3. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
    4. Complete all troubleshooting, adjustments, manual alignments, and maintenance necessary to be able to initialize the instrument to a GREEN (Ready) status.
  5. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.

Auto-Aligning the Substrate Loader

Perform the following steps to auto-align all points within the substrate loader.
  1. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  2. Be sure two bottles of substrate have been loaded.
    Note: You can perform an auto-alignment with any two containers of substrate, even if the containers are empty or expired. However, the preferred method is to use empty bottles in the event you must discard them after you complete this procedure.

    Complete the following steps to manually load the bottles:

    1. In the Machine Control App go to MENU > Prototype Alignment to open the Prototype Alignment page.
    2. Go to Substrate Loader > Probe Seal Height.
    3. Select Home All to open the door and to raise the substrate probe.
    4. Insert a substrate bottle onto the platform.
    5. Select Move To Position to rotate the platform.
    6. Insert another substrate bottle.
  3. Go to Substrate Loader > Auto Align.
  4. Select Auto Align. The procedure will run for approximately eleven minutes. During this period, the system will place the platform, door, and probe into desired positions, and there will be no activity for approximately ten minutes. The system will then complete and save the alignments.
    Note: If this auto-alignment procedure changes the SubstrateLoader.DoorSealingPosition value or the SubstrateLoader.ProbeSealingPosition value by 4 or more steps, and if the instrument has system software version 1.20 or earlier installed, perform the following procedures.
    • If the SubstrateLoader.DoorSealingPosition value was adjusted by 4 or more steps, complete the following procedure.
      1. Go to MENU > Machine Control > SubstrateLoader.Assembly.
      2. On the Action tab select OpenDoor.

      3. Select Execute.
      4. Go to SubstrateLoader.Assembly > SubstrateLoader.DoorBottleSealer
      5. Select MoveToSealedPosition.

      6. Select Execute.
    • If the SubstrateLoader.ProbeSealingPosition value was adjusted by 4 or more steps, complete the following procedure.
      1. Go to MENU > Machine Control > SubstrateLoader.Assembly.
      2. On the Action tab select RaiseProbe.

      3. Select Execute.
      4. Go to SubstrateLoader.Assembly > SubstrateLoader.ProbeBottleSealer
      5. Select MoveToSealedPosition.
      6. Select Execute.

Ending an Adjustments and Alignments Session

  1. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics.
  2. Select End Session.
  3. Close all hoods and covers.
  4. Enable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  5. Sign out from the BeckmanAdmin account.
  6. Sign in to use the LabUser account.
  7. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.

Verifications

Complete the verification of service repair. See Verification of Service Repairs for more information.
