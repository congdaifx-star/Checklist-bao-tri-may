Troubleshooting Luminometer Drift Failures

This topic includes information about how to troubleshoot luminometer drift failures.
Note: For general luminometer troubleshooting steps, see Troubleshooting the Luminometer for more information.
Table of Contents

Troubleshooting when Resetting Drift Targets Fails

Perform this procedure to troubleshoot when resetting drift targets fails.

  1. Reset drift targets. Repeat the reset procedure up to five times. See Resetting Drift Targets for more information.
    Tip: On rare occasions, resetting drift targets might fail.
  2. If resetting drift targets fails on all five attempts, calibrate the luminometer. See Calibrating the Luminometer for more information.
  3. Reset drift targets. Repeat the reset procedure up to five times.
  4. If you are unable to resolve the issue using these troubleshooting steps, gather information for escalation. See Gathering Information for Escalating Issues with the Luminometer for more information.

Troubleshooting 'Luminometer Requires Drift Correction' when Resetting Passes

Perform this procedure to troubleshoot when resetting drift targets passes but the message The luminometer requires drift correction is displayed.

  1. Calibrate the luminometer. See Calibrating the Luminometer for more information.
  2. Reset drift targets. Repeat the reset procedure up to five times, if necessary. See Resetting Drift Targets for more information.
  3. If the message continues to be displayed, perform drift detection. See Performing Drift Detection for more information.
  4. Reset drift targets. Repeat the reset procedure up to five times, if necessary. Confirm the message is no longer displayed.
  5. If you are unable to resolve the issue using these troubleshooting steps, gather information for escalation. See Gathering Information for Escalating Issues with the Luminometer for more information.
