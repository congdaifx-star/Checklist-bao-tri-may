Exporting a Cognex Camera JOBFILE

This topic includes information about how to export a JOBFILE for a Cognex camera.

See Cognex Camera JOBFILE Descriptions and Use for more information about the Cognex Camera JOBFILE.

  1. Insert a USB drive into an open USB port on the instrument.
  2. Press the Windows key and go to Cognex > In-Sight Explorer to open the In-Sight Explorer application.
  3. In the In-Sight Explorer application go to View > In-sight Network to open the In-Sight Network pane.
  4. In the In-Sight Network pane go to In-Sight Sensors and select the camera.
  5. Go to File > Save JOBFILE as and save the JOBFILE to the USB drive.
    Warning: This step removes the JOBFILE from the camera. Therefore, you must complete the next step, which is to save the JOBFILE to the camera.
  6. Go to File > Save JOBFILE as and select In-Sight Sensors and select the camera.
    Important: You must complete this step after you have saved the JOBFILE to the USB drive.
