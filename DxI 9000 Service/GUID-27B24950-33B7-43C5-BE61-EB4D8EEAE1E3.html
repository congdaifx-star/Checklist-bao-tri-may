Adjusting and Aligning the Analytic Pick and Place (PnP)

This topic includes information about how to adjust and align the analytic pick and place.

Safety Reminder

Servicing the DxI 9000 instrument involves potential risks for pinch and puncture, electrical shock, and exposure to hazardous materials. You must mitigate these risks by taking appropriate countermeasures. See Safety for more information.

Prerequisites

Before you begin an alignment procedure:
  • If you must make changes to the instrument's hardware, you must complete those changes before you prepare the instrument for adjustments and alignments.
  • You must verify that alignments have previously been completed on the instrument. To verify, in the Machine Control App go to Menu > Prototype Alignment to open the Prototype Alignment page and to verify the Finalize Instrument Alignments button is GRAY in color. If the button is BLUE in color, do not complete this procedure. Instead, you must first complete manual alignments.
  • You must first initialize the instrument to a GREEN (Ready) status to ensure all subsystems have been successfully initialized and homed. You must then enter the instrument into a BLUE (Maintenance) status.

Prepare the Instrument for Adjustments and Alignments

You must prepare the instrument for adjustments and alignments.

  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Disable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  3. Open all hoods and covers.
  4. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
    Note: If the instrument enters into a RED (Stopped) status:
    1. Verify the interlock switch is in the correct position.
    2. Be sure you are signed in to use the BeckmanAdmin account.
    3. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
    4. Complete all troubleshooting, adjustments, manual alignments, and maintenance necessary to be able to initialize the instrument to a GREEN (Ready) status.
  5. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.

Auto-Aligning the Analytic PnP to the Wash Wheel

Perform this procedure to align the analytic pick and place (PnP) to the wash wheel.

  1. In the Console App go to MENU > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  2. in the Machine Control App go to MENU > Prototype Alignment to open the Prototype Alignment page.
  3. Go to Analytic PnP > Analytic PnP to Wash Wheel to view the alignment keys for aligning the analytic pick and place to the wash wheel.
  4. Select Home All.
  5. Select Auto Align.
    • If the alignment succeeds, you will see a dialog with the notification Save successful. Select OK.
    • If the status message displays the notification Analytic PnP Y adjustment is needed. Alignments will not be saved. you must adjust the analytic pick and place and luminometer Y-axis. See Manually Adjusting the Analytic PnP to the Wash Wheel (Y-axis) and Adjusting the Luminometer to the Analytic PnP for more information.
      Note: Analytic pick and place alignment values will not be saved if a Y-axis adjustment is necessary.
      Note: The status message indicates the direction of the adjustment and the number of drive screw rotations required.
    • If the alignment fails, continue with this procedure.

  6. Select Disable All to disable power to the motor.

  7. Manually move the PnP so that the PnP collet fully seats on top of the wash wheel alignment pin. Be sure the PnP collet is down as far as it will travel on top of the pin.
    Caution: Be careful when moving devices by hand so as not to bend or damage any components.
  8. Select Measure All. The PnP should move to the home position.
  9. Select Save All to save the alignments.
  10. Select Move to Position to verify the alignment.
  11. Select Home All.
  12. Repeat auto alignment.

Auto-Aligning the Analytic PnP to the Incubate Wheel - Inner Position

Perform this procedure to align the analytic pick and place (PnP) to the Incubate Wheel - Inner position.

Important: Be sure there are no vessels in locations adjacent to the auto-alignment pin.
  1. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  2. In the Machine Control App go to Menu > Prototype Alignment to open the Prototype Alignment page.
  3. Go to Analytic PnP > Analytic PnP to Incubate Wheel - Inner.
  4. Select Home All.
  5. Select Auto Align.
    • If the alignment succeeds, you will see a dialog with the notification Save successful. Select OK.
    • If the alignment fails:
      1. Select Disable All to disable motor power.
        Caution: Be careful when moving devices by hand so as not to bend or damage any components.
      2. Manually move the PnP and wheel so that the PnP collet fully seats on top of the inner alignment pin on the incubate wheel. Be sure the PnP collet is down as far as it will travel on top of the pin.
      3. Select Measure All. The PnP and wheel should return to their home positions.
        Caution: Measure All and Home All will enable all the motors.
      4. Select Save All to save the alignments.
        Note: If the Save All button remains grayed out, there are no changes to save.
      5. Select Move To Position again and verify the alignment.
        Tip: You can disable the PnP Z-motor and use the belt and pulleys to move the PnP up and down. Verify the collet successfully picks up the alignment pin and is centered in the X and Y directions.

      6. Select Home All.
      7. Repeat auto alignment.

  4. Select Home All.
  5. Select Auto Align.

      2. Manually move the PnP so that the PnP collet fully seats on top of the luminometer alignment pin. Be sure the PnP collet is down as far as it will travel on top of the pin.
      3. Select Measure All. The PnP should return to the home position.
      4. Select Save All to save the alignments.

      7. Repeat auto alignment.

        If the auto-alignment fails, then adjust the luminometer to the analytic PnP. See Adjusting the Luminometer to the Analytic PnP for more information.

Manually Adjusting the Analytic PnP to the Wash Wheel (Y-axis)

Perform this procedure to manually adjust the analytic pick and place (PnP) gantry to the wash wheel on the Y-axis. Use auto-alignment to adjust the X-axis and Z-axis. See Aligning the Wash Wheel for more information.
Important: Do not adjust the analytic PnP gantry to the wash wheel on the Y-axis unless directed to do so by the system during the Auto-Aligning the Analytic PnP to the Wash Wheel procedure.
Note: If you perform this procedure, you must also complete all other analytic PnP alignments, as noted at the end of this procedure.
  1. Use a 3mm driver to loosen the four screws that secure the analytic pick and place (PnP) gantry to the tower just below the MCC.

  2. Turn the analytic PnP Y-axis drive screw in the direction and number of rotations indicated by the notification you received while performing the Auto-Aligning the Analytic PnP to the Wash Wheel procedure.
    Note: Use a 5mm allen wrench to make Y-axis adjustments by turning a bolt located just below the point where the gantry connects to the tower.
  3. Use the 3mm driver to secure the gantry to the tower by tightening the four screws.
  4. Auto-align the analytic PnP to the wash wheel to verify the Y-axis adjustment. See Auto-Aligning the Analytic PnP to the Wash Wheel for more information.
  5. Adjust the luminometer to the analytic PnP and fix it in place. See Adjusting the Luminometer to the Analytic PnP for more information.
  6. Align the PnP to the incubate wheel and luminometer.
    • Auto-Aligning the Analytic PnP to the Incubate Wheel - Inner Position
    • Auto-Aligning the Analytic PnP to the Incubate Wheel - Outer Position
    • Auto-Aligning the Analytic PnP to the Luminometer

Adjusting the Luminometer to the Analytic PnP

Perform this procedure to manually adjust the luminometer to the analytic PnP.
  1. Use a 3mm driver to loosen the three screws that secure the luminometer to the luminometer chassis.
  2. Slide the luminometer on the chassis in the Y-axis so that the collet aligns with the luminometer alignment pin. Be sure the collet is centered over the alignment pin by moving it up and down on the pin.
  3. Use the 3mm driver to tighten the three screws to secure the luminometer in place.
  4. Move the PnP collet away form the luminometer alignment pin and back again to confirm the Y-axis adjustment is acceptable.
  5. Auto-align the analytic PnP to the luminometer. See Auto-Aligning the Analytic PnP to the Luminometer for more information.

Ending an Adjustments and Alignments Session

  1. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics.
  2. Select End Session.
  3. Close all hoods and covers.
  4. Enable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  5. Sign out from the BeckmanAdmin account.
  6. Sign in to use the LabUser account.
  7. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.

Verifications

Complete the verification of service repair. See Verification of Service Repairs for more information.
