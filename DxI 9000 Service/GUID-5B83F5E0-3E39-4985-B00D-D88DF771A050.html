Configuring the Destination Address for the Remisol Dynamic Interface

This topic includes information about how to configure the destination address when you must use a different subnet than 192.168.150.x for the Remisol Dynamic Interface. This network address translation (NAT) rule will enable the Dynamic Interface to connect inbound to the instrument using a specified subnet.

  1. Access the EdgeMax router dashboard. See Accessing the EdgeMax Router Dashboard for more information.
  2. On the dashboard select Firewall/NAT.

  3. On the NAT tab, for Remisol Dynamic Interface, select Actions and then select Config to open the Destination NAT Rule Configuration window.

  4. Enter the subnet.

    For example, if the defined IP address is 192.16.13.11/24, type 192.16.13.0/24.

  5. Select Save.
