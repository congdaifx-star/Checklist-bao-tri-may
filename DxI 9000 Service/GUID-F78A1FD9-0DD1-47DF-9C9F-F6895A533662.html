Software 1.13 Common Failure Troubleshooting

A list of the most commonly observed failure modes and resolution steps for system software versions 1.13.

  • Symptom/Error: Description fo the symptom, or, when applicable, the error/event message observed during the failure.
  • Advisor Case: If the issue has an Advisor case associated with it, the case number will be listed here as a reference for additional details.
    Note: Access the Advisor program here. Contact Advisor.Support@beckman.com if unable to login or account creation is needed.
  • Details/Resolution: Details regarding what may have caused the failure mode and how to recover.
Symptom/Error Advisor Case Details/Resolution
Reagent Storage (RSM) X Slippage K65276232 Reagent Pack Gripper detected slippage when moving in the X-axis.
  1. Open and inspect for/remove any debris or fallen packs.
  2. Manually move gripper to home position.
  3. Initialize with remap selected.
Precision Sample Pipettor Z Slippage ("PrecisionSamplePipettor.ZAxisSlip" error) K71067740 Precision Sample Pipettor detected slippage when moving in the Z-axis.
  1. Check precise sample pipettor for obstructions, especially in tip discard waste chute.
  2. Manually move pipettor with power off to check for binding/resistance.
  3. Check electrical connections/move pipettor via Machine Control and observe for failure.
Controller Command Execution Aborted K43952147 Timing error that typically resolves with system reboot.
  1. Reboot the system.
  2. Review events to understand which subsystems are causing the error and perform alignments of those subsystems to ensure misalignments do not lead to timing problems (most common is reagent carriage timing/alignments).
  3. Perform sample pip camera calibrations after aligning.
Precise Sample Pipettor Volume Failure K24411353 Similar to PVSR/PVDR flags.
  1. Inspect mandrel/reflector/tips for damage or debris.
  2. Check sample precise pipettor alignments.
  3. Check sample aliquot pipettor alignments.
  4. Perform sample precise pipettor camera calibraton.
Pick and Place (PnP) Unexpected Vessel State

K57415998

K51751244

K98731457

These errors should be treated as missing RV errors.
  1. Review events to understand which PnP/location the errors occur at.
  2. Check PnP alignments.
  3. Inspect PnP collet/ejector for damage/debris and replace/clean as needed.
  4. If errors are intermittent, perform vessel exerciser to observe vessel movement and attempt to observe the failure live.
Passenger missing / Unsuccessful attempt to keep RV feeder chute full / RV starvation K00074237 RV starvation occurs when the RV feeder is unable to output vessels at a rate the instrument is requesting them, typically caused by low level of RV's remaining in the feeder "hopper".
  1. Inspect RV supply counts and replenish if needed.
  2. If issues persist with sufficient vessels in the feeder, check RV feeder components and alignments. Clean/replace/align as needed.
  3. If errors are intermittent, perform vessel exerciser to observe vessel movement and attempt to observe the failure live.
Reagent Pipettor Fluid Failed to Wash K87540850 Reagent pipettor failed to detect wash, may elicit RWF or RWV flags.
  1. Prime the system.
  2. Check reagent pipettor alignments to wash tower.
  3. Re-calibrate reagent wash pressure sensors.
  4. Inspect/replace reagent pipettor probe tip.
  5. Inspect/repalce as needed vacuum components (PCB, tubing, etc.)
Pick and Place (PnP) Z-Slippage K57010509 Z-axis motor detected slippage during movement, may be due to physical obstruction or electrical failure.
  1. Inspect PnP for which the error occurred for any signs of damage/debris, or fallen RV's/tips in the path of operation.
  2. Restart the system.
  3. Check mechanical components (belt, slide, pulley) and move the device by hand to sense for resistance.
  4. Check electrical components for potential failure (motor, cables, PCBs).
Wheel Encoder Mismatch / Wheel Axis Out of Tolerance / Wheel Slippage K05311729 Motion failure errors relating to sample, incubate, or wash wheel.
  1. Check wheel for obstruction/debris and clean or remove as needed.
  2. Move the wheel by hand and sense for resistance.
  3. Check mechanical components (belt, slide, pulley) and move the device by hand to sense for resistance.
  4. Check electrical components for potential failure (motor, cables, PCBs).
Pick and Place (PnP) Rendezvous Failed K00222562 Rendezvous failures are generic timing errors that may occur on a variety of devices. For PnP rendezvous failures:
  1. Restart the system.
  2. Inspect the PnP and associated rendezvous subsystem for signs fo damage/debris. Clean or clear debris as needed.
  3. Perform alignments of the affected PnP subsystem.
Large Leak in the System K03421596 Pneumatics detected a large leak in the system.
  1. Reboot the system and initialize while monitoring pressure in diagnostics.
  2. Check for signs of audible leaking from pneumatic tubing/fittings throughout the system.
  3. Confirm compressor is activating when needed (pressure <32 psi).
  4. Perform pneumatic leak test.
Level Sense Failure K56242117 Aliquot pipettor level sense failure at the sample container.
  1. Check sample volume in container and if truly insufficient add more or pour into a smaller aliquot container.
  2. Perform level sense test to investigate hardware failure.
  3. Check sample pipettor alignments.
  4. Check sample pipettor pump/pressure sensor components (level sense).
Lumi Dark count out of range K74977655 Luminometer dark count reading was above acceptable limits (>300 RLU) prior to sample read. May be associated with LDCH flags.
  1. Inspect Lumi area and analytic PnP for signs of splashing, clean as needed.
  2. Perform dark count reads and if values still exceed acceptable limit then consider cleaning luminometer.
  3. Consider luminometer calibration or replacement.
RSM Gripper Z-Axis Movement Failure K29694585 Z-axis slippage/movement failed for the RSM gripper.
  1. Open the RSM and clear any obstructions, manually home the gripper (lower left corner). If dislodged packs are found inspect for damage and discard to prevent future failures if pack is root cause.
  2. Initialize with remap and observe for further failures.
  3. Restart the system and repeat initialize/remap.
  4. Check alignments and perform RSM gripper timing calibration.
Sample Pipettor Collision Event K21072095 Collision sensor failure caused an event for aliquot or precise sample pipettor.
  1. Inspect the mandrel/collision sensor/flag and clean/repair as needed.
  2. Inspect for debris or obstruction (fallen tips or loose wires).
  3. Restart system.
  4. Check sample pipettor alignments.
USB Timeout K06023282 Communication error within the system. Restart the system to re-establish USB communication between the PCB's.
Sample Pipettor Failed to Discard Tip K54069154 Sample aliquot or precise pipettor failed to discard a tip.
  1. Inspect designated pipettor mandrel and remove tip/clean as needed.
  2. Inspect tip discard chute for obstruction causing a buildup of discarded tips creating an obstruction.
  3. Check sample pipettor alignment to tip discard chute.
SPU Motion Failure (On-Load Slippage / Failed to Pack Racks)

K55157209

K69251131

Generic motion failures for the sample presentation unit (SPU) / sample handler.
  1. Remove racks if present and inspect for damage/debris, discard or clean as needed.
  2. Clean SPU rails and ensure sensors are not obstructed by debris.
  3. Restart system and attempt loading empty racks to confirm they process from onload > presentation > offload without further errors.
  4. Check SPU alignments if issues persist.
Rack stuck in instrument, test queued but not processing K24386235 Rack appears "stuck" in the instrument and samples will nto process but no events are posted.
  1. Confirm all required supplies are sufficient and review system events/actions, resolve these first as applicable.
  2. Confirm system temperatures are within range.
  3. Restart the system and re-load the rack.
SYS flag with no associated events K02418841 Results are flagged with "SYS" but no associated system event is noted.
  1. Restart system and repeat samples.
  2. If flags persist, check analytic PnP alignments to wash wheel.
  3. Check wash wheel for debris or splashing residue, clean if found.
Reagent pack did not get QC by pack order, orders running at same time consolidated K81611387 This is a known bug currently without a temporary workaround, may need to repeat QC requests..
STO Flag (Substrate Timeout) K96383852 STO flag on result (substrate timeout), may correlate to first sample after initializing/priming. Flag designates that the substrate in the line/probe had been sitting for too long.
  1. Ensure the on-board substrate is not expired, replace if found.
  2. Prime the substrate system at least two cycles.
  3. Repeat samples.
  4. If flag persists, restart the system and repeat above.
ASD and Sample Diluent packs shown as due but are full K00244112 This is a known bug currently without a temporary workaround, the required supplies notification can be ignored.
Unable to switch/load substrate bottles K32791484 System will not allow user to load a new substrate bottle.
  1. Check events for further details (bottle already used, expired, barcode not read).
  2. Attempt loading a different bottle.
  3. Restart the system and repeat.
  4. Check substrate loader alignments.
Destination Slot Occupied, Unable to Deliver K14061128 Destination slot occupied error when PnP is trying to place a vessel.
  1. Open covers and inspect the affected PnP, remove vessel from PnP and any fallen vessels/debris in the area.
  2. Initialize system (ideally with "consolidation" selected).
  3. Restart system if issues persist.
  4. Check alignments/PnP hall effect sensor operation.
