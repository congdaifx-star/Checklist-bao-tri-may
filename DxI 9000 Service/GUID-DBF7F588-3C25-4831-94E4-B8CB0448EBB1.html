Troubleshooting the Luminometer

This topic includes information about how to troubleshoot issues with the luminometer.

Troubleshooting the Luminometer

Perform this procedure to troubleshoot issues with the luminometer.

  1. Clean the luminometer. See Cleaning the Luminometer for more information.
    Important: When you clean the luminometer, you must also clean and inspect the wash wheel, incubator wheel, and pick-and-place (PnP) components, because contamination in reaction vessels (RVs) originates within those subsystems.
    Tip: If the luminometer is wet inside, investigate the wash wheel for aspiration issues. For example, a clogged aspirate probe may cause RVs to overflow.
    Important: Be sure to torque all green signal cables to the proper value using the torque screwdriver and bit referenced in Cleaning the Luminometer. Otherwise, the cables will not connect correctly.
  2. Complete the following steps to determine whether MOD 13262 is necessary.
    Note: It may or may not fix your current issue. For instruments that need it, MOD will reduce chance of calibration failures in the future, it fixes one way calibration can fail.
    1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
    2. In the Machine Control App go to MENU > Machine Control > Luminometer > Luminometer.Assembly > Luminometer.Device.
    3. On the Action tab select GetCalibrationData.
    4. Select Execute.
      • If the value for CorrectionFactor is less than (<) 0.79, MOD 13262 is necessary.
      • If the value for CorrectionFactor is greater than (>) or equal to (=) 0.79, MOD 13262 is NOT necessary.
    5. For additional troubleshooting, see the following topics:
      • Troubleshooting Luminometer Initialization Failures
      • Troubleshooting Luminometer Calibration Failures
      • Troubleshooting Luminometer Dark Count Failures
      • Troubleshooting Luminometer Drift Failures
    6. If you are unable to resolve the issue using these troubleshooting steps, gather information for escalation. See Gathering Information for Escalating Issues with the Luminometer for more information.
