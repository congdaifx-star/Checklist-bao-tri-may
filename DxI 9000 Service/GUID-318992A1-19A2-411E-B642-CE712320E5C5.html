Configuring for Remisol on Local Ethernet with a Firewall Device

This topic includes information about how to configure a DxI 9000 instrument connected to a DxA to be managed by Remisol on the INSTRUMENTS Subnet of a firewall device.

When to Perform

Perform this procedure when the middleware/LIS managing the instrument is located locally, and a private subnet, separate from the lab network, is used, or when the instrument is connected to these entities using a peer-to-peer method, and when a firewall device is installed as a perimeter defense. This also applies to a Command Central server or to a network printer.

Configuring the DxI 9000

Perform the following procedures to configure the DxI 9000:

  • Enabling Automation on the DxI 9000
    Note: This is mandatory for DxI 9000 to DxA communication. If not already connected, perform this first.
  • Configuring the LIS Protocol on the DxI 9000
  • Configuring the IP Address for the Network
  • Configuring Port Forwarding for the Dynamic Interface
  • Configuring Port Forwarding for the Command Central Server

OpenVPN Requirements

In most situations, this configuration does not require you to install OpenVPN on any components in the lab network.
Note: OpenVPN encrypts PHI traffic to the LIS and provides for inbound connectivity over the firewall device as required by the Dynamic Interface from Remisol to the instrument and/or the connection from Command Central to the instrument.
However, you will need to install OpenVPN under the following conditions:
  • If Command Central needs to be located on the lab network. In this case, you must install the OpenVPN client on the PC where the Command Central server is installed.
  • If the Customer desires encrypted traffic between the DxI 9000 instrument and Remisol. In this case, you can install the OpenVPN client on the LIS PC.

See the Remote Solutions Service Manual for more information about how to install the OpenVPN client.

Connecting the Ethernet Cables to the DxI 9000

Connect the Ethernet cable from the INSTRUMENTS port on the firewall device to the eth4 port at the rear of the instrument.
