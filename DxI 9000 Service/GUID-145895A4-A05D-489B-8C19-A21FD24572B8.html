Configuring the IP Address for the Local/LIS Remisol Interface

This topic includes information about how to configure the IP address for the Local/LIS Remisol interface located on a private network separate from the customer network, if it must be different from the default setting.

Note: If multiple systems are connected, each must have its own static IP address.
Table 10: IP Addresses for Multiple Systems (example)
Instrument IP Address
DxI 9000 #1 192.168.150.191
DxI 9000 #2 192.168.150.192
  1. Access the EdgeMax router dashboard. See Accessing the EdgeMax Router Dashboard for more information.

  2. On the dashboard, for the Local LIS/Remisol (eth1) interface, select Actions and then select Config to open the Interface Configuration for eth1 window.
    Note: Because the Description for an interface can be modified, the Description may vary, but the (eth#) will remain the same.

  3. Enter the IP address. You must enter the subnet mask after the IP address.

    For example, if the IP address is 192.16.13.11 and the desired subnet mask is 255.255.255.0 then type 192.16.13.11/24.

  4. Select Save.
