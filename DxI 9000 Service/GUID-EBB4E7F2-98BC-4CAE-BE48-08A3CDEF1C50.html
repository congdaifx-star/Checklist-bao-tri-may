Troubleshooting Event Codes for the Luminometer

This topic includes information about how to troubleshoot event codes for the luminometer. The topic provides recovery steps for resolving the potential cause of symptoms, including event codes and failed diagnostics, for Luminometer and RLU signal issues.

In the table below, follow the recovery steps for the symptom identified by the event code.
Note: If the symptom clears after performing a recovery step, do not perform additional recovery steps but complete the verification of service repair.

Symptom

Potential Cause

Recovery Steps

The luminometer calibration data is incorrect.

Event code: 411030001

Auto-calibration during the drift correction routine run failed and/or a new device was installed.

  • Mismatch between HW device values and SW database values.
  • Not fully calibrated (i.e. failed calibration).
  1. Confirm all instrument covers are closed.
  2. Initialize the Instrument to a GREEN (Running) status.

If the symptom persists

  1. Calibrate the Luminometer. SeeCalibrating the Luminometer for more information.

    If calibration fails, clean the Luminometer and repeat this step. See Cleaning the Luminometer for more information.

  2. Reset the drift targets. See Resetting Drift Targets for more information.

    If resetting the drift targets fails, clean the Luminometer and repeat from Step 1.

  3. Complete the Luminometer drift detection procedure. See Performing Drift Detection for more information.

    If the Luminometer drift detection procedure fails, clean the Luminometer and repeat from Step 1.

If the symptom persists, clean the Luminometer and repeat from Step 1, "Calibrate the Luminometer" above.

If the symptom clears, complete the verification of service repair. See Verification of Service Repairs for more information.

The luminometer requires drift correction.

Event code: 411030101

  • Drift is outside the acceptable range after auto-correction and auto-calibration.
  • The calibrated PMT high voltage is outside the acceptable range.
  1. Confirm all instrument covers are closed.
  2. Initialize the Instrument to a GREEN (Running) status.

If the symptom persists

  1. Calibrate the Luminometer. SeeCalibrating the Luminometer for more information.

    If calibration fails, clean the Luminometer and repeat this step. See Cleaning the Luminometer for more information.

  2. Reset the drift targets. See Resetting Drift Targets for more information.

    If resetting the drift targets fails, clean the Luminometer and repeat from Step 1.

  3. Complete the Luminometer drift detection procedure. See Performing Drift Detection for more information.

    If the Luminometer drift detection procedure fails, clean the Luminometer and repeat from Step 1.

If the symptom clears, complete the verification of service repair. See Verification of Service Repairs for more information.

If the symptom persists

  1. Replace the Luminometer subsystem. See Replacing the Luminometer Subsystem for more information.
  2. Calibrate the Luminometer.

    If calibration fails, clean the Luminometer and repeat this step.

  3. Reset the drift targets.

    If resetting the drift targets fails, clean the Luminometer and repeat from Step 1.

  4. Complete the Luminometer drift detection procedure.

    If the Luminometer drift detection procedure fails, clean the Luminometer and repeat from Step 1.

If the symptom clears, complete the verification of service repair.

The luminometer drift detection values are missing.

Event code: 411030002

Target drift RLUs have not been established.

Reset the drift targets. See Resetting Drift Targets for more information.

If the symptom clears, complete the verification of service repair. See Verification of Service Repairs for more information.

The maximum RLU of the luminometer is insufficient for testing.

Event code: 411030003

The theoretical maximum RLU calculated too low based on calibration values.
  1. Confirm all instrument covers are closed.
  2. Initialize the Instrument to a GREEN (Running) status.
  3. Shut down the Instrument.
  4. Disconnect and reconnect all Luminometer connections.
  5. Turn on the Instrument and wait 15 minutes to complete the temperature equilibration process.

If the symptom persists

  1. Calibrate the Luminometer. SeeCalibrating the Luminometer for more information.

    If calibration fails, clean the Luminometer and repeat this step. See Cleaning the Luminometer for more information.

  2. Reset the drift targets. See Resetting Drift Targets for more information.

    If resetting the drift targets fails, clean the Luminometer and repeat from Step 1.

  3. Complete the Luminometer drift detection procedure. See Performing Drift Detection for more information.

    If the Luminometer drift detection procedure fails, clean the Luminometer and repeat from Step 1.

If the symptom clears, complete the verification of service repair. See Verification of Service Repairs for more information.

If the symptom persists

  1. Replace the Luminometer subsystem. See Replacing the Luminometer Subsystem for more information.
  2. Calibrate the Luminometer.

    If calibration fails, clean the Luminometer and repeat this step.

  3. Reset the drift targets.

    If resetting the drift targets fails, clean the Luminometer and repeat from Step 1.

  4. Complete the Luminometer drift detection procedure.

    If the Luminometer drift detection procedure fails, clean the Luminometer and repeat from Step 1.

If the symptom clears, complete the verification of service repair.

The luminometer high voltage is outside the expected range.

Event code: 411030004

Connections are not secure or tight.

The PMT is damaged.

  1. Confirm all instrument covers are closed.
  2. Initialize the Instrument to a GREEN (Running) status.
  3. Shut down the Instrument.
  4. Disconnect and reconnect all Luminometer connections.
    Note: The issue often exists due to a bad connection with the front push pin luminometer connections (gold connectors).
  5. Turn on the Instrument and wait 15 minutes to complete the temperature equilibration process.

If the symptom persists

  1. Calibrate the Luminometer. SeeCalibrating the Luminometer for more information.

    If calibration fails, clean the Luminometer and repeat this step. See Cleaning the Luminometer for more information.

  2. Reset the drift targets. See Resetting Drift Targets for more information.

    If resetting the drift targets fails, clean the Luminometer and repeat from Step 1.

  3. Complete the Luminometer drift detection procedure. See Performing Drift Detection for more information.

    If the Luminometer drift detection procedure fails, clean the Luminometer and repeat from Step 1.

If the symptom clears, complete the verification of service repair. See Verification of Service Repairs for more information.

If the symptom persists

  1. Replace the Luminometer subsystem. See Replacing the Luminometer Subsystem for more information.
  2. Calibrate the Luminometer.

    If calibration fails, clean the Luminometer and repeat this step.

  3. Reset the drift targets.

    If resetting the drift targets fails, clean the Luminometer and repeat from Step 1.

  4. Complete the Luminometer drift detection procedure.

    If the Luminometer drift detection procedure fails, clean the Luminometer and repeat from Step 1.

If the symptom clears, complete the verification of service repair.

Luminometer - MachineControlStatus (The Luminometer Reference value was out of range.)

The luminometer timed out while calibrating.

Event code: 411030005

Some other system operation is occurring at the same time.
  1. Confirm all instrument covers are closed.
  2. Initialize the Instrument to a GREEN (Running) status.
  3. Shut down the Instrument.
  4. Disconnect and reconnect the USB connection for the Luminometer.
  5. Turn on the Instrument and wait 15 minutes to complete the temperature equilibration process.

If the symptom persists

  1. Calibrate the Luminometer. SeeCalibrating the Luminometer for more information.

    If calibration fails, clean the Luminometer and repeat this step. See Cleaning the Luminometer for more information.

  2. Reset the drift targets. See Resetting Drift Targets for more information.

    If resetting the drift targets fails, clean the Luminometer and repeat from Step 1.

  3. Complete the Luminometer drift detection procedure. See Performing Drift Detection for more information.

    If the Luminometer drift detection procedure fails, clean the Luminometer and repeat from Step 1.

If the symptom clears, complete the verification of service repair. See Verification of Service Repairs for more information.

If the symptom persists

  1. Replace the Luminometer subsystem. See Replacing the Luminometer Subsystem for more information.
  2. Calibrate the Luminometer.

    If calibration fails, clean the Luminometer and repeat this step.

  3. Reset the drift targets.

    If resetting the drift targets fails, clean the Luminometer and repeat from Step 1.

  4. Complete the Luminometer drift detection procedure.

    If the Luminometer drift detection procedure fails, clean the Luminometer and repeat from Step 1.

If the symptom clears, complete the verification of service repair.

The luminometer detected dark count values that are out of range.

Event code: 411000001

The PMT is reading more light than expected during dark readings.

  • The cover is not closed.

  • Contamination, such as a spill or debris, is present.

  1. Confirm all instrument covers are closed.
  2. Initialize the Instrument to a GREEN (Running) status.
  3. Check the Luminometer dark counts. See Checking Dark Count Values for more information.

If the RLU reading is above 300 RLU

  1. Clean the Luminometer. See Cleaning the Luminometer for more information.
  2. Calibrate the Luminometer. SeeCalibrating the Luminometer for more information.
  3. Check the Luminometer dark counts.

If a spill was found

  1. Check the wash wheel aspirate probe connections.
  2. Check the PnP alignments.

If the symptom clears, complete the verification of service repair. See Verification of Service Repairs for more information.

If the symptom persists

  1. Replace the Luminometer subsystem. See Replacing the Luminometer Subsystem for more information.
  2. Calibrate the Luminometer.
  3. Reset the drift targets. See Resetting Drift Targets for more information.
  4. Complete the Luminometer drift detection procedure. See Performing Drift Detection for more information.

If the symptom clears, complete the verification of service repair.

The luminometer drift detection ASD was unable to verify the performance of the PMT.

Event code: 411000003

The system has not been allowed to check drift for 48 hours due to being offline or busy performing tests.

Complete the Luminometer drift detection procedure. See Performing Drift Detection for more information.

The luminometer drift detection failed to run.

Event code: 411000002

The system has not been allowed to check drift in the last 24 hours.

Note: SW 1.16 has been updated to run automatically so this should not happen anymore.

Complete the Luminometer drift detection procedure. See Performing Drift Detection for more information.

Supposed to be: Failed while attempting to open the luminometer door. SI 261113 created to fix.

Is: Generic event failure with details: Could not open the Luminometer's external door.

Event code: 411010101

Luminometer door was supposed to move but home sensor states not "as-expected."

  • Broken sensor(s).

  • Broken motor and cap, and/or wheel flag.

  1. Confirm all instrument covers are closed.
  2. Initialize the Instrument to a GREEN (Running) status.

If the symptom clears, complete the verification of service repair. See Verification of Service Repairs for more information.

If the symptom persists, inspect the open sensor and the closed sensor. If either sensor is broken or damaged, replace it. See Replacing the Door Sensors for more information.

If the symptom persists after inspecting the system for a broken or damaged open sensor or closed sensor and/or after replacing a sensor, inspect the motor, cap, and wheel flag. If either of these components is broken or damaged, replace it.

If the symptom ultimately clears, complete the verification of service repair. See Verification of Service Repairs for more information.
