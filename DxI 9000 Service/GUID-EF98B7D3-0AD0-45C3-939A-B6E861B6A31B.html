Verification of Instrument Installation

This topic includes information about the minimum verification you must complete after you install the instrument and before you proceed to the applications phase of the installation process.

Table 31: Definitions
Term Definition
Service Tasks Tasks to be completed either before or after instrument verification depending on the module serviced and the required verification.
Minimum Verification Required The minimum testing required before releasing the instrument to the customer for its intended use.
Procedure / Activity Performed Service Tasks Minimum Verification Required Data to be Collected
Instrument Installation
  • Prime substrate
  • Prime all other components
  • Enable the cover interlock system
  • Login to the LabUser account
ASD Tests
  • Luminometer Linearity
    Note: Luminometer Linearity ASD must be performed before any other ASD tests.
  • Substrate Blank
  • Wash Efficiency
  • Low Volume Reagent Pipetting
  • System Carryover
  • Precision Sample Pipetting
ASD printouts or screen captures
  • Luminometer Linearity
  • Substrate Blank
  • Wash Efficiency
  • Low Volume Reagent Pipetting
  • System Carryover
  • Precision Sample Pipetting
Instrument Move (within the same floor of the same building) Initialize the instrument None No data required
