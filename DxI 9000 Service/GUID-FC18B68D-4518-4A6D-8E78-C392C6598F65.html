Operating Principles for the Instrument's Data Files

This topic includes information about operating principles, or the theory of operation, for the instrument's data files.

Table of Contents

About the Data Files

The instrument's data files are a persisted form of Machine Control data for physical objects loaded onto the system, such as reagent packs, vessels, and associated sample information.

Data Description
DV List of vessels for use in creating sample dilutions on the Reaction Build Carriages.
EV List of empty vessels in the RV Supply Carriage and Sample Wheel.
MV List of maintenance vessels used throughput the system for priming, cleaning, maintenance, and diagnostic activities.
RV List of reaction vessels on the Reaction Build Carriages, Incubation Wheel, Wash Wheel, and Luminometer used to generate test results.
SV List of sample vessels on the Sample Wheel and Reaction Build Carriages used as a source of sample for test processing.
Sample Limited sample information used to restore the association with SV objects during startup.
ReagentPack List of on-board reagent packs, positions, and reagent volumes.

Interacting SQL database files are updated automatically after successful deletion and restart of apps. In addition, it’s worth noting that these .data files in the D:\ProgramData\Beckman Coulter\Falcon folder are associated with the SQL database application and are mentioned here for the purpose of association and reference. The SQL database application also shares some data with:

Database Data
ICE_DB Calibration data
ICE_QC_DB QC data
ICE_SAMPLES_DB Mostly patient data but also racks and general test results, and the test menu.

How and When the System Saves and Loads Data Files

The system saves the data files when you close the Machine Control App, and the system loads the files when you open the Machine Control App.

Troubleshooting Issues with Data Files

In a perfect world, the system should always persist data correctly, and the Machine Control App should never lose track of vessels and packs. However, you may encounter issues with the persisted data or issues with the sensors on the instrument that might cause a difference between where Machine Control thinks an object is located versus where it is actually located. To correct the issue, it is sometimes necessary to remove vessels and packs from the system.

If the data fails to load, or if the system detects differences between the restored data and the physical objects on the system, you must perform a full passenger consolidation and vessel remap. See Initializing the Instrument for more information.

In some situations, and as a last resort, you may need to delete the instrument's data files. See Deleting the Instrument's Data Files for more information.
Note: Do not delete any data file unless directed to do so by a level 2 (L2) field service engineer (FSE).
