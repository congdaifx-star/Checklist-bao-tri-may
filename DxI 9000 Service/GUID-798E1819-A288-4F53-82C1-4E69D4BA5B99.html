Luminometer Linearity ASD Test Overview

This process is internal to the Luminometer. The LED inside the luminometer is illuminated to a variety of voltages, and the slope of the voltage versus the sensor response is determined.

The acceptance criteria is that the percent difference of is greater than -2% and less than 2% for all targets.

This diagnostic takes ~22 minutes to complete.

When to Perform

Test luminometer linearity as required for verification of instrument performance following service activity. The luminometer linearity test will require approximately 20 minutes of service time.
Note: It is possible test luminometer linearity using both the ASD Tests page or intrusive diagnostics, but there are important differences:
  • If the instrument is in a GREEN (Ready) status, you must test luminometer linearity using the ASD Tests page to maintain easy access to viewing historical testing data using the Console App.
  • If the instrument is in a RED (Stopped) status, you can test luminometer linearity using intrusive diagnostics as needed during troubleshooting, but you must then access log files to view historical data for tests completed using intrusive diagnostics. See Testing Luminometer Linearity Using Intrusive Diagnostics for more information.

Performing the Luminometer Linearity Automated System Diagnostics (ASD) Test

  1. Be sure the instrument is in a GREEN (Ready) status.
  2. In the Console App go to Menu > Tools > ASD Tests to open the ASD Tests page.
  3. Select Luminometer Linearity.
  4. Select Order Diagnostics.

Reviewing Result Details and Historical Data

  1. In the Console App go to Menu > Tools > ASD Tests to open the ASD Tests page.
  2. Select Luminometer Linearity.
  3. Select Details to open the ASD History page.
  4. To view details for a specific test, in the Summary area in the Details column select View.
