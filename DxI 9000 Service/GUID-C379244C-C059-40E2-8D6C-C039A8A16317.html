Aligning the Sample Storage Wheel

This topic includes information about how to align the sample storage wheel.

Important: You must first initialize the instrument to a GREEN (Ready) status to ensure all subsystems have been successfully initialized and homed, and then you must enter the instrument into a BLUE (Maintenance) status before you complete an alignment procedure.

Safety Reminder

Servicing the DxI 9000 instrument involves potential risks for pinch and puncture, electrical shock, and exposure to hazardous materials. You must mitigate these risks by taking appropriate countermeasures. See Safety for more information.

Prerequisite

Before you complete this procedure, you must verify that alignments have previously been performed on the instrument. In the Machine Control App on the Prototype Alignments page, verify that the Finalize Instrument Alignments button is GRAY in color. If the button is BLUE in color, do not complete this procedure. Instead, you must first perform manual alignments.

Performing Alignments

  1. Turn on the instrument. See Turning On the Instrument for more information.
  2. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  3. Initialize the instrument. See Initializing the Instrument for more information.
    Note: If the instrument status changes to the RED (Stopped) status:
    • Verify interlock switch is in the correct position. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
    • Be sure you are signed in to use the BeckmanAdmin account.
    • In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
    • Perform the troubleshooting, adjustments, manual alignments, and maintenance needed to pass initialization.
  4. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  5. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  6. Perform the following alignments:
    • Aligning the Aliquot Sample Pipettor
    • Aligning the Sample PnP to the Sample Wheel - Inner Position
    • Aligning the Sample PnP to the Sample Wheel - Outer Position

Ending an Alignments and Adjustments Session

  1. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select End Session.
  2. Close all hoods and covers.
  3. Enable interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  4. Sign out from BeckmanAdmin account.
  5. Sign in to use the LabUser account.
  6. Initialize the instrument. See Initializing the Instrument for more information.

Verification

See Verification of Service Repairs for more information.
