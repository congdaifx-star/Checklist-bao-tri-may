Configuring Port Forwarding for the Dynamic Interface

This topic includes information about how to configure port forwarding for the Dynamic Interface.

  1. Access the EdgeMax router dashboard. See Accessing the EdgeMax Router Dashboard for more information.
  2. On the dashboard select Firewall/NAT.
  3. On the Port Forwarding tab select Add Rule.
  4. Enter the following information.
    • In Original port type 48842
    • In Protocol select Both
    • In Forward-to address type 172.16.6.2
    • In Forward-to port type 48842
    • In Description type Dynamic Interface

  5. Select Apply.
