Installing Firmware

This topic includes information about how to install firmware onto the dMCC, DAQC, spin mixer, ultrasonics, and temperature control boards for the DxI 9000 instrument.

Firmware Version Information

You can use the Console App to view the firmware versions of installed boards. See Viewing Firmware Version Information for more information.

Obtaining the Firmware Loader and Files from Box

  1. Open Box.
  2. In the Service Documentation - Dx\Immunoassay\DxI 9000\Files folder select Firmware Loader and Files.zip and download the file to a USB drive.
  3. Extract the files onto the USB drive.

Prepare to Install Firmware

  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.

Close the Console App and the Machine Control App.

Insert the USB drive with the firmware files into a USB port on the USB hub behind the console PC monitor.

Installing Firmware on dMCC Board

  1. On the USB drive open dMCC_USB_Programmer signed.exe to view the list of IDs.

  2. Each ID except 0 and 14 will display a version. The IDs 0 and 14 will display Not Found.
    Important: If any ID except 0 or 14 displays Not Found, be sure to troubleshoot the issue.
  3. Type ! and press Enter. After each board has been programmed, the notification Flash programming has finished- quitting will be displayed. Wait two to three minutes for all the boards to be programmed.

  4. Close the window.

Installing Firmware on DAQC Board

  1. On the USB drive open DAQC USB Programmer signed.exe.
  2. When notified to Press any key to continue, press any key.

  3. At the Command prompt type ? to view the menu.

  4. Type 1. Wait four to five minutes for the Done Writing notification.

  5. Confirm the values for USB Programmer Checksum and Nios Checksum match. If they don't match, programming failed. Repeat the steps above.
  6. Type ? to view the menu.
  7. Type 2 and wait for DAQC in FIFO mode to be displayed.

  8. Close the window.

Installing Firmware on Spin Mixer, Ultrasonics, and Temperature Control Boards

  1. On the USB drive open MC56F847XX USB Programmer signed.exe to display the Command prompt.

  2. Type U (the capital letter). Wait for programming to complete. The screen will stop updating.
  3. Confirm the config quantity is correct by the number of instances, as listed below.

    • 0081 qty 1 (spin mixer)
    • 0082 qty 6 (temp ctrl)
    • 0083 qty 1 (luminometer)
    • 0084 qty 2 (ultrasonics)
      Note: The luminometer is not being programmed. It shows up during the com scan for information only. Verify the luminometer was NOT programmed by confirming the absence of P=XXXX, D=XXXXX, B=XXXXX, ID= XXXX and Version= X.X.X.X after the line that displays Config=0083.

  4. Close the window.

Finishing the Installation Process

  1. Close File Explorer.
  2. Remove the USB drive from the USB hub behind the console PC monitor.
  3. Open the Console App and the Machine Control App.
  4. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
  5. Sign in to use the LabUser account.
