Clearing Passenger Obstructions from the Empty to Tray Waste Locations

Passenger obstructions in the empty to tray waste locations may occur due to the following reasons:
  • The tray waste drawer is partially open.
  • The internal latch is not closed.
  • The drawer alignment is off.
  • There is an erroneous tray waste passenger listed in the Machine Control passenger list.
  • There is a corrupt DATA (.dat) file.

Use this procedure to clear passenger obstructions from the empty to tray waste locations:

  1. In the Console App select the SYSTEM event indicator in the navigation bar. The analyzer will display the System Events page and list the errors that have occurred. If an error indicates there may be a tray obstruction or collision in the empty to tray waste locations, continue with this procedure.
  2. Open the assembly doors to verify that the internal latch for the tray waste drawer is secure.
  3. Close the assembly doors and verify that the doors are aligned properly.
  4. Complete the auto-alignment procedure for the DispoTip Stocker. See Auto-aligning the Tray Gripper for more information.
  5. Complete the verification of the service repair. See Verification of Service Repairs for more information.
