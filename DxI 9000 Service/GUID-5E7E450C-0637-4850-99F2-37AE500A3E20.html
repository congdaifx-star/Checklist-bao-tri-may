Clearing Passenger Obstructions from the Tray in Waiting to Tip Supply Locations

Passenger obstructions in the tray in waiting to tip supply locations may occur due to an incorrect passenger listing, a faulty tray gripper timing adjustment, a faulty tray gripper alignment, or a stuck anti-tray flip bearing.

Use this procedure to clear passenger obstructions from the tray in waiting to tip supply locations:

  1. Be sure you are signed in and using the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. In the Console App select the SYSTEM event indicator in the navigation bar. The analyzer will display the System Events page and list the errors that have occurred. If an error indicates there may be a tray in waiting to tip supply passenger obstruction, continue with this procedure.
  3. Disable the interlock system that controls the instrument cover locks. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  4. Open the tip stocker assembly. Manually remove all trays except the tip supply tray from all tip stocker locations.
  5. Return the tip stocker assembly to a properly secured state. Verify all latches and drawers have been secured.
  6. In the Machine Control App verify that the passengers in the tip stocker tray locations match the passengers in the Machine Control passenger list for those locations.
    • If the Machine Control passenger list includes erroneous passengers, you must clear the passengers from the list. See Clearing Passengers from Subsystem Locations in the Machine Control Passenger List for more information.
  7. Home the tray gripper assembly. See Homing the Tip Tray Gripper for more information.
  8. Shut down and restart the PC.
  9. Initialize the Instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
    Note: A successful remapping of the tray gripper assembly during initialization will clear from the Master Control passenger list any passengers that are not physically present in the tray stocker and tip supply locations. If passenger obstructions in the tray in waiting to tip supply locations continue to occur, complete the following additional substeps.
    1. Complete the auto-alignment procedure for the tray gripper. See Auto-aligning the Tray Gripper for more information.
    2. Initialize the Instrument to a GREEN (Ready) status.
    3. Confirm the Machine Control passenger list is correct for the tip stocker tray locations.
    4. Replenish the tip supply via the tip supply loader.
    5. Once again, confirm the Machine Control passenger list is correct for the tip stocker tray locations.
    6. Complete the verification of the service repair. See Verification of Service Repairs for more information.
      If Passenger obstructions in the tray in waiting to tip supply locations continue to occur, continue with the following additional substeps.
    7. Remove the tray from the tip supply location.
    8. Manually adjust the DispoTip Stocker angular arm. See Adjusting and Aligning the DispoTip Stocker Angular Arm for more information.
    9. Complete the auto-alignment procedure for the tray gripper.
    10. Initialize the instrument to a GREEN (Ready) status.
    11. Confirm the Machine Control passenger list is correct for the tip stocker tray locations.
    12. Replenish the tip supply tray via the tip supply loader.
    13. Once again, confirm the Machine Control passenger list is correct for the tip stocker tray locations.
    14. Complete the verification of the service repair.
  10. Initialize the instrument to a GREEN (Ready) status.
  11. Enable the interlock system that controls the Instrument cover locks.
  12. Sign out of the BeckmanAdmin user account and sign in to use the LabUser account.
