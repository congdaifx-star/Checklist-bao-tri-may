Configuring Sales and Service Contact Information

This topic includes information about how to configure sales and service contact information on the instrument.

  1. In the Console App go to MENU > System Configuration to open the System Configuration page.
  2. Go to Internal Use > Contact Information to open the Contact Information page.
  3. Type the geo-dependent, local contact information into the Service Number and Sales Number boxes.
  4. Type the instance ID into the Instance ID box.
  5. Go to System Configuration to return to the System Configuration page.
  6. Select Activate.
