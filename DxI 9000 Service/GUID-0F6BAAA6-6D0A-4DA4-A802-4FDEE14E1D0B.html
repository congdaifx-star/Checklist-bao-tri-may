Performing the Precision Sample Pipetting ASD Test

This topic includes information about performing the Precision Sample Pipetting Automated System Diagnostics (ASD) test, which measures the precision and accuracy of the precision sample pipettor and the dilution capabilities of the reagent pipettors.

Note: It is recommended to run Substrate Blank ASD first, followed by Wash Efficiency ASD. The order of running Low Volume Pipetting, System Carryover, or Precision Sample Pipetting ASD is interchangeable.

Precision Sample Pipetting ASD Test Overview

The Precision Sample Pipetting ASD test verifies the performance of the precision sample pipettor. The test
  • Verifies that the precision sample pipettor is correctly aligned to the reaction build carriages.
  • Assesses the dilution capabilities of the reagent pipettors.
  • Tests whether the precision sample pipettor can dispense defined sample volumes with precision, which is crucial for producing reliable test results.
Note: An earlier version of this test, the Low Volume Precision Pipetting ASD test, appeared in software versions 1.14 through 1.16.2. Software version 1.16.2 had a known issue that affected results. If the instrument software includes this earlier test, before you proceed, read more information about troubleshooting ASD test results. See Troubleshooting Automated System Diagnostics (ASD) Test Results for more information.

This ASD runs 5 replicates of 953, ASD LV PP on each reagent pipettor, for a total of 20 replicates.

For each replicate of 953, ASD LV PP:
  • An RV is retrieved from the RV supply carriage and moved to the specified RBC.
  • The reagent pipettor adds 240 uL of wash buffer to the RV.
  • The reagent pipettor retrieves 10 uL of ASD system check with a 10uL overdraw, and adds 10 uL of system check to the RV.
  • The reagent pipettor performs a full wash at the wash tower.
  • The reagent pipettor adds an additional 250 uL of wash buffer to the RV and performs a vessel mix on the RV.
  • The RV is moved to the incubate wheel and is incubated for 32 seconds. This RV is now used as an SV for the following steps.
  • A DV is moved from the RV supply to the next RBC (dilution builds use two RBCs).
  • The second reagent pipettor adds 52uL of wash buffer to the DV.
  • The SV is returned to the second RBC (dilution builds use two RBCs.).
  • An RV is moved to the first RBC (dilution builds use two RBCs.).
  • The first reagent pipettor adds an additional 45 uL of wash buffer to the RV.
  • A dilution is performed from the SV to the RV pulling 3 uL from the SV and mixing to 10 uL at the DV.
  • The precision pipettor takes a series of images of this process, first of the initial draw at the RV (3uL), second at the overdraw at the DV (10uL) and third at the dispense to the SV (5 uL).
  • The RV is incubated at the inc wheel for 32 seconds.
  • The RV is moved to the wash wheel, but no washing occurs. The RV moves around the wash wheel under normal scheduling, waiting 8 seconds at each position.
  • At the end of the wash wheel, the vessel receives 200 uL of substrate.
  • The RV is moved to the incubate wheel for the 48 second substrate incubation time.
  • The RV is moved to the Luminometer and a reading is recorded. (This is the official end of the timer on the Console screen).
  • The RV is removed from the Luminometer and discarded (Lumi -> incubate wheel -> solid waste).
  • Once all replicates are complete, a SpecialProbeClean runs on each of the pipettors, removing any residual system check. These take ~4.5 minutes to complete.

This diagnostic takes ~26 minutes to complete, 22 minutes for the diagnostic itself and 4 minutes for the probe cleans, as they will not start until the other replicates are completed due to the specified ordering or the replicates.

Requirements

  • System software 1.14 through 1.16.2 for Low Volume Precision Pipetting ASD test.
  • System software 1.17 or newer for Precision Sample Pipetting ASD test.
  • Automated System Diagnostic (ASD) Reagent Pack C23913 is loaded onto the system
  • Be sure all reagent pipettors are enabled.

Performing the Test

  1. Be sure the instrument is in a GREEN (Ready) status.
  2. In the Console App go to MENU > Tools > ASD Tests to open the ASD Tests page.
  3. Select Precision Sample Pipetting.
    Note: You may select multiple ASD tests.
  4. Select Order Diagnostics.
    Note: The system will prioritize patient, calibration, and QC samples over ASD tests, so the requested test may remain queued if other samples are being processed.
  5. The notification Completed will be displayed in the Status column when the test is complete.

Reviewing the Results

  1. On the ASD Tests page select Precision Sample Pipetting.
  2. Select Details.
  3. To view details for a specific test, in the Summary area in the Details column select View.
  4. If you need to troubleshoot the test results, capture a screenshot of the page and then proceed with troubleshooting. See Troubleshooting Automated System Diagnostics (ASD) Test Results for more information.
