Calibrating Gripper Timing

This topic includes information about how to calibrate timing for the gripper.

Prerequisites

Before you begin an alignment procedure:
  • If you must make changes to the instrument's hardware, you must complete those changes before you prepare the instrument for adjustments and alignments.
  • You must verify that alignments have previously been completed on the instrument. To verify, in the Machine Control App go to Menu > Prototype Alignment to open the Prototype Alignment page and to verify the Finalize Instrument Alignments button is GRAY in color. If the button is BLUE in color, do not complete this procedure. Instead, you must first complete manual alignments.
  • You must first initialize the instrument to a GREEN (Ready) status to ensure all subsystems have been successfully initialized and homed. You must then enter the instrument into a BLUE (Maintenance) status.
  • Perform this calibration with only one reagent pack on-board. If more than one pack is loaded, temporarily un-load all but one to perform the calibration. Performing with multiple packs may result in timeline errors and the calibration failing.

To calibrate RSM Gripper Timing:

  1. Sign in to use the BeckmanAdmin account. See Signing In to Use the BeckmanAdmin Account for more information.
  2. Disable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  3. Open all hoods and covers.
  4. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
    Note: If the instrument enters into a RED (Stopped) status:
    1. Verify the interlock switch is in the correct position.
    2. Be sure you are signed in to use the BeckmanAdmin account.
    3. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
    4. Complete all troubleshooting, adjustments, manual alignments, and maintenance necessary to be able to initialize the instrument to a GREEN (Ready) status.
  5. Select the SYSTEM RUNNING button and go to Stop > Pause to enter the instrument into a YELLOW (Paused) status.
  6. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics and select Start Session.
  7. In the Machine Control App go to MENU > Machine Control > ReagentStorage.
  8. On the Action tab select CalibrateGripperTiming.
  9. Select Execute. The system will transfer the onboard reagent pack from each nest to each pipettor nest to measure transfer time. Wait approximately 20 minutes for the process to complete.
    Note: Any errors, such as motor slips or bad grips on the on the packs, will cause the procedure to fail. If the procedure fails, troubleshoot the reagent storage module and then re-run the calibration. See the following troubleshooting procedures for more information:
    • Troubleshooting the Reagent Storage Module (RSM)
    • Manually Homing the RSM Gripper Assembly
    • Checking Compressor and Check Valve Functionality without the Use of House Air Supply
    • Aligning the Reagent Loader Tray
    • Aligning the Reagent Gripper
  10. In the Console App go to Menu > Tools > Diagnostics > Intrusive Diagnostics.
  11. Select End Session.
  12. Close all hoods and covers.
  13. Enable the interlock switch. See Enabling and Disabling the Interlock System for Cover Switch Sensors for more information.
  14. Sign out from the BeckmanAdmin account.
  15. Restart the console PC. See Restarting the Console PC for more information.
  16. Sign in to use the LabUser account.
  17. Initialize the instrument to a GREEN (Ready) status. See Initializing the Instrument for more information.
  18. Complete Verification. Refer to Verification of Service Repairs document for more details.
