Replacing the X-axis Carriage and Linear Slide

This topic includes information about how to replace the X-axis carriage and linear slide for the aliquot and precision sample pipettors.

Removal of the subsystem may be required for ease of access to certain components. If removal of the subsystem is deemed necessary, see the following procedures prior to component removal:
  • Replacing the Aliquot Sample Pipettor Subsystem
  • Replacing the Precision Sample Pipettor Subsystem

Refer to the table below for instructions on installing, removing, or replacing the desired component. Not all steps may be required depending on the component being replaced. The aliquot and precision sample pipettor subsystems are similar; they differ primarily in the size and orientation of the gantry and in range of motion. These instructions are written in a generic manner as to work with either subsystem, any specific details for subsystems will be listed in the notes.

Safety Reminder

Servicing the DxI 9000 instrument involves potential risks for pinch and puncture, electrical shock, and exposure to hazardous materials. You must mitigate these risks by taking appropriate countermeasures. See Safety for more information.

Recommended Tools

The following tools are recommended for replacement of the components listed in this topic:
  • 1.5mm hex driver (for M2 screws)
  • 2.5mm hex driver (for M3 screws)
  • 3mm hex driver (for M4 screws)

Removing the X-axis Carriage and Linear Slide

Perform this procedure to remove the x-axis carriage and linear slide.

  1. Disconnect and remove the following cables/tubing from the carriage:
    • Z-axis motor/encoder cables from the motor/encoder assembly
    • Z-axis home sensor from the cable leading to the dMCC
    • Remove the belt from the x-carriage belt clip
  2. Remove the four screws (2.5mm driver) securing the x-axis carriage to the x-axis linear rail truck, and remove the x-axis carriage.
  3. Remove the screws (2.5mm driver) securing the x-axis linear rail to the gantry, and remove the x-axis linear rail.
    Caution: Ensure that the linear rail truck does not slide off the end of the linear rail.
    • Aliquot Sample Pipettor linear rail is secured with 7 screws.
    • Precision Sample Pipettor linear rail is secured with 8 screws.

Installing the X-axis Carriage and Linear Slide

Perform this procedure to install the x-axis carriage and linear slide.

  1. Install the x-axis linear rail and secure with screws (2.5mm driver).
    Caution: Ensure that the linear rail truck does not slide off the end of the linear rail.
    • Aliquot Sample Pipettor linear rail is secured with 7 screws.
    • Precision Sample Pipettor linear rail is secured with 8 screws.
  2. Install the x-axis carriage onto the x-axis linear rail truck and secure with four screws (2.5mm driver).
    Note: Ensure to adjust the machined reference surface of the x-axis carriage to the x-axis linear rail truck when tightening screws. This ensures perpendicularity of the mandrel at pipetting positions.
    1 Reference machined surface
    2 Linear rail truck
    3 Carriage

  3. Install and connect the following cables/tubing onto the carriage:
    • Z-axis motor/encoder cables from the motor/encoder assembly
    • Z-axis home sensor from the cable leading to the dMCC
    • Install the belt to x-carriage belt clip

Alignments

Perform alignments. See the following topics for more information.

  • Aligning the Precision Sample Pipettor
  • Aligning the Aliquot Sample Pipettor

Verification

Complete the verification of service repair. See Verification of Service Repairs for more information.
