Detecting and Removing Malware from USB Drives

This topic includes information about how to detect and remove malware from USB drives used on Beckman Coulter instruments and products.
Important: You must use a malware detection and removal tool to prepare any USB drive for use on any Beckman Coulter instrument or product. You must perform the following procedure BEFORE AND AFTER you use any USB drive on a Beckman Coulter instrument or product.
  1. Download the malware detection and removal tool. See Downloading the Malware Detection and Removal Tool for more information.
  2. Insert the USB drive into your laptop.
  3. In File Explorer, select This PC to display the drive letter assigned to your USB drive.
  4. Open the malware detection and removal tool (MSERT.exe) that you downloaded to start the Microsoft Safety Scanner wizard.
  5. Select Accept all terms of the preceding license agreement.
  6. Select Next, and select Next again to proceed to the Scan type page..
  7. On the Scan type page, select Customized scan. Select Choose Folder and select the drive letter for the USB drive. Select Select Folder.

  8. Select Next to start the scan.
    Note: Even though you selected the USB drive, the tool will also perform a quick scan of the C drive. Wait for the scan to complete. A progress bar and timer will be displayed. The tool will indicate whether malware was found.
    • If no malware was found, select Finish. You may use the USB drive.
    • If malware was found, the tool will indicate that viruses, spyware, and other potentially unwanted software was detected and removed. Select View detailed results of the scan to view the report.
    • If malware was found but the tool was unable to remove the malware, contact Global Product Security at ProductSecurity@beckman.com for next steps.

  9. Capture a screenshot that shows the details about the malware found.
  10. Open File Explorer.
  11. Go to C:\Windows\debug and locate the MSERT log file.
  12. Email the MSERT log file, along with the screenshots of the reported malware found, to ProductSecurity@beckman.com
  13. Repeat this procedure each time you use the USB drive on an instrument or product. Remember, you must perform this procedure BEFORE AND AFTER you use any USB drive on a Beckman Coulter instrument or product. If malware or a virus is detected on a USB drive after you have used it with a BEC instrument or product, follow the procedure to remove malware from the affected product. See Detecting and Removing Malware and Detecting and Removing Malware from the Instrument for more information.
