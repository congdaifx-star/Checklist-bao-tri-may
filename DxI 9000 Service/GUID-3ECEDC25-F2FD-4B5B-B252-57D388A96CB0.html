Troubleshooting Sample Processing Flags

This topic includes information about how to troubleshoot fatal flags and warning flags for events that occur while processing samples.

Fatal Flags

A Fatal flag is applied when an event has occurred while processing a test, which may cause the test result to be inaccurate. The result is displayed or printed with the flag.

Flag Name Flag Description Information for Troubleshooting
Instrument Error SYS A device error occurred during a scheduled event for an RV.

Warning Flags

A Warning flag is applied when an event has occurred while processing a test, which indicates that the test result requires attention. The result is displayed or printed with the flag. It is left to the discretion of the operator whether or not to report the result.

Flag Name Flag Description Information for Troubleshooting
Unofficial Configuration IUO-C The system detects an unofficial configuration was used to run the test. Acceptable to occur in development. DxI 9000 Sample Flags Specification.pdf
Unofficial Recipe IUO-R The system detects an unofficial recipe was used to run the test. Acceptable to occur in development. DxI 9000 Sample Flags Specification.pdf
IUO Mode IUO-S The system detects an internal use only software was used to run the test. Acceptable to occur. Note: IUO-S can be confirmed by observing the "Investigation Use Only" text at the top of the home screen of the application. DxI 9000 Sample Flags Specification.pdf
Overrange OVR > The result is above the highest or most concentrated calibrator. The OVR flag is available only to quantitative and semi-quantitative assays. For semi-quantitative assays only: If APF (Calib file, cell #160, Report Over Range) is set to zero, the interpretation will be set to "No Value".

DxI 9000 Sample Flags Specification.pdf

On-board Dilution (OBD) Assays and Reagent Pipettor Pairings

LowResult LOW < The result is lower than the minimum reportable results per Cal file DxI 9000 Sample Flags Specification.pdf
High H The result is above the upper limit of the reference range. DxI 9000 Sample Flags Specification.pdf
Low L The result is less than the configured reference range minimum threshold and is greater than or equal to the configured critical low threshold DxI 9000 Sample Flags Specification.pdf
Critically High HH The result is greater than the configured critically high threshold In the event the critically high threshold and the reference range maximum threshold are the same value, this flag would not be applied. DxI 9000 Sample Flags Specification.pdf
Critically Low LL The result is less than the configured critically low threshold In the event the critically low threshold and the reference range maximum threshold are the same value, this flag would not be applied. DxI 9000 Sample Flags Specification.pdf
LumRange RLU The analog voltage reading is at the maximum level of detectability. DxI 9000 Sample Flags Specification.pdf
