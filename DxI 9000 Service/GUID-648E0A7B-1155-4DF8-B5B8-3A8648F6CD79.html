Gathering the Right Information Before You Ask for Help

This topic includes information about the context Technical Support needs to assist you with solving problems, and about how to assemble that context.

Problems and Related Data

The following tables list common issues and the information you need to gather for various types of problems.

Type of Problem Common Issues Information Needed

Hardware

Issues with physical components of the instruments.

  • Alignments
  • Motor slippage
  • Component temperatures
  • USB problems
  • Camera issues
  • Machine Control App Logs - Data in the D: Drive
  • Images/Videos - Data in Other Locations
  • Alignment Data Exports - Data in Other Locations
  • JOBFILE (if camera related) - Data in Other Locations

PC Performance

Issues related to the performance of the instrument computer and screens.

  • PC freezing
  • Slow displays
  • Long, unexpected waits
  • High CPU warnings
  • Machine Control App Logs - Data in the D: Drive
  • Console App Logs - Data in the D: Drive
  • Agent Logs - Data in the D: Drive
  • Windows Event Logs - Data in Other Locations
  • System Monitor Agent Logs - Data in the D: Drive

Assays

Issues with Calibration, QC, Patient Results, that relate to the assay or RAPID.

  • Incorrect Results
  • Unit discrepancy
  • Calibration problems
  • No results
  • RAPID settings
  • Machine Control App Logs - Data in the D: Drive
  • Console App Logs - Data in the D: Drive
  • Result Processing Agent Logs - Data in the D: Drive
  • Automation DAC Logs - Data in the D: Drive
  • Calibration DAC Logs - Data in the D: Drive
  • Image/Video/Screenshot - Data in Other Locations
  • Results to Disk exports (If applicable) - Data in Other Locations

Software

Issues that stem from software running on the instrument.

  • Displays not working
  • Remisol
  • Database
  • RSU
  • LIS
  • Issues after updates
  • Updating/Loading RAPIDs
  • Machine Control App Logs - Data in the D: Drive
  • Dynamic Comm Logs - Data in the D: Drive
  • Dynamic Interface Agent Logs - Data in the D: Drive
  • LIS Agent Log (If LIS Problem) - Data in the D: Drive
  • RSU Service Log (If RSU Problem) - Data in the C: Drive
  • Image/Video/Screenshot - Data in Other Locations
  • State Management DAC Logs - Data in the D: Drive
  • System Monitor Agent Logs - Data in the D: Drive

Subsystem Communications

Subsystem issues when interacting with other systems.

  • Reagent Pipettor Rendezvous
  • Missing passengers
  • Machine Control App Logs - Data in the D: Drive
  • Alignment Data Exports - Data in Other Locations
  • Sample DAC logs - Data in the D: Drive

Data in Other Locations

The following table includes information about other log files and evidence and their locations.

Evidence Type Use / Desc. Location
Alignment Data Export Alignment issues
  1. in the Machine Control App go to MENU > Prototype Alignment to open the Prototype Alignment page.
  2. Select Export Instrument Alignments.
JOBFILE Cameras See Exporting a Cognex Camera JOBFILE for more information.
BAR Service Logs regarding system backup and recovery operations (No specific path provided in original text)
Database Backup Database / DAC issues See Backing Up the Databases Using Microsoft SQL Server Management Studio for more information.
Picture/Video Physically alignment issues, workflows, intermittent issues (No specific path provided in original text)
Results To Disk Export Result, Pack Use Issues

See Exporting Results to Disk for more information.

Windows Event Log (System, Application) Computer/Operating System
  1. Press the Windows key, type event viewer, and press Enter to open Event Viewer.
  2. Select Widows Logs to display the Windows Logs pane.
  3. In the Windows Logs pane select Application or System.
  4. In the Actions pane select Save All Events As...
