Troubleshooting the Wash Buffer Fluid Detection Sensor

This topic includes information about how to troubleshoot issues with the wash buffer fluid detection sensor.

Table of Contents

About the Wash Buffer Fluid Detection Sensor

The wash buffer fluid detection sensor is located on the back side of the wash buffer container drawer. Wash buffer fluid tubing is routed between the arms of the sensor. The sensor reads voltage across the sensor to detect the difference between fluid or air in the tube.

Testing the Wash Buffer Fluid Detection Sensor

Perform this procedure to test the wash buffer fluid detection sensor.

  1. In the Machine Control App go to MENU > Machine Control > WashFluidics > WashFluidics.Assembly > WashFluidics.BufferSupply > WashFluidics.FluidDetector.
  2. On the Action tab select GetVoltage.

  3. Select Execute.
    • If the voltage reading is less than 2.5, there is air in the wash buffer fluid tube.
    • If the voltage reading is 2.5 or greater, there is fluid in the tube.
