Verifying the Date and Time Settings from Windows Desktop

This procedure describes how to verify or adjust the Date&Time and Time Zone settings from Windows Desktop.
Note:
  • For DxI System - If the Console PC's and AU's "Date&Time" and "Time Zone" settings are not matching, then system will fail initialization with "Failed to Synchronize Clocks" error.
  • For Access 2 System - If the Console PC's "Date&Time" and "Time Zone" settings are incorrect, customers may lose onboard samples to early expiration time and Access 2 will not get any UI messages.
  1. Verify the date and time settings in Windows XP from the Windows desktop.
    1. Double-click the clock at the bottom right corner of the Windows desktop.
    2. Select the Time Zone tab in the Date and Time Properties window. Set the time zone properties to these options:
      • Select (GMT) Greenwich Mean Time: Dublin, Edinburgh, Lisbon, London
      • Cancel the selection, Automatically adjust clock for daylight saving changes
    3. Select the Date & Time tab, enter the correct local time, and select OK.
  2. Verify the date and time settings in Windows 8 from the Windows desktop.
    1. Click on the clock at the bottom right corner of the Windows desktop.
    2. In the pop up window select Change date and time to adjust the time or select Change time zone to adjust the time zone if needed.
      Note: Coordinated Universal Time is the default setting and does not observe Daylight Savings.
    3. When date, time, and time zone have been verified select OK.
