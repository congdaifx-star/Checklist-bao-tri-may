Software V4.2 and V4.2.1 Release Notes

Purpose

This document provides details of the most significant features and enhancements in DxI software version 4.2.

Confidentiality

Software release notes are confidential and should not be shared with customers.

Hardware Changes Enabled

These major hardware changes are included in this software version:
  • Integrated system capability (DxC 860i, 680i 660i)

Enhancements

These enhancements are included in software version 4.2:
  • RMS phase II
  • Added scheduling priority by assay and assay number
  • LAS tube setup now allows for flexible reserve volume
  • Rack ID dialog shows the type of reserve volume being drawn
  • Supplies required now show the lot number for needed reagents (calibrations)
  • Scheduler optimization to handle high throughput sites
  • Added new calibration expiration date edit box for shared packs for parent and child assays in reagent detail dialog
These enhancements are included in software version 4.2.1:
  • RMS phase II:
    • Reporting LED DCF to four decimal points
    • Added Target field to allow file transfer from the AU
    • Required changes to allow metering for Remisol

Diagnostics Improvements

These improvements to Diagnostics are included in software version 4.2:
  • Updated DxI and UCTA carryover tests to isolate the running of the carryover test from patient, QC, or other samples. Also modified procedure to ensure hot sample is run.
  • Improved error detection for derived assay formulas
  • Improved synchronization between DxC and DxI in an integrated system to resolve test requests better.
  • Updates to qualitative calibration curve failure modes
  • Set tube number to one base in QNS event
  • Corrected issue with stranded vessel in the sample wheel
  • Added encoder count for dual carriage gantry errors
  • Fixed synchronization between DxC and DxI for ranges
  • Fixed issue with duplicate QC tiles
  • Fixed issue on integrated system where samples without patient ID
  • SV aliquoted from the UCTA now expires after 20 minutes and is not run
These improvements to Diagnostics are included in software version 4.2.1:
  • Integrated Systems:
    • Corrected the assay user units change.
    • Corrected display of incorrect patient name after DxC DB renewal or backup and restor.e
  • Removed Test not enabled event log warning from all DxI configurations except integrated.
  • Corrected database errors and instrument model crashes found during limited distribution of V4.2.
    • Semi-automatic restart of the console software if the console crashes.
  • Re-enabled sample pipettor process monitoring drift checks.
