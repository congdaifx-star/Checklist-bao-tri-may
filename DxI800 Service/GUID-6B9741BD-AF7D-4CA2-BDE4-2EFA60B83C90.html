DxI Software V7.1.0 Release Notes

Purpose
  • This document provides details of the most significant features and enhancements included in DxI software version 7.1.0.
Confidentiality
  • Software release notes are confidential and should not be shared with customers.
Background
  • DxI software version 7.1.0 was released to fielded instruments as mandatory Mod 12945.
  • The software requires regulatory clearance in all geographies and the Mod was not released in all geographies on the original release date of Mod 12945.
  • Refer to Oracle Mod 12945 to determine if software version 7.1.0 is released for a specific instrument or geography.
  • Software version 7.1.0 will only ship with new instruments for geographies that have regulatory clearance.
  • The previous software version (5.7.0) will continue to be shipped with new instruments to geographies that have not received regulatory clearance.
  • DxI software version 7.1.0 can be installed on Windows XPe or 8e operating systems.
Feature Overview
Feature Description
4-Digit APF

Ability to add additional Investigational Use Only (IUO) or IVD assays with new 4-digit APF numbers.

Type Existing Proposed Range
IUO or IVD / QC assays 100 - 899 IUO or IVD / QC assays 100 - 4095
Reagent Lot Correction Account for variation in performance across a production run during pack manufacturing, A lot correction factor ID is added to the reagent pack bar code. This ID is used during calibration to adjust the concentration value.
Reagent Authentication Enhance the security level of the reagent top label barcode to reduce the chance of barcodes being reverse engineered and used for unauthorized reagents.
Associate Reagent Lot with Test ID In the current system software, the same reagent lot numbers are allowed across different assays. This feature will ensure the lot numbers are unique across different assays.
Expand Reagent Lot Serial Number Add a character to the serial number of the reagent pack barcode to allow lot sizes to be increased.
BAssert Utility Assay Error Update the memory handling of the events framework to prevent BAssert errors from occurring during the utility assay.
Expected Behavior
  • Same as version 7.0.0.
