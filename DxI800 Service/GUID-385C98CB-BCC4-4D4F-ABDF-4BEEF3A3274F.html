Replacing Encoders

This procedure describes how to disassemble and reassemble the encoders on the DxI instrument when replacing an encoder or removing and reassembling an encoder to obtain access to other components.

Required Materials:
  • 0.050-in (1.27-mm) hex wrench
  • 0.040-in (1.016-mm) feeler gauge set

Encoders are shipped as an assembled unit.

Note: The device is assembled with all of the parts shown in this exploded view except the hub/code wheel. The code wheel is sent externally from the encoder (because there is nothing to attach it to until it is installed into the instrument).
Prerequisites:
  • To access an encoder on the analytical module, first remove the analytical module from the instrument.
    Note: Refer to the AU: Removing Analytical Module procedure.
  • To access an encoder on the sample storage module, first remove the sample storage module from the instrument. Refer to the procedure.
  • To access an encoder on the reagent storage module (x-encoder rear), first remove the reagent storage module from the instrument. Refer to the procedure.
  • To access an encoder on the reagent storage module (y-encoder right side), first remove the cover from the reagent storage module.
  1. Remove the encoder.
    Caution: The encoder wheel inside the encoder assembly is attached to the motor shaft with a set-screw. The set-screw must be loosened before attempting to remove the encoder assembly from the module.
    1. Remove the encoder cover.
    2. Remove the screws holding the encoder module into position, and then remove the encoder module.
    3. Loosen the set-screw in the code wheel, and then remove the code wheel.
    4. Remove the two screws that attach the encoder base to the module or motor.
      Note: Some encoder bases have these screws on 'ears' and others have these screws directly into the base of the encoder.
    5. Remove the encoder.
  2. Install the encoder.
    1. Mount the base. Secure the base to the mounting surface.
      Note: Before tightening the mounting screws, center the hole in the base shaft around the shaft.
    2. Install a spacer.
      The spacer tool is not provided with new encoders. The picture provides an indication of the surface to be used to center the code wheel when while installing it. A feeler gauge, set to 0.040 inches, can used to space the code wheel to the correct height above the base.
    3. Install the code wheel. With the code wheel disk towards top, slip the hub disk assembly over the shaft until it bottoms out against the (feeler gauge) spacer tool. While pressing down on the hub, tighten the set-screw with the hex wrench.
    4. Install the encoder module. With the thick side of module towards bottom, slip the optical module into position until the two alignment pins slip into the holes of module. Secure the module with the two 4-40 x 1/2-in screws.
    5. Inspect the code wheel and module assembly from the side, and verify that the code wheel is centered in the module slot. If the wheel is not centered, loosen the set-screw and adjust the wheel to center it in the sensor. Tighten the set-screw.
    6. Install the cover. Place the housing (cover) over the assembly and secure with the two 4-40 x 5/8-in cover screws.
    7. Connect the power/signal cable for the encoder.
  3. Reassemble the module, and then install it in the instrument.
    Caution: When replacing an encoder on the reagent storage module, manually move the gripper assembly fully to the left and down before installing the module cover.
  4. Verify the proper operation of the encoder.
    1. Use diagnostics and move the device to several locations, home it, and move to position. Ensure that no errors occur on that device.
