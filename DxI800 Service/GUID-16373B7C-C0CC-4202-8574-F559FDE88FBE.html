Installing Wash Pick-and-Place

This procedure describes how to install the wash pick-and-place.

Perform this procedure when a wash pick-and-place has been removed for repair or replacement.
  1. Prepare the instrument.
    Caution: Do not remove the towers from the base plate (if at all possible). Removing the towers makes it much more difficult to adjust and align the sample pipettor module after it is installed.
    1. If installing the entire assembly, including the tower, then:
      • Remove the center gray rear cover, and place it in a location where it is safe from damage.
      • Remove the upper rear cover, and place it in a location where it is safe from damage.
    2. Open the upper left and right front covers.
    3. Remove power from the motors by using the switch on the Power Distribution PCB labeled "All DC power (except CPU and reagent coolers)".
  2. Install the wash pick-and-place.
    1. Install the gantry using one of two options: install new gantry only or install new gantry and new mounting towers.
      • If replacing a pick-and-place (new gantry only), remove the new gantry from the towers and install it on the mounting towers currently in place.
        1. Align the gantry mounting holes with the tower locating pins.
        2. Push the gantry onto the pins.
        3. Tighten the two captive screws that hold the gantry to the towers.
      • If installing a pick-and-place and mounting towers, mount each tower (with the gantry attached) to the instrument base plate using the four mounting screws.
        Note: The location of the incubator pick-and-place towers may have been marked on the instrument base plate.
        Caution: If the tower locations were not marked on the base plate, adjustments and alignments are required.
    2. Replace the connectors on the wash pick-and-place interface PCB.
      • J1 - Ribbon Cable
      • J2 - Wash P&P Motor
    3. Install the air line into the wash pick-and-place air valve.
      Note: Push the tubing fully into the wash pick-and-place air valve fitting.
    4. Insert the interlock bypass.
    5. Restore power to the motors by using the switch on the Power Distribution PCB labeled "All DC power (except CPU and reagent coolers)".
    6. Configure or verify the SMC.ini files to ensure the Pick and Place x-motor run current is operated at 2.0 amps. Refer to Configuring Pick and Place Gantries X-Motors Run Current to Operate at 2.0 Amps procedure.
  3. Complete the installation of the wash pick-and-place module.
    1. Confirm the pick-and-place alignments to all intersecting devices. Align and/or adjust as needed.
    2. Initialize the instrument.
    3. Perform 25 cycles of the reaction route exerciser to ensure proper movement of the wash pick-and-place.
    4. Remove the interlock bypass and close the covers.
    5. Initialize the instrument.
