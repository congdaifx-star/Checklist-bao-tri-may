Troubleshooting Mixer Errors

Purpose

This document provides information on troubleshooting mixer errors.

When To Perform

Troubleshoot when the Event Log reports:
  • Unable to initialize instrument because of mixer motor speed errors.
  • The mixer is too slow, too fast, or jammed.
Note: If the mixer speed calibration fails during initialization, then the motor might only rotate slowly in one direction and might not rotate in the other direction. When the mixer speed fails during initialization, the software leaves the speed controller in a random state that does not typically run the motor at a normal speed when enabled in Diagnostics.

Mixer Speed Errors

If the mixer speed error is caused by Then perform these troubleshooting steps
Speed sensor failures, broken sensor wires
  1. Move the belt or index wheel slowly by hand to produce a 4.2 V or a 0.03 V output at TP10 on the interface PCB. A broken sensor or wire produces no change in the output when the belt is moved, or a change when the wires are wiggled near the sensor.
    Note:
    • If a volt meter is not available, then connect the sensor to J6 and use the LED for that connector to indicate the sensor status.
    • Sensor issues can cause the detected speed to be too high or too low.
    • Check for poor soldering of the mixer tach connector J8 to the interface PCB. Poor soldering can cause speed sensing issues that are evident on TP10.
  2. Check the mixer speed signal at TP10 while running the motor. Wiggle the wires near the sensor. If the tach sensor signal is lost, then there could be a broken wire.
    Note: Refer to the AU: Running Mixer Motor During Troubleshooting procedure.
    Note: The DVOM averages the 0.03 V and 4.2 V sensor states at TP10 to a reading of approximately 3 V when the motor is running.
  3. Check the mixer speed measured by the software. View the rpm by selecting Subsystem Diagnostics > RV Mixer > Start Test.

    If the sensor output is normal at TP10, but the tach reading in diagnostics is 0 when the motor is running, then investigate the ribbon cables J1-19 to MCC backplane J72-19 and from the MCC backplane J2-49 to the COMC PCB J2-49.

    Note:
    • J4 or J2 can be used to run the motor during the speed test. The motor speed using J2 motor power is whatever speed the controller is set to during initialization. If the mixer speed calibration fails during initialization, then the motor might only rotate slowly in one direction and might not rotate in the other direction.
    • Running the RV mixer speed test with a failed initialization can cause the AU machine control program to exit.
    • The system hardware and software for the RPM display converts the tach signal on TP10 after it goes to the COMC PCB J2 Pin 49.
    • Ribbon cable damage where the cables cross between the left and right main top covers has caused the tach signal to be shorted to ground. Check for cable damage.
    • The formula for measuring the rpm using the Hz function of the DVOM at TP10 is: 2.82 x TP10 Hz = Mixer Tach RPM display. (780 Hz = 2200 rpm)
    • The mixer speed specification is 2200 ±112 rpm to initialize and after initialization 2200 ±770 rpm.
    • Belt dust in the holes of the speed sensor index wheel can cause the indicated speed to be lower than the actual speed.
Motor failure, broken motor wires Run the mixer motor and wiggle the motor wires to see if the motor stops.
Note: Refer to the AU: Running Mixer Motor During Troubleshooting procedure.
Note: The motor wires typically break at the solder joints inside the shrink tubes on top of the motor, or where the motor cable is tie wrapped to the motor.
Excessive drag from bushings or bearings
  1. After replacing the spinner grippers, run the motor, belt, and spinners with the motor power connected to the mix arm eject power connector J4 for several minutes to loosen up the spinner-gripper bearings. Then initialize the system.
    Note: Refer to the AU: Running Mixer Motor During Troubleshooting procedure.
  2. Relieve the tension on the speed sensor tensioner arm slightly while the motor is running to see it the speed increases.
    Note:
    • Push the belt tensioner arm to relieve the belt tension.
    • An increase in speed indicates a possible speed sensor bushing or idler pulley bushing issue. The bushing drag is load sensitive.
Loss of motor power or speed control or signal
  1. Swap MCC7 with MCC6 and reseat the cable from J1 on the Upper Analytical interface PCB to J72 on the MCC backplane PCB.
    Note:
    • Measuring the motor control voltage at J2 on the Upper Analytical interface PCB is not useful. When the mixer speed fails during initialization, the software leaves the speed controller in a random state which does not typically run the motor at a normal speed. The voltage at the motor power terminals is set to confusingly random values. Use the mixer arm eject connector J4 to power the motor for troubleshooting. Verify motor and speed sensor operation before investigating the motor drive voltage on J2.
    • MCC7 through J72-12-13-14-15 to J1 on the interface PCB control the speed up or down and direction signals. This operates a digital speed control circuit on the interface PCB.
    • The only hardware failure ever noted in the motor power at J2 has been poor soldering of the two heatsinked resistors R13 and R15 located above J2 on the interface PCB.
  2. Restart the instrument machine control software or reboot the AU to start a new trace file in the C:\AU\Log folder.
  3. Examine the trace file for the mixer speed calibration entry (Mixer Speed: xxxx.x, at DAC value = xx).
    Note: To pass calibration, the speed must reach 2100 rpm with a DAC control value less than 99.
