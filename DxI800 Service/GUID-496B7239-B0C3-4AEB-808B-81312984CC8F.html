Performing Database Maintenance through User Interface

This procedure describes how to perform database maintenance through the user interface (UI).

Table 14: Database Maintenance Features
Topic Notes
Function
  • The Database Maintenance button reboots the PC, performs a database consistency check, and reorganizes the database, when the user interface launches.
  • The Database Maintenance button does not clear in-progress reps or fix curves.
Modes available
  • The Database Maintenance button is active when the instrument is Ready or Not Ready mode.
  • The button is not active when the instrument is in Running mode.
  • Database maintenance occurs automatically when the software is installed.
Prerequisite Software Versions 4.4 and higher.
Time to completion The run time depends on the how many tests or objects are in the database. Range: 5 minutes to over 2 hours.
Perform database maintenance when:
  • Database errors occur.
  • Jammed critical events occur.
  • Looking for checksum errors in the database.
  • The database needs to be compressed to reduce size and improve user interface performance.
  1. In the user interface, select Configure > PC Admin  > Database Maintenance.
    Note: The Database Maintenance button is only active when the instrument is in Ready or Not Ready mode.
  2. Enter the password Access2Support.
  3. Select OK > OK.
    Note: The PC reboots and performs database maintenance while the user interface launches.
    Note: When rebooting the Privacy & Security compliant Windows 8 or Windows 10 PC, you must enter security password "Access2Admin" when prompted to launch Windows.
