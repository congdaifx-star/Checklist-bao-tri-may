Connector Overview - PCB - MCC Backplane

Connectors

Note:
  • An oscilloscope must be used to view the X/Y/Z axis stepper motor drive signal / voltages.
  • Motor / harness continuity can be confirmed by an ohm meter reading of 4 ohms between the A+/A- or B+/B- pins for each motor.
# Connection Notes Function / Signals
J01 CABLE, INTERFACE, RIBBON, SPU connects J01 to J1 on the SPU Interface PCB. SPU Interface PCB:

The 5-V power, data to and from I/F PCB and MCC0, sample bar code reader, and Home sensor signals run through J01.

J02 CABLE, INTERFACE, RIBBON, SAMPLE STORAGE connects J02 to J1 on the Sample Storage Module Interface PCB. Sample Storage Interface PCB:

The sample wheel encoder signals from the Sample Storage Module Interface PCB to the MCC0 PCB run through J02.

The 5-V power to the Sample Storage Interface PCB from the MCC0 PCB also runs through J02.

J03 CABLE, INTERFACE, RIBBON, SAMPLE PIPETTOR connects J03 to J1 on the Sample Pipettor Interface PCB Sample Pipettor Interface PCB:

The RF level sense data and Home signals from the Sample Pipettor Interface PCB run through J03.

J04 CABLE, RIBBON, SECONDARY, INTERFACE connects J04 to J4 on the Bulk Feeder II Interface PCB Bulk Feeder II Interface PCB:

The Spare I/O signals run through J04.

J1 CABLE, RIBBON, MCC BACKPLANE, J4 connects J1 to J4 on the COMC PCB. COMC PCB:

The signals from the MCC backplane for the sample bar code reader, sample wheel encoder, sample cooler PWM, RF level sense, and MCC0, 1, 2, 3 PCBs run through J1.

J2 CABLE, RIBBON, MCC BACKPLANE, J2 connects J2 to J2 on the COMC PCB. COMC PCB:

The signals from the MCC Backplane for the reagent storage module, substrate and reagent bar code readers, wash carousel and incubator encoders, mixer speed, wash carousel and substrate heaters, and reagent cooler 3, run through J2.

J3 CABLE, RIBBON, MCC BACKPLANE, J1 connects J3 to J1 on the COMC PCB. COMC PCB:

The signals from the MCC Backplane for the ultrasonics and MCC4, 5, 6, 7 PCBs run through J3.

J11 CABLE, INTERFACE, RIBBON, BULK FEEDER connects J11 to J1 on the Bulk Feeder Interface PCB. Bulk Feeder Pick and Place Interface PCB:

The 5-V power, the air valve activation, the air cylinder extended and retracted, the RV hopper motor home and index, and the hopper reserve sensor signals run through J11.

J12 CABLE, INTERFACE, RIBBON, CARRIAGE connects J12 to J1 on the RV Carriage Interface PCB. Carriage Interface PCB:

The RV Carriage Interface PCB 5-V power and home sensor signals run through J12.

J13 CABLE, RIBBON, CTA, P&P INTERFACE connects J13 to J1 on the Dual Gantry Interface PCB. UCTA:

The UCTA (SCTA) I/O signals run through J13.

J21 CABLE, INTERFACE, RIBBON, SAMPLE P&P connects J21 to J1 on the Sample Pick and Place Interface PCB. Sample Pick and Place Interface PCB:

The Sample Pick and Place Interface PCB signals to the MCC2 PCB run through J21.

The signals are the pick-and-place X/Y/Z home, end-of-travel, eject, ejector sense, and PCB revision.

The 24-V and 5-V power to the Sample Pick and Place Interface PCB from the MCC2 PCB also run through J21.

J22 CABLE, INTERFACE, RIBBON, INCUBATE P&P connects J22 to J1 on the Incubator Pick and Place Interface PCB. Incubator Pick and Place Interface PCB:

The Incubator Pick and Place Interface PCB signals to the MCC2 PCB run through J22.

The signals are the pick-and-place X/Y/Z home, end-of-travel, eject, ejector sense, and PCB revision.

The 24-V and 5-V power to the Interface PCB from the MCC2 PCB also run through J22.

Note:
  • The incubator pick-and-place uses only the RV ejector and RV ejector sense.
  • The x/y-axis end-of-travel signal is used on the sample pick-and-place only.
J23 CABLE, INTERFACE, RIBBON, WASH P&P connects J23 to J1 on the Wash Pick and Place Interface PCB. Wash / Incubator Pick and Place Interface PCB:

The Wash Pick and Place Interface PCB signals to the MCC2 PCB run through J23.

The signals are the pick-and-place X/Y/Z home, end-of-travel, eject, ejector sense, and PCB revision.

The 24-V and 5-V power to the Interface PCB from the MCC2 PCB also run through J23.

Note:
  • The wash pick-and-place uses only the RV ejector and RV ejector sense.
  • The x/y-axis end-of-travel signal is used on the sample pick-and-place only.
J31 CABLE, INTERFACE, RIBBON, PERI/VAC PUMP connects J31 (MCC3) to J1 on the Peristaltic Pump / Vacuum Pump Interface PCB. PeriPump/Vacuum Interface PCB:

The vacuum pump 1, 2,3, and 4 enable signals and the peristaltic pump home and index sensor signals run through J31.

J41 HARNESS, INTERFACE, REAGENT PIP connects JP41 to J2 on the Reagent Pipettor (1 and 2) Interface PCB. Reagent Pipettor Interface PCB:

The Reagent Pipettor (1 and 2) Interface PCB y- and z-axis motor drive signals run through JP41.

The 24-V power and the ground to the PCB also run through JP41.

J51 CABLE, INTERFACE, RIBBON, REAGENT PIPETTOR 3 and 4 connects J51 to J1 on the Reagent Pipettor (3 and4) Interface PCB. Reagent Pipettor Interface PCB:

The Reagent Pipettor (3 and 4) Interface PCB 5-V power and home sensor signals run through J51.

J61 CABLE, INTERFACE, RIBBON, LOWER CABINET connects J61 to J1 on the Lower Cabinet Interface PCB. Lower Cabinet Interface PCB:

The Lower Cabinet Interface PCB 5 V power and home sensor signals run through J61. (MCC6)

J62 CABLE, INTERFACE, RIBBON, FLUIDICS connects J62 to J1 on the Fluidics Interface PCB. Fluidics Interface PCB:

The Fluidics Interface PCB 5-V power, the sample wash and precision pump and valve home sensor, the peri-pump index sensor, the sample pump solenoid valve, and the buffer reservoir float switch signals run through J62. (MCC6)

J71 CABLE, INTERFACE, RIBBON, ANALYTIC POWER connects J71 to J1 on the Analytical Module Interface PCB. Analytical Module Power Interface PCB:

The wash wheel and incubator wheel heater PWM, home sensor, and encoder sensor signals run through J71. (MCC7)

J72 CABLE, INTERFACE, RIBBON, ANALYTICAL connects J72 to J1 on the Upper Analytical Interface PCB. Upper Analytical Module Signal Interface PCB:

The 5-V power, eject plate home, mixer tach, speed, and direction data signals run through J72. (MCC7)

J73 CABLE, INTERFACE, RIBBON, REAGENT STORAGE connects J73 to J1 on the Reagent Storage Interface PCB. Reagent Storage Interface PCB:
The reagent and substrate BCR outputs, the gripper open and closed, the gripper and tray home, the waste door open, and the Interface PCB data signals to the MCC Backplane PCB run through J73. (MCC7)
Note: The connections referenced on this connector for the colored status LEDs are not used. The colored status LEDs on the instrument front cover are connected to MCC Backplane PCB J97 and controlled by the MCC6 PCB.
J74 CABLE, INTERFACE, RIBBON, SUBSTRATE connects J74 to J8 on the Substrate Interface PCB. Substrate Interface PCB:

The substrate heater control, pump home, bottle present, door open and closed, and air valve signals run through J74. (MCC7)

J91 The Upper Right Card Cage Fan (1 of 5) connects to J91. Upper-right card cage fan.
J92 The Upper Right Card Cage Fan (2 of 5) connects to J92. Upper-right card cage fan.
J93 The Upper Right Card Cage Fan (3 of 5) connects to J93. Upper-right card cage fan.
J94 The Upper Right Card Cage Fan (4 of 5) connects to J94. Upper-right card cage fan.
J95 The Upper Right Card Cage Fan (5 of 5) connects to J95. Upper-right card cage fan.
J96 CABLE, INTERFACE, RIBBON, POWER DISTRIBUTION connects J96 to J9 on the Power Distribution PCB. Power Distribution PCB:

The pulse width modulation (PWM) control signals from the COMC PCB for the main blower fan, the sample storage Peltier, and the reagent cooler Peltiers run through J96.

J97 CABLE, LED REFERENCE connects J97 to J1 on the LED Display Panel PCB. Display Panel PCB:

The LED display panel LED power and enable signals run through J97.

JP01 HARNESS, SAMPLE HANDLING connects JP01 to J2 on the SPU Interface PCB.

The harness also connects:

  • JP01 to Sample Pipettor I/F PCB J2 and J3.
  • JP02 to Sample Storage I/F PCB J2.
SPU Interface PCB:

The SPU Interface PCB 24-V power and SPU motor drive signals run through JP01. (MCC0)

JP02 HARNESS, SAMPLE HANDLING connects JP02 to J3 on the Sample Pipettor Interface PCB.

The harness also connects:

  • JP01 to the SPU Interface PCB J2.
  • JP02 to the Sample Storage I/F PCB J2.
Sample Pipettor / Sample Storage Interface PCB:

The Sample Pipettor Interface PCB 24-V power and stepper motor drive signals run through JP02. (MCC0)

JP03 HARNESS, BULK FEEDER (Bulk Feeder II only) connects JP03 to J16 on the Bulk Feeder II Interface PCB.

The harness also connects JP11 to J16 on the Bulk Feeder II Interface PCB.

Bulk Feeder II Interface PCB:

The bulk feeder II pusher stepper motor drive signals run through JP03 (SPARE). (MCC0)

JP1 HARNESS, MCC BACKPLANE POWER connects JP1 to J2 on the Power Distribution PCB. MCC Backplane Power:

The MCC PCB 24-V power runs through JP1.

JP2 HARNESS, +24 V ULTRA POWER connects JP2 to J5 on the Power Distribution PCB. Ultrasonics PCBs:

The Ultrasonics PCB 24-V power runs through JP2.

JP11 HARNESS, INTERFACE, BULK FEEDER/CARRIAGE /P&P connects JP11 to J16 on the Bulk Feeder Interface PCB.

The harness also connects:

  • Sample Pick and Place I/F J2 to JP23.
  • Carriage I/F J2 to JP12.
Bulk Feeder Interface PCB:

The Bulk Feeder Interface PCB 24-V power and the bulk feeder hopper motor drive signals run through JP11. (MCC1)

JP12 HARNESS, INTERFACE, BULK FEEDER/CARRIAGE /P&P connects JP12 to J2 on the RV Carriage Interface PCB.

The harness also connects JP23 to Sample Pick and Place I/F J2 and JP11 to Bulk Feeder I/F J16.

RV Carriage Interface PCB:

The Carriage Interface PCB RV carriage motor drive signals run through JP12. (MCC1)

JP13 CABLE, INTERFACE, MOTOR, P&P connects JP13 to J2 on the Dual Gantry Pick and Place Interface PCB. UCTA:

The UCTA (SCTA) Interface PCB stepper motor drive signals run through JP13 (SCTA I/O). (MCC1)

JP21 HARNESS, INTERFACE, INCUBATE P&P connects JP21 to J2 on the Incubator Pick and Place Interface PCB. Incubator Pick and Place Interface PCB:

The Incubator Pick and Place Interface PCB 24-V power and stepper motor drive signals run through JP21. (MCC2)

JP22 HARNESS, INTERFACE, WASH P&P connects JP22 to J2 on the Wash Pick and Place Interface PCB. Wash Pick and Place Interface PCB:

The Wash Pick and Place Interface PCB 24-V power and stepper motor drive signals run through JP22. (MCC2)

JP23 HARNESS, INTERFACE, BULK FEEDER/CARRIAGE /P&P connects JP23 to J2 on the Sample Pick and Place Interface PCB. Sample Pick and Place Interface PCB:

The Sample Pick and Place Interface PCB 24-V power and stepper motor drive signals run through JP23. (MCC2)

JP31 HARNESS, INTERFACE, PERISTALTIC & VACUUM PUMP connects JP31 (MCC3) to J3 on the Peri/Vacuum Pump Interface PCB.

The harness also connects Peri / Vac Pump I/F J2 to JP32.

Peri Pump / Vacuum Interface PCB:

The Peri/Vacuum Pump Interface PCB liquid waste transfer, wash buffer transfer, and sample wash tower peri-pump motor drive signals run through JP31. (MCC3)

JP32 HARNESS, INTERFACE, PERISTALTIC & VACUUM PUMP connects JP32 to J2 on the Peri/Vacuum Pump Interface PCB.

The harness also connects Peri / Vac Pump I/F PCB J3 to JP31.

HARNESS, INTERFACE, PERISTALTIC & VACUUM PUMP connects JP32 to J2 on the Peri/Vacuum Pump Interface PCB.

The harness also connects JP31 to Peri / Vac Pump I/F J3.

Peri Pump / Vacuum Interface PCB:

The Peri/Vacuum Pump Interface PCB wash tower 1, 2,3, and 4 peri-pump motor drive signals run through JP32. (MCC3)

JP41 HARNESS, INTERFACE, REAGENT PIP connects JP41 to J2 on the Reagent Pipettor (1 and 2) Interface PCB. Reagent Storage Interface PCB:

The Reagent Pipettor (1 and 2) Interface PCB Reagent Pipettor (1 and 2) y- and z-axis motor drive signals run through JP41. (MCC4)

The 24-V power and the ground to the PCB also run through JP41.

JP42 HARNESS, INTERFACE, FLUIDICS connects JP42 to J2 on the Fluidics Interface PCB.

The harness also connects Fluidics Interface PCB:

  • J3 to JP52. (MCC5)
  • J4 to JP61. (MCC6)
  • J5 to JP62. (MCC6)
Fluidics Interface PCB:

The Fluidics Interface PCB precision pump 1 and 2 and precision valve 1 and 2 motor drive signals run through JP42. (MCC4)

JP51 HARNESS, INTERFACE, REAGENT PIP connects JP51 to J2 to on the Reagent Pipettor (3 and 4) Interface PCB. Reagent Pipettor Interface PCB:

The reagent pipettor (3 and 4) y- and z-axis motor drive signals run through JP51. (MCC5)

The 24-V power and the ground to the PCB run through JP51.

JP52 HARNESS, INTERFACE, FLUIDICS connects JP52 to J3 on the Fluidics Interface PCB.

The harness also connects Fluidics Interface PCB:

  • J2 to JP42. (MCC4)
  • J4 to JP61. (MCC6)
  • J5 to JP62. (MCC6)
Fluidics Interface PCB:

The Fluidics Interface PCB precision pump 3 and 4 and precision valve 3 and 4 motor drive signals run through JP52. (MCC5)

JP61 HARNESS, INTERFACE, FLUIDICS connects JP61 to J4 on the Fluidics Interface PCB.

The harness also connects Fluidics Interface PCB:

  • J2 to JP42. (MCC4)
  • J3 to JP52. (MCC5)
  • J5 to JP62. (MCC6)
Fluidics Interface PCB:

Wash pump 1 and 2 and wash valve 1 and 2 Motor drive signals run through JP61. (MCC6)

JP62 HARNESS, INTERFACE, FLUIDICS connects JP62 to J5 on the Fluidics Interface PCB.

The harness also connects Fluidics Interface PCB:

  • J2 to JP42. (MCC4)
  • J3 to JP52. (MCC5)
  • J4 to JP61. (MCC6)
Fluidics Interface PCB:

The aspirate peristaltic pump and the sample pump motor drive signals run through JP62. (MCC6)

JP63 HARNESS, INTERFACE, SUBSTRATE connects JP63 to J17 on the Substrate Interface PCB. Substrate Interface PCB:

Substrate pump stepper motor drive signals run through JP63. (MCC6)

JP71 HARNESS, INTERFACE, ANALYTICAL POWER connects JP71 to J2 on the Analytical Module Interface PCB. Analytical Power Interface PCB:

Aspirate arm, dispense arm, wash wheel, and incubator stepper motor drive signals run through JP71. (MCC7)

JP72 HARNESS, INTERFACE, REAGENT STORAGE connects JP72 to J2 on the Reagent Storage Interface PCB. Reagent Storage Interface PCB:

The reagent gripper x/z-axis and reagent load tray stepper motor drive signals run through JP72. (MCC7)
