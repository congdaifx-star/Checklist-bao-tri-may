Reagent Pack Process Monitoring Operating Principles

Purpose

This document details the operating principles for reagent pack process monitoring.

System Process Monitoring

For information on system process monitoring, refer to the OP - Process Monitoring - Pressure Checking document.

Definitions of Terms Used in This Document

Term Definition
Expected Area (EA) Determined form pressure sensor calibration curve.
Actual Area Measured (AM) Area measured by pressure sensor during reagent dispense.
A/E Ratio AM divided by EA.
Pack Seeding The process of each reagent pack well with each reagent pipettor using the algorithm to build the adaptive filter and store the data in an ini file.

Process Monitoring Overview

Reagent pack process monitoring includes:
  • Positive and negative pressure checking.
  • Active processing of all assays.
  • Detection of abnormal pressure in specific areas of the fluidics system.
  • Event log messages when pressure becomes too high or low for the expected area.
  • Flags on results if an error is detected and runs the result to completion (obtains an RLU for the result).

Detection Process

  1. The area measured during reagent dispense must be greater than or equal to 65% of the calibration curve prediction.
    • If the area measured is less than 65%, then an error is generated. For troubleshooting information, refer to the Fluidics: Troubleshoot Reagent Pack Process Monitoring procedure.
  2. Software determines if the current pipettor and reagent pack well have been seeded, and a correction factor is stored in the process monitoring INI File.
    • If the reagent pack with the selected pipettor has not been seeded, software uses the seeding filter and the dispense is not monitored using the algorithm.
    • If the reagent pack with the selected pipettor has been seeded, the area measured is used in an algorithm to determine if the pressure response is correct for the volume of reagent that is supposed to be dispensed.
  3. The dispense volume is monitored and flagged, if it is under dispensed.
    • If the dispense volume is less than or equal to 50 µL, the corrected A/E ratio must be greater than or equal to 0.88.
    • If the dispense volume is greater than 50 µL, the corrected A/E ratio must be greater than or equal to 0.9.
  4. At the time the dispense is monitored, the correction factor is also checked and adjusting a filter on a second calculation is adjusted.
    • If the A/E ratio is greater than or equal to 1.05, or less than or equal to 0.95, then the ratio is added to a filter rejection counter.
    • If there are five values in the rejection filter that are on one side (greater than or less than) of the A/E ratio, then an information event log message is posted.
  5. If the A/E ratio is greater than 0.95 and less than 1.05, then the calculated correction factor is stored as the new correction factor in the INI file.

Event Log Messages for Reagent Pack Process Monitoring Failure Modes

Event Log Message or Error Error Details or Issue
Reagent pack monitoring failed to initialize.
  • First five reagent dispenses failed to meet initial acceptable limits.
  • Reagent pack monitoring continues to attempt to initialize until pack well is seeded.
  • System continues to process tests normally; however, reagent pack monitoring is not used on this pack well until pack monitoring has established the initial baseline.
Reagent pack monitoring has detected a reagent dispense failure.
  • Any test involved is canceled.
  • Insufficient reagent dispense as determined by the corrected A/E ratio being below limits.
Reagent pack is no longer usable due to process monitoring failures.
  • Reagent pack is marked unusable.
  • Error occurs after the identified pack has accrued three dispense faults.
  • Reagent pack is not discarded automatically, pack must be manually unloaded and discarded.
Reagent pipettor is no longer usable due to process monitoring failures.
  • Reagent pipettor is marked unusable.
  • Error occurs after five consecutive dispense fault errors on same pipettor.
  • Pressure sensor must be calibrated.
Version 4.1 message: Reagent pack monitoring has encountered an excessive number of abnormal reagent dispenses.

Version 4.2 message: The pressure responses during reagent dispensing have changed from the characterized response.

  • For reagent dispenses greater than 50 µL: Five successive A/E ratio readings are 5% greater or less than the A/E ratio set in the algorithm filter.
  • For reagent dispenses less than or equal to 50 µL: Five successive A/E ratio readings are 8% greater or less than the A/E ratio set in the algorithm filter.
  • The system continues to run tests normally and results are not flagged.
Note: This is only an informational event, it does not require troubleshooting under normal circumstances.

Limitations

For systems running software version 4.1, there are eight assays (shown in the table) that are unable to use this reagent pack process monitoring for all of the wells. The rule is that the aspiration must be a minimum of 25 µL and the dispense ratio of buffer chase volume cannot be more than 50% buffer. All overdraw deliveries greater than or equal to 25 µL are monitored. Any chases with more than 50% wash buffer are not monitored. The table provides more detail about the assays that can not be monitored.

APF Name APF Number Aspirate Volume Dispense Volume Particle Well Monitored?
TotIgE 123 5 170 yes
ThgAb 227 10 175 yes
Ostase 153 15 75 yes
HCVPLUS 148 20 115 yes
IgG-Toxo 228 20 215 yes
Rub-IgG 102 25 190 yes
HBc-Ab 143 20 65 yes
CMV-G 242 25 190 yes

For systems running software version 4.2 or systems that have had Mod 10223 completed, there are six additional assays (shown in table) that are unable to use this reagent pack process monitoring. With this software version and this Mod, the rule is that the aspiration must be a minimum of 40 µL and the dispense ratio of buffer chase volume cannot be more the 50% buffer. All overdraw deliveries greater than or equal to 40 µL are monitored. Any chases with more than 50% wash buffer are not monitored. The table provides more detail about the assays that can not be monitored.

APF Name APF Number Aspirate Volume Dispense Volume Particle Well Monitored?
HIV 110 30 30 no

TSH 183 30 30 yes
Free T3 212 30 30 yes

fastTSH 246 30 30 yes

Interacting Devices

  • DAQC PCB
  • Sensor Interface PCBs
