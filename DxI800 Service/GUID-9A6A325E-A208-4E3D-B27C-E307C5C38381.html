Replacing Gripper Sensors

This procedure describes how to replace the gripper open-close sensors on the reagent storage module.

Required Materials:
  • 8-mm hex wrench
  • SAE hex wrench set
  • 0.016-in feeler gauge (A gripper shim can be used if a 0.016-in feeler gauge is not available.)
Replace the gripper open-close sensors on the reagent storage module when:
  • Troubleshooting indicates that the gripper sensors are misreporting the pack gripper open-closed status.
  • Errors are reported for a lost pack, dropped pack, pack not present, or motion errors.
  • The gripper crashes into nests during initialization.
  • Software has lockups associated with the reagent storage module.
Caution: If there are symptoms of intermittent opens or breaks in a gripper sensor cable, always replace both gripper sensors.
Perform these steps to replace the gripper sensors.
StepAction
Remove existing sensors Refer to the Removing Gripper Sensors procedure
Installing sensors
  • Refer to the Installing Gripper Sensors (Round from Round) procedure if round sensors are being replaced by round sensors.
  • Refer to the Installing Gripper Sensor (Round from Rectangular) procedure if square sensors are being replaced with round sensors.
  • Refer to the Installing Gripper Sensors (Rectangular from Rectangular) procedure if square sensors are being replaced with square sensors.
Adjust gripper flag and sensor (only when round sensors are installed). Refer to the RS: Adjusting Reagent Gripper Round Sensor and Flag procedure if round sensors were installed.
Note: The gripper flag is not adjusted when square sensors are replaced by square sensors.
