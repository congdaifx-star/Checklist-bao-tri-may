PCB - Power Conditioner

Purpose

This document provides these details for the Power Conditioner PCB:
  • Drawings
  • Details: Test Points, LEDs, Connector Overview, Connector Pin-outs
  • Schematics
  • Location
Note: The power conditioner module is not used with the latest version of the instrument.
Warning: AC voltage up to 284 volts is present on this PCB. Use extreme caution when working in the area of this PCB.

Drawings

Details

The Power Conditioner PCB connects to these devices:
  • Main Power Supply.

Test Points

There are no Test Points on this PCB.

LED Color Label / Function

D1

Green

Indicates AC power is present on this PCB.

Schematics

Page 1
  • Connectors: JP1-JP4.
  • Test Points: None.

Location

The Power Conditioner PCB is mounted on the power conditioner module. The module is located behind the lower right front door of the instrument inside the power compartment.
