Using Desktop Sharing to Transfer Files Between Console PC and AU

This procedure describes how to transfer files between the AU and the console PC using desktop sharing.

This procedure applies to DxI systems running Windows XP and Windows 8.

Use this procedure when it is necessary to transfer files:
  • from the AU to the PC.
  • from the PC to the AU.
  1. Open a connection between the console PC and the AU.

    For Windows XP:

    1. Press the [Windows] key, and then select Start  > Programs > Administrative Tools > Remote Desktop Connection to AU PC to start desktop sharing.

      The remote desktop connects to the instrument computer and allows remote control of the instrument and applications. When connected, the Remote Desktop window displays the Windows XP desktop of the instrument.

    2. To navigate the AU desktop:
      • Use the scroll bars on the right and bottom of the window.
      • Move down the scroll bar on the right to see the AU desktop toolbar,
      • The PC toolbar is at the bottom of the screen.
    3. To switch between the console PC display and the AU display:
      • To return to the console PC display, use the minimize button at the top of the AUSETUPPC screen.
      • To restore the AU Windows screen, select AUSETUPPC Remote Desktop Connection in the toolbar at the bottom of the console PC display.

    For Windows 8:

    1. Press the Windows key, type remote, and open the Remote Desktop Connection program.

      The remote desktop connects to the instrument computer and allows remote control of the instrument and applications. When connected, the Remote Desktop window displays the Windows 8 desktop of the instrument.

    2. Type in 192.168.2.4 into the Computer field and select Connect.
    3. Enter user for User Name and tech for the password if prompted.
    4. If prompted at the RDS warning screen, check the box for "Don't ask me again for connections to this computer" and select Yes.
      Note: For Windows 8, the default console IP address is 192.168.2.3 and the AU IP address is 192.168.2.4. Neither IP address changes during the software load process.
    5. To switch between the console PC display and the AU display:
      • To return to the console PC display, use the minimize button at the top of the AU Desktop screen.
      • To restore the AU Desktop screen, press the Windows key, type remote, and open the Remote Desktop Connection program.
  2. Transfer files from the AU to the PC.

    For Windows XP:

    1. From the AU Desktop, select Start > All Programs  > Windows Explorer.
    2. In Windows Explorer, locate the AU file to be transferred.
      Note:
      • The C:\ drive might be called AU_PC (C:) or Local Disk (C:).
      • Files in the window might not appear in the list format. Files could also appear as icons, thumbnails, or tiles.
    3. Right-click on the file, and then select Copy.
    4. Navigate to the C: Drive of the PC.
      Note: The PC C: Drive might be called C on CONSOLESETUP_PC or C on XXXXX (where XXXXX is the computer name of the PC).
    5. Right-click in this location, and select Paste.

      For Windows 8:

    1. From the AU desktop, double click on File Explorer on the task bar or Computer.
    2. Navigate to AU drive (Local Disk (C:)) and locate the files to be transferred.
      Note: xxxxxx is the serial number of the instrument.
    3. Right click on the file and select Copy.
    4. Navigate to Network, select xxxxxxx_PC or Console_PC > Users.
    5. Right-click in this location, and select Paste.
    6. Return to the console PC desktop and open File Explorer or Computer.
    7. Navigate to Local Disk (C:) > Users, and verify the file is transferred over.
  3. Transfer files from the PC to the AU.

    For Windows XP:

    1. From the AU Desktop, select Start > All Programs  > Windows Explorer.
    2. From Windows Explorer, navigate to the C: Drive of the PC.
      Note: The PC C: Drive might be called C on CONSOLESETUP_PC or C on XXXXX (where XXXXX is the computer name of the PC).
      Note: If C on CONSOLESETUP_PC is not available, then follow these steps:
      1. Exit desktop sharing.
      2. On the console PC, select Start > Programs > Accessories > Remote Desktop Connection .
      3. Input the IP Address to connect to (192.168.2.2 for a new XP hard drive or 192.168.2.4).
      4. Select Options > Local Resources > More.
      5. Check the Drives option, and then select OK.
      6. Select Connect.
      7. Double click the Windows Explorer icon on the AU Desktop to open an Explorer Window.
    3. From Windows Explorer, locate the PC file to be transferred.
    4. Right-click on the file, and then select Copy.
    5. Navigate to location on the C: Drive of the AU where you want to place the file.
      Note: The C: Drive might be called AU_PC (C:) or Local Disk (C:).
    6. Right-click in this location, and then select Paste.

      For Windows 8:

    1. Minimize the AU desktop.
    2. Map the AU network drive to the console PC.
      • Press the Windows key and click the File Explorer icon to open it.
      • Right click on Computer and select Map Network Drive.
      • In the Folder window, type :\\192.168.2.4\c$
      • Verify the "Reconnect at Sign in" box is checked and select Finish.
    3. Navigate to a drive (examples: Local Disk (C:), DVD RW Drive (D:), and BACKUPDRIVE (E:)) and locate the file to transfer to the mapped AU drive (c$ (\\192.168.2.4)).
    4. Transfer files to AU drive.
      Example: Transfer the alignment file to AU folder.
      • Browse to: BACKUPDRIVE (E:) > Backup folder.
      • Right click on the xxxxxx_specific.ini file and select Copy. The xxxxxx is the serial number of the instrument.
      • Navigate to the mapped AU drive (c$ (\\192.168.2.4)), right click on the AU folder, and select Paste.

        Note: If there is no AU folder, right click on the mapped AU drive (c$ (\\192.168.2.4)), select New > Folder and name the new folder AU. Then paste the xxxxxx_specific.ini file into the AU folder. The letter of the mapped network drive is not significant and may vary depending on other drives in use. it commonly shows as (Y:) or (Z:).
    5. Return to the AU desktop screen.
  4. Close the desktop sharing connection.

    For Windows XP:

    1. From the AU Desktop, select Start > Disconnect or select the X in the upper right corner.
    2. Select OK at the Disconnect Windows Session pop-up.

    For Windows 8:

    1. From the AU Desktop, right click on Remote Desktop Connection icon on the upper left corner or on the task bar > Close or select the X in the upper right corner.
    2. Select OK at the Your remote session will be disconnected pop-up.
