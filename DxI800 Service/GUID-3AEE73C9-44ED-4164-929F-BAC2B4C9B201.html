Installing Configuration Assistant

This procedure describes how to install Configuration Assistant.

Install Configuration Assistant when a module installation requires the tool and the tool is not installed on the AU.

Note:
  • Configuration Assistant is available with software V4.6 and higher.
  • For screen images and operating principles of this tool, refer to the OP - Configuration Assistant Tool concept topic.
  1. Transfer Configuration Assistant from the PC to the AU.
    1. Open a connection between the console PC and the AU using Desktop Sharing.
      Note: Refer to the Software: Using Desktop Sharing Between Console PC and AU procedure.
    2. Double-click on the Windows Explorer icon to open Windows Explorer.
    3. Double-click on C on SerialNumber_PC on the list of connected hard drives.
    4. Select to C: > Nexgen > Instrument > Tools.
    5. Right-click on theConfigurationAssistantTool.zip file, and select Copy.
    6. Browse to the C:\AU folder on the Local Disk (C:) or AU [AU_PC (C: )]
    7. Right-click in the AU folder, and select Paste to paste the ConfigurationAssistantTool.zip file into the AU folder.
  2. Install Configuration Assistant.
    1. Right-click on the ConfigurationAssistantTool.zip file in the AU folder.
    2. Select Extract All
    3. Select Next > Next > Finish. Use the program default values.
      1. Select a destination. The default value is C:\Au\ConfigurationAssistantInstaller.
      2. Extraction completes. Checkbox is checked for Show extracted files option.
      3. Window displays ConfigurationAssistantInstallerFiles.
    4. Double-click on setup.exe. If setup.exe is not visible, then double-click on the Configuration Assistant Installer folder and select the setup.exe file inside the folder.
      The Configuration Assistant - Install Shield Wizard displays three programs and an Install button.
    5. Select the Install button.
      This install process takes approximately 10 minutes.
    6. When installation is complete, the pop-up message The installation of Configuration Assistant requires a reboot. Click Yes to restart now or No if you plan to restart later is displayed. Select Yes.
      The AU reboots. Desktop Sharing closes. The instrument begins to initialize.
    7. Open a connection between the console PC and the AU using Desktop Sharing.
      Note: Refer to the Software: Using Desktop Sharing Between Console PC and AU procedure.
    8. Select Next > Install  > Finish.
  3. Verify that Configuration Assistant was installed.
    1. Double-click the Launch Configuration Assistant shortcut on the desktop.
    2. If Configuration Assistant will not be used now, close it by selecting the X in the upper right hand corner, and then exit Desktop Sharing.
