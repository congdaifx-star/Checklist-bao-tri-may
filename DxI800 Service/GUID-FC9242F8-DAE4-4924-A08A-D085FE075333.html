Troubleshooting Elevated Dark Count

Purpose

This document outlines the troubleshooting process for elevated dark counts in the analytical module.

When to Perform

Perform troubleshooting when:
  • An event log error message indicates dark counts out of range.
  • Dark counts are higher than normal, indicating that an issue may be developing.

Cautions and Warnings

Warning: The photomultiplier tube (PMT) is a very sensitive photon measuring device. Any background or extraneous light coming into contact with a powered PMT can saturate the PMT and reduce the gain. This reduces the performance of the PMT, and it can take a long time for the PMT to recover or it might never recover fully. A magnetic field close to a powered PMT also reduces the performance of the PMT. The magnetic field causes the electrons to follow a curved path instead of moving in a straight line. When you are performing service in the area of the luminometer, observe the following rules.
  • Never shine a flashlight around the luminometer while the PMT is powered on.
  • Never bring a strong magnetic field close to the luminometer while the luminometer is powered on.
  • Before removing the covers on the analytical module, turn off the power to the PMT.
  • Cap the PMT whenever it is removed from the analytical module.

Causes

Dark Count troubleshooting begins with determining the frequency of occurrence in a single revolution of the wash carousel. Does the error occur at:
  • all wash carousel positions?
  • one or only a few wash carousel positions?

Determine which condition exists and then proceed to the appropriate section of this document to determine the cause.

Note: It is possible, though uncommon, that elevated dark counts have more than one cause.

One or a Few Elevated Dark Counts

This is an overview of troubleshooting dark count errors occurring at one or a few wash carousel positions. For more information regarding determining a possible cause, refer to the last table.

Possible Cause How To Test Repair
Fluid spill (light emitting fluid or salts) in the wash carousel.
  • Dark Count Read Tests: Performing Dark Count Read
  • Visual Inspection
  • Replace the duck-bill valve.
  • Clean the wash carousel using DI water and lint-free swabs or kim wipes. If spill is severe enough, remove wash wheel and clean underneath the wheel.
Nick or scratch on the wash carousel.
  • Dark Count Read Tests: Performing Dark Count Read
  • Visual Inspection
  • Cover nick or scratch using a black marker.
  • Order a replacement wash carousel.
Electrical noise
  • Dark Count Read Tests: Performing Dark Count Read
  • Visual Inspection

Install electrical noise suppressors.

The sample next to read position had very high RLUs Examine the assay results for an extremely hot sample next to the sample giving elevated dark counts.

If a hot sample is not located, then search for other possible causes.

Note: Sample Probe Carryover test can create elevated dark counts. This is normal.

Continuous Elevated Dark Counts

This is an overview of troubleshooting dark count errors occurring at all wash carousel positions.

Possible Cause How To Test Repair
Dirty luminometer lens
  • Dark Count Read Tests: Performing Dark Count Read
  • Visual Inspection
Remove the luminometer and carefully clean the lens.
Light leakage
  • Dark Count Read Tests: Performing Dark Count Read
  • Visual Inspection
  • Reposition the analytical module cover.
  • Verify that the insulation covers the light inlet pin hole above the luminometer area.
Poor connection or defective luminometer cable
  • Dark Count Read Tests: Performing Dark Count Read
  • Reseat the connectors.
  • Replace the cable.
Defective DAQC PCB
  • Dark Count Read Tests: Performing Dark Count Read
  • Eliminate Other Causes
Replace the DAQC PCB.
Defective Luminometer
  • Dark Count Read Tests: Performing Dark Count Read
  • Eliminate Other Causes
Replace the luminometer.

Determining Cause of Elevated Dark Counts

Possible Cause Perform these steps to determine cause
Fluid spill (light emitting fluid or salts) in the wash carousel.
Note: Fluid spills into the wash carousel are most often caused by a defective duck-bill valve.
  1. Inspect the duck-bill valve and replace it if necessary.
  2. Inspect the wash carousel for salts using a flashlight.
    • If the wash carousel is clean, proceed to the next dark count troubleshooting section.
    • If the wash carousel appears dirty, remove the wash carousel and clean it.
    • Reinstall the wash carousel, and then retest.
  3. Examine the Dark Count results.
    • If the Dark Count Read passes, the wash carousel (and luminometer lens) are clean.
    • If the Dark Count Read fails, then proceed to the next possible cause.
Nick or scratch on the wash carousel.
  1. Remove the wash carousel.
  2. Examine the surfaces of the wash carousel for any areas that might cause light to reflect into the luminometer.
  3. If there is a nick or scratch, coat it using a dark black felt tip pen, reinstall the wash carousel, perform a Dark Count Red, and examine the results.
    • If the Dark Count Read passes, then order a replacement wash carousel and leave the marked wash carousel in the instrument temporarily until the replacement can be installed.
  4. If there is no nick or scratch on the wash carousel, reinstall the wash carousel, and proceed to the next possible cause.
Electrical noise
  1. Look for suppressor beads on the luminometer cable on the luminometer housing. If there are no beads, order beads and install them.
  2. Confirm that the instrument is connected to a dedicated circuit. If the instrument is not connected to a dedicated circuit, connect it to one.
  3. Confirm that the instrument is connected to a UPS. If the instrument is not connected to a UPS, connect it to one.
  4. Confirm that equipment capable of generating electrical noise spikes in not located near the instrument. If the instrument is located near such equipment, move the instrument or the equipment.
Dirty luminometer lens
  1. Remove the luminometer.
  2. Inspect the luminometer lens.
  3. Carefully clean the lens with a soft lint-free tissue or cloth.
  4. Reattach the luminometer.
  5. Perform a Dark Count Read and examine the results. If all positions continue to read high, the cause may be one or more of these components. Proceed to the section for each of these possible causes for further information.
    • Defective luminometer
    • Defective luminometer cable connection or cable
    • Defective DAQC PCB
Light leakage
  1. Confirm that the analytical module cover is positioned on its locating pins.
  2. Confirm that the analytical module cover is securely fastened to the module.
  3. Confirm that the analytical module cover is flat.
  4. Confirm that the two halves of the cover meet tightly.
  5. Confirm that the small hole near the edge of the analytical module cover, just above the luminometer, is not visible (must be covered with insulating foam). An exposed pin hole here allows light to enter the luminometer lens.
  6. To test for light leakage into the module, perform a Dark Count Read with an empty vessel in the read position.
    • If the RLUs are acceptable, then light leakage is not the cause of the excessive dark counts. Pursue other causes.
    • If the RLUs are out of range, then cover the module with dark material or temporarily cover or seal all seams between the cover and module, and then retest. If the Dark Count Read passes with the module covered, then determine the cause of the light leakage, contact STS Chaska, order the necessary parts, and then replace the parts.
Poor connection or defective luminometer cable
Note: Cable issues normally cause a dark count reading of zero RLUs.
  1. Power off the instrument.
  2. Inspect the cable connection on the luminometer and at the UL card cage.
  3. Reseat both connectors.
  4. Examine the luminometer cable insulation for damage, and replace the cable if damaged.
  5. Power on the instrument.
  6. Perform a Dark Count Read and examine the results.
    • If the Dark Count Read fails, then pursue other causes.
    • If the Dark Count Read passes, then the elevated dark counts are resolved.
Defective DAQC PCB
  1. Power off the instrument.
  2. Open the upper left card cage.
  3. Reseat the DAQC PCB.
  4. Power on the instrument.
  5. Perform a Dark Count Read and examine the results.
    • If the Dark Count Read fails, then install a replacement DAQC PCB and retest.
    • If the Dark Count Read passes, then the elevated dark counts are resolved.
Defective luminometer
Note: The luminometer can cause elevated dark counts, but because of its cost it should not be the first part to be replaced.
  1. Determine if any other sources of elevated dark counts exists.
  2. If no other issues seem to be the cause, then replace the luminometer.
    Note: Refer to the AU: Replacing Luminometer procedure.
  3. Perform a Dark Count Read and examine the results.
    • If the Dark Count Read fails, then call STS Chaska.
    • If the Dark Count Read passes, then the elevated dark counts are resolved.
