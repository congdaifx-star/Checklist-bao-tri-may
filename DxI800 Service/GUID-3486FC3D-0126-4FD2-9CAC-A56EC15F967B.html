PCB - Interface - Sample Pipettor

Purpose

This document provides these details for the Sample Pipettor Interface PCB:
  • Drawings.
  • Details: Test Points, LEDs, Connector Overview, Connector Pin-outs.
  • Schematics.
  • Location.

Drawings

Details

The Sample Pipettor Interface PCB connects to these devices:
  • Motors (Y and Z).
  • Home sensors (Y and Z).
  • RF Level Sense PCB.
  • MCC Backplane PCB.
