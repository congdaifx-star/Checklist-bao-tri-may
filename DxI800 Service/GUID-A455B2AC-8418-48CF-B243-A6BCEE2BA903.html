DxI Software V5.0 and V5.1 Release Notes

Purpose
  • This document provides details of the most significant features and enhancements in DxI software v5.1.
Confidentiality
  • Software release notes are confidential and should not be shared with customers.
Background
  • These release notes relate to v5.0 and v5.1 software only.
  • v5.0 did not go to general distribution.
  • v5.1 did go to general distribution.
  • v5.1 was a mandatory modification, mod number 11441.
  • Mod 11441 is now 100% complete.
  • These release notes are being added to AirWatch as they were not converted from Lotus Notes during the conversion.

Feature Overview v5.0

  • Resolves critical event jam due to events that do not update critical event ID.
  • Resolves critical event jam due to integrated DxI events that do not update critical event ID.
  • Resolves issue when critical events are jammed where AU resets the critical event counter.
  • Resolves AU assert when reagent Pipettor has motion error of 0 to 20 steps on a specific homing routine.
  • Adds Byte Order Mark to allow Asian language Diagnostic Copy to Disk to open in Excel without user intervention. Office 2010 support (headers will not open correctly in office 2003).
  • Resolves database lock errors after Console reboot.
  • Resolves unknown process popup on PC, update unknown process list to include drivers for new Silver Front PC (adds RTHDCPL and IGFXSRVC) to the known process list.
  • Resolves AU crash during DV route of RV exerciser with Bulk Feeder II.
  • Adds Bulk Feeder II support.
  • Resolves issue where the Recover button did not enable for pusher jams with Bulk Feeder II.
  • Removes error "Bulk RV Feeder: Vertical Dispense Chute is empty".
  • Updates to configuration assistant for the new DVWaste alignment values.

Feature Overview v5.1

  • Decreases the software installation time by removing preventative database maintenance processes (reorganize, reindex and consistency check) from the software install process.
  • Decreases consistency check runtime by removing checks of thermal data.
  • Removes reindex from the database maintenance process. Reindex is redundant as the same function is performed during reorganization.
  • Provides a status bar of percent complete during consistency check.
  • Resolves issue where consistency check does not complete (DbTest is not responsive).
  • Decreases software installation time by improving the install process's ability to determine the instrument mode (Ready, Not Ready, Running). This also prevents an assertion of the software.
  • Prevents AU assertion during remap.
