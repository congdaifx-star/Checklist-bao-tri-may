Restoring QC Button

This procedure describes how to restore a QC button that disappeared from the Quality Control screen.

Restore a QC button in the Quality Control screen when:
  • A QC button or tile is missing.
  • A BAssertEvent(NULL!=pControlLot) event log message occurs (indicating a QC button was not created).
Note: Software V4.4 and above resolves the missing QC button issue.
  1. Restore the QC button.
    1. In the Main Menu, select Quality Control > QC Setup. Select the QC lot and level that the QC button disappeared from, and then select Edit Control.
    2. Perform a Print Screen to obtain the QC setup information.
    3. Select the row for the test name where the QC button disappeared, and then select Clear Row.
    4. Select OK.
    5. Select Edit Control, and then add the QC setup information back into the screen exactly how it was prior to clearing it.
    6. Select OK.
    7. Run QC for the restored QC test to recover the data points.
    8. If the QC tile does not appear after performing these steps, then clear in-progress reps and run a database consistency check.
      Note: Refer to the Software: Database - Clearing In-Progress Samples procedure.
  2. Verify the proper operation of the system.
    1. In the Main Menu, select Quality Control.
    2. Select the button that had the missing data and verify that the data has been restored.
