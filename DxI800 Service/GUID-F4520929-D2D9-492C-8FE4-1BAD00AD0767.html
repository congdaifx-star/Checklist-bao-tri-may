Aligning Sample Pipettor to LAS Track

This procedure describes how to align the sample pipettor to the LAS track position.

The alignments for this module include:
  • sample pipettor to LAS track.
Perform this procedure when:
  • Verifying alignments to the track position.
  • Troubleshooting LAS level sense problems.
Support documents referenced in this procedure include:
  • LAS: Loading Tubes Manually
  1. Pause the LAS sample tube loading.
    1. On the PrepLink Console, select Setup > Instrument Loading .
    2. Select the correct CONN-X Loading Paused option (X = 1,2,3, or 4).
      The DxI instrument connection units are labeled CONN-1 through CONN-4, according to how many DxI instruments are connected to the LAS.
    3. Before proceeding, verify that the selected DxI instrument has completed processing all samples.
  2. Prepare for aligning the sample pipettor to the track position.
    1. Remove the SPOTB housing assembly from the rear cover of the DxI instrument.
      Note: SPOTB stands for sample pipettor out the back.
    2. From the Main Menu, select Diagnostics  > Device Diagnostics > Mechanics  > Alignments.
    3. Select Sample Pipettor as the device and Track as the position.
    4. Select Alignments / Offsets > Semi-Auto Alignment.
  3. Manually load and pause an auto-aliquot tube.
    1. Bypass normal operations of the connection unit.
      1. On the track keypad, press the [Auto / Manual] key to toggle to Manual mode.
      2. On the track keypad, press the [+] key repeatedly until the display shows 01, then press [Enter].
      3. On the connection keypad, press the [Auto / Manual] key to toggle to Manual mode.
      4. On the connection keypad, press the [+] key repeatedly until the display shows 50, then press [Enter].
      5. On the connection keypad, press the [+] key repeatedly until the display shows 51, then press [Enter].
      6. On the connection keypad, press the [Auto / Manual] key to toggle to Auto mode.
    2. Insert an auto-aliquot tube into a tube carrier, and apply an LAS-readable bar code label to the exposed surface of the tube.
      If a tube is loaded without an LAS-readable bar code label, an alarm occurs at the connection unit keypad.
    3. Insert the tube and carrier onto the connection unit track.
    4. Observe the tube as it moves through the connection unit track, stopping at the aspiration position. When the gripper begins to close on the tube, press the [Pause / Run] key.

      This action pauses the tube indefinitely, secured in the gripper. Keep the tube paused in this position while performing track alignments or RF level sense testing.

  4. Align the sample pipettor to the track position.
    Note: The track position alignment requires a barcoded 13x100 autoaliquot tube in a 13x100 or 13x75 carrier (whichever is used on the LAS) as the alignment tool.
    1. Select OK at the screen prompt, Load the sample carrier and tube.
      Note: The sample pipettor moves to a default position, and then disables power to the motors. This allows manual movement of the sample pipettor to the alignment position.
    2. Move the sample pipettor manually so that the probe tip is in contact with the bottom of and centered in the auto-aliquot tube, and then select OK.
      Note: The sample pipettor seeks the x- and z-home sensors and records these step counts from the alignment position.
    3. Ignore the screen prompt that says to release the sample carrier (leave it in place), and select OK.
  5. Verify the sample pipettor track alignment.
    1. Select Move Z to Position (Track).
    2. Verify the sample probe tip is back to the bottom and center of the auto-aliquot tube.
    3. Gently wiggle the probe tip from side-to-side while it is in the auto-aliquot tube. Note if the probe tip slides lightly against the bottom of the tube. Adjust the z-offset, if necessary, to achieve a light touch to the bottom surface of the tube.
      Adjust the z-offset, if the z alignment is:
      • Too low— the probe tip is tight against the bottom surface of the auto-aliquot tube.
      • Too high—the probe tip does not touch the bottom surface of the auto-aliquot tube.
    4. Verify the z-current position (not the z-offset) is between -740 and -1020, when the pipettor is moved to the z-position.
      If the z-current position is not between -740 and -1020 with the probe lightly touching the bottom surface, then raise (or lower) the instrument using the leveling feet.
      • To make the z-current position more negative, raise the DxI instrument. Repeat the semi-auto alignment to the track position.
      • To make the z-current position less negative, lower the DxI instrument. Repeat the semi-auto alignment to the track position.
      Caution: To avoid damaging the probe, home the pipettor before adjusting the height of the DxI instrument.
      Note:
      • One full turn of the (four) adjustable feet is equivalent to about 35 counts.
      • When the z-alignment is not between -740 and -1020, a Motion error after sample dispense error can occur intermittently. For dual-gantry systems, a faulty pipettor motor encoder, encoder cable, or encoder cable connection can cause this error.
    5. Select Save Alignments > Home Device.
  6. Release the auto-aliquot tube from the connection unit.
    1. Toggle the [Pause / Run] key until Run displays on the connection keypad.
      The gripper should release the tube.
    2. Allow the carrier to pass the sensor in front of the connection keypad, and then remove the tube and carrier from the track.
    3. Store the bar-coded auto-aliquot tube in the same location as the other alignment tools.
  7. Reinstall the SPOTB housing.
  8. Reset the connection unit.
    Caution: If the connection unit is not reset to normal mode following usage of the 50 and 51 codes for manually loading tubes, the connection unit will not operate correctly.
    1. Remove the access panel from the rear of the connection unit.
    2. Locate the green power switch inside the connection unit (on the lower left).
    3. Power off the connection unit for 15 seconds, and then power on the connection unit.
    4. Press the [Auto / Manual] key on the connection keypad twice, to return to auto mode.
    5. Press the [Auto / Manual] key on the track keypad twice, to return to auto mode.
    6. Reinstall the access panel on the connection unit.
  9. Resume the LAS sample tube loading.
    1. On the PrepLink Console, select Setup > Instrument Loading tab.
    2. Clear the CONN-X Loading Paused check box.
      The DxI instrument connection units are labeled CONN-1 through CONN-4, according to the number of DxI instruments connected to the LAS.
    3. Observe while the DxI instrument runs a minimum of ten samples from the LAS. Confirm that all tubes are processed correctly through the connection unit and that all samples are aspirated and run correctly by the DxI instrument.
      Note: If captive tubes were released from the connection unit, then errors will show in the event log, as expected for tubes that had processed beyond the query BCR before release.
