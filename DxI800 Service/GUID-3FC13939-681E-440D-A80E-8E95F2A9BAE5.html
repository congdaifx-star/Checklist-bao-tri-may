System Check Troubleshooting

Troubleshooting Failed System Check: Substrate

Troubleshoot the failed System Check in this order: Substrate, Unwashed, Washed.

Substrate Failing Portion Possible Causes Troubleshooting
Substrate %CV
  • Substrate probe or tubing kinked
  • Substrate system air leak
  • Substrate pump, valve, or belt failure
  • 100% System Check used in tube 4
  • Aspirate probe tubing failure
    Note: The peristaltic pump stops midway through System Check. If the aspirate tubing is in poor condition, System Check can leak backwards into the substrate replicates.
  • Substrate probe contamination
  • Luminometer failure
  1. Perform a Dark Count Read.
  2. Look in the Event Log for indications of a substrate delivery problem. The most likely Event Log message is Substrate dispense failure: Air in the Fluidics Line or other pump-related dispense failure.
    Note: If this Event Log message is found, then refer to the System Issues and Event Log Errors in the Fluidics: Troubleshoot Substrate System procedure.
  3. If the unwashed RLU is 20-30 million RLU, then verify a 1:501 was used in tube 4. If tube 4 contained 100% System Check (rather than diluted), then the last few substrate replicates can be elevated from crosstalk.
  4. Inspect for and replace damaged substrate probe and tubing.
  5. Verify that all luminometer ground cables are secure.
  6. Perform substrate volume checks.
    Note:
    • Refer to the Tests: Volume Check procedure.
    • Refer to the Fluidics: Troubleshoot Substrate System procedure.
  7. Inspect for and replace damaged substrate pump and belt.
  8. Consider decontaminating the substrate system.
    Note: Refer to the Fluidics: Decontaminating Substrate procedure.
Substrate High RLU
  • External light source
  • Spill in the analytical module
  • Substrate contamination
  • Luminometer failure or incorrect DCF saved
  • Cable or connection issue with the cable from the DAQC PCB to the luminometer or LED
  • DAQC PCB failure
  • Electrical noise in the system or environment that causes negative feedback to the DAQC PCB
  1. Check for external light leakage. Securely close all internal module covers and instrument covers.
  2. Check the Drift Correction Factor.
    Note: Refer to the AU: Adjusting Luminometer DCF procedure.
  3. Perform a Dark Count Read.
    Note: Refer to the AU: Performing Dark Count Read and AU: Troubleshoot Elevated Dark Count procedures.
  4. Test for substrate contamination and Luminometer issues.
    Note: Refer to the Contamination section of the Fluidics: Troubleshoot Substrate System procedure.
  5. Perform substrate volume checks.
    Note:
    • Refer to the Tests: Volume Check procedure.
    • Refer to the Fluidics: Troubleshoot Substrate System procedure.
Substrate Low RLU
  • Expired substrate or improper equilibration
  • Substrate dispense volume too low
  • Citranox incompletely flushed out after decontamination procedure
  • System temperature too low (can occur if temperatures are simulated in specific.ini)
  • Luminometer failure
  • Cable or connection issue with the cable from the DAQC PCB to the luminometer or LED
  1. Verify correct substrate equilibration and storage.
    Note: Refer to the Substrate document in the "Access Systems Applications" Database.
  2. If the instrument is a new install or the substrate was recently decontaminated, then prime the substrate an extra 30 primes and rerun System Check.
  3. Check the Drift Correction Factor.
    Note: Refer to the AU: Adjusting Luminometer DCF procedure.
  4. View the Event Log for indication of a substrate delivery issue. The most likely Event Log message is Substrate dispense failure: Air in the Fluidics Line or other pump-related dispense failure.
    Note: If this Event Log message is found, then refer to the System Issues and Event Log Errors in the Fluidics: Troubleshoot Substrate System procedure.
  5. Test for substrate contamination and luminometer issues.
    Note: Refer to the Contamination section of the Fluidics: Troubleshoot Substrate System procedure.
  6. Perform substrate volume checks.
    Note:
    • Refer to the Tests: Volume Check procedure.
    • Refer to the Fluidics: Troubleshoot Substrate System procedure.

Troubleshooting Failed System Check: Unwashed

Troubleshoot the failed System Check in this order: Substrate, Unwashed, Washed.

Unwashed Failing Portion Possible Causes Troubleshooting
Unwashed %CV - Multiple Pipettors
  • RV spring finger
  • Dispense probe plate adjustments and alignments
  • Gripper-spinner ejectors
  • Substrate dispense
  • Defective substrate probe
  • Wash carousel motor alignment
  • Turcite bearing
  • Reagent probes dirty, damaged, or loose
  • Sample pump failure
  • Reaction vessels
  • Pick-and-place alignments
  • Luminometer
  • Reagent pump (multiple pumps)
  1. Remove the RV spring finger from the vessel positioner and reinstall the vessel positioner.
  2. Verify the dispense probe plate adjustment and alignment.
    Note: Raise the dispense probe plate up 10 to 15 steps if unwashed continues to fail.
    Note: Refer to these procedures:
    • AU: Adjusting Analytical Module
    • AU: Aligning Analytical Module
  3. Inspect for and replace damaged or obstructed reagent probes.
  4. If one pipettor has a higher mean than the others, consider running Pipettor Matching.
    Note: Refer to the Tests: Pipettor Matching procedure.
  5. Inspect for and replace damaged gripper-spinner ejectors.
  6. Verify wash wheel motor alignment.
    Note: Refer to Aligning Wash Carousel / Wheel Motor procedure.
  7. Lubricate turcite bearing.
    Note: Refer to Performing Turcite Bearing Lubrication procedure.
  8. Check the pick-and-place alignments.
    Note: Refer to these procedures: P&P: Aligning Pick-and-Place Module
  9. Inspect the reaction vessels for scratches or damage. Consider running an Unwashed System Check with the bulk feeder isolated to one bag of vessels. File a Type 2 CF on any reaction vessel box- or bag-related failures.
  10. Perform substrate volume checks.
    Note:
    • Refer to the Tests: Volume Check procedure.
    • Refer to the Fluidics: Troubleshoot Substrate System procedure.
  11. Inspect substrate probe tip for bent or damage. Replace the substrate probe if unwashed continues to fail.
  12. Inspect the sample pump.
    Note: Refer to the Fluidics: Cleaning Pump (Precision/Sample/Wash) procedure.
  13. Verify all the luminometer ground cables are secure.
  14. Troubleshoot the multiple pipettor circuits.
Unwashed %CV - One Pipettor
  • Wash buffer supply insufficient
  • Air in reagent pipettor system
  • Reagent probe dirty, damaged, or loose
  • Reagent pump or valve failure
  • Reagent pipettor alignments
  • Ultrasonics failure
  1. Inspect for and replace damaged or missing parts:
    • O-rings between the pump and fluidics reservoir.
    • O-rings between the pump and pressure sensor.
    • Red and white quick-disconnect fitting to pump.
    • Tubing or connectors.
    • Probe.
  2. Inspect the valve for dried wash buffer. Clean it if necessary.
    Note: Refer to the Fluidics: Cleaning Valves (Precision and Wash) procedure.
  3. Check the reagent pipettor to carriage and wash tower alignment.
    Note: Refer to the RP: Aligning Reagent Pipettor procedure.
  4. Perform a level sense test. Troubleshoot any failures.
    Note: Refer to the RP: Ultrasonics Level Sense Test procedure.
  5. Clean and replace any damaged belt in the precision pump.
    Note: Refer to the Fluidics: Cleaning Pump (Precision/Sample/Wash) procedure.
Unwashed RLU High RLU
  • System Check dilution improperly prepared
  • Tube 1 and 4 switched
Low RLU
  • System Check dilution improperly prepared
  • Poor sample aspiration

Prepare the 1:501 dilution of System Check by mixing 20 µL of System Check solution with 10.0 mL of wash buffer. Do not use HS System Check.

Troubleshooting Failed System Check: Washed

Troubleshoot the failed System Check in this order: Substrate, Unwashed, Washed.

Washed Failing Portion Possible Causes Troubleshooting
Washed %CV
  • Aspirate probes dirty or damaged
  • Duck-bill valve damaged
  • Aspirate peri-pump tubing damaged
  • Dispense probes dirty or damaged
  • Aspirate probe plate adjustment or alignment
  • Wash pump and dispense probe
  • Gripper-spinner ejector damaged
  • Pick-and-place alignment
  • Reaction vessels
  1. Replace the aspirate probes and duck-bill valve.
  2. Replace the peri-pump tubing.
  3. Verify the aspirate probe plate adjustment and alignment.
    Note: Refer to these procedures:
    • AU: Adjusting Analytical Module
    • AU: Aligning Analytical Module
  4. Inspect for and replace damaged dispense probes and tubing.
  5. Inspect for and replace damaged gripper-spinner ejectors.
  6. Check the pick-and-place alignments.
    Note: Refer to these procedures: P&P: Aligning Pick-and-Place Module
  7. Inspect the wash pump valves for dried wash buffer. Clean if necessary.
    Note: Refer to the Fluidics: Cleaning Valves (Precision and Wash) procedure.
  8. Inspect the reaction vessels for scratches or damage. File a Type 2 CF on any reaction vessel box- or bag-related failures.
  9. Clean and replace any damaged belt in the wash pumps.
    Note: Refer to the Fluidics: Cleaning Pump (Precision/Sample/Wash) procedure.
Washed High RLU
  • Aspirate probes dirty or damaged
  • Aspirate peri-pump tubing damaged
  • HS System Check used
  • Aspirate probe plate adjustment or alignment
  • Gripper-spinner ejector damaged
  • Wash pump or valve and dispense probe
  • Contaminated consumables (substrate, wash buffer, or reaction vessels)
  1. Confirm that System Check Solution (not HS System Check) was used.
  2. Replace the aspirate probes.
  3. Replace the peri-pump tubing.
  4. Verify the aspirate probe plate adjustment and alignment.
    Note: Refer to these procedures:
    • AU: Adjusting Analytical Module
    • AU: Aligning Analytical Module
  5. Inspect for and replace damaged gripper-spinner ejectors.
  6. Inspect the wash pump valves for dried wash buffer. Clean if necessary.
    Note: Refer to the Fluidics: Cleaning Valves (Precision and Wash) procedure.
  7. Check consumables for potential contamination. Replace any consumables that are suspect.
  8. Clean and replace any damaged belt in the wash pumps.
    Note: Refer to the Fluidics: Cleaning Pump (Precision/Sample/Wash) procedure.
Washed Low RLU
  • Premature level sense
  • Aspirate probe 3 failure
  • Incorrect sample
  • Flooded wash wheel
  1. Confirm that System Check was used in tube 1.
  2. Perform a Level Sense Test and troubleshoot any failures.
    Note: Refer to the RP: Ultrasonics Level Sense Test procedure.
  3. Replace aspirate probe 3 and the associated peristaltic pump tubing.
  4. Inspect the wash wheel for a wash buffer spill.

Troubleshooting Failed System Check: Other

Other Failing Portion Possible Causes Troubleshooting
Substrate Ratio
  • Aspirate robes dirty or misaligned
  • Peri-pump tubing damaged
  • Duck-bill valve dirty or damaged
  1. Replace the aspirate probes and duck-bill valve.
  2. Replace the peri-pump tubing.
Drift Correction Factor
  • DCF needs adjustment
Check the Drift Correction Factor.
Note: Refer to the AU: Adjusting Luminometer DCF procedure.
Wash Efficiency Troubleshoot the other portion of System Check that is failing
