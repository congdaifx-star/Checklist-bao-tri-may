Using pcAnywhere Between Remote PC and Console PC (DxI and Access 2)

This procedure describes how to connect to an instrument console PC using a remote PC.

Connect to the console PC from a remote PC to:
  • Confirm that the modem line works for a new instrument installation.
  • Save Diagnostic Copy To Disk data for a Type 1 CF investigation.
  • Troubleshoot advanced software or database issues.

For troubleshooting information, refer to the Software: Troubleshoot pcAnywhere procedure.

Note: There are different procedures for connecting to a console PC depending on the version of pcAnywhere that is being used by the remote PC. Confirm the pcAnywhere version before beginning. To determine the software version, select Help  > About Symantec pcAnywhere.
  1. For pcAnywhere V11.5 or lower: Connect to an instrument console PC from a remote PC.
    1. On the PC, select Start  > Programs > Symantec pcAnywhere.
    2. In pcAnywhere, select Remote Control.
    3. Double-click the Add Remote Control Item icon.
      Previously created connections are listed, and can be opened by double-clicking on the entry.
    4. Enter the required information at the prompts for name, standard modem (default), phone number to dial, auto connect when finished.
      Note:
      • Use commas after the phone number to allow a delay before entering the extension number.
      • When dialing into a phone switch box, add five comas after the phone number and then the switch box port number (#55,,,#55 is used for port number 5).
    5. To log in to the remote host, enter ID: administrator and password: Access2.
      Note:
      • DTX PCs might use password: unicel.
      • To set up the location to log in automatically, right-click the icon of the location, and then select Properties > Settings > Login information > Automatic login. Enter the ID and password (administrator, Access2).
  2. For pcAnywhere V11.5 or higher: Connect to an instrument console PC from a remote PC.
    1. On the PC, select Start  > Programs > Symantec pcAnywhere.
    2. In pcAnywhere, select Remotes.
    3. Select Modem.
    4. Enter the phone number and select OK.
      Note:
      • Use commas after the phone number to allow a delay before entering the extension number.
      • When dialing into a phone switch box, add five comas after the phone number and then the switch box port number (#55,,,#55 is used for port number 5).
    5. To log in to the remote host, enter ID: administrator and password: Access2.
      Note:
      • DTX PCs might use password: unicel.
      • To set up the location to log in automatically, right-click the icon of the location, and then select Properties > Settings > Login information > Automatic login. Enter the ID and password (administrator, Access2).
