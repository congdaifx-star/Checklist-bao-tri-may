Software V1.3 Release Notes

Confidentiality

Software release notes are Confidential.

Notes

These release notes apply to the change from Version 1.0, 1.0.1, and 1.2 to Version 1.3 software.

Purpose

This release of software is released to correct software bugs and improve operator ease of use.

Reference Documents

Installation instructions are available for this release of software and must be used to install this version of software. These instructions, and other pertinent documents are referenced in Mod 6302

New Features and Enhancements of V1.3 Software

New Features Details
Release of APF Version 1.10.8. Adds assay 166, TotT3, and changes the curve fitting parameters for 111, FT4. The user must recalibrate FT4 and verify references ranges.
Alignment - Dispense Probe Plate Changes the dispense probe plate alignment in the wash arm.
Note: This change requires the service engineer to realign the device. This alignment is an auto-alignment of primary device Dispense Probe Plate and alignment point RV engage.
Alignment - Aspirate Probe Plate Changes the aspirate probe plate alignment in the wash arm.
Note: This change requires the service engineer to realign the device. This alignment is a semi-auto-alignment of primary device Aspirate Probe Plate and alignment point RV bottom.
Back Draw Changed Changes the dispense probe back draw to reduce bubbles at the bottom of the probe to improve the precision of the results for some assays.
Motor Accelerations Decreases the maximum motor accelerations for the devices that handle vessels with fluid in them. When the pick-and-place devices do not have vessels, they operate at the faster motor accelerations. This change decreases fluid splashing in the vessels and improves the precision of the results for some assays.
Manufacturing Enhancements Adds these enhancements for manufacturing support:
  • Vessel handling exercisers
  • Reagent exercisers
  • Volume check routines
  • Wash wheel dark count detection routine
  • LumiPip precision
  • Ultrasonic level sense simultaneous pipettor tests
  • RF level sense simultaneous wet and dry tests
  • Additional and modified diagnostics reports: Ultrasonics test, RF level test
Bulk Vessel Feeder Escrow Chute Changes the system behavior when the bulk vessel feeder escrow chute is empty. In previous software versions, the system went to Pause mode followed by Not Ready mode with the assumption that the bulk hopper was truly empty. Since it was determined that the bulk feeder cannot always keep up with demand even when the hopper has sufficient supply, a new algorithm was implemented. The system now stops scheduling new tests and attempts to fill the chute. After ten unsuccessful attempts, the system goes to Paused mode and then to Not Ready mode.
Software Installation Enhances software installation. The installation program now closes all DxI software processes that were not closed correctly as part of the normal shutdown procedure on both the instrument and the console. If there are unsent event messages on the instrument, the installation does not proceed, allowing the previous version of software to handle all of its events prior to upgrading. It is no longer necessary to hold down the [Shift] key when inserting the CD.
Processing Monitoring Process Monitoring now includes an early algorithm for empty reagent pack detection for assays that dispense 50 µL or more of reagent. The sensitivity is currently set low allowing us to collect field data and not rejecting good packs.
Substrate Temperature Substrate temperature control now accounts for the ambient temperature when controlling the substrate temperature.
Pipettor Status Display Displays the instrument pipettor status as part of the pipettor enable and disable screen in System Configuration to allow the user to see when the system disables a pipettor automatically.
Reflex Equations Changes he internal reflex equation for reflexing from a low dil-hCG to TBhCG2 to allow the system to generate a reflex. For example, if the customer set up a reflex equation of dil-hCG < 1000 and the current dil-hCG result is below the curve, the reflex condition triggers the reflex assay. This reflex currently goes to Work Pending and automatically runs when the primary tube is reloaded.
Reagent Cooler Vendor This software now supports two vendors for reagent coolers (see Val Plan #808). To allow a future cut-in of the reagent cooler from the second vendor, changed the gain to support hardware from either vendor.
Sample Probe Wash Now the sample probe is shower-washed as it goes down into the wash tower.
Complete Init Box Removed The Complete Init checkbox was removed from the System Initialization dialog because of confusion with its usage. Now, the system behaves as if the checkbox is always checked.

Workarounds

Recommended workarounds for specific issues remaining in this version of software.

Issue Workaround
Prime No Substrate If priming is requested when there is no substrate, the system can lock up. Before requesting priming, make sure there are sufficient supplies
Test Result In Process Tests In some cases, some tests can appear to be in process forever in the Test Results screen. This issue can be ignored, as it does not prevent other runs. In general, this issue was corrected with the upgrade to V1.2 and the manual database cleaning (performed by the software engineers via PCAnywhere).

Identified and Corrected Issues

Some of the issues that were addressed in this release. Over 180 SPRs were closed in this software release.

Issue Corrected or Changes Made (Version 1.2) Notes
Sample Manager Rack ID Corrects the problem where editing an existing rack through the Sample Manager screen can show the wrong rack ID with the expected sample tube information.
Reagent Gripper Now, the reagent gripper verify routine functions correctly when tweaking the nest positions. This problem was introduced in V1.2 software.
Upside Down Vessels Corrects some occurrences of upside down vessels where software was a cause. The system could sometimes advance two scoop positions at software startup which could cause an upside down vessel if a vessel was present at the top ejector that should have been pushed out by the bottom ejector..
Substrate Less Than Zero Corrects the problem of substrate counts that are less than zero (-1, -2).
Waste Chute Auto-aligner The new waste chute design caused the auto-aligner to fail for the sample pick-and-place and incubator pick-and-place. Removes the auto-aligner and replaces it with a semi-auto-aligner for sample pick-and-place and incubator pick-and-place.
QC Screen Lockups Corrects the problem with missing and extra QC icons and occasional screen lock-ups while in QC during a run
LAS Sample ID Reuse Corrects a problem with the automation track where a sample ID reused within 30 days would not find the correct sample tube to pull a test out of Work Pending.
LIS Case Insensitive Assay Names Removes the LIS assay name case sensitivity in the software since V1.0. This change is identical to the change for Access 2 V2.1 software.
Japanese Tube Types Corrects a problem with sample tube geometry that affected the three Japanese tube types. Now, the system runs all of these tube types correctly.

Known Issues Remaining in This Version

  • Leaving the Communications Test Dialog open for a long time (more than 8 hours) can cause an instrument software crash.
