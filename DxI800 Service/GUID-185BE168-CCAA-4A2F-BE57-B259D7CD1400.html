Specs - DS3000b UPS

Purpose

This document provides the specifications for the DS 3000b UPS.

Notes

This UPS:
  • Is available for OUS only.
  • Is provided with a cord for use between the UPS and the wall outlet.
  • Provides backup power for the DxI instrument.
  • Ships from Powervar UK.

Specifications
