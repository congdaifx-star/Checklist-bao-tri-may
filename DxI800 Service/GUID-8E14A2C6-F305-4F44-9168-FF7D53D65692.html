LEDs - PCB - Power Distribution

Note: A power indicator LED may appear to be on (although it will be dim) even when the voltage is not correct.
LED Color Label / Function

D1

Green

+24V_REAG_AUX. (All Coolers).

24V to this branch is present when D1 LED is on.

Power for the three reagent storage cooling fans and the BCR window heater through J14 to the Reagent Storage I/F PCB. Also converted to +12V to power the PWM drivers for all Peltiers.

D2

Green

+24V SPARE (not used).

24V to this branch is present when D2 LED is on.

D3

Green

+24V ANALYTICAL MODULE.

24V to this branch is present when D3 LED is on.

Power for the mixer motor and the ejector plate air valve through J8 to the Analytical Module I/F PCB.

D4

Green

+24V DAQC/LUMI.

24V to this branch is present when D4 LED is on.

Power to the DAQC PCB for the luminometer HVPS through J7 to the CPU card cage.

D5

Green

+24V SAMPLE (sample cooler).

24V to this branch is present when D5 LED is on.

Power for the sample storage Peltier through J1.

D6

Green

+24V INCB (incubator heater).

24V to this branch is present when D6 LED is on. Illuminated.

Power to the incubator heater through connector J1 to the Analytical Power I/F PCB.

D8

Green

+24V ULTRA (Ultrasonics PCBs).

24V to this branch is present when D8 LED is on

Power for the two Ultrasonics PCBs through J5 to the MCC backplane.

D9

Green

+24 MCC (MCC PCBs).

24V to this branch is present when D9 LED is on.

Power through J2 to the MCC backplane for:
  • All motors. Peri pumps, sensors, and valves driven by the 8 MCC PCBs.
  • Substrate heater.
  • Four reagent pipettor heaters.
  • Five MCC card cage fans.

D10

Green

+24V_CPU.

24V to this branch is present when D10 LED is on.

Power for all CPU card cage devices through J4 to the CPU Power Distribution PCB.

D11

Green

+24V_REAG1 (reagent cooler 1).

24V to this branch is present when D11 LED is on.

Power to reagent Peltier 1 through J10-1.

D12

Green

+24V_REAG2 (reagent cooler 2).

24V to this branch is present when D12 LED is on.

Power to reagent Peltier 2 through J10-4.

D13

Green

+24V_REAG3 (reagent cooler 3).

24V to this branch is present when D13 LED is on.

Power to reagent Peltier 3 through J10-7.

D15

Green

REAG PWM1+ (reagent cooler 1).

Reagent Peltier 1 enabled: (TP5) = 0 V and D15 LED is on.

Signal from U1-7 to Q12 (TP7) to Q8 grounds 24V output of reagent storage module Peltier 1 on J10-3 (pulsed ground).

D17

Green

REAG PWM2+ (reagent cooler 2)

Reagent Peltier 2 enabled: (TP7) = 0 V and D17 LED is on.

Signal from U4-7 to Q11 (TP8) to Q4 grounds 24V output of reagent storage module Peltier 2 on J10-6 (pulsed ground).

D19

Green

REAG PWM3+ (reagent cooler 3).

Reagent Peltier 3 enabled: (TP8) = 0 V and D19 LED is on.

Signal from U4-5 to Q14 (TP9) to Q10 grounds 24V output of reagent storage module Peltier 3 on J10-9 (pulsed ground).

D24

Green

+24V LOWER CAB (Lower Cabinet I/F PCB)

24V to this branch is present when D24 LED is on.

Power to the compressor, moisture bleed valve, and selector valves for wash buffer and waste bottles through J1 to the Lower Cabinet I/F PCB.

D25

Green

+24V WASH (wash carousel heater).

24V to this branch is present when D25 LED is on.

Wash carousel heater power through J1 to the Analytical Power I/F PCB.

D26

Green

MAIN BLOWER

24V to this branch is present when D26 LED is on.

Power to the main blower fan through J12.

D28

Green

SAM PWM+ (sample storage cooler).

Sample Peltier enabled: (TP6) = 0 V and D28 LED is on.

Signal from U1-5 to Q13 (TP11) to Q9 grounds 24V coming from the sample storage module Peltier (pulsed ground).

D30

Green

+24V PERI (vacuum pumps).

24V to this branch is present when D30 LED is on.

Vacuum pump power through J1 to the Peri Pump / Vacuum I/F PCB.

Note: The peristaltic pumps are powered by the MCC PCBs through the motor drive cables.

D31

Green

24V GATE

24V to this branch is present when D31 LED is on.

This 24V is converted to +36V (TP1) to power the solid state relays. The solid state relays enable power to various power distribution PCB connectors when the interlock or toggle switches are closed.

Note:
  • If this branch does not have power, then power is off on all other branches except CPU and MAIN BLOWER.
  • If power supply 1 is dead, then the entire system will appear to be dead even if power supplies 2 and 3 are OK.
