Using Desktop Sharing Between Laptop and Console PC or AU

This procedure describes how to connect a laptop to either a console PC or an AU using desktop sharing applications.

Prerequisite: The instrument must be on software V5.1 or higher.

Connect a laptop to the console PC or AU to display and interact with:
  • the user interface (helpful when working behind instruments).
  • the AU.

If only trace files or instrument files must be saved, refer to the Software: Transferring Files (Trace/Debug/Data) procedure.

Note:

For Windows XP System

  • Use the laptop's Windows Remote Desktop Connection application to remote to the Windows XP Console PC or Windows XP AU side.
  • The console PC with the latest Windows XP image and AU hard drive with the latest Windows XP already had the remote connection enabled.
  • If Remote Desktop sharing fails due to remote connection is not enabled, then perform the following steps to enable remote connection.
    • Select Start > Settings > Control Panel > System > Remote.
    • Check the box for the Allow users to connect remotely to this computer option.
For Windows 8 System
Note: Windows 8 system no longer allows remote access using Windows Remote Desktop Connection application from a laptop. Windows Remote Desktop Connection application is replacing by VNC Viewer application.
  • VNC Viewer application is required to remote to the Windows 8 Console PC. If VNC Viewer application was not installed on the laptop, please contact IT for installing the application.
  • Using VNC Viewer application to remote to the Windows 8 AU side is not possible, because the AU side does not have VNC Server application installed. Use the VNC Viewer Windows 8 Console PC remote screen to remote to the AU side.
  1. Plug an ethernet cable from the laptop into the SPU port.
    Note: The port is located on bottom of the SPU near the substrate bar code reader.
  2. Configure the laptop for remote connection.

    For Windows XP Laptop:

    1. Select Start > Settings > Control Panel > Network Connections..
    2. Right-click on Local Area Connection.
    3. Select Properties > Internet Protocol (TCP/IP)  > Properties > Use the Following IP address, and type 192.168.2.5.
    4. Press the [Tab] key, and then select OK > OK.

    For Windows 10 Laptop:

    1. Press Windows key, type in control panel and select Control Panel.
    2. Select Network and Sharing Center > Change adapter settings.
    3. Right click on Etherent, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    4. Select Use the following IP address, type IP address 192.168.2.5 and Subnet mask 255.255.255.0.
    5. Select OK to save the changes.

    For Windows 8 Laptop:

    1. Press the Windows key, type network connections and select the View Network Connections icon under the settings search.
    2. Right click on Local Area Connection, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    3. Select Use the following IP address, type IP address 192.168.2.5 and Subnet mask 255.255.255.0.
    4. Select OK to save the changes.

    For Windows 7 Laptop:

    1. Press the Windows key > Control Panel > Network and Sharing Center > Change adapter settings.
    2. Right click on Local Area Connection, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    3. Select Use the following IP address, type IP address 192.168.2.5 and Subnet mask 255.255.255.0.
    4. Select OK to save the changes.
  3. Use Windows Remote Desktop Connection application to remote Windows XP system.
    1. Open a remote connection to Windows XP system.

      For Windows XP Laptop:

      1. Select Start > Programs  > Accessories > Remote Desktop Connection.
        Note: If the remote desktop connection is not available under Accessories, select Start > Run, type mstsc.exe, and select OK.
      2. Input the IP address to make the associated connection:
        • 192.168.2.3 Console PC
        • 192.168.2.4 AU
      3. Select Options > Local Resources > More.
      4. Check the Drives option, and select OK > Connect.
      5. Enter the username user and password tech.

      For Windows 10, 8, or 7 Laptop:

      1. Press the Windows key, type in remote desktop and select the Remote Desktop Connection application.
      2. Type in the following IP addresses:
        • 192.168.2.4 for the AU into the Computer field.
        • 192.168.2.3 for Console PC into the Computer field.
      3. Select Show Options > Local Resources > More.
      4. Check the Drives option and select OK > Connect.
      5. Enter user for User Name and tech for the password if prompted.
      6. If prompted at the RDS warning screen, check the box for "Don't ask me again for connections to this computer" and select Yes.
    2. Close the desktop sharing connection to Windows XP system.

      For Windows XP Laptop:

      1. From the AU Desktop or Console PC Desktop, select Start > Disconnect or select the X in the upper right corner.
      2. Select OK at the Disconnect Windows Session pop-up.

      For Windows 10, 8, or 7 Laptop:

      1. From the AU Desktop or Console PC Desktop, right click on Remote Desktop Connection icon on the upper left corner or on the task bar > Close or select the X in the upper right corner.
      2. Select OK at the Your remote session will be disconnected pop-up.
    3. If the laptop was connected to the console PC (192.168.2.3), then unlock the console screen by entering the username user and password tech.
  4. Use VNC Viewer application to remote connection to Windows 8 system.

    For Windows 10, 8, or 7 Laptop:

    Note: Windows 8 system no longer allows remote access using Windows Remote Desktop Connection application from a laptop. Windows Remote Desktop Connection application is replacing by VNC Viewer application.
    • VNC Viewer application is required to remote to the Windows 8 Console PC. If VNC Viewer application was not installed on the laptop, please contact IT for installing the application.
    • Using VNC Viewer application to remote to the Windows 8 AU side is not possible, because the AU side does not have VNC Server application installed. Use the VNC Viewer Windows 8 Console PC remote screen to remote to the AU side.
    1. Open a remote connection to the Windows 8 Console PC.
      1. Press Windows key, type in vnc viewer and select VNC Viewer application.
      2. Enter 192.168.2.3 to the VNC Server box.
      3. Select Let VNC Server choose potion in the Encryption box and click Connect.
      4. Enter the following password
        • Access2 for earlier Windows 8 Console PC image.
        • BCService for current Windows 8 Console PC image.
        when the password box prompted and then click Ok.
    2. Open a remote desktop connection to the Windows 8 AU side.
      • Use VNC Viewer to remote to Windows 8 Console PC.
      • In the VNC Viewer Windows 8 Console PC remote screen, press Windows key and select Remote Desktop Connection to DxI icon.
      • Enter user for User Name and tech for the password if prompted.
      • Select OK at the Your remote session will be disconnected pop-up.
    3. Close the desktop sharing connection to Windows 8 system by selecting X in the upper right corner.
  5. Disconnect the laptop from the SPU port.
  6. Reset the laptop connection settings to normal.

    For Windows XP Laptop:

    1. Select Start > Settings > Control Panel > Network Connections..
    2. Right-click Local Area Connection.
    3. Select Properties > Internet Protocol (TCP/IP)  > Properties.
    4. Select the Obtain an IP address automatically option.
    5. Select OK > OK.

    For Windows 10 Laptop:

    1. Press Windows key, type in control panel and select Control Panel.
    2. Select Network and Sharing Center > Change adapter settings.
    3. Right click on Etherent, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    4. Select Obtain an IP address automatically. .
    5. Select OK to save the change.

    For Windows 8 Laptop:

    1. Press the Windows key, type network connections and select the View Network Connections icon under the settings search.
    2. Right click on Local Area Connection, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    3. Select Obtain an IP address automatically.
    4. Select OK to save the change.

    For Windows 7 Laptop:

    1. Press the Windows key > Control Panel > Network and Sharing Center > Change adapter settings.
    2. Right click on Local Area Connection, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    3. Select Obtain an IP address automatically.
    4. Select OK to save the change.
