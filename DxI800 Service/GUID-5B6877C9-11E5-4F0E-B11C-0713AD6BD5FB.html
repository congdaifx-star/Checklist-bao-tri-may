Installing Dual NIC Card

This procedure describes how to install a dual NIC card into a No Dot DTx PC.

Perform this procedure when upgrading the system. The network interface card is added to support:
  • DxI - Install PROService
  • Install - Dynamic LAS, Enable
  1. Install the Dual NIC into the console PC.
    1. Shut down and power off the PC.
    2. Remove the left side panel of the PC.
    3. If this is an initial NIC installation, move the modem card and the serial interface card down one slot.
    4. Install the network interface card into the top most card slot in the PC.
      Note:
      • The network interface card may not work properly, if it is not installed in the top slot.
      • Refer to the PC Console, Connector Identification procedure (No Dot DTx PC With NIC Card Modification section) for card location details.
    5. Reattach the side panel to the PC.
  2. Configure the PC CMOS.
    1. Power on the PC, pressing the [Del] key during the boot-up to enter CMOS setup.
    2. Select Advanced > Port Configuration > Onboard Game MIDI Port, and then select Disabled.
    3. Press Esc to exit the Advanced menu.
    4. Select PCIPnP, then set Allocate IRQ to PCI VGA to No and Palette Snooping to Disabled.
    5. Press Esc to exit the PCI menu, and then press F10 > Enter to exit and save the changes.
      Note: The Enter key near the number pad may not work.
  3. Configure the NIC ports.
    1. Select Start > Settings > Control Panel > Network Connections.
    2. Select Advanced > Network Identification > Change, and then enter the instrument serial number_PC (60xxx_PC) as the Computer Name.
      Note: The Computer Name must be unique for each PC connected to Dynamic LAS or RMS to avoid network conflicts.
    3. Select OK > OK to the nonstandard name pop-up, and respond OK to the You must restart popup, No to the Restart now pop-up, if it appears.
    4. Right click on Local Area Connection (the one without a number), and select Properties  > (General tab) TCP/IP > Properties to access the adapter configuration settings.
    5. Edit the Local Area Connection properties:
      • IP Address: 192.168.2.3
      • Netmask: 255.255.255.0
      • Default Gateway: Leave the line blank.
    6. Edit the Local Area Connection 3 properties:
      • IP Address: 134.217.96.181 (.182, .183, etc., see Note below)
      • Subnet Mask: 255.255.255.0
      • Default Gateway: Leave the line blank.
      Note:
      • This adapter is used for Dynamic LAS or UCTA connection and will not be present if the Dual NIC is not installed.
      • The IP address should match the address set on the Preplink console for this DxI IDC connection.
      • For Integrated systems with a UCTA, set this port to 134.217.96.184. Refer to the "Drawing - Network Connectivity" procedures for connection details. For two integrateds networked, this address may be 134.217.96.185. Check the Chem console for the correct address.
      • For multiple DxIs connected to Dynamic LAS, use the "ipconfig" command in the CMD window at each PC to confirm that all connected PCs will have a unique IP address for ethernet adapter 3.
    7. Edit the Local Area Connection 2 properties:
      • IP Address: 172.16.1.30 (or .31, .32, .33 etc., see Note below)
      • Subnet Mask: 255.255.255.0
      • Default Gateway: 172.16.1.1
      Note:
      • This adapter is used for RMS and will not be present if the Dual NIC is not installed.
      • For multiple PCs networked to one RMS box, use the "ipconfig" command in the CMD window at each PC to confirm that all connected PCs will have a unique IP address for ethernet adapter 2.
      • Select the Connected Systems button on the Admin window on the RAP Box to list the expected IP addresses of the connected systems. Refer to the "DxI - Install ProService" procedure for details.
    8. Select OK, and then exit the Network Properties window.
