Disabling Process Monitoring

This procedure describes how to disable and enable process monitoring for devices.

Warning: Do not allow customers to operate the DxI instrument when any process monitoring function is disabled. This could allow inaccurate and unflagged results to report when hardware is malfunctioning.
Disable process monitoring:
  • When procedures require temporary suppression of process monitoring for troubleshooting or repair.
Enable process monitoring:
  • immediately following any procedure where process monitoring has been temporarily disabled.
  • when Some process monitoring features are disabled warnings appear in the Event Log. Warnings were added in software V2.2 and higher.
  • to confirm that all process monitoring devices are enabled. Software prior to V2.2 does not provide warnings in the Event Log when process monitoring devices are disabled.
  1. Disable process monitoring from the AU.
    Warning: Process monitoring must be re-enabled before resuming normal operations. Do not allow customers to operate the DxI when process monitoring is disabled, because inaccurate and unflagged results can occur.
    1. Connect to the AU using Desktop Sharing.
      Note: Refer to the Software: Using Desktop Sharing Between Console PC and AU procedure.
    2. In the AU, right click on the Y icon at the bottom right corner of the display, and then select Exit.
    3. In the AU
      • For Windows XP, select Start  > Programs  > Windows Explorer.
      • For Windows 8, press Windows key and select File Explorer in the application menu.
    4. Browse to the C:\AU directory and open the Specific.ini file.
    5. Scroll down and change the value from Enabled=yes to Enabled=no for the desired device.
      Table 90: Device Process Monitoring
      [FluidLevelControl. ProcessMonitoring] Enabled=

      (monitors the WB fluid detector, if present). Default value = yes regardless of whether the WB bubble detector is present.

      [ReagentPipettor1. ProcessMonitoring] Pressure Enabled=

      Vacuum Enabled=

      PeriPump Flow Enabled=

      AdaptiveEmptyPackDetection_Enabled=

      Empty Pack Detection=

      [ReagentPipettor2. ProcessMonitoring] Pressure Enabled=

      Vacuum Enabled=

      PeriPump Flow Enabled=

      AdaptiveEmptyPackDetection_Enabled=

      Empty Pack Detection=

      [ReagentPipettor3. ProcessMonitoring] Pressure Enabled=

      Vacuum Enabled=

      PeriPump Flow Enabled=

      AdaptiveEmptyPackDetection_Enabled=

      Empty Pack Detection=
      Note: On the DXI 600 the default values are:
      • no for Pressure Enabled, Vacuum Enabled and PeriPump Flow Enabled.
      • yes for AdaptiveEmptyPackDetection_Enabled and Empty Pack Detection.
      [ReagentPipettor4. ProcessMonitoring] Pressure Enabled=

      Vacuum Enabled=

      PeriPump Flow Enabled=

      AdaptiveEmptyPackDetection_Enabled=

      Empty Pack Detection=
      Note: On the DXI 600 the default values are:
      • no for Pressure Enabled, Vacuum Enabled and PeriPump Flow Enabled.
      • yes for AdaptiveEmptyPackDetection_Enabled and Empty Pack Detection.
      [SamplePipettor. ProcessMonitoring] Pressure Enabled=

      Vacuum Enabled=

      PeriPump Flow Enabled= yes

      [Substrate. ProcessMonitoring] Enabled=

      (for the drawback / bubble detector)

      [WashWheel. ProcessMonitoring] Enabled=

      (for the A1 probe collar wash vacuum and pressure sensors)

    6. Select File > Save to save the changes to the Specific.ini file, and then exit Notepad.
    7. Restart the AU software by double clicking the large Y icon on the AU display.
    8. Exit Desktop Sharing and return to the user interface.
  2. Enable process monitoring for any device that is disabled, or to confirm that all devices are enabled.
    1. Verify that the pressure sensors and substrate drawback have been successfully calibrated.
      Caution: Enabling process monitoring for a device with an invalid calibration can cause the instrument software to exit when the device is used.
      Note: These non-calibrated sensors have hard-coded error limits:
      • The pressure sensor for the A1 probe wash pump.
      • The vacuum sensor for the A1 probe wash collar.
      • Vacuum sensors for all pipettor wash towers.
    2. Connect to the AU using Desktop Sharing.
      Note: Refer to the Software: Using Desktop Sharing Between Console PC and AU procedure.
    3. In the AU, right-click on the Y icon at the bottom right corner of the display, and then select Exit.
    4. In the AU
      • For Windows XP, select Start > Programs > Windows Explorer.
      • For Windows 8, press Windows key and select File Explorer in the application menu.
    5. Browse to the C:\AU directory and open the Specific.ini file.
    6. Select Search > Find.
    7. Type processmon in the text box, and press [Enter].
    8. Scroll down and change any Enabled=no to Enabled=yes for each device in the Device Process Monitoring table.
      Note: Confirm calibrations for the calibrated sensors by the SensorCalibrated=yes line.
    9. Select File > Save, and then exit Notepad.
    10. Restart the AU software by double-clicking on the large Y icon on the AU display.
    11. Exit Desktop Sharing and return to the user interface.
