Enabling DxI Dynamic LAS Interface

This procedure describes how to enable the DxI dynamic LAS interface feature with the power processor lab automation system. NOTE: Because the network might include a firewall or might be managed by the customer's IT department, to configure the IP address for the DxI instrument, see the DxA Service Manual for more information.

Perform this procedure only after confirming these prerequisites:
  • DxI software V5.1 or higher has been installed.
  • The DxI console has a network port available for LAS or console pre-configured with multiple network ports.
  • PrepLink V3.5 software or higher has been installed and configured.
  • The lab automation group has prepared the LAS to run with the DxI Dynamic Interface.

The procedure for enabling the dynamic LAS is different for DxI instruments running different versions of Windows. Use the procedure for the version of Windows running on your DxI instrument.

  1. Pause the LAS sample tube loading.
    1. On the PrepLink Console, select Setup > Instrument Loading .
    2. Select the correct CONN-X Loading Paused option (X = 1,2,3, or 4).
      The DxI instrument connection units are labeled CONN-1 through CONN-4, according to how many DxI instruments are connected to the LAS.
    3. Before proceeding, verify that the selected DxI instrument has completed processing all samples.
  2. For DxI instruments running Windows XP with Software 5.2 and below, use this procedure to enable dynamic LAS.
    1. At the DxI console, select Configure > LIS/LAS > LAS, and then select Disabled and OK.
    2. Press [Alt] + [F4], and then enter the password Access2Support when prompted.
    3. SelectStart > Settings  > Control Panel > Network Connections.
    4. Select Advanced > Network Identification. Under Computer Name, select Change.
    5. Enter the DxI instrument serial number followed by PC (example: 600010PC), select OK > OK > OK, and then select No to the Restart option.
    6. Select Local Area Connection 3, choose Internet Protocol (TCP/IP), and select Protocols > Properties.
    7. Select the Use the following IP address option, change the IP address to 134.217.96.181, select Apply > OK  > Close, and then select No at the Restart option.
      If more than one DxI instrument will be connected to the LAS, use these IP addresses:
      • DxI 1 IP 134.217.96.181
      • DxI 2 IP 134.217.96.182
      • DxI 3 IP 134.217.96.183
      • DxI 4 IP 134.217.96.184
      Note: The subnet mask is 255.255.255.0. Change as needed.
    8. Select Start > Run, and then type regedit and press [Enter].
    9. In the Registry Editor, go to the Workgroup folder:
      My Computer  > HKEY_LOCAL_MACHINE > SOFTWARE > Beckman  > NexStep > Workgroup

    10. In the right pane, highlight the PWPEnabled line, select Edit > Modify, change the Value data: to 1, and then select OK.
    11. Highlight the PWPServerIp line, select Edit > Modify, change the Value data: to 134.217.96.181, and then select OK.
      If more than one DxI instrument will be connected to the LAS, use these IP addresses:
      • DxI 1 IP 134.217.96.181
      • DxI 2 IP 134.217.96.182
      • DxI 3 IP 134.217.96.183
      • DxI 4 IP 134.217.96.184
    12. Highlight the PWPTcpIpPort line, select Edit > Modify, change the Value data: to beca, and then select OK.
    13. Exit the Registry Editor and Control Panel windows.
    14. Select Start > Shut Down  > Restart the computer > Yes.
      Note: Reboot the PC for the changes to take effect.
  3. For DxI instruments running Windows 8 or 10 with Software 5.3.1 and above, use this procedure to enable dynamic LAS.
    1. At the DxI console, select Configure > LIS/LAS > LAS, and then select Disabled and OK.
    2. Press [Alt] + [F4], and then enter the password Access2Support when prompted.
    3. Press Windows key, select Control Panelicon or type control panel and open the program.
    4. Double click on System, select Change settings on the middle left side of the System pop-up box.
    5. On the System Properties pop-up box, select Computer name tab and click on the Change option. Enter the DxI instrument serial number followed by PC (example: 600010PC).
    6. Click OK to save the change, select Yes to "Do you want to use this computer name?" prompted message, and selectOK to "You must restart your computer to apply these changes" prompted message.
    7. On the System Properties pop-up box, change the Computer description to match the computer name, and select Apply > Restart Now to restart the PC.
    8. Press Windows key, type network connections, click on Settings, select View Network Connections.
    9. Right click on Local Area Connection 3, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    10. Select the Use the following IP address option, change the IP address to 134.217.96.181, select OK  > Close.
      If more than one DxI instrument will be connected to the LAS, use these IP addresses:
      • DxI 1 IP 134.217.96.181
      • DxI 2 IP 134.217.96.182
      • DxI 3 IP 134.217.96.183
      • DxI 4 IP 134.217.96.184
      Note: The subnet mask is 255.255.255.0. Change as needed.
    11. Press Windows key, type regeditand open the regedit.exe program.
    12. In Registry Editor, go to the Workgroup folder:
      • For Windows 10 go to My Computer  > HKEY_LOCAL_MACHINE > SOFTWARE > WOW6432Node > Beckman  > NexStep > Workgroup
      • For Windows 8 go to My Computer  > HKEY_LOCAL_MACHINE > SOFTWARE > Beckman  > NexStep > Workgroup
    13. In the right pane, highlight the PWPEnabled line, select Edit > Modify, change the Value data: to 1, and then select OK.
    14. Highlight the PWPServerIp line, select Edit > Modify, change the Value data: to 134.217.96.181, and then select OK.
      If more than one DxI instrument will be connected to the LAS, use these IP addresses:
      • DxI 1 IP 134.217.96.181
      • DxI 2 IP 134.217.96.182
      • DxI 3 IP 134.217.96.183
      • DxI 4 IP 134.217.96.184
    15. Highlight the PWPTcpIpPort line, select Edit > Modify, change the Value data: to beca, and then select OK.
    16. Exit the Registry Editor and Network Connections windows.
    17. Configure the Privacy & Security firewall. See Configuring the Privacy and Security Firewall for the DxI Dynamic LAS Interface for more information.
    18. Press Windows key, type turn off, and select Settings > Power > Restart.
      Note: Reboot the PC for the changes to take effect.
      Note: When rebooting the Privacy & Security compliant Windows 8 or Windows 10 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

  4. Verify the IP addresses on the DxI PC console and install network cables.
    Caution: Verify that the DxI instrument consoles have the correct IP addresses before connecting the cables.

    For Windows XP System:

    1. Connect a network cable between the DxI console PC port (local area connection 3) and a port on the LAS that can communicate with the PrepLink PC.
      Note:
      • Refer to the PC Console, Connector Identification document to determine the location of the local area connection 3 port on the DxI PC.
      • If there are no available ports on the LAS, then install an extra hub. Contact Automation Technical Support for advice on installing an extra hub.
    2. Select Start > Run, type cmd, and then press the[Enter] key.
    3. Type ipconfig, and then press [Enter].
    4. Verify the IP address for ethernet adaptor local area connection 3 is 134.217.96.18x, where x = 1, 2, 3, or 4 corresponding to the DxI.
      When multiple DxI instruments are connected, each console PC must have a unique IP address on this port.
    5. Close the CMD window.

    For Windows 8 or 10 System:

    1. Connect a network cable between the DxI console PC port (local area connection 3) and a port on the LAS that can communicate with the PrepLink PC.
      Note:
      • Refer to the PC Console, Connector Identification document to determine the location of the local area connection 3 port on the DxI PC.
      • If there are no available ports on the LAS, then install an extra hub. Contact Automation Technical Support for advice on installing an extra hub.
    2. Press Windows key, open the Command Prompt icon or type command prompt and open the program.
    3. Type ipconfig, and then press [Enter].
    4. Verify the IP address for ethernet adaptor local area connection 3 is 134.217.96.18x, where x = 1, 2, 3, or 4 corresponding to the DxI.
      When multiple DxI instruments are connected, each console PC must have a unique IP address on this port.
    5. Close the CMD window.
  5. Resume the DxI sample processing.
    Warning: Performing the steps to resume LAS operation causes the DxI instrument to run LAS samples automatically.
    1. If the serial communication cable to the connection unit was disconnected, reconnect it.
    2. On the DxI Console, select Menu > Configure > LIS/LAS > LAS, and then select Online.
    3. Select OK.
  6. Resume the LAS sample tube loading.
    1. On the PrepLink Console, select Setup > Instrument Loading tab.
    2. Clear the CONN-X Loading Paused check box.
      The DxI instrument connection units are labeled CONN-1 through CONN-4, according to the number of DxI instruments connected to the LAS.
    3. Observe while the DxI instrument runs a minimum of ten samples from the LAS. Confirm that all tubes are processed correctly through the connection unit and that all samples are aspirated and run correctly by the DxI instrument.
      Note: If captive tubes were released from the connection unit, then errors will show in the event log, as expected for tubes that had processed beyond the query BCR before release.
  7. Repeat steps as required (pause loading, enabling, verifying, connecting, or activating) to enable the dynamic LAS operations for all additional DxI systems.
