DxI Fluidics: Calibrating Wash Buffer Supply Pressure Sensors

This procedure describes how to calibrate the pressure sensors in the Wash Buffer Supply Drawer.

Perform this calibration procedure when:

  • Installing an instrument.
  • Replacing the Cap/Tube Assembly with Pressure Sensor.
  • Installing, replacing, or upgrading the new Wash Buffer Supply Drawer.
  • The user interface Supplies screen does not match the field level of the container.

The new style or design Wash Buffer Supply Drawer uses pressure sensors to detect fluid level. This calibration procedure verifies the software can determine and display the correct amount of fluid in the containers.

The voltage guidelines are for all conditions of the Wash Buffer Supply Drawer.

Table 58: Pressure Sensor Voltage and Fluid Level Guidelines
Condition If the sensor is And the Wash Buffer Supply Container Then the approximate maximum DC voltage And the approximate Fluid Display Level %
1 disconnected absent ~5V Not Present -- %
2 connected absent 2.5V +/- 0.1V 0%
3 connected present but empty 2.5V +/- 0.1V 0%
4 connected present and full ~4.1V 100%

Caution: Wear proper PPE when performing this procedure. Handle the Cap/Tube Assemblies with care to avoid buffer contamination and damages to cap/tube components. Keep the Cap/Tube Assemblies facing downward to prevent wash buffer entering the sensor tubes and cause voltages to drift.

Note: In this procedure, a full:
  • Wash Buffer container is one that is unopened and full.
Note: In this procedure, an empty:
  • Wash Buffer container is one that is completely drained of Wash Buffer (no fluid).
Note: The Wash Buffer Sensor Calibration Screen has not been changed in Software 5.2 and above. Do not follow screen to calibrate the pressure sensors. Follow this procedure carefully to calibrate the pressure sensors.
  1. Select Diagnostics > Device Diagnostics > Analog Devices > Sensor Calibration > Wash Buffer.
  2. Gently pull the Wash Buffer Supply Drawer out.
  3. Gently remove both Cap/Tube Assemblies from the Wash Buffer containers and keep the Cap/tube Assemblies facing downward.
    Caution: Be careful not to break draw straw/tubes, stretch both sensors connection wires, or contaminate the tubes.
    Note: Gently cover the Cap/Tube Assemblies with clean absorbent pads if necessary.
  4. Remove the shims from the containers.
  5. Remove both containers from the Wash Buffer Supply Drawer.
  6. Select Done and then observe the DC voltages that are displayed.
    Note: Both Front and Rear containers voltages should read N/A. If there are voltages displayed, then check the pressure sensor connectors or sensor tubes before proceeding. Refer to Troubleshooting Wash Buffer Supply Pressure Sensors for more troubleshooting.
  7. Place the full Wash Buffer container in the front position and the empty container in the rear position.
  8. Slide the Shims onto the containers' necks.
  9. Gently screw in the Front Cap/Tube Assembly to the front full container and Rear Cap/Tube Assembly to rear empty container.
    Note: Ensure the Cap/Tube Assemblies are put in the containers in the correct order. Front assembly has black color coded sensor connector lock cap at the Bulk Fluid Tray Interface PCB cover or label near the cap contains the assembly part number and the assembly position "Front". Rear assembly has red color coded sensor connector lock cap at the Bulk Fluid Tray Interface PCB cover or label near the cap contains the assembly part number and the assembly position "Rear". Refer to Replace Wash Buffer Cap/Tube Assembly with Pressure Sensor procedure for more details.
  10. Select Done and then observe the DC voltages that are displayed.
    Note: Front container should read ~4.1V and Rear container should read 2.5 +/- 0.1V. SeeTable 1. Pressure Sensor Voltage and Fluid Level Guidelines for more details. If the rear or empty container does not read within 2.5 +/- 0.1V, then refer to Step 13m of Instrument: Performing Optimized PM procedure or DxI Fluidics: Troubleshooting Wash Buffer Supply Pressure Sensors procedure.
    Note: If voltage reads are opposite from each container, then check the sensor connectors on J3 (Front) and J5 (Rear) of the Bulk Fluid Tray Interface PCB for swapped connectors.
  11. Gently remove the Cap/Tube Assemblies from the containers and keep them facing downward.
  12. Do not remove the containers from the drawer and keep them in same positions (full in front and empty in rear).
  13. Gently screw in the Front Cap/Tube Assembly to the to rear empty container and Rear Cap/Tube Assembly to the front full container.
  14. Select Done and then observe the DC voltages that are displayed.
    Note: Front container should read 2.5V +/- 0.1V and Rear container should read ~4.1V. See Table 1. Pressure Sensor Voltage and Fluid Level Guidelines for more details. If the front or empty container does not read within 2.5 +/- 0.1V, then refer to Step 13m of Instrument: Performing Optimized PM procedure or DxI Fluidics: Troubleshooting Wash Buffer Supply Pressure Sensors procedure.
    Note: If voltage reads are opposite from each container, then check the sensor connectors on J3 (Front) and J5 (Rear) of the Bulk Fluid Tray Interface PCB for swapped connectors.
  15. Place the original Wash Buffer containers with the shims into the drawer.
  16. Gently screw in the Cap/Tube Assemblies to both containers.
    Note: Ensure the Cap/Tube Assemblies are put in the containers in the correct order. Front assembly has black color coded sensor connector lock cap at the Bulk Fluid Tray Interface PCB cover or label near the cap contains the assembly part number and the assembly position "Front". Rear assembly has red color coded sensor connector lock cap at the Bulk Fluid Tray Interface PCB cover or label near the cap contains the assembly part number and the assembly position "Rear". Refer to Replace Wash Buffer Cap/Tube Assembly with Pressure Sensor procedure for more details.
  17. Gently close the Wash Buffer Supply Drawer.
    Note: Ensure the Cap/Tube connectors are not pinched when closing the drawer.
  18. Exit the Calibration screen.
  19. Enter the Supplies screen and verify that the sensors are operating correctly.
    Note: If fluid levels are incorrectly displayed, repeat this procedure or refer to Troubleshooting Wash Buffer Supply Pressure Sensors for troubleshooting.
