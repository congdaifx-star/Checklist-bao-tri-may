Instrument: Shut Down and Restart Navigation

Purpose

This procedure describes how to shut down and restart the PC, the instrument, or both correctly.

When to Perform

Perform this procedure when it is necessary to shut down:
  • PC
  • Instrument
  • Both

Cautions and Notes

Caution:
  • Not following the correct shutdown procedure can damage the instrument or corrupt the system database.
  • When it is necessary to shut down the PC and the instrument at the same time, shut down the instrument first.
Note:
  • Restarting an instrument after shut down restarts the software and returns all instrument devices to their home positions.
  • When the PC is shut down and restarted, the instrument continues to process samples. The results are automatically sent to the PC after it re-establishes communications with the instrument.

Shutting Down the PC

There are two methods for shutting down the PC. Those methods involve using:
  • User interface software for standard shutdowns.
  • Computer keyboard (only when the user interface is not available).
If the computer keyboard is used to shut down the PC, the database may need to be cleaned. Contact your local support organization if this situation is encountered.

Shutdown Options

Determine which device or devices to shut down, then perform the navigation steps to shut down all or part of the system correctly.

To shut down Navigation Results or Notes
PC only From the Main Menu
  1. Select [F8] Configure
  2. Select [F7] PC Admin
  3. Select [F8] System Admin
  4. Select [F1] Shut Down PC. Do not select the Shutdown Instrument option.
  5. Select Yes at the Are you sure...pop-up.
  • The console application software (user interface) is terminated.
  • The Windows software shuts down and displays the Restart button.
  • Selecting the console Restart button reboots the console PC.
    Note: When rebooting the Privacy & Security compliant Windows 8 or Windows 10 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

  • The analyzer application software and the Windows software are unchanged.
DxI instrument PC only (using the keyboard)
  1. Simultaneously press the [Ctrl], [Alt], and [Delete] keys on the computer keyboard.
  2. Select Shutdown.
  3. Select one of the shutdown options.
  4. Select OK.
  • If the keyboard does not respond, shutdown the PC by turning off the power. Press and hold the power switch for a minimum of 10 seconds. Then wait a minimum of 20 seconds before restarting the PC.
    Note: When rebooting the Privacy & Security compliant Windows 8 or Windows 10 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

DxI instrument AU and PC From the Main Menu
  1. Select [F8] Configure.
  2. Select [F7] PC Admin
  3. Select [F8] System Admin
  4. Select [F2] Shut Down Instrument
  5. Enter Password and select OK.
  6. Wait for the instrument to shut down.
  7. Turn off the power switch.
  8. Select [F8] System Admin
  9. Select [F1] Shut Down PC. Do not select the check box.
  10. Select Yes at the Are you sure...pop-up.
  11. Wait until the Restart button is displayed, and then hold in the power switch until the power is off.
  • The console application software and Windows software are terminated
  • The AU application software and Windows software are terminated.
Note: When rebooting the Privacy & Security compliant Windows 8 or Windows 10 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

DxI instrument AU only From the Main Menu
  1. Select [F8] Configure
  2. Select [F7] PC Admin
  3. Select [F8] System Admin
  4. Select [F2] Shut Down Instrument
  5. Enter password and select OK.
  6. Wait for the instrument to shut down.
  7. Turn off the power switch.
  • The console application software and Windows software are unchanged.
  • The AU application software and Windows software are terminated.
