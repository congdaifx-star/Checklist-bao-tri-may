Installing a Windows 10 Console PC onto a DxI System

This procedure describes how to replace a failed Windows 10 console PC on a DxI system with a new Windows 10 console PC.
Note: If you are upgrading an instrument with Windows XP or Windows 8 to Windows 10, refer to Upgrading the DxI Instrument to Windows 10 from an Older Operating System.
Note: The hard drive of a Privacy & Security-compliant Windows 10 console PC cannot be replaced separately from the PC itself. The hard drive and motherboard are paired with a unique encryption key and will not function if separated.
Note: When restarting a Privacy & Security-compliant Windows 10 console PC, you must type the security password Access2Admin in the dialog to open Windows.
  1. Shut down the console PC
    The analytical unit (AU) CPU must be turned on. Do not shut down the AU CPU.
    If the DxI instrument is connected to an LAS, pause the connection unit to prevent LAS samples from loading during the repair process. See Servicing Instruments Connected to LAS for more information.
    • Go to Windows > Start > Shut down > Shut down and turn off the console PC, or
    • In the main menu of the console application go to F8 Configure > F7 PC Admin > F8 System Admin > F1 Shut Down PC > F1 OK.
    If Windows is not open, turn off the console PC. You might need to hold in the power button on the PC for several seconds to turn off the PC.
  2. Remove the old and install the new console PC
    See Console PC Connector Identification for more information.
    1. Disconnect the following cables from the old console PC, as applicable:
      • Power
      • Monitor
      • Hand-held bar code reader
      • Keyboard
      • Mouse
      • Touchscreen
      • LIS Serial connections
      • AU (LAN1) Ethernet
      • PROService (LAN2) Ethernet
      • Dynamic LAS (LAN3) Ethernet
      • Printer
      • Backup drive USB
    2. Connect the following cables to the new console PC, as applicable:
      • Power
      • Monitor
      • Hand-held bar code reader
      • Keyboard
      • Mouse
      • Touchscreen
      • LIS Serial connections
      • AU (LAN1) Ethernet
      • PROService (LAN2) Ethernet
      • Dynamic LAS (LAN3) Ethernet
      • Printer
      • Backup drive USB
  3. Use Remote Desktop to connect to the instrument CPU
    1. Press the Windows key and type remote to open Remote Desktop Connection. The Remote Desktop window will display the Windows 10 Desktop for the AU CPU.
    2. In the Computer box type 192.168.2.4 and select Connect.
      If prompted, type user for the username and tech for the password.
      At the RDS warning dialog, if prompted, select the Don't ask me again for connections to this computer checkbox and select Yes.
      For Windows 10, the default IP address for the console PC is 192.168.2.3 and the default IP address for the AU CPU is 192.168.2.4. The IP addresses will not change during the software installation process.
    3. Use the ALT + Tab keyboard shortcut to switch between the console PC Desktop and the AU CPU Desktop.
  4. Clear critical event notifications
    1. In Machine Control select Communications to open the Communications Diagnostics window.
    2. In the Communications Diagnostics window select Clear CE Storage. The question and warning Are you sure to delete all unsent critical messages? This might cause loss of data and database mismatch. will appear. Select Yes.
    3. Click OK to close the Communications Diagnostics window.
  5. Verify date and time settings match
    Before you install software, you must be sure the date, time, and time zones on both CPUs match. Otherwise, the system will fail to initialize and display the error Failed to synchronize clocks.
    • To change the settings on the console PC or the AU CPU, on the applicable Desktop right-click the date and time and select Adjust date and time to open the Time & language tab in the Settings window.
  6. Close the Desktop sharing connection
    1. On the AU CPU Desktop, right-click Remote Desktop Connection and select Close, or simply close the Remote Desktop Connection window.
    2. At the notification Your remote session will be disconnected, select OK.
  7. Install the software
    1. Insert the DxI software CD into the CD drive. The installation application will prompt you to select actions and confirm notifications.
      The software version that you install on the console PC must be the same as or newer than what is installed on the AU CPU.
      • If prompted to confirm the IP address for the AU CPU, type 192.168.2.4 and select Next.
      • If the IP address entered for the AU CPU does not match the actual IP address, or if the console PC is unable to communicate with the AU CPU, the software already has been installed.
      • If the installation application displays the error Unsent Data stored on the instrument, clear critical event notifications again.
      • If the installation application displays the notification and question Instrument version is the same. Do you wish to overwrite? select Yes.
    2. Select Yes or OK for all other messages during the installation.
      If the screen is blank for several minutes, use the Alt + Tab keyboard shortcut to display open applications and to find any hidden dialogs that you need to respond to.
    3. Select Yes, I want to restart my computer now and select Finish.
    4. After the PC restarts, at the notification There are no defined assays..., select Cancel.
    • If you are restoring from a backup, see Database - Restoring Console PC from Backupfor more information.
    • If you are not restoring from a backup, install eAPF by opening setup.exe from the prepared USB drive.
    WARNING! Do not initialize the instrument with Remap selected, which will corrupt the test counts of all on-board reagents and reset them to full.
  8. Configure the system
    1. Go to Configure > Tests. If the APF version displayed is not the current version, update the assay protocol files (APFs).
      Restoring from backup overwrites APF with the version that was in use when the backup was made.
    2. Configure the printer. See Installing LaserJet Printerfor more information.
    3. Calibrate the touchscreen. See Calibrating Touch Screen Monitorfor more information.
    • If the database was not useable copied or restored, enable tests, calibrate assays, and configure QCs.
  9. Enroll in PROService, if applicable
    See the Remote Solutions service manual for more information.
  10. Configure the LAS, if applicable
    1. Select Start, type control panel, and select Control Panel to open the Control Panel.
    2. Select System.
    3. In Computer name, domain and workgroup settings select Change Settings.
      The System Properties dialog will be displayed.
    4. In the System Properties dialog select Change.
    5. Type the DxI instrument serial number followed by PC (for example, 600010PC).
    6. Select OK.
      The notification You must restart your computer to apply these changes will be displayed.
    7. Select OK.
    8. In the Computer description box type the DxI instrument serial number followed by PC (for example, 600010PC).
    9. Select Apply.
    10. Select Close.
    11. Select Restart Later.
    12. Close the System screen.
    13. Select Start and type regedit or select Registry Editor and press Enter to open the Registry Editor window.
    14. In the Registry Editor window go to Computer > HKEY_LOCAL_MACHINE > SOFTWARE > WOW6432Node > Beckman > NexStep > Workgroup.
    15. Select PWPEnabled and go to Edit > Modify to open a dialog. In the Value data: box type 1. Select OK.
    16. Select PWPServerIp and go to Edit > Modify to open a dialog. In the Value data: box type 134.217.96.181. Select OK.
      If more than one DxI instrument will be connected to the LAS, use the following IP addresses for the instruments:
      Instrument IP Address
      DxI 1 134.217.96.181
      DxI 2 134.217.96.182
      DxI 3 134.217.96.183
      DxI 4 134.217.96.184
    17. Select PWPTcpIpPort and go to Edit > Modify to open a dialog. In the Value data: box type beca. Select OK.
    18. Close Registry Editor.
    19. Close Control Panel.
    20. Restart the console PC.
    21. Reconnect the RS-232 Serial cable between the DxI AU and the connection unit, if it was disconnected previously.
    22. Go to Configure > LIS/LAS > LAS > Online and select OK.
    23. Go to Diagnostics > LIS/LAS > LAS > Track Comm. Test. The notification COMM diagnostics test passed should be displayed. Close Diagnostics.
    24. On the connection unit keypad set the mode selector to Auto.
    25. On the PrepLink console clear Loading Paused for this connection unit. See Servicing Instruments Connected to LAS for more information.
    26. Observe several LAS samples as they pass through the connection unit to the DxI. Verify the samples aspirate and process on the DxI successfully.
  11. Verify system operation
    1. Process QC samples and verify the results are within customer specifications and that there are no issues posting results to the QC database.
      WARNING! Results flagged with IND or QC failure codes may indicate an incorrect reagent pack test count.
    2. Remove all cover interlock switch bypass devices and close all instrument covers.
