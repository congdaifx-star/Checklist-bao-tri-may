Changing Level 1 Voltage During Troubleshooting

Perform these steps to check and change the Level 1 Voltage. Only instruments with a Level 1 Voltage of 50 and a Pass, Fail, Pass, Fail pattern of calibration require changing the Level 1 voltage to 62.

  1. Verify that the last ultrasonics adjustment passed.
  2. Confirm that the system is in Ready mode.
  3. Open a connection between the console PC and the AU.

    For Windows XP:

    1. Press the [Windows] key, and then select Start  > Programs > Administrative Tools > Remote Desktop Connection to AU PC to start desktop sharing.

      The remote desktop connects to the instrument computer and allows remote control of the instrument and applications. When connected, the Remote Desktop window displays the Windows XP desktop of the instrument.

    2. To navigate the AU desktop:
      • Use the scroll bars on the right and bottom of the window.
      • Move down the scroll bar on the right to see the AU desktop toolbar,
      • The PC toolbar is at the bottom of the screen.
    3. To switch between the console PC display and the AU display:
      • To return to the console PC display, use the minimize button at the top of the AUSETUPPC screen.
      • To restore the AU Windows screen, select AUSETUPPC Remote Desktop Connection in the toolbar at the bottom of the console PC display.

    For Windows 8:

    1. Press the Windows key, type remote, and open the Remote Desktop Connection program.

      The remote desktop connects to the instrument computer and allows remote control of the instrument and applications. When connected, the Remote Desktop window displays the Windows 8 desktop of the instrument.

    2. Type in 192.168.2.4 into the Computer field and select Connect.
    3. Enter user for User Name and tech for the password if prompted.
    4. If prompted at the RDS warning screen, check the box for "Don't ask me again for connections to this computer" and select Yes.
      Note: For Windows 8, the default console IP address is 192.168.2.3 and the AU IP address is 192.168.2.4. Neither IP address changes during the software load process.
    5. To switch between the console PC display and the AU display:
      • To return to the console PC display, use the minimize button at the top of the AU Desktop screen.
      • To restore the AU Desktop screen, press the Windows key, type remote, and open the Remote Desktop Connection program.
  4. Check the Level 1 Voltage.

    For Windows XP AU with Software 5.2 and below:

    1. Select Start  > Programs > Windows Explorer > Local Disk (C:) > AU.
    2. Double-click on the Specific.ini file to open it.
    3. Select Edit > Find at the top of the page, and then enter Level Sense Voltage in the search field. Select Find Next to search the .ini file.
      Note: This search finds the level sense voltage for reagent pipettor 1.

    For Windows 8 AU with Software 5.3.1 and above:

    1. Navigate to Computer > Local Disk (C:) or AU_PC > AU.
    2. Double-click on the Specific.ini file to open it.
    3. Select Edit > Find at the top of the page, and then enter Level Sense Voltage in the search field. Select Find Next to search the .ini file.
      Note: This search finds the level sense voltage for reagent pipettor 1.
  5. Change the Level 1 Voltage, if necessary.
    1. For each pipettor, determine if a change to the voltage is necessary.
      If the level sense voltage is Then
      45 and the calibration adjustment proceeds with Pass, Fail, Pass, Fail alternating pattern This behavior is expected.
      1. Exit the ultrasonics adjustment with a passing calibration.
      2. Complete the ultrasonics voltage adjustment procedure.
        Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
      Note: A firmware bug on the ultrasonics PCB causes failed calibrations when the level 1 DACs are between 100 and 115 counts on every other calibration attempt. The failed calibration is considered a false failure and does not require a hardware replacement. For accounts at high elevation, the Level 1 voltage is set to 45. For more information, refer to the RP: Configuring Level 1 Ultrasonics Voltage for High Altitude Sites procedure.
      45 and the calibration adjustment fails often without a Pass, Fail, Pass, Fail alternating pattern Troubleshoot the circuitry.
      Note: Proceed to the Troubleshooting Calibration Adjustment and Sweep Failure table in the RP: Troubleshoot Ultrasonics procedure.
      Note: A firmware bug on the ultrasonics PCB causes failed calibrations when the level 1 DACs are between 100 and 115 counts on every other calibration attempt. The failed calibration is considered a false failure and does not require a hardware replacement. For accounts at high elevation, the Level 1 voltage is set to 45. For more information, refer to the RP: Configuring Level 1 Ultrasonics Voltage for High Altitude Sites procedure.
      50 Change the level sense voltage to 62 and continue to the next step in this procedure.
      62 The level 1 voltage is not the cause of failure. Proceed to the Troubleshooting Calibration Adjustment and Sweep Failure table in the RP: Troubleshoot Ultrasonics procedure.
  6. Save changes and exit.
    1. Select File > Save to save the changes.
    2. Exit out of the Specific.ini file.
    3. Exit and restart the AUObj.exe program.
    4. Exit out of Desktop Sharing.
  7. Calibrate reagent pipettor ultrasonic transducers.
    Note: If the Event Logs Initialization Failed During Phase 5 of Initialization and General Pump Failure, Reagent Pip #X on Initialization occur, use TestUltrasonic.exe to calibrate the pipettor.
    Note: Refer to the RP: Using TestUltrasonic.exe procedure.
    1. Calibrate all reagent pipettor ultrasonic transducers.
      Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
    2. If the calibration continues to fail, then troubleshoot the circuit.
      Note: Refer to the Troubleshooting Calibration Adjustment and Sweep Failure table in the RP: Troubleshoot Ultrasonics procedure.
