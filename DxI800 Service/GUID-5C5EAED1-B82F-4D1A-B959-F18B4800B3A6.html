Purpose

This document provides these details for the Bulk Fluid Tray PCB:
  • Drawings.
  • Details: Test Points, LEDs, Connector Overview, Connector Pin-outs.
  • Schematics.

Details

The Bulk Fluid Tray Interface PCB connects to these devices:
  • Lower Cabinet Interface PCB.
  • Front/Rear weight sensors.
  • Front/Rear selector valves.
