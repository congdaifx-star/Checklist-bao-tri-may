MCC / Ultrasonics Backplane PCB Operating Principles

Purpose

This document details the operating principles for the MCC / Ultrasonics Backplane PCB.

PCB Function

The MCC / Ultrasonics PCB provides a connection point for the eight MCC PCBs, two ultrasonics PCBs, and all the other devices that connect to it.

PCB Location

Note: The PCB location and function is the same for the DxI 600 and DxI 800 instruments.

Operational Overview

The PCB is an interconnect board that contains mostly connectors and fuses. Other include a few resistors, capacitors, and diodes.

Component Locations

Component locations are not provided for this PCB. Service personnel are advised not to change or repair this PCB unless directed to do so by the support group.

PCB Features and Functions

This PCB:
  • Contains many nonserviceable, resettable fuses
  • Contains a common 24-V DC line shared by all of the MCC PCBs and a separate 24-V DC line shared by ultrasonics PCBs.
  • Remains powered only if the main cover interlocks are closed. Opening the main cover doors removes power from this board, thus stopping motion of all devices.
  • Has separately fused 24-V DC connections for external PCBs that require 24-V DC power.
  • Contains heavy RF shielding provided by multiple trace layers on the PCB.
  • Is accessible from the back of the instrument when the upper rear access panel is removed.

Interacting Devices

The MCC/Ultrasonics backplane PCB interacts with:
  • All ultrasonic transducers
  • All motors
  • All Solenoids
  • All home, index, and trigger sensors.
  • Most other digital sensors
  • Communications PCB
  • Interlock switching from power distribution PCB
  • Power distribution PCB
  • Dual ultrasonics PCB
  • DxI 600: One PCB
  • DxI 800: Two PCBs
  • MCC PCBs
