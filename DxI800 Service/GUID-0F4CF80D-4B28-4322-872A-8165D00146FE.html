Config - CMOS Setup

Purpose

This document provides information for checking and setting the CMOS settings on the instrument CPU PCB.
  • The CPU board has two possible versions. The CPU boards can be distinguised by the color of the hard drive connector.
    • Black hard drive connector: Advantech CPU PCB.
    • Blue hard drive connector: Rocky CPU PCB.
  • For more information regarding the CPU boards, refer to the Drawing - PCB - CPU document.
Note: The CMOS settings for CPU boards with the Atom processor are pre-configured.

When to Perform

View and confirm the instrument CMOS settings if there is doubt about the correct CMOS settings.

Accessing CPU CMOS Setup

  1. Access the CMOS Setup screen.
    1. Connect an external mouse, keyboard, and monitor to the AU CPU (use the extender cables located behind the upper left card cage).
    2. Reboot the AU, and press [Delete] during boot-up.

If the settings were changed, then select [Esc] > [F10] to save and exit when finished. The boot-up process continues after exiting CMOS setup.
