Printing Test Page During Troubleshooting (HP 1200)

This procedure describes how to print a test page on an HP1200 Printer.

The configuration or test page provides:
  • all of the printer configuration settings.
  • verification that the scanner is attached.
  • a sample of the print quality.
  • information about the printer page counts.
  • a method for verifying that the printer is printing correctly.
Print a configuration page.
  1. Ensure that the printer is in the Ready state.
  2. Press and release the Go button on the printer control panel.
  3. Analyze the printed page for any issues.
