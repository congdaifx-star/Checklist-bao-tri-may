Troubleshooting Printing System

This procedure describes how to troubleshoot printing issues on the DxI system.

The troubleshooting steps are organized to confirm and correct the most easily identifiable causes first. Each step represents a general task. Links to service procedures containing additional details are provided where needed.
Note:
  • Asterisked (*) steps should be rechecked after correcting an identified problem, as the corrected error condition can send backlogged corrupt print jobs to other points in the report generation process.
  • If an obvious fault is identified and corrected, try to print again.
  • These steps can be performed with the user interface (UI) active, unless otherwise noted.
  1. Verify the printer can print a test page.
    Note: If the printer is an HP LaserJet 1200, then to print a test page.
    1. To print a test page using an Okidata B4300 or 4350 printer:
      1. Press the Menu button until the Info menu is displayed.
      2. Press the Select button to select the Info menu.
      3. Press the Item button until the Print Menu Map option is displayed.
      4. Press the Select button to print the menu map page.
      Note: For printer hardware troubleshooting information, refer to the Peripherals: Troubleshooting Okidata Printer procedure.
    2. To print a test page using an HP LaserJet 1200 printer, depress the green online button for five seconds.
      Note: Refer to the Peripherals: Printing Test Page DuringTroubleshooting (HP 1200) procedure.
    3. To print a test page using a Lexmark printer:
      1. Press the > button until the Utilities menu option appears in the display.
      2. Press the Check Mark button to select the Utilities menu.
      3. Press the > button until the Printing Menus Settings option appears.
      4. Press the Check Mark button to print the Menu page.
      Note: Refer to the Peripherals: Troubleshooting Lexmark Printer procedure.
  2. Verify the printer setup in Windows.

    For Windows XP console PC:

    1. Select Start > Settings > Printers, right-click on the LaserJet Printer or Lexmark Printer icon, and then select Set as Default Printer.
    2. Select Start > Settings > Printers, right-click on the LaserJet Printer or Lexmark Printer icon, and then select Properties. Verify the printer driver is HP LaserJet III, and then select Print Test Page.
      Note: To change the printer driver, refer to the Peripherals: Installing LaserJet Printer procedure.
    3. Select Start > Settings > Printers, right-click on each Printer icon, and then select Open. Cancel any in-process print jobs.
      Note:
      • To cancel a print job, left-click on the print job, and then right-click on the print job and select Cancel from the menu. Wait for the print job to be deleted.
      • A locked Crystal Report can block all subsequent reports from printing. Canceling the waiting print jobs can resolve the printing issue.
    4. *Check the task bar at the bottom of the screen for any crystal reports applications, and close them.
      Note: Pressing the Windows key brings the task bar to the front of the screen.
    5. *Check the task manager for crystal reports (running), nsprint (not responding), or HP printer (running). Highlight the process, and then select End task to shut down the process.
      Note: Press [Ctrl] + [Alt] + [Delete] to open the Windows security box. Select Task Manager > Applications. Also check the Processes tab.
    6. Reboot the PC using an approved shutdown process. A shutdown and restart may clear the printing problem.

    For Windows 8 console PC:

    Note: Okidata and HP Laserjet printers previously used by BEC are not compatible with Windows 8 and must be replaced with a Lexmark printer. The Windows 8 PC has an universal Lexmark printer driver installed.
    1. Press the Windows key and select the Devices and Printers icon or type Devices and Printers and open the program.
    2. Right click on the Lexmark Universal V2 XL printer and set it to default.
    3. Right click on the Lexmark Universal V2 XL printer and select Printer Properties.
    4. Select Advanced and verify the printer driver is Lexmark Universal V2 XL.
    5. Select General > Print Test Page.
      Note: To change the printer driver, refer to the Peripherals: Installing LaserJet Printer procedure.
    6. Right click on the Lexmark Universal V2 XL printer and select See What's printing.
    7. On the Lexmark Universal V2 XL printing pop-up box, select Printer > Cancel All Documents.
      Note: A locked Crystal Report can block all subsequent reports from printing. Canceling the waiting print jobs can resolve the printing issue.
    8. *Check the task bar at the bottom of the screen for any crystal reports applications, and close them.
      Note: Pressing the Windows key and select File Explorer to bring the task bar to the front of the screen.
    9. *Check the task manager for crystal reports (running), nsprint (not responding), or Lexmark printer (running). Highlight the process, and then select End task to shut down the process.
      Note: Press [Ctrl] + [Alt] + [Delete] to open the Windows security box. Select Task Manager > Processes.
    10. Reboot the PC.
      Note: When rebooting the Privacy & Security compliant Windows 8 or Windows 10 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

      Note: A shutdown and restart may clear the printing problem.
      • Press Windows key, type turn off and select Settings > Turn off your PC > Power > Restart.
  3. Verify the printer setup in the user interface.

    For Windows XP console PC with DxI Software 5.2 and below or Access2 Software 3.4.2 and below:

    1. Select Main Menu > Configure > System Setup > Reports Setup.
    2. Check the Report Header Information in the Reports Setup window and remove any " (double quotes) or / (forward slash) characters.
      Note: These two characters are known to lock-up the Crystal Reports process. There may be other nonstandard characters with similar effects. The characters corrupt all reports containing them. Cancel any corrupt reports still in the print queue.
    3. In the Reports Setup screen, select the LaserJet Printer (or the name of the printer) from the drop-down printer selection menu, and then press OK.
      Note: Reselect the printer, whether it is shown or not. Reselecting the printer guarantees that the registry entry for the printer selected in the user interface is correct.
    4. Print a report and a print-screen from the user interface.

      If the User Interface does not print successfully, then proceed to the next step to delete the spooled print files that may be locking-up the printing process.

    For Windows 8 Mini PC with DxI Software 5.3.1 and above or Access2 Software 3.4.3 and above:

    Note: DxI Software 5.3.1 and Access2 Software 3.4.3 are compatible with Windows XP console PC. If either software was installed on the Windows XP console PC, then follow the Windows XP section to verify the printer setup.
    1. Select Main Menu > Configure > System Setup > Reports Setup.
    2. Check the Report Header Information in the Reports Setup window and remove any " (double quotes) or / (forward slash) characters.
      Note: These two characters are known to lock-up the Crystal Reports process. There may be other nonstandard characters with similar effects. The characters corrupt all reports containing them. Cancel any corrupt reports still in the print queue.
    3. In the Reports Setup screen, select the Lexmark Universal V2 XL (or the name of the printer) from the drop-down printer selection menu, and then press OK.
      Note: Reselect the printer, whether it is shown or not. Reselecting the printer guarantees that the registry entry for the printer selected in the user interface is correct.
    4. Print a report and a print-screen from the user interface.

      If the User Interface does not print successfully, then proceed to the next step to delete the spooled print files that may be locking-up the printing process.

  4. Delete spooled print files, if the above procedures have not corrected the printing problem.
    Note: If the user has requested a large number of print jobs, then the Deleting Files step of this procedure can be used to delete them.
    1. If the user interface is open, press [Alt] + [F4] and enter the password Access2Support to close the user interface.
    2. Using Windows Explorer, navigate to the C:\NexGen\Console\Drw\Reports folder. Delete any HeaderFooter.txt, Flags.txt, or storeFlag.txt files.
      Note:
      • When printing a Continuous Sample Report, the print application accumulates flags from test results in a stored flags file until the report is ready for printing. Then it outputs all the flags onto the report during printing. After the print is done, the stored flags file is deleted.
      • A bad Flags or Store Flags file generates the error An attempt to access an unnamed file past its end.
    3. Navigate to the C:\NexGen\Console\DRW\Reports\Spool folder.
    4. In the spool folder, press [Ctrl] + [a] to select all files, and then press [Delete] to delete the files. At the Confirm multiple file delete message, select Yes.
      Note:
      • The spooled files all end in .txt or .csv.
      • Do not delete the Spool folder.
      • A hard drive that is too full can cause a problem spooling print files.
      • When deleting the spooled files, also delete the Flags.txt and the storeFlag.txt files.
      • Each spooled file can be linked to a BptPrintJob file in the database and when deleted create a harmless error and an Event Log message.
  5. Delete print files from the database, if the procedures have not corrected the printing problem, or if deleting the spooled files has created too many Internal error in print job processing Event Log messages.

    For Windows XP console PC with DxI Software 5.2 and below or Access2 Software 3.4.2 and below:

    1. If the user interface is open, then press [Alt] + [F4] and enter the password Access2Support to exit the user interface.
    2. Select Start > Programs > NexGen or Access2 > Poet Administrator or Poet Developer.
    3. In the POET Administrator or Developer, select File > Open Database. In the Hostname field, enter LOCALHOST. In the Database field, enter NexStepBase. Use correct capitalization (upper or lower case).
    4. In the POET Administrator or Developer, select Objects > Browse Extent.
    5. Select BPtPrintJob in the left window of the Extent Explorer.
      Note: A list of pending print jobs then displays on the right side.
    6. Right-click on any of the print jobs listed in the right window panel, and select Delete All BPtPrintJob > Flat from the menu to clear all pending print jobs from the database.
    7. Close the POET Administrator or Developer program. Open the user interface.
      Note: Rebooting the PC opens the user interface.
    8. Print a report and a print-screen from the user interface.
      Note:
      • The first attempt to print might generate a printing error in the Event Log.
      • If a Crystal Reports error appears in the Windows task bar at the bottom of the display, then right-click on the Crystal Report and select Close.

    For Windows 8 Mini PC with DxI Software 5.3.1 and above or Access2 Software 3.4.3 and above:

    Note: DxI Software 5.3.1 and Access2 Software 3.4.3 are compatible with Windows XP console PC. If either software was installed on the Windows XP console PC, then follow the Windows XP section to launch Fast database application. Poet database application is replaced by Fast database application.
    1. If the user interface is open, then press [Alt] + [F4] and enter the password Access2Support to exit the user interface.
    2. Press Windows key, select Fast Developer or Fast Administrator icon or type developer or administrator and open the program.
    3. In the Fast browser, select File > Open Database. In the Hostname field, enter LOCALHOST. In the Database field, enter NexStepBase. Use correct capitalization (upper or lower case).
    4. Select Objects > Browse Objects.
    5. Select BPtPrintJob in the left window of the Extent Explorer.
      Note: A list of pending print jobs then displays on the right side.
    6. Right-click on any of the print jobs listed in the right window panel, and select Delete All BPtPrintJob > Flat from the menu to clear all pending print jobs from the database.
    7. Close the Fast database application program. Open the user interface.
      Note: When rebooting the Privacy & Security compliant Windows 8 or Windows 10 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

      Note: Rebooting the PC opens the user interface.
    8. Print a report and a print-screen from the user interface.
      Note:
      • The first attempt to print might generate a printing error in the Event Log.
      • If a Crystal Reports error appears in the Windows task bar at the bottom of the display, then right-click on the Crystal Report and select Close.
