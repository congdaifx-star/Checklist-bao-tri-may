PCB - Interface - SPU

Purpose

This document provides these details for the SPU Interface PCB:
  • Drawings.
  • Details: Test Points, LEDs, Connector Overview, Connector Pin-outs.
  • Schematics.
  • Location

Drawings

Note: Previous configurations of this PCB, although very similar, do not contain connectors J16, J17 and J18.

Details

The SPU Interface PCB connects to these devices:
  • MCC Backplane / MCC0 PCB.
  • SPU motors and home sensors.
  • SPU User Interface PCB.
  • Sample rack bar code reader.
