Software V2.2.2 Release Notes

Purpose

This document provides details regarding the most significant features and enhancements included in DxI software version 2.2.2.

Confidentiality

Software release notes are confidential and should not be shared with customers.

Prerequisites

Prerequisites for updating or installing software version 2.2.2.

If updating from version Then
1.4 or lower Recalibrate all customer assays and run QC within customer limits.
1.4.1 or 1.4.2 Run QC on all customer assays within customer limits.
prior to 2.0 All open mandatory MODs must be completed. Calibrate Process Monitoring.
2.0 or 2.0.1 Install software, then calibrate substrate backdraw in the priming window.

MODs Obsoleted

Installation of this software version obsoleted these MODs.
  • Customer assigned sample tube MODs:
    • Mod 6618 - Sarstedt 5.5 mL SampleTubes.ini - Modify
    • Mod 6619 - 7.5 mL Sarstedt Monovette SampleTubes.ini - Modify
    • Mod 6655 - GTFR Aliquot SampleTubes.ini - Modify
  • Other MODs:
    • Mod 6574 - Software Version 2.1.1 - Install
    • Mod 6643 - Ultrasonics Level 1 DAQC Counts - Modify (to 45 Volts). MOD 6643 (obsolete, replaced by MOD 6768) is overwritten by installation of 2.2.2.

Hardware Changes Enabled

This software revision enabled these hardware changes.
  • A circuit board and sensor can be added for monitoring wash buffer delivery to the peri-pumps.
  • A two-port ethernet card can be added to the PC console to enable the Power Processor smart connection.

Enhancements

The most visible enhancements included in this software revision are:
  • The sample pick-an-place can clear upside down vessels from the supply shuttle. If an upside down SV is detected (it is taller), the SV is discarded without interrupting any runs. For an upside down RV or DV, the instrument pauses and during the next initialization discards the upside down vessel.
  • Added a QC Rerun button to the Test Results screen:
    • Select the QC test to rerun, and the test runs on the same pipettor and reagent pack to streamline troubleshooting.
    • If the pipettor or the reagent pack is not available, there is an event log message and the retest does not run.
  • The system initialization now performs three parameter checks:
    1. Verbosity:
      • If the settings differ from the default, then an event log message is posted.
      • Added a button on the PC Admin screen to reset the verbosities to factory default.
      • Verbosity is automatically reset when software is installed.
    2. Process monitoring:
      • If the settings differ from the default, then an event log message Some process monitoring features are disabled occurs each time the system is initialized.
      • Correct any process monitoring that is disabled by manually editing the specific.ini file on the AU.
    3. Read-only settings:
      • Are checked for the .ini files in the AU.
      • If a problem is detected, an event log message is generated.
      • Correct the read-only status manually.
  • The Sample Pipettor alignments window has a new button for moving the presentation tray in and out.
  • A Prime Wash Buffer check box was added to the priming screen. It is used during calibration of wash buffer monitoring.
  • A Copy to Disk button was added to the event log window. The user can select to copy trace files from a number of seconds before or after a specific event.
  • The user-defined tube parameters are retained when software is loaded.
  • Now the maintenance or diagnostic assays can be run while a pipettor is disabled.
  • Now the alignments for reagent pipettor, wash wheel, and RV supply shuttle are effective as soon as they are saved.

Event Log Enhancements

This software revision enabled these improvements to the Event Log messages.
  • Pick-and-Place
    • Pick-and-place (PnP) failures are identified with the PnP name.
    • PnP vessel sensor failure messages are improved.
    • Separated wash pick-and-place errors, vessel not present and vessel missing, into two events.
  • Analytical Module
    • Changed the Aspirate collar pressure above limit message to Aspirate Probe #1 pressure above limit during staged aspirate.
    • Aspirate probe collar wash vacuum error message has improved text and is informational for empty carousel holes.
    • Added dispense arm ejector plate error message to the event log.
    • Dark count error RLU values are now reported.
    • Added incubate wheel error details
  • General
    • Message details for over 40 sections of the event log were improved, giving as much information as possible.
    • To reduce nuisance events, the Connector Unit Paused event message is delayed 60 seconds.
    • Now the Rack ID is reported when no tube type is associated with a rack being loaded.
    • Added the tube ID to the Failure to aliquot from the track event.
    • Added tube ID to the Event Log details.

Other Changes

This section lists other changes to the software that are not as visible as those changes listed in the enhancements section.
  • Diagnostics and Alignments
    • Corrected sample pick-and-place semi-auto alignment Z height offset to the supply shuttle.
    • Aspirate probe plate semi-auto alignment for RV bottom now loads three vessels.
    • The SMC position for devices with encoders is shown in the alignment screen now.
    • Added compressor duty cycle to the Analog Devices window.
    • Now all diagnostics functions can be performed while a pipettor is disabled.
    • Now diagnostic "Copy to disk" is available before the end of the utility assay.
    • Reagent pipettors are not disabled by ultrasonic calibration failure until diagnostics is exited.
    • Extended the level sense test z-max limit from -1000 to -2000 steps.
    • Manufacturing cleanup now deletes the C:\AU\Log directory on the instrument and the startup link to auobj.bat.
    • Modified the commissioner routine to match manufacturing startup requirements.
    • Reagent pipettor air gap used in diagnostics changed to 15 µL to match the air gap used for level sense of samples.
    • Widened the substrate backdraw calibration range from 600 to 850 steps to 500 to 850 steps to accommodate the new probe design.
    • Added QC CSV fix errors to the DbTest.
  • Reports and Events
    • Added instrument ID to the test result record sent from the DxI to the LIS host (ASTM conformance).
    • Consolidated the trace files with data from ultrasonic, SMC (slippage), and RF level sense.
    • The printed temperature report now contains the duty cycle information.
    • Now operation messages are tracked on the AU and are enabled by default or disabled by setting "TrackOPHist=no" in specific.ini.
    • Log files on the AU are limited in size and duration to prevent long backups and tape drive problems. Log files are limited to 1 GB total on the AU.
    • Dump files are cleaned up during startup, leaving only the last 100 files or 150 MB of files in the directory.
    • Corrected missing AU trace statements.
  • Assays and Tubes
    • Added base-10 log, natural log, and exp to derived result formulas for Ferritin ratios.
    • Added Sarstedt Monovette sample tubes (75x15 mm 5.5 mL, 92x15 mm 7.5 mL).
    • Added Mayo VS2 sample tubes (GTFR Aliquot).
    • Added dose units SMU, SGU, SAU for Anti Beta2-Glycoprotein 1 assay.
    • Corrected the calibration expiration indicator for multi-assay packs.
    • Added support for surfactant-specific APF.
  • Hardware and Monitoring
    • Added pressure monitoring for wash buffer supply, when hardware is installed.
    • Dynamic connection to PrepLink for Power Processor can be enabled if Power Processor software is V3.5 or higher.
    • Wash tower external wash flow monitoring enabled, when hardware is installed.
    • Pick-and-place slippage is checked during system initialization to ensure proper RV clean out.
    • Changed the sample height step tolerance for level detect +/- 40 steps (100 µL) to +/- 30 steps (75 µL) to reduce false level sense.
    • Added a check for stranded RVs on the wash wheel.
    • Now mixer speed is checked only when the mixer is running to reduce the number of false error messages.
    • Reduced the slippage tolerance for the reagent shuttles from eight steps to five steps.
    • Disabling or enabling a pipettor no longer sets the AU status to Not Ready.
    • Now the reagent gripper is sent to home during a controlled shutdown, even if in Not Ready mode.
    • Now the reagent gripper is returned to the highway when there is an error while pipetting.
    • Now wash arms are homed during initialization to prevent jamming the mixer collets into the wash wheel.
    • Corrected issue where recovery from a specific SPU motion error could result in aliquoting from the wrong rack.
    • Corrected AU software crash caused by vessel handling error.
  • Substrate System
    • Now substrate pump backlash is checked during startup, priming, and the utility assay.
    • Moved substrate backlash limits into the subsystem.ini file.
    • Added substrate backlash warning zone with limits of 220 to 260 steps (information event) and >260 steps (warning event).
    • On-screen text for Substrate decontamination now specifies Citranox instead of Contrad.
  • User Interface
    • The date and time formats are retained (no longer reset to defaults) after a software load.
    • To prevent having a calibration stuck in the requested or in-progress states, the user is returned to the sample manager screen if making a calibration request when the assay is disabled or the reagent pack test count is insufficient.
    • To prevent stuck calibrator racks, loading a rack before exiting the rack ID entry field forces the cursor out of the entry box and enters the rack ID into the database.
    • Removed backup message box that prevented the backup from starting automatically.
    • Corrected the reflex condition (reflex to a test that can also reflex) that caused the ReduceUD.exe process to crash.
    • A SPU motor failure during initialization (like when the load cover is open) is no longer a critical event.
    • Opening the main cover while aliquoting no longer prevents the system from successfully reinitializing.
    • Resolved the "can't initialize" issue if a door is opened when the Barcode reader is scanning racks.
    • Updated translations in all five languages.
    • Reduced the incidence of Win 32 exceptions.
    • Code changes for this software release resulted from 277 SPRs.
