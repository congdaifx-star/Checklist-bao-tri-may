Ref - Sample Racks and Containers

Purpose

This document provides information for the sample racks and sample containers used on the DxI system.

Rack Label Overview

The figure in this section shows a rack and the four adhesive backed labels to be applied to it. All of these labels are shipped with new instruments. Refer to the Operator Guide for more information.
  • Rack ID Label
  • Rack Bar Code Label
  • Rack Container Type Label
  • No Reserve Volume Label

Rack Label Details

Label Type Notes
Rack ID The Rack ID label distinguishes one sample rack from another and identifies the accepted sample container type for each rack.
Warning: The Rack ID label and the Rack Bar Code Label must match (contain the same number).
Rack Bar Code Label Bar code label provides a unique identifier for each rack.
Container Type The container type labels are applied to the lower end of the rack to identify the type of container to insert into a rack.
No Reserve Volume This blue, yellow, and black label is applied to any sample rack that has been designated 'no reserve volume'. Refer to the 'Reserve Volume' document for more information. The label is applied directly above the container type labels. Refer to the reference diagram.

Racks

The sample rack that is used on the DxI has been used for several years on other Beckman Coulter products. These sample racks:
  • Are color-coded for easy identification.
  • Hold four sample containers.
  • Are marked with the size of container to be used in them.
  • Are not used in automation set ups (a tube holder is used instead).
  • Can have up to four different labels applied.
  • Can be placed directly into the SPU onload area.

Rack Holders

The DxI sample racks can stand vertically, but tip over easily, therefore two acrylic holding racks are supplied at each installation. More racks can be ordered from Beckman Coulter. Racks are available in 9.5-inch or 13.6-inch sizes. Refer to the parts list for part numbers.

Minimum Sample Volume

Use this formula to determine the minimum sample volume for any test:

Minimum sample volume = (Number of repetitions x Sample volume for that test) + (80 µL) + (Sample container dead volume).
Note: In this formula, the 80 µL is the dead volume of the sample vessel.

The 80 µL of dead volume used in the formula equals the 60 µL of dead volume plus 20 µL of overdraw. For larger volumes, additional volumes of 80 µL (SVDV + Overdraw) need to be added for every 500 µL of dispensed volume.

Example: To sample 1000 µL [(Number of repetitions x Sample volume) + (2 x 80 µL) + (Sample container dead volume)]. The reason is that after a 500-µL dispense, the instrument starts dispensing into a new sample vessel that requires another dead volume. At these larger volumes, the customer usually does not measure the sample volume. Instead, they fill the tube using a disposable pipettor.

Special Aliquot Caution

This section provides information regarding possible confusion over which type of Autoaliquot tube to use on the DxI.

Caution: The UniCel DxI and Access 2 documents refer to an autoaliquot tube that can be used on both systems. A similarly shaped tube, the microtube, is used on the Immage and the Synchron systems and can be confused with the autoaliquot tube. Both tubes fit into the 13x100 racks, but the false bottoms on the two tubes are at different levels. If the microtube is mistakenly used on the DxI or Access 2, then the dead volume is greater than with the Autoaliquot tube.
