Troubleshooting LAS Sampling

Purpose

This procedure provides information for troubleshooting LAS sampling problems and instructions for capturing RF noise data generated during sample aliquot from the LAS track.

When to Perform

Perform this procedure when there are QNS errors on LAS samples only.

Note: Refer to the SPU: Performing SPU RF Level Sense Test procedure.

Background

Excessive RF noise from the connection unit track has been found to interfere with DxI level-sensing on LAS track samples. When RF noise is excessive, it can cause intermittent Unexpected Sample Height or Insufficient Sample Volume errors at random reagent pipettors. The false (or premature) sample probe level sensing on LAS samples (no error event is triggered at the LAS) causes the volume problems reported at the reagent pipettors.

Non-RF noise issues that can cause random level sense failures:
  • Poorly prepared LAS patient samples (insufficient volumes, excessive bubbles, clots).
  • Incorrect connection unit R601, R602, and R504 register settings.
    Note: Refer to the LAS: DxI Connection Unit Operating Principles procedure for details.
  • Incorrect track position or z-alignment, possibly caused by using a wrong tube (or carrier) during alignment. Use an auto-aliquot tube to confirm the sample pipettor z-alignment to the track.
  • The current z-position when moved to the track z-position should be between -740 and -1020. Adjust the DxI height if the z-position is outside this range.

Troubleshoot LAS Sampling Problems

  1. Perform the LAS RF Level Sense Test.
    Note: Refer to the LAS: Performing LAS RF Level SenseTest procedure.
  2. Review the results from the LAS RF Level Sense Test to identify possible causes for failure.
    If the RF Level Sense Test shows: Then possible causes are:
    No failures

    (Dry and wet failure counts = 0, and wet test CVs <1.0%)

    BUT

    LAS patient samples cause QNS errors

    • Poorly prepared LAS patient samples (insufficient volumes, excessive bubbles, clots).
    • Incorrect connection unit R601, R602, and R504 register settings.
      Note: Refer to the LAS: DxI Connection Unit Operating Principles procedure for details.
    • Incorrect track position or z-alignment possibly caused by using the wrong tube (or carrier) during alignment. Confirm the sample pipettor z-alignment to the track using an auto-aliquot tube.
      Note: The z current position when moved to the track z position should be between -740 and -1020. Adjust the DxI height, if it is outside of this range.
    • Marginally excessive RF noise interference.
      Note: Refer to LAS: Capturing RF Noise Data During Troubleshooting.
    Dry failure counts >0

    OR

    Wet test CVs >1.0%

    • Missing or poorly connected LAS ground strap Mod 6277.
    • Loose ground screw on sample pipettor I/F PCB or RF level sense PCB.
    • Poor ground strap contacts on sample pipettor gantry (Mod 6385).
    • Incorrect x- or z-alignment to the track position (probe hitting the tube).
    • Excessive RF noise interference. Refer to the step "If excessive RF noise interference is suspected."
    Wet failure counts >0
    • Incorrect z-alignment to the track position (z-alignment set too high above target).
    • Wrong container type selected for LAS RF Level Sense Test.
    • Hardware failures in the sample pipettor module (RF level sense PCB, sample pipettor I/F PCB, probe, cables).
    • Excessive RF noise interference. Refer to the step "If excessive RF noise interference is suspected."
    Sample pipettor z-motion errors
    • Check the sample pipettor z-alignment to the track using an auto-aliquot tube.
      Note: An intermittent Motion error after sample dispense error can occur when the z-alignment is not between -740 and -1020. Use the DxI leveling feet to adjust the height.
      Note: Refer to the LAS: Installing DxI Instrument into LAS procedure for alignment details.
    • Hardware failures in the sample pipettor module (RF level sense PCB, sample pipettor I/F PCB, probe, cables)
    • Excessive RF noise interference. Refer to the step "If excessive RF noise interference is suspected."
  3. Use the LAS Data Capture Utility to capture several Add Tube Command messages and compare the tube-type codes to the tubes going to the DxI.
    Note: Refer to the LAS: Capturing RS-232 Communication Data During Troubleshooting procedure.

    Examples of Add Tube Commands:

    <STX>1<0x83>8828146990<US>1NNB7<ETX> (1 = 13x100 tube)

    <STX>1<0x83>8828146990<US>2NNB8<ETX> (2 = 13x75 tube)

    <STX>1<0x83>8828146990<US>5NNBA<ETX> (5 = auto-aliquot tube)

    The digit following the <US> character is the tube-type code. QNS errors usually result when a code 5 is sent but the tube is not an auto-aliquot tube.

    If codes are being sent that do not match the tube type, then an automation service engineer must change register settings in the connection unit.

    Refer to LAS: DxI Connection Unit Operating Principles for configuration guidance.

    Note: The DxI applies level sensing criteria for LAS samples determined by the tube-type code received in each Add Tube Command from the track. Incorrect register settings in the connection unit can cause the wrong codes to be sent, the DxI to apply inappropriate level sense criteria, and inappropriate QNS errors at the sample pipettor.
  4. If excessive RF noise interference is suspected, then:
    1. Verify that the LAS Ground Strap kit is installed correctly.
      Note: Refer to the Verify Ground Strap Installation step in the LAS: Attaching DxI to LAS Connection Unit procedure.
    2. Verify that all of the ground points shown in the MOD are making sufficient metal-to-metal contact.
    3. Check inside the connection unit for loose ground connections.
    4. Capture RF noise data to identify possible RF noise issues. Troubleshoot other possible causes before checking the RF noise.
      Note: Refer to the LAS: Capturing RF Noise Data During Troubleshooting procedure.
