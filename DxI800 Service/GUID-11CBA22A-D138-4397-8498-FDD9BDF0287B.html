DxI Software V7.2.0 Release Notes

This topic includes information about the most significant features and enhancements included in DxI software version 7.2.0.

Confidentiality

Software release notes are confidential and should not be shared with customers.

Feature Overview

Feature Description
Windows 10 compatibility System software 7.2.0 is the first version compatible with Windows 10.
Region Designation to assign the geographic location (at the country level) of the instrument

Preventative - The FSE will be able to assign the country where the instrument is installed.

Implement a two-point authentication

Preventative - The instrument will confirm that the correct APF set in a specific folder location on the console PC aligns with the instrument Region designated.

WIX Installer update Preventative - UniCel DxI System Software support for the Windows 10 Operating System
eAPF Tool (VAL# 3020.02) The eAPF tool will be updated to read the instrument region designation as part of the upload process to select which APF sets to upload. The eAPF tool is separate from the UniCel DxI System Software.
IFU Updates Manuals, Labeling and software string changes to support "Regional Designation" and new Software Version "UniCel DxI System Software Version 7.2.0".

Expected Behavior

Same as version 7.0.0.
