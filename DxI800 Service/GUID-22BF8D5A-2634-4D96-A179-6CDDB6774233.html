Installing Substrate Pump

This procedure describes how to install the substrate pump.

  1. Mount the pump to the support arm.
    • If the pump support arm remains in the instrument, mount the pump to the support arm.
    • If the pump support arm was removed from the instrument, mount the pump to the support arm and then install the support arm in the instrument.
  2. Install the substrate pump.
    1. Connect the cables to the substrate interface PCB located behind the substrate loader.
      • J13 - Substrate Valve
      • J16 - Substrate Pump Motor
      • J6 - Home Sensor
      • J12 - Substrate Heater
    2. Connect the thermistor cable to the temperature interface PCB at J4.
      Note:
      • If the pump was not removed from the instrument completely, then the cables can be connected.
      • If necessary, mount the substrate loader (four captive screws).
    3. Place the pump wiring into the cable clamps leading to the substrate interface PCB.
    4. Install these items onto the substrate pump:
      • Bubble detector clamp
      • Bubble detector cable to the pump bubble detector PCB
      • Substrate supply line
      • Substrate probe
      • Foam insulation
  3. Complete the pump installation.
    1. If the upper rear cover on the instrument was removed, replace it.
    2. If the power is off, restore power to the pump using the switch on the Power Distribution PCB labeled "All DC POWER (except CPU and reagent coolers)."
    3. If the instrument is in Not Ready mode, then initialize the instrument.
  4. Decontaminate the substrate pump.
    Note: Refer to the Fluidics: Decontaminating Substrate procedure.
  5. Prime the substrate pump.
    1. Prime the substrate five times with the Disable Process Monitoring option selected.
    2. Prime the substrate five cycles with the Calibrate Drawback option selected.
      Note: If there are substrate bubble detector errors, then perform the Fluidics: Adjusting Substrate Bubble Detector procedure.
  6. Remove any cover interlock bypass devices and close the covers.
  7. Initialize the instrument.
  8. Verify system operation.
    1. Perform system verification as stated in the Verification of Service Repair document .
      Refer to the Admin: Verification of Service Repair document.
