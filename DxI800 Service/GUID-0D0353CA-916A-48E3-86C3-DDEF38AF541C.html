PCB - MCC Backplane

This document provides these details for this PCB:
  • Drawings
  • Details: Test Points, LEDs, Connector Overview, Connector Pin-outs
  • Schematics
  • Location

Drawings

Note:
  • Connection points JP13 (SCTA), J13 (SCTA I/O), JP03 (SPARE), and J04 (SPARE I/O) were added to Configuration F.
  • The dual-carriage gantry (SCTA) and bulk feeder II (SPARE) use these new connections.

Details

The MCC Backplane PCB connects to these devices:
  • Interface PCBs
  • Ultrasonics PCBs
  • MCC PCBs
  • DAQC PCB
  • Card Cage Fans
Note: Connectors identified with J are signal connectors. Connectors identified with JP are power connectors.
