Connector Overview

This is the Connector Overview Table for the BF II Interface PCB.

Note: The Bulk Feeder Interface PCB connects to the MCC Backplane PCB. (MCC1)
# Connection Notes Connection Notes
J1 Cable, Interface, Ribbon, BF (P/N 116162) connects J1 to J11 on the MCC Backplane PCB. The 5V power/signal for all but one (see J4) sensor runs through this Ribbon Cable.
J2 The RV Pusher Motor Home Sensor This sensor indicates when the RV Pusher is retracted to the home position.
J3 The Emitter LED for the RV Hopper Reserve (Full) Sensor. Light from the Emitter LED crosses the Bulk Feeder Hopper to the Detector. The Hopper Reserve sensor is activated when an RV blocks the light.
J4 Cable, Ribbon, Secondary, BF Interface (P/N B29433) connects J4 to J04 (SPARE I/O) on the MCC Backplane PCB. The 5V RV Pusher Motor home signal runs through this Ribbon Cable.
J5 The detector for the RV Hopper Reserve (Full) Sensor. Light from the Emitter LED crosses the Bulk Feeder Hopper to the Detector. The Hopper Reserve sensor is activated when an RV blocks the light. This resets the RV supply count to 1000.
J6 The RV Dispense Cylinder Retracted Sensor. This is the Hall Effect magnetic sensor clamped to the front end of the Escapement (RV dispenser) Air Cylinder. It is active, LED on the sensor is On, when the air cylinder is retracted.
J7 The RV Dispense Cylinder Air Valve. The LED on the Air Valve is On when the Air Valve is activated. Valve activation should extend the air cylinder. Pressing the orange button on the air valve will manually activate it.
J8 USB Cable connects J8 (mini-USB end) to the CPU PCB (Standard USB end). Advantech & Rocky CPU boards will use the USB2 port. Atom CPU boards will use the USB4 port. Determine the USB port numbering configuration by referring to the "Drawing - PCB - CPU" procedure
J9 JTAG (Unused) No connector.
J10 RV Pusher Motor. 24 V Stepper motor drive signal for the RV Pusher.
J11 Bulk Feeder Elevator Motor Encoder. The Encoder checks every move to detect motor slip.
  • If slippage is detected it will retry the move once without a backwards move.
  • If slippage is still detected the motor will make 5 back and forth moves to free the possible jam.
J12 Deionizer power connection. Optional device for reducing static in the Bulk Feeder Hopper.
J13 The RV Hopper Motor Index Sensor. This sensor controls positioning of the RV feed chain scoops.
J14 Dispense Chute Status Sensor (reflective). Signals software when the Dispense Chute is full and when an RV moves past it. Directs the bulk feeder to start or stop feeding RVs into the Chute.
J15 The Bulk Feeder Elevator (Hopper) Motor. 24V Stepper motor drive signal for the Elevator.
J16 Harness, Bulk Feeder (P/N B26931) connects J16 to JP03 (SPARE) & JP11 (BULK FEEDER) on the MCC Backplane PCB. The 24V power and the Bulk Feeder Hopper Motor drive signals run through J16.
Note: The Backplane end of the Harness splits into two connectors (a 4-wire connector into JP03 and a 6-wire connector into JP11 of the Backplane).
