PCB - Power Distribution

Purpose

This document provides these details for the Power Distribution PCB:
  • Drawings
  • Details: Test Points, LEDs, Connector Overview, Connector Pin-outs
  • Schematics
  • Location

Drawings

Details

The Power Distribution PCB connects to these devices:
  • Power supplies
  • Interface PCBs
  • Sample Storage Module Peltier
  • Reagent Cooler Peltiers
  • CPU Power Distribution PCB
  • DAQC PCB
  • MCC Backplane PCB
  • Main Blower Fan
  • Cover Interlock switches
