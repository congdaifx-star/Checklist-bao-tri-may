LEDs - PCB - Interface - SPU

Note: It is possible for an indicator LED to be on while the sensor voltage is not sufficient to be recognized by software. Confirm sensor status in software and sensor voltage using a DVOM.
LED Color Function

D1

Green

Rack In Presentation Area.

Rack present: TP6 = 0V and D1 LED is on.

D2

Green

Off-Load Pusher Home.

Home: TP3 = 0V and D2 LED is On.

D3

Green

Presentation Tray Home.

Home: TP4 = 0V and D3 LED is on.

D4

Green

Off-Load Queue Full.

Rack present: TP5 = 0V and D4 LED is on.

D5

Green

Rack At Rail End Position.

Rack Present: TP7 = 0V and D5 LED is on.

D6

Green

Off-Load Area Full.

Rack present: TP9 = 0V and D6 LED is on.

D7

Green

Load Routine Button pressed D7 LED is On. (no test point)

D8

Green

Onload Pusher Home.

Home: TP8 = 0V and D8 LED is on.

D9

Green

Stat button pressed D9 LED is on (no test point).

D11

Green

SPU Load Cover Closed.

On-load cover closed: TP13 = 24V and D11 LED is on.

The switch provides power to relay K1 that enables the SPU on-load axis motor, K3 that enables the off-load axis motor, and K4 that enables the presentation tray motor.

D16

Green

Off-Load Cover Closed.

Off-load cover closed: TP14 = 24V and D16 LED is on.

The switch provides power to relay K2 that enables the off-load axis motor.
