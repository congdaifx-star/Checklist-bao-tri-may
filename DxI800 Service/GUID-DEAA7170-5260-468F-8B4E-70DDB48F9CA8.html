Aligning Pick-and-Place Module

Required Tools
The specialty tools required for this procedure are:
  • Green, vessel-shaped alignment tool
  • Pick-and-place auto alignment tool (optional)
  • Feeler gauge set (optional)
Note: If the green tool is left in the instrument during initialization, it is discarded into the solid waste bin.

Prerequisites

Complete these mechanical adjustments before setting the alignments in the software:
  • Pick-and-place gantry to wash carousel.
  • Pick-and-place z home position.
Overview

This procedure provides instructions for aligning the pick-and-place collets.

The available pick-and-place alignment positions are:
  • Wash pick-and-place to incubator wheel inner positions
  • Wash pick-and-place to incubator wheel outer positions
  • Wash pick-and-place to wash carousel position
  • Incubator pick-and-place to incubator wheel inner positions
  • Incubator pick-and-place to incubator wheel outer positions
  • Incubator pick-and-place to wash carousel position
  • Incubator pick-and-place to reagent carriage positions
  • Sample pick-and-place to sample wheel inner position
  • Sample pick-and-place to sample wheel outer position
  • Sample pick-and-place to supply carriage position
  • Sample pick-and-place to reagent carriage positions
The available pick-and-place semi-auto alignment positions are:
  • Incubator pick-and-place to waste tube position
  • Sample pick-and-place to the waste tube position

Perform the steps in the appropriate section to align the pick-and-place. The pick-and-place can be aligned using the manual alignment process, the auto alignment process, or the semi-auto alignment for the waste tube.

Warning: The photomultiplier tube (PMT) is a very sensitive photon measuring device. Any background or extraneous light coming into contact with a powered PMT can saturate the PMT and reduce the gain. This reduces the performance of the PMT, and it can take a long time for the PMT to recover or it might never recover fully. A magnetic field close to a powered PMT also reduces the performance of the PMT. The magnetic field causes the electrons to follow a curved path instead of moving in a straight line. When you are performing service in the area of the luminometer, observe the following rules.
  • Never shine a flashlight around the luminometer while the PMT is powered on.
  • Never bring a strong magnetic field close to the luminometer while the luminometer is powered on.
  • Before removing the covers on the analytical module, turn off the power to the PMT.
  • Cap the PMT whenever it is removed from the analytical module.
  1. Manual alignments—Place the green alignment tool in the alignment position.
    1. Open the instrument upper front covers and install a bypass device in each of the two cover interlock switches.
    2. From the Main Menu, selectDiagnostics > Device Diagnostics > Mechanics > Alignments.
    3. Select the Device to be aligned, and then select the alignment Position.
      Note: Refer to the list at the beginning of this procedure for the available alignment positions.
    4. Select Home Device > Move X/Y to Position.
      Note: The pick-and-place moves to the alignment location. Use this movement to identify where to place the alignment tool.
    5. Place the green, vessel-shaped alignment tool into the alignment position on the intersecting device below the pick-and-place.


  2. Manual alignments—Find the average X and Y alignment values for the pick-and-place.
    1. Disable the pick-and-place Z motor.
      1. Select Start > Programs > Administrative Tools > Remote Connection to AU.
      2. Open SMCtest.exe on the AU desktop.
      3. Select the pick-and-place Z motor from the device list in the SMC Test pop-up window.
        Note: Refer to the Tests: SMCTest Motor Channels document.
      4. In the SMC Test pop-up window, select Disable to disable the Z motor.
      Note: The fast motor entries are not used.
    2. Minimize the remote desktop connection and return to the Alignments window of the UI.
    3. With the z-motor disabled, manually roll the pick-and-place z-pulley down until the pick-and-place collet engages the RV by ¼ inch.
      Note: The pick-and-place Z motor can be disabled in the Alignments screen, but then stepping in the X/Y direction in the Alignments screen to set the alignment is also disabled.
    4. Roll the pick-and-place upward so that it picks up the vessel, and then push the vessel so that it drops into the carriage or wheel.
    5. Repeat the pickup operation, while stepping the pick-and-place device ( + ) one step in the X/Y direction for each pickup, until the pick-and-place no longer picks up the vessel.
      Note: The ± step range for pickup is typically ±7 steps from 0. If the maximum steps allowed in the UI are exceeded, then use SMCtest.exe to step the X/Y motor, or set MFGAlignmentsDone=No in specific.ini on the AU. Initialize the AU to enable the change.
    6. Repeat the up and down pickup process while stepping the pick-and-place device ( - ) in the X/Y direction until the pick-and-place no longer picks up the vessel.
    7. Set the alignment to the center of the ± pickup range, and then select Preserve Offsets > Save Alignment.
    8. Select the Selected Device option for the intersecting device, and then repeat the centering process to set the alignment for the intersecting device.
      Note: The alignment of the wash pick-and-place or incubator pick-and-place to the wash carousel is done with the carousel at the angular offset position and pinned into place. The pick-and-place gantry must be loosened and moved if the carousel rotational position does not align to the pick-and-place. Use the auto-alignment tool mounted to the pick-and-place as an alignment gauge for the mechanical adjustment of the gantry. Refer to the appropriate pick-and-place adjustment procedure for specific instructions.
    9. Set the alignment for the intersecting device to the center of the ± pickup range, and then select Preserve Offsets > Save Alignment.
  3. Manual alignments—manually set the Z alignment for the pick-and-place.
    1. Select Motors > Enable All > Home Device > Move Z to Position so that the pick-and-place goes down over the green alignment tool.
    2. Select Motors > Disable Z Motor.
    3. Manually move the pick-and-place upward and examine the position of the green tool in the pick-and-place fingers.
    4. Align the pick-and-place collet fingers with the BOTTOM of the white ring on the green RV alignment tool. At the sample pick-and-place to supply carriage, the alignment is to the TOP of the white ring.
    5. Manually move the pick-and-place down to its original location, and then select Enable All > Home Device > Move Z to position. Use the up and down arrows to adjust the Z height to the correct level.
    6. Repeat checking and adjusting the pick-and-place Z offset until the bottom of the gripper fingers align to the:
      • Bottom of the white ring on the green RV alignment tool.
      • Top of the white ring at the sample pick-and-place to supply carriage alignment.
      This table lists the pick-and-place height from the alignment surface using the green alignment tool, motor steps, or feeler gauge.

      Wash P&P to Wash Carousel 24 N/A

      Note:
      • The pick-and-place moves approximately 0.003 inch per motor step.
      • A stack of feeler gauges (0.022 + 0.023 + 0.025 + = 0.070) can also be used to check the Z alignment height on the incubator or sample wheels. The feeler gauge thickness for the top of the shuttles is 0.020 because of the recessed RV hole.

The Z alignment height for the sample pick-and-place varies between locations.
      • The same alignment number is saved for the inner and outer wheel Z alignments when either is changed.
    7. Select Home Device  > Preserve Offsets > Save Alignment.
  4. Auto Alignment—Use the Auto Alignment software to verify the pick-and-place alignments.
    1. Open the instrument upper front covers and install a bypass device in each of the two cover interlock switches.
    2. From the Main Menu, selectDiagnostics > Device Diagnostics > Mechanics > Alignments.
    3. Select the Device to be aligned, and then select the alignment Position.
    4. Select Home Device > Alignments & Offsets > Auto Align Selected.
    5. Mount the pick-and-place auto-alignment tool onto the pick-and-place collet.
      Note:
      • The two collet versions and two auto-alignment tool versions are not interchangeable. The original tool requires mounting the tool with the internal slots aligned with the fins on the ejector. Rotate the tool until the internal slots in the tool align with the fins on the ejector. If the tool is mounted incorrectly, the eject sensor indicates vessel present continuously. Ensure that the eject sensor indicator LED on the interface PCB goes off and on when the spring tip on the tool is pressed and released.
      • The auto-alignment software does not work with the linear slide version of the supply and reagent carriages. The auto-alignment tool can still be used to confirm the pick-and-place alignment to the new shuttles manually.
    6. At the Load the P&P tool into the P&P collet pop-up, select OK to begin the auto alignment.
      Note:
      • Auto alignment can be done with the module covers mounted, but the process is observed more easily with the covers removed.
      • One RV near the sample wheel inner alignment point must be removed for the alignment and then replaced.
      • Ensure that the tool goes into the RV hole at the end of the alignment process. Missing the hole causes the Z alignment to be 80 steps too high.
      • If an alignment fails because the offset is out-of-range and not because the tool misses the RV hole, then set MFGAlignmentsDone= No in specific.ini to allow additional range. Exit / launch the AU machine control program to enable the change and repeat the alignment.
        Caution: A jam during auto alignment can allow incorrect alignment values to be saved without warning, if MFGAlignmentsDone= No is set in specific.ini.
    7. When the semi-auto alignment is complete, select Save Offset & Exit.
    8. Leave the tool in position and at the Remove Tool message, select OK to continue aligning another device. Or, remove the tool and select OK to continue.
  5. Auto Alignment—Use the auto-alignment software to verify the pick-and-place alignments.
    1. With the auto-alignment tool removed, place the green alignment tool in the alignment location, and then select Home Device > Move Z to Position.
    2. Manually adjust the pick-and-place Z offset to align the bottom of the gripper fingers to the:
      • Bottom of the white ring on the green RV alignment tool.
      • Top of the white ring at the sample pick-and-place to supply carriage alignment.

      • For the wash and incubator pick-and-place, the Z Current Position (motor steps) at the Z alignment position are the same for all locations for each pick-and-place because the surfaces where the vessel is placed are all machined to the same height.       • The same alignment number is saved for the inner and outer wheel Z alignments when either is changed.
    3. When the alignment is complete, select Save Offset & Exit.
  6. Semi-auto align pick-and-place to waste tube—
    1. From the Main Menu, selectDiagnostics > Device Diagnostics > Mechanics > Alignments.
    2. Select Sample or Incubator P&P as the device, then select Waste Tube as the position.
    3. Select Alignments/Offsets > Semi - Auto Align Selected.
      Note: The pick-and-place automatically homes and then moves to the alignment position.
    4. Manually move the pick-and-place until the collet is centered over and is flush with the top of the waste tube.
      Note: Use a feeler gauge over the waste tube to find the top.
    5. Select OK.
      Note: The pick-and-place homes.
  7. Verify the pick-and-place alignments— Perform the appropriate vessel exerciser test to confirm pick-and-place operation.
  8. Verify system operation.
    1. Perform system verification as stated in the Verification of Service Repair document .
      Refer to the Admin: Verification of Service Repair document.
