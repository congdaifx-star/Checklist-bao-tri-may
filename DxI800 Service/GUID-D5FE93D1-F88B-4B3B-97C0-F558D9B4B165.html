Installing Dual-Gantry Sample Pipettor

This procedure describes which procedure to use to install a dual-gantry sample pipettor.

Perform this procedure when upgrading a DxI instrument to an integrated configuration or when installing a dual-gantry sample pipettor on an integrated system that was shipped without a sample pipettor.

Caution:
  • All DxI 600 instruments can be upgraded.
  • Only DxI 800 instruments with serial numbers 600781 and above can be upgraded.
Refer to this table for information on pre-installed instrument features based on the DxI serial number. Based on the pre-installed instrument features refer to the specific installation procedure.
DxI serial numbers Pre-installed instrument features Procedure

600781 to 601134 (DxI 800)

900025 and below (DxI 600)

None IP: Installing Dual-Gantry Sample Pipettor When Upgrading (no pre-installed features)

601135 to 601432 (DxI 800)

900026 to 900096 (DxI 600)

  • Three cables: USB encoder cable, ribbon cable, and power harness cable
IP: Installing Dual-Gantry Sample Pipettor When Upgrading (pre-installed cables)

601433 and above (DxI 800)

900097 and above (DxI 600)

  • Universal towers
  • Pneumatics tubing
  • Three cables: USB encoder cable, ribbon cable, and power harness cable
  • Second network port for integrated systems
IP: Installing Dual-Gantry Sample Pipettor When Upgrading (pre-installed towers)
If the instrument was ordered as an integrated system and a sample pipettor is not installed. N/A IP: Installing Dual-Gantry Sample Pipettor for Integrated System
