Configuring Console PC to Disable QC Mismatch Behavior

Pre-requisites: This configuration requires software version 4.4 or higher.

DxI software versions 4.3 and lower do not check the bar code labels on racks that are programmed with QC, allowing a misplaced patient tube in a QC rack to be run as QC rather than as patient.

Software versions 4.4 and higher correct this behavior by reading the bar code labels of programmed racks. If the bar code label disagrees with the programming, the event log displays this error message Sample IDs entered manually and read on the bar code do not match. No tests will be started.

This procedure describes how to set system software V4.4 to stop checking the bar code labels of programmed racks (similar to V4.3 and lower software).

  1. Configure the QC racks to run without checking the bar code labels.
    1. In the Main Menu screen, press [Alt] + [F4], and then enter the password Access2Support to exit the user interface.
      Note: The password is case-sensitive.
    2. SelectStart > Run. Type regedit. Select OK.
    3. Select the registry key.
      • In Windows 8 select HKEY_LOCAL_MACHINE > SOFTWARE > Beckman > NexStep > Console > System Setup.
      • In Windows 10 select HKEY_LOCAL_MACHINE > SOFTWARE > WOW6432Node > Beckman > NexStep > Console > System Setup.
    4. Right-click on DisableQCBarcodeMismatchFlagging, chooseedit, and change the value data from 0 to 1.
    5. Close the registry editor.
    6. Launch the user interface.
  2. Verify proper instrument operation.
    1. Program a QC rack through the Sample Manager.
    2. Pipette QC material into a non-QC bar code labeled tube and place the tube into a QC programmed rack position.
    3. Run the QC and verify all QC tests run.
