Software or APF Install Quick Reference

Purpose

This document provides information on where to find procedures for installing system software or APFs under a variety of circumstances.

When to Perform

Use this document to find software loading instructions for these circumstances:
  • Instrument installation
  • System software upgrades
  • After replacing the AU Hard Drive
  • After replacing the PC Hard Drive
  • Upgrading an Assay Protocol File (APF)

Documents

Situation Support Documentation
Initial software installation (normally performed only at instrument installation). Refer to the installation procedure in the UniCel DxI Service manual. Refer to the Installing DxI Instrument procedure.
System software upgrades (upgrading from a previous to new software version). Refer to the Access Systems Applications Database for the appropriate version of software.
Loading software after replacing AU hard drive. Refer to the AU hard drive replacement procedure in the UniCel DxI Service manual. Refer to the Electronics UL: Replacing Hard Drive on Analytical Unit procedure.
Loading software after replacing the PC Hard Drive. Refer to the Console PC or Console PC Hard Drive replacement procedure in the UniCel DxI Service Manual. Refer to the Peripherals: Replacing Console PC or PC Hard Drive procedure.
Loading an Assay Protocol File (APF). Refer to the Access Systems Applications Database for the appropriate APF version.
