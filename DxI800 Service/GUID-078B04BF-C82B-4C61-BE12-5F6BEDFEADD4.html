Drawing - PCB - Interface - Reagent Storage

Purpose

This document provides these details for the Reagent Storage Interface PCB:
  • Drawings.
  • Details: Test Points, LEDs, Connector Overview, Connector Pin-outs.
  • Schematics.
  • Location.

Drawings

Note: Remove jumper on J25 if present and connect the reagent load cover switch connector to J25.

Details

  • The Reagent Storage Interface PCB connects to these devices:
    • MCC Backplane PCB (MCC7).
    • Power Distribution PCB.
    • Reagent air temp thermistor.
    • Gripper and reagent load tray stepper motors.
    • Gripper motor position encoders.
    • Reagent and substrate bar code readers.
    • Gripper and waste door air valves.
