Sample Probe Carryover Test (Isolate Carryover)

This carryover troubleshooting procedure isolates the hot System Check samples to the sample probe. The reagent pipettors and substrate probe contact only wash buffer. Hot samples are held in the sample carousel in supply-wait by programming these samples as Cortisol tests and removing all Cortisol packs from the instrument. Cortisol is used because both AP25 and Cortisol have a 25-µL sample volume.

Note: This test is a separate troubleshooting-only procedure. The Sample Probe Carryover procedure is not a substitute for carryover verification following a PM, install, or new sample probe installation.
  1. Obtain a baseline and determine a pass/fail cutoff for the carryover test.
    1. Obtain a rack configured for 2-mL cups or 3-mL containers.
    2. Select Menu > Sample Manager  > New Request > Patient/QC Requests, and then enter the Rack ID.
    3. Select More Options > Request Service Assay, and then enter a Sample ID for cup 1 (example: 2031 for rack 203 position 1).
    4. Select OK.
    5. Select AP25 three times (three replicates).
    6. Pipette 500 µL of wash buffer into cup 1.
    7. Load the rack onto the SPU.
    8. Calculate the pass/fail cutoff from the baseline cup results:
      • All three replicates of the baseline cup must be <9000 RLU.
      • The median (middle value) of the three replicates = wash buffer baseline.
      • Pass/fail cutoff = wash buffer baseline + 17,500 RLU.
      Note: Baseline replicates >9000 RLU might indicate contaminated wash buffer.
  2. Program racks to detect sample probe carryover.
    1. If any on-board Cortisol packs are present, select Supplies > Reagent Supplies, and then unload the packs.
    2. Obtain sample racks for 2-mL cups or 3-mL containers.
      Note:
      • DxI 800: Eight racks
      • DxI 600: Four racks
    3. Select Sample Manager > New Request > Patient/QC Requests to start a new rack, and then repeat these steps until all racks are programmed.
      1. Enter the Rack ID.
      2. Enter a Sample ID for cups 1 and 3 (Example: Hot1 and Hot3).
      3. Request one replicate of Cortisol for cups 1 and 3.
        Note: The Cortisol test may need to be enabled. Select Menu > Configure > Tests
      4. Request three replicates of AP25 for cups 2 and 4. Select More Options > Request Service Assay. Enter a Sample ID (example: washbuff1), and then select OK. Select AP25 (test 910) three times.
      Note:
      • All cups in a rack are programmed to run on the same pipettor.
      • Each of the pipettors has two racks programmed to run on them.
      • All cups in the racks have unique sample IDs.
    4. Place cups in positions 1 and 3 (only) of each rack, and then pipette 300 µL of NEAT System Check (undiluted) into each cup.
      Note: To avoid contamination from dripping or splashing System Check, fill cups 1 and 3 before placing the cups in positions 2 and 4.
    5. Place the cups in positions 2 and 4 of each rack, and then pipette precisely 500 µL of Wash Buffer into all cups 2 and 4.
      Note: Wash Buffer volume is a critical variable. Use precise pipetting technique and new cups for repeat runs.
    6. Load the racks onto the SPU.
      Note: Ignore the yellow Supply Wait icon. Do not load Cortisol packs. The Supply Wait condition will be resolved with a system initialization and Clean-out All after the instrument completes the carryover run and returns to the Ready state.
  3. Print and evaluate the results of the sample probe carryover test.
    1. Select Sample Manager > Test Result > More Options > Configure Screen, and then select RLU for display.
    2. Select Filter and All Samples Loaded Between....
    3. Select a time range that includes the results, and then select OK.
    4. Highlight the results from all racks (including the baseline rack), and then select Print > Report.
    5. Select Test Results Report from the drop-down menu, select Current Selection, and then select OK.
    6. Analyze the results from the racks.

      The Sample Carryover Test passes if there are no wash buffer results (cups 2 and 4) that have an RLU greater than the pass / fail cutoff (baseline + 17500).

    7. If the test did not pass, troubleshoot for the carryover test.
      If Carryover Test and Sample Probe Carryover Test Then
      Fails Fails suspect sample probe carryover
      Fails Passes suspect substrate or reagent probe carryover
      Note: For specific troubleshooting information, refer to the Tests: Troubleshooting Carryover Test document.
  4. Initialize the instrument with Clean out all Sample Wheel Positions selected to discard the RVs held in the sample carousel. If the RVs in the sample carousel are not cleaned out, the samples are discarded after three hours.
  5. If any Cortisol packs were removed, reload the packs.
