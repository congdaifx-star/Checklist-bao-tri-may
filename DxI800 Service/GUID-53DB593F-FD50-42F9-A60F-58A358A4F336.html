Determining Percent Fluid During Troubleshooting

This procedure describes how to save the trace file information for substrate dispense events and search the trace file for percent fluid.

  1. Save the trace file information for substrate dispense events.
    1. Insert a USB memory device into the console.
    2. Select the Substrate Dispense message in the event log.
      Note: If there are a series of substrate dispense messages, then select the earliest message.
    3. Select Copy to Disk.
    4. Enter these values in the Copy to Disk screen:
      • Before Event (Sec): 30
      • After Event (Sec): 10
      • Path: Enter the drive where you want to save the file (example E: or C:)
      Note: The Include Details option is checked by default.
    5. Select OK.
    6. Repeat these steps for any additional errors to be evaluated.
  2. Open the saved trace files from disk on either the console PC or another PC.
    Note: If the PC asks which program to use to open the file, select Notepad.
  3. Search the trace file for percent fluid.
    1. Select Edit > Find.
    2. Search down for the substrate dispense exception:
      1. Type x00400010 in the Find What box.
      2. Select Find Next.
      Note: x00400010 is part of the event descriptor code for substrate dispense errors. The code is the fastest way to locate the error in the trace file.
    3. Search up for the percentage of fluid:
      1. Type percentage of fluid in the Find What box.
      2. Select the Up option for Direction.
      3. Select Find Next.
    4. Identify the percentage of fluid detected for the substrate dispense.

      i.e.

      1805089812, (4810), Substrate:T_Disp200uL id1209760, “Disp200” cleared DrawbackCompromi

      Bubble detector: latest air/fluid transition permitted is 152 samples in data

      Bubble detector: air/fluid edge NOT found

      Bubble detector: counted 0 fluid sample is 122 total samples

      Bubble detector: Percentage of fluid samples 0%

      1805089812 None. Substrate: T_Disp200uL REPORT: 1805089812

      1805089813 , Sequencer, 1805089812, Sequencer, CAUGHT EXCEPTION, 0x400010 from Subsystem

      Note:
      • The expected percent fluid for a normal substrate dispense is 100%.
      • On software V4.5 and below, a substrate dispense error is generated when the percent fluid is < 75%.
      • On software V4.6 and above or when Mod 11183 is completed, a substrate dispense error is generated when the percent fluid is <60%
      • Percent fluid errors of 0% can indicate an electrical signal issue from the Bubble Detect PCB to the Upper Left Card Cage.
