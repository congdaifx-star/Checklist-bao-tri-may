Aligning Sample Pipettor

This procedure describes how to align the sample pipettor to the wash tower, the inner and outer wheels of the sample storage modules, and the sample presentation unit (SPU) tray.

Required Materials:
  • Green, vessel-shaped alignment tool
  • Sample pipettor to SPU alignment and adjustment tool

Prerequisites:

All mechanical adjustments to the following devices must be completed before performing the software alignments in this procedure:
  • Sample pipettor
  • SPU

The sample pipettor interacts with the lab automation system (LAS), sample presentation unit (SPU), sample storage module, and the wash tower. The sample pipettor must aspirate from the containers presented by the SPU, dispense into a sample vessel in the sample storage wheel, and be cleaned in the wash tower.

The alignments for this module include:
  • align sample pipettor to LAS track position.
  • align sample pipettor to wash tower position.
  • align sample pipettor to sample storage module wheel inner position.
  • align sample pipettor to sample storage module wheel outer position.
  • align sample pipettor to SPU position.
Note: Changes to alignment offsets are written to file:
  • when the alignments are saved while exiting the Alignment screen.
  • by selecting Alignments / Offsets > Save Alignments.
  1. From the Main Menu, select Diagnostics  > Device Diagnostics > Mechanics  > Alignments.
  2. Align sample pipettor y-position to SPU position.
    1. Select Sample Pipettor as the device, and then select SPU Presentation Tray as the position.
    2. Select Alignments / Offsets  > Semi-Auto Alignment.
      The instrument homes both devices and moves the tray to the tray-out position.
    3. Place the insert-cup tool into position 4 of a 13x75-mm sample rack.
    4. Open the SPU cover, load the rack into the center of the on-load area, and close the cover.
    5. Select OK.
      The instrument moves the rack into the pipetting position, moves the pipettor to a location that is a safe distance above the alignment tool, and disables the pipettor motors.
    6. Manually place the pipettor probe tip onto the recessed surface of the tool at the center of the cross hair.
    7. Select OK.
      The instrument homes the pipettor, and moves the tray to the tray-out position.
    8. Select OK.
      Do not remove the tray as instructed by the pop-up screen, the tray is required when performing the z-alignment. The instrument homes both devices.
  3. Align sample pipettor z-position to SPU position (manual alignment).
    Caution: Perform the sample pipettor y-position to SPU tray alignment before the sample pipettor z-position to SPU tray alignment.
    1. Select Home Device > Move Z to Position.
    2. Using the directional keys, step the pipettor z-position up or down until the probe is barely touching the top of the tool (no vertical movement of alignment tool).
    3. Select Alignments / Offsets > Preserve Offsets.
    4. SelectHome Device > Move Z to Position, then check the alignment.
    5. Adjust if necessary, then save by selecting Alignments / Offsets > Save Alignments.
      Caution: If an adjustment is made before saving the alignment, the alignment must be preserved again.
    6. Select Home Device.
    7. Select Tray In / Out, and remove the alignment tool and the rack.
    8. Close the cover, and select Tray In / Out to home the SPU tray.
  4. From the Main Menu, select Diagnostics  > Device Diagnostics > Mechanics  > Alignments.
  5. Align sample pipettor y-position to wash tower position.
    1. Select Sample Pipettor as the device, and then select Wash Tower Y as the position.
    2. Select Alignments / Offsets  > Semi-Auto Alignment.
      The instrument homes the pipettor, moves the pipettor to a location that is a safe distance above the wash tower, and disables the pipettor motors.
    3. Manually place the pipettor probe tip directly over the center of the wash tower hole.
    4. Select OK.
      The instrument homes the pipettor.
  6. Align sample pipettor z-position to wash tower position (manual alignment).
    Caution: Perform the sample pipettor y-position to wash tower alignment before the sample pipettor z-position to wash tower alignment.
    1. Select Sample Pipettor as the device, then select Wash Tower Z as the position.
    2. Select Home Device > Move Z to Position > Motors > Disable X/Y Motor.
    3. Carefully move the pipettor carriage rearward using the y-belt pulley at the front of the pipettor.
    4. Determine whether the wash tower nozzle is the new style or old style of nozzle.
      Wash tower nozzle (old style) Wash tower nozzle (new style)
      • Old style - If the wash tower nozzle is the old style of nozzle, determine whether there is clearance between the probe tip and the recessed flat surface of the wash tower.
      • New style - If the wash tower nozzle is the new style of nozzle, determine whether there is clearance between the probe tip and the top of the inner ring directly adjacent to the hole.
    5. Complete the following steps depending on whether there is clearance.
      • If there is clearance:
        1. Select Motors > Enable X/Y Motor > Home Device > Move Z to Position.
        2. Step the alignment down one step.
        3. Select Alignments / Offsets > Preserve Offsets.
        4. Select Home Device > Move Z to Position > Motors > Disable X/Y Motor.
        5. Carefully move the pipettor carriage rearward using the y-belt pulley at the front of the pipettor.
        6. Go back to the main step and determine if there is clearance between the probe tip and the recessed flat surface of the wash tower. Follow the steps for if there is clearance or if there is no clearance.
      • If there is no clearance:
        1. Select Motors > Enable X/Y Motor > Home Device > Move Z to Position.
        2. Step the alignment up one step.
        3. Select Alignments / Offsets > Preserve Offsets.
        4. Select Home Device > Move Z to Position > Motors > Disable X/Y Motor.
        5. Carefully move the pipettor carriage rearward using the y-belt pulley at the front of the pipettor.
        6. Determine if there still is no clearance between the probe tip and the recessed flat surface of the wash tower.
          • If there still is no clearance, then repeat the steps for "If there is no clearance:" until an offset change of one step causes the probe tip to barely clear the recessed flat surface of the wash tower.
          • If there is clearance, then proceed to the next step.
        7. Select Motors > Enable X/Y Motor > Home Device  > Move Z to Position.
        8. Select Alignments / Offsets > Save Alignments.
  7. From the Main Menu, select Diagnostics  > Device Diagnostics > Mechanics  > Alignments.
  8. Align sample pipettor y-position to sample wheel inner position.
    1. Select Sample Pipettor as the device, and then select Sample Wheel Inner as the position.
    2. Select Alignments / Offsets  > Semi-Auto Alignment
      There is a prompt to remove any vessel in the alignment position.
    3. Select OK.
      The instrument homes the pipettor, and moves the sample wheel to the load tool position.
    4. Place the green vessel-shaped tool into the inner hole marked with two dots, and select OK.
      The instrument homes both devices, moves the sample wheel to the alignment location, moves the sample pipettor to a location that is a safe distance above the alignment tool, and disables both motors.
    5. Manually moving the sample pipettor and the sample wheel, place the pipettor probe tip onto the surface of the tool at the center of the crosshair.
      The sample pipettor tip does not fit into the recessed area on the top of the tool; the metal outer sheath contacts the top surface of the tool.
    6. Select OK.
      The instrument homes both devices.
  9. Align sample pipettor z-position to sample wheel outer position (manual alignment).
    Caution: Perform the sample pipettor y-position to the sample wheel outer position alignment before the sample pipettor z-position to the sample wheel outer position alignment.
    1. Select Sample Pipettor as the device, and then select Sample Wheel Outer as the position.
    2. Select Home Device > Move Z to Position.
    3. Using the directional keys, step the pipettor z-position up or down until the probe is barely touching the top of the tool (no vertical movement of alignment tool).
    4. Select Alignments / Offsets > Preserve Offsets.
    5. Select Home Device > Move Z to Position, then check the alignment.
    6. Adjust if necessary, then save by selecting Alignments / Offsets > Save Alignments.
      Caution: If an adjustment is made before saving the alignment, the alignment must be preserved again.
    7. Select Home Device.
  10. Complete alignments.
    • If this instrument is connected to a LAS, align the sample pipettor to the LAS track position.
      Note: Refer to the LAS: Aligning Sample Pipettor to LAS Track procedure.
    • If this instrument is not connected to LAS:
      1. Verify that all alignment tools are removed from the instrument.
      2. Exit the Alignments screen.
      3. At the pop-up Do you want to home all moved devices?, select Yes.
      4. At the pop-up Do you want to save the alignments?, select Yes.
      5. Initialize the instrument.
