Deleting UDRs

This procedure describes how to delete UDRs.

Pre-requisites: The system should be in Standby mode.

It is recommended that you follow this procedure IN THE ORDER THAT IT IS WRITTEN to ensure the necessary printouts are collected and to prevent problems.

  1. Print Current Calibration for each UDR.
    1. Select Rgts/Cal from the menu bar.
    2. Select the UDR chem position(s) to print.
    3. Select Options.
    4. Select <10> Print Current Cal Report, or enter 10 in the Option No. field and press [Enter].
    5. Select <1> Current Cal Report, or enter 1 in the Option No. field.
  2. Print Calibration Rack Assignments for each UDR
    1. Select Rgts/Cal from the menu bar.
    2. Select Assign.
    3. Select a <Next> or <Prev> to locate each UDR calibrator. OR Select the Calibrator Name options button at the top of the Assign Barcode/Rack dialog box to view the List of Calibrators.
    4. Print each UDR calibrator rack assignment using the Print Screen key on the LX keyboard.
  3. Print Chemistry Panels for each UDR
  4. Delete UDR chemistries from Chemistry Panels
    1. Select Setup from the menu bar.
    2. Select <6> Panels, or enter 6 in the Option No. field and press [Enter].
    3. Print the Panels Summary information using the Print Screen key on the LX keyboard
    4. Edit the Panels to remove the UDR chemistries
      1. Enter the number(s) of the panels that contain UDR chemistries in the Number(s) field or select the panel number. Multiple entries can be selected by separating with commas or a range can be selected by separating with a hyphen.
      2. Select Define. All chemistries defined in the chemistry panel will be indicated by the highlighted number next to each chemistry.
      3. Remove the individual UDR chemistries by selecting the number next to each chemistry.
      4. Select Main from the menu bar to exit and save the changes.
  5. Print Reference/Critical Ranges for each UDR
  6. Delete UDR chemistries from Reference/Critical Ranges
    1. Select Setup from the menu bar.
    2. Select <10> Reference/Critical Ranges, or enter 10 in the Option No. field and press [Enter].
    3. Enter the number(s) of the UDR chemistries in the Chem Number(s) field or select the chemistry number. Multiple entries can be selected by separating with commas or a range can be selected by separating with a hyphen.
    4. Select <Ranges Summary>.
    5. Print the Ranges Summary information using the Print Screen key on the LX keyboard and then select <OK> to exit.
    6. Clear the Reference/Critical Ranges.
      1. Enter the number(s) of the UDR chemistries in the Chem Number(s) field or select the chemistry number. Multiple entries can be selected by separating with commas or a range can be selected by separating with a hyphen.
      2. Select <Clear Ranges>.
      3. When asked Clear All Ranges for Selected Chems?, select <OK>.
      4. Select <Cancel> to exit.
  7. Print Special Calculations for each UDR
  8. Delete UDR chemistries from Special Calculations
    1. Select Setup from the menu bar.
    2. Select <12> Special Calculations, or enter 12 in the Option No. field and press [Enter].
    3. Enter the special calculation number that contains UDR chemistries in the Calculation No. field or select the calculation number.
    4. Select View.
    5. Print the Special Calculation information using the Print Screen key on the LX keyboard, and then select <Cancel> to exit.
    6. Delete the Special Calculation.
      1. Enter the special calculation number to delete in the Calculation No. field or select the calculation number
      2. Select Delete.
      3. Select <OK> to delete calculation.
  9. Print UDR Chemistry Parameter Information (Do not delete the UDR)
    1. Select Setup from the menu bar.
    2. Select <15> User-Defined Chemistries OR Enter 15 in the Option Number field and press [Enter].
    3. Press the Print Screen key on the LX keyboard. This will provide a printout of the User-Defined Chemistries and their defined locations. Repeat to print page 2, if necessary.
    4. Select a User-Defined Chemistry position number.
    5. Select Define.
    6. Press the Print Screen key on the LX keyboard to print page 1 of the Define/Edit User-Defined Chemistry screen. Repeat to print pages 2 and 3.
    7. Select Done to return to the User-Defined Chemistries screen.
    8. Repeat steps 4 to 7 for each User-Defined Chemistry.
  10. Remove UDR from Reagent/Calibration (Example: UIBX)
    Note:
    • The Calibration, Sample Programming, Control (QC) and Reference/Critical Range Information needs to be CLEARED out from the instrument before the Chemistry can be de-configured.
    • It is recommended that you follow these sections IN THE ORDER that they are written to prevent problems with deleting chemistries from the QC definition. Control samples in the Sample Required, Incomplete or Rerun status may prevent the removal of the chemistry from the QC definition.
    1. Select Rgts/Cal from the menu bar.
    2. Ensure the cal status of the chemistry UIBX is not Requested. To cancel a calibration request,
      1. Select the position for the appropriate requested and assigned chemistry to be canceled.
      2. Select No Cal to cancel calibration request.
        Note: Chemistries currently selected may be canceled only if the calibration is not yet in progress
    3. Remove calibrator assignments. To clear calibrator barcode ID and/or rack and position:
      1. Select Assign.
      2. Select <Next> or <Prev> to locate the calibrator of interest OR Select the Calibrator Name option button at the top of the Assign Barcode/Rack dialog box to view the List of Calibrators.
      3. Clear the fields by selecting the Calibrator ID, Rack and Position fields for each level of calibrator and using the Delete button on the keyboard.
      4. Select <Close> to exit and save information.
    4. Remove the reagent cartridge. To remove the reagent cartridge UIBX:
      1. Select the position for the chemistry to be removed.
      2. Select Load.
      3. If prompted by the instrument to remove the reagent cartridge, open the reagent carousel door to remove the cartridge. The reagent cartridge may be scanned off if it has a barcode or select Clear to remove reagent data.
      4. Close the reagent carousel door.
  11. Delete UDR from Sample Programming (Example: UIBX)
    Note: All Samples in the Sample Required, Incomplete and Rerun status needs to be CLEARED before the chemistry can be de-configured. Samples in the In Progress or Removed status should be allowed to proceed to Complete or Incomplete status.
    1. Request sample load lists for (1) Sample Required, (2) Incomplete and (3) Rerun.
    2. Select Samples from the menu bar.
    3. Select List.
    4. Select the options button next to the Status field at the bottom of the Load List dialog box to view the List of Sample Status.
    5. Select 1 for a list of samples in the Sample Required status.
    6. Select <Display> to display the Load List on the screen. The Load List may then be printed using the Print key OR Select <Print> to print the Load List without viewing on the screen.
    7. Repeat Steps 2 to 5 in this section to request the load lists for samples in the Incomplete and Rerun status.
      Note: Select 4 for a list of samples in the Incomplete status. Select 5 for a list of samples in the Rerun status.
    8. Look for the chemistry to be de-configured, UIBX, in each load list and clear these samples. Refer to the LX20 Operations Manual, Clearing Samples section for information on how to clear sample programming.
  12. Print Quality Control (QC) Definition for UDR Chemistry
    1. Select QC from the menu bar.
    2. From the QC screen, select a control number.
    3. Select Review.
    4. Press the Print Screen key on the LX keyboard to print each page of QC definition containing UDR control information.
    5. Repeat these steps for each QC definition for each UDR Chemistry.
  13. Archive Quality Control (QC) to Floppy Disk
    Note: QC should be archived to an external media before deletion from the instrument hard drive.
    1. Select QC from the menu bar.
    2. Select Archive.
    3. Select <1> Archive to Disk, or enter 1 in the Option No. field.
    4. At the prompt, enter an operator ID of 1 to 3 alphanumeric characters.
    5. Insert a diskette into the floppy disk drive of the LX computer.
    6. At the LX monitor, select <OK>. The disk will be formatted by erasure, then the QC data will be archived to it.
      Note: When archiving is complete, a prompt will ask the operator if QC data should be deleted from the hard disk.
    7. Select <Cancel> to exit without deleting QC data from hard disk.
  14. Remove UDR from the Quality Control (QC) Definition (Example: UIBX)
    • If a control is defined solely for that chemistry and is no longer needed, the entire control definition should be deleted.
      1. Select QC from the menu bar.
      2. Select the control containing UIBX to be cleared.
      3. Select Delete.
      4. The following message displays to confirm the clearing of the selected control: All QC files for the control will be deleted. Archiving is suggested. Delete this control? Select <OK> to delete the control.
      5. If the control was deleted, enter an operator ID of 1 to 3 alphanumeric characters and press [Enter] or [Tab].
    • If the control definition contains the chemistry along with other chemistries that should not be deleted, a single chemistry definition can be deleted.
      1. Select QC from the menu bar.
      2. From the QC screen, select a control number.
      3. Select Define.
      4. Select Chems. A list of configured chemistries will be displayed. Remove the chemistry UIBX by deselecting the number next to the chemistry name. Use the <Page Up> and <Page Down> buttons to access all chemistries. Select <OK> to leave the selection screen and save the changes.
      5. The following message displays to confirm the clearing of the selected chemistries from the control: QC data and statistics for this chemistry files will be deleted. Archiving is suggested. Deselect this chemistry? Select <OK> to remove the chemistry from this control.
  15. Delete UDR Chemistries (Example: UIBX)
    1. Select Setup from the menu bar.
    2. Select <15> User-Defined Chemistries OR Enter 15 in the Option Number field and press [Enter].
    3. Select the User-Defined Chemistry position number (the number next to UIBX).
    4. Select Delete.
    5. Repeat the above steps to delete all User-Defined Chemistries.
  16. De-Configure a UDR Chemistry (Example: UIBX)
    1. Select Setup from the menu bar.
    2. Select <2> Chem Config/Sample Type OR Enter 2 in the Option Number field and press [Enter].
    3. Select Configured chemistry position number.
    4. Select Delete.
    5. Repeat the above steps to de-configure all User-Defined Chemistries.
