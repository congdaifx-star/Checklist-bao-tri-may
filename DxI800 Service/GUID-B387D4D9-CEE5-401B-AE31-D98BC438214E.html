Configuring the Privacy and Security Firewall for the DxI Dynamic LAS Interface

This procedure describes how to configure the firewall on a Privacy & Security-compliant PC for the DxI dynamic LAS interface feature with the power processor lab automation system.
Note: This procedure for configuring the firewall only applies to Privacy & Security-compliant versions of console PC in Windows 8 and Windows 10.
Verify the following prerequisites before completing this procedure:
  • Identify the IP address for the Cennexus PC, Preplink PC, Remisol, or Firewall device (when connecting to a virtual Remisol on the Lab network)
    Device Default IP Address
    Cennexus / Preplink PC In the 134.217.96.### subnet
    Firewall In the 192.168.150.### subnet
  • Confirm that the DxI console has a network connector available for LAS or a console pre-configured with multiple network connectors.
  • Verify PrepLink V3.5 software or newer has been installed and configured.
  • Confirm the lab automation group has prepared the LAS to run with the DxI Dynamic Interface.
  1. On the keyboard, press the Windows key, type control panel, and select Control Panel to open the Control Panel window.
  2. In the Control Panel window, select Windows Firewall to open the Windows Firewall window.
  3. In the Windows Firewall window, select Advanced settings to open the Windows Firewall with Advanced Security window.
    1. In the Windows Firewall with Advanced Security window, select Inbound Rules to view the list of Inbound Rules.
    2. In the Inbound Rules list, right-click Integrated and select Properties to open the Integrated Properties window.
    3. In the Integrated Properties window, select the Scope tab to view the Scope properties.
    4. In Scope properties, in the Remote IP address area, select These IP addresses.
    5. Select the IP addresses displayed in the box.
    6. Select Edit to open the IP Address window.
    7. In the IP Address window, select This IP address range.
    8. In the From box, enter the IP address that represents the low end of the IP address range for the Cennexus PC, Instrument Manager PC, or firewall device (when connecting to virtual Remisol on the Lab network).
    9. In the To box, enter the IP address that represents the high end of the IP address range.
    10. Select OK to close the IP Address window.
      Note: If the customer is using multiple subnets, select Add and repeat steps g through j to add the new values.
    11. In the Integrated Properties window, select Apply and select OK.
  4. Repeat step 3 for
    1. Track in Inbound Rules
    2. Integrated in Outbound Rules
    3. Track in Outbound Rules
    Note: In Step 3, when you configure Track, the Integrated Properties window will be named Track Properties.
  5. Start LAS sample loading to the DxI to confirm the samples route as expected.
