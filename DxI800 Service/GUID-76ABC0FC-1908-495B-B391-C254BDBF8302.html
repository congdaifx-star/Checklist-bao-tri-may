Configuring Pick and Place Gantries X-Motors Run Current to Operate at 2.0 Amps

This procedure describes how to configure the Pick and Place x-motor run current to operate at 2.0 amps.

Perform this procedure after
  • installing or upgrading to linear slide Pick and Place gantries.
  • installing, reloading, or upgrading software.
For the following action... Refer to...
Use the PnP Software Application to configure the Pick and Place gantries x-motors run current. Step 1
Manually configure the Pick and Place gantries x-motors run current if software application is not available or not working properly. Step 2
Verify all the SMC.ini files on the AU side to ensure all Pick and Place gantries x-motors run currents were successfully configured. Step 3
  1. Use the PnP Software Application to configure the Pick and Place gantries x-motors run current to 2.0 amps.
    1. Download the application zip file and extract the root folder of a flash USB drive.
      PnP Software Application - Zip File
      Note: Check to ensure the software files are extracted properly and the root folder contains all the files needed. After extraction, you will find an executable file named C65237.exe and a folder called "Pick and Place Change" at the root of the flash USB drive.

    2. Insert the flash USB drive to Console PC.
    3. Navigate to the flash drive and open the software application folder and run C65237.exe application.
    4. Check the status of the instrument under Instrument section of the C65237.exe user interface.
      Note:

      • The software is communicating with the instrument IP address of 192.168.2.4 only. If there is proper communication between the Console PC and the instrument, the user interface will display the instrument type and serial number of the instrument. Then proceed to the next step.
      • If there is no communication between the Console PC and the instrument, then refer to Troubleshooting AU and UI Communication Loss procedure.
    5. Click Configure button in the Incubate, Sample and Wash PnP Run Current Configuration group box to configure x-motor current on the Pick and Place gantries to run at 2.0 amps.
      Caution: Only perform the Incubate, Sample and Wash PnP Run Current Configuration section. Do not perform any of the other configurations.

      Note: If the Configuration status shows
      • "Fully Configured at 2.0 Amps", then the configuration has completed successfully and proceed to the next substep.

      • "Error: Unable to copy \\Pick and Place Change\DxI800_SMC.ini to \\192.168.2.4\C$\AU\DxI800_SMC.ini" pop up box, then

        • Recheck to root folder to ensure all the files are located at the root of the flash USB drive.

        • Rerun the software application.
        • If software application still fails to complete the configuration, then perform step 2.
    6. Exit the software application.
    7. Open a Remote Desktop Connection to the AU.
    8. Exit AUobject Y icon on the task bar. Task Manager can also be used to terminate the AUobject or AUModule program.
    9. Relaunch the AUobject Y icon.
    10. Proceed to step 3 to verify the SMC.ini files.
  2. (Perform this step only if PnP Software Application is not available or not working properly.) If the run currents were NOT updated in Step 1, follow the steps below to manually configure the Pick and Place x-motor run current to 2.0 amps. If the run currents were updated in Step 1, then proceed to Step 3.
    1. Modify SMC.ini files on the AU side in the following folders.
      C:\AU folder.
      • SMC.ini
      • DxI800_SMC.ini
      • DxI600_SMC.ini
      C:\AU\Defaults folder
      • SMC.ini
        Note: SMC.ini may not be present in the C:\AU and C:\AU\Defaults folders if AUObject hasn’t been launched before with the in-use AU hard drive. If SMC.ini isn’t present in those folders, the PnP x motor run currents only need to be updated in the DxI800_SMC.ini and DxI600_SMC.ini files.
      Caution: Change the X motor run currents for the pick and places only.
      1. Open a Remote Desktop Connection to the AU.
      2. Exit AUObject Y icon on the task bar. Task Manager can also be used to terminate the AUModule program.
      3. Modify the SMC.ini files in the AU folder.
        1. Press the Windows key, select File Explorer or Windows Explorer and navigate to C:\AU folder.
        2. Open AU folder and locate SMC.ini file.
        3. Right click on the SMC.ini file and select Properties.
        4. Uncheck the "Read Only" check box on the General tab to make the SMC.ini file unprotected and editable.

        5. Select Apply and then select Ok.
        6. Open the SMC.ini file with Notepad.
        7. In Notepad, select Edit then Find (or press CTRL + F), enter "samplepnp", and select Find Next.
        8. Change the Sample Pick and Place X motor run current from 1.5 to 2.0 on both .XMotor and .XMotor.Fast sections.

        9. In Notepad, select Edit then Find (or press CTRL + F), enter "incubatepnp", and select Find Next.
        10. Change the Incubator Pick and Place X motor run current from 1.7 to 2.0 on both .XMotor and .XMotor.Fast sections.

        11. In Notepad, select Edit then Find (or press CTRL + F), enter "washpnp", and select Find Next.
        12. Change the Wash Pick and Place X motor run current from 1.7 to 2.0 on both .XMotor and .XMotor.Fast sections.

        13. In Notepad, select File > Save and close the file.
        14. Right click on the SMC.ini file and select Properties.
        15. Check the "Read Only" check box on the General tab to make the SMC.ini file protected and not editable.
        16. Select Apply and then select OK.
        17. Repeat step iii to modify the DxI800_SMC.ini and DxI600_SMC.ini files in the AU folder.
      4. Modify the SMC.ini file in the Defaults folder.
        1. Navigate to C:\AU\Defaults folder.
        2. Locate the SMC.ini file in the Defaults folder.
        3. Right click on the SMC.ini file and select Properties.
        4. Uncheck the "Read Only" check box on the General tab to make the SMC.ini file unprotected and editable.

        5. Select Apply and then select Ok.
        6. Open the SMC.ini file with Notepad.
        7. In Notepad, select Edit then Find (or press CTRL + F), enter "samplepnp", and select Find Next.
        8. Change the Sample Pick and Place X motor run current from 1.5 to 2.0 on both .XMotor and .XMotor.Fast sections.

        9. In Notepad, select Edit then Find (or press CTRL + F), enter "incubatepnp", and select Find Next.
        10. Change the Incubator Pick and Place X motor run current from 1.7 to 2.0 on both .XMotor and .XMotor.Fast sections.

        11. In Notepad, select Edit then Find (or press CTRL + F), enter "washpnp", and select Find Next.
        12. Change the Wash Pick and Place X motor run current from 1.7 to 2.0 on both .XMotor and .XMotor.Fast sections.

        13. In Notepad, select File > Save and close the file.
        14. Right click on the SMC.ini file and select Properties.
        15. Check the "Read Only" check box on the General tab to make the SMC.ini file protected and not editable.
        16. Select Apply and then select OK.
      5. Relaunch the AUObject program.
  3. Verify all the SMC.ini files on the AU side to ensure all Pick and Place gantries x-motors were successfully configured at 2.0 amps.
    Note: If the x-motor currents are incorrect or unchanged, re-run the software or manually re-modify the currents.
    1. Verify all SMC.ini files on the AU side in the following folders.
      C:\AU folder.
      • SMC.ini
      • DxI800_SMC.ini
      • DxI600_SMC.ini
      C:\AU\Defaults folder
      • SMC.ini
      1. Open a Remote Desktop Connection to the AU.
      2. Verify the SMC.ini files in the AU folder.
        1. Press the Windows key, select File Explorer or Windows Explorer and navigate to C:\AU folder.
        2. Open AU folder and locate SMC.ini file.
        3. Open the SMC.ini file with Notepad.
        4. In Notepad, select Edit then Find (or press CTRL + F), enter "samplepnp", and select Find Next.
        5. Verify the Sample Pick and Place X motor run current is set to 2.0 on both .XMotor and .XMotor.Fast sections.

        6. In Notepad, select Edit then Find (or press CTRL + F), enter "incubatepnp", and select Find Next.
        7. Verify the Incubator Pick and Place X motor run current is set to 2.0 on both .XMotor and .XMotor.Fast sections.

        8. In Notepad, select Edit then Find (or press CTRL + F), enter "washpnp", and select Find Next.
        9. Verify the Wash Pick and Place X motor run current is set to 2.0 on both .XMotor and .XMotor.Fast sections.

        10. In Notepad, select File > Exit to close the file.
        11. Repeat step ii to verify the DxI800_SMC.ini and DxI600_SMC.ini files in the AU folder.
      3. Verify the SMC.ini file in the Defaults folder.
        1. Navigate to C:\AU\Defaults folder.
        2. Locate the SMC.ini file in the Defaults folder.
        3. Open the SMC.ini file with Notepad.
        4. In Notepad, select Edit then Find (or press CTRL + F), enter "samplepnp", and select Find Next.
        5. Verify the Sample Pick and Place X motor run current is set to 2.0 on both .XMotor and .XMotor.Fast sections.

        6. In Notepad, select Edit then Find (or press CTRL + F), enter "incubatepnp", and select Find Next.
        7. Verify the Incubator Pick and Place X motor run current is set to 2.0 on both .XMotor and .XMotor.Fast sections.

        8. In Notepad, select Edit then Find (or press CTRL + F), enter "washpnp", and select Find Next.
        9. Verify the Wash Pick and Place X motor run current is set to 2.0 on both .XMotor and .XMotor.Fast sections.

        10. In Notepad, select File > Exit to close the file.
