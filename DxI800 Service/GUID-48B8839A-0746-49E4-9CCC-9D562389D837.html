PCB - Pick-and-Place Single-Head Sensor

This document provides these details for the Pick-and-Place Single-Head Sensor PCB:
  • Drawings.
  • Details: Test Points, LEDs, Connector Overview, Connector Pin-outs.
  • Schematics.
  • Location

Drawing

Details

The Single-Head Sensor PCB is used with the:
  • Incubator Pick-and-Place.
  • Wash Pick-and-Place.

Test Points: There are no test points provided on this PCB.

LEDs: There are no LEDs on this PCB.

Conn. Overview:
# Connection Notes Function / Signals

J1

The SINGLE HALL EFFECT SENSOR PCB connects to J8 on the Pick-and-Place Interface PCB through the service loop cable (CABLE, RIBBON).

The wires exit the 6 pin service loop connector from the side that faces upward when connected to J8 on the interface PCB. The service loop connector is also keyed for polarity.

Note: The wash and incubator service loop cables are different lengths.
J1:
  • The 5V power and the ejector sensor signals run through JP1.
  • The service loop cable connects JP1 to J8 on the Pick-and-Place Interface PCB.
