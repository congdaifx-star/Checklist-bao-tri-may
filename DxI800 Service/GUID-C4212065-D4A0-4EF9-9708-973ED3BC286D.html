Repairing Windows Login

To correct an issue where the PC requests password entry when powered on, perform these steps to repair the Auto Admin Login feature of the console PC.

  1. Repairing Windows Login for Windows XP.
    1. Enter the current Windows password (tech) to launch Windows.
      Note:
      • The password should be tech but the operator could have changed the password. In order to change the password, the current password must be known. Reimage the PC or replace the PC hard drive to recover from an unknown password.
      • The tech password configuration also applies to the AU, with the additional symptom of desktop sharing failing to login.
    2. Select Start > Run and type control userpasswords2 on the open text line.
    3. Un-check mark the Users must enter a user name and password check box, then select OK.
    4. Reboot the PC.
    5. If the PC continues to request a password at boot-up, then selectStart > Settings  > Control Panel > User Accounts.
    6. Select user, and then selectChange my password.
    7. Type tech for the new password, then tech as the confirmed new password, and then select Change password.
    8. Reboot the PC.
    9. If the PC continues to request a password at boot-up, then select Start > Run  > Regedit.
    10. Browse to HKEY_LOCAL_MACHINE > SOFTWARE > Microsoft > Windows NT > CurrentVersion > WinLogin in the registry editor.
    11. Right-click on AutoAdminLogin, select Modify, and then change the value from 0 to 1.
    12. Ensure that the DefaultPassword string value is tech. If the DefaultPassword does not exist, then right-click in the editor window, create a new string, name the string DefaultPassword, and set the value to tech.
  2. Repairing Windows Logon for Windows 8.
    1. Enter the current Windows password (tech) to launch Windows.
      Note:
      • The password should be tech but the operator could have changed the password. In order to change the password, the current password must be known. Replace the PC or replace the PC hard drive to recover from an unknown password.
      • The tech password configuration also applies to the AU, with the additional symptom of desktop sharing failing to login.
    2. Press Windows key, type run and open the program.
      Note: If the run box does not appear, recommend exiting the user interface and reopen the run program.
    3. Type in control userpasswords2 on the open text line and click OK or hit Enter.
    4. Un-check mark the Users must enter a user name and password check box, then select Apply.
    5. Type in User name: user, Password: tech, Confirm Password: tech, and click OK to save.
    6. Click OK to exit.
    7. Reboot the PC.
      Note: When rebooting the Privacy & Security compliant Windows 8 or Windows 10 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

    8. If the PC continues to request a password at boot-up, then press Windows key, type run and open the run program.
    9. Type in Regedit on the open text line and click OK or hit Enter.
    10. Browse to HKEY_LOCAL_MACHINE > SOFTWARE > Microsoft > Windows NT > CurrentVersion > WinLogon in the registry editor.
    11. Right-click on AutoAdminLogon, select Modify, and then change the value from 0 to 1.
    12. Ensure that the DefaultPassword string value is tech. If the DefaultPassword does not exist, then right-click in the editor window, create a new string, name the string DefaultPassword, and set the value to tech.
