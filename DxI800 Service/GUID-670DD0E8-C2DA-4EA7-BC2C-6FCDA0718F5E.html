Using PC Diagnostic CD During Troubleshooting

This procedure describes how to use the PC Diagnostic CD to confirm PC function.

Use the PC Diagnostic CD to confirm PC function when a hardware problem is suspected. The automatic test takes approximately three minutes.
Note: If a PC hard drive software issue is suspected, refer to the Peripherals: Reimaging Console PC Hard Drive procedure.
The Diagnostic CD checks these areas of the console PC:
  • Serial ports
  • Parallel or printer port
  • USB ports
  • Hard drive
  • Floppy drive
  • CD ROM drive
  • Tape drive
  • CPU
  • RAM memory
Boot the PC using the Diagnostic CD.
  1. Insert the Diagnostics CD into the CD ROM drive on the console PC.
  2. On the Windows desktop, select Start > Shutdown > Restart to reboot the PC, or cycle the PC power off and on so that the PC reboots.
    • If the diagnostic CD boots the PC, then proceed to the Diagnostics Tests.
    • If the diagnostic CD does not boot, then reboot the PC and press the Delete key during the boot-up to enter CMOS Setup.
      Note: Some BIOS versions can indicate, on the boot-up display, to use a key other than [Del] to enter the CMOS setup.
      1. In the CMOS Setup window, select Advanced Settings or Boot (depending on the BIOS revision).
      2. Select First Boot Device or Boot Device Priority  > Enter > CD ROM.
        Note: The [Enter] key on the number keypad might not work.
      3. Select Second Boot Device > IDE-0 or Hard Drive.
        Note: If Hard Drive is not selected, there will be an Insert Boot Media error and the PC will not boot to Windows.
      4. Select Third Boot Device (if it is available), and then select Disabled.
      5. Press [F10] to Exit or Save, enter [Y], and then press [Enter] to exit and save the changes.
Table 77: Diagnostic Tests
Diagnostic Test Action
Automatic Diagnostic tests
The automated test takes three minutes to complete. It checks:
  • CPU.
  • Memory.
  • Hard Drive (hda1 and hda2).
  • Serial Ports (ttyS0 and ttyS1, detect only).
  • Flash Drive (sda1).
  1. When the PC boots using the Diagnostics CD ROM, use the arrow keys to select IDE Tape Support - GUI from the Startup menu, then press Enter to continue.

  2. The diagnostic CD launches and runs an automated test of the PC.
  3. Select OK to the Passed Burn In Test Result pop-up.
  4. Select Close to the USB Test pop-up, and then select OK to the Are You Sure You Want To Exit USBTest pop-up.
  5. Select the fd0 (Floppy Drive), hda1 (Hard Drive), or sda1 (USB) location to save the results. Select OK in the Select a file pop-up.
  6. Select OK to the Tests Complete pop-up.
  7. If more testing is desired, then (within 15 seconds) select Cancel to the second Tests Complete pop-up. Otherwise, select OK to exit testing and reboot the PC.

    Note: If a selection is not made within 15 seconds of the appearance of the second Tests Complete pop-up, the PC automatically reboots.
Floppy Drive test
  1. Insert a floppy disk into the floppy drive.
  2. Double left-click on the Floppy Test icon.
  3. Press Enter to start the Floppy Drive test. If the test exits immediately, the floppy disk might be bad or unformatted.

  4. The Floppy Drive test runs for two minutes and then exits.
    Note: To exit Diagnostics completely, right-click on the display and select Reboot or Shutdown from the menu.
Tape Drive test
  1. Insert a tape into the tape drive.
  2. Double left-click on the Tape Test icon.
  3. The test runs automatically for two minutes and then exits. The test displays:
    • Checking Drive status....[OK]
    • Reading from Tape ........[OK]
Burn-in test
The Burn-in test takes three minutes to complete. It checks:
  • CPU
  • Memory
  • Hard drive (dev/hda1 and hda2)
  • Serial ports (ttyS0 and ttyS3 detect only)
  • Flash Drive (sda1)
  1. Double left-click on the Burn-in test icon.
  2. Select the green button.
    Caution: Do not reconfigure the Hard Drive test. Some settings can cause it to overwrite important files on the hard drive.
  3. Select OK.
    Note:
    • The test runs automatically. To cancel the test, select the Stop icon.
    • To set the burn-in test to run continuously until stopped, select the Tests to perform and their duty cycles icon in the GUI Burn-in Test window, set Auto Stop After to 0 (zero), and then select Start.
    • The burn-in serial port check detects the ports only and is not a loopback check.
    • The Hard Drive test writes data to and then reads data from the hard drive. Files are created in the free space on the disk until the disk is 94% full. When the disk has reached this limit, all the test files are deleted and the test starts again. The default burn-in runs for two minutes, so the cycle will not be completed in that time. Use chkdsk to check the hard drive more thoroughly.
  4. Select OK to the Passed or Failed pop-up, and then select File > Exit.
USB Port test
  1. Insert a USB drive or memory stick into a USB port on the rear of the PC.
  2. Double left-click on the USB Test icon.
  3. The test detects the USB Drive (manufacturer, possibly SMART) and indicates the status (OK).
    Note:
    • If only the motherboard host controllers are listed, then the USB Drive was not detected.
  4. Select Close > OK to exit the USB Test.
Printer Port Loopback test
  1. Insert a loopback connector into the printer parallel port on the back of the PC.
    Note: Refer to the Console PC Connector Identification (DxI and Access) for details.
  2. Double left-click on the LPT1 Test icon.
  3. Select the green button.
  4. Select OK.
    Note: The test runs automatically for two minutes. The test can be canceled by selecting the Stop icon.
  5. Select OK to the Passed or Failed pop-up, and then select File > Exit.
Serial Port Loopback test
  1. Insert a loopback connector into the desired serial port on the back of the PC.
    Note: Refer to the Console PC Connector Identification (DxI and Access) for details.
  2. Double left-click on the Serial Test icon.
  3. Select the green button.
  4. Select OK.
    Note: The test runs automatically for two minutes. The test can be canceled by selecting the Stop icon.
  5. To add or remove ports to or from the test:
    • Select the Set Preferences icon at the top of the Burn-in Test window.
    • Select the Serial Port tab.
    • Enter the desired port number to add or remove.
    • Select the Detect and loopback test button.
    • Select Add port or Remove port.
    • Select OK to return to the Main Menu.
    • Select Start to run the test.
    Note:
    • Serial Port ttyS0 is the same as Com1.
    • If the Serial Loopback test fails the first time, try it again or add and remove ports and try again. The Serial Loopback test sometimes has problems detecting the serial expansion card ports on the first run.
    • To test the Dual NIC card, add ttyS2 and ttyS3. Skipping S2 might cause S3 to fail.
  6. Select OK to the Passed or Failed pop-up, and then select File > Exit.
Network Port test
Note: The tftpd32.exe program configures the service laptop network adapter to work as a DNS server.
  1. Configure the service laptop to run as a DNS server.
    1. On the service laptop, right-click on the My Network Places icon, and then select Properties from the menu.
    2. Right-click on the Local Area Connection entry, and then select Properties.

    3. Select Internet Protocol (TCP/IP > Properties.
    4. Record the network settings for the IP address and DNS server.
      Note: Typically, the network settings are set to Obtain an IP address automatically and Obtain DNS Server address automatically.
    5. Right-click in the test PC desktop, then select Reboot or Shutdown from the menu. Retrieve the Diagnostic CD from the test PC, and then insert the Diagnostic CD into the service laptop.
    6. Open Windows Explorer on the service laptop, browse to and open the D:\setup\tftpd32\tftpd32.exe file on the Diagnostic CD.

      Note: If virus protection does not allow the file to be opened:
      1. Right-click on the McAfee icon at the lower right of the desktop, select Virus Scan Enterprise, and select the Disable On-Access Scan option.
      2. Verify the laptop is not connected to a corporate network.
      3. Run the script.
    7. Eject the Diagnostic CD from the service laptop and return the CD to the test PC.
  2. Run the Network Port test.
    1. Boot the test PC using the Diagnostic CD. Proceed through the steps listed in the Automatic Diagnostic test of this table to navigate to the GUI desktop with the Network Test icon.
    2. Double left-click on the Network Test icon.
    3. Select the green button.
    4. Select OK.
      Note: The test runs automatically for two minutes. The test can be canceled by selecting the Stop icon.
    5. Select OK to the Passed or Failed pop-up, and then select File > Exit.
    6. When testing is complete, restore the network settings and the virus protection settings on the service laptop.
Save the results.
  1. Double left-click on the Save Logs icon.
  2. Select where to save the results: fd0 for the Floppy Drive, or sda1 for the USB Drive.

  3. Select OK to exit the save window.
  4. To exit PC Diagnostics completely, right-click in the display and select Reboot or Shutdown.
