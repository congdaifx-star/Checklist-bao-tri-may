PCB - CPU - Atom

Connector Locations

  • The red stripe on the serial ribbon cables face upward.
  • The CPU PCB comes pre-configured with the correct CMOS settings. If there are errors after installation, then refer to the Config - CMOS Setup procedure for CMOS setup instructions. Enable USB support in CMOS for integrated systems.
  • The cable from the AU network hub connects to LAN 1 on the Atom PCB, but whichever LAN port shows "connected" status when only the console PC is connected to the AU should be the port configured with the 192.168.2.4 address. Move the cable or change the port address to comply. To prevent a network conflict, ensure that both ports do not have the same address.
  • The Bulk Feeder II USB cable connects to USB 4.
  • The Dual Gantry USB cable connects to USB 0.
  • A keyboard/mouse splitter cable is provided with the Rocky and Atom CPU PCBs. If the cable is missing, then connect the keyboard to the keyboard/mouse connector and a USB mouse to one of the USB ports.
