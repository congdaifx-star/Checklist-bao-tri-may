Performing Ultrasonics Level Sense Test

This procedure describes how to perform an ultrasonics level sense test to verify reagent pipettor level sense performance.

Perform an ultrasonics level sense test to verify reagent pipettor level sense performance when:
  • an ultrasonics adjustment is performed.
  • troubleshooting reagent pipettor ultrasonics failures.
  • replacing any:
    • transducer.
    • service loop.
    • reagent pipettor tubing.
    • ultrasonic PCB.
  • when referenced from another procedure as a verification step.
Table 82: Specifications
Test Failure Count Z-Step Range
Wet 0 Less than or equal to 40
Dry 0 Less than or equal to 4
Note:
  • These specifications are based on 100 reps of the wet level sense test. Running more than 100 reps can create false wet z-step range failures.
  • Software V2.2 and greater displays the results that fail in red on the test window in the user interface.
  • Z-step range is calculated by subtracting the minimum from the maximum (max - min = step range).
  • Wet %CV is not used to determine the pass or fail status.
Perform an ultrasonics level sense test.
  1. From the Main Menu, select Diagnostics > Device Diagnostics > Ultrasonics > Ultrasonic Settings > Level Sense Test.
    Note: All four pipettors are displayed along the left of the Ultrasonics Level Sense Test for Reagent window with a drop-down menu for selecting the type of test.
  2. Select the desired test.
    If Then
    Dry test is selected, only the Dry test runs
    Wet test is selected, only the Wet test runs
    Dry and Wet test is selected, both the Dry and Wet test runs
    a printout of the results is desired, select the Print Report at End of Test option.
  3. Enter 100 in Test Repetitions field.
    Note:
    • Run 100 test repetitions per pipettor for troubleshooting and verification of ultrasonics.
    • If no tests are required for a specific pipettor, then enter 0 in Test Repetitions field.
  4. Select Start Test.
  5. Review the results with the specifications.
    Note: To troubleshoot failures, refer to the RP: Ultrasonics Level Sense Troubleshooting procedure.
