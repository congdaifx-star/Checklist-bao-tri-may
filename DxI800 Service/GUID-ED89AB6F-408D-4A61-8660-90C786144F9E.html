Dilution Assay Test

This procedure describes how to perform and interpret the DilTest and DilAP.

Perform dTest and dAP when troubleshooting:
  • On-board dilution assays.
  • Dil-hCG2 with APF 2010B and higher.
  • Dil-AFP with APF 2010B and higher.
Note:
  • Performance macro used to evaluate the results of the tests automatically checks data against the DilTest specifications.
  • DilTest specifications differ between DxI instruments and Access instruments.
  • Typical dTest means are 38K to 66K RLU.
Table 35: DilTest Specifications
Parameter Specification Best Practice Guideline
LumiAP mean RLU 10 million to 20 million RLUs
LumiAP CV <2.0%
dTest CV <7.0% </=5%
dAP <5.5% </=3%
dTest Ratio: 205-300
  1. Prepare a 1:201 dilution of system check solution by mixing 100 µL of system check solution with 20 mL of wash buffer. Prepare a 1:501 dilution of system check solution by mixing 50 µL of system check solution with 25 mL of wash buffer.
  2. Run the dilution tests dTests and dAP.
    Repeat these steps for each pipettor. Select a new pipettor for each rack.
    1. Place sample containers capable of holding 2 mL into the first, second, and third positions of a sample rack.
    2. Pipette a minimum of 2 mL of the 1:201 dilution into the sample containers in positions 1 and 2.
    3. Pipette a minimum of 2 mL of the 1:501 dilution into the sample container in position 3.
    4. Select Menu  > Sample Manager > New Request  > Patient/QC Requests, and then enter the Rack ID.
    5. Select More Options > Request Service Assay, enter a Sample ID for cup 1, and then select Pipettor 1 > OK.
    6. Select Position 2 > More Options > Request Service Assay, enter a Sample ID for cup 2, and then select Pipettor 1 > OK.
    7. Select Position 3 > More Options > Request Service Assay, enter a Sample ID for cup 3, and then select Pipettor 1 > OK.
    8. For Position 1, request 10 replicates of test 936 (dTest).
    9. For Position 2, request 10 replicates of test 907 (LumiAP).
    10. For Position 3, request 10 replicates of test 935 (dAP).
    11. Repeat for the other pipettors. Select a new pipettor for each rack.
  3. Open the SPU cover, load the racks, and close the SPU cover.
  4. Use the Performance macro to evaluate the results of the test.
    1. Select and save the results.
      1. From the Main Menu, select Test Results > Filter.
      2. Configure the filter to capture all the desired data points. Select the test results by placing the cursor on the first data point, pressing the [Shift] key, and then selecting the last desired test result.
      3. Save the data.
        Caution: If using an external USB drive to collect data, the external USB memory shared between the DxI console PC and other systems can introduce a virus.
        • To save the data to a USB drive:
          1. Run virus scan on any suspect USB device. See USB Drive Malware Scan and Removal for more information.
          2. Insert a flash drive into a USB port of the console PC.
          3. Select Copy To Disk > Current Selection. Select the desired drive from the drop-down menu, and then select OK.
          4. When finished, remove the USB flash drive.
    2. Analyze the results using the Performance macro.
      1. Select Performance Macro.xls and save the Excel file to your PC Desktop.

        Note: If the file opens and displays the warning BLOCKED CONTENT: The ActiveX content in this file is blocked, select Learn More to open the Microsoft support topic about how ActiveX controls are disabled by default in Microsoft 365 and Office 2024. Follow the steps in that topic for enabling ActiveX controls in the Trust Center for Excel.

        Note: The file will also display the warning SECURITY WARNING: Macros have been disabled. Select Enable Content to start the Performance Macro file.

      2. Select the type of test to analyze.
      3. Select Select Data File (*.csv) to open File Explorer and select the data file. Within a few seconds, the macro will analyze the test results and produce reports and charts.
        • If prompted, enter the instrument serial number and the substrate RLU. Acceptance criteria for individual tests might be different between Access systems and DxI systems. The macro uses the serial number to identify the limits to apply. Instruments that have an Instance Number in the Serial Number field require you to manually enter the serial number.
        • If the error This is not an XXX run is displayed, the test results file contains insufficient or incorrect data.
        Tip: To test the macro, you can use one of the following sample test result files.
        • dTestdAP Test File.csv
        • HS Test File.csv

      4. Remove the USB backup drive or the floppy disk from the service laptop.
  5. Complete dilution assay test processing and chart results.
    1. Wait for the macro to process results and create a chart of the results.
      • Data sorting order is pipettor, test, and then completion time (descending order).
      • Any pipettor with fewer than ten replicates per test is omitted.
      • The macro uses only ten replicates per pipettor, any additional replicates are ignored.
    2. If desired, print the results.
    3. If the test did not pass, identify which pipettor is failing, and then troubleshoot.
      Note: Refer to the Tests: Dilution Assay Test Troubleshooting procedure.
