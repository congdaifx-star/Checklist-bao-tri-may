Software V4.3 Release Notes

Purpose

This document provides details of the most significant features and enhancements in DxI software version 4.3.

Confidentiality

Software release notes are confidential and should not be shared with customers.

Obsoleted Mods

Once this version of software is installed on an instrument, these Mods are no longer applicable to it:
  • Mod 10224 - Software Version 4.2.1

Hardware Changes Enabled

These major hardware changes are included in this software version:
  • The copy to disk function now includes the option to copy to a USB flash drive. The copy to disk function has a drop-down menu that can be used to select where to copy the data to.

Enhancements

These enhancements are included in this software version:
  • Fix for the PCA issue introduced in software V4.2 and V4.2.1 where dispense plate slippage was not flagged correctly. Reference TIUS FYI2009C060 for further details of the issue that is being fixed.
  • Preparations for the on-board dilution feature. The feature will be made operable with an APF release scheduled for Q1 2010.
  • Fix for the issue that was introduced in software V4.1 where customers on LAS systems can receive Database Mismatch errors that are benign. Automation customers no longer see this nuisance message.
  • Fixed DxI 800 dual gantry max travel range. In some cases, the pipettor could hit the end of the rail, the max travel range has been adjusted from 455 to 440 to correct this.
  • Fixed flexible reserve volume for automation instruments issue. In some cases, the max volume did not get set in the database, this has been corrected.
  • Fixed reagent pack monitoring for a flagged pipettor issue. Previously if a pipettor was flagged for pack monitoring, it would complete the two-step assays that were started on that pipettor and give a result, now these test results are flagged.
  • BAssertEvent errors for tape backup failures are clearer and provide more details about the failure.
  • Resolved reagent barcode read errors at position 1. It was found that this event could be posted instead of flagging reagent load tray slippage properly. Added a proper slippage flag to make sure that the correct event is given for the failure mode.
