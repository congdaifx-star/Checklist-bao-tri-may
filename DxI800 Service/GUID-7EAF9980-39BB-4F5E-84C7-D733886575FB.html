Reagent Storage Interface PCB Operating Principles

This document details the operating principles for the reagent storage interface PCB.

Overview

The reagent storage module is a two-dimensional array of reagent packs that are randomly accessible by X- and Z-axis movement of the reagent pack gripper. The reagent storage interface provides the interface and control circuitry necessary for movement and operation of the reagent pack gripper.

During normal operation, the host processor determines the X and Z locations of the reagent pack gripper by interrogating the microcontroller located on the reagent storage interface. If a power down occurs, the reagent storage interface maintains the location of the pack gripper for up to 48 hours. At start-up, the host processor can move the pack gripper through the maze of reagent packs to the home location.

The reagent storage interface controls the LEDs on the Lexan panel and the LED display. These LEDs provide the operator with instrument status. Depending on the condition of the instrument, an LED can be on, off, blinking at rate 1, or blinking at 2. The microcontroller can control the status of each LED individually. The blink rates of the LEDs are software configurable.

General Operation

The reagent storage interface printed circuit board performs the following general operations:

  • Provides power back-up for reagent storage X- and Z-axis positions.
  • Controls LEDs on the Lexan display panel and the LED display panel.
  • Senses the reagent storage door switch.
  • Provides reagent storage motor (power) and sensor signal interface.
  • Provides the reagent storage bar code reader interface.
  • Provides the substrate bar code reader interface.
  • Provides the reagent storage load door LED indicator interface.
  • Provides the interface for an audible alarm.

Operating Principles

Encoder interface and LED/Alarm control:

The reagent storage interface uses a PIC microcontroller to acquire encoder data from X- and Z-axis reagent storage encoders and to control LEDs on the Lexan panel and LED display.

Encoder Interface:

The reagent storage interface encoder circuitry uses two quadrature decoder ICs for the quadrature decoding and bus interface functions. The quadrature decoder ICs provide Schmidt trigger inputs and digital noise filtering to reject noise on the incoming encoder signals. Each decoder decodes the incoming filtered signals into quadrature count information that is transmitted to an internal 16-bit position counter. The value contained within the position counter represents the absolute position of the reagent gripper pack.

Position data is latched within the quadrature decoder ICs on each rising clock edge, unless inhibit logic disables this operation. Latching is disabled during a two-byte read operation when the decoder transfers data to the microcontroller. The 16-bit latch and inhibit logic allows access to 16 bits of count with an 8-bit bus. The latch is automatically re-enabled at the end of these reads.

LED Control:

The microcontroller controls LEDs on the Lexan display panel and on the LED display panel. Each LED can be controlled individually to be on, off, blinking at blink rate 1 or blinking at blink rate 2. Blink rates 1 and 2 are software configurable from x to y Hz. The microcontroller latches the LED data into the LED latches at a rate of 100 ms. Sixteen discrete blink rates are available for blink rate 1 and blink rate 2.

Alarm Control:

The microcontroller controls the system alarm. The alarm volume is software configurable with 16 discrete levels. The alarm can also be made to beep with varying frequency. The beep frequency has 16 discrete rates that are software configurable.

Power Back Up:

The reagent storage interface provides power back up to maintain the position of the reagent gripper pack for up to 48 hours following a power down.

This system uses a 3.3 F capacitor to provide power back-up during power down. The backup capacitor is charged initially by the +5 V local power supply on the reagent storage interface to the voltage Vcap, approximately 4.5 volts. This provides the input to the switching power supply that generates regulated 5 volts to the encoder circuitry.

The microcontroller monitors the status of the + 24 volt supply and the voltage across the backup capacitor. When the microcontroller detects a power failure condition, there are three time important time intervals. During the first 60 seconds of a power failure, the motors can continue to turn as they come to rest. The encoders must continue to operate until the motors come to their final position. If microcontroller detects motion more than 60 seconds after a power failure, it records this as a fault condition.

During power down, +5 V backup supply powers the encoder circuitry. After the initial 60 seconds of power down, the final values of the encoder positions are stored by the microcontroller in its internal EEPROM. The microcontroller then shuts down the encoder back up supply and goes into sleep mode to conserve power.

While the microcontroller is in sleep mode, it performs the following three tasks: 1)tracks real time by incrementing an internal counter, 2) checks the Vcap voltage, and 3) waits for an interrupt if the reagent storage cover is opened.

The microcontroller tracks real time by incrementing its internal counter during the power down. If the power failure continues more than 48 hours, the microcontroller records this as a fault condition. The microcontroller periodically checks the back-up capacitor voltage. If the Vcap falls below 2.5 volts within 48 hours of a power failure, the microcontroller records this as a fault condition. Opening the reagent storage cover generates a signal that interrupts the microcontroller from sleep causing it to record this as a fault condition

Status LED Interface:

The interface provides a TTL signal to control LEDs located on the Lexan panel and the LED status panel to be on, off, or blinking.

Reagent Door Switch:

The reagent storage interface PCB monitors the reagent module door switch to determine if the door is opened during power down. If the door is opened, then an error flag is set. This requires that the reagent pack gripper be returned to the home position manually.

Reagent Storage bar code reader interface:

The interface PCB provides an RS422 interface and +5 V DC power for a Microscan bar code reader.

Substrate bar code reader interface:

The interface PCB provides an RS232 to RS422 interface and +5 V DC power for an RS232 bar code reader.

Software Overviews

The reagent storage interface PCB performs the following operations:
  • Initialization:
    • All counters are reset to 0.
    • Default values for LED status, LED blink rates, alarm volume, alarm beep frequency, Vcap limit, encoder dwell time, and power down timeout are loaded into the reagent storage interface registers.
  • Normal Operation:
    • Outputs data to the LED latches every 100 ms.
    • Receives and processes commands from the host (e.g. read the encoder count, turn LEDs off or on)
    • Checks for a power down condition.
    • Waits for a cover open interrupt. If cover opened set cover opened status bit.
  • Power down:
    • When the reagent storage interface microcontroller detects a power down condition, the microcontroller performs these operations:
      • Sets the power down error flag.
      • Turns off the LEDs.
      • Tracks time.
      • Successively reads and stores encoder data.
      • Checks for stopped encoder motion.
      • If encoder motion detected after encoder dwell time, sets error flag.
      • Waits for a cover open interrupt. If cover is opened, sets cover opened during power down status bit.
  • Sleep mode:
    • During power down after the encoder dwell time has been exceeded, the microcontroller performs the following operations:
      • Tracks time.
      • Checks Vcap level, if Vcap falls below minimum value, an error flag is set.
      • If downtime is greater than maximum value, an error flag is set.
      • Waits for a cover open interrupt. If cover is opened, sets cover opened during power down status bit.
      • Wakes up from sleep when power is restored.
