Software V2.3 Release Notes

Purpose

This document provides details regarding the most significant features and enhancements included in DxI software version 2.3.

Confidentiality

Software release notes are confidential and should not be shared with customers.

Prerequisites

The prerequisites for updating or installing software version 2.3:

If updating from version Then
1.4 or lower Recalibrate all customer assays and run QC within customer limits.
1.4.1 or 1.4.2 Run QC on all customer assays within customer limits.
Prior to 2.0 All open mandatory MODs must be completed. Calibrate Process Monitoring.
2.0 or 2.0.1 Install software, then calibrate substrate backdraw in the priming window.
2.1 or 2.2 No prerequisite. The software is customer installable.

Mods Obsoleted

Installation of software version 2.3 obsoletes these Mods:
  • Mod 6769: On-load Pusher Speed - Modify.
  • Mod 6744: Reagent and Supply Shuttle Delta - Modify.
  • Mod 6712 - Software Version 2.2.2 - Install.
  • Mod 6814 - Software Version 2.2.3 - Install.

Enhancements

This software revision includes these enhancements.
  • Added ability to recover from some Bulk Feeder, Reagent Storage, and SPU errors during run. Recovery is performed by using the Recover button on the bottom of the event log screen.
  • Changed ultrasonic probe mixing to incorporate a lock when mixing a dilution vessel (same as Access 2).
  • To prevent jams, changed timing to upper ejector cylinder in bulk feeder when recovering from a blocked RV. When a second push is required, the upper ejector does not eject until both upper and lower ejectors retract sensors are recognized.
  • Fixed issue where the APF update of a qualitative assay with the calibrator setup introduced inconsistencies in the database.
  • End of Run Utility no longer starts while tests are still in progress.
  • Corrected RV supply shuttle delta-spacing to reduce vessel handling issues. This change obsoletes Mod 6744.
  • SPU slip check routine eliminates on-load pusher stalls and obsoletes Mod 6769. SPU slip check timing is reset to 1400/1500 rate. Time is recovered by allowing samples to pipet before the on-load pusher returns home.
  • Wash pump now replenishes after exiting the Luminometer Diagnostics screen.

Event Log Enhancements

These improvements to the event log are included in software revision 2.3:
  • Sample pick-and-place errors now report the correct vessel: SV, DV, or RV.
  • New event log message reports RV, SV, or DV ejector failure when pick-and-place fails to eject (or Hall Effect sensor fails). Added troubleshooting suggestions.
  • Soft pick-and-place errors now specify which pick-and-place.
  • Reagent pipettors now report if slippage occurs while homing after a fault.

Diagnostics Changes

These improvements to Diagnostics are included in software revision 2.3:
  • Vessels now mix during dispense portion of aspiration volume checks.
  • Corrected the height where the sample pipettor and reagent pipettors dispense during volume checks.
  • Added a long wash during level sense test every other wash (same as Access 2). The long wash flushes any potential bubbles created during the short washes to avoid adding bubbles to the reaction vessel.
  • Added test count to events in event log database. Only noticeable when using the EventsTest UD application to save the Event Log as a text file.
  • Added logging of instrument state changes to the events database. Only noticeable when using the EventsTest UD application to save the Event Log as a text file. Examples:
    • Instrument to Ready Mode
    • Instrument to Running Mode
    • Instrument to Pause Mode
    • Pause Button Pressed
    • Resume Button Pressed

Other Changes

This section lists other changes to the software that are less visible than those changes listed in the enhancements section:
  • Fixed IP address issue in new Dual NIC "blue dot" PC. Updated the new registry entry for PrimaryConsoleIP to match the physical IP address of the PC. If software cannot determine the correct IP address, a pop-up box requests that the user select the correct IP address.
  • Allows pipetting of one reagent type across multiple wells in a pack.
  • If wash pick-and-place is left holding a vessel at the end of a run, then the instrument transitions to Not Ready.
  • Increased the maximum number of prime cycles for reagent pipettors from 20 to 999.
  • Added Wash Buffer II support. Only affects instruments with a Wash Buffer II APF.
    • Eliminated timing pause between mixer belt direction change. Increased the spin time (0.125 s each direction) to maintain timing.
    • Changed Wash Buffer in Bulk Supplies Screen to Wash Buffer II.
  • Added support for DxI 600.
