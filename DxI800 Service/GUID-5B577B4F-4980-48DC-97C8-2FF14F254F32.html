Troubleshooting Ultrasonics

Purpose

This document provides troubleshooting information for failures in the ultrasonics circuit.

Event Log Messages

Event Log Message or Error Details Troubleshooting
  • Ultrasonics General Failure
  • Software V4.4 and above: Reagent pipettor ultrasonics failure: Pipettor X. Where X is pipettor number
  • Failed to find or lock on resonant frequency.
  • Failed to clear a previous Level Sense Phase Lock (PLL).
  1. Perform the ultrasonics adjustment procedure.
    Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
  2. Use the Failure Modes table in this document to troubleshoot any messages received during the ultrasonics adjustment.
Ultrasonics Level sense failure (QNS)
  • No fluid detected before maximum steps.
  • Level sense detected before level sense start.
  • If the QNS occurs on an SV with more than one test requested, then the SV continues processing.
    • If the SV was under-filled, then more QNS errors occur.
    • If hardware or fluidics issues on a reagent pipettor caused the QNS, then the other replicates continue to completion.
  1. Perform the ultrasonics level sense procedure.
    Note: Refer to the Tests: Performing Ultrasonics Level Sense Test procedure.
  2. Perform the ultrasonics adjustment procedure.
    Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
  3. Use the Failure Modes table in this document to troubleshoot any messages received during the ultrasonics adjustment.
Reagent Pipettor detects sample vessel fluid at unexpected height (QNS) The SV level is greater than or equal to 30 steps (75 µL) above or below the expected volume. If the error occurs on all pipettors, then:
  1. Verify that the rack and cup configuration and the sample and reagent pipettor z-axis alignments are correct.
  2. For instruments at high elevation, consider the high elevation configuration. Refer to the RP: Configuring Level 1 Ultrasonics Voltage for High Altitude Sites procedure.
  3. Troubleshoot the sample pipettor circuit.
    Note: Refer to the Unexpected Height Errors on Multiple Pipettors table in the Fluidics: Troubleshoot Pumps (Sample/Wash/Precision) procedure.
Note: Examples of high elevations sites: Mexico City, Santa Fe, NM and Salt Lake City, UT.
If the error occurs a single pipettor, then:
  1. Verify reagent shuttle movement.
  2. Perform the ultrasonics level sense procedure.
    Note: Refer to the Tests: Performing Ultrasonics Level Sense Test procedure.
  3. Perform the ultrasonics adjustment procedure.
    Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
  4. Use the Failure Modes table in this document to troubleshoot any messages received during the ultrasonics adjustment.
Insufficient Sample volume in SV (QNS) Fluid is detected before Max Depth but there is insufficient volume to aspirate the required volume. If the error occurs on all pipettors, then:
  1. Verify that the rack and cup configuration and the sample and reagent pipettor z-axis alignments are correct.
  2. For instruments at high elevation, consider the High Elevation Configuration.
    Note: Refer to the RP: Configuring Level 1 Ultrasonics Voltage for High Altitude Sites procedure.
  3. Troubleshoot the sample pipettor circuit.
    Note: Refer to the Unexpected Height Errors on Multiple Pipettors table in the Fluidics: Troubleshoot Pumps (Sample/Wash/Precision) procedure.
    Note: Examples of high elevations sites: Mexico City, Santa Fe, NM and Salt Lake City, UT.
If the error occurs a single pipettor, then:
  1. Verify reagent shuttle movement.
  2. Perform the ultrasonics level sense procedure.
    Note: Refer to the Tests: Performing Ultrasonics Level Sense Test procedure.
  3. Perform the ultrasonics adjustment procedure.
    Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
  4. Use the Failure Modes table in this document to troubleshoot any messages received during the ultrasonics adjustment.

Failure Modes

Failure Modes Details Troubleshooting
The user interface prevents access to the ultrasonics adjustment. If the AU fails to initialize the ultrasonics correctly, then the reagent pipettor is disabled. If the pipettor is disabled, it is not possible to run an adjustment in the Ultrasonics Adjustment screen. To calibrate the pipettor when it is not possible to run an ultrasonic adjustment, use the TestUltrasonic.exe workaround.
Note: Refer to the RP: Using TestUltrasonic.exe procedure.
The instrument is not initializing.

And

The event log displays: Initialization Failed and General Pump Failure.

The general pump failure is a misleading error message. The error is related to the ultrasonics calibration failure for the pipettor associated with the pump. If the details of the events log display these details:
  • Initialization Failed During Phase 5 of Initialization
  • General Pump Failure, Reagent Pip #X on Initialization

then calibrate the ultrasonics of that pipettor. Do not troubleshoot the pump.

Note: To calibrate the pipettor when it is not possible to run an ultrasonic adjustment, use the TestUltrasonic.exe workaround. Refer to the RP: Using TestUltrasonic.exe procedure.
Calibration Sweep Failure. Transducer frequency fails to lock during adjustment. Refer to the Troubleshooting Calibration Adjustment and Sweep Failures table.
Calibration Adjustment Failure. The instrument failed to make the voltage adjustments required to reach the assigned frequency of the probe. Refer to the Troubleshooting Calibration Adjustment and Sweep Failures table.
Baseline Voltage Failure. Unable to reach or hold a stable voltage between 187 V AC and 207 V AC. Refer to the Troubleshooting Baseline Calibration Failures table.
Ultrasonics Voltage Failure. Unable to reach or hold the baseline voltage ±10 V AC. Refer to the Troubleshooting Baseline Calibration Failures table.
Sonicator Power High Value is reported as a 0. The actual value the system is receiving is greater than 1023 DAQC counts. Refer to the Troubleshooting Baseline Calibration Failures table.

Troubleshooting Baseline Calibration Failures

Symptom Action
Voltage is unstable (see note) or outside of the 187 to 207 V AC range
Note:
  • Normal voltage readings decay approximately 4 to 7 V and then stabilize. The reading generally increases slowly as the transducer heats up. Unsteady voltages continue to decay.
  • This voltage is taken with the buffer supply line nut out, so the voltage is expected to be between 187 V AC and 207 V AC.
Use this list to identify possible contributing issues.
  1. Remove the pipettor probe tip, retorque, and perform the ultrasonics adjustment procedure.
    Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
  2. Inspect the hex set-screw for damage or to check that it is not touching the transducer. Remove the set-screw, and straighten it if it is bent. Install the set-screw, then back it out two turns.
  3. Check that the slot in the transducer horn is aligned to the set-screw.
  4. Check that the pipettor tip is not touching the wash tower.
  5. Perform the ultrasonics adjustment procedure.
    Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
    If the adjustment is still unsuccessful, then continue to the Troubleshooting Calibration Adjustment and Sweep Failures table.


Troubleshooting Calibration Adjustment and Sweep Failures

Note:
  • If troubleshooting one pipettor, then component swaps might be necessary to isolate the failure.
  • If swapping components while troubleshooting and the failure remains with the originally failed pipettor, then return to the original configuration and proceed with other parts swaps. This eliminates the confusion of what was the failed part and limits the parts that must be changed.
  • Perform the action items in the table in the order they are presented.
Troubleshooting Action If Then
Calibrate the ultrasonics several times. If the calibrations follow an alternating pattern of Pass, Fail, Pass, Fail Change Level 1 Voltage.
Note: Refer to the RP: Changing Level 1 Voltage During Troubleshooting procedure.
If the calibration continues to Fail, Continue Troubleshooting Calibration Adjustment and Sweep Failures.
Verify that these electrical connections are secure and in good condition:
  • Service loop.
  • Pipettor interface PCB.
  • Signal cable.
  • Ultrasonics PCB.
Perform the ultrasonics adjustment with the buffer supply line nut and z-guide removed.
  1. Select the correct drained pipettor to be adjusted.
  2. Select Adjustment.
  3. Select OK on the pop-up with countdown clock. The pipettor sonicates at all power levels.
The adjustment is successful, Continue with adjusting ultrasonics voltage using the baseline calibration.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage Using Baseline Calibration procedure.
The transducer voltage continues to not reach 197 V AC (187 to 207 V AC), Move the signal cable (the cable from the interface PCB to the ultrasonics PCB) to a different known good channel on the ultrasonics PCB. Perform the ultrasonics adjustment and baseline voltage.

Example: Pipettor 1 is failing. Switch signal cable connection with pipettor 2 and perform the adjustment for pipettor 2.

The other channel works, Replace the ultrasonics PCB, return hardware to the correct configuration, and perform the ultrasonics adjustment on all affected pipettors.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
The other channel continues to fail, Return hardware to the correct configuration, perform the ultrasonics adjustment on all affected pipettors, and continue to the next action item.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
Switch the ultrasonics PCB and perform the ultrasonics adjustment.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.

Example: Pipettor 1 is failing calibration. Switch the ultrasonics PCB and perform the adjustment procedure on pipettor 1.

The new ultrasonics PCB works, Then replace the failed ultrasonics PCB, return hardware to the correct configuration and perform the ultrasonics adjustment on all affected pipettors.
Note: Refer to theRP: Adjusting Ultrasonics Transducer Voltage procedure.
The new ultrasonics PCB fails, Return hardware to the correct configuration, and perform the ultrasonics adjustment on all affected pipettors and continue to the next action item.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
Switch the signal cable for a known good signal cable and perform the ultrasonics adjustment.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.

Example: Pipettor 1 is failing calibration. Switch the signal cable for pipettor 1 with pipettor 3 (on both the ultrasonics PCB and reagent pipettor interface PCB) and perform the adjustment procedure on pipettor 1.

A different signal cable works, Replace the bad signal cable, return hardware to the correct configuration, and perform the ultrasonics adjustment on all affected pipettors.
The new signal cable continues to fail, Return hardware to the correct configuration, perform the ultrasonics adjustment on all affected pipettors, and continue to the next action item.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
On the reagent pipettor interface PCB, switch the two connections for the signal cables and then switch the two connections for the service loop. Perform the ultrasonics adjustment on both pipettors.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
The failure moves to the other pipettor, Replace the reagent pipettor interface PCB, return hardware to the correct configuration, and perform the ultrasonics adjustment on all affected pipettors.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
The failure does not move to the other pipettor, Return hardware to the correct configuration, perform the ultrasonics adjustment on all affected pipettors, and continue to the next action item.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
Replace the transducer and perform the ultrasonics adjustment.
Note: Refer to the RP: Adjusting Ultrasonics Transducer Voltage procedure.
If the new transducer continues to fail, then replace the service loop.
