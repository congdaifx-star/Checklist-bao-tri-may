DxI Software V7.0.0 Release Notes

Purpose
  • This document provides details of the most significant features and enhancements included in DxI software version 7.0.0.
Confidentiality
  • Software release notes are confidential and should not be shared with customers.
Background
  • DxI software version 7.0.0 was released to fielded instruments as mandatory Mod 12827.
  • The software requires regulatory clearance in all geographies and the Mod was not released in all geographies on the original release date of Mod 12827.
  • Refer to Oracle Mod 12827 to determine if software version 7.0.0 is released for a specific instrument or geography.
  • Software version 7.0.0 will only ship with new instruments for geographies that have regulatory clearance.
  • The previous software version (5.7.0) will continue to be shipped with new instruments to geographies that have not received regulatory clearance.
  • DxI software version 7.0.0 can be installed on Windows XPe or 8e operating systems.
Feature Overview
  • hsTnI carryover resolution for field action (FA-000604) - "O" command probe washing. After installing software version 7.0.0 along with APF 2023B as part of Mod 12827, the customer no longer needs to perform the actions in FA-000604 after running hsTnI samples with extremely high values. The software implements an "O" command wash of the reagent pipettors as well as a double wash of the sample pipettor for all hsTnI samples. Refer to the updated hsTnI assay IFU on the Beckman Coulter website for the new carryover specifications.
  • Sample Pipettor Double Wash - The sample pipettor double wash can be implemented via APF for any assay. Previously the feature was only available based on the volume of sample aspirated by the pipettor. At the initial release date of Mod 12827, the only assay that currently uses this feature is hsTnI.
  • APF Installation Control - Ensures that only .3 APF versions (example 2.10.236-B.3) can be loaded on new instruments with software version 7.0.0 or above. This ensures proper implementation of "O" command probe washing.
  • Restore Utility Tool - The restore utility tool will now clear all instrument critical events when the program is run. Full functionality of the tool has been restored. All reagent supply counts will be restored, and the critical events will be cleared when the restore utility tool is used.
  • Installer Database Licensing - The database license is updated when converting from PoetObjects to FastObjects during the software load. This feature improves the installation process and eliminates the need to reimage the console PC when upgrading from older software versions.
  • Installer Upgrade - The software will now load regardless of whether or not the driver folder exists on the C: drive. Previously the driver folder had to be manually deleted for the software to load when upgrading from version 5.2.
  • PC Name Change - The PC name no longer needs to be Console_PC for the software installation to complete.
  • PC Reboot - The console PC and instrument will be automatically rebooted during the software installation if it has been more than 24 hours since they were last rebooted.
Expected Behavior
  • Same as version 5.7.0.
