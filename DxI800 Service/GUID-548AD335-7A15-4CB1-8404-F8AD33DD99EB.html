Aligning Reagent Carriage

This procedure describes how to align the reagent carriages to the DV waste. The reagent carriage module is a secondary alignment device for the reagent pipettors, the incubator pick-and-place, and the sample pick-and-place. The alignments to these devices is included in the other device alignment procedures.

Required Materials:
  • No special tools are required.
Prerequisites:
  • All mechanical adjustments to the reagent carriages must be completed prior to performing the software alignments.

The reagent carriages interact with the reagent pipettors, the incubator pick-and-place, the sample pick-and-place, and the DV waste. This module is a secondary alignment device for the reagent pipettor module, the incubator pick-and-place module, and the sample pick-and-place module.

The manual alignment for this module includes:
  • reagent carriages to DV waste
Note: Changes to alignment offsets are written to file:
  • when the alignments are saved while exiting the Alignment screen.
  • by selecting Alignments / Offsets > Save Alignments.
  1. Align the reagent carriage to the DV waste.
    1. Open the upper left front cover and insert an interlock bypass.
    2. From the Main Menu, select Diagnostics > Device Diagnostics > Mechanics > Alignments.
    3. Select Reagent Carriage as the primary device.
    4. Select Home Device, then move it to the reagent pipettor position.
    5. Place a vessel in position 4 of the reagent carriage.
    6. Select DV Waste as the position.
    7. Select Move X/Y to Position.
    8. Observe the transition of the vessel into the DV waste tube to determine if the alignment is correct.
      • If the vessel is ejected into waste tube smoothly, then the alignment is correct.
      • If the vessel is not ejected into waste tube smoothly, then the alignment is incorrect. Use the directional buttons on the screen to adjust the offset, then repeat the alignment procedure.
    9. If the alignment is correct, select Alignments/Offsets > Preserve Offsets .
    10. Repeat the alignment procedure for the remaining reagent carriages.
  2. Initialize the instrument.
  3. Verification: Run the vessel exerciser to verify proper operation of the reagent carriage.
    1. From the Device Diagnostics screen, select Exerciser.
    2. Run 50 replicates of the Vessel Exerciser Dilution Route.
    3. Select Cycle Vessels.
    4. Observe the transition of the vessel into the DV waste tube to determine if the alignment is correct.
      • If the vessel is ejected into waste tube smoothly, then the alignment is correct.
      • If the vessel is not ejected into waste tube smoothly, then the alignment is incorrect. Align or adjust the carriage position, as necessary.
  4. Verify system operation.
    1. Perform system verification as stated in the Verification of Service Repair document .
      Refer to the Admin: Verification of Service Repair document.
  5. Remove the interlock bypass, and close the cover.
  6. Initialize the instrument.
