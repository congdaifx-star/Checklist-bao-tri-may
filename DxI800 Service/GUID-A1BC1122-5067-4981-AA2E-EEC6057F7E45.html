Aligning Reagent Pipettor

This procedure describes how to align the reagent pipettor to the reagent carriage, the front and rear reagent packs, the wash tower y-position, and the wash tower z-position.

Required Materials:
  • Green, vessel-shaped alignment tool
  • Reagent pack alignment tool

Prerequisites:

All mechanical adjustments to the following devices must be completed before performing the software alignments in this procedure:
  • Reagent pipettor
  • Reagent carriages

The reagent pipettor must aspirate fluids from vessels and reagent packs and dispense fluids into the center of vessels in the reagent carriage.

The semi-automatic alignments for this module include:
  • Reagent pipettor y-position to reagent carriage position
  • Reagent pipettor y-position to reagent pack position
  • Reagent pipettor y-position to wash tower position
Note: The pipettor to reagent carriage and pipettor to reagent pack z-position alignments are preserved when the semi-automatic y-position alignments are completed, but the z-position alignments must be verified manually.
The manual alignments for this module include:
  • Reagent pipettor z-position to reagent carriage position
  • Reagent pipettor z-position to reagent pack positions
  • Reagent pipettor z-position to wash tower position
Note: Changes to alignment offsets are written to file:
  • when the alignments are saved while exiting the Alignment screen.
  • by selecting Alignments / Offsets > Save Alignments.
  1. From the Main Menu, select Diagnostics  > Device Diagnostics > Mechanics  > Alignments.
  2. Align reagent pipettor y-position to reagent carriage position.
    1. Select Reagent Pipettor as the device, and then select Reagent Carriage as the position.
    2. Select Alignments / Offsets  > Semi-Auto Alignment.
      Select OK at the Remove the alignment tool pop-up.
    3. Place the green, vessel-shaped alignment tool into the carriage, third position from the front.
    4. Select OK.
    5. Manually place the pipettor probe tip onto the recessed surface of the tool at the center of the cross hair.
    6. Select OK.
      The instrument homes the pipettor, and preserves the y-position and z-position alignments (but does not save them).
    7. Select OK.
      Do not remove the tool as instructed by the pop-up, the tool is required when performing the z-alignment.
  3. Align reagent pipettor z-position to reagent carriage position (manual alignment).
    Caution: Perform the semi-automatic alignment of the sample pipettor y-position to the SPU tray before manually aligning the sample pipettor z-position to the SPU tray.
    1. Select Reagent Pipettor as the device and Reagent Carriage as the position.
    2. Select Home Device > Move Z to Position.
      The green, vessel-shaped alignment tool should be in the carriage, third position from the front.
    3. Using the directional keys, step the pipettor z-position up or down until the probe is in the recessed surface of the tool (no vertical movement of alignment tool).
    4. Select Alignments / Offsets > Preserve Offsets.
    5. SelectHome Device > Move Z to Position, then check for correct alignment.
    6. Adjust if necessary, then save by selecting Alignments / Offsets > Save Alignments.
    7. Select Home Device.
  4. From the Main Menu, select Diagnostics  > Device Diagnostics > Mechanics  > Alignments.
  5. Align reagent pipettors to pipetting nest positions without removing the reagent storage cover.
    1. Load the reagent pack tool into position 1 on the reagent load tray.
      Note: Position 1 is the leftmost position on the reagent load tray.
    2. Select Reagent Pack Gripper as the device and Reagent Load Tray as the position.
    3. Verify that the gripper status is open and the Gripper Open indicator light is on.
      Caution: If the gripper is closed, a software crash occurs during the next step.
      Note: If the gripper status is open, the user interface LED should be green. If the gripper status is closed, then select the Toggle Gripper button. The gripper must be open before continuing.
    4. Select Move Z to Position.
    5. Select Toggle Gripper to grip the tool.
      Note: Verify that the Pack Present indicator light is on in the UI.
    6. Select the pipettor of choice as the position option, then select Move Z to Position.
      Note: Repeat this alignment for each reagent pipettor that needs alignment by selecting the appropriate pipettor as the position option and repeating the steps that follow.
    7. Once the gripper has moved the pack tool into position, select Toggle Gripper to release the pack into the nest.
      Note: Verify that the Gripper Open indicator light is on in the UI.
    8. Select Home Device to home the reagent pack gripper.
      Note: Failure to home the gripper causes the software to crash.
    9. Switch the device option to the pipettor where the pack tool was placed, and change or verify the appropriate alignments.
      See the semiautomatic and manual alignments to the reagent pack rear position.
    10. Select Reagent Pack Gripper as the device and verify that it is in the home position and that the gripper is open.
    11. Switch the device to the Reagent Pack Gripper. Move it to the location of the tool by selecting the pipettor of choice and selecting Move Z to Position. Select Toggle Gripper to grip the tool.
      Note: Verify that thePack Present indicator light is on in the UI.
    12. If another pipettor requires alignment, repeat the alignment steps. If all pipettor alignments have been completed, then remove the tool.
  6. Align reagent pipettor y-position to reagent pack position.
    Note: The software does not include the option to align the reagent pipettor y-position to the reagent pack front using semi-auto alignment. The alignment of the reagent pipettor y-position is to the reagent pack rear only.
    1. Select Reagent Pipettor as the device, and then select Reagent Pack Rear as the position.
    2. Select Alignments / Offsets  > Semi-Auto Alignment.
    3. Verify that the reagent pack tool is in the pipettor slot (nest) to be aligned, and select OK.
    4. If the reagent storage module does not have pipetting access inserts that are removable from the top of the module, look down the front pack access hole and note the position of the tool crosshair relative to the hole.
      Note: You might need a flashlight to see the position of the tool crosshair in the pack access hole.
    5. Manually move the pipettor probe tip into alignment with the center of the reagent pack tool rear crosshair and into contact with the top surface of the tool.
    6. Select OK.
      The instrument homes the pipettor and preserves the y-position and z-position alignments, but does not save them.
    7. Select OK.
      Do not remove the tool as instructed by the pop-up, the tool is required when performing the z-alignment.
  7. Align reagent pipettor z-position to reagent pack rear position.
    Caution: Perform the semiautomatic alignment of the reagent pipettor y-position to the reagent pack before aligning the reagent pipettor z-position to the reagent pack.
    Note: The reagent pipettor z-position alignment to the reagent pack includes both a Reagent Pack Front position and a Reagent Pack Rear position.
    1. Select Reagent Pipettor as the device, and then select Reagent Pack Rear as the position.
    2. Select Move Z to Position with the reagent pack tool in the pipettor slot (nest).
    3. Using the directional keys, step the pipettor z-position up or down until the probe is barely touching the top of the tool (no vertical movement of alignment tool).
    4. Select Alignments / Offsets > Preserve Offsets.
    5. SelectHome Device > Move Z to Position, then check for correct alignment.
    6. Adjust if necessary, and then save by selecting Alignments / Offsets > Save Alignments.
    7. Select Home Device but do not remove the tool. Proceed to the alignment to the reagent pack front position.
  8. Align reagent pipettor z-position to reagent pack front position.
    Note: The reagent pipettor z-position alignment to the reagent pack includes both a Reagent Pack Front position and a Reagent Pack Rear position.
    1. Select Reagent Pipettor as the device, and then select Reagent Pack Front as the position.
    2. Select Move Z to Position with the reagent pack tool in the pipettor slot (nest).
    3. Using the directional keys, step the pipettor z-position up or down until the probe is barely touching the top of the tool (no vertical movement of alignment tool).
    4. Select Alignments / Offsets > Preserve Offsets.
    5. Select Home Device > Move Z to Position, then check for correct alignment.
    6. Adjust if necessary, and then save by selecting Alignments / Offsets > Save Alignments.
    7. Select Home Device.
  9. Remove the pack tool.
    1. Select the Reagent Load Tray as the position, select Move Z to Position, and then select Toggle Gripper to release the tool into the tray.
    2. Select Home Device to home the reagent pack gripper and the reagent load tray.
    3. Remove the tool.
  10. From the Main Menu, select Diagnostics  > Device Diagnostics > Mechanics  > Alignments.
  11. Align reagent pipettor y-position to wash tower position.
    1. Select Reagent Pipettor as the device, and then select Wash Tower Y as the position.
    2. Select Alignments / Offsets  > Semi-Auto Alignment.
      The instrument homes the pipettor, moves the pipettor to a location that is a safe distance above the wash tower, and disables the pipettor motors.
    3. Manually place the pipettor probe tip directly over the center of the wash tower hole.
    4. Select OK.
      The instrument homes the pipettor.
  12. Align reagent pipettor z-position to wash tower position (manual alignment).
    Caution: Perform the reagent pipettor y-position to wash tower alignment before the reagent pipettor z-position to wash tower alignment.
    1. Select Reagent Pipettor as the device, and then select Wash Tower Z as the position.
    2. Select Home Device > Move Z to Position > Motors > Disable X/Y Motor.
    3. Carefully move the pipettor carriage rearward using the y-belt pulley at the front of the pipettor.
    4. Determine whether the wash tower nozzle is the new style or old style of nozzle.
      Wash tower nozzle (old style) Wash tower nozzle (new style)
      • Old style - If the wash tower nozzle is the old style of nozzle, determine whether there is clearance between the probe tip and the recessed flat surface of the wash tower.
      • New style - If the wash tower nozzle is the new style of nozzle, determine whether there is clearance between the probe tip and the top of the inner ring directly adjacent to the hole.
    5. Complete the following steps depending on whether there is clearance.
      • If there is clearance:
        1. Select Motors > Enable X/Y Motor > Home Device > Move Z to Position.
        2. Step the alignment down one step.
        3. Select Alignments / Offsets > Preserve Offsets.
        4. Select Home Device > Move Z to Position > Motors > Disable X/Y Motor.
        5. Carefully move the pipettor carriage rearward using the y-belt pulley at the front of the pipettor.
        6. Go back to the main step and determine if there is clearance between the probe tip and the recessed flat surface of the wash tower. Follow the steps for if there is clearance or if there is no clearance.
      • If there is no clearance:
        1. Select Motors > Enable X/Y Motor > Home Device > Move Z to Position.
        2. Step the alignment up one step.
        3. Select Alignments / Offsets > Preserve Offsets.
        4. Select Home Device > Move Z to Position > Motors > Disable X/Y Motor.
        5. Carefully move the pipettor carriage rearward using the y-belt pulley at the front of the pipettor.
        6. Determine if there still is no clearance between the probe tip and the recessed flat surface of the wash tower.
          • If there still is no clearance, then repeat the steps for "If there is no clearance:" until an offset change of one step causes the probe tip to barely clear the recessed flat surface of the wash tower.
          • If there is clearance, then proceed to the next step.
        7. Select Motors > Enable X/Y Motor > Home Device  > Move Z to Position.
        8. Select Alignments / Offsets > Save Alignments.
  13. Complete alignments.
    Caution: Homing all devices or only the reagent pipettors leaves them in a position that is not directly over the wash towers.
    1. Verify that all alignment tools are removed from the instrument.
    2. Exit the Alignments screen.
    3. Select Yes at the Do you want to home all moved devices? pop-up.
    4. Select Yes at the Do you want to save the alignments? pop-up.
    5. Initialize the instrument.
      The instrument places the reagent pipettors over the wash towers.
    6. Place the alignment tools into the specialty tool kit that remains with the instrument.
