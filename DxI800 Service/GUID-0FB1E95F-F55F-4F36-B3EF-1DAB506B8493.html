Using Check Disk

This procedure describes how to run the Check Disk function to repair the PC hard drive.

Use the Check Disk function to repair the hard drive when the PC or AU has a corrupt file. A corrupt file generally cannot be copied or deleted. The most common evidence of a corrupt file is the failure of the backup process when attempting to copy the file.
  1. Run Check Disk on the PC or AU hard drive.

    For Windows XP System:

    1. Select Start  > Run, and then type CMD on the Open text area. Select OK.
      Note: For the AU, run chkdsk from a remote desktop connection.
    2. Type chkdsk c: /f in the DOS command window and press [Enter].
    3. Type Y and press [Enter] at the Chkdsk cannot run because the volume is in use by another process. Would you like to schedule this volume to be checked the next time the system restarts? (Y/N) message.
    4. Reboot the PC or AU to run Check Disk when Windows restarts.
      Note:
      • For the AU with older Windows XP image, use the Task Manager and Command Prompt in the remote connection or the power switch to shutdown and restart Windows.
      • For the AU with latest Windows XP image, use Command Prompt in the remote connection or power switch to restart or shutdown Windows.
        • Open Command Prompt, and type shutdown.exe /r /t 00 and hit Enter to restart Windows.
        • Open Command Prompt, and type shutdown.exe /s /t 00 and hit Enter to shutdown Windows.
      • The results of the Check Disk run are displayed on the monitor and logged in the system events file. To review the Check Disk log, select Start > Run, type eventvwr, and then press [Enter] or OK. When Event Viewer opens, select Application. Scroll down and double-click on Winlogon. Winlogon is the log created after running Check Disk.

    For Windows 8 System:

    1. Press Windows key, select the Command Prompt icon or type cmd and open the program.
      Note: For the AU, run chkdsk from a remote desktop connection.
    2. Type chkdsk c: /f in the DOS command window and press [Enter].
    3. Type Y and press [Enter] at the Chkdsk cannot run because the volume is in use by another process. Would you like to schedule this volume to be checked the next time the system restarts? (Y/N) message.
    4. Reboot the PC or AU to run Check Disk when Windows restarts.
      For console PC:
      • Press Windows key, select Restart icon or type in restart, select settings > Turn off your PC > Power > Restart.
      Note: When rebooting the Privacy & Security compliant Windows 8 or Windows 10 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

      For AU:
      • Press Windows key, type in restart, select settings > Turn off your PC > Power > Restart.
      Note: The results of the Check Disk run are displayed on the monitor and logged in the system events file. To review the Check Disk log, Press Windows key, type view event, select Settings, and open the View event logs program. When Event Viewer opens, select Windows Logs > Application. Scroll down and double-click on Winlogon. Winlogon is the log created after running Check Disk.
  2. Review the Check Disk log and take the appropriate action.
    Problem Action to take
    Nothing found. No action.
    A corrupt harmless log file is fixed. No action.
    UI does not operate. Reload software.
    UI does not operate. Restore database.
    Errors running random applications. Reimage HDD / load software / restore database.
    HDD errors / lockups reoccurring. Replace HDD / load software / restore database.
