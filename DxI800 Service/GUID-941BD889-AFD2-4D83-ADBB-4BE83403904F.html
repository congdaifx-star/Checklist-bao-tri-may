Pipettor Matching Operating Principles

Purpose

This document provides an overview of the Pipettor Matching process.

Function

Any DxI reagent pipettor can process calibrations and test results, therefore the delivery from each pipettor must be within acceptable limits, and the results from each of the pipettors must agree with the results of any other pipettor. The pipettor matching routines help match the delivery volume and results from all the reagent pipettors to ensure that they can be used interchangeably when processing tests.

The pipettor Matching Routines are used to create and verify the pipettor adjustment factors. All three types of Matching Routines measure the RLUs of RVs containing unwashed 1:501 System Check and substrate. The system software analyzes the resulting RLUs and an adjustment factor is established for each pipettor.

Overview

This table describes the three types of Matching Routines.

Routine Description DxI 600 Replicates per Pipettor DxI 800 Replicates per Pipettor Assay Affected
Run Matching Calculates a Pump Correction Factor (PCF) for each pipettor. This calculation is performed at the completion of the Run Matching routine. The pipettor with the lowest mean RLU becomes the baseline pipettor with a Pump Correction Factor (PCF) of 1.000. All other pipettors are assigned PCFs in reference to the baseline pipettor.
Note:
  • The PCF is a stored constant that is applied to all precision pump actions. The DxI uses the PCF to mechanically adjust the number of motor steps required to deliver a specified volume.
  • The percent difference (%Diff) spec for Run Matching is higher than Pipettor Verify because Run Matching calculates the difference between pipettors without a matching factor applied. Verify Matching calculates the difference between pipettors with the matching factor applied and is therefore expected to be a smaller percent difference. Rules for Low Volume Matching Use

The low volume matching factor is a number applied to the calculated dose after samples are run. The APF (Assay Protocol File) specifies a correction variable for each low volume matching assay. This correction variable determines what percent of the Low Volume Correction Factor is used.

Low Volume Correction Factor = 1.0 + (LVCV x (1-(MeanPipRun / MeanPipCal))

Where

LVCV = Low Volume Correction Variable.

MeanPipRun = Mean Low Volume Pipettor Matching RLU for the pipettor assigned to the test.

MeanPipCal = Mean Low Volume Pipettor Matching RLU for the pipettor where the calibration occurred.
