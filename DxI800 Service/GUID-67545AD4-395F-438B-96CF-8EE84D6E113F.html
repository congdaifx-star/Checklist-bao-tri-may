Calibrating Wash Buffer Supply Bubble Detector

This procedure describes how to calibrate the wash buffer supply bubble detector sensor and the vacuum sensor monitoring the wash buffer supply to the upper reservoir.

Perform this calibration when the system fails a prime sequence and displays an event log message stating to calibrate the bubble detector.

This calibration detects the lack of fluid flow from the wash buffer supply containers to the wash towers during a pipettor wash sequence. General causes of this calibration failure:
  • Bubbles in the system caused by broken or cracked draw tube in the wash buffer containers.
  • Loose, broken, or defective fittings from the buffer containers to the bubble detector.
  • Pinched tubing from the containers to the bubble detector.
  • Poorly connected draw tube top fitting in the buffer supply drawer.
Calibrate the wash buffer supply bubble detector.
Note: Both wash buffer containers must be at least one-third full before calibrating the bubble detector.
  1. Select Diagnostic > Device Diagnostic > Analog Devices > Sensor Calibration > Wash Buffer Flow.

  2. Remove the rear wash buffer container cap and draw tube, select Start, and then follow the screen prompts.
    Note:
    • The straw must be removed from the fluid to draw air into the sensor to calibrate the sensor for bubbles.
    • Removing the clip at the top of the straw does not draw air into the sensor and calibration will fail.
  3. Allow the calibration sequence to complete.
  4. Reinstall the rear wash buffer container cap and draw tube.

  5. Select Continue.
  6. Allow for calibration sequence to complete.
  7. Read the message in the Calibration screen.

    If the message is:
    • Calibration complete, select Done to return the Device Diagnostics screen, then no action is required.
    • Calibration failed, select Done to return the Device Diagnostics screen, then review the screen for the failure cause and troubleshoot the system accordingly.
