Using TestAnalog

Purpose

This document provides information about the TestAnalog application.

When to Use

Use the Test Analog application to view the analog data present on the DAQC PCB.

The analog data is from sensors for:
  • Temperature
  • Voltage
  • Vacuum or pressure
  • Weight

Launching TestAnalog

  1. Open a network connection from the console PC to the AU.
    • For Windows NT, refer to the "pcAnywhere, Console PC to AU" procedure.
    • The Windows XP and Windows 8, refer to the Software: Using Desktop Sharing Between Console PC and AU procedure.
      Note: On Windows 8 system with Software 5.3.1 and above, the Test-Analog data channels are not displayed properly on the desktop sharing screen. To open and view the data channels properly, connect the monitor, mouse, and keyboard to the AU side.
  2. Double-click on the TestAnalog icon at the left edge of the AU desktop to open the TestAnalog application.
    Note: If there is no icon, then browse to C:\AU\TestAnalog.exe.
