DxI Software V5.7.0 Release Notes

Purpose
  • This document provides details of the significant features for DxI software version 5.7.0.
Confidentiality
  • Software release notes are confidential and should not be shared with customers.
Background
  • DxI Software version 5.7.0 was released to the field as optional MOD 12581 and as a manufacturing cut-in.
  • DxI software 5.7.0 can be installed only on Windows XPe and Windows 8e systems.
  • DxI software 5.7.0 requires special precautions when installing over prior software versions with POET databases (i.e. 5.1.0 & 5.2.0). Refer to MOD 12581 for details.
Feature Overview
  • LAS Duplicate Message - Fixed handling of duplicate message received from LAS (Lab Automation System). A duplicate message is one with a sequence number equal to or less than the currently processing message.
  • LAS Time out and retries - Set the retries communication messages, between the UniCel DxI instrument and the LAS system to 1 second interval. The current code does not observe a timeout resulting the DxI sending multiple message retries one immediately after another.
  • LAS Serial Communication - When DxI Instrument is connected to DxA5000 via serial port, while reading from/ writing to serial port, if the communication is disrupted, the error handling asserts instead of the performing expected function. Fixed this error handling in serial communication to continue responding to commands via serial communication between UniCel DxI and LAS.
  • AuComLogger - The communication logger, which stores serial communication logs from the Laboratory Information System (LIS), LAS and Integrated Systems (DxC), has a synchronization issue. The code change will eliminate a thread clash that was causing an access violation.
  • DB Trim - Deleted (not needed) Reagent Vessel (RV) temperature data stored in the database to reduce database size.
  • Language pack for DxI PROService on Chinese and Japanese - Updated the language localization package for Chinese and Japanese languages to send the correct characters in each language to PROService, instead of sending special characters like "???".
  • Timing window - Adjusted the timing error window to utilize the entire 9-second pitch for Wash Wheel operations. This change does not affect any established system timing of the assays.
  • PROService - PHI - Removed the Patient demographic details from Event terse and Verbose messages sent to PROService.
  • DVWaste Alignment point, (Specific.ini) - Includes with the UniCel DxI Software the "Specific.ini " configuration file with DVWaste value = 9.
Expected Behavior
  • Same as version 5.6.0 with privacy & security features and fixed software bugs.
