Pipettor Matching

This procedure describes how to run three DxI routines: pipettor matching, verify matching, and low volume matching.

This document provides instructions for these DxI routines:
  • Run Matching (pipettor matching)
  • Verify Matching
  • Low Volume Matching
Note:
  • The pipettor matching routines are used to create and verify reagent pipettor adjustment and correction factors. These factors ensure that all pipettors can be used interchangeably when processing tests. For more information, refer to the Instrument OP: Pipettor Matching document.
  • If one or more pipettors are disabled, matching routines cannot be performed
  • The DxI 800 instrument performs matching routines across four pipettors, while the DxI 600 instrument performs the tests across two pipettors.

  1. Review and print results of previous pipettor matching runs.
    1. From the Main Menu, select Maintenance Review  > Pipettor Matching Reag. Pipettor Matching or Low Volume Matching.
      Pipettor matching routines cannot be initiated from this window.
    2. Select Print to print current results sorted by pipettor and overall statistics.
  2. Perform these steps to run matching (pipettor matching) routine.
    Note:
    • Pipettor matching routines cannot be performed, if one or more pipettors are disabled.
    • After performing the run matching routine, run the low volume matching routine.
    1. From the Main Menu, select Sample Manager > New Request > Maintenance, and then select the Run Matching option from the Other Routines field and select OK.
    2. Enter the Rack ID when prompted.
    3. Place four sample tubes into the sample rack, fill each tube with a minimum of 3 mL of 1:501 solution, and then load the rack onto the SPU.
      Note:
      • 1:501 system check can be made by adding 50 µL of system check solution to 25 mL of wash buffer.
      • The rack must be configured for the tube type used and all four tubes must be the same size.
      • The same dilution of 1:501 system check must be used for all four samples.
      • If the run fails, then start with fresh tubes of 1:501 system check. Adding more 1:501 system check to previously pipetted tubes might cause failure of the precision specifications, even if the original dilution is used.
    4. After the test is complete, select Maintenance Review > Pipettor Matching > Reag. Pipettor Matching.
    5. Analyze the results.
      If Then
      Status = Passed Select Accept to accept and save the new results, and then calibrate the process monitoring sensors for the reagent pipettors.
      1. From the Main Menu, select Diagnostics  > Device Diagnostics > Analog Devices > Sensor Calibrations > Pressure.
      2. Calibrate all sensors.
      3. Perform a low-volume matching routine. Proceed to low-volume matching step.
      Status = Failed Note the reason for failure in the Reason field. Select Cancel to discard the results and retain the previous results. Proceed to troubleshooting. Refer to the Tests: Pipettor Matching Troubleshooting document.
  3. Perform these steps to run the low-volume matching routine.
    1. From the Main Menu, select Sample Manager > New Request > Maintenance, select the Low Volume Matching option from Other Routines, and then select OK.
    2. Enter the Rack ID when prompted.
    3. Place four sample tubes into the sample rack, fill each tube with a minimum of 3 mL of 1:501 solution, and then load the rack onto the SPU.
      Note:
      • 1:501 system check can be made by adding 50 µL of system check solution to 25 mL of wash buffer.
      • The rack must be configured for the tube type used and all four tubes must be the same size.
      • The same dilution of 1:501 system check must be used for all four samples.
      • If the run fails, then start with fresh tubes of 1:501 system check. Adding more 1:501 system check to previously pipetted tubes might cause failure of the precision specifications, even if the original dilution is used.
    4. After the test is complete, select Maintenance Review > Pipettor Matching > Low Volume Matching.
    5. Analyze the results.
      If Then
      Status = Passed The new correction factors are saved. Proceed to the Verify system performance step.
      Status = Failed The previous factors are retained. Note the reason for failure in the Reason field. Proceed to troubleshooting. Refer to the Tests: Pipettor Matching Troubleshooting document.
  4. Perform these steps to run the verify matching routine.
    1. From the Main Menu, select Sample Manager > New Request > Maintenance, and then select the Verify Matching option from the Other Routines field, and select OK.
    2. Enter the Rack ID when prompted.
    3. Place four sample tubes into the sample rack, fill each tube with a minimum of 3 mL of 1:501 solution, and then load the rack onto the SPU.
      Note:
      • Make 1:501 system check by adding 50 µL of system check solution to 25 mL of wash buffer.
      • Configure the rack for the tube type used and use the same size tubes for all four tubes.
      • Use the same dilution of 1:501 system check for all four samples.
      • If the run fails, then start with fresh tubes of 1:501 system check. Adding more 1:501 system check to previously pipetted tubes might cause failure of the precision specifications, even if the original dilution is used.
    4. After the test is complete, select Maintenance Review > Pipettor Matching > Reag. Pipettor Matching.
    5. Determine if the routine passed or failed.
      Caution: The person running the test must determine from the results if the verify matching routine passed or failed. The software does not monitor the % Difference or PCF values, and even with a status of Passed displayed, the test might not have passed.
      Passing criteria:
      • % Difference </=1.50% for all pipettors and status
      • Status = Passed
    6. Analyze the results.
      If Then
      Status = Passed Proceed to the Verify system performance step.
      Status = Failed Proceed to troubleshooting. Refer to the Tests: Pipettor Matching Troubleshooting document.
  5. Verify system performance after running the Run Matching or Low Volume Matching routines.
    Caution: Ensure that all matching routines have passed prior to verifying system performance.
    1. If the customer runs dil assays and new Pipettor Matching values have been accepted, then perform the Dil Factor Adjustment procedures.
      Note:
      • The Dil Factor Adjustment Procedures must be performed on all pipettors after accepting new Pipettor Matching Values.
      • The procedures are located in the Support Documents and Procedures section of the Access Applications Service Manua.
    2. Perform system verification as stated in the Admin: Verification of Service Repair document.
