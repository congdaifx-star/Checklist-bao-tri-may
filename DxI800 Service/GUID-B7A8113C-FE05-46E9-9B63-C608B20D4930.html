PCB - Interface - Substrate

This document provides these details for the Substrate Interface PCB:
  • Drawings.
  • Details (Test Points, LEDs, Connector Overview, Connector Pin-outs).
  • Schematics.
  • Location.

Drawings

Details

The Substrate Interface PCB connects to these devices:
  • Substrate Pump.
  • Substrate Loader Assembly.
  • MCC Backplane (MCC6, MCC4) PCBs.
