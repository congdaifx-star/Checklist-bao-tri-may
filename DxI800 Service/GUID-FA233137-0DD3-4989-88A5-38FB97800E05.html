DxI Software V5.6.0 Release Notes

Purpose
  • This document provides details of the significant features for DxI software version 5.6.0.
Confidentiality
  • Software release notes are confidential and should not be shared with customers.

Background

  • DxI Software version 5.6.0 was released as MOD 12482 for systems connected to DxA automation and expected to be released as a manufacturing cut-in.
  • DxI Software version 5.6.0 corrects a bug causing a UI lock-up and crash when left in the reagent inventory screen for a long period of time. The software also corrects an AUObject crash due to a message collision that can occur on systems connected to DxA automation (not likely to affect Power Express or Power Processor connected systems).
  • DxI software 5.6.0 can be installed only on Windows XPe and Windows 8e systems.

Feature Overview

  • Removal of the "System Check Passed" Event Log message.
  • Application code signing (required for privacy & security features).
  • Fixed UI crash when in the Reagent Inventory screen.
  • Fixed an AUObject crash that can occur on systems connected to DxA automation.
  • Fixes to Restore Utility (correct reagent pack counts).

Expected Behavior

  • Same as version 5.5.0 with privacy& security features and fixed software bugs.
