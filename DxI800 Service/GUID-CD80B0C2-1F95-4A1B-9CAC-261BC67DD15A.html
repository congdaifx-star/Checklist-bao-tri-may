Servicing Instruments Connected to LAS

This procedure describes how to service a DxI instrument that is connected to a lab automation system (LAS).

Perform this procedure when service activities require:
  • more than 30 minutes down-time,
  • performance verification before resuming operations,
  • opening front covers and bypassing interlock switches, or
  • removal of the upper rear cover.
General Information:
  • LAS sample tubes continue loading into the connection unit regardless of the operational status of the DxI instrument. The PrepLink Loading Paused option stops tubes from loading into the connection unit.
  • The DxI instrument automatically begins running LAS samples whenever:
    • the DxI instrument is in Ready mode or Running mode AND
    • LAS sample tubes are in the connection unit.

    The Offline option of the DxI LAS mode is used to prevent unwanted automatic sampling.

  • Various service activities can require:
    • Releasing captive tubes from the connection unit.
    • Separating the DxI instrument from the connection unit.
    • Temporarily halting or blocking travel of LAS tubes.
  1. Pause the LAS sample tube loading.
    1. On the PrepLink Console, select Setup > Instrument Loading .
    2. Select the correct CONN-X Loading Paused option (X = 1,2,3, or 4).
      The DxI instrument connection units are labeled CONN-1 through CONN-4, according to how many DxI instruments are connected to the LAS.
    3. Before proceeding, verify that the selected DxI instrument has completed processing all samples.
  2. Pause the DxI instrument from running LAS samples.
    Setting the LAS mode to Offline prevents the instrument from running LAS samples prematurely or actuating sample pipettor movements during servicing.
    Caution: To prevent LAS samples from running automatically, set the LAS mode to Offline before initializing the DxI instrument.
    Note: If the user interface on the DxI instrument is not responsive, disconnect the serial communication cable from the DxI instrument to the connection unit.
    1. If the DxI instrument is still processing samples, allow the instrument to complete all samples before proceeding.
    2. On the DxI Console, select Menu > Configure > LIS/LAS > LAS, and then select Offline from the LAS Mode menu.
    3. Select OK.
  3. Release the captive tubes from the connection unit.
    If the DxI instrument became inoperable while LAS tubes were in the connection unit (or if the tubes were sorted to an inoperable DxI instrument), then sample tubes are captive and must be released back to the LAS.
    Caution: Release captive sample tubes whenever service procedures require:
    • Total downtime to exceed 30 minutes, or
    • Removal of the DxI upper rear cover or SPOTB housing.
    1. Inspect the connection unit for captive tubes lined up behind the bar code readers or at the aspiration position. If there are no captive tubes, skip this entire step.
    2. Before proceeding, inform an operator that these samples were not run on the DxI.
      • The operator may want to record the IDs from these tubes to facilitate their retrieval later.
      • When DxI operations resume, these tubes must be:
        • Reprogrammed and run from the LAS, or
        • Placed in sample racks and run from the SPU.
    3. Verify that the sample probe is clear of the path of tube travel.
    4. On the connection keypad, press the [Auto / Manual] key until Manual mode is indicated.
    5. Press the [+] key until 01 is displayed.
    6. Press the[Enter] key. This action releases the captive tubes from the connection unit.
    7. When all tubes have exited the connection unit, press the [Auto / Manual] key until Auto mode is displayed.
  4. Refer to the table for the correct steps to take in servicing the instrument.
    If service involves Then separation is Do this
    Lower rear of the instrument required
    1. Mark outlines of the locations and height adjustments of the DxI instrument leveling feet, and then lower the DxI instrument onto the wheels by rotating the leveling feet upward.
    2. Carefully roll the DxI away from the connection unit to allow sufficient room to service the DxI.
    3. Service the instrument.
    4. Attach the DxI and LAS. Refer to the LAS: Attaching DxI to LAS Connection Unitprocedure.
    Front or upper rear of the instrument not required
    1. If servicing involves leaning on or near the LAS track, then it may be necessary to halt all LAS sample tubes temporarily. Halting LAS sample tubes can be accomplished by:
      • Having an operator temporarily shutdown the entire LAS line, OR
      • Placing blocks across the LAS track (from both directions) to hold back sample tubes temporarily for brief periods.
        Note: LAS tubes approach from both directions. Blocking both approaches is required.
    2. Service the DxI instrument.
    3. Proceed with the remaining steps in this procedure.
  5. Resume the DxI sample processing.
    Warning: Performing the steps to resume LAS operation causes the DxI instrument to run LAS samples automatically.
    1. If the serial communication cable to the connection unit was disconnected, reconnect it.
    2. On the DxI Console, select Menu > Configure > LIS/LAS > LAS, and then select Online.
    3. Select OK.
  6. Configure the LAS operations.
    1. On the DxI Console, select Diagnostics > LIS/LAS > LAS > Track Comm. Test.
    2. Verify that the DxI instrument responds with COMM diagnostics test passed.
    3. Exit Diagnostics and return to the Ready mode .
  7. Reset the connection unit.
    Caution: If the connection unit is not reset to normal mode following usage of the 50 and 51 codes for manually loading tubes, the connection unit will not operate correctly.
    1. Remove the access panel from the rear of the connection unit.
    2. Locate the green power switch inside the connection unit (on the lower left).
    3. Power off the connection unit for 15 seconds, and then power on the connection unit.
    4. Press the [Auto / Manual] key on the connection keypad twice, to return to auto mode.
    5. Press the [Auto / Manual] key on the track keypad twice, to return to auto mode.
    6. Reinstall the access panel on the connection unit.
  8. Ensure that all required PV (performance verification) activities such as System Checks and QC runs have completed satisfactorily before proceeding. For DxI PV requirements, refer to Admin: Verification of Service Repair.
  9. Resume the LAS sample tube loading.
    1. On the PrepLink Console, select Setup > Instrument Loading tab.
    2. Clear the CONN-X Loading Paused check box.
      The DxI instrument connection units are labeled CONN-1 through CONN-4, according to the number of DxI instruments connected to the LAS.
    3. Observe while the DxI instrument runs a minimum of ten samples from the LAS. Confirm that all tubes are processed correctly through the connection unit and that all samples are aspirated and run correctly by the DxI instrument.
      Note: If captive tubes were released from the connection unit, then errors will show in the event log, as expected for tubes that had processed beyond the query BCR before release.
