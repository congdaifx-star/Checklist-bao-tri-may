Rinsing and Priming Dry (Prime Dry Method)

This procedure describes how to rinse and prime dry a DxI instrument. Rinsing and Priming Dry is the first of four procedures for deinstalling a DxI instrument. Perform this procedure when preparing an instrument for storage or deinstalling an instrument to be shipped to another site or returned to Chaska.

Required Materials

  • 5 mL of Contrad.
  • 5 mL of 1:5 Citranox dilution (1 part Citranox to 4 parts of deionized water).
  • 5 mL of methanol or ethanol dilution (7 parts methanol or ethanol and 3 parts Wash Buffer II).
  • 100 mL of 1:5 Contrad dilution (1 part Contrad to 4 parts deionized water)
  • DI water.
  • Lint-free towels.
Note: This procedure describes rinsing and priming without using siphoning equipment—the Prime Dry Method. The Prime Dry Method takes approximately 1 hour longer than the Siphon Method.

This procedure is the first of four procedures for deinstalling a DxI. All four procedures are summarized in the Deinstall Quick Reference. If an instrument is being moved within a building or temporarily stored, not all procedures are necessary. When performing the deinstallation procedures, consider:

  • Moving and shipping conditions
  • Final destination
  • Environmental issues
Perform this procedure when:
  • Preparing an instrument for storage.
  • Deinstalling an instrument to be shipped to another site or returned to Chaska.
  1. Prepare the instrument for flushing or siphoning.
    1. Run a Special Clean.
    2. Remove all reagent packs and racks from the instrument.
    3. Confirm at least one substrate bottle is installed on the DxI.
    4. Empty the liquid waste containers and reinstall into the instrument.
    5. Open the main upper left cover and insert a cover interlock switch bypass.
    6. Initialize the instrument.
    7. Select Maintenance Review  > Disable Utility Routine.
  2. Flush the upper wash buffer system when siphoning equipment is unavailable. (Prime Dry Method)
    1. Replace both wash buffer containers with containers filled with DI water.
    2. Prime DI water into the instrument.
      1. From the Prime Fluidics screen, select Disable Process Monitoring.
      2. Prime using one of these options:
        • If the instrument is a DxI 600, then prime all reagent pipettors 40 times each.
        • If the instrument is a DxI 800, then prime all reagent pipettors 20 times each.
    3. From the Main Menu, select Supplies > Bulk Supplies > Change In-use Bottle > Wash Buffer.
    4. From the Prime Fluidics screen, select Disable Process Monitoring.
    5. Prime the DI water into the instrument. using one of these options:
      1. From the Prime Fluidics screen, select Disable Process Monitoring.
      2. Prime using one of these options:
        • If the instrument is a DxI 600, then prime all reagent pipettors 40 times each.
        • If the instrument is a DxI 800, then prime all reagent pipettors 20 times each.
    6. Remove both draw straws from the wash buffer containers.
    7. Prime using one of these options:
      • If the instrument is a DxI 600, then prime all reagent pipettors 260 times each.
      • If the instrument is a DxI 800, then prime all reagent pipettors 130 times each.
      Note:
      • Leave process monitoring disabled.
      • During this process, the upper reservoir drains and the system enters Not Ready mode. Continue to allow the reagent pipettors to prime.
    8. Verify that the upper reservoir has been primed dry.
    9. Reinstall the draw straws in the wash buffer cubes.
    10. Initialize the system.
      The system may need to be initialized more than once to come to the Not Ready state. During this process, the upper reservoir fills to at least the reserve level.
    11. Prime the DI water through the instrument.
      1. From the Prime Fluidics screen, select Disable Process Monitoring.
      2. Prime all reagent pipettors, the sample pipettor, and the dispense probe10 times each.
  3. Prime the wash buffer system dry. (Dry Method)
    1. Remove the draw straws from both wash buffer containers.
    2. Prime out the DI water.
      1. From the Prime Fluidics screen, select Disable Process Monitoring.
      2. Prime using one of these options:
        • If the instrument is a DxI 600, then prime all reagent pipettors 40 times each.
        • If the instrument is a DxI 800, then prime all reagent pipettors 20 times each.
    3. From the Main Menu, select Supplies > Bulk Supplies > Change In-use Bottle > Wash Buffer.
    4. Prime the fluidics system dry.
      1. From the Prime Fluidics screen, select Disable Process Monitoring.
      2. Prime using one of these options:
        • If the instrument is a DxI 600, then prime all reagent pipettors 260 times each.
        • If the instrument is a DxI 800, then prime all reagent pipettors 130 times each.
      Note: During this process, the upper reservoir drains and the system enters the Not Ready state. Continue to allow the reagent pipettors to prime.
    5. Drain the sample pipettor tubing and dispense probe tubing.
      1. Place the sample pipettor over the wash tower.
      2. Place the three dispense probes and aspirate probe 1 in a small container to prevent wash buffer from draining into the wash wheel.
      3. Select Device Diagnostics > Digital Devices > Digital Outputs.
      4. Select Vacuum Pump 1.
      5. Select Toggle Output Value to turn on the vacuum pump to the sample wash tower.
      6. Remove the red-white quick-disconnects from these connections:
        • Sample pump
        • Fluidics reservoir: D1, D2, D3
        • Aspirate probe 1 (on the front of the pressure sensor, on the far right side of the fluidics reservoir)
      7. Select Toggle Output Valueto turn off the vacuum pump.
      8. Select Done.
      9. Reconnect the red-white quick-disconnects.
  4. Decontaminate the substrate system.
    1. In the user interface, select Maintenance Review > Decontaminate Substrate.
      Note: Do not initialize the instrument. Decontamination can be performed in the Not Ready state (because of the empty upper reservoir).
    2. Select OK to proceed with the decontamination process.
      Note: Once started, all steps of the decontamination process must be completed. If a step is canceled, then the entire process must be repeated. The status is stored in the instrument NVRAM.
    3. In the Decontaminate Substrate window, enter 300 as the dwelling time (in seconds), and then select Next.
    4. Remove both substrate bottles, rinse them with DI water, and fill each bottle with 50 mL of 1:5 Contrad.
    5. Install the bottles containing the diluted Contrad, and select Next.
    6. When air-priming is complete, remove the two substrate bottles and empty them, and then wipe both substrate draw tubes with a lint-free towel.
    7. Select the Empty Bottles - Service Use Only option, and then select Next.
      Note: Selecting New Substrate Bottles requires scanning the bar code labels on the new substrate bottles.
    8. Install the two empty substrate bottles, and then select Next.
    9. When the priming is complete, select Done.
      The instrument is in the Not Ready state.
    If Then
    Substrate decontamination fails
    1. Isolate and resolve the failure.
    2. Load one new substrate bottle.
      Note: If a substrate bottle is unavailable, contact Systems Technical Support for a bar code label to use temporarily.
    3. Flip the upper reservoir float sensor to simulate a full condition.
    4. Initialize the instrument.
      Note: The instrument transitions to Ready mode and then Not Ready mode because the substrate decontamination is incomplete.
    5. Restart substrate decontamination.
  5. Complete the rinsing and priming process.
    1. If the instrument was siphoned dry, then reinstall the float sensor and float sensor screw.
    2. Remove the wash buffer containers from the instrument.
    3. Rinse the wash buffer draw straws with DI water. Dry and wrap the draw straws in lint-free towels. Place the draw straws inside empty wash buffer drawers.
    4. Empty the liquid waste containers.
    5. Remove the solid waste bag.
      • If the instrument is being shipped to a new location, then leave the solid waste bin empty.
      • If the instrument is remaining onsite, then place a clean solid waste bag in the bin.
  6. When you have completed the procedure do one of the following:
    • If the instrument will be shipped or requires decontamination, then continue to the Deinstalling: Decontaminating and Cleaning procedure.
    • If the instrument will remain onsite and does not require decontamination, then power down the instrument and PC, remove all interlock bypasses, and replace all the covers.
