Documents Required for Installing a UniCel DxI

Purpose

This document provides access to the documents necessary for installing a DxI.

Procedures

Document Title Description Information/Location/Link
DxI Installation Procedure Detailed instructions for installing a UniCel DxI system. Installing DxI Instrument

IP: Installing DxI Instrument in Integrated System
Installation Record Form for recording customer and system information and completion of procedural steps for installation. This document may be completed electronically or manually.
To complete electronically:
  • Launch the document. The cursor is in the first form field.
  • Enter the requested information.
  • Press the [Tab] key to advance the next form field.
  • When finished, select Save As, rename the file, and save the file to the desired location on your hard drive.
  • E-mail the completed form to the DxI support team leader.
DxI Install Record.doc
Assay Implementation Guide Procedures and worksheets provided in document.
Note: When performing crossover correlation studies comparing a DxI to an Access or Access 2, it is important to eliminate as many potential variables as possible by observing the following conditions:
  • Use the same reagent pack and calibrator lots for both the test and reference systems.
  • Perform calibrations and measure samples on both systems on the same day.
From the customer manual: "UniCel DxI Installation Implementation Guide", P/N 986183 986184C.pdf
Assay Verification Parameters Lists units, sample type, reportable range, expected values, expected imprecision, and diluent used for each Access assay. Intended for use as a quick reference when performing assay verification studies at system installations. Access Applications Manual
Dil-Assay Correction Factor Procedures for DxI Systems Procedures and Templates for Dil-Ferritin, Dil-BhCG and Dil-AFP Access Applications Manual
Sample Volume Calculation Chart Launch the spreadsheet and perform the instructions as indicated. Volume LookUp-DxI-v11.xls
Pipettor Matching Routines Detailed instructions for running the Pipettor Matching Routines on the DxI system. Access Applications Manual
Sales Group Information Sales Group Part Numbers for NAO and International. Access Applications Manual
