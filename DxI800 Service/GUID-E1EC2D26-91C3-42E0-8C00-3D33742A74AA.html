Calibrating Pump Pressure Sensors (Sample and Precision)

This procedure describes how to calibrate the pressure sensors for the sample and precision pumps.

Calibrate the pressure sensors for the sample and precision pumps when:
  • replacing a sample or precision pump.
  • replacing a sample or precision pump pressure sensor.
  • replacing sample or precision pump tubing or belt.
  • replacing a sample pump valve.
  • replacing a transducer.
  • completing pipettor matching.
  • performing a PM.
  • installing an instrument.

For issues that arise during the Pressure Sensor Calibration, troubleshooting can be found in the Fluidics: Troubleshoot Pumps (Sample/Wash/Precision) document.

  1. Calibrate the pressure sensor.
    Note: Pressure sensor calibration erases the values used for pack process monitoring, which is part of software versions 4.0 and higher. The instrument begins collecting new data to obtain new pack process monitoring values. Refer to the Fluidics OP: Reagent Pack Process Monitoring document.
    1. Select Diagnostic > Device Diagnostic.
    2. Select Analog Devices > Sensor Calibration  > Pressure.
    3. To calibrate all pumps, select Determine All Curves. To calibrate a single pump, select the option for the pump, and then select Determine Curve.
  2. Verify system operation.
    1. Perform system verification as stated in the Verification of Service Repair document .
      Refer to the Admin: Verification of Service Repair document.
