Data Backup Overview

This document provides details of what happens during the backup process.

Backup Overview

The DxI system provides the user with two backup methods:
  • Immediate backup
  • Automatic scheduled backup
For both scheduled and immediate backups, the system saves data into the backup device and into a backup folder on the PC. The data saved is:
  • Nexstep registry
  • Workgroup settings
  • Application executables and dlls
  • NexStep database (Results, Cal Curves, QCs, etc.)
  • Event Log database
  • AU alignment file (specific.ini)
  • Instrument logging files

Backup Information

Step Action Description
1 Backup checks the workgroup status to make sure the system is ready. A backup can be launched at any time. However, it is best to run a backup when the instrument is in the Ready or Not Ready mode. If the operator requests a backup when the instrument is in Running or Paused mode, the system displays a warning. If the system is in Running or Paused mode at the scheduled backup time, the scheduled backup is postponed and rescheduled. Performing a backup when the instrument is in Ready mode, ensures that the database is in the best state if it is needed for restoration.
2 Backup takes a snapshot of the database and registry and then copies the files into a backup folder on the PC hard drive of the server. This step takes several seconds. Normal operation of the system is not interrupted.
3 The system launches the NT Backup program (for writing to the backup tape). During this step, the backup process copies the files from the backup folder on the PC to the tape (or to the USB BACKUPDRIVE, if available). This step can take several minutes, depending on the system database size, but it does not interrupt the normal operation of the system.
Note: Do not use NT Backup when performing a backup to a USB backup drive.
4 The system displays a Backup Report. When the NT Backup process is completed, the system displays a backup report. Three results are possible from the backup process. The results and corresponding messages are on the Backup Report.
  • Successful
  • User Aborted
  • Failed
Note:
  • For both Scheduled Backup and Immediate Backup, the operator is responsible for labeling tapes and making sure that the correct tape is in the drive for the next backup.
  • The backup overwrites the contents of the tape in the tape drive or the contents of the USB backup drive.
