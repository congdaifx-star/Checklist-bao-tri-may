Database - Clearing DxC Unable to Update Control Lot Error for DxI Software V4.2 or Lower.

This procedure describes how to clear a DxC Unable to Update Control Lot Event Log error.

This procedure applies to integrated DxI instruments that use software V4.2 or lower. Perform this procedure when DxC Unable to Update Control Lot appears in the Event Log.

Note: For DxI software V4.1, this error can cause the user interface to lock-up.
  1. Prepare the instrument.
    1. Wait for any in-progress samples to complete.
    2. Select Sample Manager > Work Pending > Print to print a copy of the samples in work pending.
      Note: Any samples in work pending will need to be reloaded after this procedure to complete the tests. The printed copy of work pending will assist the customer in reloading the samples.
    3. Select Delete to clear all work pending requests.
    4. Perform a database consistency check.
      Note: Refer to the Software: Database - Performing Database Consistency Check procedure. Do not launch the user interface at the end of the Database Consistency Check procedure.
  2. Open the Poet or Fast database application.

    For Windows XP console PC with DxI Software 5.2 and below or Access2 Software 3.4.2 and below:

    1. From the Windows Desktop on the console PC, select Start > Programs > NexGen (or Access2) > Poet Developer or Poet Administrator.
    2. In Poet browser, select File > Open Database.
    3. In the Host field, enter LOCALHOST. In the Database field, enter NexStepBase. Select OK.
      Note: NexStepBase is case-sensitive.
    4. Select Objects > Browse Extent.

    For Windows 8 Mini PC with DxI Software 5.3.1 and above or Access2 Software 3.4.3 and above:

    Note: DxI Software 5.3.1 and Access2 Software 3.4.3 are compatible with Windows XP console PC. If either software was installed on the Windows XP console PC, then follow the Windows XP section to launch Fast database application. Poet database application is replaced by Fast database application.
    1. Press Windows key, select Fast Developer or Fast Administrator icon or type developer or administrator and open the program.
    2. In Fast browser, select File > Open Database.
    3. In the Host field, enter LOCALHOST. In the Database field, enter NexStepBase. Select OK.

      Note: NexStepBase is case-sensitive.
    4. Select Objects > Browse Extent.
  3. Clear the DxC Unable to Update Control Lot error using the POET developer.
    1. Execute a query.
      1. In the Extent Explorer window of the POET database, select OQL > New Query from the top menu.
      2. In the query window, type SELECT * FROM BPtTestResultExtent WHERE m_eTestResultState < 10.
        Note: The query text is case-sensitive.
      3. Select OQL > Execute Query. A pop-up window displays the search results.
    2. Edit the TestResultState.
      1. Double-click to open the first result in the query.
      2. Locate the m_eSampleTubeState entry on the right side of the screen.
      3. Highlight m_eSampleTubeState.
      4. Right-click and select Edit, and then change the number to 10.
      5. Select OK.
    3. Highlight the top line (PTObjID) of the left side of the split screen, then right-click on the object and select Store.
    4. Edit the TestState.
      1. Highlight BPtRepResult on the bottom line on the left side of the screen
      2. Double-click on the first line on the right side of the screen to open the file.
      3. Locate the m_eTestState entry on the right side of the screen.
      4. Highlight m_eSampleTubeState.
      5. Right-click and select Edit, and then change the number to 10.
      6. Select OK.
      7. Right-click on m_eTestState again and select Store.
    5. Close the PtObjID windows to return to the original query window.
    6. For each additional line in the query, edit theTestResultState, edit the TestState, and close the PtObjID windows to return to the original query window.
      Note: If the query window is inadvertently closed, it can be reopened by repeating the step: Execute a query.
    7. When all lines in the query have been edited, close the POET developer.
  4. Perform a database consistency check.
    Note: Refer to the Software: Database - Performing Database Consistency Check procedure.
  5. Select Start > Programs > NexGen > NexGenUI UD to launch the user interface.
  6. Check the Event Log and verify that the DxC Unable to Update Control Lot error message is no longer occurring.
