Software V4.1 Release Notes

Purpose

This document provides details of the most significant features and enhancements in DxI software version 4.1.

Confidentiality

Software release notes are confidential and should not be shared with customers.

Obsoleted Mods

Once this version of software is installed on an instrument, these Mods are no longer applicable to it:
  • Mod 6846 - Software Version 2.3 - Install
  • Mod 10028 - Software Version 2.4 - Install

Hardware Changes Enabled

These major hardware changes are included in this software version:
  • Integrated system capability (DxC 880i).
  • Vacuum sensor baseline calibration for a new vacuum/peristaltic interface PCB.
  • USB backup capability.

Enhancements

These enhancements are included in this software version:
  • Operating System upgraded to Windows XP.
  • Windows Desktop Sharing replaces pcAnywhere to access the AU.
    • Refer to the Software: Using Desktop Sharing Between Console PC and AU procedure for more details.
    • Refer to the Software: Using Desktop Sharing for File Transfer Between Console PC and AU procedure for more details.
  • System configurable to use Standard Reserve Volume and Flexible Reserve Volume feature.
    • Reference Instrument: Reserve Volume - Flexible and Standard for more details.
  • New flag (CLX) added for a calibration run on an expired calibrator lot.
  • New process monitoring algorithm for reagent delivery (empty pack detection).
    • Reference Fluidics: Reagent Pack Process Monitoring Operating Principles for more details
  • Level 1 Ultrasonics mix voltage decreased from 62 Vrms to 50 Vrms (for new instruments only).
  • Optimized sample pipettor wash is enabled when software is installed.
  • Dark count checkis not taken if the empty position is next to a sample in the wash wheel.
  • Reduced memory leaks in AU and PC.
  • Expanded event log troubleshooting.
  • Low volume sample rack (880i only) feature that allows a sample vessel (SV) to be picked by the dual-gantry pick-and-place.
  • APF load changed to prevent a partial APF load.
  • Added a slippage check for the sample pipettor on a SPOTB automation gantry when a carrier times out.
  • Debug logging is disabled by default. If debug logging is enabled, an event log message is posted.
    Note:
    • Log file verbosity is set too high informational message is posted in the Event Log, if any logging is set to yes.
    • Event log message details indicate which parameter in specific.ini is set to yes.

Diagnostics Improvements

These improvements to Diagnostics are included in this version:
  • Automated Carryover Procedure
    • Refer to the Tests: Automated Carryover Test procedure for more details
  • RV Exerciser Improvements
    • Realistic ejector plate timing
    • Pick-and-place and carriage movements now more like assay operation
    • RV collet of sample pick-and-place now used for Reaction Route 1 and 2
    • Capability to test the dual-gantry sample pipettor (880i)
  • Volume check dispense slowed down to minimize bubbles.
  • Level sense test now uses sample vessel instead of dilution vessel.
  • Volume check for sample pipettor now works for dual gantry (880i) and SPOTB gantry.
