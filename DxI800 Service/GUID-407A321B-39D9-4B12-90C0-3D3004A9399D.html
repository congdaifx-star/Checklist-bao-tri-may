VSR: Acceptable Data to be Collected

The following table contains examples of acceptable data that can be collected to show objective evidence that the service activity is complete and the instrument is verified to return to service. These are only examples of data and other forms may be also be acceptable.

Verification Data to be Collected Examples of Acceptable Data
System check printout

-OR-

HS system check printout
Carryover printout
Pipettor matching printout
Low volume matching printout
Luminometer dark count printout
QC printout
Precision run printout
Method correlation printout
Ultrasonic level sense test printout
RF level sense test printout
Dil assay correction factor printout
Assay calibration printout
dTest printout
Temperature printout
Ultrasonic voltage adjustment printout
