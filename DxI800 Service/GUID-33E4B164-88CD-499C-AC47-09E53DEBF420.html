CPU PCB Operating Principles

This document details the operating principles for the CPU PCB.

PCB Function

The CPU PCB performs these functions:
  • System control
  • Mathematic calculations
  • Logic decisions
  • Memory registers
  • Memory cache
  • RAM
  • ROM
  • Assorted logic functions
  • Executes AU software
  • Miscellaneous input/output interfaces

PCB Location

Component Locations

Specific information regarding the components for this PCB is not provided. Service personnel are advised not to change or repair any PCB unless directed to do so by STS Chaska.

PCB Features and Functions

This PCB is an off-the-shelf (store-bought standard) single-board computer. At the time of this writing, the current computer is a Pentium III running at a minimum of 1.2 GHZ. Certainly, the computer will change as newer technology is released. The minimum requirements of this board are:
  • Pentium III or higher
  • 1.2 GHZ or higher with standard PC support logic
  • PCIMG bus (PCI bus and ISA bus connectors)
  • 512k cache memory
  • 256 MB RAM minimum
  • ATA100 hard drive interface
  • IDE CD ROM interfaces
  • Standard floppy drive interface (not used)
  • Two standard serial interfaces
  • One printer interface (not used)
  • Ethernet interface (10/100 base TX)

Interacting Devices

The CPU PCB is responsible for the entire AU function; however, the PCB is connected to only a limited number of devices that send and receive data and channel it to the CPU. The following devices are directly connected and controlled by the CPU PCB.
  • ISA and PCI busses.
  • Communications PCB.
  • Data acquisition and control PCB.
  • CPU backplane PCB.
  • Hard disk drive.
  • Network hub.
  • Video display (only when connected to the AU, not the normal user interface PC).
  • Keyboard and mouse (only when connected to the AU, not the normal user interface PC).
