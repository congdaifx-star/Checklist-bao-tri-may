Tool Kits - Specialty

This document provides information on the UniCel DxI Specialty Tools and Upgrade Tools.

Specialty Tool Kit

The specialty and adjustment tool kit was created for service personnel to easily acquire all necessary adjustment and alignment tools for DxI.
  • Specialty Kit:
    • Seven tools (ten total pieces) are in the specialty tool kit.
  • Upgrade Kit:
    • To create a full tool kit for the instrument, service personnel can also order individual tools or the upgrade tool kit.
    • Three revised or new tools are available - Green vessel-shaped alignment tool, the aspirate probe plate tools, and the redesigned dispense probe plate tools that have a clearance hole for the substrate probe.
