DxI Software V5.3.0 Release Notes

Purpose
  • This document provides details of the most significant features and enhancements in DxI software v5.3.0
Confidentiality
  • Software release notes are confidential and should not be shared with customers.
Background
  • This information relates to v5.3.0.
  • v5.3.0 system software is compatible with Windows 8e or Windows XPe operating systems.
  • v5.3.0 system software is not compatible with Windows NT operating system.
  • There will be no general distribution of this software release.
  • Specific, targeted accounts will receive this version of software in April, 2016.
  • v5.3.0 will not ship with new DxI's from Chaska. Sales groups will continue to ship with v5.2 system software until further notice.

Related Mods

  • A mod will be created to track the specific accounts that receive v5.3.0 system software.

Feature Overview

  • DxI Windows 8 enhancements:
    • Eliminate NVRAM - NVRAM information will now be stored on the AU hard drive, eliminating the need for a battery backup. If there is a need to use the NVM Editor tool, continue to use the same procedure in the DxI Service Manual.
    • System software installer update - new, simplified install process.
    • Update Icons - updated to follow BEC corporate branding.
    • Utility Programs - Items such as Fast Objects (replaces POET) and DbTest are now stored in a folder on the console desktop named Utility Programs.
    • Resource Monitoring (console only) - capability to measure PC system resources for offline/development troubleshooting. To export logs; F7 Diagnostics, F6 Save Data, F2 Export logs.
    • Save data/Export Logs - allows user to easily collect data needed for offline/development troubleshooting. To export logs; F7 Diagnostics, F6 Save Data, F2 Export logs.
    • Screen Transition Logging - diagnostic capabilities to measure user interface response for offline/development troubleshooting. To export logs; F7 Diagnostics, F6 Save Data, F2 Export logs.
  • Removes "Always On" RDS setting - regulatory required change.
  • CPU Power Distribution Voltage Range fix - corrects ranges in user interface.
  • Diagnostic Copy to Disk Updates - extends the default range for data collection. Also changes the location to export the Diagnostic Copy to Disk; F7 Diagnostics, F6 Save Data, F1 Copy to Disk.
  • Database Management Passive Data Reduction - reduces the amount of thermal data kept in the database after the test has completed.
  • IND and System Check Failure events - adds an IND event log message in addition to the IND flag already generated by the system. In addition, it also adds event log messages for both passing and failing system check test completion.
  • LAS RF Level Sense & Edit Units - Allow the user to correctly update settings associated with the fluid height detection feature for automation lines
  • Sample Pipettor Volume Test fix - corrects issues that were introduced in v5.2 system software.
  • FastObjects database - replaces POET, and used for the same functions as POET. Fast Objects programs are located in the Utility Programs folder.
  • Version convention changes - changes to address the needs of global regulatory needs.

Expected Behavior

Topic Information
Diagnostic event message relating to screen transition log. Event message is only displayed when filtering by diagnostics events. This message indicates that screen transition logging is active.
Pressing print screen may print incorrect screen. There are occasions when the print screen function may print the previous screen. For example, if selecting print while in the carryover screen, the maintenance and temperature page could be printed.
Selecting a printer in user interface. At initial install, if there are two Lexmark printer options, select the Lexmark 310 Copy 1 option.
