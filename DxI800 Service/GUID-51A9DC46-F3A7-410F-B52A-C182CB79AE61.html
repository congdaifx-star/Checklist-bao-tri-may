Adjusting Wash Pick-and-Place

This procedure describes how to mechanically adjust the position of the wash pick-and-place to the wash carousel, analytical module cover, and vertical home position prior to performing any alignments on this module.

Required Materials:
  • Wash carousel locking pin
  • Pick-and-place auto-align tool
  • Retractable tape measure or ruler
Prerequisites:
  • The wash carousel angular offset alignment must be performed prior to wash pick-and-place adjustments.
Note: Refer to the AU: Aligning Wash Carousel Angular Offset procedure.
Adjustments for this module include: adjust wash pick-and-place to
  • adjust wash pick-and-place to analytical module cover position
  • adjust wash pick-and-place to wash carousel position
  • adjust wash pick-and-place to vertical home position
Warning: The PMT is a very sensitive photon measuring device. Any background or extraneous room light coming into contact with a powered PMT can and most likely will reduce the performance of the PMT. Extraneous light causes the PMT to become saturated and reduces its gain. A PMT can require an extended period of time to recover from this or it may never fully recover from it. These rules should be followed whenever performing service in the area of the luminometer:
  • Remove power from the PMT prior to removing the covers on the analytical module.
  • Limit the affects of extraneous light capping the PMT whenever it is removed from the analytical module. Doing so keeps light out and prevents debris from accumulating on the PMT window.
  • Never shine a flashlight into the area of the luminometer with power applied to the PMT.
  • Never bring a strong magnetic field near the luminometer while it is operating. The magnetic field will cause the electrons to follow a curved path instead of moving in a straight line, thus degrading the performance of the PMT.
Note:
  • Normally the wash pick-and-place is removed by removing only the gantry and not the towers, thus it is rare that mechanical adjustment will be required.
  • The front section of the analytical module cover needs to be removed when performing this procedure.
  • Verify that the vessel positioner assembly is seated properly.
  1. Remove the front section of the analytical module cover.
  2. Verify that the vessel positioner assembly is seated correctly.
  3. Select Main Menu > Diagnostics > Device Diagnostics > Mechanics > Alignments.
  4. Adjust wash pick-and-place to wash carousel and analytical module positions.
    If you determine that the adjustment is correct for the wash pick-and-place, you may not have to complete this entire step.
    1. Select Wash Carousel as the device and Angular Offset as the position.
    2. Select Home Device > Move to Position, and insert the wash carousel locking pin.
    3. Select Wash P&P as the device, and then select Motors > Disable Both Motors.
    4. Install the pick-and-place auto-align tool onto the wash P&P collet.
    5. Manually move the carriage with the tool towards the front of the instrument, then downward using the index wheel on the end of the upper gantry rod.
    6. Determine if the adjustment to the wash carousel is correct (the tool is centered).
      (When centered, the tool shoulder will be completely inserted into the wash-in position without rubbing or jarring the wheel.)
      • If the tool IS centered in the wash-in position of the wash carousel, the adjustment is correct.
        1. Manually move the carriage with the auto-alignment tool to the rear of the instrument, then downward using the index wheel on the end of the upper gantry rod so that it intersects with the analytical module cover access slot.
        2. Determine if the adjustment to the analytical module cover is correct.
          • If the tool is centered in the analytical module cover slot, the adjustment of the wash pick-and-place to analytical module cover is correct and this adjustment is complete.
          • If the tool is not centered in the analytical module cover slot, the adjustment is incorrect.

            Verify that the analytical module cover is seated properly and recheck, if necessary.

            Adjust the wash pick-and-place to wash carousel and analytical module positions.

      • If the tool is NOT centered in the wash-in position of the wash carousel, the adjustment is incorrect.

        Adjust the wash pick-and-place to wash carousel and analytical module positions.

    7. To adjust the wash pick-and-place to wash carousel and analytical module cover positions:
      1. Verify that the wash carousel is at the angular offset position.
      2. Slightly loosen the four screws that secure the wash pick-and-place to the base plate.
        Note:
        • The tower should be moveable, with little or no slop.
        • If the screws are loosened too much, the tower will lean.
      3. Adjust the pick-and-place x-axis (left/right) to the wash carousel wash-in hole and the center of the slot in the analytical module cover.
        Note: A ruler is useful in indicating the true center of the insulation slot. The pick-and-place tool needs to move cleanly along the z-axis into the wash carousel hole.
      4. Tighten the screws at each of the mounting towers.
      5. To verify this adjustment, repeat the adjustment from the beginning.
  5. Adjust pick-and-place to z-home position.
    1. Select the pick-and-place type being serviced as the device option, and then select Motors > Disable Both Motors.
    2. Move the pick-and-place carriage assembly to the uppermost position.
    3. Select the appropriate pick-and-place as the device option, and then select Motors Enable All.
    4. Loosen the index wheel attachment screw at the end of the upper gantry rod.
    5. Rotate the index wheel to a position where the square hole in the wheel is centered in the sensor.
    6. Tighten the index wheel attachment screw.
  6. Remove the alignment tool.
  7. If any adjustments were made, perform the wash pick-and-place alignments.
    Note: Refer to the P&P: Aligning Pick-and-Place Module procedure.
