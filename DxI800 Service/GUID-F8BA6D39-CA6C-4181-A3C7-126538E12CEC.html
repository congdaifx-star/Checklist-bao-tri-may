Configuring LIS to Send Fatal Results or Accept Duplicate Requests

This procedure describes how to configure the LIS to send fatally flagged results to the host or to accept duplicate test requests from the host.

Use this procedure when the customer desires fatally flagged results to be sent to the host.

The result message can be interpreted by the host software to reorder tests or have the LAS system reintroduce the sample tubes containing the canceled tests (LIS or LAS vendor programming required). The feature might be added to the user interface LIS Setup screen in a future software release.

For the following action... Refer to...
Configure LIS to Send Fatal Results or Accept Duplicate Requests on Windows 8 or Windows 10 system. Step 1
Configure LIS to Send Fatal Results or Accept Duplicate Requests on Windows XP system. Step 2
Verify LIS to Send Fatal Results. Step 3
  1. Configure LIS to Send Fatal Results or Accept Duplicate Requests on Windows 8 or Windows 10 system.
    1. Configure the LIS interface to send fatal results to the host.
      1. Press Windows key, type regedit and open the program.
      2. In the registry editor, navigate to the System Setup folder.
        • For Windows 8: HKEY_LOCAL_MACHINE > SOFTWARE > Beckman > NexStep > Console > System Setup.
        • For Windows 10: HKEY_LOCAL_MACHINE > SOFTWARE > WOW6432Node > Beckman > NexStep > Console > System Setup
      3. Right-click on the LIS Send Cancel entry, and then select Modify.
      4. Enter 1 for the value data, and then select OK.

        If there is no LIS Send Cancel entry, then select Edit > New > DWORD Value. Enter LIS Send Cancel for the name. After the entry is added, change the value data from 0 to 1.

      5. Exit the registry editor, and return to the user interface.
    2. Configure the user interface LIS connection to accept duplicate test requests from the host.
      1. Press Windows key, type regedit and open the program.
      2. In the registry editor, navigate to the System Setup folder.
        • For Windows 8: HKEY_LOCAL_MACHINE > SOFTWARE > Beckman > NexStep > Console > System Setup
        • For Windows 10: HKEY_LOCAL_MACHINE > SOFTWARE > WOW6432Node > Beckman > NexStep > Console > System Setup
      3. Right-click on Ignore Duplicate LIS Test Order, and then select Modify. Change the data value from 1 to 0, then select OK.
        Note:
        • Setting the value to 0 will enable the system to accept duplicate test requests from the LIS host.
        • The value 0 is the default setting, so normally it does not need to be modified.
      4. Exit the registry editor, and return to the user interface.
  2. Configure LIS to Send Fatal Results or Accept Duplicate Requests on Windows XP system.
    1. Configure the LIS interface to send fatal results to the host.
      1. Press the Windows key, and then select Run.
      2. Enter regedit, and then select OK.
      3. In the registry editor, navigate to HKEY_LOCAL_MACHINE > SOFTWARE  > Beckman > NexStep > Console > System Setup.
      4. Right-click on the LIS Send Cancel entry, and then select Modify.
      5. Enter 1 for the value data, and then select OK.

        If there is no LIS Send Cancel entry, then select Edit > New > DWORD Value. Enter LIS Send Cancel for the name. After the entry is added, change the value data from 0 to 1.

      6. Exit the registry editor, and return to the user interface.
    2. Configure the user interface LIS connection to accept duplicate test requests from the host.
      1. Press the Windows key, and then select Run.
      2. Type regedit, and select OK.
      3. In the registry editor, navigate to HKEY_LOCAL_MACHINE > SOFTWARE  > Beckman > NexStep > Console > System Setup.
      4. Right-click on Ignore Duplicate LIS Test Order, and then select Modify. Change the value date from 1 to 0, and then select OK.
        Note:
        • Setting the value to 0 will enable the system to accept duplicate test requests from the LIS host.
        • The value 0 is the default setting, so normally it does not need to be modified.
      5. Exit the registry editor, and return to the user interface.
  3. Verify that the LIS interface sends fatal results to the host.
    1. Navigate to the LIS Diagnostics window in the user interface to begin automatically logging LIS transmissions.
    2. Select a fatally flagged test result in the Test Results display, and select Send to LIS > Current Result > OK.
      Note: The LIS status for the result should progress to Accepted.
    3. If desired, navigate to the LIS Diagnostics window, and view the results LIS transmission.
