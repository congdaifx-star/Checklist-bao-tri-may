J1 - PCB - Power Distribution

  • Vacuum / Inc / Wash / Sample 24V power run through J1.
  • HARNESS, INTERFACE POWER (P/N 116473) connects J1 to:
    • Lower Cabinet Interface PCB J2.
    • Analytic Power Interface PCB J3.
    • Sample Storage Peltier.
    • Peri / Vacuum Pump Interface PCB J4.
Note: The Vacuum / Inc / Wash / Sample 24V power runs through Q3 (controlled by the 24V power switch SW1). It is not disabled by the cover switches.
