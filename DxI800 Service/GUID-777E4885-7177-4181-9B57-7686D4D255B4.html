Software V2.0.1 Release Notes

Purpose

This document provides details regarding important new features, enhancements, workarounds (where applicable), corrected issues, and issues remaining in DxI software version 2.0.1. Many corrections and enhancements were made in version 2.0. Review those release notes as well.

Confidentiality

Software release notes are confidential and should not be shared with customers.

Prerequisites

Prior to installing V2.0.1 software, install the new wash collar (MOD 6424), aspirate probes, and duck-bill valve (MOD 6312).
  • If updating from V1.0 to V2.0.1, then the software is not customer installable.

    A service visit is required because all open MODs must be completed.

  • If updating from V1.2 to V2.0.1, then the software is not customer installable.

    A service call is required because Process Monitoring must be calibrated.

  • If installing the software over V1.4 or lower, then recalibrate and run all assays and run QC. Verify that QC is within customer specifications.
  • If installing the software over V1.4.1 or V1.4.2, then run all levels of QC on all assays. Verify that QC is within customer specifications.

Reference Documents

Installation instructions are available for this release of software and must be used.

Issues Identified and Corrected

These issues were addressed in this release.
  • Set the peltier monitoring to 100% duty cycle deviation effectively turning off the monitoring and preventing unnecessary warnings.
  • Removed a backup dialog box notifying the user that in-use log files cannot be backed up. The dialog box required the operator to press OK to continue. The backup now continues automatically.
  • Removed a wash wheel and incubator wheel stepper motor correction enhancement that was causing pick and place errors.
  • Corrected a problem with process monitoring for low-resolution aspiration.
  • Modified help text for HIV customers in the maintenance section; aspirate probe cleaning frequency has changed to weekly.
  • Corrected thescheduler assert problem that could occur when there was more than one calibration queued by the scheduler at the same time, low risk in the field.

Issues Identified But Not Corrected in this Version

Depending on the level of severity and impact, these issues may or may not be fixed in a future release:
  • A database mismatch event can be generated after initial software install because of an RV data update in V2.0 that makes the RV ID look like a valid POET ID. The AU then decides to cancel the RV, which has no corresponding entry in the database. The only effect is the event log being posted. The database integrity is not compromised in any way and it is safe to disregard this message.
  • The aspirate probe plate returns to "spin height" after priming, daily clean and special clean; while the dispense arm is at "ready height" leaving aspirate probe #1 slightly through the duck-bill valve. The probe returns to normal height during the next routine run, including the utility assay.
  • In the Diagnostics Mechanics screen, the display of encoder counts can be misleading. If the encoder value is non-zero when at home, the next “move to position” value adds this home offset to the displayed value. The stored alignment value is correct in specific.ini. For example, if the value displayed at home is 4 and the move to position value displayed is 125, the actual move was 125 minus 4, or 121.
  • Leaving the Communications Test Dialog open for a long time (more than 8 hours) can cause an instrument software crash.
  • The Diagnostics volumetric tests crash the instrument software if the weighed vessels are placed in the wrong positions on the sample wheel. The volumetric tests function properly if the vessels are placed in the correct positions. Higher impact to instrument manufacturing, low risk to field.
  • The Diagnostics volumetric tests dispense buffer in the incubator wheel. The dispense probe does not go completely into the RV. The .ini file must be edited to perform the test and then reset. This test is primarily used in instrument manufacturing and because of that no instructions will be published. Contact Systems Technical Support with any questions.

Contact

Contact your local support organization with any questions of concerns.
