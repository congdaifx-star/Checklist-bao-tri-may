Re-imaging Console PC Hard Drive

This procedure describes how to re-image the Orange-dot version of the DTx console PC when the PC hard drive will not boot to the Windows desktop.

Perform this procedure when the PC hard drive will not boot to a the Windows desktop. For Windows NT systems, attempt the repair procedure before re-imaging.

Newer DTx PCs are shipped with an image CD that can be used to erase the PC hard drive and replace all the files with known good copies (re-image). For PCs that have been upgraded to Windows XP, use the XP upgrade CD to reimage the PC.

  1. Re-image the PC using the image CD or the Windows XP upgrade CD.
    Note: Due to software licensing considerations, the re-image CD should be used only on the PC that it is shipped with. When a PC is received with a re-image CD included in the box, the CD should be placed in the software binder and stay with the original system. Do not remove the CD from the lab.
    • Re-image a DTx PC using the image CD.
      Warning: The reimage process erases all information on the PC hard drive. A tape or USB backup is required for database restoration.
      1. Insert the image CD into the PC CD-ROM drive.
      2. Cycle the PC power off and on so that the PC reboots.
        Note: This message is displayed when the re-image CD boots: 
        DTx Inc. System Recovery Disc		*
*							*
*	The Recovery Disc will overwrite		*	
*	   all data on the hard drive.		            *		
*							*
*  Press CTRL-C NOW TO STOP THE PROCESS*
*							*
*			    OR				*
*							*
*	 ANY KEY TO CONTINUE
      3. Press any key (Enter, Space bar, etc) to start the re-image process.
        Note: To cancel the re-image process, press Eject and remove the CD, and then press [CTRL] + [C].
      4. The Symantec Ghost 8.2 application re-images the PC hard drive. The re-image program:
        • has a progress indicator.
        • takes approximately 3.5 minutes to complete.
        • formats the PC hard drive, erasing all existing files.
        • loads the Windows software used on a new orange dot DTx PC hard drive.
        Note: If the re-image fails with an output error message due to a possible defective re-image CD or a defective PC hard drive, then reboot and attempt to re-image again.
      5. Remove the image CD from the CD ROM drive and return it to the system software binder when the image process is finished.
        Note: This message is displayed when the re-image process is finished: 
        The Recovery process is now finished.*
*						*
*	Remove media from drive.	*
*	Restart your computer.		*
      6. Reboot the PC.
    • Re-image a DTx PC using the Windows XP upgrade CD.
      Warning: The re-image process erases all information on the PC hard drive. A tape or USB backup is required for database restoration.
      1. Insert the Windows XPe PC upgrade CD #2 (A80319) into the PC CD-ROM drive.
        Note: For V1.1, insert the appropriate NoDot or Blue or Orange Dot CD.
      2. Cycle the PC power off and on to reboot the PC.
        Note:
        • The upgrade CD boots to a black screen with an A:\ prompt (not a Windows desktop).
        • V1.1 boots to a Press any key to continue... prompt.
      3. At the A:/ prompt, type NoDot.bat or BlueDot.bat (depending on the type of PC being imaged), and then press Enter.

        For V1.1, press any key to continue the re-image process.

        Note:
        • Select BlueDot.bat for the Blue dot and the Orange dot DTx PCs.
        • The No Dot PC has a video expansion card and motherboard video.
        • The Orange Dot and Blue dot PCs have the motherboard video only.
      4. The Symantec Ghost 8.2 application re-images the PC hard drive.
        The re-image program:
        • has a progress indicator.
        • takes approximately 3.5 minutes to complete.
        • formats the PC hard drive, erasing all existing files.
        • loads the Windows software used on a new orange dot DTx PC hard drive.
        Note:
        • If the re-image fails with an output error message due to a possible defective re-image CD or a defective PC hard drive, then reboot and attempt to re-image again.
        • To display a directory listing of the files on the CD, type dir and press Enter at the A:/prompt .
        • Refer to the Software: Troubleshoot Windows XPe Upgrade Failures procedure.
      5. Press [Ctrl] + [Alt] + [Del] when prompted at the end of the ghost image process.
      6. Remove the XP upgrade CD from the CD ROM drive and return the CD to the system software binder.
        Note: When the PC reboots to the desktop using the Windows XP upgrade CD, the PC might attempt to continue the normal upgrade. If this is not an actual upgrade, the process fails.
  2. If the PC is part number B23083 and the PC was re-imaged with the image CDs for B23083, then perform Mod 11504 to disable dual core processing and hyper threading. Refer to "Mod 11504 - Access 2 Console PC (B23083) Configuration Update" procedure for details on disabling these features.
    Note:
    • The re-image CD for P/N B23083 only will re-image the PC and set dual core processing and hyper threading to enabled
    • These features need to be disabled for the software to function properly
    • Mod 11504 only applies to the B23083 PC (small black PC with silver faceplate)
  3. Load the system software and restore the database.
    Important: For DxI systems, verify the Console PC's "Date&Time" and "Time Zone" settings match the AU before installing software. If they don't match, then system will fail initialization with "Failed to Synchronize Clocks" error. For Access 2 systems, verify the Console PC's "Date&Time" setting is set to correct local time and "Time Zone" setting is set to "GMT: Dublin, Edinburgh, Lisbon, London." If they are incorrect, customers may lose onboard samples to early expiration time and Access 2 will not get any UI messages.
    Note: For DxI systems, refer to the Peripherals: Replacing Console PC or PC Hard Drive procedure. For Access 2 systems, refer to the Replacing Access 2 PC or PC Hard Drive procedure.
