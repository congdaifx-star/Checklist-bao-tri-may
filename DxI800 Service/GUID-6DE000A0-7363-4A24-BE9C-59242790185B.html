PCB - Data Acquisition (DAQC)

Purpose

This document provides these details for this PCB:
  • Drawings
  • Details: Test Points, LEDs, Connector Overview, Connector Pin-outs
  • Schematics
  • Location

Drawings

Details

The DACQ PCB connects to these devices:
  • Luminometer
  • Thermistors
  • Vacuum / Pressure Interface PCBs (vacuum and pressure sensors, substrate bubble detector)
  • Lower Cabinet Interface PCB (weight sensors for the waste and buffer supplies, air pressure sensor, buffer flow sensor).
