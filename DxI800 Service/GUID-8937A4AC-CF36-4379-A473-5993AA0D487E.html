Aligning SPU

This procedure describes how to align the sample presentation unit (SPU). The SPU must place sample racks into proper position to enable the barcode reader to read the rack serial number and sample bar codes.

Required Materials:
  • No special tools are required

Prerequisites:

All mechanical adjustments to the following devices must be completed before performing the software alignments.
  • SPU

The SPU must place sample racks into position to allow the barcode reader to read the rack serial number and sample bar codes. Even though the SPU interacts with the sample pipettor, that alignment is provided as a sample pipettor alignment because the SPU is the secondary device.

The automatic alignments for this module include:
  • On-load pusher to end of on-load.
  • SPU to rack barcode position.
  • SPU to sample barcode position 1.
The manual alignments for this module include:
  • SPU to on-load position
  • SPU to rack barcode position
  • SPU to sample barcode position 1.
Note: Changes to alignment offsets are written to file:
  • when the alignments are saved while exiting the Alignment screen.
  • by selecting Alignments / Offsets > Save Alignments.
  1. Align SPU on-load pusher to end of on-load position.
    1. Select SPU On-load Pusher as the device, and then select End of Onload as the position.
    2. Select Alignments / Offsets  > Auto Align Selected.
      The instrument homes both devices and moves the tray to the on-load position.
    3. Open the SPU cover, load the rack into the center of the on-load area, and close the cover.
    4. Select OK
      The instrument proceeds with the auto-alignment.
    5. Select Save offset & Exit.
      The instrument homes both devices and moves the tray to the on-load position.
    6. Open the cover, remove the rack, and close the cover.
    7. Select OK.
  2. Align SPU presentation tray to rack barcode positions.
    1. Select SPU Presentation Tray as the device, and then select Rack Bar Code as the position.
    2. Select Alignments / Offsets  > Auto Align All.
      The instrument homes the presentation tray and moves the tray to the on-load position.
    3. Place a tube with a barcode in position 1 of an appropriate rack.
      The sample barcode and the rack barcode labels must be facing to the right.
    4. Open the SPU cover, place the rack in the on-load area of the SPU, and close the cover.
    5. Select OK.
      The instrument proceeds with the auto-alignment.
      Note: If the message [SPU Presentation Tray, Rack Bar Code] Instrument Alignment Failed occurs, the bar codes cannot be read. Proceed to next step "Perform the manual alignment of SPU tray to bar code position".
    6. Select Save offset & Exit.
      The instrument homes both devices and moves the tray to the on-load position.
    7. Open the cover, remove the rack, and close the cover.
    8. Select OK.
  3. Perform the manual alignment of SPU tray to rack barcode position.
    Note: Perform these steps to move the presentation tray to position for alignment when installing a new bar code reader or when auto-alignment fails.
    1. Open the SPU cover, and bypass the SPU cover interlock switch to allow better access for viewing the bar codes and bar code reader.
    2. Select SPU Presentation Tray as the device, and then select Onload Position as the position.
    3. Select Home Device > Move X/Y To Position.
    4. Place a tube with a bar code into position 1 of a 13x75-mm sample rack.
    5. Open the SPU cover, place the rack in the bar code read position of the SPU, and close the cover.
    6. Select Home Device.
    7. Select Rack Bar Code as the position.
    8. Select Move X/Y to Position.
    9. Using the directional keys, step the presentation tray x and y forward and rearward until the beam is aligned on the center of the rack barcode position.
      The sample bar code reader bracket might require manual adjustment until the light beam is aligned on the center of the rack bar code position.
      If the alignment position is difficult to view, then consider these options:
      • Open the SPU to access a better viewing angle into the bar code area
      • Remove the barcoded tube and center the red vertical lines from the barcode reader on the opening in back of the rack.
    10. Select Alignments / Offsets > Preserve Offsets > Home Device > Move X/Y to Position.
    11. Check for correct alignment and adjust if necessary.
    12. Save by selecting Alignments / Offsets > Save Alignments .
    13. Select Home Device.
    14. Repeat the manual alignment to the presentation tray, this time to the sample barcode position.
    15. Remove the SPU cover interlock switch bypass, and close the cover.
  4. Align SPU to on-load position (manual alignment).
    1. Select SPU Presentation Tray as the device, and then select Onload Position as the position.
    2. Select Home Device > Move X / Y To Position.
    3. Using the directional keys, step the presentation tray x and y forward and rearward until the presentation tray rails are in-line with the on-load and off-load rails. Slide a rack between the presentation tray and the on-load and off-load rails. Smooth movement indicates correct alignment.
    4. Select Alignments / Offsets > Preserve Offsets > Home Device > Move X / Y to Position.
    5. Check for correct alignment and adjust if necessary.
    6. Save by selecting Alignments / Offsets > Save Alignments .
    7. Select Home Device.
  5. Verify the proper operation of the SPU.
    1. Verify that all alignment tools are removed from the instrument.
    2. Load four racks into the SPU and observe as the instrument processes the racks. If the alignment of the sample bar code position was changed, then include tubes with bar codes in the rack.
      The on-load pusher advances differently, depending on the number of racks remaining in the on-load area.
      Rack Position On-load pusher advances based on Notes
      One or more racks in end of on-load sensor that detects racks
      No racks in on-load area. The remaining racks are being pushed through the presentation tray. end of on-load alignment If motion issues only occur with fewer than three racks, then troubleshoot the end of on-load alignment. Verify that the racks push straight (do not tilt) during this alignment.
    3. Verify the following:
      • Correct tray motion
      • Correct barcode reader operation
      • No motion errors
      • Correct bar code label reading
      • Correct rack movement and presentation
