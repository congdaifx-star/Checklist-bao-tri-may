Creating Immediate Backup (Tape or USB)

This procedure describes how to create an immediate backup of the database for review by software engineering or in preparation for replacing a console PC.

An immediate backup creates a copy of the database for review by software engineering or in preparation for replacing a console PC.
  • An immediate backup can be launched at any time, but it is better to wait for the instrument to be in Ready mode before starting the backup.
  • The contents of the backup tape or USB drive are overwritten each time a backup is performed.
  • The backup takes a minimum of 14 minutes to complete and the time can increase depending upon the number of instrument trace files and the size of the database.
  • Back up to a USB drive named BACKUPDRIVE is available for Windows XP systems. If there is a USB drive, the XP system defaults to the USB drive and ignores the tape.
  • If switching from a USB backup to a tape backup, then reboot the PC after removing the USB drive. A reboot is necessary so that the backup recognizes the tape. Without the PC reboot, a backup failed message occurs soon after the copying instrument logging files message during backup.
Note: For additional information, refer to the Software: Data Backup Overview concept topic.
  1. Create an immediate backup.
    1. In the Main Menu, select Configure > PC Admin.
    2. Verify the backup tape (or USB drive) is installed in the PC, and select Immediate Backup.
    3. Enter the password Access2Support (case sensitive), and then select OK.
    4. When the warning dialog is displayed, select OK.
    5. If there are no errors (hardware or software), the backup starts and displays a Backup Status dialog box. If there are errors, resolve the errors and retry the backup.
      Error examples:
      • No tape, or tape drive is not recognized.
      • Another backup is already in progress.
      • Tape is write protected.
    6. For any Skip Open Files messages, ignore them or select Cancel.
      Note: The open file messages will close automatically after 30 seconds. The operator can continue regular system operation while the backup is running.
    7. When the backup is complete, the Backup Status dialog box closes automatically.
    8. After a one or two-minute delay, the Backup Report dialog box is displayed. To dismiss the dialog box, select OK.
  2. If the tape is needed in another PC, then select Eject Tape, wait for the tape to rewind (approximately 1 minute), and then remove the tape.
    Note:
    • The USB backup can be installed or removed any time that the system is not writing information into it
    • It might be necessary to reboot the PC when switching the backup mode from tape to USB or from USB to tape.
    • Selecting Eject Tape without removing the tape from the PC afterward, might create a No Tape in Drive or Unknown Error the next time an attempt is made to access the tape.
