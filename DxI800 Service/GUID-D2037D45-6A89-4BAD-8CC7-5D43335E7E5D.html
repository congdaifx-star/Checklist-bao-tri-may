J02 - PCB - MCC Backplane

  • The sample wheel encoder signals from the Sample Storage Module Interface PCB to the MCC0 PCB run through J02.
  • The 5-V power to the Interface PCB from the MCC0 PCB also runs through J02.
  • CABLE, INTERFACE, RIBBON, SAMPLE STORAGE connects J02 to J1 on the Sample Storage Module Interface PCB.
