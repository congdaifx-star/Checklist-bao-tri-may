Upgrading AU Hard Drive to Windows XP

This procedure describes how to upgrade the AU hard drive to Windows XP when the automated process does not complete or when the PC has been replaced with the small DTx PC.

  • If the automated Windows XP upgrade fails during phase 1 and after troubleshooting the failure, then follow the procedure to upgrade the AU hard drive manually. For information on troubleshooting the failure, refer to the Software: Troubleshoot Windows XPe Upgrade Failures procedure.
  • If the PC is replaced with a small DTx XP PC only, then follow the procedure to upgrade the AU hard drive automatically . The small DTx XP PCis not configured to run the CDs for the XP upgrade. If the CD is used, a System has not detected the correct OS upgrade CD for the console HW type error occur. The automatic upgrade procedure modifies a registry setting on the small DTx XP PC to allow the upgrade from the CD. The manual upgrade procedure can also be used to upgrade the small DTx XP PC, but the manual process takes longer than the automatic upgrade.
  1. Manually upgrade the AU hard drive to XP.
    1. Place the OS upgrade CD 1 into the console drive and copy the FBA folder from the CD to the PC hard drive.
    2. Remove the AU hard drive from the instrument and place it into the PC as a slaved drive.
      Note: Refer to the Software: Restoring Console PC Database from Files Transferred Between Hard Drives procedure (preparing to transfer files section) for details on how to connect an AU hard drive into the PC.
    3. Power on the PC and open Windows Explorer to verify that the AU hard drive can be detected (it should appear as the D:\ drive, can appear as E: drive on small PCs).
    4. Open the D:\ drive, make a new folder, and name the folder NTBackup.
    5. Cut and paste the following files from the D:\ drive to the new NTBackup folder on the D:\ drive.
      • Autoexec.bat
      • boot.ini
      • Config.sys
      • ImageVersion.txt
      • Io.sys
      • Msdos.sys
      • Ntdetect.com
      • ntldr
      • pagefile.sys
      Note:
      • The files must be moved to the backup folder, the files cannot be copied.
      • The files must be removed from the D:\ directory.
      • Not all of the files may be present on the drive, move any of the files listed that are present
    6. Rename the following folders on the AU hard drive by adding a 1 to the end of the file (for example, Winnt should be renamed Winnt1)
      • Program Files
      • Temp
      • Install
      • Multimedia Files
      • Winnt
    7. Copy the contents of the FBA folder from the PC hard drive to the AU hard drive.
      Note: Do not copy the FBA folder. Only copy the contents of the FBA folder to the AU hard drive. If the FBA folder is copied, the upgrade will not complete.
    8. Remove the AU hard drive from the console and install it back into the instrument.
      1. Power off the PC.
      2. Remove the AU hard drive and install it into the instrument.
      3. Reassemble the PC.
      4. Power on the PC and AU.
      5. The XP upgrade process should automatically run and complete on the AU hard drive after it is powered on.
        Note: A monitor can be hooked up to the instrument to verify that the hard drive is upgrading. When the black DOS window disappears the upgrade is complete.
    9. Perform these steps to configure the remote desktop sharing feature on the AU hard drive.
      Note: Remote desktop sharing is functional until these steps are completed. These commands set the AU to allow remote desktop sharing and set the password to not expire.
      1. Press the [Start] key, select Run, type CMD, and then press [Enter].
      2. Caution: For the commands in this section to work, the OS upgrade CD 1 must be in the CD drive.
        Type D:\psexec.exe \\192.168.2.4 regedit /s c:\au\setupauregistry.reg, and press [Enter].
      3. Type D:\psexec.exe \\192.168.2.4 net accounts /maxpwage:unlimited, and press [Enter].
      4. Close the CMD window.
    10. Perform these steps to complete the upgrade based on the operating system that is currently installed on the PC.
      • If the PC OS is NT,
        1. Confirm that the OS upgrade CD 1 is in the drive.
        2. Press the [Start] key, select Run , type D:\upgrade.exe 2, and press [Enter].
        3. Follow the on-screen instructions to complete the upgrade and load the system software.
          Note: Entering this command forces Phase 2 of the upgrade to start.
      • If the PC OS is XP,
        1. Copy the specific.ini file from the backup folder on the PC to the C:AU folder on the AU (copy located at C:\ NexGen\ Console\ Backup\ 60xxx_specific.ini)
        2. Insert the system software CD into the drive and follow the on-screen instructions to complete the software load.
  2. Automatically upgrade the AU hard drive after the PC is replaced with a small DTx XP PC only.
    1. Change the registry setting.
      1. Select [Start] > Run, type Regedit, and press [Enter] .
      2. Select HKEY_LOCAL_MACHINE > Hardware > Descriptions > System > Central Processor > 0.
      3. Right-click ~MHz, and select Modify.
      4. Record the entry in the value data window.
        Note: This entry will be re-entered after the upgrade completes.
      5. Type 8fc, and select OK.
      6. Close the registry editor.
    2. Place the OS upgrade CD 1 into the console drive and select [Start] to begin the upgrade.
      Note:
      • The OS on the AU will be upgraded to XP.
      • The upgrade process should fail on step 1 of phase 2 after detecting that the console is already on XP.
      • This error is expected.
    3. Reboot the AU.
      Note: The upgrade temporarily changes the IP address to 192.168.2.199. Rebooting the AU changes the IP address to 192.168.2.2 so the software can be loaded.
    4. Insert the system software CD into the drive and follow the on-screen instructions to complete the software load.
      Note: The AU IP address should be 192.168.2.2. Select this IP address when the software prompts for the IP address of the instrument.
    5. Repeat the steps in Change the registry setting to change the registry setting back to the original value.
    6. To restore the database, do the following:
      • Rename the NexGen folder on the C:\ drive to NexGenx.
      • Restore the database from a previous hard drive.
        Note: Refer to the Software: Restoring Console PC Database from Files Transferred Between Hard Drives procedure.
