Transferring Event Log Files (Verbose and Terse)

This procedure describes how to transfer event log files.

Transfer event log files when it is necessary to:
  • copy event log information to a separate PC for viewing.
  • save event log for early look mod site
  1. For Software V5.1 and higher, use the Simple Save Method to save event log files to the PC.
    1. Select the Event Log screen.
    2. Select [Ctrl] + [Shift] + [Home].
    3. Select OK to the message.
  2. Transfer the event log files.
    • Transfer the event log files to an on-site USB drive.
      1. Scan the USB device that will be installed in the console PC for malware. See USB Drive Malware Scan and Removal for more information.
      2. Insert the USB drive into the PC.
      3. Open File Explorer (a.k.a. Windows Explorer on Windows XP) and select the C:\ drive.
      4. Scroll down and find the events files.
      5. Right-click the Verbose file and select Send To -> the USB flash drive name (E: or F:).
      6. Right-click the Terse file and select Send To -> the USB flash drive name (E:or F:).
      7. Remove the USB drive.
    • Transfer the event log files to an on-site laptop.
      Note: Refer to the Software: Transferring Files Between Laptop and Console PC or AU procedure.
