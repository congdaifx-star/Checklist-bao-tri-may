Tool Kits: Upgrade Tool Kit

The Upgrade tool kit, P/N A21853, contains these new/modified tools:
Tool Name (CARES) Tool Name (STS) Part Number Qty In Kit Notes
Tool, Alignment, Aspirate Probe Tool, Adjustment, Aspirate Probe Plate A21818 3
Use: Adjusting
  • Aspirate Probe Plate to the Wash Carousel.
Note: Flats on top end are to enable easier removal from the wash carousel.

Quantity: Ordering this part number provides 3 of these tools.

Align Fixture, Dispense Probe Plate Tool, Adjustment, Mixer to Wash Carousel A19086 2

Use: Gripper/spinner to vessel position.

Advantage: Was modified in Fall 2004 to have a clearance hole for the substrate probe when the probe plate is moved downward. Eliminates the need to remove the substrate probe.

Quantity: Ordering this part provides 2 of these tools.

Alignment Tool, Universal RV Tool, Adjustment / Alignment, Vessel Shaped, Green A25192 1
Use: Aligning
  • Sample Pipettor to the Sample Storage Wheel.
  • Bulk Feeder Vessel Ejector to Scoops.
  • Reagent Pipettors to the Reagent Carriages.
  • Pick and Place Devices.
