Searching Wash Wheel Slippage Trace Files During Troubleshooting

This procedure describes how to troubleshoot the analytical unit for wash wheel slippage errors.

  1. Save a section of the trace file.
    Note: Since intermittent issues can not be apparent during exercisers or observation of the instrument, they can be difficult to troubleshoot. Searching the trace file helps direct troubleshooting efforts.
    1. Insert a floppy disk into the floppy drive of the console PC.
    2. Select the Excessive Slippage message in the event log.
      Note: If there are a series of slippage messages, select the earliest message.
    3. Select Copy to Disk.
    4. In the Copy to Disk screen, enter:
      • Before Event (Sec): 30
      • After Event (Sec): 10
      • Path: A:
      Note: By default, the Include Details option is active.
    5. Select OK.
    6. Repeat the steps for any additional Excessive Slippage errors.
    7. If Oracle is available, attach these files to the Oracle Service Request for future reference.
    8. Open the saved trace files from the disk on either the console PC or another PC.
      Note: If the PC asks which program to use to open the file, select Notepad.
  2. Search the trace file for wash wheel slippage.
    1. Select Edit > Find.
    2. Search down for the wash wheel exception: Type x901442 in the Find What box, and then select Find Next.
      Note: x901442 is part of the event descriptor code for wash wheel slippage. The code is the fastest way to locate the wash wheel slippage error in the trace file.
    3. Search up for the encoder movement: Type mod in the Find What box, select Up for Direction, and then select Find Next.
    4. Identify the encoder read of the movement from these lines of text.
      Perform the mathematical operation: last Encoder modulo position minus first Encoder modulo position.

      Example: 3651 - 3573 = 78 steps. The wash wheel encoder measured 78 steps of movement. Normal slot-to-slot wash wheel movements are 168 - 169 steps. Priming routines or initialization can cause different step movements.

      1447246271,(1271),WashWheel:T_Advance, SMC running position: 3573.

      1447246271,(1271),WashWheel:T_Advance, SMC C/M position: 3573.

      1447246271,(1271),WashWheel:T_Advance, Encoder's modulo position: 3573.

      1447246274,(1274),WashWheel:T_Advance, Proximity of home CW WashWheel current position: 3573, relative move: 168, StepsAwayFromHome: 20, nAllowedSlippage: 5, fTolerance: 20.62

      1447246539,(1539),WashWheel:T_Advance, SMC running position: 3741.

      1447246539,(1539),WashWheel:T_Advance, SMC C/M position: 3741.

      1447246539,(1539),WashWheel:T_Advance, Encoder's modulo position: 3651.

      1447246539,(1539),WashWheel:T_Advance, WashWheel Corrected encoder error: -11510.

      1447246542,(1542),WashWheel:T_Advance, ERROR WashWheel RotateToAngle failed, motor position: 3741, encoder position: 3651

      System error code: 0x80004005

      1447246542,AuObj, 09:06:35,1447246542,WashWheel has been disabled by WashWheel.Worker

      1447246542,(1542),WashWheel:T_Advance, WARNING: Subsystem has been DISABLED

      1447246542,(1542),WashWheel:T_Advance, Disabled

      1447246542 Advance.WashWheel:T_Advance REPORT:1447246542

      1447246570,Sequencer, 1447246542,Sequencer, CAUGHT EXCEPTION, 0x901442 from Subsystem WashWheel during T_Advance, dev Wash Wheel: 'Excessive motor slippage', 21150, C:\NexGen\Instrument\AU\WashWheel.cpp rev:$Revision: 1.566 $ line:4949, OtherSys:None

    5. Analyze the movements using this table.
      If the expected motor (SMC) movement is and the encoder read of the movement is then

      Positive

      Positive

      The wash wheel moved forward, but not far enough. Proceed to the Search Trace File for RV Ejection step.

      Positive or Negative

      Zero

      The wash wheel moved zero steps or the encoder measured no change in movement. Refer to the table to troubleshoot Electrical Issues.

      Positive

      Negative

      The wash wheel moved backwards. Refer to the table to troubleshoot Electrical Issues.

      Negative

      Positive

      The wash wheel moved forward rather than the expected backwards movement (priming is the most common activity that this motion can occur). Refer to the table to troubleshoot Electrical Issues.

      Negative

      Negative

      The wash wheel moved backwards as expected, but not far enough. Proceed to the Search Trace File for RV Ejection step.

      Note: Refer to the AU: Troubleshooting Motor Motion Errors in Analytical Module document.
      Wash carousel slippage is caused by Then perform these troubleshooting steps...
      Electrical issues:
      • Loose electrical connections
      • Damaged cables
      • Defective MCC 7 PCB
      • Damaged or defective sensor
      1. Reseat MCC 7 or swap MCC 4 and 7. If the issue is a bad MCC, then when MCC 4 and 7 are swapped, the failure is moved from the wash carousel to Reagent Pipettor 2 motion errors.
      2. Reseat and inspect these cables (replace if damage is seen or suspected):
        • Home sensor and encoder
        • Analytical Interface PCB: J1, J2, J11, J14, J20
        • MCC backplane: J71, JP71, J2, J3
        • COMC PCB: J1, J2
  3. Search the trace file for RV ejection.
    1. Determine if the error occurred during priming.
      1. Select Edit > Find, and type x901442.
      2. Select Down for direction, and then select Find > Next.
      3. Look at the words following the highlighted x901442 text.
        • If the text is from Subsystem WashWheel during...M_Prime, then the error occurred during priming. Check other trace files for the same pattern of priming. If the errors occur during priming, troubleshoot the pick and place issues and RV ejection issues under causes of errors.
      Note: Wash wheel slippage errors during priming do not report to the trace file if RVs were ejected from the gripper-spinner. Contact STS for further assistance with the trace file, searching multiple trace files, or troubleshooting both pick-and-places and gripper-spinners.
    2. Determine if the error occurred after an RV ejection.
      1. Select Edit > Find, and type D2.
      2. Select the Up option for Direction, and then select Find > Next.
      3. Look at the D2, D3, and SUB positions.
        • A1 after the position indicates there was a vessel at that gripper-spinner.
        • A0 after the position indicates that there was no vessel at that gripper-spinner.
        • Example: WashWheel:T_Advance, Active D1:1 D2:1 D3:0 SUB:1

          A vessel was underneath D2 and at the substrate gripper-spinner.

          A vessel was underneath D1, however there is no gripper-spinner at the D1 position.

    3. Search multiple trace files to determine if there is a pattern of vessel ejection issues.
      • If one particular gripper-spinner always causes the issue, then troubleshoot that gripper-spinner.
      • If the error occurs on multiple gripper-spinners, then refer to the RV ejection issues under causes of errors,
      • If the errors are occurring without vessels under the gripper-spinner, then refer to all the causes of error for the wash carousel, except for those for RV ejection issues.
