Decontaminating Substrate

This procedure describes how to decontaminate the substrate system using the Decontaminate Substrate routine included in the DxI user interface and how to decontaminate the substrate system when elevated RLUs return after performing the Decontaminate Substrate routine.

Decontaminate the substrate system using the Decontaminate Substrate routine included in the DxI user interface when:
  • contamination of the substrate system is confirmed.
  • new substrate system hardware is installed or replaced.
    • substrate pump
    • substrate pump valve and o-rings
    • substrate pump piston and guide
    • substrate pump o-ring and seal
    • substrate pump bottom seal shaft
    • substrate loader module
  1. Confirm substrate contamination.
    Note: Refer to the Fluidics: Confirming Contamination During Substrate Troubleshooting procedure.
  2. Prepare the decontamination supplies.
    Note: Confirm that a minimum of two bottles of equilibrated substrate are available, so that the instrument can be returned to service after decontaminating.
    1. Wash two empty substrate bottles with wash buffer or deionized water.
    2. Add 50 ml of 20% Citranox solution to each bottle.
    3. The Citranox solution is the same solution that is used for the daily clean (one part Citranox to four parts deionized water).
  3. Decontaminate the substrate fluidics.
    1. In the user interface, select Maintenance Review > Decontaminate Substrate.
      Note: Decontamination discards the on-board substrate. Confirm that a minimum of two bottles of equilibrated substrate are available, if the instrument will be returned to service after decontaminating.
    2. Select OK.
      Follow the instructions for the decontamination process on the Decontaminate Substrate dialog box.
      Note: Once started, all steps of the decontamination process must be completed before samples can be processed. If a step is canceled, then the entire process must be repeated. The status is stored in the instrument NVRAM.
    3. Enter 300 in the Dwelling Time (seconds) area of the Decontaminate Substrate window, and then select Next.
      Both substrate bottle load doors open.
    4. Remove both substrate bottles, load the two prepared bottles (20% Citranox), and select Next.
      • Both substrate bottle load doors close, and priming begins.
      • Both substrate bottle load doors open when the air priming step begins.
    5. When air priming is complete, remove the two bottles of Citranox solution and wipe off both substrate draw tubes with a lint-free towel.
    6. Select the New Substrate Bottles option, and then select Next.
      The substrate doors close.
      Note:
      • The Empty Bottles option is intended for priming the system dry before shipment or storage.
      • If the Empty Bottles option is selected, then initialization will fail after decontamination until new substrate is loaded. The errors posted are Unable to Initialize Instrument, Failed during phase 5, or Substrate bottle Selector Valve is out of position.
    7. Open the left substrate door and load a new substrate bottle into the left position.
      Note:
      • Both substrate load doors are closed.
      • If both substrate load doors are open, confirm that the Next button was selected.
      • The door closes after the bottle is inserted.
    8. Scan the substrate bottle bar code label using the instrument bar code reader.
      Note: If the bottle bar code label is from a used, empty, or expired bottle, then the door reopens for loading of a usable bottle. Load a new bottle. If a new bottle is not available, then a full canceled bottle can be loaded after giving it a different serial number. Move the bottle out and back in, then wait for the instrument bar code reader to timeout after 30 seconds. Scan the bottle using the PC bar code reader in the UI supplies window. To change the bottle serial number and load the bottle as a new full bottle, change the third letter from the end of the bar code up or down one letter.
    9. Load and scan the second substrate bottle. When finished loading, select Next.
      The system completes a final 15 primes from each bottle.
    10. When the priming is complete, select Done.
      Note: If the operator cancels decontamination or a system error occurs that stops decontamination, such as a substrate load failure or bar code read failure, then:
      • The system defaults to a No Substrate Bottles On-board condition.
      • The Event Log indicates that the substrate decontamination failed.
      • The system enters Not Ready mode.
      • Initialization fails until decontamination is completed successfully.
      Note: If an error loading the substrate occurs in the final step and decontamination has otherwise completed successfully, then perform these steps to reset the decontamination required condition:

      For AU with Windows XP:

      1. Connect to the AU using remote desktop share connection.
      2. Exit the AUObj.exe machine control program (right-click the small Y icon, and select Exit).
      3. Record the TotalTestSeconds and TestNumber using the NVMEditor program.
        Note: Refer to the Software: Modifying Run Time and Test Counts from Database procedure.
      4. Select Start > Run, type auobj.exe /clean, and then press Enter to erase the instrument NVRAM.
      5. Restore the TotalTestSeconds and TestNumber using the NVMEditor program.
      6. Start the AUObj.exe machine control program (large Y icon).
      7. Load two new bottles of substrate and initialize with Remap selected to restore the instrument reagent supplies memory.
      8. If decontamination did not finish the final priming step, then prime both left and right substrate bottles 15 times.

      For AU with Windows 8:
      1. Connect to the AU using remote desktop share connection.
        1. Press the Windows key, type remote, and open the Remote Desktop Connection program.
        2. Type 192.168.2.4 into the Computer field and select Connect.
        3. Enter user for the User Name and tech for the password if prompted.
        4. If prompted at the RDS warning screen, check the box for “Don’t ask me again for connections to this computer” and select Yes.
          Note: For Windows 8, the default console IP address is 192.168.2.3 and the AU IP address is 192.168.2.4. Neither IP address changes during the software load process.
      2. Exit the AUObj.exe machine control program.
        1. Right click on the task bar and select Task Manager.
        2. In the Task Manager box, click on Processes, select AUobj Module, and click on End Task in the bottom corner of the box.
      3. Record the TotalTestSeconds and TestNumber using the NVMEditor program.
        Note: Refer to the Software: Modifying Run Time and Test Counts from Database procedure.
      4. Press the Windows key, type run, and open Run program.
      5. Type auobj.exe /clean, and then press Enter to erase the instrument NVRAM.
      6. Restore the TotalTestSeconds and TestNumber using the NVMEditor program.
      7. Start the AUObj.exe machine control program (large Y icon).
      8. Load two new bottles of substrate and initialize with Remap selected to restore the instrument reagent supplies memory.
      9. If decontamination did not finish the final priming step, then prime both left and right substrate bottles 15 times.
  4. Verify the proper operation of the system.
    1. Confirm that there are no event log errors (substrate or temperature).
      Perform system verification as stated in the Verification of Service Repair document (Admin: Verification of Service Repair).
      Note:
      • Refer to Fluidics, Pump, Substrate Assembly in the DxI Verification spreadsheet.
      • If the substrate pump has been replaced, then calibrate the substrate back-draw in the priming window.
      • If elevated RLUs return, then perform the next procedure section.

Alternate Decontaminating Substrate Method

Decontaminate the substrate system when elevated RLUs return after performing the Decontaminate Substrate routine.
  • The Decontaminate Substrate routine has an intermediate step that removes the 20% Citranox from the system before priming in the substrate. The intermediate step is referred to as Air Cycles.
  • This alternative method will reduce the number of Air Cycles performed during the decontamination routine. The reduction in Air Cycles will allow the Citranox to be pulled out of the substrate loader, but keep the pump full. The operator will then be able to determine the amount of time the Citranox will remain in the pump.
  1. The Air Cycle change is made in the Subsystem.ini file. Perform the following steps to make the change.
    1. Open a remote desktop connection to the AU.

      For Windows 8:

      1. Press the Windows key, type remote, and open the Remote Desktop Connection program.
      2. Type 192.168.2.4 into the Computer field and select Connect.
      3. Enter user for the User Name and tech for the password if prompted.
      4. If prompted at the RDS warning screen, check the box for “Don’t ask me again for connections to this computer” and select Yes.
        Note: For Windows 8e, the default console IP address is 192.168.2.3 and the AU IP address is 192.168.2.4. Neither IP address changes during the software load process.

      For Windows XP :
      1. Select Start > Programs > Administrative Tools > Remote Desktop Connection to AU PC.
    2. In the AU desktop find the Subsystem.ini file.

      For Windows 8:

      1. Double click on Computer and select Local C: drive or AU_PC (C:) > AU > Subsystem.ini.
      2. Right click on Subsystem.ini file and select Properties.
      3. In Properties find Attributes and uncheck the Read Only box. Select Apply and then OK to exit.

      For Windows XP:
      1. Select Start > Programs > Windows Explorer > Local Disk (C:) > AU > Subsystem.ini.
      2. Right click on Subsystem.ini file and select Properties.
      3. n Properties find Attributes and uncheck the Read Only box. Select Apply and then OK to exit.
    3. Open the Subsystem.ini file and search for Substrate.Diagnostics.
    4. Change the Decont_AirLeftBottleCyles and Decont_AirRightBottleCycles values from 5 to 2.
    5. Select File and Save. Exit Subsystem.ini.
    6. Shut down the AU Object program.

      For Windows 8:

      1. Right click on the task bar and select Task Manager.
      2. In the Task Manager box, click on Processes, select AUobj Module, and click on End Task in the bottom corner of the box.

      For Windows XP:
      1. Right-click on the AU Object icon (small Y-shaped icon) in the task bar at the bottom right hand corner of the screen, and select Exit.
    7. Double-click the large AU Object icon on the AU desktop to re-launch the AU Object.
    8. Minimize the AU desktop screen to return to the user interface.
  2. Follow the Decontaminate Substrate routine in the DxI user interface procedure until you finish Step 3e (completion of the air cycles).
    1. The reduced number of air cycles will leave the substrate pump full of 20% Citranox.
    2. The Citranox will remain in the pump until Step f (loading new substrate) is performed.
    3. Wait 45 minutes to 1 hour before performing Step f. This time frame should be long enough to remove any contaminates from the substrate pump.
  3. After completing the decontamination procedure recheck the substrate RLU values. If the substrate values are within specifications.
    1. Go to AU desktop and return the Subsystem.ini file Cycle values (changed in Step 1) to the original settings.
      Note: If remote connection is disconnected or ended, refer to Step 1a to reconnect to the AU desktop.
    2. Select File and Save. Exit Subsystem.ini.
    3. Right click on Subsystem.ini file and select Properties.
    4. In Properties find Attributes and check the Read Only box. Select Apply and OK to exit .
    5. Right-click on the AU Object icon (small Y-shaped icon) in the task bar at the bottom right hand corner of the screen, and select Exit.
    6. Double-click the large AU Object icon on the AU desktop to re-launch the AU Object.
    7. Close AU remote connection.

      For Windows 8:

      1. From the ~AU Desktop~, right click on Remote Desktop Connection icon on the upper left corner or on the task bar > Close or select the X in the upper right corner.
      2. Select OK at the ~Your remote session will be disconnected~ pop-up.

      For Windows XP:
      1. From the ~AU Desktop~, select Start > Disconnect or select the X in the upper right corner.
      2. Select OK at the ~Disconnect Windows Session~ pop-up.
