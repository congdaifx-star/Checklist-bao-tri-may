JP1 - PCB - Interface - Lower Cabinet

  • The flow monitoring revision normal / bypassed jumpers (two) connect to JP1.
Note:
  • For a system that does not have the tubing installed for wash buffer flow monitoring, install the two jumpers on the bypassed pins (C and D) at the top left corner of the newer bubble trap style PCB.
  • On the newer bubble trap style PCB, software uses the waste valve 2 control signal to switch between the front or rear wash buffer weight sensor output going out to the DAQC PCB. Selection of external waste disables software control of waste valve 2 when the old style PCB is detected. Display of the rear wash buffer supply weight sensor output for both front and rear boxes can be a symptom of PCB version misidentification or a bad occlusion pressure sensor (also possible is a shorted ribbon cable to the MCC backplane).
  • The DAQC PCB identifies the flow monitoring revision by querying the output of the wash buffer occlusion pressure sensor when the machine control program is launched (initialization does not redetect the version).
  • For PCB version detection, the pressure sensor output signal Mux Detection Value recorded in the trace file should be:
    • -1.25 V DC (spec is <-0.5 V DC) for the bubble trap style PCB with the jumpers set to normal. (TP11, J1-9 / TestAnalog CH63, Trace file Fluid Control: MUX Detection). The signal shown on Test Analog CH63 can be toggled (from pressure to bubble) using wash buffer valve 2 in Outbit test, but it may not show the same value as the dynamic reading stored in the trace file for MUX detection.
    • +2.25 V DC for original version of the PCB, or for the bubble trap style PCB with the two JP1 jumpers set to BYPASSED.
