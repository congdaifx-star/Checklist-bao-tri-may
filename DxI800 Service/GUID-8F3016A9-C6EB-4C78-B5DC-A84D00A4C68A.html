J1 - PCB - CPU Power Distribution

  • The 24V, 12V, -12V, 5V, and 3.3V ATX power to the CPU backplane run through J1.
  • HARNESS, POWER, MAIN CPU (P/N110862) connects J1 to J7 on the CPU Backplane PCB.
