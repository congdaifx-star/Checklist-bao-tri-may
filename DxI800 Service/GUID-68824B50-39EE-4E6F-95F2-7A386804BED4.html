Fluidics: Calibrating the Lower Cabinet Interface PCB

This procedure describes how to calibrate the Lower Cabinet Interface PCB.
Note: This procedure is applicable to Lower Cabinet Interface PCB revision AC and above only.
Perform this calibration procedure when:
  • replacing the Lower Cabinet Interface PCB.
  • replacing the bubble trap assembly.
  • wash bubble detector or flow sensor fails calibration.
Warning: There is live power on the Lower Cabinet Interface PCB. Wear proper PPE and use caution when working in this area.
Required Tools or Materials:
  • a volt meter or multi-meter
  • a small potentiometer turner tool or flat head screw driver
Table 59: Lower Cabinet Interface PCB Revision AC and Higher - Air Voltage Calibration Guideline
Adjusting Potentiometer R41 Air Voltage Guideline
Air Reading Calibration 500mVDC (+50mVDC/-10mVDC)
  1. Prepare the instrument for calibrating the Lower Cabinet Interface PCB.
    1. Remove the lower rear right cover of the instrument and place it in a location where it is safe from damage.
      Note: If the instrument is using an external house air system or a drain system, be careful not to damage the fittings and tubing attached to the cover.

    2. Locate the Lower Cabinet Interface PCB.
      Note: The Lower Cabinet Interface PCB is mounted on the left side of the lower rear right wall.

    3. Gently move the Intermediate Waste Jar out and put it to the side to gain access to the PCB.

    4. Gently push or move the Accumulator Jar to the right side to gain more access to the PCB.
      Note: For the DxI 600 instruments, the Accumulator Jar does not need to be moved to gain more access to the PCB.
    5. Remove the Lower Cabinet Interface PCB cover from the four plastic standoffs and set to the side.
    6. Drain the bubble trap assembly.
      1. Select Diagnostics > Prime Fluidics, and then select options Wash Buffer Bubble Detector, Sample Pipettor, and all Reagent Pipettors.
      2. Enter 5 cycles for each pipettor and select Disable Process Monitoring.
      3. Remove the wash buffer straws or tubes from the Wash Buffer Cubitainers and select Start Priming.
        Caution: Handle the straws or tubes with care to avoid wash buffer contamination.

      4. Once priming is complete, confirm the bubble trap assembly is empty with no fluids inside.

        Note: If there are still fluids in the bubble trap assembly, repeat substep 1f.
      5. Do not exit the Prime Fluidics Screen and do not reinstall the wash buffer straws or tubes into the Wash Buffer Cubitainers.
  2. Calibrate the Lower Cabinet Interface PCB.
    1. Connect the meter black lead to PCB TP2 GND.
    2. Connect the meter red lead to PCB TP10.

    3. Set the meter to read DC Voltage.
    4. Locate the PCB potentiometer R41 and use a small potentiometer turner tool or flat head screw driver to turn the pot.

      Note: Turning the potentiometer clockwise to increase the voltage and counterclockwise to decrease the voltage.
    5. Confirm the meter is reading 500mVDC (+50mVDC/-10mVDC).
    6. Disconnect the meter leads from the PCB and set the meter to the side.
    7. Reinstall the PCB cover.
  3. Prime the Wash Buffer Bubble Detector and all pipettors.
    1. Put the Intermediate Waste Jar and Accumulator Jar back in place.
    2. Gently reinstall the wash buffer straws or tubes into the Wash Buffer Cubitainers.
      Caution: Handle the straws or tubes with care to avoid wash buffer contamination.
    3. If the Prime Fluidics screen is still on, then ensure the options are the same from step 1f, enter 10 cycles to each pipettor select Start Priming.
      Note: If the Prime Fluidics screen was exited, then
      • Select Diagnostics > Prime Fluidics, and then select options Wash Buffer Bubble Detector, Sample Pipettor, and all Reagent Pipettors.
      • Enter 10 cycles for each pipettor, select Disable Process Monitoring, and select Start Priming.
    4. Once priming is complete, confirm the bubble trap assembly has fluids inside.

      Note: If there are air or bubbles in the bubble trap assembly, then repeat step 3.
    5. Exit the Prime Fluidics screen.
  4. Calibrate the Wash Buffer Bubble Detector sensor. Refer to Fluidics: Calibrating Wash Buffer Supply Bubble Detector procedure.
  5. Reinstall the lower rear right cover.
