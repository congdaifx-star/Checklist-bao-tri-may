Diagram - Electrical System

This Electrical System Diagram is an overview of the electrical connections in the DxI. Cable identifications are not contained in this diagram.

Diagram

The Electrical System Diagram contains all DxI 800 parts.

System Electrical Diagram.doc

Note: When working with a DxI 600 note the following differences:
  • Only one pipettor interface board
  • Reagent pipettors 3 and 4 not present
  • RV carriages 3 and 4 are not present
  • Only one ultrasonics board
  • No Lexan panel board
  • No SPU offload motor
  • Wash tower 3 and 4 are not present
    • Only three wash tower peri- pumps
    • Only two vacuum pumps
