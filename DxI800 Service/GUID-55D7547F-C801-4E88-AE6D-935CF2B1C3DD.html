Tool - Wash Carousel Locking

Drawing

Description

The Wash Carousel Locking tool is custom made. The handle is aluminum, the pin is stainless steel.

Part Number

Part # 3352A

Uses

The tool is used on DxI instruments to lock the Wash Carousel into position during certain module adjustments and alignments.

Note: This tool is also used to service Access instruments.

Instructions for Using

  • Refer to the AU: Adjusting Analytical Module procedure.
  • Refer to the AU: Aligning Analytical Module procedure.
  • Refer to the AU: Aligning Wash Carousel Angular Offset procedure.

Calibration

Not Required - Replace if damaged.
