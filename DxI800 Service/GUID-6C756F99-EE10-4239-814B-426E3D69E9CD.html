Restoring Factory Settings Using NS Utility (Mfg Cleanup)

This procedure describes how to use the NS Utility to restore factory settings on a DxI system.

Use the NS Utility to restore factory settings on a DxI system when other software or database troubleshooting procedures have been unable to resolve errors.
Warning: The NS Utility application was provided by manufacturing, to erase the instrument data easily after completing manufacturing tests. The utility was made for Windows NT systems. It may fail to work properly on a Windows XP console PC unless the specific applications listed are exited before running the utility.
Warning: Use of the NS Utility application is not advised. The actions performed by the NS Utility can be performed individually as part of other troubleshooting procedures.
Warning: When installing software, the software installation looks for a registry entry called "PrimaryConsoleIPAddress" to help identify the network port that will be communicating with the Analytical Unit. The NS Utility may delete this registry entry, and then the software installation may choose a random network port for the PC or AU address. After loading software, ensure that the expected port settings (192.168.2.1) are present on the PCs primary network port, and that the secondary port addresses do not conflict with the primary port. Corrections to the port addresses and the workgroup entries in the registry may be needed. Generally, the corrective steps are: 1) correct the network port addresses, 2) correct the workgroup IP address entries in the registry, and 3) reboot the PC to launch the user interface. Similar network port address issues may occur on the AU.
Note: For systems that run IVD software andneed to revert to an older version of the released software, refer to the Current version of the console software is newer than the version on the installation disk error message in troubleshooting. Refer to the Software: Troubleshoot Software Error Messages procedure.
Manufacturing cleanup:
  • Removes software from the PC and AU.
  • Removes the user interface database from the PC including:
    • Reagent information - all punctured packs must be unloaded and discarded.
    • Substrate information - onboard substrate must be discarded.
    • Solid Waste information - solid waste container must be emptied and reset.
    • Onboard vessel information - all vessels must be removed from the instrument (except the vessels in the bulk feeder).
    • User configuration and configured tests.
    • Calibrations.
    • APF information.
  • Erases the AU NVRAM (run hours, test counts, reagent pack counts, and substrate counts).
    Note: Refer to the Software: Modifying Run Time and Test Counts from Database procedure for details on restoring the test count and run time information.
  • Resets the IP addresses on the PC (to 192.168.2.1) and AU (to 192.168.2.2).
  • Does not remove the instrument alignment information (specific.ini).
  1. Use Task Manager to view and end specific processes.

    For Windows 8:

    1. Press [Alt] + [F4], and then enter the password Access2Support to exit the user interface.
    2. Press Ctrl + Alt + Delete keys together and select Task Manager or press Windows key, type Task Manager and open the program.
    3. From the Task Manager window, select the Processes tab.
    4. Determine if any of these processes are running in the Task Manager.
      • NexGenUI MFC Application or NexStepUI MFC Application
      • AUCommunicator DLL
      • DbMaintenance DLL
      • InstrumentModel Module
      • LISService MFC Application
      • PostOffice DLL
      • Reduce MFC Application
      • Screen TransitionTool MFC Application
    5. For each process that is running, select the process, and then select End Task.
    6. Close the Task Manager window.

    For Windows XP:

    1. Press [Alt] + [F4], and then enter the password Access2Support to exit the user interface.
    2. Select Start > Run, type taskmgr in the Run dialog box, and then select OK.
    3. From the Task Manager window, select the Processes tab.
    4. Determine if any of these processes are running in the Task Manager.
      • DbMaintenanceUD
      • AUCOMM~.EXE
      • INSTRU~.EXE
      • LISServiceUD.exe
      • NexGenUIUD.exe or NexStepUIUD.exe
      • ReduceUD.exe
      • NSWGSVUD.exe
      • POSTOF~.EXE
    5. For each process that is running, select the process, and then select End Process > Yes.
    6. Close the Task Manager window.
  2. Run the Mfg Cleanup utility.
    Note: The PC must be able to communicate with the instrument in order for the cleanup to be successful.

    For Windows XP System with Software 5.2 and below:

    1. Select Start > Programs > NexGen > NS Utility.
    2. Select the MFG Cleanup button in the NexStep Utilities dialog box.
    3. Select Yes to the Warning dialog box.
      Note: Status messages are displayed at the bottom of the NexStep Utilities dialog box.
    4. Select Exit when the cleanup is complete.
    5. Power down the instrument.
    6. Shut down the console PC.
      • Select Start > Shut Down.

    For Windows 8 System with Software 5.3.1 and above:

    1. Press Windows key, select NS Utility icon or type ns and open the program.
    2. Select the MFG Cleanup button in the NexStep Utilities dialog box.
    3. Select Yes to the Warning dialog box.
      Note: Status messages are displayed at the bottom of the NexStep Utilities dialog box.
    4. Select Exit when the cleanup is complete.
    5. Power down the instrument.
    6. Shut down the console PC.
      • Press Windows key, type turn off and select Settings > Turn off your PC > Power > Shut down.
        Note: The PC can also be shut down using Command Prompt application.
        • Press Windows key, open Command Prompt icon or type command prompt and open the program.
        • Type shutdown.exe /s /t 00 and hit Enter.
  3. Remove the supplies from the instrument.
    1. Manually remove all the reagent packs from the reagent storage module and discard all the punctured packs.
      Caution: Because the system supply information has been erased, all onboard packs, even empty ones, will be identified as full when scanned during initialization with remap selected.
    2. Remove and discard both bottles of substrate.
      Caution: Because the system supply information has been erased, all substrate bottles, even empty ones, will be identified as full when scanned during loading.
    3. Empty the solid waste and liquid waste containers.
    4. Remove all vessels from:
      • Sample wheel
      • Carriages
      • Incubator wheel
      • Wash carousel
      • Pick-and-place collets
