Automated Carryover Test

This procedure describes how to perform an automated carryover test and how to interpret the results.

Perform the automated carryover test when:
  • Replacing a sample probe.
  • Installing a new system.
  • Troubleshooting assay performance issues.
  • Performing preventive maintenance.

Sample carryover can occur when sample or reagent probes are not washed correctly, dispense and aspirate probe adjustments are incorrect, or RV contents are splashed onto the substrate probe.

These issues can be caused by:
  • Damaged or defective probes
  • Incorrect probe to wash tower alignments
  • Faulty wash tower function

The automated carryover test detects carryover on sample and reagent probes, but not on aspirate, dispense or substrate probes. This procedure uses service assay test AP25 (910) and DilTest (932).

Note: Refer to the Tests: Service Tests document.

For additional information, refer to the Tests: Automated Carryover Test Troubleshooting procedure.

The pass/fail specifications for the Automated Carryover test are shown in this table. The DxI software automatically checks the data for these values.

Note: Due to differences in the probe geometries, the pass/fail criteria differs between the sample and reagent pipettors.
Parameter Specification
Baseline RLU <9,000 RLU
Sample Pipettor <11,000 + Baseline RLU
Reagent Pipettor <6,500 + Baseline RLU
DilTest RLU >3 Million RLU
  1. If the sample probe has been replaced, then perform a Special Clean maintenance routine before the automated carryover test.
    Note: New sample probes can have residues remaining in the probe from the manufacturing process that could cause the carryover test to fail. The Special Clean should remove these residues.
  2. Perform the automated carryover test
    1. From the Main Menu, select Sample Manager > New Request  > Maintenance, select DxI Carryover as the Other Routine option, and then select OK.
    2. Determine volume and position in the racks.
      Note: Wash buffer volume is a critical variable. Use precise technique and new sample cups for repeat runs.
      Rack Position 1 Position 2 Position 3 Position 4
      Rack 1 Wash Buffer (2 mL in a 2-mL Sample Cup) NA NA NA
      Rack 2 System Check (500 µL in a 2-mL Sample Cup) Wash Buffer (500 µL in a 2-mL Sample Cup) System Check (500 µL in a 2-mL Sample Cup) Wash Buffer (500 µL in a 2-mL Sample Cup)
      Rack 3 System Check (500 µL in a 2-mL Sample Cup) Wash Buffer (500 µL in a 2-mL Sample Cup) System Check (500 µL in a 2-mL Sample Cup) Wash Buffer (500 µL in a 2-mL Sample Cup)
    3. Enter the rack IDs when prompted, and then load the racks onto the SPU.
    4. After the test is complete, select Maintenance Review > Carryover to review the results.
      • If the test passes, then this procedure is complete and no further action is required.
      • If the test fails:
        1. Troubleshoot the automated carryover test. Refer to the Tests: Automated Carryover Test Troubleshooting procedure.
        2. Make the required changes.
        3. Repeat the test.
