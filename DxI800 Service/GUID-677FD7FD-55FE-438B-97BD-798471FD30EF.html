Operator Controls Operating Principles

Purpose

This document details the operating principles for the operator controls.

Operator Controls

Operator controls described in this document include:
  • SPU load panel on the framus.
  • Status panel on the framus.
  • LED indicators on the instrument upper right front cover.

SPU Load Panel Description

The SPU load panel indicates the SPU load status and allows selection of routine or stat sample loading.

Button or Indicator Description
Onload Pusher Motion Indicator
  • Flashes green when SPU pusher is pushing sample rack toward presentation area (SPU load cover is locked).
  • On steadily after initial tray push to presentation area. Remains lit steadily until SPU pusher returns to home position (retracted) to wait for another tray load.
ROUTINE Load Button Used to load additional racks when SPU is busy processing racks that were loaded previously.
  • Homes rack pusher and unlocks SPU cover.
  • Allows placement of additional racks at end of rack queue in onload area.

Pressing the ROUTINE Load button:

  • Initiates a signal to software to load sample rack or to view contents of onload area.
  • Causes the onload pusher to move to retracted position and release cover interlock, allowing operator to load racks. When software detects that the tinted cover is closed, the rack pusher packs racks, remains in packed position, and continues processing racks.
ROUTINE Load Indicator Illuminates steady green when ROUTINE Load button is pressed (during normal rack loading). When no racks are in SPU and onload pusher is retracted, the onload pusher motion indicator light remains off.
STAT Load Button Used to load additional racks at front of rack queue (before other racks in SPU) when time to result is critical.

Pressing the STAT Load button signals software to load a STAT sample rack.

  1. If samples are being pipetted in presentation area, then these SPU events occur:
    • Current sample tube finishes pipetting.
    • Presentation tray moves into load and offload position (toward operator).
    • Onload pusher moves to retracted position.
    • Cover interlock is released.
  2. Operator pushes all racks to the right (out of and away from the presentation area). If the operator does not push all the racks from the presentation area, then the operator is alerted to remove the racks (push them to the right of the presentation area) before processing any more racks.
  3. STAT sample racks can be placed first in line for bar code label reading and pipetting.
  4. When software detects that the SPU cover has been closed, the onload pusher packs the racks and remains in the packed position.
  5. When ingested (and confirmed by reading patient bar code label), the test is started after sample information is retrieved from the console on the next open cycle (9-second pitch).
STAT Load Indicator Illuminates steady green when the STAT Load button is pressed.
