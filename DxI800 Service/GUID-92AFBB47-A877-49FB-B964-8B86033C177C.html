J10 - PCB - Data Acquisition (DAQC)

  • Power and enable signal to the LED reference run through J10 located on the right end of the DAQC PCB.
  • CABLE, LED REFERENCE connects J10 (round PS2 type connector) to the LED reference.
  • LED reference is located inside the analytical module near the luminometer.
J10 Description Signal / Voltage To / From / Notes

1

LED Power

+ 12V

To the LED reference from the DAQC PCB connection to the CPU backplane at J3-B9.

12V power for the LED reference.

Brown wire to brown wire on the LED reference cable.

2

LED Enable

0.7V or + 5V

To the LED reference from DAQC PCB U1B-6.

0.7 V = LED on, 5 V = LED off.

Red wire to yellow wire on the LED reference cable.

3

LED Ground

0V

To the LED reference.

Ground (filtered) for the LED reference.

Black wire to black wire on the LED reference cable.

4

GND

0V

Ground (cable shield).

5

GND

0V

Ground (cable shield).

6

GND

0V

Ground (cable shield).
