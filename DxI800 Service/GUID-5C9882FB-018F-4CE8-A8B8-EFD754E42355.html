Installing LogHelper

This procedure describes how to install the event log analysis tool LogHelper.

Use the event log analysis tool LogHelper to:
  • Analyze DxI instrument event log messages
  • Provide a historical summary of system errors
Event log errors are categorized and summarized for the user under their respective subsystem module. The following summary details are displayed:
  • Date and time
  • Severity level
  • Operation mode
  • Occurrence frequency
  • Total Event Log period
  • Total tests counts
  • Test counts (per year)
Two slightly different versions of LogHelper are available.
  • Laptop or desktop PC version
  • UniCel DxI console PC version
Caution: If the UniCel DxI 600 or 800 instrument is running software V4.0, do not use LogHelper. LogHelper is not validated for DxI instrument software V4.0.

Install LogHelper.
  • For users of a laptop or desktop PC:
    Note: This version requires exported event log files using the EventTestUD application.

    Refer to the Software: Transferring Event Log Files procedure.

    1. Create a folder on the laptop or desktop PC hard drive and name the folder LogHelper.
    2. Right click on each file in the Attachment Table and select Save to save these files into the LogHelper folder.
      Caution: If any of the attachment files are not installed, LogHelper is unusable
  • For users of a UniCel DxI console PC:
    Note: This version can automatically read the event log files located in the POET database. Event log files do not need to be exported.
    1. Right click on each file, and select Save to save these files into the LogHelper folder.
      Note: If any of the attachment files are not installed, LogHelper is unusable.
