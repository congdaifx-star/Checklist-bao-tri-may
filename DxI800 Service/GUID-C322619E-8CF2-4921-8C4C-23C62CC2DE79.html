PCB - Interface - Sample Storage

Purpose

This document provides these details for the Sample Storage Interface PCB:
  • Drawings.
  • Details (Test Points, LEDs, Connector Overview, Connector Pin-outs).
  • Schematics.
  • Location.

Drawings

Details

The sample Storage Interface PCB connects to these devices:
  • Thermistor - sample storage.
  • Motor - sample storage wheel.
  • Position encoder and home sensor.
  • MCC Backplane / MCC0 PCB.
