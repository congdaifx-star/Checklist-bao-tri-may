Database - Reorganizing Database

This procedure describes how to reorganize the DxI database.

Reorganize the database when:
  • The user interface is unresponsive.
  • Clearing jammed critical events.
  • Detecting checksum errors in the database.
  • Compressing the database to reduce the size of the database and improve the performance of the user interface.
Prerequisites:
  • Create a local copy of the database. Refer to Creating Local Copy of Database.
For the following action... Refer to...
Reorganize the database on Windows XP console PC with DxI Software 5.2 and below Step 1
Reorganize the database on Windows 8 Mini PC with DxI Software 5.3.1 and above Step 2
Reorganize the database on Windows 10 Mini PC with DxI Software 7.2.0 and above Step 3
  1. Reorganize the database on Windows XP console PC with DxI Software 5.2 and below.
    1. Open the database application, select Start > Programs > DxI > Poet Developer or Poet Administrator.
    2. In the POET Menu, select Database > Reorganize.
    3. To reorganize the NexStepBase database, enter the Host name Localhost and the Database NexStepBase (case sensitive).
    4. Select Reorganize, and then Yes to the message to begin the reorganization process.
    5. If errors occur, then:
      • Verify that the host name and database name were entered correctly.
      • If there is a File Permissions error, exit and relaunch the Poet Object Server application. Select the Poet Object Server icon at the bottom right corner of the display. Exit the POET application. Close any error messages. Restart the application by selecting Start > Run, type ptserv32.exe on the Open text line, and then select OK.
      • If there is a No Partner error, make sure that the Poet Object Server application is running.
      • If there is a database already exists error, delete the c:\nexgen\console\drw\objects.reo file.
      • If there is a Recovery is enabled error, select Database > Force No Recovery to delete a corrupt recovery database.
      • If there is a Checksum error, select Database  > Repair. In the Repair Menu, select all the delete options for a corrupted record
      Note:
      • Review the Reorganization Messages display for Checksum errors.
      • Reorganization can take from 5 to 20 minutes depending on the size of the database.
      • A percent completion is displayed while the reorganization is running.
    6. To reorganize the EventBase database, enter the Host name Localhost and the Database EventBase (case sensitive).
    7. Select Reorganize, and then select Yes at the message to begin the reorganization process.
      Note:
      • Refer to the errors listed in the NexStepBase step.
      • If it has an unrecoverable error, the EventBase database can be deleted in Windows Explorer. A new EventBase database will be created the next time the user interface is launched.
    8. When complete, select File > Exit to exit the POET application.
    9. If the Repair or Force No Recovery processes have been performed, then perform a Database Consistency Check procedure after completing the reorganization process.
      Note: Refer to the Database - Performing Database Consistency Check procedure.
    10. Launch the user interface.
      Note: If the database problem has been corrected, you can delete the copy of the database.
  2. Reorganize the database on Windows 8 Mini PC with DxI Software 5.3.1 and above.
    Note: DxI Software 5.3.1 and above are compatible with Windows XP console PC. If either software was installed on the Windows XP console PC, then follow the Windows XP section to launch Fast database application. Poet database application is replaced by Fast database application.
    1. Press Windows key, select Fast Developer or Fast Administrator icon or type developer or administrator and open the program.
    2. In the Fast Main Menu, select Database > Reorganize.
    3. To reorganize the NexStepBase database, enter the Host name Localhost and the Database NexStepBase (case sensitive).
    4. Select Reorganize, and then Yes to the message to begin the reorganization process.
    5. If errors occur, then:
      • Verify that the host name and database name were entered correctly.
      • If there is a File Permissions error, exit and relaunch the Fast Objects Server application.
        • Press Ctrl + Alt + Delete and select Task Manager or right click on the task bar and select Task Manager.
        • In the Task Manager box, click on Processes, select FastObjects Server and click on End Task in the bottom corner of the box.
        • Restart the server by pressing Windows key and select the Fast Objects Server icon or type run, open the Run program, typing ptserv32.exe on the text line, and selecting OK.
      • If there is a No Partner error, make sure that the Fast Objects Server application is running.
      • If there is a database already exists error, delete the c:\nexgen\console\drw\objects.reo file.
      • If there is a Recovery is enabled error, select Database > Force No Recovery to delete a corrupt recovery database.
      • If there is a Checksum error, select Database  > Repair. In the Repair Menu, select all the delete options for a corrupted record
      Note:
      • Review the Reorganization Messages display for Checksum errors.
      • Reorganization can take from 5 to 20 minutes depending on the size of the database.
      • A percent completion is displayed while the reorganization is running.
    6. To reorganize the EventBase database, enter the Host name Localhost and the Database EventBase (case sensitive).
    7. Select Reorganize, and then select Yes at the message to begin the reorganization process.
      Note:
      • Refer to the errors listed in the NexStepBase step.
      • If it has an unrecoverable error, the EventBase database can be deleted in Windows Explorer. A new EventBase database will be created the next time the user interface is launched.
    8. When complete, select File > Exit to exit the Fast application.
    9. If the Repair or Force No Recovery processes have been performed, then perform a Database Consistency Check procedure after completing the reorganization process.
      Note: Refer to the Database - Performing Database Consistency Check procedure.
    10. Launch the user interface.
      Note: If the database problem has been corrected, you can delete the copy of the database.
  3. Reorganize the database on Windows 10 Mini PC with DxI Software 7.2.0 and above.
    Note: DxI Software 7.2.0 and above are compatible with Windows XP console PC. If either software was installed on the Windows XP console PC, then follow the Windows XP section to launch Fast database application. Poet database application is replaced by Fast database application.
    1. Press Windows key, type developer or administrator and open the Fast Developer or Fast Administrator program.
    2. In the Fast Main Menu, select Database > Reorganize.
    3. To reorganize the NexStepBase database, enter the Host name Localhost and the Database NexStepBase (case sensitive).

        • Press Ctrl + Alt + Delete and select Task Manager or right click on the task bar and select Task Manager.
        • In the Task Manager box, click on Processes, select FastObjects Server and click on End Task in the bottom corner of the box.
        • Restart the server by pressing Windows key + R to open the Run program, typing ptserv32.exe on the text line, and selecting OK.
      • If there is a No Partner error, make sure that the Fast Objects Server application is running.
      • If there is a database already exists error, delete the c:\nexgen\console\drw\objects.reo file.
      • If there is a Recovery is enabled error, select Database > Force No Recovery to delete a corrupt recovery database.
      • If there is a Checksum error, select Database  > Repair. In the Repair Menu, select all the delete options for a corrupted record
      Note:
      • Review the Reorganization Messages display for Checksum errors.
      • Reorganization can take from 5 to 20 minutes depending on the size of the database.
      • A percent completion is displayed while the reorganization is running.
    6. To reorganize the EventBase database, enter the Host name Localhost and the Database EventBase (case sensitive).
    7. Select Reorganize, and then select Yes at the message to begin the reorganization process.
      Note:
      • Refer to the errors listed in the NexStepBase step.

    8. When complete, select File > Exit to exit the Fast application.

      Note: Refer to the Database - Performing Database Consistency Check procedure.
