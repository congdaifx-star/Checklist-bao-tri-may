Database - Restoring Console PC from Backup

This procedure describes how to restore the database of a DxI console PC from a USB backup drive.

DxI Software must be installed before performing the following procedure.

Restore the database of a Windows XP console PC with DxI Software 5.2 and below from a backup when:
  • Replacing a defective or corrupt hard drive.
  • Swapping a functioning, but suspect, PC with a new PC.
  • Restoring the database using a USB drive.
  1. Load the backup media.
    1. In the Main Menu screen, press [Alt] + [F4], and then enter the password Access2Support to exit the user interface.
    2. Exit the Poet Object Server, if present.
    3. Insert the USB drive into a USB port on the PC.
      Note: If the database is not available for restoration from the USB drive, then attempt to copy the database from the hard drive of the old PC.

      Refer to the Software: Transferring Files Between PC Hard Drives procedure.

  2. Determine the files to use for backup. The two options are:
    • Load files from the USB drive.
    • Loads files from the old hard drive.
    Note: The backup folder on the PC hard drive always contains the most recent backup file. If there is a backup folder, then copying the files from the USB backup drive might not be necessary.
    Note: If the database is not available for restoration from the USB drive, then attempt to copy the database from the hard drive of the old PC.
  3. To load files from the USB drive:
    1. Press Start > Programs > Windows Explorer.
    2. Browse to and open the USB BACKUPDRIVE.
    3. Copy the most recently saved backup folder found in the BACKUPDRIVE, and then paste the backup folder into the C:\NexGen\Console folder on the PC hard drive (replace existing files).
    4. Exit Windows Explorer.
      Note:
      • Windows XP is required for support of the USB drive. USB support must be enabled in the PC CMOS.
      • The immediate or scheduled backup stores the previous five backups in the C:\NexGen\Console\ directory.
  4. To load backup files from the old hard drive.
    Refer to the Software: Restoring Console PC Database from Files Transferred Between Hard Drives procedure.
  5. Restore the backup files.

    Option 1: Restore the database by manually replacing the database folders.
    1. Open Windows Explorer.
    2. Browse to C:\NexGen\Console folder and open the Backup folder.
      Note: Make sure the Backup folder was copied properly from the USB flash drive and has the latest data or information.
    3. Open DRW folder in the Backup folder and then Copy NexStepBase and EventBase folders.
    4. Browse back to C:\NexGen\Console folder, open DRW folder, then Paste NexStepBase and EventBase folders to replace the existing folders.
    5. Exit Windows Explorer and restart th user interface.
    Option 2: Restore the database using the Restore Utility.
    1. Press Start > Programs > NexGen > Restore Utility.
      Note:
      • When restoring onto a new PC or a new PC hard drive, the software must be loaded first because the software contains the Restore Utility.
      • Before starting the restoration, exit the user interface. Keep the instrument powered on.
    2. In the Restore Utility, select Next > Restore Console PC > Next.
    3. Select Restore Registry and Database. Select Next.
      Note: If there is an error copying the files, confirm that you have exited the Poet Object Server and then retry restoration.
    4. Select Next to the IP address information.
      Note: Typically the IP address for the console is 192.168.2.3, the workgroup server is 192.168.2.3, and the analyzer is 192.168.2.4. For Windows XP systems, 127.0.0.1 is the typical workgroup server IP address.
    5. Select Restore Supplies From Analyzer.
      Note:
      • During restoration, the AU must be powered on and must be able to communicate on the TCP/IP network.
      • An incorrect AU or server IP address in the registry causes an error at this step.
    6. Select Next.
    7. If a Delete Reagent dialog window is displayed (reagents are listed as off-board punctured or off-board unpunctured), select and then delete the off-board punctured reagents. Select Next. Select and then delete any off-board confirmed unpunctured reagents (reagents that cannot be found and confirmed to be unpunctured). Select Next.
      Caution: Any punctured reagents that were used after the backup was made and that were not on-board during the restoration need to be identified and discarded. When reagents are off-board, their status is not stored in instrument memory.
    8. Select Finish with Reboot selected.
      Note:
      • When restoration is complete, both the console PC and the AU reboot automatically.
      • The user interface launches. While the instrument reboots, it might not appear to communicate for up to 5 minutes.
  6. Verify instrument operation.
    1. Confirm that the software version shown at the bottom right of the Main Menu is the current version.
      If needed, update the software and the APF to the current version.
    2. In the Main Menu, select Supplies > Bulk Supplies. Check the status of the supply inventory and load any required supplies.
      Note: The restore process identifies on-board expired or deleted reagent packs with question marks (???). Having one or two on-board packs with question marks might be normal. If the substrate supplies are empty and all on-board reagents are identified with question marks (???), then you might have selected Restore Analyzer inadvertently. Other possibilities are that the NVRAM PCB in the AU is defective or running MFG Cleanup erased the AU NVRAM.
    3. In the Main Menu, select Diagnostics > Initialize. Select Clear all Positions and Remap the reagent storage.
      Caution: If there are on-board deleted or expired reagents (marked with question marks) after restoration, then unload all the reagents and confirm that the unopened reagents on the reagent supply display are actually unopened. Reload the reagent packs that are not marked with question marks (???).
    4. Confirm that the following items are configured correctly and are functional:
      • Printer setup
      • Auto Delete setup
      • Scheduled Backup
      • LIS
      • PROService
    5. Perform QC and ensure that the results are within customer specifications and that there are no problems posting results to the restored database.

Restore the database of a Windows 8 Mini PC with DxI Software 5.3.1 and above from a backup when:
Caution: Restore from backup >> Restore Supplies from Analyzer does not work in SW V 5.3.1 where the AU NVRAM is simulated. All punctured reagents will need to be discarded if restoring from a previous backup (or immediate backup if the system was running when the issue occurred).
Note: DxI Software 5.3.1 is compatible to Windows XP console PC. If the software was installed on Windows XP console PC, then follow the Windows XP section to restore the database. Poet database application is replaced by Fast database application.
  • Swapping a functioning, but suspect, PC with a new PC.
  • Restoring the database using a backup USB drive.
  1. Load the backup media.
    1. In the Main Menu screen, press [Alt] + [F4], and then enter the password Access2Support to exit the user interface.
    2. Exit the Fast Objects Server, if present.
      • Press Ctrl + Alt + Delete and select Task Manager or right click on the task bar and select Task Manager.
      • In the Task Manager box, click on Processes, select FastObjects Server and click on End Task in the bottom corner of the box.
    3. Insert the USB drive into a USB port on the PC.
  2. Determine the files to use for backup. The two options are:
    • Load files from the USB drive.
    • Loads files from the old hard drive.
    Note: The backup folder on the PC hard drive always contains the most recent backup file. If there is a backup folder, then copying the files from the USB backup drive might not be necessary.
    Note: If the database is not available for restoration from the USB drive, then attempt to copy the database from the hard drive of the old PC.
  3. To load files from the USB drive:
    1. Press Windows key and select File Explorer icon or type file explorer and open the program.
    2. Browse to and open the USB BACKUPDRIVE.
    3. Copy the most recently saved backup folder found in the BACKUPDRIVE, and then paste the backup folder into the C:\NexGen\Console folder on the PC hard drive (replace existing files).
    4. Exit File Explorer.
  4. Restore the backup files.
    Option 1: Restore the database by manually replacing the database folders.
    1. Open File Explorer.
    2. Browse to C:\NexGen\Console folder and open the Backup folder.
      Note: Make sure the Backup folder was copied properly from the USB flash drive and has the latest data or information.
    3. Open DRW folder in the Backup folder and then Copy NexStepBase and EventBase folders.
    4. Browse back to C:\NexGen\Console folder, open DRW folder, then Paste NexStepBase and EventBase folders to replace the existing folders.
    5. Exit File Explorer and restart the user interface.
    Option 2: Restore the database using the Restore Utility.
    1. Press the [Windows] key, and then select Restore Utility icon or type restore utility and open the program.
      Note:
      • When restoring onto a new PC or a new PC hard drive, the software must be loaded first because the software contains the Restore Utility.
      • Before starting the restoration, exit the user interface. Keep the instrument powered on.
    2. In the Restore Utility, select Next > Restore Console PC > Next.
    3. Select Restore Registry and Database. Select Next.
      Note: If there is an error copying the files, confirm that you have exited the Poet Object Server and then retry restoration.
    4. Select Next to the IP address information.
      Note: Typically the IP address for the console is 192.168.2.3, the workgroup server is 192.168.2.3, and the analyzer is 192.168.2.4. For Windows 8 systems, 127.0.0.1 is the typical workgroup server IP address.
    5. Select Restore Supplies From Analyzer.
      Note:
      • During restoration, the AU must be powered on and must be able to communicate on the TCP/IP network.
      • An incorrect AU or server IP address in the registry causes an error at this step.
    6. Select Next.
    7. If a Delete Reagent dialog window is displayed (reagents are listed as off-board punctured or off-board unpunctured), select and then delete the off-board punctured reagents. Select Next. Select and then delete any off-board confirmed unpunctured reagents (reagents that cannot be found and confirmed to be unpunctured). Select Next.
      Caution: Any punctured reagents that were used after the backup was made and that were not on-board during the restoration need to be identified and discarded. When reagents are off-board, their status is not stored in instrument memory.
    8. Select Finish with Reboot selected.
      Note:
      • When restoration is complete, both the console PC and the AU reboot automatically.
      • The user interface launches. While the instrument reboots, it might not appear to communicate for up to 5 minutes.
      Note: When rebooting the Privacy & Security compliant Windows 8 or Windows 10 PC, you must enter security password "Access2Admin" when prompted to launch Windows.

  5. Verify instrument operation.
    1. Confirm that the software version shown at the bottom right of the Main Menu is the current version.
      If needed, update the software and the APF to the current version.
    2. In the Main Menu, select Supplies > Bulk Supplies. Check the status of the supply inventory and load any required supplies.
      Note: The restore process identifies on-board expired or deleted reagent packs with question marks (???). Having one or two on-board packs with question marks might be normal. If the substrate supplies are empty and all on-board reagents are identified with question marks (???), then you might have selected Restore Analyzer inadvertently. Other possibility is that running MFG Cleanup erased the AU test count and run time.
    3. In the Main Menu, select Diagnostics > Initialize. Select Clear all Positions and Remap the reagent storage.
      Caution: If there are on-board deleted or expired reagents (marked with question marks) after restoration, then unload all the reagents and confirm that the unopened reagents on the reagent supply display are actually unopened. Reload the reagent packs that are not marked with question marks (???).
    4. Confirm that the following items are configured correctly and are functional:
      • Printer setup
      • Auto Delete setup
      • Scheduled Backup
      • LIS
      • PROService
    5. Perform QC and ensure that the results are within customer specifications and that there are no problems posting results to the restored database.
