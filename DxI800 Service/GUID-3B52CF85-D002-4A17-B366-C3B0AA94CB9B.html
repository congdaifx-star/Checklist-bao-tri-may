Capturing RS-232 Communication Data During Troubleshooting

This procedure describes how to capture RS-232 serial communications data between the DxI and the connection unit.

Capture RS-232 serial communications data between the DxI and the connection unit when analysis of the communications data is required for troubleshooting.

A software utility program called LasUtilities.exe (resident in the DxI console PC) can capture the serial communications data (ASCII code) between the DxI and the connection unit. The program must be transferred to the AU to connect to the serial communications data. The captured data exchange can also be saved to a file and printed.

Operating Principles and Communication Protocol
  • For detailed explanations of the connection unit operating principles, refer to LAS - OP - Connection Unit.
  • For additional details of the RS-232 serial communications protocol, refer to LAS Vender Information.
RS-232 Message Structure
  • For a description of major components, ASCII characters, and structure of the RS-232 messages between the DxI and the connection unit, refer to the LAS: Troubleshoot Communication Data document.
Example of Serial Communication
  • For an example of an RS-232 communication sequence that occurs while processing two samples through the connection unit spur, refer to the LAS: Troubleshoot Communication Data document.
  1. Start the data capture program.

    For Windows XP System with Software 5.2 and below:

    1. Select Start  > Programs > Window Explorer.
    2. Navigate to the C:\NexGen\Console\Bin folder and open it.
    3. Right-click on the LasUtilities.exe file, and select Copy.
    4. On the console PC, select Start > Run.
    5. Enter \\192.168.2.4\C$\AU, and then select OK.
    6. Right-click in the Explorer window that opens, and select Paste.
      If a message The folder already contains a file named... occurs, select No, and skip the next step.
    7. Navigate to the C:\NexGen\Console\Bin folder, and open it.
    8. On the console PC, select Programs > Administrative Tools > Remote Desktop > Connection to AU PC.
    9. In Desktop Sharing, select My Computer > C:  > AU.
    10. Double-click on the LasUtilities.exe file.
    11. Enter 192.168.2.4 in the Instrument IP. Leave the User, Password, and Domain lines blank.
      Caution: Do not enter anything in the User line (not even a space character) or Unable to find AU... errors occur when connect is selected.
    12. Select the Connect button to initiate the capture process. When the program detects a successful connection, the top bar displays LAS Communication monitor Connected to: 192.168.2.4.
      Note: The connection captures data for up to 30 minutes, then terminates.

    For Windows 8 System with Software 5.3.1 and above:

    1. Press Windows key, select File Explorer icon or type file explorer and open the program.
    2. Navigate to the C:\NexGen\Console\Bin folder and open it.
    3. Right-click on the LasUtilities.exe file, and select Copy.
    4. On the console PC, press Windows key, type run and open the Run program.
    5. Enter \\192.168.2.4\C$\AU, and then select OK.
    6. Right-click in the Explorer window that opens, and select Paste.
      If a message The folder already contains a file named... occurs, select No, and skip the next step.
    7. Navigate to the C:\NexGen\Console\Bin folder, and open it.
    8. On the console PC, press Windows key, select Remote Desktop Connection icon or type remote and open the desktop connection program.
    9. In Desktop Sharing, select Computer > Local Disk (C: ) or AU_PC (C:)  > AU.
    10. Double-click on the LasUtilities.exe file.
    11. Enter 192.168.2.4 in the Instrument IP. Leave the User, Password, and Domain lines blank.
      Caution: Do not enter anything in the User line (not even a space character) or Unable to find AU... errors occur when connect is selected.
    12. Select the Connect button to initiate the capture process. When the program detects a successful connection, the top bar displays LAS Communication monitor Connected to: 192.168.2.4.
      Note: The connection captures data for up to 30 minutes, then terminates.
  2. Capture communications data and save the data to a file.
    1. Process tubes through the connection unit.
      The LAS Utilities program displays the data as it is being captured.
      Note: Data generation starts when a tube arrives at the Query BCR.
    2. Select the Save... button. In the Save As window, select a file location and then select Save.
      Note: The data is saved with a file name in this format:

      LAS_log_061005_1641.txt. The file name shows the date and time the data is saved. In this case, it is June 10, 2005 at 4:41 PM.

    3. To display and print the saved data, locate the desired LAS_log file and double-click on the file to open it.
      Note:
      • For Windows XP: If the default Save As location is not changed, the file is in the My Documents folder, or whatever folder is set as the default save folder.
      • For Windows 8: If the default Save As location is not changed, the file is in the Documents folder, or whatever folder is set as the default save folder.
    4. Close all Desktop Sharing and Windows or File Explorer windows.
