Troubleshooting Sample Pipettor

Purpose

This document provides troubleshooting information for the sample pipettor.

General Sample Pipettor Issues

Issue Possible Causes and Areas to Troubleshoot
Sample pipettor crashed into a capped tube or a rack.
  • Verify that x- and z-motion is not impeded by tubing or cables.
  • Verify sample pipettor alignments.
    Note: Refer to the SP: Aligning Sample Pipettor procedure.
  • Perform carryover test before running any more patient samples.
    Note: Refer to the Tests: Carryover Test procedure.
Sample pipettor motion failures
  • Verify that x- and z-motion is not impeded by tubing or cables.
    • Check the placement of the bulk feeder upper ejector sensor cables.
  • Exercise the device in Device Diagnostics.
  • Verify sample pipettor alignments.
    Note: Refer to the SP: Aligning Sample Pipettor procedure.
  • Check bearings and guide rods.
    Note: Refer to the Instrument: Lubrication procedure.
  • Reseat MCC PCB number 0.
  • Reseat all ribbon cables and power harnesses on interface PCB and MCC backplane.

Sample Pump Issues

Refer to the Fluidics: Troubleshooting Pumps (Sample/Wash/Precision) procedure.

Sample Probe Issues

Issue Possible Causes and Areas to Troubleshoot
Teflon receding Refer to the Specs - Sample Pipettor Module document.

Diagnostic Procedures

If this issue exists, Then perform these steps
Failed carryover test
  • For software V 4.0 or higher: Perform the automated carryover test.
    Note: Refer to the Tests: Automated Carryover Test procedure.
  • For software V2.4 or lower: Perform the manual carryover test.
    Note: Refer to the Tests: Carryover Test procedure.
RF level sense errors
  • If the error occurs only on Special Clean, then make a new 70% dilution. Methanol or ethanol can be used, but it must be diluted with Wash Buffer II (7 parts methanol or ethanol and 3 parts Wash Buffer II).
  • If the instrument is not on an automation line, then perform a SPU RF Level Sense Test.
    Note: Refer to the SP: Performing Sample Pipettor Level Sense Test procedure.
  • If the instrument is on an automation line, then perform an LAS RF Level Sense Test.
    Note: Refer to the LAS: Performing LAS RF Level Sense Test procedure.

Instruments on Automation Systems (LAS)

To troubleshoot sampling problems and RF level sense errors on DxI instruments attached to automation lines, refer to the LAS: Troubleshooting LAS Sampling Problems procedure.
