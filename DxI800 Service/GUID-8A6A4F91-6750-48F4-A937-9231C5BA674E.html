Magnetic Particle Test

This procedure describes how to test system functionality not tested by System Checks or Service Assays.

Required Materials (required to perform the Magnetic Particle Test on four pipettors):
  • two boxes of aTnI reagent (four packs)
  • one box of aTnI calibrators (or a high control near the S4 calibrator value)
  • Wash Buffer
  • 500-µL pipet and tips.
  • 2-mL cups
Note: The aTnI assay is a good choice for the Magnetic Particle Test because it is fast and has a hot conjugate which stresses the particle washing function. If aTnI is not available, then use an alternate assay, but the sample volumes and types required are affected.
This procedure describes how to perform a test of system functionality not tested by System Checks or Service Assays, including:
  • Ultrasonic mixing in reagent packs (magnetic particle resuspension) and
  • Magnetic particle washing.

Use these guidelines to determine which action to perform.

  1. Review troubleshooting and address any known causes of poor magnetic particle performance before proceeding.
    Note: Refer to the Tests: Magnetic Particle Test Troubleshooting procedure.
  2. Prepare a high sample using a box of aTnI calibrators.
    1. Open the calibrator vials S1 through S5. Prepare a high sample using a box of aTnI calibrators.
    2. Pour them all into one container and mix well.
      Note: If a competitive assay is used instead of aTnI, then a low sample such as S0 calibrator or wash buffer must be used instead of a high sample.
  3. Perform a single pipettor run.
    1. Navigate to the Reagent Inventory screen, and unload all aTnI reagent packs that are on-board the DxI instrument.
    2. Load one new, unmixed aTnI reagent pack.
      Note: Before loading the pack, confirm that all of the magnetic particles are settled at the bottom of the well, and do not rock or invert the pack.
    3. Use one of these methods to run only one pipettor at a time:
      • Configure the aTnI assay to run on only one pipettor (Configure > Tests)
      • Disable three of the four pipettors (Configure > System Setup > Supplies Setup)
    4. Obtain two racks designated for 2-mL sample cups.
    5. Place 2-mL cups in positions 1 and 2 of the first rack and in all four positions of the second rack.
    6. Pipette 500 µL of the high sample into the two cups in the first rack.
      Note: If an assay other than aTnI is used, then a volume >500 µL might be required. Also, if a competitive assay is used, then a low sample such as S0 calibrator or wash buffer must be used instead of a high sample.
    7. Pipette 500 µL of Wash Buffer into the four cups in the second rack.
      Note: If an assay other than aTnI is used, then a cup volume >500 µL might be required.
    8. Program all cups in both racks to run five reps of aTnI (all six cups). Load the first rack (with two cups) into the SPU followed by the second rack (with four cups).
    9. Repeat a single pipettor run for each of the remaining pipettors.
      Note: Each run must complete before starting the next run.
  4. Evaluate the results of the particle test runs.
    1. On the DxI console, select Test Result > Filter, and then select All Samples Loaded Between.
    2. Select a time range that includes the particle test results, and then select OK.
    3. Highlight the results from all of the particle test runs, select Copy to Disk, alter the file name, and then select Current Selection.
    4. Insert a formatted 3.5-in floppy disk into the A: drive of the console PC (or designate an alternate save destination), and select OK.
    5. Transfer the file to the console PC (or alternate save destination), and then open the file.
      Note: It is a *.csv file, so Excel launches automatically when you open the file.
    6. Highlight and copy the cells containing the RLU results (column M) from one pipettor (30 results per pipettor).
    7. Double-click on the attached particle test spreadsheet file, select Open, and then paste the copied data into cell H7 in the spreadsheet. The spreadsheet displays a Pass or Fail status under the Results headings of the two sections.
      Particle Test.xls
    8. Do a Save As to change the name and location of the altered file, and then fill in the cells for TECH, DATE, CHEM... etc., and print a copy of the spreadsheet.
    9. Repeat the highlight, copy, paste, and print actions to obtain spreadsheet printouts for all four pipettors.
    10. If any test did not pass, identify which pipettor failed, and proceed to Troubleshooting.
      Note: Refer to the Tests: Magnetic Particle Test Troubleshooting procedure.
