Performing LAS RF Level Sense Test

This procedure describes how to perform level sense test for LAS track samples.

Perform the LAS RF Level Sense Test to identify possible causes for level sense failures or to verify level-sensing at the sample probe.

Perform the LAS RF Level Sense Test.
  1. From the Main Menu, select Diagnostics > Device Diagnostics > RF Level Sense  > LAS.
  2. Run a dry test.
    1. Select 20 repetitions for Dry Test and LAS Autoaliquot Tube for Container Type.
      Caution: If a gel tube is used in the dry test or the selected option for container type does not match the actual container type, the sample probe can be damaged.
    2. Confirm that the carrier and tube are in the aspiration position. Select Load a Carrier  > OK > Start Test.
    3. Select the Print Report at End of Test option.
    4. When the test is complete, select Release Carrier.
  3. Run a wet test.
    1. Select 20 repetitions for Wet Test and LAS Autoaliquot Tube for Container Type.
      Caution: If a gel tube is used in the dry test or the selected option for container type does not match the actual container type, the sample probe can be damaged.
    2. Fill the auto-aliquot tube with 200 µL of wash buffer.
    3. Select the Print Report at End of Test option.
    4. Confirm that the carrier and tube are in the aspiration position. Select Load a Carrier  > OK > Start Test.
    5. When the test is complete, select Release Carrier.
  4. Verify that the failure count is zero for both the dry test and the wet test runs. If failures occur, perform repairs and repeat tests.
