Running Mixer Motor During Troubleshooting

This procedure describes how to run the mixer motor for troubleshooting the mixer tach and motor drive wiring in the analytical module.

  1. Run the mixer motor to troubleshoot the mixer tach and the motor drive wiring.
    1. Move the mixer motor power connector from J2 (Mixer Motor) to J4 (Mix Arm Eject) on the upper analytical module interface PCB.
    2. Select Diagnostics > Device Diagnostics > Digital Devices > Digital Outputs, select MixerArmEjector, and then select Toggle Output Value.
      Note:
      • The eject arm connector provides 24 V to the motor so that it runs at maximum speed for troubleshooting purposes
      • Run newly installed spin grips using 24 V for 5 minutes before use.
      • When enabled, the output LED indicator is green (ON).
  2. Use a meter to check the mixer motor current for excessive load on the motor.
    1. Reconnect the mixer motor power connector to J2 (Mixer Motor) on the upper analytical module interface PCB.
    2. Connect the meter black lead to the TP4 (Ground) and red lead to TP15 (Mixer Current) on the upper analytical module interface PCB.
    3. Turn the meter to measure DC voltage.
    4. Select Diagnostics > Device Diagnostics > Digital Devices > Digital Outputs, select MixerEnable, and then select Toggle Output Value.
      Note: Select MixerDirection > Toggle Output Value to switch the direction of the mixer motor.
      Note: A voltage greater than 1.25 V DC indicates excessive load on the motor possibly caused by defective idler bushing, spinner bearing, frayed mixer belt, or belt rubbing on something.
  3. Verify operation of the mixer and mixer speed detections systems.
    1. Select Diagnostics > Initialize System > OK to observe the mixer belt and tensioner motion sequence during the automatic mixer calibration.
    2. Repeat initialization several times and verify that:
      • Belt moves smoothly in both directions.
      • Mixer calibration passes each time.
      Note: The mixer calibration sequence starts when the progress bar reaches approximately 75%.
    3. Remove all safety interlock and cover switch bypass keys, close all covers, and reinitialize the system.
  4. Verify system operation.
    1. Perform system verification as stated in the Verification of Service Repair document .
      Refer to the Admin: Verification of Service Repair document.
