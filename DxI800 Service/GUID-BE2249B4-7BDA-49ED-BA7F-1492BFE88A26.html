Decontaminating and Cleaning

This procedure describes how to clean, empty, and disinfect a DxI instrument. Decontaminating and Cleaning is the second of four procedures for deinstalling a DxI instrument. Perform this procedure when preparing an instrument for storage or deinstalling an instrument to be shipped to another site or returned to Chaska.

Required Materials
  • Touchscreen Monitor and PC Decontamination kit. Refer to DxI parts list for part numbers
  • Lint-free towels
  • 0.5% solution of sodium hypochlorite. Prepare by mixing 1 part household bleach with 9 parts water.
    Note:
    • Use either regular or ultra bleach to make the sodium hypochlorite solution.
    • Refer to local documentation or the Returned Instrument Decontamination Procedure in the United States Customer Operations Database for alternative decontaminants.
Caution: Use bleach only to clean the exterior surfaces of the instrument. Do not use bleach to flush tubing or internal instrument components.

This procedure includes steps to remove all customer information and patient data. These steps are only necessary when shipping the instruments.

This procedure is the second of four procedures for deinstalling a DxI. All four procedures are summarized in the Deinstall Quick Reference. If an instrument is being moved within a building or temporarily stored, not all procedures are necessary. When performing the deinstallation procedures, consider:
  • Moving and shipping conditions
  • Final destination
  • Environmental issues
  1. Prepare the instrument.
    1. Verify the rinsing and priming procedure is complete. The procedure includes a Special Clean.
      Note: Refer to the Deinstalling: Rinsing and Priming Dry (Dry Method) or Deinstalling: Rinsing and Priming Dry (Siphon Method) procedure.
    2. Perform an immediate back-up. Give all DxI back-up tapes to the customer for storage or secure disposal.
  2. Clean the software using the NS Utility. Refer to Software: Restoring Factory Settings Using NS Utility (Mfg Cleanup) procedure for more details.
    Cleaning the software deletes these items:
    • Supply counts
    • Laboratory information
    • Event log information
    • QC and patient data

    For Windows XP console PC with DxI Software 5.2 and below:

    1. Select Alt+F4 and enter the password Access2Support (observing upper and lower case) to exit the user interface.
    2. Double-click on the Poet Object Server icon at the bottom right corner of the display. Shut down the Poet Object Server when it opens.
    3. Select Start > Programs > NexGen > NS Utility.
    4. Select the MFG Cleanup button in theNexStep Utilities dialog box.
    5. Select Yes to the Warning dialog box.
      Note: Status messages are displayed at the bottom of the NexStep Utilities dialog box.
    6. Select Exit when the cleanup is complete.

    For Windows 8 Mini PC with DxI Software 5.3.1 and above:

    Note: DxI Software 5.3.1 is compatible with Windows XP console PC. If the software was installed on the Windows XP console PC, then follow the Windows XP section to clean the software.
    1. From the Main Menu, press [Alt] + [F4] and then enter Access2Support to exit the user interface.
    2. Shut down the Fast Objects Server.
      • Press Ctrl + Alt + Delete and select Task Manager or right click on the task bar and select Task Manager.
      • In the Task Manager box, click on Processes, select FastObjects Server and click on End Task in the bottom corner of the box.
    3. Press Windows key, select NS Utility icon.
    4. Select the MFG Cleanup button in theNexStep Utilities dialog box.
    5. Select Exit when the cleanup is complete.
  3. Remove and discard any remaining supplies and waste.
    • Wash buffer cubes
    • Aspirate probes
    • Aspirate peri-pump tubing
    • Wash tower peri-pump tubing
    • Wash buffer and liquid waste transfer peri-pump tubing
    • Reaction vessels from:
      • Sample carousel
      • Wash wheel
      • Incubator wheel
      • Bulk feeder: Hopper, dispense chute, scoop
      • RV supply carriage
      • RV carriages
      • Instrument base
  4. Remove non-RoHS compliant Luminometer for disposal.
    Note: This section applies to instruments that were tagged for MOD 12912 and MOD 12913 only. See MOD procedures in the documentation distribution platform for more details and the impacted instruments list.
    1. Remove the non-RoHS Luminometer. Refer to Replacing Luminometer procedure.
    2. Follow the Decontamination of Returned Parts GLB-QS-PCD-0086 document and return the part to this address: 312 Lake Hazeltine Dr. Chaska, MN 55318.
  5. Decontaminate the instrument and peripheral surfaces.
    1. Decontaminate the intermediate waste containers, biohazard waste bin, and two liquid waste containers with the bleach solution.
    2. Decontaminate the keyboard, console computer, and monitor.
      Note:
      • Refer to decontamination instructions included in the decontamination kit.
      • Do not use cleaners with a pH of 9 to 10 on the touchscreen monitor.
    3. Clean instrument external skin, doors and covers, and solid waste area surfaces with the bleach solution.
    4. Power down the instrument.
    5. Shut down the console PC.

      For Windows XP System:

      • Select Start > Shut Down.

      For Windows 8 System:

      • Press Windows key, type turn off and select Settings > Turn off your PC > Power > Shut down.
        Note: The PC can also be shut down using Command Prompt application.
        • Press Windows key, open Command Prompt icon or type command prompt and open the program.
        • Type shutdown.exe /s /t 00 and hit Enter.
    6. When you have completed the procedure, do one of the following:
      • If the instrument is shipped or requires decontamination, then continue to the Deinstalling: Securing Components procedure.
      • If the instrument is remaining onsite and does not require decontamination, then power down the instrument and PC, remove all interlock bypasses, and replace all covers.
