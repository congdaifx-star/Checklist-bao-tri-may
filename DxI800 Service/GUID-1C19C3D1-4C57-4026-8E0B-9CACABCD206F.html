Troubleshooting CPU Alarm

This procedure describes how to troubleshoot the CPU alarm.

Pre-requisite:

Verify all CPU CMOS settings before troubleshooting the alarm.

Note: Refer to the Config - CMOS Setup document.
The CPU has an alarm that beeps when:
  • the CPU fan fails.
  • communication errors occur between the CPU and DAQC.
  1. Confirm that the CPU fan is working.
    1. Open the upper left front cover.
    2. Remove the upper left card cage cover.
    3. Verify that the Fan on the CPU PCB is operating.
      If the fan is not operating, replace the CPU PCB.
  2. Shut down the DxI instrument.
    1. Select Configure  > PC Admin > System Admin > Shutdown Instrument to exit the software in preparation for powering off the instrument.
    2. Enter the password Access2Support, and then select OK.
    3. At the pop-up You must now turn off the instrument, using the instrument power switch, select OK.
    4. After the instrument software has shut down, turn off the instrument at the power switch.
  3. Verify all PCB connections.
    Caution: The instrument must be shut down correctly through the user interface to avoid corrupting the AU hard drive.
    1. Open the upper left front cover.
    2. Remove the upper left card cage cover.
    3. Remove each PCB and reseat - one at a time until all PCBs have been reseated.
      Note: Do not overtighten the holding screw. Overtightening can cause the PCB to be seated incorrectly.
  4. Power on the instrument.
  5. Confirm that the beeping has stopped.
    • If the beeping has stopped, monitor the instrument for further occurrences.
    • If the beeping has not stopped:
      1. Repeat the Verify all PCB connections step.
      2. Remove the DAQC PCB.
      3. Power on the instrument.
      4. Confirm that the beeping has stopped.
        • If the beeping has stopped, replace the DAQC PCB.
        • If the beeping has not stopped, replace the CPU PCB.
