LAS: Enabling Logging of the Dynamic Connection for DxI Instruments Connected to LAS Systems For Troubleshooting

This document describes how to enable logging of the dynamic network connection for DxI instruments connected to LAS systems. The logs can be used to troubleshoot connection and setup issues.

  1. Press Alt + F4 to exit the DxI user interface, type Access2Support for the password and press Enter.
  2. Press the Windows key, type regedit, and open regedit.exe program.
    1. For Windows XP and Windows 8: Navigate to HKEY_LOCAL_MACHINE > SOFTWARE > Beckman > NexStep > Workgroup
    2. For Windows 10: Navigate to HKEY_LOCAL_MACHINE > SOFTWARE > WOW6432Node > Beckman > NexStep > Workgroup
    3. On the right hand side box, right click on PWPCommDiagEnabled select modify, change the Value Data number from 0 to 1 and select OK.
    4. For Windows XP and Windows 8: Navigate to HKEY_LOCAL_MACHINE > SOFTWARE > Beckman > NexStep > Console > System Setup
    5. For Windows 10: Navigate to HKEY_LOCAL_MACHINE > SOFTWARE > WOW6432Node > Beckman > NexStep > Console > System Setup
    6. On the right hand side box, right click on EnablePWPLogging select modify, change the Value Data number from 0 to 1 and select OK.
  3. Double click on NexGen Application icon to relaunch the user interface.
    Note:
    A live DxI Side Server dialog window will open. Return the DxA, Remisol, and DxI back to normal operation. Messages should start showing up immediately and samples don't have to be running. Only leave this window up during troubleshooting of the connection. Exit when finished and change the PWPCommDiagEnabled setting back to 0 when done. The PWP logging will create historical PWPLog files in C: NexGen > Console > DRW folder. PWP logging does not have to be disabled when troubleshooting is finished.
