System Check

This procedure describes how to perform the System Check.

This table lists the System Check details and specifications.

Perform the System Check.
  1. Fill a rack with four 13x100 tubes.
    • Tube 1 = 4 mL of 100% System Check Solution
    • Tube 2 = 2 mL of wash buffer
    • Tube 3 = Empty
    • Tube 4 = 2 mL of 1:501 diluted System Check Solution
      Note: Prepare the 1:501 dilution of System Check Solution by mixing 20 µL of System Check Solution with 10.0 mL of wash buffer.
  2. Select Sample Manager > New Request > Maintenance.
  3. Select All as the System Check Routine option, and then select OK.
  4. Enter the rack ID in the Enter ID field, and press [Enter].
  5. Load the sample rack and allow the tests to complete.
