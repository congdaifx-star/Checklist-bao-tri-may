Right Side Connectors - Card Cage - Upper Left - Layout

Connectors

Note:
  • Two possible versions of the CPU board exist. The boards can be distinguished by the color of the hard drive connector on the CPU board.
    • black hard drive connector: Advantech CPU PCB.
    • blue hard drive connector: Rocky CPU PCB.
  • For further information regarding the CPU boards refer to these documents:
    • Drawing - PCB - CPU
    • Electronic UL : Replacing CPU PCB for Analytical Unit
Connections Name

1

Luminometer Signal

2

LED Reference

3

Luminometer Control

4

LAS serial connector (COM1)

5

Network Hub (The cable to the hub has a ferrite bead, Advantech or Atom: LAN1, Rocky: LAN2)

6

Video Monitor.

7

Keyboard. (A Keyboard/Mouse splitter cable is provided with the Rocky and Atom CPU PCBs. If the cable is missing, then connect the Keyboard to the keyboard/mouse connector and a USB Mouse to one of the USB ports.)

8

USB 2 (Not Used)

9

USB 3 (Not Used)

10

USB 0 (Only used for Integrated Platforms.)

11

USB 1 (Not Used)

12

Mouse

13

Network Spare (Only used for Integrated Platforms. Advantech or Atom: LAN2, Rocky: LAN1)

Advantech CPU PCB connections (right end)

Rocky CPU PCB connections (right end)

For the Rocky CPU PCB, the cable from the AU network hub can appear as connection 5 in the network connections display. Rename the network connection that shows "connected" status when only the console PC is connected to the AU. Rename it connection 2 and configure it with the 192.168.2.4 address. For additional information, refer the Electronic UL: Replacing CPU PCB for Analytical Unit document .
