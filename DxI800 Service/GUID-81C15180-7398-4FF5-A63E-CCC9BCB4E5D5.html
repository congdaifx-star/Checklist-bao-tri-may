Software V4.5 Release Notes

Purpose

This document provides details of the most significant features and enhancements in DxI software version 4.5.

Confidentiality

Software release notes are confidential and should not be shared with customers.

Overview

Topic Details
CAPA and PCA Version 4.5 software supports CAPA 16241 resolution:
  • CAPA 16241 (PCA 16241) is for assay thermal bias that occurs when the instrument experiences significant changes in temperature.
  • Thermal sensitivity of assays reported in CAPA 16241 will be corrected with future changes beyond 4.5 software.
Customer Documentation Changes Customer documentation has been updated to include:
  • instrument ambient operating temperature range changed from 18 to 32 °C to 18 to 30 °C.
  • upper cabinet temperature range of 18 to 36 °C.
Definitions
  • Thermal algorithm: Adjust patient dose results as a function of temperature.
  • All tests: Patients, calibrations, quality control, and service assays.
Features
  1. The capability to implement thermal algorithms for any assay via future APF changes.
  2. Temperature monitoring of the upper cabinet thermistor.
  3. SYS flags to suppress results if the internal case temperature is outside of 18 to 36 °C. This feature applies to all assays and all tests.
  4. SYS flags to suppress results if the internal case temperature varies by more than 6 °C. This feature applies to all assays and all tests.
  5. Calibration failure reason of Temp. Out due to temperature-based result suppression (feature 3 and 4)
Release

Version 4.5 did not release worldwide.

Instead Version 4.6.1 releases the features listed in this document. Refer to the Release Notes for V4.6 and V4.6.1 Software.

Expected Behavior

Topic Details
SYS Flags with Event SYS flags occur on test results, if the upper case temperature is outside of 18 to 36 °C.

An event log Temperature [Upper Case] out of limits also posts to the event log.

SYS Flags with no Event SYS flags occur on test results, if the temperature varies by more than 6 °C while remaining within 18 to 36 °C during test processing (from the first aspiration to test completion).

No event posts for this condition.

The cause of the SYS flag can be confirmed by viewing the temperature logging data in the copy to diagnostic disk.

Calibration Curve Failure reason "Temp Out" Calibration curves fail with a reason of Temp Out, if the upper cabinet case temperature changes more than 6 °C during the processing of a calibration.
Upper Case Temperature Monitoring In the Maintenance Review screen, the upper cabinet box turns red if the upper cabinet temperature is out of range.

Diagnostic Copy to Disk The diagnostic copy to disk contains additional information:
  1. New columns at the top of the file:
    • Column BS: Result Temp
    • Column BT: Result Temp Calculation Method
    • Column BU: Expression
    • Column BV: Unadjusted Result
    • Column BW: Adjusted Result
    • Column BX: Curve Temp
    • Column BY Curve Temp Calculation Method
  2. New section "BO_Temps_Record" contains Test Serial # and temperature data for each test.
