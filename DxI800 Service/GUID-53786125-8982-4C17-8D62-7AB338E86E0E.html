Transferring Files (Trace/Debug/Data)

This procedure describes how to retrieve files from the AU or PC in preparation for analyzing the files.

Required Materials:
  • Laptop computer with a network connection.
  • Network cable (not a crossover cable).
Note: Transferring files from the AU to the PC does not require a laptop or a network cable.
Perform this procedure whenever it is necessary to transfer or retrieve these files in preparation for analyzing them:
  • AU files—trace, debug, specific.ini.
  • PC files—data or database.

For DxI instruments with software V5.1 and higher, transferring data to a flash drive might be simpler than transferring data directly to a laptop.

Files may be transferred from:
  • the AU to the PC.
  • the PC to a laptop computer.
  • the AU to a laptop computer.
  1. Transfer files from the AU to the PC.

    For Windows XP System:

    1. On the console PC, select Start > Run.
    2. Type \\192.168.2.4\C$ and select OK.
    3. At the password entry screen, enter
      • Connect As: user
      • Password: tech
    4. Select OK to log in.
      The file browser opens allowing access to all of the files on the AU C: Drive.

    For Windows 8 System:

    1. Press Windows key, type run and open the Run program.
    2. Type \\192.168.2.4\c$ and select OK.
    3. At the password entry screen if prompted, enter
      • user for account name.
      • tech for user password.
    4. Select OK to log in.
      The file browser opens allowing access to all of the files on the AU C:\ drive.
  2. Connect the network cable into the laptop network connector and the instrument network connector on the SPU.
    Note: The instrument network connector is located on the underside of the SPU, on the far right.
  3. Configure the laptop for remote connection.

    For Windows XP Laptop:

    1. Select Start > Settings > Control Panel > Network Connections..
    2. Right-click on Local Area Connection.
    3. Select Properties > Internet Protocol (TCP/IP)  > Properties > Use the Following IP address, and type 192.168.2.5.
    4. Press the [Tab] key, and then select OK > OK.

    For Windows 10 Laptop:

    1. Press Windows key, type in control panel and select Control Panel.
    2. Select Network and Sharing Center > Change adapter settings.
    3. Right click on Etherent, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    4. Select Use the following IP address, type IP address 192.168.2.5 and Subnet mask 255.255.255.0.
    5. Select OK to save the changes.

    For Windows 8 Laptop:

    1. Press the Windows key, type network connections and select the View Network Connections icon under the settings search.
    2. Right click on Local Area Connection, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    3. Select Use the following IP address, type IP address 192.168.2.5 and Subnet mask 255.255.255.0.
    4. Select OK to save the changes.

    For Windows 7 Laptop:

    1. Press the Windows key > Control Panel > Network and Sharing Center > Change adapter settings.
    2. Right click on Local Area Connection, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    3. Select Use the following IP address, type IP address 192.168.2.5 and Subnet mask 255.255.255.0.
    4. Select OK to save the changes.
  4. Transfer files from the PC to the laptop.

    For Windows XP laptop:

    1. Select Start > Run.
    2. Type \\192.168.2.3\C$, and then select OK.
    3. In the password entry screen, enter
      • Connect As: user
      • Password: tech
    4. Select OK to log in.
      The file browser opens, allowing access to all of the files on the PC C:\ drive.
    5. Navigate to the files that you want to capture, then use the standard windows functions to move them to the laptop: copy and paste, drag and drop, or send to.

    For Windows 8 laptop:

    1. Press Windows key, type run and open the Run program.
    2. Type \\192.168.2.3\c$ and select OK.
    3. At the password entry screen if prompted, enter
      • user for account name.
      • tech for user password.
    4. Select OK to log in.
      The file browser opens allowing access to all of the files on the AU C:\ drive.
    5. Navigate to the files for capture, and then use the standard windows functions to move the files to the laptop: copy and paste, drag and drop, or send to.

    For Windows 7 laptop:

    1. Press Windows key, type \\192.168.2.3\c$ to the "Search programs and files" box and hit the Enter key or select Run program on the right side, type \\192.168.2.3\c$, and select OK.
    2. At the password entry screen if prompted, enter
      • user for account name.
      • tech for user password.
    3. Select OK to log in.
      The file browser opens allowing access to all of the files on the AU C:\ drive.
    4. Navigate to the files for capture, and then use the standard windows functions to move the files to the laptop: copy and paste, drag and drop, or send to.
  5. Transfer files from the AU to the laptop.

    For Windows XP laptop:

    1. Select Start > Run.
    2. Type \\192.168.2.4\C$ and select OK.
    3. At the password entry screen, enter
      • Connect As: user
      • Password: tech
    4. Select OK to log in.
      The file browser opens allowing access to all of the files on the AU C:\ drive.
    5. Navigate to the files for capture, and then use the standard windows functions to move the files to the laptop: copy and paste, drag and drop, or send to.

    For Windows 8 laptop:

    1. Press Windows key, type run and open the Run program.
    2. Type \\192.168.2.4\c$ and select OK.
    3. At the password entry screen if prompted, enter
      • user for account name.
      • tech for user password.
    4. Select OK to log in.
      The file browser opens allowing access to all of the files on the AU C:\ drive.
    5. Navigate to the files for capture, and then use the standard windows functions to move the files to the laptop: copy and paste, drag and drop, or send to.

    For Windows 7 laptop:

    1. Press Windows key, type \\192.168.2.4\c$ to the "Search programs and files" box and hit the Enter key or select Run program on the right side, type \\192.168.2.4\c$, and select OK.
    2. At the password entry screen if prompted, enter
      • user for account name.
      • tech for user password.
    3. Select OK to log in.
      The file browser opens allowing access to all of the files on the AU C:\ drive.
    4. Navigate to the files for capture, and then use the standard windows functions to move the files to the laptop: copy and paste, drag and drop, or send to.
  6. Reset the laptop connection settings to normal.

    For Windows XP Laptop:

    1. Select Start > Settings > Control Panel > Network Connections..
    2. Right-click Local Area Connection.
    3. Select Properties > Internet Protocol (TCP/IP)  > Properties.
    4. Select the Obtain an IP address automatically option.
    5. Select OK > OK.

    For Windows 10 Laptop:

    1. Press Windows key, type in control panel and select Control Panel.
    2. Select Network and Sharing Center > Change adapter settings.
    3. Right click on Etherent, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    4. Select Obtain an IP address automatically. .
    5. Select OK to save the change.

    For Windows 8 Laptop:

    1. Press the Windows key, type network connections and select the View Network Connections icon under the settings search.
    2. Right click on Local Area Connection, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    3. Select Obtain an IP address automatically.
    4. Select OK to save the change.

    For Windows 7 Laptop:

    1. Press the Windows key > Control Panel > Network and Sharing Center > Change adapter settings.
    2. Right click on Local Area Connection, choose Properties, select Internet Protocol Version 4 (TCP/IPv4) and choose Properties.
    3. Select Obtain an IP address automatically.
    4. Select OK to save the change.
