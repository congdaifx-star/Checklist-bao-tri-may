Tool - Aspirate Probe Plate

Drawing



Description

The aspirate probe plate adjustment tool is a custom made plastic tool for use on DxI instruments.

Note:
  • Three of these tools are required to perform the adjustment correctly.
  • This tool is available separately, or as part of the complete Specialty Tool Kit, or as part of the three piece Specialty Tool Upgrade Kit. Search for "tools" in the DxI parts list for part numbers.

Part Number

Part Number A21818

Uses

The tool is used on DxI instruments to aid in the adjustment of the aspirate probe plate to the wash carousel which aligns the aspirate probes to the reaction vessels in the wash carousel.

Instructions for Using

Refer to the AU: Adjusting Analytical Module procedure.

Calibration

Not required - Replace if damaged.
