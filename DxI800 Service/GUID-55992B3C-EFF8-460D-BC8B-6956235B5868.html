PCB - Interface - Lower Cabinet

Purpose

This document provides these details for the Lower Cabinet Interface PCB
  • Drawings.
  • Details: Test Points, LEDs, Connector Overview, Connector Pin-outs.
  • Schematics.
  • Location.
:

Drawings

Note: The silk screen for D2 and D3 (on both versions of this PCB) are incorrect. They are reversed. Refer to the Details section for the correct information.

Details

The Lower Cabinet Interface PCB connects to these devices:
  • DAQC PCB.
  • MCC Backplane PCB (MCC3, MCC6).
  • Bulk Fluid Tray Interface PCB (Buffer, Waste).
