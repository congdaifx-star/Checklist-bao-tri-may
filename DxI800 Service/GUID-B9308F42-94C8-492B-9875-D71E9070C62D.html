Replacing Reagent Load Tray Mount

This procedure describes how to replace the reagent load tray mount.

Replace the reagent load tray mount when installing a linear slide reagent gripper if the existing tray mount is the machined version. An injection molded tray mount is used with the linear slide. If the mount is not replaced when installing the new gripper, it will interfere with gripper movement

  1. Remove the reagent storage module from the instrument. Refer to the Removing Reagent Storage Module procedure.
    Note: There is insufficient space to remove the reagent load tray when the reagent storage module (RSM) is still inside the instrument.
  2. Disconnect the reagent load tray motor J19, tray out sensor J23, and tray in sensor J26 connectors from the reagent storage interface PCB.
  3. Remove and retain the 4 screws that secure the reagent load tray to the reagent storage module.

  4. Grasp the reagent load tray assembly from the outside of the RSM and pull to remove it from the module. Set it on a table for easy access.

  5. Remove the 2 screws that secure the left side cover to the load tray assembly and slide the cover off the shaft.

    Note: Ensure that the bushing on the cover stays in position after removing the cover from the shaft. The bushing can be re-inserted in the cover if it falls off when disassembling.
  6. Remove the 4 screws that secure the reagent load tray base to the load tray mount and hold the shaft when separating so that the washers don't fall off the shaft inside the base.

  7. Remove the tray in sensor from the reagent load tray mount.

  8. Install the tray in sensor into the new reagent load tray mount and route the cable through the slot in the mount

  9. Hold the shaft to prevent washers from falling off and re-attach the reagent load tray base to the new mount. Make sure both shafts go into bushing holes on the mount and secure the base to the mount with 4 screws.

  10. Put left side cover on the shaft and ensure that the bushing is in place. Slide cover to the right and secure it to the load tray assembly with 2 screws. Pictures are in previous steps above.
  11. Insert reagent load tray assembly into position in the RSM and ensure that the shaft is fully seated in the bearing block. Secure in position with 4 screws from inside the RSM.

  12. Re- connect the reagent load tray motor J19, tray out sensor J23, and tray in sensor J26 connectors to the reagent storage interface PCB.
  13. Re-install the reagent storage module. Refer to the Installing Reagent Storage Module procedure.
