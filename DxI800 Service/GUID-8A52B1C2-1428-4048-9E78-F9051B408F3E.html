Purpose

  • Drawings.

Drawings

Details

The Analytical Module Interface PCB connects to these devices:
  • MCC Backplane PCB. (MCC7)
  • Power Distribution PCB.
  • Analytical Module stepper motors (4).
  • Analytical Module Motor Encoders (2).
  • Analytical Module heaters (4).
