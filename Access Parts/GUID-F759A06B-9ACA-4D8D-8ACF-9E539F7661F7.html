Interface PCBs

Illustrated Parts List

This document contains parts for the Access 2 and Access 2 Enhanced Electronics, Printed Circuit Boards (PCBs).

Note: Access 2 and Access 2 Enhanced systems share components. The Access 2 Enhanced parts list table identifies components that are currently used only for the Access 2 Enhanced systems.
Table 17: Access2 Interface PCBs Parts List
Item Description Order Number Notes
1 PCB, Main Pipettor Interface. RoHS B35418 Replaces 8806A.
2 PCB, Interface, Fluidics. RoHS B33354 Replaces P/N 7639F. No longer able to order just the vacuum sensor.
3 PCB, Interface, Sample / Reagent Carousel, RoHS, with Bracket C20889 RoHS-compliant PCB. Has fan speed control. Has bracket to protect PCB. Replaces B35420.
Note: You must install the bracket included in the kit unless the identical bracket is already on the system.
4 PCB, Interface, X- Axis - For 3 Inch Pipettor. RoHS B35416 Replaces 8803A.
5 PCB, Cup / Tube Reader (Tube Detector PCB) RoHS A59724 Replaced by C30735 at stockout.
PCB, Tube Sensor Board (Tube Detector PCB) RoHS C30735 Replaces A59724 at stockout.
6 PCB, Interface, Analytical Module. RoHS A60765 Replaces part 6618E at stockout. New PCB has index sensor adjustment.
Kit, Analytic IF PCB & Incubator Index Sensor, RoHS A61030 Kit contains both the new Incubator Belt Index Sensor (A60636) and the Analytical IF PCB (A60765). New sensor requires the use of the new PCB. Old sensor (973028) will work with both types of PCB.
7 Kit, RV Sensor PCBs, RoHS 386171

Kit contains two RV Sensors (PCBs) and 4 screws to secure the PCBs in place.

8 PCB, Obstruction Detection RoHS B93918 PCB only. Has 6 pins connection and only compatible with pressure sensor part# B98041 that has 6 pins connector. Order the following parts if needed:
  • Obstruction detection signal (optical) cable part# 09-011196-1.
  • Obstruction detection ribbon cable part# 09-011197-1.
  • Pressure sensor part# B98041.
    Note: Has 6 pins connector and only compatible with PCB part# B93918 that has 6 pins connection.
Note: Access 2 and Access 2 Enhanced systems share components. Components listed in parts list are for Access 2 Enhanced systems only.
