Vacuum System

Illustrated Parts List

This document contains parts for the Access 2 Fluidics Vacuum System assembly including:
  • Fluidics Interface PCB
  • Plastic Standoff
  • Frame Screw
  • Case Temperature Thermistor
  • Vacuum Sensor
  • Vacuum Pump
  • Tubing
  • Fittings
  • Vacuum Jar/Bottle
  • Probe Wash Assembly (including Wash Tower)
