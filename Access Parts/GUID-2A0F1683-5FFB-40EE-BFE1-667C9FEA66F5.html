9 Access 2 Hard Drive with Software (Field Service Kit) ROHS C38147
  • Solid state 8 Gb Compact Flash (CF) Card flash drive that connects directly to the back of the VDX2 CPU PCB. No cables are required.
  • Works only with the short VDX2 CPU board.
  • Requires NIC PN 973141. If the AU has the older Network Interface Card, then also order a new NIC card or be able to load older NIC drivers into this new drive using floppy disks made from files in the service manual. Refer to the "Making Utility Disks On Site" procedure for details. Communication errors will occur if the correct NIC driver is not installed.
  • The drive comes loaded with OS9000 software but not System Software. Follow the "AU Hard Drive, Replacing Access 2." procedure when replacing the AU hard drive.
Drive, Hard, Access2, Instrument, RoHS A50385
Note:
  • Solid state 8 Gb flash drive that connects directly to the CPU PCB. No ribbon cable is needed.

  • The flash drive power cable connects to old HDD power harness.
  • Works only with the short 486 Dx4-S, Iowa, or newer CPU PCBs.
  • Requires NIC PN 973141. If the AU has the older Network Interface Card, then also order a new NIC card or be able to load older NIC drivers into this new drive using floppy disks made from files in the service manual. Refer to the "Making Utility Disks On Site" procedure for details. Communication errors will occur if the correct NIC driver is not installed.
  • The drive comes loaded with OS9000 software but not System Software. Follow the "AU Hard Drive, Replacing Access 2." procedure when replacing the AU hard drive
