PC Consoles and Components

Note: Console PC's are listed from top to bottom in order of newest (most recently released) to oldest models.

Table 38: Windows 10 "Mini" PC Parts List
Item Description Order Number Notes
1 Assembled Console + Monitor Windows 10 C73788

Kit contains mounting bracket, monitor, and PC. Also includes keyboard, USB backup flash drive, reimage flash drive, optical drive (with USB cable), mouse, USB BCR cable, video cable, and external power cable.

Important: Order when replacing an existing Windows XP or Windows 8 PC. Older PC system mounting brackets are not compatible with the Windows 10 PC.

Software compatibility depends on PC part number (may need to remove PC from mounting brackets to see PC PN sticker):

  • PC PN C73368 - Only compatible with Windows 10 software 3.7.0 CD (lot number C73398) or above (order software CD B35312 or D00133).
  • PC PN D07915 - Only compatible with software 4.0 or above (order software CD D00133).

Replaces all standalone Access 2 and Access 2 Enhanced Windows 8 PCs (C56589, C56590, B88029, and C33695), except integrated Access 2 (A2i) PCs. Replaces all standalone Access 2 Windows XP PCs (B55102, B80128, A80541, and B07034). For integrated Access 2 (A2i) instruments, order C33695 or C56589.

Windows 10 Console PC (with OS hardening image) D07915

This PC comes loaded with Windows 10 OS. It includes privacy and security features and additional OS hardening. Also includes keyboard, USB backup flash drive, reimage flash drive, optical drive (with USB cable), mouse, USB BCR cable, video cable, and external power cable.

Important: Order when replacing an existing Windows 10 PC.

Only compatible with software 4.0 or above (order software CD D00133).

2 Drive, Optical, CD DVD RW Drive External B93861 External CD drive.

Note: PC eligible for re-commercialization. Ensure defective unit is returned when replacing. Only applicable to B88029. Privacy and Security compliant PC console is not compatible with re-commercialization at this time.
