Sample and Reagent Carousel

Illustrated Parts List

This document contains parts for the Access 2 and Access 2 Enhanced Sample and Reagent Carousel assembly including:
  • Sample carousel and components
  • Reagent carousel and components
  • Barcode reader
  • Interface PCB
Note: Access 2 and Access 2 Enhanced systems share components. The Access 2 Enhanced parts list table identifies components that are currently used only for Access 2 Enhanced systems.
