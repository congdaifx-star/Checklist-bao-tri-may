Luminometer

Illustrated Parts List

This topic contains part numbers and descriptions for the DxI 9000 Luminometer subsystem and components, including but not limited to:

  • Door/Cap Assembly
  • Cables

Luminometer Assembly

Note: Few of the electrical/signal components on the luminometer can be replaced individually, as the parts are mated and programmed together. In the event of a luminometer failure, the entire assembly should be replaced.
Order Number Mfg. Number Oracle Description Service Description Notes
C83385 C09882 Kit, Luminometer Assy Luminometer Assembly Entire subsystem assembly.

Door/Cap Assembly

Item Order Number Mfg. Number Oracle Description Service Description Notes
1 C58952 C58952 ASSY, CAP AND MOTOR, LUMINOMETER Motor/Cap Assembly, Luminometer

Cap comes pinned to motor shaft as one assembly. Does not come with motor mount / alignment pin.

Notch in flag wheel should face away from the cap when assembling.

2 B77768 B77768 ASSY, SENSOR, ANGLED Sensor, Luminometer Door Open/Close

Both open and close sensors are the same part number.

3 C79173

C79173

WHEEL, FLAG, LUMINOMETER Open/Close Sensor Flag Wheel, Luminometer

Wheel that triggers the door open/close sensors. Fastens to the end of the motor/cap assembly. Notch in the flag wheel should face away from the cap when assembling.
