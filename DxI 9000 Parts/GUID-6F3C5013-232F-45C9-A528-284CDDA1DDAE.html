Item Order Number Mfg. Number Oracle Description Service Description Notes

Exterior "skin" for the front of the solid waste drawer.

2 N/A C36571 Asy/Waste BOX, Tray Solid Waste Intermediate Tray Assembly

This is the "escrow" tray that catches tips/vessels when the solid waste drawer is open/bin is not present.

7 N/A C14259 CHUTE, VESSEL, SW Vessel Waste Chute

Same for Sample and Incubate PnP chutes.

8 N/A C57612 ASSY, WASTE DRAWER Solid Waste Drawer Frame

This is the drawer "frame" that the waste bin sits into. Drawer slides and door fasten to this.

9 N/A C21435 STAY, DRAIN, SW Solid Waste Drain Tubing Fittings Bracket

C14617 C14617 FITTING, 1/4 HOSE BARB COUPLING 1/4" Hose Barb Coupling, Female
C23952 C23952 FITTING, 1/8" NPT X 3/16" HB STRAIGHT Drain Tubing, Barbed, Male, 1/8" NPT
C23951 C23951 FITTING, 1/8" NPT X 6 MM TUBING Pneumatic Drain Tubing Fitting, 1/8" NPT
10 C37556 C37556 REFLECTOR, SOLID WASTE BAG Solid Waste Bag Sensor Reflector
11 B77769 B77769 ASSY, SENSOR, WIDE Solid Waste Drawer Sensor

Detects if drawer is open or closed. Same as intermediate tray sensor.

12 C37554 C37554 BAG DETECT SENSOR, SOLID WASTE Solid Waste Bag Sensor

Reflective beam type sensor that interacts with reflector C37556 at front of drawer.

13 N/A N/A N/A Solid Waste Drawer Slide

Same slide for both left and right sides. Not orderable, contact Technical Support if needed.

14 B77769 B77769 ASSY, SENSOR, WIDE Solid Waste Intermediate Tray Sensor

Sensor detects if intermediate waste tray is open/closed. Same as drawer sensor.

15 C14265 C14265 PIN, BIN Solid Waste Bin Deflector

White plastic deflector/pin at rear of solid waste bin that opens the intermediate waste tray when bin is present and drawer is closed.

16 C85385 C85385 BIN, SOLID WASTE Solid Waste Bin

Bin only, no hardware attached.
